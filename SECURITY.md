# Security Policy

## Reporting

Please report vulnerabilities privately — use GitHub's **"Report a vulnerability"** (security advisory) on this repository, or contact the maintainer [@dwgx](https://github.com/dwgx).

## Scope notes

- This repository contains research content and scripts; the bundled skill executes prompts and local scripts only.
- **Never commit credentials or tokens.** If you find any exposed secret, report it immediately — it will be rotated and redacted.
