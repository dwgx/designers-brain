# Design Brief — gate 文件（walkthrough_01 ·「拾光」开业主视觉）

> 用途：设计 / 替换任务的「批准前落盘」gate 文件（skill：Designers_Brain 设计顾问）。**「文件不在 = 环节没做」。**
> 出处：`templates/design_brief.md`；`docs/skill/skill_ecosystem.md` §4.5-2 / §5.3；`docs/skill/skill_spec.md` §2.4。
> 纪律：没问到的 = 假设（内容 + 默认 + 错了的代价），不许静默；「用户选择原话」逐字引用，不转述。
> 落盘时点：2026-10-15 · 客户选定方向（「第 2 个。」）之后、定稿图产出之前（批准前落盘）。

## 1. 意图（要什么）

- 一句话：「拾光」独立咖啡馆开业主视觉——先出海报主视觉 1 张（后续可能延展 10 秒小动画发小红书）。
- 业务 / 产品 / 身份：新开的独立咖啡馆「拾光」。
- 受众 + 场景：本地生活感客群（20–35 岁；小红书刷到 + 进店看到）。**受众为假设**（客户未答）。

## 2. 非目标（不做什么）

- 10 秒动画（本轮不做；需另行授权，不越级）。
- 排版终稿 / 印刷文件（本轮只到「无字主视觉」；店名与文案后期排）。
- 店门口照片的修图与使用（质量一般，未采用）。
- Logo 设计（客户明确没有 logo；本轮到主视觉为止）。

## 3. 约束

- 输出形态：**图像 prompt**（海报主视觉）。
- 时长 / 尺寸 / 渠道：竖版 2:3（通道实回 768×1152；请求 1024×1536）；小红书 + 店内张贴。
- 物料（路径）：店门口照片（客户口头说有，未给路径；**不采用**）；无 logo；无现成文案（顾问编造并标注）。
- 风格模块（主 / 辅）：**维米尔（主 70%）+ 莫奈（辅 30%）**——轴归属：表面/笔触轴归维米尔；莫奈仅贡献「大气包络」（远景对比压缩、色相收拢）；莫奈笔触条按 N3 整条移除（非降档）。
- 强度档：主·维米尔 §4 默认（P1 75% / P2 70% / P3 80% 静物·器物档 / P4 60% / P5 80% / P6 85%）；辅·莫奈仅包络轴（P3 默认 50%）。
- 预算 / 期限：预算一般（未给数字）；期限未给。
