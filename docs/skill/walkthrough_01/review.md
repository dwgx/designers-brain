## 4. 修复清单（按对最终印象的影响力排序）

1. **【抬 wow + 概念】让蒸汽"接住光"**：现在蒸汽对比太低、读不出"光"，而全画最亮的事发生在壶口（L=253）。在蒸汽束与窗光锥交叠区叠一层暖金（RGB≈252,236,206，不透明度 12–20%，羽化 6–10px），蒸汽顶端补 3–5 个 1–2px 圆点高光。为什么重要：客户要"记忆点"，"拾光"（把光拾起）的语义目前画面零兑现；这同时把 10 秒动画里唯一该动的元素（维米尔 §8.2-8 单一事件）提前立好。
2. **【概念】把"引用"降级成"语法"**：改 2–3 个构图变量（人物由正侧转 3/4 背、桌子改为更大斜入前景占画高 ≥35%、窗只露下半扇），目标是与原画并排时结构相似度 <70%；光逻辑与色板不动。为什么重要：不拉开距离，这张 KV 的品牌可替换性始终是 100%。
3. **【必须 · 风格/质感】修暗部触黑**：把 L<8 的 1.4% 像素（裙摆下部、桌下阴影、桌/碟暗面，最大连通块 2935px@y75%/x48%）抬到 L≥20，色相转向冷蓝灰（目标 RGB≈26,34,44，B-R≥+12，对齐现有墙面暗部 26,32,37），区域内部 std 保持 ≤5/255。为什么重要：这是 §8.2-7 的硬阈值，也是维米尔"暗部=平坦冷蓝灰"这条签名技法在下半幅断档的直接原因。
4. **【必须 · 质感】消 1px 硬边**：杯口左缘 1px 内 ΔL=143（74→217）、壶身高光边缘同类；做 1–2px 高斯过渡（σ=0.5–1）后叠 0.5px 亮芯。为什么重要：§8.2-5 明禁 1px 描边；这也是放大后"贴片感"的来源。
5. **【建议 · 风格】点彩补锐度**：在壶身/杯口/面包皮/碟沿增加直径 0.75–2.25px@768（=1–3px@1024）的圆点高光，每器物 ≥15 个、圆度 >0.7、与底材亮度差 ≥+60L（现状：壶 9 / 杯 3 / 面包 12 个圆点，其余为软斑）。为什么重要：P3 静物档 80% 的判据就是这种颗粒感。
6. **【建议 · 设计】把排版安全区数字化**：标题锁定 x 432–768 / y 96–500（避开人物头顶 x300–450/y200–400，实测最干净亮区在此）；小红书 feed 3:4 缩略会裁掉上下各 ~5.5%（64px），标题上缘不得高于 y=96px；底部深色带留给小字或压一条 6–8% 画高的暗色渐隐。为什么重要：无字 KV 的一半价值是"后期排得进去"，现在这层是碰巧空着而非留出来的。
7. **【建议 · 规格】店内张贴分辨率**：当前 768×1152 仅够屏幕；至少 2× 重渲（1536×2304）再 4× 放大 + 1–2% 颗粒，或换通道出 ≥1024×1536，A3 300dpi 目标 3508×4961。为什么重要：用途含店内张贴，直接打印会明显发虚。
8. **【建议 · 融合诚实性】莫奈轴二选一**：要么在窗光/蒸汽交界加 10–15% 暖雾（RGB≈225,215,195）把全画最暗值抬到 35–40，做出"光在空气里"的包络证据；要么在 prompts.json 把该轴如实标 N/A（画内无"远景"可作用）。为什么重要：现状是"声明级融合"，画面实际 100/0；如实标注比虚假融合更保护复现性。
9. **【建议 · 色彩】补一处红色点缀**：全图红色像素仅 0.052%（且多为肤色），卡要求"tiny red accents"。建议加一处 <0.5% 面积的红（如碟边一小片红色点心，RGB≈150,45,40），既守蓝-黄主色对，又给眼睛一个记忆锚点。

## 5. 末段

**必须修复项**
- 暗部触黑（L<8 占 1.4%，最低 0.0）与局部 1px 硬边——对卡 §8.2-5/-7 的硬性违规，也是下半幅风格语言断档的根源（清单 3、4）。
- 品牌可替换性 100%（无专属母题、名画直引）——客户"记忆点"需求的正面失败（清单 1、2）。
- 店内张贴分辨率不足（768px 宽 vs 打印级需求）——打印前必须重渲/放大（清单 7）。

**建议优化项**
- 点彩锐度/圆度（清单 5）；排版安全区数字化与 3:4 裁切余量（清单 6）；莫奈轴的诚实化或补证（清单 8）；红色点缀（清单 9）。

**无法验证项**
- 地砖/窗框的单点透视灭点是否同一且落画面高 55–65%（未做反投影复核，受本次"不写文件"限制，只能目测"近大远小、有汇聚趋势"）。
- 画布织纹是否"几乎不可见"（768px 下不可判，需原始渲染尺寸）。
- 手部/面部在 100% 像素下的解剖细节（本次只有整图目视 + ASCII 放大；目视未见畸形，但不构成像素级结论）。
- 打印色域与纸张适配（无 CMYK/ICC 信息）。
- 动画阶段全部指标（运动工艺、声音同步、包络漂移）——静态图无法评。
