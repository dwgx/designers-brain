## 三、opt-out 路径（若用户下一条回「直接做就行」）

> **口径**：opt-out 免的是「提问轮次」，不免视觉门与留档纪律；成本敏感按最省口径执行——「用看得见的东西代替继续追问」。唯一不静默的是**风格画面本身**：给「看得见的候选」替代追问；若用户再次不回应，才取最强假设继续。
> 依据：`SKILL.md`「何时用」例外 + `skill_spec.md` §2.1 例外 A / §2.5。

1. **停问**——不再补问、不再索要物料；把用户原话「直接做就行」原样记下（gate 文件要用）。〔`SKILL.md` L25；`skill_spec.md` §2.1（L147）〕
2. **默认值补齐五件 + 假设清单（内容 + 默认 + 错了的代价）**：
   - 主题 / 内容：拾光咖啡馆开业主视觉（已知）；
   - 风格模块：**单模块**（默认非组合）；按域过滤自核取最强候选——「别太花哨、要有记忆点 + 咖啡 / 光」→ 光感 / 海报系（例：莫奈 / 维米尔 / 马蒂斯；以 `artist_modules/README.md` 能力定位 + `conflicts.md` 复核为准），**能查的不问、自己核**；
   - 替换轴：D 从零选型（假设）；
   - 输出形态：图像 prompt（海报）；10 秒动画另起（后续、需另行授权）；
   - 强度：卡内 §4 默认档起步；**[UNVERIFIED]**：E3 强度扫描未做 → 不做强度定量承诺；
   - 受众 / 物料：默认「本地生活感客群 / 无物料（文案配色编造并标注）」。
   - 一行示例：`假设：受众=本地 20–35 岁生活感客群；物料=无（编造并标注）；D 从零；单模块；强度=默认档；形态=图像——代价：受众若偏差→文案需重调；物料若后补→文案/配色返工。`
   〔`skill_spec.md` §2.3（默认说出口）/ §2.4（缺件默认：单模块、§4 默认档、§3.5 形态映射；假设留档 L182）；`SKILL.md` 红线（L106，[UNVERIFIED] 标注）〕
3. **视觉门照走（拒答不枯等）**——用户已放弃「选择参与」：按「继续到『可展示』再停」产出 **2–3 个看得见的差异化方向候选**（E 系列出图通道、低成本小图；每个 = 方向名 + 一句定位 + 一张图），**展示后停、等选择**；用户一个字母即可选定（「假设即选项」：两个 labeled 候选 > 一个落地猜测）。若仍无回应 → 取最强假设继续到下一「可展示」（首稿）再停，不枯等、不静默。〔`SKILL.md` L49；`skill_spec.md` §2.5（L190–192）；`skill_ecosystem.md` §4.3-16 / §4.3-17（L286–289）〕
4. **冲突预检（自核）**——单模块口径：无需 C 条处置、核对 §4 near-miss 取值；若最终成组合（主 + 辅 70/30）→ 跑全流程：§1 总表 → §4 near-miss 显式取值 → N1 反约束重算 → N3 轴所有权表 → N4 可拆 / 不可拆 → N9 验收口径；**静默折中禁止**。〔`references/conflicts.md` → `knowledge/cross/conflicts.md`；`skill_spec.md` §3.3（L248）〕
5. **出稿要素（图像形态必带字段）**——主题句 + 风格段（§8.1 或 §8.1b，逐字）+ 强度档 +（70/30 时）融合句 +（可拆冲突时）分区句 + 负向段（留档、通道无负向不发送）+ 通道口径（裸模型名 `grok-imagine-image-2.0`；尺寸实回 768×1152）；留档契约 = req / resp + sha256（可追溯、不承诺可复现）。〔`SKILL.md`「怎么出」；`skill_spec.md` §4.5.1；通道细节 `knowledge/cross/image_channel.md`（经 `references/pipelines.md`）〕
6. **gate 文件落盘**——`design-brief.md`：意图 / 非目标 / 约束 / 用户选择原话 / 假设清单 / 批准范围；「文件不在 = 环节没做」；批准只覆盖实际展示过的东西（方向候选 / 首稿），**不越级**到动画。〔`templates/design_brief.md`；`skill_ecosystem.md` §4.5-2；`skill_spec.md` §2.4（L183）〕
7. **出稿后独立评审**——按 `review_rubric.md`：先机械后人工、目标 ≥9、Do not inflate；交付前干净上下文终检（带帧号 / 证据）。〔`SKILL.md`「怎么出」·出稿后；`knowledge/cross/review_rubric.md`〕
8. **展示后停 + 授权边界**——出完即停轮、等反馈；不得自选继续（10 秒动画、发布等动作需其对应授权）；轮次账：opt-out = 补问 0 轮，用户以单字母 / 一句话选定即进入定稿。〔`skill_spec.md` §2.5；`skill_ecosystem.md` §4.5-3〕

**走完标志**：假设已一行列出、候选（或首稿）已展示、gate 文件已落盘、停轮等待——缺一即未走完。

## 四、自审（四段）

**① 合规核对（做对了什么）**：逐条对照——(a) 先问后做、未直接出稿：第一动作 = 首问包（`SKILL.md` L25）；(b) 例外判定正确：A 未触发（用户没说「直接做 / 随便」）、B 不成立（②③未给、⑤未明）；(c) 收敛纪律：猜测式提问（④⑤）、默认说出口（②③④ + 两条约定）、能查的不问（未问卡 / 冲突）、≤3 轮预算（本条 = 第 1 轮）；(d) 视觉协议预告到位：成本敏感 → 文字方向卡（L49 / §2.5），「展示后停」留到实际展示时执行；(e) 未出稿、未生成图片（本记录性质）。与 RED 基线（同场景）相比，把「方向给太早」「提问偏多」两处压掉——这正是 skill 要修的行为差。
