## 撤回和修复了什么

最初冻结候选的独立门审是 NEEDS_REPAIR。七项具体问题包括：缩放包装被称原生 1080、mp4v 浏览器兼容、遗漏 UI 修补、语料矩阵过度覆盖、公开日志中的机器路径、Klimt 条件许可未被当前清单接纳、缺四个 seed 包。本轮逐项落实工程修复，没有覆盖旧失败记录。

进一步复核又发现原 seek 报告虽然写通过，实际时间全为0；新测试通过 HTTP Range 206、请求/观察时间、解码后画布哈希与真实播放前进共同判定。另一个真实故障是并发 UI 测试共享 Chrome 临时目录；现使用独立临时目录，四个并发进程复跑通过。权利负例曾因 Windows 默认编码崩溃，修正后以预期诊断失败，未把偶然异常当成通过。

Motion-03 修正六本书的侧面/顶面和遮挡关系、中文地面文字与最后连续拉远。Motion-14 修正相机取整导致的约2.7%跳变；用浮点相机后最大相邻缩放变化约0.451%。其水量图直接指向 USGS 表：展示若干选取类别，类别合计不是完整分割；淡水湖和河流合计约0.0072%，极小柱的可见性下限明示，不称“可用水”。

19项文本修补包含：短边1080对应的像素换算、冲突卡 B 的整画幅归属、杜勒间距比例与角度区别、萨金特计数39/9/5、霍珀1≤3的逻辑、光源可在画外等。七份新 how-to-think 全部按当前来源组织“选择—取舍—失效—自查”，明确标为本轮归纳，未声称复原画家心理。李可染亮区与留白统计都以全画幅为分母，并要求分掩膜及记录交集。

## 历史阅读覆盖

原网页导出包含1899个节点：21条用户消息、1191条 assistant、686条 tool。主审读完169段叙事及21条用户决定；独立审阅建立1360条操作账：674项 assistant 工具请求与686项工具返回。

686项工具返回只有141项有正文，545项为空；至少26处截断。5个嵌入ZIP完成解码、CRC与哈希核对，但并未宣称所有成员、407个 OMP子日志或所有外部引文全文均已重新阅读。无法恢复的历史输出仍未知，报告中的成功语句没有代替当前运行验证。

## 新 C1 的结论为何没有改成通过

新消费者在隔离的 e0 输入上完成一次26分20秒的试验，15个 A 文件先封存，B 在留出参考揭示前冻结。实际修改 SVG 与 PNG 的负控触发指定失败。Root和独立审阅者都观看了两张输出：局部对比、颜色数和边界检查成立，不足以维持整体对象辨识，所以案例判失败。

实际读取的是8份输入的身份，其中6份有正文/范围消费；SKILL.md与LEARNING-INDEX.json只核了身份。该结果不是完整技能链或最终提交上的新试验。`FINAL-INPUT-DELTA.json` 记录当前修改与实际已消费范围的区别。新的“先检查整体对象可读性”指导是由此提出的修订，其改善效果尚未重新实测。

## 可复验的技术边界

媒体验证完整解码到 EOF，检查每帧尺寸、PTS/帧时长、编码格式与不同帧；不通过转换帧率或拉伸来掩盖错误。10项负控绑定同一 manifest，具体检查源码/helper缺失与修改、缺SHA、缺卡、缺/截断视频、字体和seek伪造。PNG生成器拒绝缺帧和损坏帧。

所有新公开文本以 UTF-8 LF 输出；原弱浏览器报告保留原字节并专门标为历史拒绝证据。Git clean-filter 对 Motion 的50个关键文件已核对，最终仍以实际干净克隆复验为发布依据。原图中心manifest、旧媒体与旧评分输入保留，不靠重写历史获得“全绿”。
