## 组合规则速查

### 先记三条（N1 / N3 / N6；完整 N1–N9 见 `conflicts.md` §3）

- **N1 · 反约束一致性检查**：反约束段中每一条，必须与画风段的某条正向规则**不矛盾**；组合卡（引入第二个模块）时**必须重算反约束段**——凡与新模块正向规则冲突的默认禁令，删除或改写，不许两条并存。
- **N3 · 轴所有权表**：组合卡必须附 `轴名 | 持有模块 | 对方在该轴上的规则处置（删除/降档/分区）`。规则：① 每个轴只能有一个持有者；② 辅模块在冲突轴上的 §8.2 规则**整条移除**（不是调档）——§8.2 是判分规则，不是强度旋钮；③ 未列入表的轴默认无冲突。
- **N6 · 色数计数口径**：色数上限只约束**平涂色块层**；金属/金箔/高光材质层单列，不计入色数，但面积 ≤5% 画面、且必须在卡内声明。

### 组合前检查单（每对模块）

1. 查 `conflicts.md` §1 总表：这对模块是否命中 C 条 → 命中则按该条处置（反约束改写 / 轴单主 / 分区表 + 掩膜）。
2. 查 `conflicts.md` §4 near-miss 表：非冲突但**必须显式取值**（不取值会被静默折中成「两个都不像」）。
3. 反约束段重算（N1）；组合卡附轴所有权表（N3）。
4. 判分口径：主模块规则全集 + 辅模块**非冲突轴**规则；冲突轴上只保留持有者一行（N9，见 `conflicts.md` §3；落地判分见 `research/experiments/design.md` §5b）。

## 使用说明

### 单独用

- **图像生成**：粘卡内 §8.1「正向段 + 负向段」（英文原样）；强度按 §4 默认值起调。
- **跨场景 / 去题材迁移**：改用卡内 §8.1b「纯风格段（场景可迁移）」——已删题材词（人物/肖像/室内/静物）与场景专属道具、仅留视觉语言（E-02 派生）；未偏置卡附「场景可迁移性注记」；michelangelo 于 E-03 修订至 v2（从句级改写为可迁移到无机物的等价语言，v1 逐字存档于卡内「v1 审计存档」——见 `research/experiments/E1_t1c/RESULTS_t1c.md`）。拆分记录：`research/experiments/E1_t1b/RESULTS_t1b.md`。
- **代码艺术（HTML 逐帧 / Blender）**：把 §8.2 逐条当逐帧自查表；§4 参数给弱/中/强档。
- 注意：§8.1 的 `--no` 是**生成护栏**（防模型退化），不是历史断言；边界说明见各档案 §8.1 注记 / §8.3。

### 70/30 组合

- 主模块 70% 定「画面身份」；辅模块 30% 只贡献**非冲突轴**特征。
- 冲突轴上：只保留主模块规则；辅模块的冲突条**整条删除**（不是降档）（N3）。
- 反约束必须重算（N1）；可拆/不可拆按 N4：同一像素统计量 → 二选一；可分区域 → 写死分区表 + 掩膜。
- 档案侧现成提示（细则见各档案 §8.1；冲突对上仍按 `conflicts.md` 处置）：
  - 达·芬奇适合做「底子」（光影、空间、真实感），对方模块放「表面事件」（笔触、色彩、几何）；
  - 维米尔 70 / 莫奈 30：莫奈只贡献大气包络（远景对比压缩、色相收拢），不做笔触分解；
  - 维米尔 70 / 卡拉瓦乔 30：只允许把 P1 提到 90% 并把背景压暗，不引入硬光边缘与戏剧投影；
  - 已判定互斥/二选一的对（达·芬奇 × 米开朗基罗「天然互斥」、丢勒 × 北斋「着色系统二选一」）：组合前先按 N3 定轴单主。

### 强度

- 每卡 §4 = 弱/中/强三档 + 默认值；默认起步，按目标时期/子风格调档（如梵高：早期 / 阿尔勒 / 圣雷米；维米尔：早期 / 成熟期 / 晚期）。
- **只调 §4；§8.2 不调档**——冲突轴处置用 N3（删除 / 分区），不用「降档」。

## 维护 / 复跑

- 卡片由 `_extract.py` 生成（只读档案、只写本目录）：
  - `python _extract.py --write` 重建 11 张卡；
  - `python _extract.py --check` **逐字校验**全部卡片 §8.1 / §8.2 / §4 与档案一致（期望 `checks=33 ok=33 fail=0`）；
  - `python _extract.py --diff <id> [--sec 81|82|4] [--full]` 查看单卡比对详情（含 sha256 与原样全文）。
- §8.1b 为 E-02 派生补充（非档案内容；E-03 起可含 v2 修订与「v1 审计存档」子节，如 michelangelo）：`--check` 在 §8.1b 处截断后比对 §8.1（不参与逐字校验）；`--write` 重建时原样保留卡内现有 §8.1b 节。
- 档案更新 → 重跑 `--write` + `--check`；`conflicts.md` 更新（C 条被推翻 / 新增）→ 同步各卡「冲突注记」。
