# 实验设计 v0.1（验证蒸馏是否有效）

> 状态：v0.1 草稿（主脑，2026-10-15）。**待 wave2 用真实模块修订**（A-12）。
> 来源：ChatGPT 对话的实验表 + 本项目口径。原则：同一主题、固定一切可固定的，只换被测量的模块。

## 1. 问题

蒸馏出来的「艺术家模块」和「风格卡」到底有没有用、可不可控、能不能组合？
不训练模型、不先收提示词，先用**小型实验集**回答。

## 2. 实验矩阵（图像线，Lane A）

同一主题，逐一对照：

| # | 实验 | 目的 |
|---|---|---|
| E0 | 基础提示词（无风格模块） | 参照基线 |
| E1 | 单模块 × 8 位画家 | 判断每个模块的独立能力 |
| E2 | 双模块组合（莫奈+梵高 / 达芬奇+米开朗基罗 / 毕加索+马蒂斯） | 两种视觉语言能否有效融合（70/30 主辅） |
| E2b | 达·芬奇 + 卡拉瓦乔（冲突清单 C-01/C-02/C-03 的直接检验） | 硬光×柔明暗的「不可拆轴」是否真的互斥 |
| E2c | 莫奈 + 塞尚（冲突清单 C-10） | 大气包络×反大气透视的分区/掩膜解法 |
| E3 | 同一模块强度扫描（如梵高 30/50/75/100%） | 提示词能否控制画面变化 |
| E4 | 换主题重测（≥2 个不同主题） | 模块能否迁移到其他对象 |

## 3. 固定变量（每轮不许动）

- 生成模型 + 版本（**待定**：本机无本地出图管线；候选=ChatGPT 网页 / API / 其他——开放决策）
- 画幅与分辨率、种子（能固定就固定）、生成次数（每格 ≥3 张取中位）
- 主题文案逐字一致；只允许替换风格模块段与强度参数

## 4. 主题建议

- T1 暴风雨中的海边灯塔（对话原案：风景+光+情绪，对莫奈/梵高/透纳都敏感）
- T2 一个坐着的人（对达芬奇/米开朗基罗/塞尚敏感）
- T3 城市街角的黄昏（对毕加索/马蒂斯/莫奈敏感）

## 5. 评分维度（人评，每格逐项打 1-5）

构图 / 造型 / 色彩 / 笔触与质感 / 情绪 / **对提示词变化的响应度**（E3 专用）。
同时记录「失败形态」（退化成什么、和哪张卡的重叠最高）。

## 5b. 组合判分口径（吸收 conflicts.md §3 N4/N9，2026-10-15）

- **N4 可拆/不可拆**：两条规则作用于**同一像素统计量**（全帧均值 / 直方图占比 / 全帧计数）→ **不可拆，二选一**；作用于**可分区域或对象类别**（主体/背景、暗部/亮部、近景/远景）→ **可拆，但必须写死分区表 + 掩膜定义**，自查按掩膜分区统计。
- **N9 组合卡验收**：逐帧自查表 = 主模块规则全集 + 辅模块**非冲突轴**规则；冲突轴上只保留持有者一行；「冲突轴上出现双标准」列为失败形态之一。
- 组合前先跑 **N1 反约束一致性检查**（逐条反约束 × 逐条画风规则，标 `一致/冲突`），冲突项按 N5 句式改写。

## 6. 代码艺术线联动（Lane B）

同一画家模块的 8.2 段（可判定规则）→ 生成一张风格卡（`templates/style_card.md`）→ 让 agent 做 10 秒动画。
对照：同一模块「图像 prompt 版」与「代码动画版」的可控性差异（B-07）。

## 7. 记录格式

每格一目录：`research/experiments/<exp-id>/<cell>/`（prompt 原文 + 生成物 + 评分表）。
汇总表：`research/experiments/RESULTS.md`。
