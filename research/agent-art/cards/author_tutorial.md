## 6. 缺口与可选补法

**已知缺口（查不到就写查不到）**

1. **语音未转写**：本机无 ASR；本拆解用**烧录字幕帧读**替代（1s 密集 t0042–t0104 + 2s 网格全程），字幕帧间有漏字风险，非逐字全转录。
2. **作者的小文档不可得**：「项目地址 + 怎么跑 + 二次开发步骤」在主页粉丝群群文件里，需登录 B 站/QQ 群，未取（已查：视频内无公开链接；结束卡只写「主页群 · 群文件自取」，t0122）。
3. **Bilibili 官方字幕/元数据未取**：`api.bilibili.com/x/web-interface/view?bvid=BV1g7po6qEgM` 直连返回空（未签名请求被拒/需 WBI 或 SESSDATA），未继续深挖。
4. **15 风格混剪段（t0002–t0014）未逐风格识别**：属展示片/仓库对照的活（D-03、B-10 已覆盖）。

**可选补法（按成本排序）**

- (a) 平台字幕：带 SESSDATA cookie 调 bilibili `x/player/v2` 拿 CC 字幕（若 UP 传了）；或第三方镜像站取字幕轨。成本低，但多数 UP 未传。
- (b) 本地 ASR：`pip install faster-whisper`（CPU 可跑 small/medium，123s 音频约 1–3 分钟）或 whisper.cpp（需编译/下载模型）。本机 Python 3.14 可用，唯一门槛是模型下载。
- (c) 用 1s 密集帧做「字幕 OCR 全量对齐」：字幕是烧录的，可对全程 1s/0.5s 抽帧 + 视觉模型逐帧读，拼出近全文字幕（我们已在 t0042–t0104 做了一半）。零依赖，但费帧读次数。
- (d) 云端 ASR API（需 key）：最快，但要外部凭据，本项目暂无。
