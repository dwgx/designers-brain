CLREQ 中文换行/标点示例

中文排版需求规定：点号（顿号、逗号、句号、冒号、分号、叹号、问号）、结束引号、结束括号不能出现在一行的开头；开始引号、开始括号不能出现在一行的结尾。这是「基本处理」禁则；严格处理还要求破折号、省略号不出现在行首。此处用 line-break: strict 近似实现可由 CSS 控制的部分，标点挤压与行内调整未实现（见 cjk_layout.json）。「他说：『你好，世界！』」然后大家都笑了，这是一段用于观察行首行尾禁则行为的示例文本，包含各类标点：逗号，句号。分号；冒号：问号？叹号！以及括号（内容）、引号「引用」、书名号《名称》、省略号……与破折号——以便测试断行位置是否符合禁则。

对照（line-break: loose）：「他说：『你好，世界！』」然后大家都笑了，这是一段用于观察行首行尾禁则行为的示例文本，包含各类标点：逗号，句号。分号；冒号：问号？叹号！以及括号（内容）、引号「引用」、书名号《名称》、省略号……与破折号——以便测试断行位置是否符合禁则。

这是一个用于验证关闭后焦点恢复到触发按钮的对话框。
