# 艺术家档案模板 v0.1

> 每份档案一个文件：`research/artists/<id>.md`。全节填满；查不到写「未找到（已查: …）」。
>
> **证据分级（每条结论逐条标）**
> - `[自述]` 艺术家本人写下/说出的（书信、笔记、访谈）→ **必须带出处**（URL 或 书+页）
> - `[史料]` 当时人记录、档案、馆藏信息
> - `[研究]` 艺术史家 / 博物馆 / 学术资料的分析
> - `[归纳]` 我们从作品与资料归纳的**操作规则**（AI 产出，明确标注）
> - `[推测]` 低置信推断
>
> 项目口径：不得把 `[归纳]` 写成艺术家「心里想的」。统称「从作品、书信和艺术史资料归纳的创作原则」。

---

## 0. 元信息

- 生卒 / 国别 / 主要流派 / 主要媒介
- **一句话能力定位**：他给系统补哪块能力（如：塑造真实 / 人体力量 / 情绪笔触 / 光色 / 解构 / 结构 / 平面色彩 / 线条剪影）
- 关键作品 3-5 件（带馆藏与 URL）

## 1. 视觉指纹（8-12 条）

「一眼认得出」的特征。每条尽量具体到可观察量（边缘、色相数量、笔触尺寸、明度结构）。

## 2. 技法规则（8-12 条）

画面**是怎么做出来的**：明暗体系、笔触/线条、色彩方法、构图/空间、材质与表面。每条标证据级。

## 3. 创作原则（6-10 条）

作画时**优先考虑什么、如何取舍**。每条标证据级；有自述支持的写 `[自述]`，我们归纳的写 `[归纳]`。

## 4. 控制参数（4-6 个）

每个参数给「弱 / 中 / 强」三档**可观察描述** + 默认值建议（例：笔触表现强度 75%）。

## 5. 自述与原话（≥5 条）

逐条：原文（原语言）→ 中文意译 → 出处（URL / 书+页）。优先书信、笔记、访谈、序跋。

## 6. 临摹与影响链

- **他学过谁**（临摹、收藏、影响来源）
- **谁学过他**（后世临摹、再创作、流派演化、关键事件）
- 一句话总结：这条链在系统里有什么用（提示词模块的「来历」注脚）

## 7. 深度分析（≥5 条）

博物馆长文 / 艺术史家专论 / 学术资源，逐条带 URL + 一句话要点。

## 8. 提示词模块

### 8.1 图像生成模块（英文 prompt + 中文说明）

- 正向段（英文，可粘贴）；负向约束（`--no` 风格）；中文使用说明与强度建议。

### 8.2 代码艺术模块（4-8 条可判定规则）

参考 `templates/style_card.md` 的画风段写法：把该画家的视觉语言翻译成**可逐帧自查**的量化/物理规则。

### 8.3 野外样本（可选）

已有的该画家 AI prompt 例子（来源 URL + 原文 + 点评）。

## 9. 参考资料

全部 URL 编号清单（与正文标注对应）。

## 10. 缺口与待验证

没查到什么、哪里只有单一来源、哪里是推测。
