# RESUME 写盘模板（provider 抖动期续跑）

> 用途：长任务工人的续跑文件（`RESUME.md`）——provider 抖动 / 被杀 / 重启后，续跑者凭此直接接续，不重抓素材、不重走流程。
> 纪律：每 10–15 分钟写盘一次（小段增量）；写路径契约写进文件头；随任务产物一同留档。
> 出处：`docs/PROTOCOLS.md` §12 · `ops/OPS-LOG.md` §16。实例：wave19 十份 `knowledge/domains/painters/_scratch/*/RESUME.md`。

```
# RESUME — <工名>（<id>，<波次>）

> 任务：<一句话>｜写路径：<唯一写路径清单>｜状态：<研究中 / 落盘中 / 收尾>
> 写盘时间：<YYYY-MM-DD HH:mm>（每 10–15 分钟更新）

## 已完成步骤（按时间）
<按序：已读规格/样例 → 已核关键文献 → 已落盘产物>

## 已抓素材清单 + URL
<文件 → 内容 → 来源 URL 表；标注「可复用」/「需重抓」>

## 下一步（按序）
<可直接执行的步骤清单；含自测命令>

## 已核实的结论（可直接引用）
<逐条结论 + 出处；写死口径（如分工条款）一并列出>
```

规矩：续跑前先读本文件；**已落盘素材绝不重抓**；四段缺一不可。
