# LOOP 目标条目模板

```
## <ID> [<open|running|done|blocked>] <一句话目标>
- 车道: <A|B|C|D>
- 为什么: <它解决哪个问题 / 补哪个缺口>
- 产出路径: <绝对或项目内路径>
- 完成条件: <一个能看的文件 / 一条能跑的命令>
- 归属: <主脑 | 工人名 | 跨家 worker + board ID>
- parent: <可选，父条目 ID>
- 发现 → 新条目: <研究过程中冒出的新线头，追加为新条目后回填 ID>
- 验收: <完成时填：跑过的命令/文件>
```

规矩：发现新线头**当场**追加条目（哪怕只有一行），不许只放在脑子里。
