# 15 卡结构蒸馏（Opus 5.5 代码动画提示词体系）

> 素材：`knowledge/domains/motion-graphics/origin/`（15 张卡 + 全文转录 + 截图）。署名 `Claude Code · Opus 5.5`。
> 状态：v0.1（主脑直接分析，2026-10-15）。深研究见 GOALS B-01 子条目。

## 1. 骨架（15 条完全同构）

每条 = **4 段 + 页头提示**：

1. **任务头（固定句式）**
   > 用代码做一支 10 秒的 MG 动画（1920×1080，30 帧），`<渲染器>`，配乐音效也用代码合成、跟画面卡点；**先出 6 张关键帧给我看，再做动画，最后逐帧自查**。
   - 渲染器只有两种：**01 = Blender Python 脚本搭场景渲染**；**02-15 = 网页逐帧渲染**（HTML/canvas/WebGL，无视频模型）。
2. **画风段**：`画风：<名字>。<4-8 条规则>`——**不是形容词，全是可验收的量化/物理约束**。
   实例：斜线一律 30°、线宽 1-2 像素、动作 8-12 张/秒、冲过头 5-10%、回弹约 8 帧、全片 16-32 色、画布 320×180、每个动作不短于 0.6 秒、同屏 ≤3 色、位移整格、旋转 90° 倍数。
3. **内容段**：`内容：【<10 秒分镜 + 结尾落地文案>】`——【】是用户替换槽；**每条自带收尾字/标题**（PLAY、合、书归原位、午夜电台、灵感、3 分、着陆成功、山野骑行、晴朗、猫头鹰日报、大丰收、早安、番茄意面、不到 1% 的水、完美早餐…），一眼可验收。
4. **反约束段**：`别做成：<3-4 条>`——每条封堵一个**模型默认退化行为**：
   交叉淡化冒充形变、默认塑料材质、硬阴影、运动模糊、淡入淡出转场、发光字、细字体、半像素位置、互补色、多个强调色、柱子比例乱画……

页头固定提示：**「提示词　暂停截图，【】里换成你的」**。信息密度：每片约 200-280 字。

## 2. 为什么有效（v0.1 分析，[归纳]）

1. **规则全部可逐帧自查**：画风段的每一句都能被机械检查（帧率、色数、缓动、角度、色相数）——所以「最后逐帧自查」不是口号，**自查表就是画风段本身**。
2. **三段流程 = 计划→执行→验证**：先 6 关键帧（低成本早期检查点，人类先看）→ 做动画 → 逐帧自查（机器验证）。这正是 agent 工作流的正确形状。
3. **量化代替形容词**：把「柔和/有分量/机械感」翻译成数字与物理描述——模型无法糊弄可判定的规则。
4. **反约束对着默认行为打**：每条「别做成」都点名一个模型的默认捷径；不封堵，模型就退化。
5. **音画同源**：配乐音效**也用代码合成**（WebAudio/Blender 侧），跟画面卡点——全链路无外部素材。
6. **验收锚点内置**：收尾文案 = 一帧能核对的终点；样片 10 秒固定时长 = 统一比较单位。
7. **两种渲染器分工清晰**：3D/材质/物理 → Blender；2D/排版/特效 → 网页逐帧。选择成本降到二选一。

## 4. 与画家模块（Lane A）的对应

| 15 卡 | 画家档案（`templates/artist_module.md`） |
|---|---|
| 画风段（可判定规则） | 视觉指纹 + 技法规则 |
| 内容段（分镜+收尾） | 创作原则（先定情绪/主题，再定取舍） |
| 别做成（反约束） | 负向约束（画家模块 8.1 的 `--no` 段） |
| 控制参数（强度） | 控制参数（弱/中/强） |

两条车道的蒸馏**同构**：都是「可判定规则 + 反退化约束 + 强度参数 + 验收锚点」。这支持把它们收进同一套「美术流程 prompt 体系」。
