## 2. 逐展开（每步：先选 / 牺牲 / 为什么[分栏] / 何时失效 / 等级）

<a id="db-source-line-40"></a>
### S1 · 先选「看的方式」
- **先选**：把母题拆成「一小方蓝 / 一块长方粉 / 一道黄」，照它在眼里的样子画，直到给出「天真的印象」。`[自述]` corpus 条目3 `:28`（Perry 回忆录，`[reported speech]`，原刊 OCR 转录）；dossier §3-1 `:62`。
- **牺牲**：物体轮廓、固有色、叙事可读性（这是该选法的直接代价，`[归纳]` 从 §1-6 去线性透视、§1-9 边缘溶解推得）。
- **为什么（分栏，不混写）**：
  - `[自述]`：「画你真正看到的，而不是你以为该看到的；不是试管里孤立的物体，而是被阳光与大气包裹、阴影里映着天穹的物体」——dossier §5-2 `:113`（Perry，`[contemporary record]`，原刊未加引号的概括，corpus 条目4 `:35/:40` 已注明）。
  - `[归纳]`：该选法对应「色点分解 / 并置不混合」的表面机制（§2-3 `:49`），但**「对应」是研究者归纳，不是莫奈说「我要做色点分解」**。
- **何时失效**：任务需要可辨识物体/肖像/图解；或把此选法写成「莫奈主张忽略对象」的心理学断言——后者是本卡禁止（`[推测]` 红线）。
- **等级**：`[自述]`（决策来源）+ `[归纳]`（代价与失效条件）。

<a id="db-source-line-49"></a>
### S2 · 先选「光/时刻」并制度化（系列）
- **先选**：固定构图，只改 `time of day / weather / light direction`（`dossiers/monet.md:196` 系列用法 `[归纳]`）；同景多布并行、光变即换布（§2-6 `:52` `[研究]`）。
- **牺牲**：单张「合成完美光」的可能——§12-6 现有练习明确要求「最后画 1 张凭记忆的合成版，用它检验你为何要反对 composite」（`:397` `[归纳]`）。
- **为什么（分栏）**：
  - `[自述]`：「我在追一串颜色」(dossier §5-8 `:127`)；「瞬间性，尤其是 enveloppe，同一道光铺满各处」(§5-4 `:117`，1890-10-07 信，Seitz 转录)。
  - `[归纳]`：把「重复」制度化、用系列穷尽变量（§3-6 `:67`、P6 `:101-104`、`:154` 注脚）；这是项目对工作流的结构化，不是作者原话。
- **何时失效**：题材 = 天气事件 / 动势 / 灾难与崇高 / 边缘溶解 → **边界外=透纳领域**（B3）；此时换模块，不是把 P3 拉满。
- **等级**：`[自述]`（意图）/ `[研究]`（师承与系列史实）/ `[归纳]`（工作流结构、失效条件）。

<a id="db-source-line-58"></a>
### S3 · 起手「一次覆盖定调」
- **先选**：第一遍粗率盖满全画布，先定整体调性；第一眼最真、最无偏见（§2-1 `:47`、§2-9 `:55`）。
- **牺牲**：局部先精、分区抠细节的顺序。
- **为什么（分栏）**：`[自述转述]` Perry 记「the first painting should cover as much of the canvas as possible, no matter how roughly, so as to determine at the outset the tonality of the whole」（corpus 条目2 `:19`，`[reported speech]`；dossier §2-1 `:47` 同）；`[归纳]` 与 §8.2-4 包络「统一全画」判据方向一致，但**一致性是研究者比对，非作者自述**。
- **何时失效**：C-10 与塞尚组合需「按地平线分层 + 掩膜」（`conflicts.md:184-185`、N4 `:314-315`）时，「全画面一次铺」让位于分区表。
- **等级**：`[自述转述]` / `[归纳]`（失效）。

<a id="db-source-line-65"></a>
### S4 · 「关系」优先于「母题」
- **先选**：水面/天空镜像、大气包络统一全画；母题是次要的。
- **牺牲**：立体感、线性透视、硬边轮廓（§1-6 `:37` `[研究]`、§8.1 负向段 `dossiers/monet.md:189-192` 禁 3D modelling / crisp vector edges）。
- **为什么（分栏）**：
  - `[自述]`：「The motif is secondary; what I want to capture is what there is between the motif and myself.」(dossier §5-6 `:123` `[自述]` R5 吉维尼引语页)；「母题的核心是水镜」(`:125`)。
  - `[归纳]`：包络规则 §8.2-4 与 P3 是把「关系第一」翻译成可判定阈值（`dossiers/monet.md:204,86-89`）；**翻译动作归研究者**。
- **何时失效**：与塞尚反大气透视同帧（C-10），或把「关系第一」读成「莫奈不重视题材」的心理断言（禁止）。
- **等级**：`[自述]` / `[归纳]` / `[研究]`（去透视史实）。

<a id="db-source-line-74"></a>
### S5 · 表面：笔触全覆盖（**纯 `[归纳]` 步**）
- **先选**：短逗号笔触 4–12 px、间距 2–6 px、覆盖率 90–100%、禁 >12 px 无笔触平滑区（§8.2-1 `dossiers/monet.md:201`）。
- **牺牲**：平滑渐变、柔和无笔触过渡。
- **为什么**：**`[归纳]`** C-05 把「笔触可见度」定为一条轴，达·芬奇「只有渐变」在另一端；组合卡按 N3 轴所有权表让该轴单主（`conflicts.md:36,109-121,311-312`）。**此步没有任何作者自述支撑「4–12 px」这个数值**——它是逐帧可查的项目判据（AUDIT-monet `claim-evidence-map.md:#8,#9` 确认阈值标 `[归纳]`、未冒充史料）。
- **何时失效**：以达·芬奇为主模块时整条移除（`:119`）；或把 Lane B「别做成：渐变」当全局常量照抄进莫奈卡 → C-14 误伤（`conflicts.md:237`）。
- **等级**：`[归纳]`（单一步，**不夹 `[自述]`**）。

<a id="db-source-line-81"></a>
### S6 · 深度与色相：单调衰减 + 收拢（**纯 `[归纳]` 步**）
- **先选**：远景对比 ≤ 近景 60%、远→近单调梯度 R² ≥0.8（§8.2-4）；S ≤65%、色相簇 ≤10（§8.2-3）；P3 强档「全画色相向单一大气色收拢」（`dossiers/monet.md:89`）。
- **牺牲**：远景清晰度、高饱和撞色。
- **为什么**：**`[归纳]`** C-10（深度衰减轴）/ C-06 + near-miss #4（饱和度轴）/ C-14（渐变轴）的规则层判定（`conflicts.md:180,129,235,350`）；分层解法与改写句式（`:184-185,239-241,320`）。
- **何时失效**：塞尚反大气透视在场（C-10，需 N4 掩膜）；题材越过透纳边界（B3）；组合取更严 ≤0.35（near-miss #4）。
- **等级**：`[归纳]`（单一步，**不夹 `[自述]`**）。

<a id="db-source-line-88"></a>
### S7 · 收笔：停止标准与关键元素最后补
- **先选**：只在「不再加强画面」时停笔（§2-8 `:54`）；太阳/倒影/渡船等收笔时补（§2-7 `:53`）。
- **牺牲**：按预定清单画满即停的确定性。
- **为什么（分栏）**：`[自述转述]` Perry 记停止标准（`dossiers/monet.md:54`，corpus 同链）；`[研究]` R1 玛摩丹说明《印象·日出》关键元素最后补（`:53,:160`）。**「为什么停」是转述记录，「哪些元素后补」是藏馆研究，二者不混为一句自述**。
- **何时失效**：进入 §8.2-7 动画域（水面 ≤2 px/帧、雾 ≤1 px/帧、禁物体级动画，`dossiers/monet.md:207`）时，「停止」变帧级判据；AUDIT-monet RESULT §3 确认此低频局部场**不并入 C-09**（`claim-evidence-map.md:#11,#12`）。
- **等级**：`[自述转述]` / `[研究]` / `[归纳]`（失效）。

## 3. 组合时的决策序（C-05 / C-10 / C-14 插入点）

> 全部 `[归纳]`；规则层判定，**非实验验证**（AUDIT-monet `coverage-manifest.md:61`）。

1. **先判轴，不先调强度**：按 N3（`conflicts.md:311-312`）列「轴名 | 持有模块 | 对方规则处置」。笔触轴（C-05）、深度轴（C-10）、饱和度轴（C-06）各自单主；§8.2 是判分规则不是强度旋钮，冲突轴上辅模块规则**整条移除**。
2. **再重算反约束**：按 N1（`:305-306`）逐条「反约束 × 正向规则」标一致/冲突；C-14 结论「反约束是卡级资产，不是全局常量」（`:237`），渐变按 N5 句式改写（`:320`）。
3. **可拆才分层**：C-10 若与塞尚并存，按 N4（`:314-315`）写死分区表+掩膜；单调梯度只在远景层内拟合（`:184-185`）。
4. **最后查双标准**：N9（`:332-333`）把「冲突轴上是否出现双标准」列为失败形态。
5. **E2c「莫奈+塞尚」为待补实验**（`:186,:335`），不得写成「已验证可组合」（AUDIT-monet `claim-evidence-map.md:#16`）。

## 4. 本卡明确「不写」的内容（反心理推断清单）

- 不写「莫奈**感到**孤独/宁静/焦虑」「他**想要**捕捉时间的流逝」「他**潜意识**里…」——这些是从画面外观推作者心理，属 `[推测]`，本卡禁用。

- 不把「规则层互斥」写成「实验验证通过」；不把 `submitted` 写成 `accepted`。
