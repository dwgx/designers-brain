## 4. 具体练习（阶梯；全部为「建议练习」`[归纳]`，未经人评）

> 三条阶梯按作业顺序设计：先建笔触场（M1）→ 再叠包络梯度（M2）→ 最后做色相收拢与边界自律（M3+M4）。每条含「可操作动作 / 自查 / 完成定义」，**不声称学习收益**。

<a id="db-source-line-64"></a>
### 阶梯一：comma-stroke field studies（短逗号笔触场写生）
- **目标机制**：M1（§8.2-1 / P1）。
- **动作**：取 `§12-2《蛙塘》`/`§12-8 睡莲池` 为参照（`dossiers/monet.md:374-377,404-407`），对同一片水面/花田做 3 张 1 小时速写；**只许用笔触方向与密度**表达差异（静水／微风／风皱），不许调匀颜料（§2-3「笔触并置、让眼睛去混合」，`:49`）。
- **自查（可判定）**：把成品缩放到练习分辨率后做边缘密度 + 连通域扫描——是否处处有 4–12 px 级短笔触、覆盖率是否接近 90–100%、**是否出现 >12 px 无笔触平滑区**；对照 3 张的边缘密度差异。
- **完成定义**：三张在「笔触方向/密度」上可区分，且无 >12 px 平滑区（即不触发 §8.2-1 失败形态）。
- **来源**：`dossiers/monet.md:374-377`（§12-2 怎么练）、`:404-407`（§12-8）、`:49`（§2-3）、`:201`（§8.2-1 自查法）。练习映射 `[归纳]`。

<a id="db-source-line-71"></a>
### 阶梯二：atmospheric envelope gradients（大气包络梯度）
- **目标机制**：M2（§8.2-4 / §4 P3）。
- **动作**：取 `§12-3《印象·日出》`/`§12-5《圣拉扎尔车站》`/`§12-7《鲁昂大教堂》` 为参照（`:379-382,389-392,399-402`），画晨雾/蒸汽场景；**先按 §2-1「一次覆盖定调」粗率铺满全画布**（`:47`），再把远→近的对比度做成**单调下降**梯度，只在**远景/天空层**内拟合（C-10 分层解法 `conflicts.md:184-185` 要求「单调梯度只在远景层内拟合、近景层不许雾色」）。
- **自查（可判定）**：按深度分区测对比度，从远到近线性拟合 R² 是否 ≥0.8；远景对比是否 ≤ 近景 60%；近景是否未出现雾色；测一次黑白值——《印象·日出》式「太阳应几乎消失」（`:382` 为现有记录里的自查提法，照用不升级）。
- **完成定义**：远景层内 R² ≥0.8 且衰减方向单调、近景无雾色；若与塞尚式「反大气透视」同帧，按 `conflicts.md:184-185` 显式写分层边界与掩膜（N4 `:314-315`）。
- **来源**：`dossiers/monet.md:204`（§8.2-4）、`:86-89`（P3）、`:47`（§2-1）；`conflicts.md:180,184-186,314-315,320`（N5 渐变改写句式）；`:335`（E2c「莫奈+塞尚」为**待补实验**，不冒充已验证）。练习映射 `[归纳]`。

### 阶梯三：hue-collapse discipline（色相收拢 / 饱和度自律）
- **目标机制**：M3 + M4（§8.2-3 / C-05 / C-10 / C-14 / 透纳边界）。

## 8. 使用边界（硬边界；违反即超出本卡适用范围）

- **B1 练习边界**：全文练习 = **建议练习**（`[归纳]`），学习收益未经人完成或评价；不得改称「已证实学习收益」「已验证有效」（`01-AUDIT.md:273`）。
