## 4. 三个可执行的 proposed 练习（未执行，非实测收益）

<a id="db-source-line-45"></a>
### P-E1 基础：先搭透视，再放形体
- **输入／来源**：自建一幅有地砖与两根柱子的简图；dossier §12《基督受洗》《鞭笞》，corpus #3（点线面到复杂形体的自述结构）。先声明视平线、消失点、画幅与三个人物剪影位置。
- **操作／提交**：先画地砖／柱体骨架，再加入剪影；交一张带延长线的构造图及一张源锚点—教学推断表。无需复制原作或生成图像。
- **局部正／负控制**：固定对象、相机／画面假设、色板、其他边线与声明的消失点。A 的进深边收敛到该点；B 只把一条进深边旋转离开该收敛关系。交两张叠图并标出唯一改变的边，预期只检查该透视关系，不能从 B 推出整张图“不是 Piero”。
- **反馈／常见错**：延长线是否到达声明的点；若对象位置或视点同时改变，先恢复固定条件再比较。数值误差阈值若采用 R2，标为项目未校准值。检查失败时只改这条边。
- **迁移**：保持透视关系，将柱体换成盒体并再做一次边线检查；不声称已产生学习收益。

<a id="db-source-line-52"></a>
### P-E2 分支：夜景单一画内光源
- **输入／来源**：dossier §12《君士坦丁之梦》与 §8.2 R4；corpus #21 为 Vasari 转述，非 Piero 自述。自建一个发光体与三个体块的位置图，声明 night 模式。
- **操作／提交**：固定光源位置，画三个亮度层与被照面；交光源—体块示意及适用规则表。把 R4 记为待执行的局部检查；白昼版本记 R4 不适用，不能记作已通过。
- **反馈／常见错**：是否无意加入第二主光、最亮位置是否与声明发光体相符；先区分构造错误与未取得可测图像。R² 等数值只在实际测量后报告，当前不填 PASS。
- **迁移**：将发光体位置改变一次并重新推导被照面；比较的是所选照明假说，物件不必是天使。

<a id="db-source-line-58"></a>
### P-E3 进阶：有影与有意省影的表达比较
- **输入／来源**：dossier §3-5 的研究解释及 §12《降生》建议练习；同一静态构图、对象和色板。
- **操作／提交**：A 标注一个自洽的投影方向，B 仅删除投影；交 A/B 草图、删去区域及各自的表达意图。此处只比较有影／省影的解释，不是新的光学消融实测。
- **反馈／常见错**：B 的阴影几何记“有意省略／不适用”，不写 R3/R8 PASS；没有资料判定为何无影时记 unknown。若同时改变对象、颜色或光源，不能把差异归给删影。
- **迁移**：以无宗教物件的静物重复该比较，声明其仅迁移表达操作，不证明原作含义可被无损替换。

以上交付是可观察的练习产物，不是已证实学习成效。建议从 P-E1 开始，按目标选 P-E2 或 P-E3，不强制三个分支串联；数值阈值未校准，human_review 不由本参考补丁改变。
