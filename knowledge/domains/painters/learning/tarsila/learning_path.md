## 3. 要观察的机制（6 条，来自 §8.2 七规则 + §1 视觉指纹）

1. **色块扁平（平涂 + 零投影）**：天/地/水 = 连续色带（背景 2–4 层、无消失点）；形靠轮廓线与色阶分隔，投影 ≈0、内部渐变 ≤2 色阶、可见笔触 0——`pintura limpa`。对照 §8.2-4/5、C-01/C-05/C-18。
2. **cores caipiras 限色**：主色相 ≤5（蓝/玫粉/黄/绿 + 白）；高饱和像素 S>0.6 占 15–40%；白混梯度带（相邻色阶差 ≤12/255）——注意是「掺白软过渡」不是「渐变成图案系统」。对照 §8.2-1、§3.1 判据①③。
3. **乡土人物变形（前缩夸张 + 几何化简）**：≥1 个身体部件 ≫ 自然比例（Abaporu 巨足档 ≥2.5×）；主形曲率拐点 ≤12，球/弧/方块模板命中 ≥1；**形体完整、轮廓闭合、无多视点、无拼贴物**。对照 §8.2-3/7、§3.1 判据②。
4. **热带植物 = 单件符号**：每画 ≥1 种（香蕉叶对角单块 / 太阳花仙人掌 / 木瓜树 / 棕榈）；**不得成 all-over 图案**——图案化即滑向马蒂斯侧。对照 §8.2-6、§3.1 判据②。
5. **梦境与食人式转译**：≥1 个幻想元素（发明的动物/悬浮形/发光卵）；「吞欧洲几何骨架 → 吐本土色板与母题」两阶段状态机（§8.3-2）——全片不得在「碎裂度」轴上滑动。对照 §8.2-7、§3.1 vs 毕加索。
6. **现代图标 / 群像**：铁路/电线杆/加油站与棕榈同框；群像同构脸 + 肤色变奏（Operários 档）。对照 §8.2-5、§1-7/9。

> P1/P2 定「是不是塔西拉」的起步（两条中 ≥1 条 ≥ 中档才成立——热带色板或几何化简形）；P3/P4 定梦境-夸张档；P5/P6 定空间与现代性档（档案 §4 L101）。所有这些数值 `[归纳]` 未实测（§6 前置 #6）。

## 4. 具体练习（可操作；三阶梯 + 一收口，全部为**建议练习**）

> 三阶梯从「色块扁平」单机制 → 「乡土人物变形」 → 「分工判别（马蒂斯/毕加索混合压测）」，逐级加一个变量；每级给可观察结果、自查、常见失败。**全部未渲染、未像素实测、未经真人评价。**

<a id="db-source-line-59"></a>
### 阶梯 L1｜色块扁平基础研究（flat-block discipline）— 建议练习

- **做什么**：一张小风景，只画「天/地/水」3 条水平色带（无消失点），色板锁 cores caipiras 四主色 + 白；平涂、深色轮廓、零投影、零可见笔触；每色至少 1 个 ≥3% 画幅的连通块；允许掺白软过渡，禁止渐变成图案。
- **可观察结果**：色带读成「土地的切片」；色相直方图主色族 ≤5；投影区 ≈0；色块内部标准差 ≤2/255（`[归纳]` 阈值，仅作判定草案）。
- **自查**：① 色板能否逐块对表四色名句 + 白梯度？② 有没有投影/可见笔触/写实明暗？③ 背景是不是条带而非透视？
- **常见失败**：滑向写实渐变（C-14 句式，见 §6）；把白梯度画成 all-over 纹样（越界马蒂斯，§4 警报①）；学院灰调（P1 弱档越界警报）。

<a id="db-source-line-66"></a>
### 阶梯 L2｜乡土人物变形（vernacular-figure distortion）— 建议练习

- **做什么**：在 L1 的画面里加 1 个坐姿人物（W1/W3 法）：只允许**一个**身体部件夸张（≥1.5×，Abaporu 档 ≥2.5×）；形体用球/弧/方块化简，轮廓闭合、无碎裂/多视点/拼贴物；旁置 1 个单件热带植物符号（太阳花仙人掌或对角香蕉叶）。
- **可观察结果**：第一眼看到的是那个被放大的部件；主体轮廓闭合、碎裂主体数 = 0；植物是单件符号不是纹样；身体圆润无骨、姿态安静。
- **自查**：① 只夸张了一个部位吗？② 形体有没有被多视点切开 / 有没有拼贴物或字母（出现即毕加索侧，判失败）？③ 植物是否单件出场？
- **常见失败**：碎裂/多视点/拼贴物（越界毕加索，§4 警报②）；植物 all-over 化（越界马蒂斯）；写实解剖细节（P2 弱档）；丛林细描（越界卢梭式，§4 警报⑤）。

<a id="db-source-line-73"></a>
### 阶梯 L3｜分工判别压测（4 判据 × ≥2 轴，混合反例）— 建议练习

- **做什么**：故意构造两张「混合帧」并**只用 §3.1 判据判分**（不追求产出好看的画，追求判分正确）：
  - 帧 A（仿 AUDIT `counterexample.md` 反例 1）：把植物做成 all-over 纹样，但**保留**四主色 + 白梯度、形体完整圆润。
  - 帧 B（仿反例 2）：用高饱和 + 本土题材（A Negra 式身体），但主体做轻微多视点碎裂（仍闭合轮廓、无拼贴物）。
- **可观察结果（判分答案）**：
  - 帧 A：vs 马蒂斯 4 判据里仅 ②图案系统 在马侧，①色板来源 / ③色的组织 在塔侧 → **仅 1 轴，按 ≥2 轴联合不判越界马蒂斯**（§3.1 L78「尤其①③」、L79 边界注）。
  - 帧 B：vs 毕加索 4 判据里 ①④（来源方向、题材主体性）均在塔侧 → **不判越界毕加索**；但碎裂度是单轴否决项（§3.1 L86「不得在碎裂度轴上双开」）。
- **自查**：① 判分是否用了 ≥2 轴联合而非单特征一票否决？② 是否读了边界注（马蒂斯也画异域、毕加索后期也高饱和，但①④仍分侧）？③ 是否把 §4「字面三合」警报当作快速筛查而非终判？
- **常见失败**：只看「高饱和/异域题材/几何感」就判（L79/L85 边界注明确禁止）；把 §4-L102「字面三合」当终判，与 §3.1「≥2 轴联合」冲突——**AUDIT 已报此判分优先级未显式对齐，建议以 §3.1 ≥2 轴为准，§4 警报作筛查**（report-only，不越权改仓库）。

<a id="db-source-line-84"></a>

## 6. 常见失败（反例，按冲突行与现有记录）

| 失败 | 越界 / 冲突 | 处置立场（不越权改仓库） |
