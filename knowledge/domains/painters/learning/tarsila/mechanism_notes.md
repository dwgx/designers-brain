| # | 规则（档案 §8.2 / 模块卡 §代码艺术规则 原样） | 自查方法（`[归纳]`） | 练习 | 失败线 |

| 2 | 完整形：碎裂主体（同色域被 ≥3 条非轮廓线切割）= 0；轮廓闭合、无拼贴物/字母/多视点 | 边缘图 + 连通域 | L2 | 任一出现 → 毕加索侧（判据②） |
| 3 | 几何化简：曲率拐点 ≤12/主体；球/弧/方块模板命中 ≥1；高频纹理能量低于参考帧 30% | 曲率 + 频域 | L2 | 写实纹理 / 自然轮廓 |
| 4 | 平涂：投影 ≤2% 画幅；可见光源 0；可见笔触 0；色块内 std ≤2/255（pintura limpa） | 帧差 + 方差 | L1 | 硬阴影 C-01 / 笔触 C-05 / 明暗 C-18 |

| 7 | 梦境-夸张（梦境档启用）：≥1 幻想元素；≥1 部件夸张（≥1.5× / Abaporu ≥2.5×） | 目标检测 + 比例测量 | L2/收口 | 自然比例 / 纯写实 |

### C.2 分工：vs 马蒂斯 / vs 毕加索 各 4 判据 + ≥2 轴联合 + ≥2 轴边界注（carried）

> 来源：档案 §3.1 L73–88（写死；`[归纳]`，可被组合实验推翻其 `[归纳]` 部分，但两条主分工主軸不得混用）；模块卡 L71–73 同步浓缩；ACCEPTED AUDIT [claim_evidence_map.md](claim_evidence_map.md) TA-§3.1-L75..L88 与 `review-gate-receipt.json` 的 division_vs_matisse / division_vs_picasso 逐字复核（L78/L79/L84/L85）。

**vs 马蒂斯（第一写死条款：色彩 欧洲设计 vs 热带）— dossier L78 四判据**

| 轴 | 马蒂斯档（欧洲设计） | 塔西拉档（热带） |
|---|---|---|
| ① 色板来源 | 欧洲工作室装饰系统（多色相自由调用、图案可同权） | 被贬本土色正名（限 4 主色+白，可对表四色名句） |
| ② 图案系统 | 图案/纹样与主体同权（all-over 可） | 无 all-over 图案；植物/符号单件出场 |
| ③ 色的组织 | 平涂纯色块（渐变≈0、硬边）+ 面积配比主导 | 平涂为主但允许白混梯度；形=球/弧/方块几何化简 |
| ④ 空间与尺度 | 装饰平面（零深度、尺度恒定） | 层次平面（planos sucessivos 色带、前缩出框、局部夸张） |

- **判定须 ≥2 轴联合成立（尤其 ①③）**（L78）。
- **边界注（L79）**：马蒂斯也画「异域」（尼斯室内、塔希提剪纸）——但色彩仍按装饰系统组织（① 在「设计」侧）；塔西拉个别作品近装饰（Religião Brasileira 的花框）——但色彩来源与母题仍为巴西民间宗教图像（① 在「热带」侧）。**判定不得只看「高饱和」或「异域题材」**。→ 这是 ≥2 轴边界注（至少覆盖 ① + 题材/装饰两轴），练习 L3 帧 A 直接压测。
- **组合纪律（L80）**：同用时必须选一个主导轴（建议 70/30 起），否则互相抵消。

**vs 毕加索（第二写死条款：立体主义 来源 → 巴西转译）— dossier L84 四判据**

| 轴 | 毕加索档（来源/发明） | 塔西拉档（转译/食人） |
|---|---|---|
| ① 来源方向 | 发明者/自源 | 学徒-转译（三师名录、朝圣叙述、「兵役」自述） |
| ② 碎裂度 | 物象解体重组（多视点、面碎裂、字母/拼贴物） | 形体完整（轮廓闭合、无多视点、无拼贴物） |
| ③ 色彩 | 分析期棕灰单色 | cores caipiras 高饱和 |
| ④ 题材主体性 | 欧洲题材（原始=外部素材） | 本土主体（A Negra 的政治身体；把欧洲「原始主义」凝视转回本土自身） |

- **判定须 ≥2 轴联合成立（尤其 ①④）**（L84）。
- **边界注（L85）**：毕加索后期也有高饱和（30 年代）与本土（西班牙）题材——但 ①④（来源方向、主体性方向）仍分侧；塔西拉也有近抽象（A Lua、Calmaria）——但「软几何」与色彩规程仍在塔侧，②③ 联合成立。**判定不得只看「抽象度」或「几何感」**。→ 练习 L3 帧 B 压测。
- **组合纪律（L86/L88）**：碎裂度轴不得双开；不得让毕式拼贴物进入塔式画面（击穿 pintura limpa）；按 N4 二选一或分区。

**与系统其余模块（L87）**：不借马蒂斯图案系统/硬边平涂装饰、不借毕加索碎裂拼贴、不借莱热工业机械质感、不借里维拉壁画工程尺度、不借卢梭式丛林细描。组合预检 C-06/C-18/C-05/C-01。
