## 1. 前置知识（先知道什么，再开练）

1. **本模块的身份不是「热带装饰」，是「去殖民归还装置」**：一句话定位 = 把欧洲前卫的几何-超现实语汇，改写为非洲-加勒比的仪式神话与历史记忆；链路「先取（欧洲前卫骨架）→ 再还（把面具与符号放回自身 landscape）→ 合体（人-动物-植物生长式混合）→ 去殖民（精神层面的输出与搅扰）」（档案 `:20`、`:145`、`:69`）。不先认这条，练出来会滑向高更/塔西拉侧的「装饰性热带色」（`§4 越界警报③` `:106`）。
2. **两条写死分工轴（第一/第二条款）**：vs 毕加索＝立体主义：欧洲神话/外部素材 vs 加勒比神话/自身世界；vs 博斯＝混种生物：道德编码讽喻机器 vs 仪式性在场。两档**判定须 ≥2 轴联合**（尤其符号指向/方向；尤其合体职能/情绪距离），**不得只看「面具脸」「几何感」「怪诞/混种程度」**（档案 `:77-88`、`:81`、`:87`）。`[归纳]` 可被组合实验推翻，但主分工轴不得混用（档案 `:8`）。
3. **《丛林》(La jungla / The Jungle, 1942–43) 的馆藏必须先校正（OVERTURNED）**：**在 MoMA（140.1945，Inter-American Fund；239.4×229.9 cm；油彩+炭笔于 kraft 纸、后裱画布）**；**MALBA 藏的是《La mañana verde》2003.35（186.9×124 cm，Costantini 捐赠）并展出《Omi Obini》**（档案 `:22`、`:253` §10-1；AUDIT RESULT §结论、review-evidence §(b) 四源交叉：Wayback MoMA 对象页 `Inter-American Fund. 140.1945.`、MALBA 页 `2003.35`、Wikipedia infobox `The Jungle (1943), Museum of Modern Art collection`、MoMA 新闻稿）。**原 wave22 简报误记「MALBA《丛林》在藏」= 已 OVERTURNED，不可回退、不可复抄**（GOALS.md:110 A-114、AUDIT `LAM-S10-01`）。练《丛林》前先把这条事实钉死——它本身就是本模块「不要把外部标签贴到错误对象上」的第一课（见 §6 失败 0）。

## 3. 要观察的机制（练时盯什么）

> 观察顺序建议：先 1+2（密度场 + 兽形，身份轴 P1/P2）→ 3（符号指向，分工轴）→ 4（暗域色光）→ 5（表面）→ 6（节律）。前两步定「是不是林飞龙」，后四步定「会不会滑到邻居档」。

1. **满幅丛林密度（P2 默认 80% / 强档）**：负空间（天空/纯背景）≤15%、地平线检测=无、四边触边率 ≥90%、秆 ≥8 根/画幅（§1-2 `:36`、P2 `:99`、§8.2-2 `:195`）。**失败信号**：留白/天空可见（弱档 `:99`）、出现地平线或透视消失点（→ 卢梭式越界警报④ `:106`）、植物画成植物学细描标本（§3.1 `:89`）。
2. **兽形/混种合体（P1 默认 75%）**：全帧 ≥1 主体可拆 ≥2 类部件来源（人/马/鸟/植物/果实）、**拼贴接缝=0**、马首/鸟首/爪形足模板命中 ≥1（§1-1 `:35`、P1 `:98`、§8.2-1 `:194`）。**关键：生长式而非装配式**——轮廓连续过渡，禁字母/报纸/木纹拼贴物（§2-7 `:58`、§3.1 `:78`）。**失败信号**：面片碎裂/多视点（→ 毕加索越界警报① `:106`）、部件像贴上去的（接缝可见）、只剩「单一物种畸变」（P1 弱档 `:98`）。
3. **符号指向 ≥2 轴联合（分工判据）**：每帧 ≥1 仪式符号（月/供盘/烟叶/剪刀/鼓式节律）且符号承担叙事、不得静物化陈列（§1-6 `:40`、§1-8 `:42`、§8.2-6 `:199`）；甘蔗=奴隶制、烟叶=存续传统、月亮=童年神性恐惧（§3.1 `:79`）。判「林档」而非「毕/博档」须 ≥2 轴（符号指向 + 方向/职能），**不得只看面具脸或几何感**（`:80-81`、`:86-87`、dossier 自审 B1 `:426`）。
4. **暗绿-赭-黑主域＋红橙闪点（P3 默认 70%）**：主色相 ≤4（绿/黑/赭/红橙）、红橙像素 2–8%、高饱和(S>0.6) ≤12%、平均明度 ≤0.45（§1-5 `:39`、§8.2-3 `:196`）。**失败信号**：亮色铺开（P3 弱档 `:100`，→ 博斯/高更越界 `:106`）、糖果色/装饰图案（§8.1 负向段 `:182-186`）。**归纳阈值内部张力**：P3 弱档「亮色铺开」与 §8.2-3「红橙 ≤8%」字面上互斥（AUDIT `counterexample.md` 反例 3 `[inference]`）——练习时按「弱档须显式豁免 §8.2-3 区间」处理，不自相矛盾。
5. **薄涂-渗化表面（kraft 纸底透出）**：露纸/浅底 5–20%、滴/溅连通域 ≥3、厚涂高光=0、高频能量显式中档（§1-9 `:43`、§8.2-4 `:197`、§2-6 `:57`）；须显式声明「柔边薄涂、哑光、无清漆」（C-01/C-05）。**失败信号**：厚涂/impasto/光泽 3D 渲染（§8.1 负向段 `:185`）。
6. **竖向节律与「舞蹈」结构**：竖线族 ≥3 组、弧线与竖线交替、重心偏下（植被承载重量）（§1-10 `:44`、§8.2-8 `:201`）；Berger：「arranged with such rhythmic skill… almost exorcises their terror」（corpus #23 `:170-174`）。与机制 1 一体：密度靠竖秆成节律，节律把「满」组织成「仪式进行时」而非杂乱堆砌。

## 4. 具体练习（可操作 · 3 阶梯 · 全为「建议练习」）

> **每一级都带「可观察结果」「自查」「常见失败」**，自查引用 §8.2 原文规则作判据（不另造阈值）。执行介质为纸笔/数字笔临摹或重演（§12 `:359`）。**全部标 `建议练习`；练习效果未经真人验证，不声称已证实学习收益。本轮未渲染、未生成帧、未像素测量。**

### 阶梯 1 — 密度场 + 单部件兽形（density field + single-part hybrid）

**目标**：先只建立「满幅无地平线的竖向场」与「一处兽形替换」，不铺满混种、不加神祇。
1. 取一张对开纸，先用炭笔只画**甘蔗/竹/阔叶的竖线族**（≥3 组、秆 ≥8 根），让四边都被植物触边、不留天空、不画地平线（§12.1 `:364` 的「禁地平线、禁亮色」；§8.2-2/-8）。
2. 在竖线场里放**一个**主体，只允许替换**一个部位**为动物部件（如头→马首 / 足→手形足），其余保持人；用 ≥3 遍稀释色、每遍等干（§12.8 `:399`；§2-6 `:57`）。
3. 暗域收尾：主色只用暗绿/黑/赭＋一处红橙闪点；纸底透出、留 3 处以上滴点（§8.2-3/-4）。
4. 自查（§8.2）：① 拼贴接缝=0、部件可拆 ≥2 类来源；② 负空间 ≤15%、无地平线、四边触边 ≥90%；③ 竖线族 ≥3、重心偏下；④ 红橙 ≤8%、露纸 5–20%。
- **可观察结果**：第一眼数得出「几类部件」；画面找不到地平线/天光；主体像从秆里长出而不是站在景前；竖秆成列、弧肢与竖线交替。
- **常见失败**：把植物画成植物学细描（→ 卢梭式）；加了透视消失点或一小块天空；兽形部件像贴上去（有接缝）；亮色铺开（滑向博斯/高更侧）。

### 阶梯 2 — 生长式三元合体 + 仪式在场（grown hybrid + ritual presence）

**目标**：把 L1 的「单部件」升级为「人-动物-植物三元合体」，并让符号承担叙事。
1. 选人 / 动物 / 植物各一，做 **3 版递进**：写生 → 几何化 → **生长式融合**（§12.1 `:364`）；目标「接缝不可见」（§2-7 `:58`、§12.1 `:362`）。
2. 画「一场仪式」：1 个主体 + 1 个供物 + ≥2 个符号（月/叶/果/剪刀/供盘）；主体只允许**一处**「附体标记」（马蹄/翼/第二头）（§12.2 `:369`）；禁说明性手势、禁把供物画成静物摆设（§8.2-6 `:199`）。
3. 用 §3.1 四判据做一次 **≥2 轴联合**自检：符号指向（加勒比仪式/历史 vs 欧洲日常）、形体构造（生长合体 vs 碎裂）、色彩（暗域+闪点 vs 棕灰）、方向（被殖民方自我图像 vs 内部革命）（`:80`）；并做 vs 博斯的 ①③ 自检（合体职能=力量/神性、情绪距离=交感敬畏）（`:86`）。
4. 自查（§8.2）：§8.2-1 合体、§8.2-6 符号叙事、§8.2-5 面具脸≥1（P6 强档加非人首 ≥1）、§8.2-7 性征「神圣而非色情」。
- **可观察结果**：≥1 主体可拆 ≥2 类部件且无接缝；≥1 符号在推动叙事（不是陈列）；至少 2 条分工轴同时落在林侧；暗域中仍可读（靠轮廓与微光，不靠戏剧光）。
- **常见失败**：只因「有面具脸/几何感」就判林档（单轴假阳性，见 §6 失败 3）；把神祇/符号画成人类学插图（§3-8 `:73`）；混入毕式碎裂/拼贴物或博式道德讽喻、明亮全景；§8.2-7 滑向 body-horror/装饰色情。

### 阶梯 3 — 满幅综合 + 越界警报对照（full composition + boundary A/B）

**目标**：把密度、兽形、符号、暗域、表面、节律六机制顶住不退化，并用 A/B 对照验证身份边界。
1. 用 4 张对开纸拼一张大画（不裁接缝对齐），只允许 3 个母题循环 ≥2 次，涂层保持「能透出纸纹」的稀薄度（§12.9 `:404`）；或以一则新闻为题画「无中心群像」≥8 个面具化头/肢、无叙事主角、土色+黑+白闪点（§12.5 `:384`）。
2. **A/B 对照（建议练习）**：同一题材出两张——A 卡按林档（生长合体＋满幅暗域＋加勒比符号），B 卡故意引入一条越界警报（碎裂/拼贴物、或亮色全景＋道德讽喻、或装饰性热带色、或植物学细描、或壁画工程尺度）（§4 `:106`）；逐条用 §8.2 八项 + §3.1 ≥2 轴判据说清「哪条轴先越界」。
3. 完成 **§8.2 八条逐项自查表**（§8.2 `:194-201`），每项记「过 / 不过 / 未指定」，不把「未指定」算成「过」。
4. 自查：§8.2-1/-2/-3/-4/-5/-6/-7/-8 全表；并检查起步判据（P1/P2 ≥1 中档）**之后**是否仍满足八条（反例 1 的教训）。
- **可观察结果**：八条逐项有结论；A/B 的越界点能用 1 条写死判据指认（不是「感觉不像」）；大画保持稀薄统一、母题复现 ≥2 次；满幅仍无地平线。
- **常见失败**：为了「讲清故事」加说明文字/字母（击穿「回到自身 landscape」核心，§3.1 `:82`）；「怪诞」轴同帧折中（博斯一半林一半，`:88`）；把 L1 已建立的密度/暗域在升阶梯时回退；照抄简报把《丛林》记成 MALBA 藏品（事实层失败，见 §6 失败 0）。

> **阶梯间递进逻辑**：L1 场+单兽形 → L2 三元合体+仪式在场 → L3 满幅综合+A/B 边界。每升一级，**已建立的密度/暗域/无拼贴纪律不得回退**（这正是 mechanism_notes 把 C-01/C-05/C-06/C-12/C-17/C-18 及 §3.1 两写死条款当「失败条件」的用武之地）。
