## §1 起点：先分清楚「两类知识」

学荷加斯最容易犯的错，是把两件事混在一起：

1. **他本人写下的形式论与创作意图**——`[自述]`：《美的分析》的 line of beauty / serpentine line（语料 #22/#23）、「我的画就是我的舞台」「绘制现代道德题材」「性格而非漫画」「为用不为饰」（§3 / §5 / corpus）。这些是**可逐字回引的作者原意**。
2. **本项目为逐帧生成归纳的操作规则**——`[归纳]`：§8.2 八规则、§4 六参数、§3.1 分镜接口。这些是**设计者的决策程序**，不是荷加斯的内心（[hogarth.md](../../dossiers/hogarth.md) L243 明言阈值「未对原作做像素测量」，L5 把 `[归纳]` 定义为「不冒充艺术家内心」）。

学习路径的第一课，就是给下面每一条标对等级；标错等级 = 把研究者的推断冒充作者原意（`00-GOAL.md` L9、AUDIT caveat）。

## §3 三个主机制（M0 / M1 / M2）

<a id="db-source-line-38"></a>
### M0 — line-of-beauty S 曲线（形式分析工具）`[自述]`

- **作者原意（逐字可回引）**：语料 #22（[hogarth.md](../../dossiers/_corpus/hogarth.md) L168–173）「在以上诸线之外加上**波状线 waving line**……因此我们称它为『美的线』the line of beauty」；语料 #23（L175–180）「**蛇形线 serpentine line** 同时朝不同方向起伏缠绕，牵引眼睛愉悦地沿着它连续的多样行进……精确的蛇形线，或『优雅的线』line of grace」——图版以细金属丝绕锥体缠出。底本 = 1833 Anecdotes / Gutenberg #51459（AUDIT RESULT §4 联网复核 `line of beauty`×7、`line of grace`×5 命中）。
- **学什么**（§12 #7 L413）：「形式分析工具——线条作为造型主变量；『看得见的理论』的图版设计」。即：把「多样 variety / 有组织的多样」（语料 #20/#21）落到一根可画的 S 线上，让眼睛沿连续变化移动。
- **边界（关键，别学错）**：S 曲线**不是**「是不是荷加斯」的画面判据。[hogarth.md](../../modules/hogarth.md) §8.1 负向段 L32 明确 `--no … idealised beauty … decorative abstraction`；§4 用法注 L114 说「P2/P3 定是不是荷加斯」，与线条美论无关。S 曲线是《美的分析》里的形式论/教具，与「现代道德题材 + 系列叙事」是两条不同的轴：一条讲线条造型，一条讲叙事工程。**不要把 S 曲线当成生成 moral subject 的 prompt 关键词。**
- **它落到练习的位置**：阶梯1（§4）——先练「看线」再练「用线」；它不进 §8.2 八条逐帧规则（八条里没有一条是 S 曲线阈值）。

### M1 — 连环画叙事序列机制（progress series）`[自述]` 意图 + `[归纳]` 操作

- **作者意图** `[自述]`：corpus #1「modern moral subject… a field not broken up」；§3-1 L69「画如戏剧 dumb show」；§3-5 L73「为用不为饰」；§1-1 L35「作品以 6/8/12 帧成套……完整道德弧必须按序读」。
- **机制内核** `[归纳]`（[hogarth.md](../../dossiers/hogarth.md) §3.1 L86–101）：叙事在**帧间**——「帧＝时间轴上的一站；服装/道具状态跨帧推进」；判据 = **「帧间是否存在进度依赖」**（跳过一帧则因果断裂）。对侧洛克威尔 = 单帧自足（帧内线索链）。
- **可操作三条**（§3.1 L98）：① 系列骨架 N 帧＝N 场景，逐帧「标题＋一行动作＋道具状态」；② 帧间连续性检查 = 把主角服装/道具列「进度表」逐帧核（Lane B 分镜一致性 B1–B4 原型）；③ 顺序写死（《啤酒街》先于《琴酒巷》）、订阅预览 = 「关键帧先行」验收原型。
- **代码艺术接口** `[归纳]`：§8.2-2 L235「系列帧数 ≥6；同一主角可追踪元素每帧出现率 100%；跨帧状态可列进度表（≥2 次状态变化）」；§8.1 正向 L27 `[series variant] a numbered progress: the same protagonist across frames, costume and props declining with his fortune`；负向 L35 `single-frame isolation when a series is requested (no progress dependency between frames)`。[hogarth.md](../../modules/hogarth.md) L9 浓缩为指纹 #1。

## §4 三段练习阶梯（顺序 = 看线 → 建序列 → 收窄适用域）

每段都标 **观察对象 / 创作决策 / 机制 / 参数 / 一次可做的练习 / 反例 / 自检** 七项（Lane B 契约）。全部为建议练习，无真人评价。

<a id="db-source-line-64"></a>
### 阶梯 1 — S 曲线：把形式论变成一根可画的线（M0）

- 观察对象：《美的分析》图版 1（§12 #7）。
- 创作决策：**先选造型主变量 = 线条的连续多样，而非题材**（`[自述]` #22/#23）；牺牲「理想化美 / 装饰抽象」（§8.1 负向 L32/L34）。
- 机制：waving line → line of beauty；serpentine line → line of grace；「有组织的多样」（#21）让眼睛沿 S 线连续移动。
- 参数：**此处无 §4/§8.2 数值参数**（S 曲线不进逐帧规则）；这正是「形式论 ≠ 生成门」的证据。
- 一次可做的练习（照录 §12 #7 L414）：临摹图版 1 线条系统，标出 ≥5 处 line of beauty / line of grace 实例；再在 3 件日常物（花瓶/椅子/人体）上各画一条「最优 S 线」。
- 反例：把 S 曲线写进 moral-subject prompt 当风格词 → 与 `--no idealised beauty / decorative abstraction` 冲突（§8.1 L32/L34）；这是**误用**，不是作者原意。
- 自检：能否把「美的线/优雅的线」分别指到一段 `[自述]` 原文（#22/#23）？能否说明它为何不进 §8.2 八规则？

<a id="db-source-line-74"></a>
### 阶梯 2 — 连环画序列：建帧间进度依赖（M1），并套上 CE-1 carve-out

- 观察对象：《浪子历程》8 帧（§12 #1）/《浪女历程》1–3 帧（§12 #4）/《勤奋与懒散》12 帧双轨。
- 创作决策：**先选叙事单位 = 系列，而非单幅**（§1-1 L35）；牺牲「每帧自足」（对侧洛克威尔，§3.1 四轴）。
- 机制：帧间进度依赖；服装/道具状态推进；题刻 = 结尾落地文案槽（§3.1 L98）。
- 参数 `[归纳]`：P1 系列化强度默认 **8**（§4 L107，工作流参数、不进画面重叠计算）；P6 角色复用度 = 系列内复用（L112）；§8.2-2 L235 帧数 ≥6 / 可追踪元素 100% / ≥2 次状态变化；§8.2-7 L240 题刻 ≤2 行。
- 一次可做的练习（§12 #1 L384 扩展）：把 8 帧写成 **8 行分镜表**（帧号｜标题｜一行动作｜服装/道具状态），抽掉任意一帧让同伴复述——复述断裂即证明进度依赖成立。再用 6 格写一个当代 progress 大纲、每格标一个「降级/升级」元素（§12 #4 L399）。
- **反例 = CE-1 PARTIAL REFUTATION + scoped carve-out**（brief 点名，详见 [mechanism_notes.md](mechanism_notes.md) §E）：《琴酒巷》×《啤酒街》是 dossier 自称的 core 道德对位 pair（§1-5 L39 / §12 #3 L391），但它是 **2 帧、无同一主角**。把 §8.2-2「帧数 ≥6 + 同一主角跨帧进度」当**必要条件**逐字套上去，会拒绝一张 dossier 自己认定为荷加斯的作品。AUDIT `counterexample.md` L23 判 **PARTIAL REFUTATION**：规则对《浪子历程》/《浪女历程》/《勤奋与懒散》（8/6/12 帧 progress series）成立，但**不是荷加斯的必要条件**。
  - **carve-out（本 shard 记录，不改仓库）**：§8.2-2 / P1 默认 8 的「系列进度规则」适用域应收窄为 **progress-series variant only**；pair/对位作品走 §8.2-5（对位规则）而非 §8.2-2。§4 P1 的弱档「小系列 3–6 帧（成对/三段）」（L107）本身已给 pair 留了位置，只是 §8.2-2 被写成无条件逐帧检查，造成不一致（AUDIT counterexample.md L21）。
- 自检：分镜表抽帧测试是否断裂？练习对象若换成 2 帧 pair，是否**停手不套** §8.2-2 而改走对位规则？能否说出 carve-out 是 `[inference]` 纸面判定而非已渲染验证？

### 阶梯 3 — 对位 + 表面工艺：把 OVERTURNED 当已决事实落地（M2 + resolved fact）

- 观察对象：《琴酒巷》×《啤酒街》对（§12 #3）/《时髦婚姻 1》（§12 #2）。
- 创作决策：先选**共享构图骨架 + 语义相反**（§1-5 L39）；牺牲「单帧自足」；光线选均匀舞台光（P5 默认 30%，§4 L111）、牺牲戏剧硬光（C-01 同侧声明 `even stage light`）。
- 机制：§8.2-5 对位规则（骨架 ≥70%、相反标志物 ≥3 对）；§8.2-1 线索 ≥5 / 可读文字 ≥1；§8.2-4 面孔类型化不夸张（关键点偏差 ≤15%）；§8.2-8 表面规则。
- 参数 `[归纳]`：P2 剧场化 **70%** + P3 线索密度 **65%**（§4 L108–109；§8.1 中文说明 L228「两条同时 ≥中档才成立」= 是不是荷加斯的起步）；P4 讽刺/道德强度 50%（警示题材升 85%）；§8.2-8 L241 排线族 ≥2 方向、线覆盖率 ≥15%、平涂 ≤10%。
- **OVERTURNED 已决事实（brief 点名）**：排线塑形**允许交叉排线——与戈雅相反**。这是 AUDIT 自审B #4（L444）已 OVERTURNED 初稿假设「无交叉排线」后的**定论**，写入 §1-9 L43 / §2-3 L54 / §8.2-8 L241，对侧 `goya.md` L39/L52「无交叉排线原则 + 平飞尘块」为互斥轴。学习时**直接采信为 resolved fact，不再当作待查假设**（AUDIT RESULT §4「1/1 OVERTURNED accounted for」、GOALS A-103 L99）。
- 一次可做的练习（§12 #3 L394）：为同一主题画**两张对位草图**（同构图骨架、反语义），骨架相似度自评 ≥70%；再写两行题刻（各 ≤8 字）。版画变体按 §8.1 正向 L28 `pure etching and engraving — bold confident line, cross-hatching for shadow, a caption or verse engraved below the image` 落地交叉排线。
- 反例：若把交叉排线禁掉（照抄戈雅），即回到已被 OVERTURNED 的错误初稿；若把对位帧套用 §8.2-2 进度规则，即 CE-1 误用（阶梯2）。
- 自检：三查（§8.1 中文说明 L229）——① 每帧线索 ≥5、可读文字 ≥1？② 面孔类型化但不夸张？③ 均匀可读光（画内单一硬光源 = 0、无近黑背景）？再加两查：④ 交叉排线是否保留（OVERTURNED）？⑤ 对位骨架相似度是否自评 ≥70%？
