## 0. 写作纪律（本文件如何读）

- **严格分区**：`[自述]` 与 `[归纳]`/`[推测]` **分开列、不混写**。凡是马蒂斯本人写下/说出且带出处的，放 §1，逐条给 `corpus Q#` 或 dossier §5 定位与类型（`[self-written]`/`[reported speech]` ≈ `[自述]`；`[contemporary record]` ≈ `[史料]`，按 corpus 卷首 L4 的映射）。
- **不从画面外观反推心理**：不从「看起来欢愉」推出「作者当时心情愉悦」，不从「留白大」推出「作者追求空灵」。凡本项目为操作而归纳的决策序，一律标 `[归纳]` 并写明「这是本项目设计的操作序列，不是对马蒂斯内心或创作现场的断言」；无直接文献支持的谱系关系标 `[推测]` 并写明缺口（dossier §10-5 L238 / 自审 D L463）。
- **每个决策步骤都带证据级**：§2 的每一步在末列给出 `grade` 与定位；`[自述]` 步骤只在作者原话直接支持该决策时引用，其余一律 `[归纳]`。
- **决策序定义**：按 Lane B 的四问组织——**先选什么 / 牺牲什么 / 为什么 / 何时失效**（02-EXECUTION-PLAN.md L66）。

## 4. 何时整体失效（决策序的边界汇总）

1. **进入材质/金属域** → D7 失效，走 P4 边界注 / near-miss #9 / C-15+N6（克里姆特接口）⟨H-D7⟩。
2. **与低饱和模块组合且对方是全帧均值型** → D2/D3 失效，C-06 不可拆、二选一（N4）⟨H-D3⟩。
3. **反约束被泛化**（Lane B 02「没有高光的平涂」）→ 平涂系整体误判，须 N1/N2 重算反约束段（C-16）。
4. **「空白/留白」未定义对齐** → D5 自查自相矛盾（C-17）。
5. **浮雕/投影塑形主体** → D4 失效，C-18 须写死主体掩膜、70/30。
6. **P3 弱档 / 1900 前风格** → D1 的「整体压成纯平面」不成立，`--no` 只约束默认/强档（dossier L179）。
7. **§8.2 阈值未经实测** → 任何「达标/不达标」结论都只是对 `[归纳]` 靶值的自查，不是对原作或学习成效的验证⟨H-UNV⟩。
