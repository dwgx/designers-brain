## 1. 前置知识（动手前先知道什么）

1. **平面与平涂的概念**：色块从边缘到内部等值、不靠渐变塑形（dossier §2-1 L44 `[研究]`）；色块内部明度变化 ≤5%、剪纸期 0 渐变（dossier §1-1 L29 `[研究]`）⟨L09⟩。要能区分「平涂」与「柔边/晕染/投影」。
2. **色相—饱和度—明度三分量**：§8.2-1 用「每块饱和度 ≥70%」「明度分层 ≤3 级」「同屏纯色块 ≤8」「渐变面积 ≤5%」（dossier L186 / card L43 `[归纳]`）⟨L01⟩；要能读出并测量这四个量，而不是凭观感说「颜色很纯」。
3. **负空间不是「空着」**：背景/纸色可见面积 ≥20%，相邻形状间隙 ∈ [2%, 12%]×最短边（dossier L190 / card L47 §8.2-5 `[归纳]`）⟨L02⟩；并知道「空白」与「留白」必须先定义对齐才能与别的模块同帧（conflicts.md §2 C-17 L279-282）⟨L27⟩。
4. **剪影 / 硬边 / 垂直轴**：形由外轮廓定义、无描边无投影（§1-3 L31、§8.2-2 L187）；所有曲线回应一条隐含垂直轴（§1-7 L35 `[自述]`、§8.2-3 L188）⟨L04⟩⟨L05⟩。
5. **来源链常识（仅作背景，不在本路径新考）**：上游 Moreau / Chardin / 印象派 / 塞尚 / 日本·伊斯兰·非洲艺术，下游野兽派→毕加索→现代平面设计（dossier §6.1-6.2 L126-139 `[史料]`/`[归纳]`）。**马蒂斯—北斋的直接影响关系无直接文献支持，按 `[推测]` 处理、未写入正文结论**（dossier §10-5 L238 / 自审 D L463）⟨L53⟩。
6. **组合规则词汇**：轴所有权（N3）、可拆/不可拆（N4）、反约束适用域（N1/N2）、色数计数口径（N6）、组合卡验收（N9）（conflicts.md §3 L305-333）⟨L31⟩。因为本路径的第 3 阶练习会碰到「什么时候不该继续用马蒂斯」。
7. **诚实边界**：§8.2 全部阈值未实测（⟨L49⟩）；3 张公开图像只做过字节/清单核对、**未做视觉检视**（`image_seen=0`，AUDIT-matisse coverage-manifest.json honest_limits）⟨L22⟩；1908/1939 法语原文、Q17/Q19/Q20 原始出处、R14（429）/R15（未核）仍为未取得（dossier §10 L234-239 / corpus 缺口 L163-168 / AUDIT C15）⟨L55⟩。

### 阶梯 A｜平涂剪纸基础研究（flat-color paper-cut studies）— 建议练习

- **对应作品**：§12 第 6/7/9 件（《爵士》《游泳池》《蜗牛》）⟨L13⟩⟨L17⟩⟨L14⟩；工序依据 §2-8 剪纸工艺（助手涂 gouache 纸 → 剪刀剪形 → 墙面反复钉放调整 → 定稿，dossier L51 `[史料]`）与 §12-7「先钉墙调位置 3 轮再定稿」（L391）。

- **步骤**：
  1. 选 1 个母题（叶 / 星 / 裸体剪影），限 ≤6 色（P2 强档 4–6，默认 7；dossier L81 / card L58）⟨L23⟩；**不打草稿**直接剪 5–7 个形（对应 §12-6「不许画草稿」L386）。

  3. 定稿后逐项跑 §8.2 自查（见下）。

## 8. 使用边界

1. **【主边界】P4 边界注（克里姆特接口）**：P4 **只调图案密度**，其承载面**恒为「平涂纯色、无材质」**（见 §1 指纹 1/3、§2 规则 1、§8.1 负向约束 `--no gradient/texture noise/glow`）。它**不含**材质区分、金属/金箔表面、纹理明度范围与「写实面孔 × 装饰」的渲染方式对撞——需要这些时**不属于本模块**，应交给克里姆特类模块（另立参数：材质对比度 / 纹理明度范围 / 写实-装饰渲染落差）。本判据为 `[归纳]`，**可直接被 wave2 实验推翻**（dossier L88 / card L65；AUDIT-matisse C03/C04；expansion.md L250-252）⟨L24⟩⟨L52⟩。
2. **near-miss #9 三选口径**：金属＋人物→克里姆特 / 金·水材质→光琳 / 平涂纯色→马蒂斯；**同屏分区、「金」来源不得混用、预检按 C-15/C-16**（conflicts.md L355 `[归纳]`；AUDIT C10）⟨L30⟩。
3. **C-15 / N6 接口**：色数上限只约束平涂色块层；金属/金箔/高光材质层单列、不计色数，但面积 ≤5% 画面且必须在卡内声明（conflicts.md L253-255 / L323-324）⟨L29⟩。
4. **§8.1 `--no` 禁令范围**：是**生成用护栏**，约束「本模块默认与强档的输出」，**不是**「马蒂斯从不用明暗/排线」的历史断言——§4 P3 **弱档**明确保留体积明暗与透视（对应 1900 年前风格，学院期在卢浮宫临摹 Chardin 共 4 张，§6.1）。正确说法是「本模块的默认输出不含排线」`[归纳]`（dossier L179 / §4 P3 L82）⟨L47⟩。
5. **数值级别**：§8.2 的 7 条量化阈值（面积配比 25–45%、间隙 2–12% 等）为 `[归纳]` + `[UNVERIFIED]`，**未经真实渲染器/像素实测**；只能作自查靶值，不得写成「马蒂斯原作实测值」。R14（Met 429）、R15（未核）与若干法语原文/原始出处仍未取得⟨L49⟩⟨L55⟩。
6. **组合边界**：与任何低饱和模块组合触发 **C-06**（辅模块为全帧均值型时不可拆、二选一；为区域型时可拆，须改写为「主体色块面积 ≥5% 者 ≥70%」）⟨L25⟩；组合卡须重算反约束段（N1/N2）、附轴所有权表（N3）、冲突轴整条移除而非调档⟨L31⟩；负空间须先做「空白/留白」定义对齐（C-17）⟨L27⟩；形体塑造与米开朗基罗组合须写死主体掩膜（C-18/N4）⟨L28⟩。
7. **练习与人评边界**：本路径全部练习为**建议练习**，**未经真人完成或评价**，不写「已证实学习收益」；模型/脚本自查结果不是人评（01-AUDIT.md §8.1 L271-273、§8.4 L308）⟨L51⟩。静态图不套用动画专属检查项（S-06 第 4 项）。
