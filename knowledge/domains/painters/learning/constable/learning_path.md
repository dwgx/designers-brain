## §4 具体练习（三阶梯 + 收口；**全部为建议练习**，效果未经人评）

> 依据 02-EXECUTION-PLAN.md L64 的学习顺序：观察对象 → 创作决策 → 机制 → 参数 → 一次可做的练习 → 反例 → 自检。每组练习都标明「看什么 / 牺牲什么 / 可观察结果 / 何时失效」，失效条件即 §6 常见失败。

**阶梯 A —— 看天制度 + 云景（对应 §12 第 8/9/10 件；练 M1/M9、P1/P2/P6 弱档）** ⟨L32⟩
- **建议练习 A1（连续 7 天 skying）**：连续 7 天每天同一时刻（正午）画一张 A5 天空，背面写「日期/时刻/风向/云型/光况」；一周后按 Howard 分类归型，看自己的「云库」（沿用 dossier §12-10 L397，不新增方法）。**观察对象**＝云型与题记的对应；**牺牲**＝地标、人物、叙事；**可观察结果**＝7 张题记可相互区分、能按云型归档。⟨L22⟩
- **建议练习 A2（无地标雨云）**：只画「云 + 雨幕」、不画地标，要求云团 ≥60% 且保留一条地平线（沿用 §12-9 L392）。**这是 CX-1 反例档的正向练习**：它验证「天空即主题」成立，同时暴露 §4 越界警报① 的误判（见 §6/§8）。⟨L21⟩
- **自查靶值**：P2 升强、P6 降弱、P1 ≥50%（dossier §8.1 中文说明 L197 明确「无人物、无地标也成立——天空即主题」）。⟨L33⟩

**阶梯 B —— 英格兰乡土云景 + 六英尺大画机制（对应 §12 第 1/4/7 件；练 M3/M4/M8、P1/P3/P4/P6 联动）** ⟨L34⟩
- **建议练习 B1（三速写组装）**：选一处熟悉的河边场景，三个不同日子各画一张小速写；一周后在画室组装成「1.5 米级」大构图，要求天空 ≥1/3、1 个劳作人物、1 处红点对位（沿用 §12-1 L352）。**观察对象**＝写生库→画室建构；**牺牲**＝现场即时性（换结构完整度）；**可观察结果**＝能指出每个局部来自哪张速写。⟨L13⟩
- **建议练习 B2（等大稿对照）**：同一构图做「现场速写（2 小时）→ 等大稿（半天）→ 完成作（2 天）」三档并置，逐档记录笔触速度与底色保留量（沿用 §12-4 L367 两档法 + §2-3 L54 等大稿机制 + §2-4 L55 有色底子粉=晴/褐=风暴）。⟨L16⟩⟨L35⟩
- **建议练习 B3（红点对位）**：在绿族主导的画面里只放 2–3 处极小面积红（红缨/红砖/屋顶），自查「红是否只是对位而非互补色振动」（§2-7 L58 / §8.2-3 L205）。⟨L27⟩
