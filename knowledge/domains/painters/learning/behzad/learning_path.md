## 3. 要观察的机制

<a id="db-source-line-29"></a>
### 3.1 视觉指纹（§1，11 条）

- **层叠平面空间（无单点透视）**
- **建筑切分叙事（空间读作时间）**
- **微书级精度**
- **人物＝理想类型 + 微妙情绪**
- **克制色阶 + 金点**
- **明度对比被强调**
- **姿态/视线编排**
- **叙事游戏性（藏细节）**
- **「签名式」枯树曲枝**
- **题记嵌入物件**
- **手抄本页整体设计**

## 4. 具体练习（3 阶梯，全部建议练习 `[归纳]`）

1. **阶梯一 · 指纹认领**：取一张自绘草图，逐条勾选 §1 指纹表，记录「命中 / 未命中」——记录的是自查结果，不是原作测量。
2. **阶梯一 · 单规则自查**：用 `§8.2-1`（dossier `L202`）四项自查表对一张结构图打勾；全部为建议练习。
3. **阶梯二 · 参数滑轨**：按 §4 六参数从弱→中→强各出一版，比较档位差异（不声称原作如此）。
4. **阶梯二 · 规则联查**：把 §8.2 8 条做成一张表逐帧自查，标出冲突行，交 `mechanism_notes.md §4`。
5. **阶梯三 · 分工对照**：按 §3.1 判据与邻近模块并置两版，只做纸面分辨、不渲染像素。

## 6. 常见失败（F1–F5）

- **F1 把题材当风格**：只画对器物/题材就判「成立」——§8.2 统计量本不依赖任何器物专名（参 [mechanism_notes.md](mechanism_notes.md) 反例 CE-3 类）。
- **F2 把 `[归纳]` 阈值当已实测**：练习自查 ≠ 原作像素测量（分母＝假想参考帧）。
- **F3 混写等级**：`[自述]` 与 `[归纳]`/`[reported speech]` 不得并成一句、不得反推心理。
- **F4 把反例当史实证伪**：8 条反例均 `[inference]` 纸面推演，非已验证实验。
- **F5 把 open 写成已收口**：conflicts 命中、外部取证 partial、权利漂移一律携带。
