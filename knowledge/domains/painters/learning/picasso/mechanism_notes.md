## 3. 冲突行（grep `conflicts.md` 的 C-06 / C-16 / C-18）

> grep 结果：`C-06` 在 `conflicts.md L123`（表 `L37` 亦有条目）、`C-16 L258`、`C-18 L285`；模块卡冲突注记 `L83–85` 逐条指向三者（AUDIT claim_evidence_map §3 `L70–76` 已核，本分片沿用，不重裁）。

<a id="db-source-line-49"></a>
### C-06 · 饱和度硬冲突（空交集）
- **毕加索侧**：§8.2-1 全帧均值 ≤35%（模块卡 `L59`；conflicts.md `L128` 引 `picasso.md L167`）。**全帧均值型 → §3 N4 判别「不可拆侧」**（`L134`）。
- **对方**：马蒂斯「每块 ≥70%」（`L127`）；达·芬奇/莫奈/米开朗基罗同侧低饱和（`L129`）。
- **后果**：马蒂斯大面积色块（§8.2-4 最大块占 25–45%）使全帧均值必然 >35% → 空交集（`L130`）。
- **解与练习落点**：① 饱和度轴**单主**（`L132`）；② 可拆方案只改写马蒂斯侧为「主体色块 ≥70% + 背景走另一模块」（`L133`），但**辅模块须为区域型规则**——本卡是均值型，不可拆（`L134`）；③ 练习 1 步骤 3、练习 3 步骤 3 显式做「轴单主声明」。
- **失败条件**：把 C-06 当普通可拆冲突硬凑「背景 S≤35%」；或把马蒂斯与任一低饱和模块组合时不触发本条检查。
- **未验证**：可拆方案未经组合实验验证（AUDIT RESULT §八 `L80`）。

<a id="db-source-line-57"></a>
### C-16 · 反约束适用域覆盖冲突
- **毕加索侧**：§8.2-6 平涂判据 ΔE≤6≥85%（模块卡 `L64`；conflicts.md `L264` 引 `picasso.md L172`）。
- **对方/性质**：Lane B 02 卡「别做成：没有高光的平涂」是液态金属材质的**正当反约束**（`L262`，`[史料]`），但泛化会误伤马蒂斯/毕加索/北斋核心表面（`L266`）。
- **解与练习落点**：反约束带适用域 = 02 卡（液态金属）；改写「没有高光的平涂」→「**金属/液体表面**没有高光的平涂」（`L269`）；卡内含平涂系模块时该句必须删除或加限定（`L270`，触发 §3 N1 一致性检查）。练习 2 的「C-16 嵌入点」按此操作。
- **失败条件**：把「没有高光的平涂」当全局反约束 → 把练习 2 刻意产出的平涂判违规；模板侧 N1/N2 未落地（AUDIT RESULT §六 `L59` 注明属 02 卡反约束适用域问题、非本卡缺陷）。
- **需改写？**：AUDIT 裁定「否」（模板侧指针由上游维护），本分片沿用。

<a id="db-source-line-64"></a>
### C-18 · 形体塑造退化冲突（可分区）
- **毕加索侧**：§4 P3 强档零渐变（模块卡 `L74`）+ §8.2-6 平涂判据（`L64`）（conflicts.md `L290` 引 `picasso.md L73`/`L172`）。
- **对方**：米开朗基罗「浮雕式强明暗 + 硬边投影」（`L289`）。
- **后果**：同帧双标准下主体要么被凿出（违反 ΔE≤6≥85%）、要么被压平（违反浮雕强度与硬边阴影）（`L292`）。列为**退化冲突**因作用对象可分离（人物 vs 背景/装饰）。
- **解与练习落点**：① 分对象拆分——主体人物 = 米开朗基罗式建模（允许明暗与 ≤1 投影），背景/装饰面 = 平涂（ΔE≤6≥85%、无投影），显式写「主体掩膜」+ **分区判分**（`L294`）；② 马蒂斯「无投影」改「主体外无投影」（`L295`）；③ 70/30 时主模块塑造方式覆盖 ≥70% 面积（可判定：掩膜面积比）（`L296`）。**练习 3 全阶**按此落地。
- **失败条件**：对全帧套 ΔE≤6≥85% 的同时要求主体浮雕渐变（互相判违规）；分区掩膜未写「哪层归谁」；主体/背景面积比未记录。
- **未验证**：分区解未经组合实验验证（AUDIT RESULT §八 `L80`）；练习只产出可判分方案，不宣称 E2/E4 通过。
