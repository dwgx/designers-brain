## 4. 具体练习（建议练习 · 阶梯 ≥3 级）

> **全部为建议练习**。下列「可观察结果」= 按 §8.2 规则可自测的**产出特征**，**不是**已证实的学习收益。练习效果未经真人完成/评价，不得写成「提升」「已验证有效」。
> 阶梯顺序（brief 指定）：**① 单色族色盘练习 → ② 平涂面片拼装（ΔE 纪律）→ ③ 主体/背景分区（C-18）**。每级均沿用 dossier §12 既有「怎么练」的三步式并叠加本轮量化自查。

<a id="db-source-line-65"></a>
### 练习 1（第 1 阶）· 单色族色盘研究 —— 把「色相≤5 / 明度级≥6 / 饱和度≤35%」练成手感 `[建议练习]`
- **前置**：K1、K5。
- **材料**：W3《老吉他手》（近单色蓝绿域）与 W1《卡恩维勒肖像》（棕灰域）作为对照。
- **操作**：
  1. 取一张人物/静物照，只允许 **≤5 个色相**（分析档收敛到 ≤3：赭/棕/灰/黑/白），黑白计入明度级、不计色相数。
  2. 把选定色域拉出 **≥6 级 L* 明度**阶梯（每级标号 1–6），用这 6 级画 3 张同构图草图（对应 dossier §12.1「5 级明度草图 ×3」`L349`）。
  3. 全帧统计 **平均饱和度 HSL S ≤35%**；若超标，用「掺灰 / 降纯」而非「换亮色」修正。
  4. 缩到 64px 自查「低头+抱琴 / 坐姿」剪影仍可读（dossier §12.1 `L349`、§8.2-8 锚点验收）。
- **对应轴**：色相≤5、明度级≥6、平均饱和度≤35%。
- **本阶梯为什么先做**：把「颜色」降成受控变量，后续两级才能把注意力放到平面/平涂，不被高饱和抢走判断（这点是 `[归纳]` 的教学排序，非毕加索自述）。

<a id="db-source-line-76"></a>
### 练习 2（第 2 阶）· 平涂面片拼装（ΔE 纪律）—— 把「ΔE≤6 占比≥85% / 平面化」练成可判分动作 `[建议练习]`
- **前置**：练习 1 的受控色盘；K1、K4。
- **材料**：W1《卡恩维勒肖像》（分析期面片）、W2《三个音乐家》（综合期拼图平涂）。
- **操作**：
  1. 取练习 1 的一张草图，把形体切成 **40–120 个多边形面片**，单片面积 ≤画面 6%、长宽比 ≤4:1、主轴角度收敛到 ≤3 个角度族 ±7°（模块卡 §8.2-2 `L60`）；先勾 3–5 个锚点再炸形体（dossier §2-1 `L40`）。
  2. **面片内零渐变、硬边**：每个面片填单一色/明度值，不喷枪、不羽化、不投影（对应 §4 P3 强档）。
  3. **平涂判据自查**：统计相邻像素 **ΔE ≤6 的像素对占比 ≥85%**（模块卡 §8.2-6 `L64`；dossier §12.6「怎么练②」`L374`）。不达标即说明某处混入了渐变/抗锯齿过渡，定位并改为硬边。
  4. 体量只靠**相邻面片明度跳变 ΔL* 8–20** 与角度差表达，禁止用明暗渐变塑形（dossier §2-3 `L42`）。
  5. 中心 1/3 平均 L* 比四边 10% 边缘带高 ≥8（模块卡 §8.2-5 `L63`；dossier §12.6③ `L374`）。
  6. 缩至 64px 验证 ≥1 个人物剪影 + ≥3 个具象锚点（模块卡 §8.2-8 `L66`）。
- **对应轴**：ΔE≤6≥85%、平面化程度、明度中心。
- **C-16 嵌入点（反约束适用域）**：本练习刻意产出「没有高光的平涂」。若套用 Lane B 02 卡「别做成：没有高光的平涂」作全局反约束，会把毕加索/马蒂斯/北斋的核心表面整体判违规（conflicts.md C-16 `L266`）。练习时把该反约束**限定为「金属/液体表面」**（`L269` 改写句式），或在本平涂系卡内删除该句（`L270`）。这是**组合纪律练习**，不是史实判断。

<a id="db-source-line-89"></a>
### 练习 3（第 3 阶）· 主体/背景分区（C-18）—— 把「退化冲突」用分区掩膜落地 `[建议练习]`
- **前置**：练习 2 的平涂面片能力；K4（全帧统计 vs 分区掩膜）。
- **材料**：W1/W2 + 与米开朗基罗「浮雕式强明暗 + 投影」组合的假想任务。
- **操作**：
  1. 显式写一张**主体掩膜**：主体人物（≥70% 面积，按 C-18 §3 比例 `L296`）允许米开朗基罗式明暗建模与 ≤1 个硬边投影；**背景/装饰面**走毕加索平涂（ΔE≤6≥85%、无投影）（conflicts.md C-18 `L294`）。
  2. **分区判分**：平涂判据只在背景分区内满足；主体分区按浮雕强度单独判分——不要把「全帧 ΔE≤6≥85%」强加给允许渐变的主体，否则两边互相判违规（C-18 `L292` 同帧双标准后果）。
  3. 同时跑一遍 **C-06 检查**：若与马蒂斯组合，确认饱和度轴**单主**（conflicts.md `L132`）；本卡「平均饱和度≤35%」是**全帧均值型**规则，按 §3 N4 判别**不可拆侧**（`L134`），不能改写成「背景 S≤35%」去硬凑可拆方案。
  4. 记录每条规则「作用于哪一层」，写 3 行分区笔记（哪层归谁、判分口径、面积比）。
- **对应轴**：平面化（分区边界）+ C-18 退化冲突的分区解 + C-06 轴所有权。
- **诚实边界**：分区解是 `[归纳]` 项目操作规则内的**可行方案描述**，**未经组合实验验证**（AUDIT RESULT §八「C-06/C-18 可拆/分区解未做组合实验」）。练习只练「按规则写出可判分的分区方案」，**不宣称** E2/E4 通过或风格组合有效。

## 6. 常见失败（强反例，按冲突与退化口径）

| # | 失败 | 触发条件 / 反例 | 修正方向 |
|---|---|---|---|
| F1 | 用渐变画立体，平涂判据崩 | 模型默认「用渐变画立体」；若不保留负向段 smooth gradients / airbrushed shading，会退回 3D 渲染质感（dossier §8.1 通用防退化 `L166`） | 保留负向段；面片填单值、硬边；按 ΔE≤6≥85% 定位残留渐变 |
| F2 | 高饱和抢色，均值超标 | 「平均饱和度≤35%」是**全帧均值**；散点高饱和块会悄悄把均值顶上去 | 掺灰/降纯，不换亮色；全帧统计而非逐块目测 |
| F3 | C-06 误当硬冲突硬叠 | 把马蒂斯「每块≥70%」与本卡「全帧≤35%」直接同帧施加 → 空交集（conflicts.md `L130`） | 饱和度轴单主（`L132`）；或马蒂斯规则改写为「主体色块 ≥70% + 背景走另一模块」（`L133`），但**本卡均值型不可拆侧**（`L134`） |
| F4 | C-16 反约束泛化误伤 | 把「没有高光的平涂」当全局反约束 → 把平涂系核心表面整体判违规（conflicts.md `L266`） | 反约束带适用域（金属/液体表面）；平涂系卡内删除或加限定（`L268–270`） |
