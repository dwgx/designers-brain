## §1 创作决策序（D0→D6，每步：先选 / 牺牲 / 为什么 / 何时失效 / 等级）

<a id="db-source-line-30"></a>
### D0 — 先定「这是哪一类光任务？」`[归纳]` 分工分流

- **先选**：读 §3.1 L76 总口径——卡拉瓦乔=光的开关+物理 / 伦勃朗=连续衰减+心理 / 维米尔=荷兰光学 / **委=光的第三档：画室与空气**。若任务要「多光源柔化 + 可见空气 + 银灰调」→ 走本卡；若任务要「单光斑+厚涂亮部」或「点状高光+单室窗光」→ 分别归伦/维，不硬套本卡。
- **牺牲**：本卡固定放弃「单光源戏剧性」「暗部塌陷」「pointillé 圆点」「无痕表面」「连续 sfumato 渐变」五类签名（§3.1 L76–L80）。
- **为什么**：§3.1 是 roster.md §2.6 写死的分工条款，`[归纳]`、明言「可被组合实验推翻」(L74)；AUDIT 自审 B3 判「三轴可分离」(L403) 但组合实验 A-12 未做。
- **何时失效**：一次生成里同时要「伦勃朗式单光斑」和「委式多光源」→ 同轴双主，按 `conflicts.md` N1/N3 处置（L305/L311），不可同帧双标准。
- **等级**：全步 `[归纳]`（分工条款是项目规则，非作者意图）。

<a id="db-source-line-38"></a>
### D1 — 先选光结构：多光源弥散，而非单主光斑 `[归纳]` + `[史料]` 措辞

- **先选**：P6「画室多光源、无单一主光斑、阴影透明、亮部弥散」(§4 L96 强档) + P2「人物之间都是空气」(§4 L92 强档) 为**起步门**（§4 用法注 L98：P6+P2 定「是不是第三档的委」）。
- **牺牲**：强对比暗背景、孤立亮斑、亮部堆料（§3.1a 判「伦勃朗」的参数：`暗部塌陷 ≤8–10%、亮部厚涂`归伦）。
- **为什么** `[归纳]`：判分轴 a (L78) 写死「多光源弥散 + 银灰全域 + 人物间空气 → 判委」；`[史料]` corpus #9 `porque es verdad, no pintura` / `entre las figuras hay ambiente`（L64–L68，Palomino 1795 OCR exact，AUDIT §5-2）提供空气措辞的史料锚，但**不构成作者决策理由**。
- **何时失效**：见 D5（早期 bodegones）。
- **等级**：判据 `[归纳]`；空气引文 `[史料]`（他人转记，0 条 `[自述]`）。

<a id="db-source-line-46"></a>
### D2 — 再选空气做法：笔触空气，而非 sfumato 渐变 `[归纳]` + C-14 边界

- **先选**：空气由**断笔/色斑/灰调拼出**（P2 强档「边缘化开」靠色斑与断笔），不是连续长渐变带；§8.2-1 轮廓断口率 ≥20%、过渡带 ≥4px 非均匀。
- **牺牲**：`--no smooth airbrushed gradients / sfumato fog`（§8.1 负向 L183）。
- **为什么** `[归纳]`：§3.1c (L80) 达·芬奇=渐变（过渡带 ≥1.5% 短边、无可见笔触）、委=笔触空气；两模块组合「空气」轴只能一位持有（N3 L311），推荐达做底、委做空气与表面事件。
- **何时失效 / 已知误伤**：§4 注 L99 + §8.1 L193 自标 **C-14**「别做成：渐变」会误伤 P2 强档的远景化开 → 须按 C-14 改写句式「大气包络允许，但不得出现连续长渐变带」（`conflicts.md` C-14 行 L45 / 详 L229）。AUDIT §6 把它记为定位/一致性漂移，非硬推翻。
- **等级**：全步 `[归纳]`。

<a id="db-source-line-54"></a>
### D3 — 高光形态与表面：碎笔触亮灰 + 亮部薄透，反 pointillé / 反厚涂 `[归纳]` + `[研究]`/`[史料]`

- **先选**：2–12 px 碎笔触（§8.2-4 L200）、亮部薄涂（§8.2-5 L201 高光区纹理 ≤ 中间调 80%）、完成度分级（§8.2-8 L204 面部 ≥3×）。
- **牺牲**：圆点 pointillés（§3.1b 维米尔专属）、「无痕表面」、亮部厚涂（§1-5 L37「亮部薄而透」，与伦勃朗相反）。
- **为什么** `[研究]`：§2-4 L51 稀释颜料画层变薄、`[R1]` Prado；`[史料]` corpus #4「近看不可解，远看是奇迹」(L33–L36，Palomino OCR byte-verified) 与 #9「可以在上面行走」；但这些都是**他人转记**，不是自述。`[归纳]`：§3.1b 判分 = 高光形态 + 空间结构。
- **何时失效**：全画均匀完成 / 1px 硬描边 / 亮部堆料 → 分别撞 §8.2-8、§1-4、§3.1a。
- **等级**：规则 `[归纳]`；材料 `[研究]/[史料]`；0 条 `[自述]`。

<a id="db-source-line-62"></a>
### D4 — 空间与观看：多层开口 + 视线轴，而非单室网格 `[归纳]` + `[研究]`

- **先选**：≥1 个「第二空间」（门/窗/镜/画中画，§8.2-6 L202）；主人物视线指向画外观者位或镜面（§8.2-7 L203）；P3 只在「空间与观看」题材拉满（§4 用法注 L98）。
- **牺牲**：单室单点透视（§3.1b 维米尔侧）、正面凝视的肖像（§1-10 L42 背身/镜像）。
- **为什么** `[归纳]`：§3-2「把观看设计进画面」L66、§3-6 空间开口承担叙事 L70 是项目归纳原则；`[研究]` `[R1][R2]` 提供《宫娥》《纺纱女》分析。
- **何时失效**：平面背景肖像任务 → P3 弱档即可，不必硬塞镜子；与达·芬奇组合按 D2 的 N3 单主。
- **等级**：`[归纳]`；作品分析 `[研究]`。

<a id="db-source-line-70"></a>
### D5 — 套适用域：成熟-/宫廷期 scoped，bodegones 是反例 `[inference]` 判定 + `[归纳]` 收窄（brief 强调点 ③）

- **先选**：先判作品属于 **成熟/宫廷期**（宫娥/纺纱女/英诺森十世/胡安·德·帕雷哈…）还是 **塞维利亚早期 bodegones**（煎蛋的老妇 1618 / 卖水人 c.1620）。再按 §8.1 L191 切参数：塞维利亚期 P6→30% / P1→35%；宫廷盛期默认；晚期 P1→85% / P4→80% / P3→75%。
- **牺牲**：把 §4/§3.1 判分轴当「全生涯分类器」的省事做法。
- **为什么** `[inference]`（AUDIT RESULT §6）：把 `Las Meninas` 式「多光源+空气」判据套到 *Old Woman Frying Eggs*（单一硬侧光、深暗背景）会把真委**误判为卡拉瓦乔/伦勃朗**。§4 P6 弱档 L96 明写「单一侧光、深暗背景（tenebrist 早期）」，§8.1 L190 把 P6 降到 30%，§8.1 负向 L193 自承「其早期 bodegones 确有较暗背景」。dossier 用时期切换 + 自审 B2 `WEAKENED`(L402) 部分缓解，但**未作为单一全局规则解决**——需 A-12 组合实验证伪（B3 L403、§自审 D L449）。
- **何时失效**：对早期 bodegones 输出「非委拉斯开兹」结论时，本判分轴失效；应标 `out of scope for early Seville`，不输出作者归属结论。
- **等级**：反例判定 `[inference]`（AUDIT 原判）；时期切换/参数 `[归纳]`；0 条 `[自述]`。
