## §B 光的三档机制（brief 强调 ①，奠定宫廷肖像）

**系统分工（写死）**，[velazquez.md](../../dossiers/velazquez.md) §3.1 L76（`roster.md` §2.6 + wave15 brief，`[归纳]`、可被组合实验推翻 L74）：

| 持有者 | 光的档 | 签名机制 |
|---|---|---|
| 卡拉瓦乔 | 光的开关 + 物理 | 硬光戏剧、背景压暗 ≤10%、边界硬 |
| 伦勃朗 | 连续衰减 + 心理 | 亮斑从暗部浮现、暗部占比大、亮部厚涂、单光源戏剧性 |
| 维米尔 | 荷兰光学 | 单室单侧窗、暗箱、点状高光 pointillés、无痕表面 |
| **委拉斯开兹** | **光的第三档：画室与空气** | **多光源柔化的画室光 + 可被看见的空气 + 银灰调** |

§3.1 L76 写死本模块固定为「环境光（画室）+ 空气 + 银灰调」，**不得复制另三者签名机制**。一句话能力定位（§0 L16）：宫廷肖像 + 空间与观看 + 大气透视 + 直接画法，给系统补「多主体空间 + 自反观看」档与「空气感肖像」。

**三对判分轴（§3.1 L78–L81）**：

- **(a) vs 伦勃朗（写死）**：伦强档「暗部塌陷 ≤8–10% / 亮部厚涂」为伦专属；本模块强档 = P6≥80% + P2≥80%，暗部占比 ≤35%、亮部薄透。判分：单光斑地图 + 大片近黑背景 + 亮部堆料 → 伦；多光源弥散 + 银灰全域 + 人物间空气 → 委。跨 ref `conflicts.md` N3:L311。
- **(b) vs 维米尔（roster 写死）**：维专属 = 点状高光 1–3px 圆点 + 无痕表面；本模块专属 = P3 空间层数 + P4 笔触经济，不采用 pointillé。判分 = 高光形态（碎笔触亮灰 vs 圆点）+ 空间结构（多层开口 vs 单室单点透视）。
- **(c) vs 达·芬奇（roster 写死）**：达 = 渐变 sfumato（连续灰调、无可见笔触、过渡带 ≥1.5% 短边）；委 = 笔触空气（断笔/色斑拼接、笔触可见）。判分 = 过渡带做法与笔触可见度。两模块组合「空气」轴只能一位（N3 L311）；推荐达做底、委做空气与表面事件；同轴对撞按 `conflicts.md` N1(L305)/N3(L311) 处置。
- **(d) 与卡拉瓦乔（旁注）**：塞维利亚期受其自然主义影响（明暗对照、直接从生活画）但**不复制硬光开关**——bodegones 的光 = 「画室直射侧光 + 透明阴影」，边界随即被银灰化。判分 = 亮暗边界是否化开、背景是否被空气填充（卡：背景压暗 ≤10% 且边界硬）。

**自审状态**（§自审 B3 L403，`[归纳]`）：三轴（光源数 / 高光形态 / 过渡带做法）逐对检验 → **CONFIRMED（轴可分离）**；但 **A-12 组合实验未做**，留待验证（§自审 D L449）。本 shard 不重跑、不升级为实验验证。

**机制 → 宫廷肖像**：§3-5 L69「宫廷肖像＝受控的表演」（不美化、用姿态/光位/站位让被画者有威严，`[史料]` R16）；§1-8 L40「宫廷极简 / 反排场」；§8.1 正向段 L20–L33（可直接粘贴的第三档 prompt）与负向段 L39–L44。

## §E §8.2 八条逐帧自查（`[归纳]`，全部阈值未做像素测量）

1. 空气规则：轮廓断口率 ≥20%、过渡带 ≥4px 非均匀（L197）——Canny + 轮廓闭合分析。
2. 银灰调：饱和中位 ≤0.35、纯白/纯黑各 ≤2%、灰调 ≥45%（L198）——HSV 分位。
3. 多光源：亮斑连通域 ≥4、质心 ≥3 高度带、最大亮斑 ≤3%（L199）——连通域 + 质心聚类。
4. 碎笔触：2–12px@1024、高频 ≤ 中频 60%（L200）——带通能量比。
5. 亮部薄涂（反伦勃朗）：高光区纹理 ≤ 中间调 80%（L201）——分区 Laplacian 方差。
6. 空间开口：≥1 第二空间、明度差 ≥8/255 或色温差 ≥150K、远对比 ≤前 60%（L202）——区域分割。
7. 视线轴：≥1 条看向观者/镜面主视线（≤45°）（L203）——面部朝向 + 视线向量。
8. 完成度分级：面部 ≥ 其余 3×、次要 ≤ 面部 40%（L204）——分区域高频能量比。

> L206：第 1–4 条与 §3.1 分工判据同轴，组合实验时以本节自查表为准；**分母＝假想参考帧**。[velazquez.md](../../modules/velazquez.md) L57 原样同值。

## §F bodegones counterexample（brief 强调 ③，成熟-/court-period scoping carried）

**目标规则**：§4 P6 强档「画室多光源、无单一主光斑」+ §3.1a 判分「单光斑地图 + 大片近黑背景 + 亮部堆料 → 判伦勃朗」。

**反例**（AUDIT RESULT §6，Verdict `[inference]`）：dossier **自身**的塞维利亚期 bodegones——§4 P6 弱档 L96 明写「单一侧光、深暗背景（tenebrist 早期）」；§8.1 L190 塞维利亚期把 P6 降到 30%；§8.1 负向约束 L193 自承「其早期 bodegones 确有较暗背景」。把 *Las Meninas* 式「多光源+空气」判据套到 *Old Woman Frying Eggs*（1618，单一硬侧光、深暗背景）会**把真委误分类为卡拉瓦乔/伦勃朗**。

**判定（照录，不夸大）**：§4/§3.1 判分轴是**成熟-/宫廷期 scoped**，**不是 whole-œuvre 分类器**；这是真实边界反例，dossier 用「时期切换」(§8.1 L191) + 自审 B2 `WEAKENED`(L402) 部分缓解，但**不作为单一全局规则解决**——需 A-12 组合实验（§自审 B3 L403 / D L449 仍 undone）证伪。第二反例：§3.1c 达·芬奇「只有渐变」vs 委「笔触空气」，§4 注 L99 自标 C-14 误伤（大气包络），记为定位/一致性漂移，非硬推翻。

**本 shard 的携带方式（不修规则）**：learning_path 阶梯3 的判分表强制带「时期」列；how-to-think D5 先分流时期；本文件 §A P6 行保留弱档原文；对 bodegones 行显式写 `mature/court-scoped → out of scope for early Seville`，不输出作者归属结论。**不改 §4/§3.1 文本、不改 AUDIT 产物**（repo READ-ONLY，AUDIT 为 ACCEPTED 依赖，复用而非重审）。
