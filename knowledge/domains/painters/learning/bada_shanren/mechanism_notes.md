### 1.2 机制要点：这是**双层谓词**，不是单条几何
§8.2-4 是**局部（单眼包围盒）几何检查**；但「白眼向天 / 冷峻孤愤」是**主体层 gestalt**。AUDIT `counterexample.md CE-2` 给出具体可构造的反例（`[inference]`）：
- 画一个方眼、瞳孔在顶外角的小墨点（几何三条全过），但把鸟头画成**圆胖下视的可爱雏鸟**并配一个居中的圆眼 → 单眼几何合规，整体却读作「cute round bird」，直接撞 §8.1 负向段 `:178-180`。
- **结论**：§8.2-4 是必要-looking 但非充分；练习必须把「瞳孔上角 + 缩颈/独立 + 单主体 + 无运动线」一起观察（§4 P3 强档 `:83`、§1-10 `:37`），不能只跑包围盒测试。这正是 `learning_path.md §4 阶梯二` 把「自查」拆成几何 + gestalt 两段的原因。

<a id="db-source-line-25"></a>
### 1.3 与相邻机制的接口
- **单色墨 / 笔墨经济**：§8.2-2（彩色≤1%）、§8.2-3（连通组件≤30）保证白眼是「最小表达单元」而非被笔群淹没（§3-7b `:62` 第④项）。
- **圆笔**：§8.2-6（端点圆、飞白）决定眼框与鱼鸟轮廓的笔性，与排线（丢勒 C-07）互斥。
- **款印**：「哭之笑之」连写 / 「十有三月」花押作构图配重（§1-9 `:36`、§2-10 `:50`），与白眼同为「符号」，但属书法性符号层。
- **语义边界**：孔雀三尾羽的「单一讽刺所指」在 dossier `§B-5:354` 判 **WEAKENED**（「具体讽喻对象尚存争议」）；本卡不把白眼/三尾羽写成确定的政治心理寓言（`[推测]` 红线）。

<a id="db-source-line-45"></a>
### 2.2 机制要点：「计白当黑」= 把空白当构图主语，不是「少画几笔」
- **顺序**：先定「哪 60–70% 不落墨」，再落单主体（`learning_path.md §4 阶梯一`）。空白是**被设计的正形**，主体是被空场托出的孤物；与「画完主体顺手留个背景」相反。
- **双条件**：§8.2-1 的「像素空白率 ≥55%」只是**统计条件**；「空白区禁纹理/噪点/渐变」是**材质条件**（空纸，不是浅灰底）。AUDIT `counterexample.md CE-1` 构造（`[inference]`）：上部 60% 用 RGB 245–248 近均匀灰 + ±1/255 dither，像素分类仍算「空白」，却读作「略脏的灰场」而非空纸 → **留白率单独不足以保证「冷峻/空寂」**，需与纹理/熵度量配对。§8.2-1 的「禁噪点」子句是对这一张力的补丁，低幅 dither 是边界案例（未推翻规则，但证明它非充分）。
- **悬置**：§8.2-5 把「上重下轻/边角」翻成重心、距边、下方无墨三条可判定阈值；与 §1-6、§2-6「不完整中求完整」呼应。
- **静**：§8.2-7（位移=0、禁运动线/风纹）+ §1-10（主体≤2、冷峻静物感）保证空场不被「动势」填回；§3-7a 动/静分工把本卡锁在「静」侧。

<a id="db-source-line-51"></a>
### 2.3 与 C-17 的边界（跨画家比较入口，留给总路线）
- 本卡 ≥60% 是**主体周围的悬置留白（精神场之空）**；北斋 ≥35% 是**平涂色块包围的版画大气留白**；倪瓒是**一河两岸的空间之空**（§3-7d `:65`）。三者机制不同，不能只按百分比折中。
- 组合时按 **N3 轴单主**（`conflicts.md:311-312`）：负空间轴只能有一个持有者；把 ≥60% 与 ≤15% 折中成中间值 = 双标准失败（N9 类 `:332-333`）。C-17/C-07 内绝对行号已过时（AUDIT `RESULT.md §27-32` 报告、未修），本卡一律用**规则 ID + 子串**定位。
