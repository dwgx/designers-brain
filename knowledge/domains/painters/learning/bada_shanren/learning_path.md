## 4. 具体练习（阶梯；全部为「建议练习」`[归纳]`，未经人评）

> 三条阶梯按作业顺序：先立「空」（M1）→ 再立「符号」（M2）→ 最后「笔墨经济 + 边界自律」（M3+M4）。每条含「可操作动作 / 自查 / 完成定义」，**不声称学习收益**。

<a id="db-source-line-68"></a>
### 阶梯一：计白当黑 / 悬置留白场（empty-field suspension）
- **目标机制**：M1（§8.2-1 / §8.2-5 / §4 P1+P6）。
- **动作**：取 §2 阶梯一作品为参照，画**单只鱼或单只鸟**；先定「哪 60–70% 不落墨」，再落主体（顺序反过来 = 先空后物，对应「计白当黑」）；主体压上部或边角，下方 ≥30% 高度保持空纸。空白区**不许加渐变、噪点、纸纹以外的调子**。
- **自查（可判定）**：像素分类空白率是否 ≥55%（目标 60–70%）；墨迹重心是否高于几何中心 ≥5%；距边是否 ≥8% 短边；下方 30% 带是否有墨；对空白区做亮度方差检查，确认无低幅 dither/纹理（CE-1 失败形态）。
- **完成定义**：空白率达标、重心上移、下方 30% 无墨、空白区无渐变/噪点；画面读起来是「空纸里的孤物」，不是「浅灰底上的小图」。
- **来源**：`dossiers/bada_shanren.md:28,33,70-73,95-98,191,195`；`modules/bada_shanren.md:43,47,55-58`；AUDIT `counterexample.md CE-1`。练习映射 `[归纳]`。
- **何时失效**：长卷/多主体/满构图（CE-3）；或与米氏 ≤15% / 北斋 ≥35% 负空间档同帧（C-17 硬轴）——此时按 N3 定轴单主，不折中。

<a id="db-source-line-76"></a>
### 阶梯二：白眼向天造型（white-eye symbol, subject-level）
- **目标机制**：M2（§8.2-4 / §4 P3 / §3-3）。
- **动作**：画**单主体**孤禽/孤鱼；眼作棱角形（4±1 边），瞳孔墨点置于眼眶包围盒上半部（≤中心−20% 高）、面积≤25%，视线朝上外；同时做「缩颈 / 独立 / 无伴」的**主体层**处理（强档 P3 `:83`）。
- **自查（可判定）**：单眼几何三条是否全过；**再看整体**——是否出现圆眼居中、胖圆头、下视、可爱态（§8.1 负向段 `:178-180` 禁 cute round eyes）；主体数是否 ≤2（常 1）；有无运动线/风纹。
- **完成定义**：局部几何合规 **且** 主体层读为「冷峻孤禽、白眼向天」；不是「合规方框眼 + 可爱圆鸟」（CE-2 语义反转）。
- **来源**：`dossiers/bada_shanren.md:30,56,80-83,178-180,194`；`modules/bada_shanren.md:45,58`；AUDIT `counterexample.md CE-2`。练习映射 `[归纳]`。
- **何时失效**：只查包围盒不查 gestalt；或把「白眼」写成作者心理宣泄句（§0 红线，禁 `[推测]`）。
