## 1. 作者可核实自述支撑的决策（先选什么 / 牺牲什么 / 为什么）

> 本节每一步都有一条 `[自述]` / `[自述·转引]` / `[史料]` 出处。**这些是「他说过什么」，不是「他当时脑中在想什么」**；心理描述一律不补。

<a id="db-source-line-34"></a>
### S1 · 先定概念，再让手执行 —— 证据等级 `[自述]`
- **先选**：先在心里/稿上定「conchetto（概念）」与整体构图，再动手。
- **牺牲**：边画边找形、临时即兴。
- **为什么（自述）**：`_corpus/michelangelo.md:25-31`（Rime 151，[self-written]）：「最优秀的艺术家也没有一个构思不是已包含在一块大理石的『多余』之中；只有服从理智的手才能达到它」；`_corpus/michelangelo.md:173-179`（信 CDXXXV，[self-written]）：「画画是用脑子画的，不是用手画的；脑子不在场的人只会丢丑」。档案同载 `dossiers/michelangelo.md:54`（§3-2 `[自述]`）。
- **旁证（操作层面 `[史料]`）**：`dossiers/michelangelo.md:39-40`（§2-2/3 `[研究]`）记「先整顶起稿、把构图框到墙上，再分段推进；拆架看效果后逐段放大」——这是可观察的工作流程，非心理断言。
- **何时失效**：`[推测]` 当介质不允许预演（如一次性湿壁画 giornata 的局部不可逆）或需按现场反馈放大尺度时，纯「先定概念」会被 `dossiers/michelangelo.md:40`（尺度自校正）修正——此为本 lane 推断，非自述。

<a id="db-source-line-41"></a>
### S2 · 用「减」立形 —— 证据等级 `[自述]`
- **先选**：`per forza di levare`（靠减去多余）显形。
- **牺牲**：靠「加」堆塑、软过渡、装饰金饰。
- **为什么（自述）**：`_corpus/michelangelo.md:17-23`（致 Varchi 信，[self-written]）：「我所谓雕刻，是凭『减』而成的那一种；凭『加』而成的雕塑则近似绘画」；`_corpus/michelangelo.md:33-39`（Rime 152，[self-written]）：「石越减，像越增」。档案 `dossiers/michelangelo.md:55`（§3-3 `[自述]`）、`:43`（§2-6）。
- **金饰取舍（自述·转引）**：`_corpus/michelangelo.md:43-49`（Condivi《Vita》，[reported speech]）：教皇说「总该再点些金吧」，答「我不见人身上带金……那上面画的人本来也是穷人」；原书记壁画最终未补金。档案 `dossiers/michelangelo.md:60`（§3-8 生活极简 `[自述·转引]`）、`:100`（§5-6 凿子之缘 `[自述·转引]`）。
- **何时失效**：`[归纳]` 与平涂/加色系模块组合时，C-18 要求把「减出来的浮雕」限制在主体掩膜内、背景交平涂（`conflicts.md:285-296`）——这是操作失效条件，不是自述。

<a id="db-source-line-48"></a>
### S3 · 以「像不像浮雕」判完成度 —— 证据等级 `[自述]`
- **先选**：用明暗把形体「切/凿」出来，向浮雕靠拢。
- **牺牲**：纯绘画性渐变、sfumato 烟雾过渡。
- **为什么（自述）**：`_corpus/michelangelo.md:9-15`（致 Varchi 信，[self-written]）：「画越向浮雕靠拢越受称许，浮雕越向画靠拢越被看轻；故我过去常觉得雕刻是绘画的灯笼」；档案 `dossiers/michelangelo.md:56`（§3-4 `[自述]`）、`:83-85`（§5-2 原文+意译）。
- **重要限定（防编造）**：同信米氏随即声明「因读了 Varchi 的小册子而改变看法」，认为绘雕「哲学上同一、同出一源」（`_corpus/michelangelo.md:15` 注；`_corpus/michelangelo.md:123-128` 条目 15「让它们和睦相处，别再争」）。**不得**把「浮雕优先」写成他终生不变的唯一信条；这是自述内部的自我修正，如实保留。
- **何时失效**：`[归纳]` 组合达·芬奇模块时，若按 C-02 把过渡带轴归达·芬奇（主模块），则本步的「硬边浮雕」在该轴被移除（`conflicts.md:71-83`、N3 `:311-312`）。

<a id="db-source-line-55"></a>
### 补充自述（不并入决策序，但构成边界）
- `[史料]` 1508 领款收据自称「I, Michelangelo Buonarroti, *sculptor*」（`dossiers/michelangelo.md:106-109` §5-8）；`[自述]` goiter 诗「我不在合适的位置上，我也不是画工」（`dossiers/michelangelo.md:78-81` §5-1；`_corpus/michelangelo.md:108-114` 条目 13）。→ 雕塑家身份优先是自述事实（`dossiers/michelangelo.md:53` §3-1），但**不据此编造「他厌恶绘画」的心理**；档案只记「不情愿也做完」（`dossiers/michelangelo.md:58` §3-6）。
- `[自述·转引]`「要创作自由，不要『小活儿』」：原定十二使徒方案他嫌是 "poor thing"、要求全权重做（`dossiers/michelangelo.md:57` §3-5；`_corpus/michelangelo.md:149-155` 条目 17 本人追述）。这是可核实的自述/转引，不扩写为性格论断。

## 2. 研究者归纳的决策序（非本人主张）

<a id="db-source-line-65"></a>
### S4 · 人体承载叙事 + 满构图 —— 证据等级 `[研究]` + `[归纳]`
- **先选**：肌肉裸体主导、扭转体、多组人群绕中心涡旋。
- **牺牲**：留白、风景背景主导、单人空场、对称正面站姿（§8.1 负向段 `dossiers/michelangelo.md:157-163`）。
- **为什么**：`[研究]` `dossiers/michelangelo.md:23`（§1-1 人体即舞台）、`:25`（§1-3 扭转体）、`:28`（§1-6 密集人群构图）、`:11`（§0 一句话能力定位）；`[归纳]` 量化口径 `dossiers/michelangelo.md:177`（§8.2-4 主体 ≥55%、连续空白 ≤15%）、`:178`（§8.2-5 剪影可读）。
- **何时失效**：`[归纳]` 与北斋（留白 ≥35%）/马蒂斯（背景可见 ≥20%）组合、且未按 C-17 做「空白 = 无内容 / 留白 = 低信息密度」定义对齐时，同帧判分自相矛盾（`conflicts.md:272-283`）。

<a id="db-source-line-71"></a>
### S5 · 把强档当「身份」推满 —— 证据等级 `[归纳]`
- **先选**：肌肉夸张 70% / 扭转角 50% / 浮雕强度 65% / 构图密度 60% / 未完成度 15%（§4 默认，`dossiers/michelangelo.md:66-70`；`modules/michelangelo.md:91-95`）。
- **牺牲**：对方模块的柔和笔触与身份特征。
- **为什么**：`[归纳]` `dossiers/michelangelo.md:72`（§4 使用建议）：「把扭转角与构图密度调高、把浮雕强度调高，就会快速吃掉对方的柔和笔触（与达·芬奇模块天然互斥，注意主辅 70/30 分配）」；卡 `modules/michelangelo.md:97` 同。
- **何时失效**：`[归纳]` 需要保留辅模块身份时按 70/30 定主辅，不 50/50（`dossiers/michelangelo.md:168` §8.1 中文说明）。

<a id="db-source-line-77"></a>
### S6 · 组合冲突：先定轴所有权 / 分区 —— 证据等级 `[归纳]`
- **先选**：出图前先写「轴所有权表」（N3）或「分区表 + 掩膜定义」（N4）。
- **牺牲**：同帧双标准、折中中间值。
- **为什么**：`[归纳]` `conflicts.md:311-312`（N3 每轴单持有者、辅模块冲突轴整条移除）、`:314-315`（N4 可拆判别）、`:332-333`（N9 冲突轴只保留一行）；四条本画家冲突解法 `conflicts.md:55-69`（C-01 反约束改写）、`:71-83`（C-02 轴所有权/分区）、`:272-283`（C-17 定义对齐）、`:285-296`（C-18 分对象拆分）。
- **何时失效**：未写分区表却强行组合 → `conflicts.md:71-83` C-02「agent 会静默二选一或折中成中间值，两边判分都不过」。

## 3. 明确的「不知道 / 不推断」清单

- **不推断心理**：从「硬边阴影 / 满构图 / 未完成面」等**作品外观**倒推「他追求威压感 / 刻意主张 non-finito / 厌恶绘画」等心理，一律不做。档案已明注：未完成面是「历史状态，不等于他刻意主张的 non-finito 美学」（`dossiers/michelangelo.md:32` §1-10）；terribilità 是同代人的概括（`dossiers/michelangelo.md:24` §1-2 `[研究]`），不是本人自述的心理独白。
- **不把归纳当自述**：§4 五参数、§8.2 七规则、conflicts 解法全部是 `[归纳]` 项目操作规则（`conflicts.md:10-26` §0「所有解法为 [归纳]，可被 A-12 实验推翻」），**不得**改写为「米开朗基罗认为…」。
- **不升级史实**：外部 URL 未联网复核、Condivi 训练章节未逐字直读（`dossiers/michelangelo.md:213-221`）；`[研究·百科]` 级材料（`dossiers/michelangelo.md:114-118` §6 他学谁）只作来历注脚，不作决策依据。
- **不冒进能力**：E4 纯风格迁移 / E1_t1c v2「T1 重跑 3/3」未复现（AUDIT `RESULT.md` §0）；§8.1b v2 的「块体名词可迁移」是卡内 `[史料/归纳]` 自述（`modules/michelangelo.md:41-44`），本轮未独立验证。
