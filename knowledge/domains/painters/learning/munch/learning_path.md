## 4. 具体练习（阶梯；全部为「建议练习」`[归纳]`，未经人评）

> 三条阶梯按作业顺序：先让**颜色承担情绪**（M1）→ 再让**曲线承担韵律且画面冻结**（M2+M3）→ 最后做**同一语法的两极 + 分工互锁自律**（M4）。每条含「可操作动作 / 自查 / 完成定义」，**不声称学习收益**（`01-AUDIT.md:273`）。

### 阶梯一：symbolic-colour zones（色彩情绪化 / 分区符号色）
- **目标机制**：M1（§8.2-3 / P3）。
- **动作**：取 `§12-1《尖叫》`/`§12-6《焦虑》`/`§12-4《圣母》` 为参照（`dossiers/munch.md:362-365,387-389,377-380`），对同一「桥上/室内」情境做 3 张 1 小时速写；**只许用三个符号色区**（血红 / 蓝黑 / 病绿黄）表达情绪差异（焦虑 / 压抑 / 虔敬），不许调渐变、不许按固有色上色（§2-5「颜色从情绪状态里取，不从自然里取」`:54`）。
- **自查（可判定）**：HSV 掩膜 + 区域统计——是否 ≥2 个 ≥8% 平色区落在三锚点；色区边界梯度带是否 ≤2% 短边（硬转换、无渐变过渡带）；全帧中位饱和是否 ≤0.5（与梵高全幅振动区分）；对照 3 张的情绪可读性差异。
- **完成定义**：三张靠「色区面积比 + 硬转换」区分情绪，且中位饱和 ≤0.5、无平滑渐变过渡带（不触发 §8.2-3 失败形态）。
- **来源**：`dossiers/munch.md:222`（§8.2-3）、`:96`（P3）、`:36`（§1-4）、`:54`（§2-5）；`modules/munch.md:44,59`；AUDIT-munch [claim_evidence_map.md](claim_evidence_map.md)（§4 参数行）。练习映射 `[归纳]`。

### 阶梯二：wave-line rhythm without motion（曲线韵律 / 冻结的声波）
- **目标机制**：M2 + M3（§8.2-1 / §8.2-5 / P2 / P1 / P4）。
- **动作**：取 `§12-1《尖叫》`/`§12-6《焦虑》`/`§12-10《太阳》` 为参照（`:362-365,387-389,407-410`），画「一个巨大的声音/光」场景；天空用 **≥3 条共享走向的嵌套波带**（曲率符号一致、方向族夹角 ≤20°、线宽变异 ≤2:1），主体**去面孔化**（可辨五官 ≤1），并加**一条前景斜线**（≥60% 画宽、10–30°）；**除波线形状外画面不许有任何运动**（无运动模糊、姿态静止）。
- **自查（可判定）**：边缘方向场直方图主导族占比 ≥40% + 曲线拟合波带计数 ≥3；人脸关键点检测命中 ≤1 组；光流/模糊核检测确认事件外 Δ≤1%/帧、无运动模糊；黑白稿下波线是否仍「响」。
- **组合自律（本阶梯硬要求）**：波形是**形状**不是**运动**——若出现方向性厚涂覆盖 ≥60% / 互补对近 1:1 / 全画面运动场，按 `§3.1` 越界警报①停手换模块（那是梵高能量档，不是蒙克状态档）。注意 AUDIT-munch `counterexample.md` 反例 C：越界警报①三条件宜读作「合取/主导轴」而非「任一项即越界」——仅「互补对近 1:1」但场景冻结、按色彩角色判据仍属蒙克，本阶梯自查按「主导轴」口径，不机械逐条判越界。
- **完成定义**：波带 ≥3 且共享走向、画面冻结、焦点五官 ≤1、无厚涂能量场；「无线电波」只作为**他写下的操作陈述/比喻**（[自述]，`dossiers/munch.md:139`），不写成物理声学事实。
- **来源**：`dossiers/munch.md:220,224,33,55,139`；`modules/munch.md:42,46,58`；`raw/f4_N43_no.xhtml`（`Bølgelinien`/`Radiobølgene`）；AUDIT-munch `counterexample.md`（反例 C）；`RESULT.md:77-85`（4 判据）。练习映射 `[归纳]`。
