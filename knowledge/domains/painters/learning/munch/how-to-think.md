# LEARN-munch — How to Think（创作决策序）

> 任务 `LEARN-munch` · 依赖 `AUDIT-munch`（ACCEPTED）。仓库 内部证据 db3a99569f8d41cd（未公开；来源记录由维护者保留） @ `f008952365a77e140cbda3f3959d43ef000f9a22`（只读）。
> **本文回答**：「用蒙克这套做一次创作决策时，先选什么、牺牲什么、为什么、何时失效」。它是**决策序**，不是生平、不是技法清单、不是心理画像。

## 1. 决策序总览（先选什么 → 牺牲什么 → 为什么 → 何时失效）

| S1 | **先定「画状态，不画场景」**：自然只是手段，心情才是目的 | 牺牲「画面像不像自然」、牺牲叙事性细节与写实可读性 | `[自述]`「重要的是这个心情；自然只是手段……画面像不像自然，无关紧要」(MM N 29，`dossiers/munch.md:115,67`) | 任务要求地形/肖像/图解的可辨识精度时失效（该选法本就放弃像似） | `[自述]` 为主；失效条件 `[归纳]` |
| S2 | **先选「记忆 / 第一印象」，不选现场**：画所见过的，不画所见的 | 牺牲现场准确性、牺牲「一次画完不重来」 | `[自述]`「我不画我所见的，我画我所见过的」(MM UT 13，`:111,68`)；「刮掉它……一次次重新够向第一个印象」(`:50`) | 需要现场记录/证物式再现时失效；本选法是「记忆重画」不是速写 | `[自述]` 为主 |
| S3 | **把颜色当情绪符号，不当固有色**：三锚点分区平色、硬转换 | 牺牲固有色、牺牲柔和渐变、牺牲「好看」的高饱和全幅 | `[自述]`「颜色从情绪状态里取，不从自然里取」(`:54,55`「颜色会活起来」)；`[归纳]` §8.2-3 三锚点 HSV 阈与中位饱和 ≤0.5（`:222`）——**阈值是项目判据，不是蒙克说的** | 做成梵高式全画面互补对振动 / 平滑渐变时失效（越能量档界） | `[自述]`+`[归纳]` 分列 |
| S4 | **把线当「形状化的声音」，且画面冻结**：≥3 条共享走向波带、无运动 | 牺牲运动模糊、牺牲方向性厚涂的能量、牺牲把波线做装饰花纹 | `[自述]`「波浪线……无线电波……长发＝电话线」(MM N 43，`:139`，挪威语 `Bølgelinien`/`Radiobølgene`，`raw/f4_N43_no.xhtml`)；`[归纳]` §8.2-1 波带计数/方向场、§8.2-5 冻结（`:220,224`） | 厚涂 ≥60% / 全画面运动场 → 换梵高模块；纵向拉伸 + 宗教题材 → 换格列柯 | `[自述]`+`[归纳]` 分列 |
| S5 | **把人做成原型，不做肖像**：去面孔化 / 面具化，焦点五官 ≤1 | 牺牲五官可辨、牺牲个体性与「具体的人」 | `[自述]`「我看见所有人在面具背后」(MM T 2547，corpus #14，`raw/f5_T2547_no.xhtml` 的 `MASKE`/`MENNESKER`)；`[归纳]` §8.2-2 五官 ≤1、P4 默认 60%（`:221,97`） | 任务需要具体人物/劳动者/肖像 likeness 时失效 | `[自述]`+`[归纳]` 分列 |
| S6 | **空间选「舞台化压缩」**：高视点 + 斜线 + 虚空，不做深透视 | 牺牲线性透视深度、牺牲「房间/背景可读信息」 | `[归纳]` §8.2-4 斜线 ≥60% 画宽 10–30°、地平线 ≥60% 画高（`:223`）；`[研究]` Wikipedia「play roles on a theatre stage」（`:37`） | 需要深透视/可导航空间时失效；与格列柯「上升拉伸」同轴混淆时按主判据换模块 | `[归纳]`+`[研究]` |

## 2. 逐展开（每步：先选 / 牺牲 / 为什么[分栏] / 何时失效 / 等级）

<a id="db-source-line-44"></a>
### S1 · 先定「画状态，不画场景」
- **先选**：把对象当「心情的图像」来组织，不当地形记录；画面 ≥1 处物理不可能且与情绪同向。`[归纳]` 从 §1-2（`:34`）操作化。
- **牺牲**：像似性、叙事细节、写实可读性。
- **为什么（分栏，不混写）**：
  - `[自述]`：「在强烈情绪中，风景会给人某种印象——画下这片风景，人得到的是一幅『自己心情的图像』。重要的是这个心情；自然只是手段。画面像不像自然，无关紧要。」——MM N 29，`dossiers/munch.md:115`（§5-2）/`:67`（§3-1）。
  - `[归纳]`：§1-2「心理景观（场景＝状态）」把它翻成「≥1 处物理不可能」的可观察量（`:34`）；**翻译动作归研究者**。
- **何时失效**：任务要求可辨识物体/肖像/图解；或把此选法写成「蒙克主张忽略对象」的心理学断言（本卡禁止）。
- **等级**：`[自述]`（决策来源）+ `[归纳]`（操作化与失效条件）。

<a id="db-source-line-53"></a>
### S2 · 先选「记忆 / 第一印象」
- **先选**：从记忆里找「第一个图像、第一个印象」，一次次重够；把画过的刮掉重来（记忆重画法）。
- **牺牲**：现场准确性、一次性完成。
- **为什么（分栏）**：
  - `[自述]`：「我不画我所见的，我画我所见过的……相机无法与画笔竞争——只要它还不能在天堂或地狱里使用」——MM UT 13，`dossiers/munch.md:111`；「《病中的孩子》约 20 次重画之后仍不完整」「刮掉它……一次次重新够向第一个印象」——`:50`（MM UT 13 / MM N 122）。
  - `[归纳]`：§12-9 把此法设计成「同一段记忆画 3 遍、每遍覆盖/刮掉 30%」的练习（`:402-405`，**建议练习**，非作者规定）；§2-1 的操作化归项目。
- **何时失效**：证物式/现场记录任务；本选法不是速写方法。
- **等级**：`[自述]`（意图）+ `[归纳]`（练习设计与失效）。

<a id="db-source-line-62"></a>
### S3 · 颜色当情绪符号（**双等级步，务必分栏**）
- **先选**：血红 / 蓝黑 / 病绿黄三锚点大块平色区、硬转换；颜色从情绪状态取，不从自然取。
- **牺牲**：固有色、平滑渐变、高饱和全幅「好看」。
- **为什么（分栏）**：
  - `[自述]`：「颜色从情绪状态里取，不从自然里取」（`:54`，MM N 30 / UT 13「颜色会活起来」）；`[研究]` SNL「血红线条被比作声波」（`:182`）——研究旁证，非自述。
  - `[归纳]`：§8.2-3 把三锚点写成 HSV 掩膜判据（血红 H 0–15°/S≥0.65、蓝黑 H 210–250°/V≤0.35、病绿黄 H 60–95°/S 0.25–0.6、≥2 区各 ≥8%、中位饱和 ≤0.5、边界带 ≤2% 短边）（`:222`）；P3 默认 55%（`:96`）。**「≥2 个 ≥8%」「中位饱和 ≤0.5」全是项目阈值，蒙克没说过数字**（`modules/munch.md:51` 标 `[归纳]`、未像素实测）。
- **何时失效**：做成全画面互补对振动 / 平滑渐变 → 越「状态档→能量档」界（§3.1 判据③）；或把中位饱和推过 0.5。
- **等级**：`[自述]` / `[研究]` / `[归纳]` 三行分列，**不把 §8.2-3 数值写进自述行**。

<a id="db-source-line-71"></a>
### S4 · 线当「形状化的声音」且画面冻结（**双等级步**）
- **先选**：天空 ≥3 条共享走向的嵌套波带；除波线形状外画面不许有任何运动。
- **牺牲**：运动模糊、方向性厚涂的能量、把波线做装饰花纹。
- **为什么（分栏）**：
  - `[自述]`：「波浪线其实也连着对大气中新能量的发现与预感——无线电波、从一个人到另一个人的传递……长发就是一条电话线」——MM N 43，`dossiers/munch.md:139`（§5-8）；挪威语原文 `Bølgelinien` / `Radiobølgene` / `kræfter` 逐字落在 内部证据 7ffd0a900b77f51e（未公开；来源记录由维护者保留）（sha256 `e0546bf3…ea36`，AUDIT-munch 上游联网抓取，本 lane 只做本机字节复核）。**这是他写下的比喻/操作陈述，不是物理声学结论，也不是「他内心焦虑」的证据**。
  - `[归纳]`：§8.2-1 把它翻成「≥3 条嵌套曲线带 / 曲率符号一致 / 方向族夹角 ≤20° / 线宽变异 ≤2:1 / 主导族占比 ≥40%」（`:220`）；§8.2-5 冻结（事件外光流 Δ≤1%/帧、波线区局部振荡振幅 ≤2% 短边）（`:224`）；P2 默认 60%（`:95`）。**波带计数与阈值全是项目判据**。
- **何时失效**：厚涂覆盖 ≥60% / 互补对近 1:1 / 全画面运动场 → 越界进**梵高**档（§3.1 越界警报①，`dossiers/munch.md:102`）；纵向拉伸 + 宗教狂喜 → 越界进**格列柯**档。注意 AUDIT-munch `counterexample.md` 反例 C：仅「互补对近 1:1」但场景冻结、按色彩角色判据仍属蒙克，越界警报①三条件宜读作「合取/主导轴」而非「任一项即越界」——本步按主导轴口径，不机械逐条判越界。
- **等级**：`[自述]`（比喻底本）+ `[归纳]`（判据 + 失效/组合口径），**不把「Radiobølgene」写成声学事实**。

<a id="db-source-line-80"></a>
### S5 · 把人做成原型（去面孔化）
- **先选**：焦点人物抹平/背转/面具化，可辨五官 ≤1；群像脸多为椭圆块。
- **牺牲**：五官可辨、个体性、「具体的人」。
- **为什么（分栏）**：
  - `[自述]`：「JEG SER ALLE MENNESKER BAK DERES MASKE…」（我看见所有人在面具背后）——MM T 2547，corpus #14（`:116-121`）；挪威语字节 `MASKE` / `MENNESKER` 在 `raw/f5_T2547_no.xhtml`（sha256 `f08a251a…e16b`）。同底本 #13「从我腐烂的躯体里，将有花升起……这就是永恒」(`raadnende`/`blomster`/`Evigheden`) 属同一文学草稿，**是文字意象不是画面配方**。
  - `[归纳]`：§8.2-2 五官 ≤1、全画面人脸关键点 ≤1 组（`:221`）；P4 默认 60%（`:97`）；`[研究]` R2/R3「featureless or hidden faces」（`:35`）。
- **何时失效**：需要具体人物/劳动者/肖像 likeness（梵高档的判据④）；或把「面具」自述升级为「他觉得人人虚伪」的心理断言（禁止）。
- **等级**：`[自述]`+`[归纳]`+`[研究]` 分列。

<a id="db-source-line-89"></a>
### S6 · 空间选「舞台化压缩」
- **先选**：高视点 + 一条斜线切前景 + 背后虚空；人物像舞台上的演员。
- **牺牲**：线性透视深度、背景可读信息（≤2 层）。
- **为什么**：**`[归纳]`** §8.2-4 斜线 ≥60% 画宽、倾角 10–30°、地平线 ≥60% 画高（`:223`）；§1-5「舞台化压缩空间」（`:37`）标 `[研究]`，Wikipedia「play roles on a theatre stage」为二手旁证；P5 默认 55%（`:98`）。**此步没有作者自述给出这些角度/比例**——数值是逐帧可查的项目判据。
- **何时失效**：需要深透视/可导航空间；或与格列柯「纵向拉伸 + 上升」同轴混淆时，按 el_greco 对称条款**主判据① 扭曲方向**换模块（见 §3、「组合决策序」）。
- **等级**：`[归纳]`（单一步为主）+ `[研究]`（旁证），**不夹 `[自述]`**。

<a id="db-source-line-96"></a>
### S7 · 收笔 = 减法与未完成的自律
- **先选**：删细节、留「洞」/刮痕/未完成感；把单幅按饰带编组排进序列。
- **牺牲**：按清单画满即停、把单幅孤立挂出。
- **为什么（分栏）**：
  - `[自述]`：「一幅带 10 个洞的好画，胜过十幅没有洞的坏画」（MM N 38，`:135`）；「我把椅子与杯子画过了头……把周围刮掉一半、让它们只留下块面」（UT 13，`:52`）；「把画排在一起才『共鸣』」（MM N 62，corpus #16）；「《饰带》是一首关于生命、关于爱、关于死的诗」（MM UT 23，corpus #18）。
  - `[归纳]`：P6 组画/变体性是**工作流参数**，不进画面重叠计算、不可被图像自查表判定（`dossiers/munch.md:99,101`；`modules/munch.md:62,64`；AUDIT-munch `counterexample.md` 反例 D 复核「参数 vs 指纹是不同层，非矛盾」）。
- **何时失效**：进入动画/C-09 运动预算域时，「停止」变帧级判据（§8.2-5）；P6 不可被逐帧规则验收，只能按工作流记录。
- **等级**：`[自述]`（价值陈述）+ `[归纳]`（工作流参数、失效）。
