## 3. 要观察的机制

<a id="db-source-line-29"></a>
### 3.1 视觉指纹（§1，10 条）

- **光环/拱形背景**
- **长窄画幅 + 近真人尺寸 + 静止端庄**
- **理想化女性主角**
- **连续曲线系统（whiplash / arabesque）**
- **自然纹样编织**
- **平涂 + 淡彩（pastel）**
- **字画一体**
- **边框与装饰框系统**
- **构图几何：圆/拱/菱形底座（Q formula）**
- **平面装饰空间**

<a id="db-source-line-42"></a>
### 3.2 §8.2 逐条可判定规则（8 条，逐帧可查）

- `§8.2-1`（dossier `L229`）**曲线族一致性**：1. **曲线族一致性**：全帧主要轮廓的曲率连续（无折角）；发丝/衣褶/花茎的线宽族 ≤3 档；直线段仅允许出现在版面分隔/标题基线上，占比 ≤5%。（依据 §1-4）
- `§8.2-2`（dossier `L230`）**光环规则**：2. **光环规则**：主角头部后方存在拱形/环形装饰；环中心与头部包围盒中心距离 ≤ 头宽 50%；环线与面部区域不重叠（聚焦而非遮挡）。
- `§8.2-3`（dossier `L231`）**近真人静止度**：3. **近真人静止度**：主体人物高度 ≥ 画面高 60%（强档 ≥70%）；帧间姿态位移（若有动画）≤ 2% 画面高——「静止」是身份特征。
- `§8.2-4`（dossier `L232`）**色彩预算**：4. **色彩预算**：饱和色（S ≥ 0.6）面积 ≤ 15%；主色相 ≤ 5 个；无连续渐变（渐变面积 ≤ 5%，纸张/印刷噪点除外）。（依据 8 色印刷口径）
- `§8.2-5`（dossier `L233`）**纹样生长规则**：5. **纹样生长规则**：花叶母题 ≥3 处，且每处纹样的主轴方向与其「附着对象」（发/衣/框）的切线夹角 ≤ 30°——纹样沿曲线生长、非贴片。
- `§8.2-6`（dossier `L234`）**字画一体（海报档）**：6. **字画一体（海报档）**：排版文字 ≥1 区；字体为手绘装饰体（笔画曲率与画面曲线同族）；文字区与图像共用边框或纹样边界；无文字档（装饰板）则本规则跳过、检查 P6 边框完整度。
- `§8.2-7`（dossier `L235`）**边框完整度**：7. **边框完整度**：装饰板/海报档存在闭合边框（或上下装饰带 ≥2 段）；边框纹样与画内纹样同族（同一母题库）。
- `§8.2-8`（dossier `L236`）**越界警报（组合用）**：8. **越界警报（组合用）**：帧内出现金属镜面/箔块 → 越界克里姆特域；出现网格单元填充 → 越界若冲域；出现「无文字、无曲线骨架」的纯平涂图案 → 越界马蒂斯域。自查：材质高光检测 + 网格周期检测 + 文字检测…

> 全部 `[归纳]`，阈值未像素实测；组合实验时以本节自查表为准（本片未重跑任何组合实验）。

## 4. 具体练习（3 阶梯，全部建议练习 `[归纳]`）

1. **阶梯一 · 指纹认领**：取一张自绘草图，逐条勾选 §1 指纹表，记录「命中 / 未命中」——记录的是自查结果，不是原作测量。
2. **阶梯一 · 单规则自查**：用 `§8.2-1`（dossier `L229`）四项自查表对一张结构图打勾；全部为建议练习。
3. **阶梯二 · 参数滑轨**：按 §4 六参数从弱→中→强各出一版，比较档位差异（不声称原作如此）。
4. **阶梯二 · 规则联查**：把 §8.2 8 条做成一张表逐帧自查，标出冲突行，交 `mechanism_notes.md §4`。
5. **阶梯三 · 分工对照**：按 §3.1 判据与邻近模块并置两版，只做纸面分辨、不渲染像素。

## 6. 常见失败（F1–F5）

- **F1 把题材当风格**：只画对器物/题材就判「成立」——§8.2 统计量本不依赖任何器物专名（参 [mechanism_notes.md](mechanism_notes.md) 反例 CE-3 类）。
- **F2 把 `[归纳]` 阈值当已实测**：练习自查 ≠ 原作像素测量（分母＝假想参考帧）。
- **F3 混写等级**：`[自述]` 与 `[归纳]`/`[reported speech]` 不得并成一句、不得反推心理。
- **F4 把反例当史实证伪**：8 条反例均 `[inference]` 纸面推演，非已验证实验。
- **F5 把 open 写成已收口**：conflicts 命中、外部取证 partial、权利漂移一律携带。
