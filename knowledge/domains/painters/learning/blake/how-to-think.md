## 1. 逐步展开（每步带 evidence grade + 定位 + 失效条件）

<a id="db-source-line-28"></a>
### D1 — 先判「图文同版一次印」，再谈画面 `[归纳]`
- **决策**：把文字与图像视为**同一块浮雕蚀刻板、同一次压印**的两个部分（§2-1 L48 防酸墨镜像书写、§2-2 L49 单一凸起印刷面、§2-8 L55 镜像反写）。任何「先画图 → 后加字」的流水线都判为离题。
- **grade**：依据 `[史料]`（BM BIOG1987 / Met `[R3]` / Tate `[R6]`）+ 决策规则 `[归纳]`。
- **失效条件**：若 brief 明确是「为已有文本作插图」（文字由外部给定且不可改版），则本步不适用，转普通插图工作流；不得硬套「同版同印」。
- **输入自述对照**：布莱克自述「新约旧约是艺术的大法典」「文字与图像同为艺术」（§3-6、§5-10 E274）是**他的原则陈述**，不等于「他描述了本决策序」；决策序由本项目构造。

<a id="db-source-line-34"></a>
### D2 — 定「灰阶不来自线密度」，把线只留给轮廓 `[归纳]`
- **决策**：交叉排线 0 命中（§8.2-2 L213）；主要形体 ≥80% 边界连续硬线、线宽变异 2–3:1（§8.2-1 L212 / §4 P1 L92）。灰阶/体积交给平涂水彩色区、彩色墨、白线蚀刻、留白（§1-2 L34、§2-4 L51、§2-5 L52）。
- **grade**：线的价值来自 `[自述]` E550「边界线越分明、锐利、如铁丝一般，作品越完美」（§5-8 L122 / `_corpus` Q8）；「0 命中 / ≥80% / 2–3:1」是 `[归纳]` 阈值（未像素实测，L221）。
- **失效条件**：组合中若按 `conflicts.md` C-07（L136–147）显式由**丢勒**持有「表面着色系统轴」，则排线明暗可进入，但此时布莱克只贡献构图/轮廓与文字板，且须写 70/30 分区（§3.1 L85）。禁止「排线 + 平涂」拼接（C-07 组合解法 2）。

<a id="db-source-line-39"></a>
### D3 — **先声明 P4 档位并显式写值**（本档案最关键步）`[归纳]`
- **决策**：在动笔前写一行「本页 = 书页叙事档 / 大彩色版画档；P4 = ?%」。
  - 书页档：P4 中/强档 5–40%（§4 P4 L95 中 5–15% / 强 25–40%），按 §8.2-3（L214 5–35%）自查。
  - 大彩色版画档：§8.1 建议「降 P4 到 **0–5%（纯图像）**、升 P5/P6」（L206）；§4 P4 弱档直接写 **0%（纯图像；大彩色版画档）**（L95）。
- **grade**：全为 `[归纳]`（§4/§8.1/§8.2 操作规则），未对原作像素测量（L221 / §10-6 L260）。
- **失效条件 / 已知张力**：L95 的 `0%` 与 L214 的 `≥5%`（灰区下限）在「大彩色版画档」这一合法取值上**互斥**——`AUDIT-blake/counterexample.md` 反例 1 `[inference]`。本步的「失效」不是史实被推翻，而是**规则系统出现双判**：自查脚本同时加载两条会给同一帧 pass/fail。消歧按 `conflicts.md` §3 N3 轴所有权表显式分区；本 shard 只登记、不改写档案、不自造新阈值。
- **不做**：不把 `0%` 悄悄改成 `5%` 来「修好」矛盾（那会抹掉反例），也不把 `5–35%` 改成 `0–35%`（§8.2 是 ACCEPTED 依赖，复用不重审）。

<a id="db-source-line-47"></a>
### D4 — 把「文字当图形安排」，不是排版 `[归纳]`
- **决策**：文字区沿边、成条、竖排或环绕图像（§1-3 L35），与图咬合；手写体蚀刻、同墨同质感层（§8.2-3 L214），不得排印字体/独立层（§8.1 负向段 L202）。§12-1「把文字当图形安排——标题不是贴上去的，而是构图的一部分」（L347–350）。
- **grade**：原理 `[研究]`（Tate `[R6]`「诗的文字与伴随的插图构成一个整体」）+ 阈值 `[归纳]`（5–35%）。
- **失效条件**：D3 选大彩色版画 B 版（P4=0% 纯图像）时，本步**整体跳过**并在对照表登记「按 §4 弱档、不按 §8.2-3 自查」；不得跳过登记直接勾通过。

<a id="db-source-line-52"></a>
### D5 — 定「画内单中心光源」并显式写面积 `[归纳]`
- **决策**：≥1 处单中心辐射（射线 ≥6 条或光球/环形），面积 ≥8%（§8.2-5 L216）；§4 P6 强档另写 ≥20%（L97），默认建议 60%（L97）。光源在云中/球中/火焰中（§1-4 L36）。
- **grade**：装置 `[史料]`（BM `[R9]`《亘古常在者》罗盘光球）+ 阈值 `[归纳]`。
- **失效条件**：单色线描档（P6 弱档「无光晕/无云」）跳过；取 8–20% 区间值（如 12%）时满足 §8.2-5 但**不满足** P6 强档——`counterexample.md` 反例 2：交集非空、必须显式取值，`conflicts.md` §4 near-miss 表（L347–355）blake **无行** → 应补未补。本步要求把实测/取值写进对照表，不默认。

<a id="db-source-line-57"></a>
### D6 — 判「符号来自命名神谱」还是「情绪结晶」 `[归纳]`
- **决策**：画面须有 ≥1 可点名神谱人物/象征物（Urizen/Los/Orc/Albion…；罗盘/书/锤钳/蛇/火焰球/天平，§8.2-7 L218、§1-8 L40），且具谱系/叙事关系（§3.1 L77–80 vs 蒙克条款）。
- **grade**：清单 `[研究]`（Tate `[R5]`）+ 判据 `[归纳]`。
- **失效条件**：若组合按 §3.1 让**蒙克**主导「符号系统轴」（情绪原型），则不得给蒙克式场景加命名神谱文字板（L80）；两者同用 70/30 选主导、符号系统轴不可混用。

<a id="db-source-line-62"></a>
### D7 — 判「幻视身体」而非「写生人体」 `[归纳]`
- **决策**：肌肉分明裸/半裸人体，姿态违反重力（腾空/俯冲/螺旋扭转/双臂张开，躯干轴偏离竖直 ≥15°，§8.2-6 L217 / §1-5 L37）；不得写实日常步态。
- **grade**：姿态描述 `[研究]`（Tate `[R5][R7]`）+ 阈值 `[归纳]`。
- **失效条件**：肖像/静观档（§4 P5 弱档「静立/端坐」，L96）跳过；§12-5《乌里森之书》「反动态」档用同一线质画「冻结」而非「火焰」——这说明 D7 是档位函数，不是恒定要求。

<a id="db-source-line-67"></a>
### D8 — 用「页面建筑」收尾，把整页当一个对象 `[归纳]`
- **决策**：≥1 条粗边框线或拱门/光球/洞穴（§8.2-8 L219）；构图中心轴对称 ≥60% 或明确涡旋（旋转对称分量 ≥1）、粗框小尺幅高密度（§1-6 L38 / §1-10 L42）。
- **grade**：装置 `[史料]`/`[研究]`（BM `[R8][R9]` / Tate `[R6][R7]`）+ 阈值 `[归纳]`。
- **失效条件**：涡旋档（§12-10《淫欲之环》）以旋转对称替代镜像对称，不强行 ≥60% 轴对称；「页」是作品单位，不是画框（卷首语 L6）。

## 3. 何时整套决策序失效（总边界）

1. **阈值全部未验证**：§8.2 注 L221「未对原作做像素测量（分母＝假想参考帧）」、§10-6 L260；AUDIT 把 14 条阈值标 `unverified`。D2/D3/D5/D8 的数值门槛是规则层，不是实测结论。
2. **D3 的规则层互斥**：L95 `0%` × L214 `≥5%` 在「大彩色版画档」双判（`counterexample.md` 反例 1）。整套序在**该档**不能同时满足两条；必须显式选一档、写一条自查依据。这是已知失效点，不是本 shard 修补范围。
3. **D5 的 near-miss 缺口**：§4 P6 `≥20%` × §8.2-5 `≥8%` 交集非空须显式取值，blake 在 `conflicts.md` §4 near-miss 表无行（反例 2）。
4. **组合实验接管时**：按 `conflicts.md` §3 N3「轴所有权表」（L311）同一轴只能一位持有者；C-07/C-12/C-14/C-16 与 §3.1 分工判据优先于单卡默认。
5. **外部来源限制**：28 条语料未对 R12 在线底本二次逐字复核；BM 403 / Met 429；18 张图 `image_seen=0`（AUDIT RESULT §6）。本 shard 不重跑外网、不目检、不像素测量。
6. **无真人评价**：全部练习为建议练习，`human_review.status=not_applicable`；决策序的「有效性」未经人评，不写学习收益。
