### 阶梯 1 — 线雕与套色机制（练 M1/M2/M3：浮雕蚀刻图文同版 + 铁丝轮廓 + 手工水彩套色）`建议练习`

- **观察对象**：§12-1 扉页、§12-2《老虎》、§12-3《婚姻》Plate 5；模式 = `[史料]` 著录 + `[自述]` E550（边界线金科玉律，§5-8）。
- **创作决策**：先决定「这页是不是一块板」（同版同印），再决定「灰阶由谁承担」——线密度一律拒用，交给平涂色区/留白（`[归纳]` 决策，见 how-to-think D1/D2）。
- **机制 → 参数**：M2 用 §4 P1=80%（[blake.md](../../dossiers/blake.md) L92 默认）；M1 用 §8.2-3 文字区（本阶梯取中档 5–15%，**不取 0%**）；M3 用 §8.2-4 平涂 ≤12% / 主色 ≤10 / 金 ≤5%。
- **一次可做的练习**：仿 §12-2「怎么练」——选 8 行短诗，做一页 ≤A6 的「图像 + 手写诗」草图；要求 ① 诗行与图像**共用至少一个轮廓**（同一根线既写字母也画边）；② 交叉排线 0 命中；③ 上色只用平涂透明色区、留白当一档色；④ 文字必须手写蚀刻感，不得排印字体/贴层。
- **反例**：若用排线造灰 → 越界丢勒（§4 越界警报 L100 ①）；若文字是矢量字体单独一层 → 违反 §8.2-3（「同版同印」是生产层，不是版式层）。
- **自检**（§8.1 生成后自查 L207）：放大数交叉排线命中数=0；文字区与图像是否同墨同层；单区明度标准差 ≤12/255。

### 阶梯 2 — 图文同版与文字板比例（练 M4/M5：L95 的 0% 大彩色版画档 vs L214 的 5–35% 灰区）`建议练习`

- **观察对象**：§12-6《牛顿》/ §12-7《尼布甲尼撒》（Tate 大彩色版画）对照 §12-1/2/3（书页档）。
- **创作决策**：**先声明输出属于哪一档**（书页叙事档 / 大彩色版画档），再选 P4 值——这是本阶梯唯一必须显式写的决策（见 how-to-think D3）。
- **机制 → 参数**：书页档取 P4 中/强档 5–40%（L95）；大彩色版画档取 §8.1 建议 `P4 → 0–5%（纯图像）、升 P5/P6`（L206）。
- **一次可做的练习**：对**同一构图**做 A/B 两版——
  - A 版（书页档）：手写文字区 = 12% 页面，与图咬合，按 §8.2-3 自查 pass；
  - B 版（大彩色版画档）：按 L95 弱档 `P4=0%`（纯图像）、按 L206 升 P5/P6（动态/辐射），**记录**它必然不满足 §8.2-3 的 ≥5% 下限。
  - 把两版的「取值 / 适用规则 / 自查结论」写成一行对照表，训练「显式取值」而不是「默认全过」。
- **反例（本档案重点）**：`AUDIT-blake/counterexample.md` 反例 1 `[inference]`——L95 弱档 `0%（大彩色版画档）` × L214 `≥5% 手写文字区` 在同一次自查中给同一帧 pass/fail 双判。两条都是 `[归纳]` 操作规则，**不是史实断言**；消歧按 `conflicts.md` §3 N3「轴所有权」显式分区（本 shard 不自造新解，只登记为需显式取值）。
- **自检**：每版写明「本页 P4=?%、按 §4 还是 §8.2-3 自查、结论 pass/fail」；严禁一页同时写 0% 又勾「文字区 ≥5% 通过」。

### 阶梯 3 — 辐射装置与组合预检（练 M6/M7 + C-rows + 失败条件）`建议练习`

- **观察对象**：§12-4《亘古常在者》（YCBA/BM）、§12-5《乌里森之书》（反动态）、§12-8《耶路撒冷》卷首（拱门）、§12-10《淫欲之环》（涡旋）。

- **机制 → 参数**：M6 取 §8.2-5 `≥8%`（L216）并注意 §4 P6 强档 `≥20%`（L97）——**显式取值**（`counterexample.md` 反例 2：8–20% 区间如 12% 满足 §8.2-5 但不满足 P6 强档，交集非空、须写值，blake 在 conflicts §4 near-miss 表无行 → 应补未补）；M7 取 §8.2-6/7/8（L217–219）。
