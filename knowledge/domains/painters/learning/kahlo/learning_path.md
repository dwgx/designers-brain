## §3 三个主机制（M1 / M2 / M3）

<a id="db-source-line-41"></a>
### M1 — 自画像符号系统（self-portrait as 生平符码表）`[研究]` 符号 + `[归纳]` 参数

- **看什么**：符号物**逐件摆放、像编字一样构成可解码的图句**（§2-8 L54：「猴、鹦鹉、花、荆棘项链、**蜂鸟**、柱子、面具、宇宙元素」），对应 §4-P3 象征身体密度 `[归纳]`。
- **蜂鸟（档案内符号）**：§8.1 正向段 L218 `a hummingbird pendant`（与 thorn necklace / broken column / ribbons 并列）；§12 #2 L388 注「蜂鸟坠饰（悬停的生死双重符号）」。它是**具体作品《Thorn Necklace and Hummingbird》的可命名指涉物**，因此满足 §8.2-2「自传指涉物 ≥2」与 §3.1 L78「具体事件指涉物 ≥2 件 → 卡罗档」的判据之一。
- **monobrow / 一字眉（外部文化标志，诚实降级）**：本机**唯一逐字命中**在 `knowledge/domains/painters/_scratch/kahlo/pages/wiki_kahlo.wiki` L282——2018 Mattel Barbie 争议「noticeably missing [[unibrow]]」（NYT 2018-03-09 转引）。**dossier §1 十二条视觉指纹（L31–42）未逐字列 monobrow**，§4 六参数、§8.1 正向段、§8.2 八规则亦无它。本路径把它作为「大众辨识度最高的自画像标志物」以 `[史料-转引]` 承接，**明确标注：档案 §1 未列、非 §4 参数、不冒充档案内已证符号、不补进模块卡**。它与蜂鸟的差别正是本课要教的：「档案内可回源符号」与「外部文化标志」不能混为同一证据级。
- **作者自述（意图层）** `[自述]`：corpus #4「我常独处，所以我画自己」（L33–38）、#3「我画的是我自己最坦率的表达」（L24–29）、§5 L109「我从未画梦，我画的是我自己的现实」——支持「自画像＝自我作为主语」这一**意图**，不提供任何符号清单数值。
- **参数接口** `[归纳]`：P1 自传具体度 80%（§4 L92）、P3 象征身体密度 70%（L94）、P5 服饰纹样密度 70%（L96）；§8.2-2 L250 自传指涉物 ≥2、§8.2-7 L255 动物/植物/首饰符号 ≥2 类且均处焦平面；§8.1 中文说明 L239「氛围图 2–3 个符号 / 叙事图 4–6 个，符号必须可解码、不能只是装饰」。
- **边界**：`--no dream surrealism`（§8.1 负向 L229）是**模块护栏不是历史断言**（L243）；符号必须「要求观者动用生平词典」（L240），否则滑向蒙克档的通用情绪原型。

<a id="db-source-line-50"></a>
### M2 — 镜像凝视 vs 里维拉分工（mirror / Rivera 互查）`[研究]` + `[归纳]` 写死条款

- **镜像（正面凝视/以镜作画）**：§1-2 L32「正面/近正面、目光直视观者；构图源自镜中像——病床上方装镜、以镜作画（MoMA：'alter and extend her field of vision'）」；§2-3 L49「床帐上方安装镜子作画，成为构图机制本身」；§11 L331 事故卧床期装镜 → 1926 第一幅自画像；§8.1 正向 L213 `staring directly at the viewer`；卡 [kahlo.md](../../modules/kahlo.md) L9。参数化 = **P4 正面凝视/镜像度 80%**（§4 L95，含「双身变体」，§1-7 L37）。
- **里维拉互查（写死分工，§3.1 L80–84）**：卡罗＝私密小幅 + 单人正面 + 私人生命史；里维拉＝公共巨幅 + 多人群像 + 集体历史（L81–82，MoMA「her intimate scale… sharply contrasted with the Mexican Muralists」L81）。**四条判据 ≥3 归判**（L83）：① 尺度/观看距离 ② 题材域 ③ 构图 ④ 功能。组合纪律 L84：默认不并置，组合须**显式分区**并保留各自标志（卡罗：正面镜像+符号身体；里维拉：群像+历史叙事），不得互相吞并。
- **与蒙克的另一条分工（§3.1 L75–79，carried）**：卡罗＝具体自传符号系统（需生平词典）vs 蒙克＝普世焦虑原型语法（无需生平）。符号可解码性测试 + 「具体事件指涉物 ≥2 件 → 卡罗档」（L78）。卡 [kahlo.md](../../modules/kahlo.md) L78–79 落为冲突注记。
- **两条互查的关系**：镜像是 `P4` 身份门（自我作为可反复进入的图像现场，§7-总结 L178 轴③）；里维拉是 `P6` + 分工注（L101 禁「公共巨幅＋群像＋历史叙事」同档出现）。学习时必须**同时查两轴**：一件作品可以「正面镜像」成立却因「巨幅群像」越界到里维拉档（反例见 §4 阶梯3）。

<a id="db-source-line-57"></a>
### M3 — 小画幅 / 亲密观看距离（intimate scale）与其例外档 `[研究]` + `[归纳]`

- 常规：尺幅多 30–60 cm 级（§1-9 L39 举 *Cropped Hair* 40×27.9 / *Chango y loro* 54.6×43.2 / *Grandparents* 30.7×34.5），与 ex-voto 还愿画基底同族（§2-1 L47）。参数化 = **P6 画幅与观看距离 85%**（§4 L97）。
- **尺度语义 ≠ 绝对尺寸**：§1-9 L39「尺度语义以『私密/近观』为准，非绝对尺寸」；§自审 B3 L437 已把初稿「小画幅是模块身份」判 **WEAKENED → 增设例外档**（反例：《Las dos Fridas》≈173×173 cm / 《Trotsky》≈76 cm）。
- 这正是 §C-EXCEPTION 与 AUDIT counterexample 反例A 要处理的对象（见 §4 阶梯3、mechanism_notes §C）。

## §4 三段练习阶梯（顺序 = 建符号词典 → 镜像/分工互查 → 尺度例外与权利边界）

每段都标 **观察对象 / 创作决策 / 机制 / 参数 / 一次可做的练习 / 反例 / 自检** 七项（Lane B 契约）。全部为建议练习，无真人评价。

<a id="db-source-line-69"></a>
### 阶梯 1 — 把「自画像」建成可解码的符号句（M1）

- 观察对象：《Self-Portrait with Thorn Necklace and Hummingbird》（§12 #2）/《断柱》（§12 #3）/《飞床》（§12 #4）。
- 创作决策 `[归纳]`：**先选「符号必须对应可核实的生平事件/人物」，再选符号数量**（§8.1 中文说明 L239）；牺牲「纯装饰性摆件」「无需生平即可读的通用情绪」（§3.1 L76、L240）。
- 机制：符号物逐件摆放成句（§2-8 L54）；蜂鸟坠饰=生死双重符号（§12 #2）；动物=自传替身（§1-6 L36，MALBA 转引）。
- 参数 `[归纳]`：P1=80% / P3=70% / P5=70%；§8.2-2 指涉物 ≥2、§8.2-7 符号 ≥2 类且焦平面内；§8.1 中文说明 L239 氛围 2–3 / 叙事 4–6 个。
- 一次可做的练习（照录 §12 #2 L390）：画一幅半身自画像，围绕人物**摆放 4 个符号**（1 动物 + 1 植物 + 1 器物 + 1「伤口/刺」类元素），全部平视清晰、禁止景深虚化、背景=单色/植被平面；再为每个符号写一行「它对应哪件可核实的事」，写不出即判为装饰、删掉。
- **反例（monobrow 分级练）**：把「一字眉」当唯一符号、且不给生平对应 → 它在本机档案 §1 未列、只是 `[史料-转引]` 文化标志，单独使用既不满足「≥2 可命名指涉物」（§8.2-2），也把外部标志混成档案内符号。对照「蜂鸟坠饰 + 荆棘项链 + 双猴」三件可回源符号（§8.1 正向 L217–218、§12 #2）才是卡罗档。**这是分级练习，不是否定 monobrow 的辨识度。**
- 自检：能否把每个符号指到 `_corpus` / §12 的一处 `[自述]` 或 `[研究]` 文本？能否说明 `--no dream surrealism` 是护栏不是历史断言（L243）？

<a id="db-source-line-79"></a>
### 阶梯 2 — 正面镜像 + 蒙克/里维拉双轴互查（M2）

- 观察对象：《Las dos Fridas》（§12 #1，双身变体）/《Diego y yo》（§12 #8）/《chango y loro》（§12 #7）。
- 创作决策 `[归纳]`：**先定 P4 正面镜像（80%）为身份门，再用 §3.1 两条分工判据排除蒙克档与里维拉档**（L75–84、L101）；牺牲「侧身回避对视」「全场景焦虑变形」「巨幅群像历史叙事」。
- 机制：镜像＝自我作为可反复进入的图像现场（§7 L178 轴③）；符号可解码性测试（L78）与四条判据 ≥3 归判（L83）是两把独立的尺。
- 参数 `[归纳]`：P4=80%（§4 L95）、P6=85%（L97）；§8.2-1 L249 面轴 ≤10° / 瞳孔 ±15°、§8.2-6 L254 人物数=1（≥90% 帧）、主体占高度 40–70%；§4 用法注 L99「P1/P4 定是不是卡罗」。
- 一次可做的练习（§12 #8 L414 扩展）：画自画像，让「另一个人」以肖像坠饰/嵌入物出现在面部附近（≤画面 8%），加 1 条缠绕线、保持直视；再写一张**两轴互查表**——左列「蒙克判据：是否需生平词典 / 具体指涉物 ≥2？」右列「里维拉四条：尺度/题材/构图/功能各落哪档？」逐格填，确认没有一轴越界。
- 反例：把「具体自传指涉物」换成「无脸原型 + 声波色域」（AUDIT counterexample 反例B）→ 判蒙克档；或做成「米级巨幅 + 群像 + 历史叙事」（反例A 压力点）→ 四条全落里维拉，须按 §3.1 L84 / §4 L101 拆图或显式分区。
- 自检：P4 是否保持全正面直视？两轴互查表是否每格有结论？§8.1 正向 L213 的 `staring directly at the viewer` 是否落地？

### 阶梯 3 — Las dos Fridas 173cm 例外档 + images_public=0 / NMWA 权利行边界（M3）

- 观察对象：《Las dos Fridas》（§12 #1，≈173×173 cm）/《Trotsky》≈76 cm（§1-9 L39）。
- 创作决策：**先判「尺度语义」而非绝对尺寸**（§1-9 L39、§自审 B3 L437）；牺牲「用 cm 数一刀切判档」的省事做法。
- 机制：§4-P6 L97 强档已写死「例外：《Las dos Fridas》式双身巨幅须**显式标注为『例外档』**」；§3.1 L81「个别例外如《Las dos Fridas》约 173 cm 仍属『近观/私密语义』档」。
- 参数 `[归纳]`：P6=85% 默认，但**遇例外档必须显式标注**，不得静默按弱档（大画幅/远观→越界壁画档）处理。
- **反例 = AUDIT counterexample 反例A（ carried as resolved exception, `[inference]` 纸面）**：把 173cm 喂给 §3.1 四条判据（L83）：① 尺度→里维拉档；② 题材域（双身=身份谈判/婚姻）→卡罗档；③ 构图（正面并置双身+压缩雷云，非群像深空间）→卡罗档；④ 功能（自传性私物）→卡罗档 → **3/4 归卡罗**，命中 §4-P6 预置例外档，**机制自洽、未推翻**（AUDIT counterexample.md L6–18；review-evidence.md §5 逐条复核一致）。本 shard 采信为已决例外档事实，不重新论证、不跑渲染。
