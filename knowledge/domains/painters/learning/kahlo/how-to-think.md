# LEARN-kahlo — How to Think（how_to_think）

> 回答「创作时先选什么、牺牲什么、为什么、何时失效」，**不是**作品外观形容词表（`03-RESEARCH-AGENDA.md` L14、`02-EXECUTION-PLAN.md` §Lane B L66）。
> **铁律**：不从画面外观反推作者心理，不把本项目 `[归纳]` 规则冒充卡罗原意（`00-GOAL.md` L9、[kahlo.md](../../dossiers/kahlo.md) L5）。下表每一决策步都标等级：
> - `[自述]` = 作者写下/说出（[kahlo.md](../../dossiers/_corpus/kahlo.md) / §3 / §5，逐字可回引）——**可作为「她为什么这么决策」的依据**；
> - `[研究]` = 馆方/艺术史分析（符号、镜像、尺幅语义）——**输入材料，仅作佐证**；
> - `[归纳]` = 本项目研究者为逐帧生成构造的操作规则（§4 六参数 / §8.2 八规则 / §3.1 分工条款）——**是本 shard 的决策程序，不是作者内心**；
> - `[史料-转引]` = 外部文化标志（monobrow）经转引，**档案 §1 未列，不得升级为档案内已证符号**；`[推测]` 本文件不使用；
> - `fact(已决)` = AUDIT 已独立复核的 resolved fact（images_public=0 / NMWA 权利行 ×5 / 173cm 例外档），下游直接采信、不回退为开放假设。

## §0 先问：我面对的是哪一类卡罗问题？

| 问题类型 | 该读什么 | 不该读什么 |
|---|---|---|
| 她**为什么**反复画自己？ | `[自述]` corpus #4「我常独处所以我画自己」(L33–38)、#3「我自己最坦率的表达」(L24–29)、§5 L109「我画的不是梦，是我自己的现实」 | 不要把 P1=80% 说成「她规定 80% 自传密度」 |
| 她**为什么**用这些符号？ | `[研究]` §2-8 L54 符号编制、§3.1 L76「符号需生平词典」、`[自述]` 只支持「自传即材料」的意图 | 不要把 monobrow 当成档案 §1 已列符号 |
| 我**怎么**逐帧生成/自检？ | `[归纳]` §8.2 八规则、§4 六参数、§3.1 分工判据 | 不要把操作规则写成「卡罗主张」 |
| 我**能不能**引用作品图？ | `fact(已决)` images_public=0 + NMWA 权利行 | 不要写私有 13 件路径、不要猜 PD、不要嵌图 |

> AUDIT caveat 同口径：[kahlo.md](../../dossiers/kahlo.md) L100/L320「阈值为本项目 `[归纳]`，未经渲染实验校准」、`01-AUDIT.md` §8.1 L273「建议练习不写已证实学习收益」。

## §1 创作决策序（D0→D6，每步：先选 / 牺牲 / 为什么 / 何时失效 / 等级）

<a id="db-source-line-28"></a>
### D0 — 先分流「作者意图」还是「生成任务」`[自述]` 意图 + `[归纳]` 分工

- **先选**：若问「她为什么这样画」→ 走 `[自述]` corpus + §3 创作原则（L64–71 八条，含「画现实不画梦」「自传即材料」「绘画=生存方式」）；若问「我怎么生成一帧」→ 走 `[归纳]` §8.2 + §4 + §3.1。
- **牺牲**：意图层不追数值；生成层不把作者心理写进 prompt。
- **为什么**：corpus #3/#4/#6/#20 是本人原话；§4 六参数、§8.2 八规则是研究者为逐帧生成构造的（L100、L320）。两者不同层。
- **何时失效**：把「我画自己的现实」直接翻译成 `--no dream surrealism` 并宣称这是历史断言 → 错；L243 明写该负向约束是**模块护栏，不是历史断言**。
- **等级**：意图 `[自述]`；分层判定 `[归纳]`。

<a id="db-source-line-36"></a>
### D1 — 先选「符号必须可解码」再选符号（含 monobrow / hummingbird 分级）`[研究]` + `[归纳]`

- **先选**：每件符号物对应一个**可核实的生平事件/人物**（事故/手术/流产/迭戈/墨西哥身份/宠物），逐件摆放成句（§2-8 L54）。
- **牺牲**：纯装饰摆件、无需生平即可读的通用情绪原型（§3.1 L76、§8.1 中文说明 L240）。
- **为什么（分级诚实）**：
  - **蜂鸟 hummingbird** = 档案内 `[研究]` 符号：§8.1 正向 L218 `a hummingbird pendant`、§12 #2 L388「蜂鸟坠饰（悬停的生死双重符号）」、[kahlo.md](../../modules/kahlo.md) L26 同值。它是具体作品的可命名指涉物，计入 §8.2-2「≥2 个自传指涉物」。
  - **monobrow / 一字眉** = `[史料-转引]` 外部文化标志：本机唯一逐字命中在 `_scratch/kahlo/pages/wiki_kahlo.wiki` L282（2018 Barbie「noticeably missing [[unibrow]]」，NYT 转引）。**dossier §1 十二条指纹（L31–42）未逐字列它**，§4 六参数、§8.1 正向段、§8.2 八规则亦无它。本 shard 承认它是大众辨识度最高的自画像标志，但**不把它写成档案内已证符号、不补进模块卡、不拿它单独满足「≥2 指涉物」**。
- **何时失效**：只用 monobrow 一个符号、且给不出生平对应 → 既不满足 §8.2-2（≥2），又把外部标志混成档案符号（见 learning_path 阶梯1 反例）。若把符号全换成「无脸原型 + 声波色域」→ 判蒙克档（§3.1 L78、AUDIT counterexample 反例B）。
- **等级**：符号可解码性意图 `[自述]` 支撑 + `[研究]` 符号 + `[归纳]` 计数阈值；monobrow `[史料-转引]` / partial。

<a id="db-source-line-46"></a>
### D2 — 定 P4 正面镜像为身份门 `[研究]` 来源 + `[归纳]` 参数

- **先选**：全正面直视 + 镜像结构（含双身变体）= P4 默认 80%（§4 L95），与 P1 共同「定是不是卡罗」（§4 用法 L99）。
- **牺牲**：侧身/低头/回避对视（P4 弱档）、全场景焦虑变形（蒙克档）。
- **为什么** `[研究]`：§1-2 L32「正面/近正面、目光直视；构图源自镜中像——病床上方装镜、以镜作画」；§2-3 L49「镜像工作法成为构图机制本身」；§11 L331 卧床期装镜 → 1926 第一幅自画像；`[自述]` corpus #4「我常独处，所以我画自己」是意图侧佐证。**镜像不是「画得对称」**，是「自我作为可反复进入的图像现场」（§7 L178 轴③）。
- **操作判据** `[归纳]`：§8.2-1 L249 面轴 ≤10° / 瞳孔 ±15°；§8.2-6 L254 人物数=1（≥90% 帧）、主体占高度 40–70%；§8.1 正向 L213 `staring directly at the viewer with an unflinching steady gaze`。
- **何时失效**：把「镜像」理解成「必须画一面镜子/必须双身」→ 过度字面化；P4 强档是「全正面直视 + 镜像结构（含双身变体）」，双身只是变体之一（§1-7 L37）。
- **等级**：镜像史实 `[研究]`；P4/§8.2 数值 `[归纳]`。

<a id="db-source-line-55"></a>
### D3 — 蒙克 / 里维拉双轴互查（carried）`[归纳]` 写死条款

- **先选**：生成前**同时过两把尺**——① 符号可解码性测试（§3.1 L78：具体事件指涉物 ≥2 件 → 卡罗档；全部通用情绪原型 → 蒙克档）；② 里维拉四条判据（§3.1 L83：尺度/题材域/构图/功能，≥3 条落同一档即判定）。
- **牺牲**：「通用情绪原型 + 全场景变形」（蒙克，L79 禁同档）、「公共巨幅 + 群像 + 历史叙事」（里维拉，§4 分工注 L101 禁同档）。
- **为什么（写死分工）**：§3.1 L73 标题即「写死；`[归纳]`，可被组合实验推翻」；L81 引 MoMA「her intimate scale… sharply contrasted with the Mexican Muralists」作为对照；卡 [kahlo.md](../../modules/kahlo.md) L78–79 落为冲突注记。
- **何时失效 / 组合**：默认二选一（L79/L84）；若必须组合，须「同屏显式分区」并保留各自标志（卡罗：正面镜像+符号身体；里维拉：群像+历史叙事），不得互相吞并（L84）。「需要大场景时不得同时保留本模块的『正面单人＋符号身体』标志机制」（L101）。
- **诚实边界**：两轴判据均为 `[归纳]`、可被组合实验推翻（L73/L79）；AUDIT 反例B 已指出「1 件具体 + 通用原型」混合区未被 L78 二分覆盖，是指定可推翻点，本 shard 不补阈值。
- **等级**：全部 `[归纳]`；MoMA 对照句 `[研究]` 转引。

<a id="db-source-line-64"></a>
### D4 — 尺度判语义不判 cm；遇 173cm 显式标注例外档 `fact(已决)` + `[归纳]`

- **先选**：P6 默认 85%（小画幅 30–60cm + 近距单人对视，§4 L97），但判据是「**私密/近观**」语义，不是绝对尺寸（§1-9 L39、§自审 B3 L437 WEAKENED）。
- **牺牲**：用「>60cm 即判里维拉」的一刀切。
- **为什么（已决，不重论证）**：《Las dos Fridas》≈173×173 cm / 《Trotsky》≈76 cm 是 §1-9 L39 明列例外；§4-P6 L97 强档已写死「例外：《Las dos Fridas》式双身巨幅须**显式标注为『例外档』**」；§3.1 L81「个别例外仍属近观/私密语义档」。AUDIT counterexample 反例A 把 173cm 过四条判据：① 尺度→里维拉；②③④（题材=身份谈判/构图=正面双身压缩舞台/功能=自传私物）→卡罗 → **3/4 归卡罗**，命中预置例外档、机制自洽、未推翻；review-evidence.md §5 复核一致。
- **何时失效**：若一件作品「尺度米级 + 群像 + 历史叙事 + 公共墙」四条全落里维拉却仍带「正面单人+符号身体」，则 §4 L101 与 §3.1 L84 要求拆图/分区（反例A 标注的 `[inference]` 压力点，本次未渲染验证）。若**静默**把 173cm 按 P6 弱档（大画幅/远观→越界壁画档）处理而不写「例外档」标注 → 违反 L97 的显式要求。
- **等级**：例外档文本与反例A 结论 = `fact(已决)`（AUDIT 已核）；P6 数值与四条判据 `[归纳]`；反例A 整体仍 `[inference]` 纸面、未渲染。

<a id="db-source-line-72"></a>
### D5 — 权利边界：公开侧零图，只给馆藏链接 `fact(已决)`

- **先选**：引用作品只给**馆藏页 / 文件页 URL**（[R19] GAC/MAM、[R14] HRC、[R16] NMWA 等），公开侧不嵌图、不写私有层路径。
- **牺牲**：复制 13 张私有研究副本、猜 PD、编造 CC 署名。
- **为什么（已决）**：`images_public=0` 是**事实非缺陷**（AUDIT RESULT §2）；`images_manifest=false` 意为「无公开侧 manifest 行」非「缺文件」（AUDIT claim IMG-MANIFEST-FALSE）。`_images/manifest.md` L7/L3161/L3185 与 ledger 一致：kahlo 公开 0 / 私有 13 / **全部版权未清 © Fideicomiso/ARS**；dossier §0 L5 / §10-1 L313 明写「公开侧只列作品清单 + 馆藏链接，不嵌图」。**NMWA live 权利行**：`AUDIT-kahlo/raw/nmwa_trotsky.html`（HTTP-200，sha `d6d8fdb2…`）命中 `© Banco de México Diego Rivera Frida Kahlo Museums Trust, Mexico, CDMX/Artists Rights Society (ARS), New York` **×5**（rights_review.md L15 登记、review-evidence.md §4 独立复核 ×5、dossier §9 交叉3 L306「NMWA/MoMA/HRC 三馆权利行一致」）。
- **何时失效**：把私有件伪装成公开行、或把 0 张写成「采集缺口待补」→ 与 内部证据 f44b08a42a29a8ab（未公开；来源记录由维护者保留） 冲突；把「未清」擅自改写为 PD → 猜许可。MoMA 403 / Time 订阅 / AAA 快照 3 源不可达（AUDIT risk_fetch.md）**不**构成「权利未核」的借口——权利结论锚定 manifest + dossier + NMWA live 页（rights_review.md §边界 L48）。
- **等级**：`fact(已决)` / supported（本机 manifest + 独立审者复核的缓存字节）。本 shard 未重新联网、未做 image_seen。

### D6 — 收尾自检：题字护栏、越界警报、等级复核 `[归纳]`

- **先选**：按 §8.1 中文说明 L238「定调三件套」复核 P1=80% / P4=80% / P6=85%；再过 §8.2 八规则逐帧自查表；与 Lane B 组合时按 conflicts.md 预检 C-05 笔触 / C-12 色相预算 / C-14 渐变（§3.1 L85、卡 L80）。

## §3 「何时失效」汇总（速查）

1. D0：把 `[自述]` 意图直接当 `--no` 历史断言 → 混淆层（L243 护栏非历史断言）。
2. D1：monobrow 单独当符号 / 给不出生平对应 → 外部标志混成档案符号、不满足 ≥2；符号全换通用原型 → 蒙克档（反例B）。
3. D2：把「镜像」字面化成「必须画镜子/必须双身」→ 过度字面化；P4 降到回避对视 → 退化普通肖像。
4. D3：一轴越界未查（巨幅群像 / 全场景焦虑变形）→ 里维拉或蒙克档；组合未显式分区 → 互相吞并（L84/L101）。
5. D4：静默把 173cm 按 P6 弱档处理、不写「例外档」→ 违反 L97；四条全落里维拉却保留卡罗标志 → 须拆图（反例A 压力点，未验证）。
6. D5：写私有 13 件路径 / 猜 PD / 把 0 张当缺口 → 与 manifest+ledger+NMWA 冲突。
7. D6：把 `[归纳]` 阈值当已像素实测 / 把建议练习当已证实学习收益 → 违反 A-30 口径（`01-AUDIT.md` L273）。
