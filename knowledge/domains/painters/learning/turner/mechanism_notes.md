## 1. 六参数 → 练习映射（`modules/turner.md:58-94` / `dossiers/turner.md:74-112`）

<a id="db-source-line-26"></a>
### P1 大气能见度（雾/雨/雪幕浓度，默认 60%）`[归纳]`
- 三档（`:59-61`）：弱 ≥10 km / 远景对比 60–100%、无统一幕色（早期地形画）；中 3–10 km / 40–60%、轻度幕色远处去饱和；强 <3 km / **≤40%**、地平线溶解、全画向单一色光收拢（《暴风雪》档；**莫奈强档之外**）。
- 自查（`:62`）：分区对比度 + 地平线梯度（→ §8.2-1/-2）。
- **练习映射**：阶梯1-2 把画面分近/中/远三带逐带量对比度，要求近→远单调、R²≥0.8、远景 ≤40%。`dossiers/turner.md:228` 强度调节：天气事件→P1 中-强；灾难与崇高→P1 强；日出/黄昏抒情→P2 中、P4 强、P5 中-强。
- **失败条件**：远景不衰减（同帧近远对比持平）；线性拟合 R²<0.8；强档却仍留清晰地平线。`modules/turner.md:38` 负向禁「crisp horizon line」。
- **大气光效归属**：A1。

<a id="db-source-line-33"></a>
### P2 边缘溶解强度（默认 55%，0–100% 天然强度参数）`[归纳]`
- 三档（`:65-67`）：弱 0–30% 轮廓/地平线清晰；中 30–70% 形体仍可辨（《无畏号》船体）；强 70–100% 无轮廓、无地平线、形体完全溶于光/雾（《暴风雪》《诺勒姆城堡·日出》）。
- 自查（`:68`）：边缘梯度图（主体区最大梯度 / 全帧最大梯度）。
- **练习映射**：阶梯3-2「同景两遍，第二遍未干时大笔洗掉细节、只留 2–3 个形」，按强档自查「无轮廓、无地平线」（`dossiers/turner.md:423-426` §12-8）。
- **失败条件**：强档下地平线带出现全帧最大梯度（§8.2-2 写死「最强边缘必须属于光源或动势线」）。
- **大气光效归属**：A4。

<a id="db-source-line-40"></a>
### P3 事件动势强度（默认 60%）`[归纳]`
- 三档（`:71-73`）：弱 平静/微风单组对角线；中 强风/蒸汽/急流多组对角线方向一致；强 旋涡（涡心+切向流场）或灾难事件（火/沉船）全画面场。
- 自查（`:74`）：光流方向直方图 + 涡度估计（→ §8.2-5）。**注（`:75`）**：**静水波纹属莫奈领域（其 §4 P5）；本参数只覆盖事件级动势**。
- **练习映射**：阶梯3-1 单一涡心风暴场（雪/浪/烟同向），主体只给暗示；查主方向能量 ≥60%、涡心唯一（`dossiers/turner.md:415-418` §12-6）。阶梯1 的《雨、蒸汽与速度》对角线（`:395-398` §12-1）。
- **失败条件**：对角线+旋涡双动势并存；实体（船/人/建筑）作物件级动画（§8.2-5 禁止）；天气位移 >3 px/帧或硬切；事件元素覆盖 <40%（§8.2-7）。
- **B1 硬边界**：水面练习只承载事件光，不画静水波纹（见 §3）。

- 三档（`:78-80`）：弱 中性灰主导局部暖点；中 亮暖/暗冷两段式可测；强 亮部向白/金推、暗部向紫-蓝推、中性灰占比极低（色相直方图双峰）。

- **失败条件**：暗部脏棕（负向 `:40`「muddy brown shadows」）；中性灰 >10%；互补撞色（负向 `:42`）。
- **大气光效归属**：A3。

## 3. 两条强调线的机制化（本轮点名）

<a id="db-source-line-89"></a>
### 3.1 大气光效 = A1–A5 的合成

没有一条叫「大气光效」的独立规则；它是下列五条参数的**合成可读结果**，每条都有独立自查量，不混称：

- **A1 包络**（P1/§8.2-1）：远景交给空气，近→远单调衰减（R²≥0.8）。
- **A2 单一亮核 + 径向 glow**（P5/§8.2-4 + §8.1 `:24-27`）：唯一连通域、径向剖面单调、其他峰值 ≤80%；「radial glow spreading through mist」「light glowing from beneath the surface」。
- **A3 亮暖暗冷**（P4/§8.2-3 + §8.1 `:29-30`）：暗部紫-蓝 / 亮部黄-橙或白、中性灰 ≤10%。
- **A4 边缘溶解**（P2/§8.2-2）：轮廓熔进光雾，最强边缘保留给光源或动势线。
- **A5 透明叠色 / 发光感**（P6/§8.2-6 + §2-1 技法 `[研究]`）：高光 S≤50%、层痕集中于亮部——「发光感而非白颜料堆砌」。

**优先级冲突**：A2（亮核）与 A4（溶解）争夺全帧最大梯度时，按 §8.2-2「最强边缘必须属于光源或动势线」(`modules/turner.md:49`) 光核优先。规则层 `[归纳]` 处置，非审美意见。
