## 2. 两条强调线在决策序里的位置（本轮点名）

<a id="db-source-line-40"></a>
### 2.1 大气光效

大气光效不是单独一步，而是 **S2+S3+S4+S5+S7 的合成结果**：包络（S2）把远景交给空气 → 单一亮核与径向 glow（S3）给出唯一光源 → 亮暖暗冷（S4）把光染成暖核/冷压 → 边缘溶解（S5）让轮廓熔进光雾 → 透明叠色/「光从底层透出」（S7）产出**发光感而非白颜料堆砌**（`modules/turner.md:53`、`:27` §8.1）。

决策时的**优先级冲突**：若亮核（S3）与边缘溶解（S5）争夺「全帧最大梯度」，按 §8.2-2 写死「最强边缘必须属于光源或动势线」(`modules/turner.md:49`) —— 光核优先。这是规则层 `[归纳]` 的处置，不是审美意见。

<a id="db-source-line-46"></a>
### 2.2 水体反光（须诚实）

**先承认缺口**：§8.2 七条、§4 六参数里**没有独立的「水体反光」数值规则**。决策序里能落到水面的只有三个已定位的锚点：

1. `dossiers/turner.md:406`（§12-3 怎么练）：「其中一稿以水面反射为主…留出火光与水光」——**练习级 `[归纳]`**。
2. `dossiers/turner.md:408-410`（§12-4）：「水面与船群为主部」「水面构图 ≥50%」「把『场景』写成『光』」——**构图级 `[归纳]`**。
3. `modules/turner.md:27`（§8.1 正向「light glowing from beneath the surface」）、`:39`（负向禁「calm static water」）——**prompt 措辞级**。

于是「水体反光」在本决策序里是 **S3（唯一亮核）向水面的延伸 + S7 的 lift-out 材质**，并受两条硬自律约束：

- **B1（归属）**：`modules/turner.md:75`（P3 注）与 `:101`（冲突注记）——**静水波纹属莫奈领域（其 §4 P5）**；透纳 P3 只覆盖事件级动势。水面必须承载**事件光**（火/日落/风暴亮核）的反射，不是静水色点分解。这是 S1 边界档位在水面的投影。
- **B2（不反客为主）**：借 §8.2-4「其他区域亮度峰值 ≤ 光源区 80%」(`modules/turner.md:51`) 的精神——水面反射是光的**回声**，亮度不得成为第二连通域、不得超过唯一亮核。这是 `[归纳]` 的练习自律，**不是**档案写死的水面数值规则。

> 决策时若有人问「透纳怎么处理水面反光」：正确回答是引用上述三处锚点 + B1/B2，**不**虚构一条「§8.2 水体反光规则」，**不**从画面反推他「想表现水的什么」。把三处拼成教学机制是 `[归纳]` 重组（见 `learning_path.md §3-B`），不是已验证判分规则、不是史实。

### 2.3 C-10 monet ownership（决策序里的只读项）

- C-10 = **莫奈 × 塞尚** 的深度衰减冲突（`conflicts.md:41`、`:176-186`）。规则所有权在莫奈侧（「远景对比 ≤60% + 单调梯度 R²≥0.8」，`:180`）；塞尚侧是「反大气透视 + 空间压缩」（`:181`）。
