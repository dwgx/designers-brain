### 主线 B — 水体反光（本轮重点，须诚实）

**先把口径钉死**：`turner` 的 §8.2 七条规则里**没有独立的「水体反光」数值规则**，§4 六参数里也没有水面反射阈值。档案对水-光的处理只在三处：

1. `dossiers/turner.md:406`（§12-3 怎么练）：「对同一夜事件画两稿…**其中一稿以水面反射为主**；水彩稿练「湿时擦除」留出**火光与水光**」——练习级，`[归纳]`。
2. `dossiers/turner.md:408-410`（§12-4）：「**水面与船群为主部**」「把『场景』写成『光』」「**水面构图 ≥50% 画面**」——构图级，`[归纳]`。
3. `modules/turner.md:27`（§8.1 正向）「light glowing from beneath the surface」；`:39`（负向）禁「**calm static water**」——prompt 措辞级。

再加两条硬约束，避免把「水体反光」练成莫奈：
- **B1 事件光反射，不是静水波纹**：`modules/turner.md:75`（P3 注）与 `:101`（冲突注记）：**静水波纹属莫奈领域（其 §4 P5）**；透纳 P3 只覆盖事件级动势。因此练习中的水面必须承载**事件光**（火/日落/风暴亮核）的反射，而不是平静水面的色点分解。
- **B2 水面不许成为第二光源**：借用 §8.2-4「其他区域亮度峰值 ≤ 光源区 80%」(`modules/turner.md:51`) 的精神，水面反射亮度不得反客为主超过唯一亮核；反射是光的**回声**，不是第二个连通域。这是 `[归纳]` 的练习自律，不是档案里写死的数值规则。

> 诚实声明：把上述三处拼成一条「水体反光机制」是**本学习路径的 `[归纳]` 教学重组**，用于 organizes 练习；**不是**声称档案存在一条已验证的「水体反光」判分规则，也不是人评/实验证实的学习收益。`conflicts.md` 里也没有「水体反光」冲突行。

## 4. 具体练习（三阶梯，全部为**建议练习** `[归纳]`）

> 抬头声明：下列全部是**建议练习**，学习收益未经人完成或评价，不写「已证实学习收益」（`01-AUDIT.md:273`）。阶梯顺序沿用 `dossiers/turner.md:436` 的组合练习分组，并把本轮两条强调线嵌入。练习数值来自 §8.2/§4（操作规则 `[归纳]`），不是原图像素实测。

**阶梯 1 — 大气光效地基：单一亮核 + 三带包络**（对应 §12-10《海上渔夫》`:431-434` → §12-7《无畏号》`:419-422`）
1. 画一幅月夜/落日，限 **1 个光源**，亮部 ≤5% 面积；按「暗→亮」顺序（先中间调、再压暗、最后提亮）。自查：亮度前 0.5% 像素是否单一连通域、径向剖面是否单调不增（`modules/turner.md:51` §8.2-4）。
2. 同景加雾：把画面分近/中/远 3 带，逐带量对比度，要求近→远单调下降、线性拟合 R² ≥0.8，远景 ≤ 近景 40%（强档）（`:48` §8.2-1）。
3. 给亮部推白/金、暗部推紫-蓝，统计中性灰（S≤8%）占比 ≤10%（`:50` §8.2-3）。**观察点**：地平线是否开始「被吃掉」。

**阶梯 2 — 水体反光：事件光在水面**（对应 §12-3 火灾双版本 `:403-406` → §12-4 威尼斯 `:407-410`；本轮重点）
1. 对同一夜火事件画两稿（近景仰视 + 远景平视），**其中一稿以水面反射为主**：建筑苍白、火为唯一主光源，水面承载火光的反射回声（`:404/:406`）。限暖冷两极色 + 黑。
2. 水彩稿练「湿时擦除 / lift-out」留出**火光与水光**（`:405-406`；技法来源 `dossiers/turner.md:49` §2-3 `[研究]`）。
3. 换成水面城市：水面构图 ≥50%、建筑只留 2 个可辨特征、其余融进雾光，按 §4 P1 中档自测远景对比（`:408-410`）。
4. **两条自律**（本轮 §3-B1/B2）：水面只反射事件光，**不画静水波纹**（那是莫奈 §4 P5，`modules/turner.md:75/:101`）；水面反射亮度不得成为第二亮核（借 §8.2-4 `:51` 的「≤光源区 80%」精神）。自查：全帧亮度前 0.5% 是否仍只属于唯一的火/日核。
5. **失败对照**：若画面出现「calm static water」（`modules/turner.md:39` 负向 §8.1）或干净的镜面倒影，说明已滑进莫奈的静水档，应换回事件天气或换模块。

**阶梯 3 — 极值合成：边缘溶解 + 涡旋 + 双账户记叙文**（对应 §12-6《暴风雪》`:415-418` → §12-8 诺勒姆 `:423-426` → §12-9 汉尼拔 `:427-430`）
1. 以单一涡心画风暴场（雪/浪/烟同向流动），主体只给暗示；自查主方向能量 ≥60%、涡心唯一（`modules/turner.md:52` §8.2-5；`:54` §8.2-7 事件元素覆盖 ≥40%）。
2. 同景画两遍：第一遍正常完成度，第二遍未干时大笔「洗」掉细节、只留 2–3 个形；比较「晨光感」；按 §4 P2 强档自查「无轮廓、无地平线」（`dossiers/turner.md:426`、`:64-68`）。

## 5. 可观察结果

练习产出后按「可判定量」自评（沿用 §8.2 自查项，非人评、非审美打分）：

- 大气包络：三带对比度数值 + 线性拟合 R²；地平线带最大梯度是否 ≤ 全帧 30%（强档）。
- 单一亮核：亮度前 0.5% 连通域个数 = 1；径向剖面单调性 R²；其他峰值 / 光源峰值 ≤ 0.8。
- 色温：暗部/亮部平均 H 落点；中性灰占比。
- 水体反光：水面面积占比（威尼斯稿 ≥50%）；水面反射区亮度峰值是否 < 唯一光源峰值；是否出现第二连通域；是否误入「calm static water」。
- 边缘溶解：主体边缘最大梯度 / 全帧最大梯度；强档下地平线带是否无全帧最大梯度。
- 动势：光流主方向能量 ≥60%；涡心唯一；事件元素覆盖 ≥40%。
- 双账户记叙文：是否两栏并列、有无把 WEAKENED 写成确证、有无删去任一说。
