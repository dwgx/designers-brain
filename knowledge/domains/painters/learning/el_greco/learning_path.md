## 4. 具体练习（3 阶梯；全部为「建议练习」`[归纳]`，未经人评）

> 三条阶梯按作业顺序设计：先建**灰调底层**（M1）→ 再做**扭曲变形**（M2，主判据自律）→ 最后叠**自有光／酸色／云幕＋组合边界**（M3+M4+M5）。每条含「可操作动作 / 自查 / 完成定义」，**不声称学习收益**。

<a id="db-source-line-72"></a>
### 阶梯一：grisaille-and-glaze studies（灰调底层 + 罩染）

- **目标机制**：M1（§2-1/-2/-3、Q29 Taubes、§8.1 L209、§8.2-2 无厚涂）。
- **动作**：取 §12-4《手抚胸口的绅士》／§12-2《剥夺圣衣》／§12-1《奥尔加斯伯爵的葬礼》为参照（`dossiers/el_greco.md:383-386,373-376,368-371`）。① 先画一张**灰色单色底层**（只许明度，不许色相）；② 待干后在其上**薄罩染**茜草红／铜绿／石青蓝／黄一类炽热色相，保留灰底从笔触缝隙透出；③ 在局部留一道**红棕底**从表面可见（§12-4 口径）；④ 底层之上**只加一层**颜料，禁厚涂、禁调色刀浮雕。按 §12-2「重画三次」的现有练习提法，每次把主角亮度提高一档、周边再降一档，练「一个亮点＋全部退灰」。
- **自查（可判定）**：灰度层是否可辨且先于色相层；色相是否呈罩染透出而非不透明覆盖；红棕底是否在缝隙可见；表面法线／浮雕强度是否低（无厚涂）；是否违反 §8.2-2「无厚涂」。
- **完成定义**：灰底→罩染→红底透出三层关系可读；无厚涂堆料；「一亮点＋退灰」在三次重画后仍成立。练习映射 `[归纳]`。
- **来源**：`dossiers/el_greco.md:51-54`（§2-1/-2/-3/-4）、`:209`（§8.1 brush 行）、`:229`（§8.2-2）、`:373-376,383-386`；`_corpus/el_greco.md:222-227`（Q29）、`:113-118`（Q14 Pacheco）。**等级提醒**：Taubes／Pacheco 是 `[研究]`／`[史料]`，不是 `[自述]`。

### 阶梯二：elongation-and-continuity studies（纵向拉伸 / 蛇形 / 连续性）

- **目标机制**：M2（§8.2-1/-6、P1、§3.1 ① 扭曲方向主判据）。
- **动作**：取 §12-3《三位一体》／§12-8《圣母无原罪》／§12-9《第五封印的开启》为参照（`:378-381,403-406,408-411`）。① 用 3 个以上人物排一条 **Z 形／上升轴**，只允许沿轴方向逐级变亮（§12-3 怎么练）；② 在 2:5 以上竖长画幅里画一个上升复合体，**全身无一处水平线**、光从形体内部出（§12-8）；③ 把其中一人拉长到「头＝全身高度 1/8」（§12-9）；④ 画「一群被光照亮的人」但**不许出现光源**（灯／日／窗）。⑤ **主判据自律**：另行画一张**世俗题材**（城市风景或神话，参照 §12-5《托莱多风景》／§12-10《拉奥孔》），要求仍保持**拉伸＋上升＋自有光**同轴——用它自检「有没有把题材域误当主判据」（反例结论）。
- **自查（可判定）**：焦点人物实例分割框高/宽是否 ≥3.5、人脸框高÷人物框高是否 ≤0.11（§8.2-1）；轮廓是否**连续无断裂**、直线折角段＝0（§8.2-6，与毕加索面片拆解相反）；轴方向是否向上而非压缩／波动／倾斜（§3.1 ①，与蒙克相反）；那张世俗题材是否被自己误判为「越界到蒙克」——若误判，说明把题材域当成了主判据，须改回 ①。
- **完成定义**：连续拉伸体成立（头身比、蛇形扭动、无拼接边）；上升轴可读；世俗题材稿在「扭曲方向同轴」下判为**不越界**；未出现面片拆解＋多视点、未出现压缩／波动。练习映射 `[归纳]`。
- **边界（本阶梯硬要求）**：判据冲突时**以 ① 扭曲方向 为准**（`dossiers/el_greco.md:82`）；「宗教狂喜／焦虑」只作 §3.1 判据④的**画面情绪类型学 `[归纳]` 标签**，不得写成「格列柯感到宗教狂喜」等心理陈述（`00-GOAL.md:9`；§10-7 不采用病因论）。两模块同用时按 §3.1 L83 选一个主导轴（建议 70/30 起）。
- **来源**：`dossiers/el_greco.md:34,39,57,79-87,96,228,233,378-381,388-391,403-406,408-411,413-416`；`modules/el_greco.md:45,50,60,68,74-75`；`munch.md:84`；AUDIT `RESULT.md §6`、`review-evidence.md:55-59`、[claim_evidence_map.md](claim_evidence_map.md) EG-GOAL-6 / EG-3-2。
