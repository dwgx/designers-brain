## 4. 具体练习（三阶梯；全部为「建议练习」`[归纳]`，未经人评）

> 顺序遵循 A-30 Lane B（02-EXECUTION-PLAN.md:64）：观察对象 → 创作决策 → 机制 → 参数 → 一次可做的练习 → 反例 → 自检。三阶梯从「取景与光」到「粉彩层积」再到「组合自律」，对应 §12 的「看/学/练」，但**不照抄成生平**。

<a id="db-source-line-88"></a>
### 阶梯一 · 舞台逆光/俯视取景的「取景器」（主线 A）
- **观察对象**：§12-1《舞蹈课》奥赛（俯视对角线）、§12-9《舞台后厅》（建筑线分 ≥3 层纵深）、§12-3《拉拉小姐》（极端仰视失衡）。
- **一次可做的练习**（`[归纳]` 建议练习）：用同一条对角线画一个封闭室内/排练室；机位略高（俯角 10–25°）；3 个姿态各异的人物中 ≥1 被画框边缘切割、主体不居中；画内放**一盏有方向的人工光**（脚灯/顶灯/高窗），亮部只落在纱裙/皮肤/地板三处之一，其余进暖暗剪影；**不许任何人看观众**。
- **可判定自查**（§8.2-1/-2/-3）：质心偏离 ≥15% 画宽？≥1 处边缘切割？视平线 ≥55% 画高、地板线族 ≥3 条收敛？亮部集中 ≤35% 且光源有方向/可见？
- **反例（自带）**：把光画成均匀无源自然光 + 边缘溶解 → 越界莫奈档（M-A1 失败）。

<a id="db-source-line-94"></a>
### 阶梯二 · 粉彩层积的「描线成面」（主线 B）
- **观察对象**：§12-4《蓝色舞者》（背对 + 厚层擦揉）、§12-5《梳头》（火焰橙红 + 奶油白底透出 + 未完成桌角）、§12-10《浴女》（排线随形体、俯视 20–30°）。
- **一次可做的练习**（`[归纳]` 建议练习）：用粉彩/色粉画 2–4 个背对的人体（只允许 1 个侧脸）；全画 ≤6 色，但**每处 ≥3 层**（排线 → 局部擦揉 → 固定/再叠方向不同的第二层）；刻意留 ≥2 个未完成区域、让底子透出；全程用排线塑形，**不许平涂 ≥5cm² 的色块**。
- **可判定自查**（§8.2-5/-8）：可见笔触覆盖 ≥70%？方向族 2–5？可见色层 ≥2？可见底子 ≥5%？无平滑渐变带宽 >2% 短边？
- **反例（自带）**：把排线抹成 sfumato 渐变 → C-05 对侧；或换成均匀圆点 → 越界修拉档。

<a id="db-source-line-100"></a>
### 阶梯三 · 70/30 组合自律 + 序列变体（横切，携带 N3 张力）
- **观察对象**：§12-1/§12-2《舞蹈课》双馆对读（同母题多版本）、§3.1 vs 莫奈四轴判据、conflicts.md N3 轴所有权表。

## 6. 常见失败（与 §4 越界警报 + AUDIT 反例对齐）

1. **光源越界**：无源自然光 + 大气包络 + 边缘溶解 → 莫奈档；画外单光源 + 近黑背景 + 高光只落脸/手 → 卡拉瓦乔档（`dossiers/degas.md:111`；`modules/degas.md:68`）。
2. **表面越界**：均匀点阵 + 补色光学混合 + 几何化定格 → 修拉档；抹平成平滑渐变 → C-05 对侧（达·芬奇）。
3. **人体越界**：理想化力量裸体 + 雕塑式完成态 → 米开朗基罗档；舞台华彩/正面对称/微笑看观众 → §8.1 `--no`（`:234-236`）。
4. **身份闸的结构性反例（AUDIT 已登记，本 lane 携带）**：《贝列里一家》是 §12 代表作，但 §4 用法「P1/P2/P5 ≥2 条 ≥中档」把它判为「不是德加」（三者皆弱档）——**早期肖像/历史画档被成熟期身份闸结构性排除**；另有「后台抓拍照」过身份闸却被 §8.1 `--no photographic realism` 否决的 false positive。二者均为 `[inference]` 纸面反例，无渲染/无像素测量（AUDIT-degas `counterexample.md` Attempt 1/2）。
5. **70/30 vs N3 的契约张力**：把 dossier「降档（≤弱档）」当 N3 已满足，或把 N3「整条移除」当已覆盖 dossier 口径——两者都不写「已解决」（AUDIT-degas `counterexample.md` §Relation；`RESULT.md §70/30`）。
6. **权利误用**：把 NG486《梳头》照片的 **CC BY-SA 4.0** 折叠成 PD/不署名；或把 Met 5 张 CC0 标签当成「本轮在线复核过」（实为 manifest-recorded，429/404 未重验）（AUDIT-degas `rights_review.md:9`、§A-55 rights）。
7. **取证越界**：把「本 lane 复用了 8 条原书引文」写成「本 lane 重新抓取/重新核验了原书」；把「练习自查通过」写成「原作像素实测通过」；把 `[归纳]` 阈值写成史料/作者自述。

## 8. 使用边界（何时失效 / 不能声称什么）

- **题材边界**：本路径是「封闭室内/剧场/后台/浴室的职业劳动瞬间」。天气事件/户外自然光/边缘溶解 → 换莫奈；点阵光学混合/去瞬间定格 → 换修拉；理想化力量人体 → 换米开朗基罗；画外单光源+近黑背景 → 换卡拉瓦乔（§4 越界警报 `:111`）。
- **时期边界**：§4 身份闸（P1/P2/P5 ≥2 ≥中档）只覆盖成熟期（1874+ 芭蕾/浴女）；早期肖像/历史画（如《贝列里一家》）会被误拒——用时须按时期降档/改判据，不得把该闸当全时期的分类真理（AUDIT `counterexample.md` Attempt 1）。
- **证据边界**：8 条原书引文是 **AUDIT-degas ACCEPTED 已复跑的复用证据**，不是本 lane 新抓；其余 28 条语料多为二手转引（`unverified`/`partial`），不作强证据；§4/§8.2 全部数值是 `[归纳]` 未实测；`image_seen=0`。
- **许可边界**：NG486 照片 **CC BY-SA 4.0 需署名 + share-alike**，引用必带署名；其余 12 张为 PD/CC0（manifest-recorded）；**不得**把 CC BY-SA 写成 PD，也不得把 manifest 标签写成「本轮在线复核」。
- **能力边界**：本 lane 产出的是**学习路径与机制说明文本**，不是生成图像、不是像素测量、不是组合实验、不是真人学习成效评价；`submitted ≠ accepted`；规则层互斥 ≠ 实验验证；本机文件 available ≠ 外部来源 available。
- **写入边界**：仅 内部证据 783dc2444eb3e2ac（未公开；来源记录由维护者保留）；仓库只读、无 git 操作、无子代理派发、无凭据入库。
