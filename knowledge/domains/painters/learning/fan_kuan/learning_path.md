## §4 具体练习（建议练习 · 三段阶梯 ladder，≥3 级，可操作）

> 练习总顺序（brief 强调 + A-30 观察对象→决策→机制→参数→练习→反例→自检，`02-EXECUTION-PLAN.md` L64）：**立幅巨碑比例 → 雨点皴密度 → 满皴+浓墨+云雾带的联合约束**。与 §12 既有「1→8 作品序列」（L342–376，作品维度）兼容：本 ladder 是**机制维度**三阶，§12 是**作品维度**序列，二者不互相替代、不重写 §12。

### 阶梯 1 — 立幅主峰压迫比例（练 M2「≥60% 高 + 中轴 + 顶天」）
- **输入**：竖式立轴（高宽比 ≥1.5:1，[fan_kuan.md](../../dossiers/fan_kuan.md) §3.1 L70 判据②）、一个主峰 + 两肩陪峰；参考 §8.1 正向段（卡 L18–34）与 §12-1《谿山行旅图》L344。
- **动作**：① 只画「大形」——主峰连通域、陪峰、近景大石位置，先不画皴；② 量最大山体连通域高度与水平重心；③ 做三档 **建议练习**变体（P2 弱 ≤40% / 中 40–60% / 强 ≥60%，[fan_kuan.md](../../dossiers/fan_kuan.md) L84–86 / 卡 L66–68）并排比对压迫感来源。
- **自查量**：主峰高度 ≥60% 画高（强档）；水平重心偏差 ≤10% 宽；顶部距上缘 ≤5% 高（§8.2-2 L203 / 卡 L50）。
- **可观察结果（产物级）**：强档变体里，近景点景（≤1.5% 画高）与主峰形成悬殊尺度比；换成横式手卷或群峰并置时「山勢逼人」消失——这正是 vs 黄公望分工条款的判据②（§3.1 L70）。
- **失败判据**：主峰 <60% 高；中轴偏移 >10%；把立轴画成横卷（进入黄公望「平远长卷」地盘，§3.1 L67/L71 互禁「纵向巨碑主山」）；顶部留天过多削弱压迫。
- **关联**：徐悲鸿「一山頭，幾佔全幅面積三分之二」（§1-1 L29 / corpus Q24）、赵孟頫「大圖闊幅，山勢逼人」（corpus Q18 L134）是 `[史料]/[modern]` 的古典/近现代表述，**只作观察对象，不是阈值来源**（阈值是 `[归纳]`）。

<a id="db-source-line-75"></a>
### 阶梯 2 — 雨点皴密度与方向（练 M1「≥60% 覆盖 + 方向离散」）
- **输入**：阶梯 1 的强档大形，固定构图；用中锋短笔（郭若虚「搶筆俱均」corpus Q6 L50）逐层叠搭；参考 §12-1「对临主山中段一块」L347。
- **动作**：按 P1 三档（[fan_kuan.md](../../dossiers/fan_kuan.md) L79–81 / 卡 L61–63）各做一张——
  - 弱：皴点稀疏、以轮廓＋淡染为主（雪景简笔式）；
  - 中：成片但不塞满、留结构线；
  - 强：千笔万笔密布、层层叠搭（《谿山行旅图》式满皴）。
  每张统计：短笔触长度（≤主山高 2%）、覆盖率、方向角标准差、单一方向平行排线占比。
- **自查量**：覆盖率 ≥60%（§8.2-1 L202 / 卡 L49）；方向角标准差 ≥20°；单一方向平行排线 <30%；**不得出现长线/披麻/斧劈/等宽线/平涂**。
- **可观察结果**：三档只看「皴点密度/方向」一个变量；强档仍读作「solid, weather-beaten mass」（卡 L23），方向离散而整体不紊乱。
- **越界警报（照录负向段 卡 L40–44 / [fan_kuan.md](../../dossiers/fan_kuan.md) L190–192）**：出现 `long wavy hemp-fiber strokes`（披麻，→黄公望）、`regular parallel hatching`（排线）、`color-separated pointillism (Seurat-style dots)`（西式色点分解）、`dry-brush feathering as the main texture` → 即退化，判失败。§8.1「退化处理」给追加词（[fan_kuan.md](../../dossiers/fan_kuan.md) L197）。
- **名称纪律**：此阶梯练习的是「北宋密点短笔操作」，**不写「练范宽的雨点皴」而默认该词为北宋术语**；括注「明人追认名」（§10-4 L268 / OVERTURNED §自审 B-2 L391）。
- **失败判据**：覆盖率 <60%；方向角标准差 <20° 或平行排线 ≥30%（成规整排线）；出现死黑平涂块（§8.2-3 L204）。
