## 1. 逐步展开（每步带 evidence grade + 定位 + 失效条件）

<a id="db-source-line-36"></a>
### D1 — 先选「立幅巨碑」而不是「横卷平远」 `[归纳]`
- **先选**：竖式立轴（高宽比 ≥1.5:1）、单主峰中轴耸立、占高约 2/3、两肩陪峰、近—中—远三段。
- **牺牲**：横式长卷、平远群峰、对称框、西式单点透视（`--no western single-point perspective / vanishing point / symmetrical framing`，卡 L38–39）。
- **为什么**：`§1-1 L29` 徐悲鸿「一山頭，幾佔全幅面積三分之二」+ 赵孟頫「大圖闊幅，山勢逼人」（corpus Q18 L134–138）+ NPM 2021「巨碑式山水畫的典範」（§7-8 L159）是**观察对象**；本项目把「压迫」操作化为 §8.2-2 ≥60% 画高、重心 ≤10% 宽（`[归纳]`）。
- **何时失效**：一旦改横卷/群峰并置即进入黄公望分工条款（§3.1 L67 构图轴、L70 判据②、L71 两卡互禁「纵向巨碑主山」）；「平远/阔远」不是本模块目标。
- **grade**：`[归纳]`（决策/阈值）/ `[史料]`（古典表述）/ `[研究]`（徐悲鸿、NPM）。定位：[fan_kuan.md](../../dossiers/fan_kuan.md) L29、L67、L70、L203；[fan_kuan.md](../../dossiers/_corpus/fan_kuan.md) L134；卡 L50、L19–21。

<a id="db-source-line-43"></a>
### D2 — 把主峰「顶到上缘」再谈其它 `[归纳]`
- **先选**：最大山体连通域高度 ≥60% 画高、顶部距上缘 ≤5%（或直抵）、水平重心与中线偏差 ≤10% 宽（§8.2-2 L203）；P2 强档（L86）。
- **牺牲**：大面积留天、偏心构图、主峰被云雾切断。
- **为什么**：巨碑压迫依赖「一个不可绕过的最大连通域」；`§8.1` 正向段「one colossal central peak … occupying about two thirds of the height, flanked by lower shoulders」（卡 L20–21）。
- **何时失效**：P4 强档「多带云雾、山体如浮」（L96）会在主山内部制造亮带、切断连通域 → 与 §8.2-2「顶部距上缘 ≤5%」+ §8.2-1「主山 ≥60% 短笔覆盖」冲突（FK-CE-01 推演第 1–2 条，`counterexample.md` L20–21）。
- **grade**：`[归纳]`。定位：[fan_kuan.md](../../dossiers/fan_kuan.md) L203、L86、L96；卡 L50、L68、L78；`AUDIT-fan_kuan/counterexample.md` L20–21。

<a id="db-source-line-50"></a>
### D3 — 山体量感全部押在「密点短笔」上 `[归纳]`（brief 重点①）
- **先选**：中锋短笔（长 ≤主山高 2%）、千笔万笔逐层叠搭、方向离散（角标准差 ≥20°、单一方向排线 <30%）、覆盖山体 ≥60%（§8.2-1 L202）；P1 默认强（L78）。
- **牺牲**：披麻长线、等宽刻线、色块调制、大笔触平涂、规则排线、西式色点分解。
- **为什么**：郭若虚《圖畫見聞誌》「峯巒渾厚，勢狀雄強，**搶（上聲）筆俱均**，人屋皆質者，范氏之作也」（corpus Q6 L50，`[史料]` 同代 1085 判语）；刘芳如放大检视「中鋒短線，千筆萬筆，逐層疊搭，線條的方向也並不一致，但整體卻毫不紊亂」（§2-1 L42，`[研究]`）；NPM 著录「皴法：雨點皴」（§7-1 L152，`[史料]`）。
- **术语决策（OVERTURNED 携带）**：操作者用的是**北宋已有的密点短笔**；「雨点皴」是**明代**陈继儒《妮古录》、唐志契《绘事微言》、汪珂玉《珊瑚网》、朱谋垔《画史会要》始见的名称（§10-4 L268；`AUDIT-fan_kuan/RESULT.md` §4.2 artouch 原文逐字）。**决策里不能出现「范宽决定用雨点皴」**——那是把后起术语塞进北宋人的意图。`FK-S1-02`（`claim_evidence_map.csv` L3）= **partial**：操作有据、名称不成立。**FK-B-02**（L91）= **conflict / OVERTURNED**，本 shard 保持为开放项（见 §3）。
- **何时失效**：① 覆盖率 <60% / 方向角 std <20° / 平行排线 ≥30%（§8.2-1 失败）；② 出现 `long wavy hemp-fiber strokes`（披麻→黄公望 §3.1 L66）、`uniform-width clean outlines`（→北斋 §3.1 L72）、色块调制（→塞尚 §3.1 L73）；③ `color-separated pointillism (Seurat-style dots)`（卡 L42 负向）。
- **grade**：`[归纳]`（阈值/档位/决策）/ `[史料]`（搶筆、NPM 著录）/ `[研究]`（刘芳如）。定位：[fan_kuan.md](../../dossiers/fan_kuan.md) L202、L30、L42、L78–81、L268；[fan_kuan.md](../../dossiers/_corpus/fan_kuan.md) L50；卡 L49、L60–63、L40–44；`AUDIT-fan_kuan/RESULT.md` §4.2；`claim_evidence_map.csv` L3/L91。

<a id="db-source-line-58"></a>
### D4 — 浓墨但必须「分层」，主动设退化上限 `[归纳]`
- **先选**：湿笔浓墨层层渍染、深色像素 25–60%、明度直方 ≥3 带、禁内部 std<5% 平涂块（§8.2-3 L204）；P3 默认中–强（L88）。
- **牺牲**：淡墨清爽、纯黑死墨、灰平、青绿重彩（`--no blue-green mineral pigments / saturated color`，卡 L37、L185）。
- **为什么**：米芾《畫史》「深暗如暮夜晦暝，土石不分」（corpus Q11 L85）、「晚年用墨太多，土石不分」（Q10 L78）是同代 `[史料]` 描述；NPM《临流独坐图》「水墨層加漬染，用墨甚濃」（§2-2 L43）。本项目把它操作化为「浓但有 3 层、不许平涂」。
- **何时失效（自我退化）**：P3 强档注「注意上限——**『土石不分』为退化**」（L91），而 Q10/Q11 把「土石不分」当范宽**实有**特征 → 规则集自己把逼近史料的强档判为退化（FK-CE-01 第 4 条，`counterexample.md` L23）。这是 `[inference]` 纸面张力，**未渲染、不推翻规则**（`counterexample.md` L27）。
- **grade**：`[归纳]`（阈值/退化注）/ `[史料]`（米芾/NPM）。定位：[fan_kuan.md](../../dossiers/fan_kuan.md) L204、L43、L88–91；[fan_kuan.md](../../dossiers/_corpus/fan_kuan.md) L78、L85；`counterexample.md` L23、L27。

### D5 — 留「一条」山腰云雾带，而不是满幅云雾 `[归纳]`
- **先选**：≥1 条水平亮带（亮度 ≥纸色 90%）、横贯 ≥60% 宽、位于画高 35–60%、面积 8–25%、带内连续墨线 ≤3%（§8.2-4 L205）；P4 默认中（L93，8–15% 一条）。
- **牺牲**：满幅云雾、多带、雾遮全山、空气透视全覆盖（`--no aerial perspective haze covering everything`，卡 L39）。
- **为什么**：NPM「與山石成虛實之呼應，凝重中有靈秀之韻」（§2-6 L47）；2021 特展「密密點畫…那道從天而降的懸絲瀑布」之外，云雾是「凝重中的空气」（§1-3 L31 三段式）。
- **何时失效**：P1 强（满皴 ≥60%）与 P4 强（多带 ≥15%）作用于**同一像素集合**时互斥——亮带处不许墨线、满皴要求密点（FK-CE-01 第 2 条，`counterexample.md` L21）；§8.1 退化处理明写「满幅云雾 → 追加 `a single horizontal mist band only, mountain clearly readable`」（L197）。
- **grade**：`[归纳]` / `[史料]`（NPM）。定位：[fan_kuan.md](../../dossiers/fan_kuan.md) L205、L47、L93–96、L197；`counterexample.md` L21。

### D6 — 用「方折 + 密林冠 + 水际大石」给山体立骨 `[归纳]`
- **先选**：轮廓折角 60–120° 占拐点 ≥50%、恒定曲率长弧 ≤30% 周长（§8.2-7 L208）；山顶缘 10% 高带作深色密林（§1-4 L32）；水岸 ≥1 块巨石宽 ≥15%（§1-5 L33）；P6 默认强（L103）。
- **牺牲**：圆润长弧、柔和曲线、无骨坡脚。
- **为什么**：米芾《畫史》「山頂好作密林…水際作突兀大石」（corpus Q9 L71，`[史料]`）；NPM「全幅以方折線條鉤勒輪廓，再藉短筆皴畫土石質感」（§2-3 L44）。
- **何时失效**：圆润曲线退化 → §8.1 追加 `angular faceted contours, axe-cut corners`（L197）；把「矾头密林」画成装饰性花木即触负向 `decorative prettiness / sweet flowers`（卡 L37）。
- **grade**：`[归纳]`（阈值）/ `[史料]`（米芾/NPM）。定位：[fan_kuan.md](../../dossiers/fan_kuan.md) L208、L32–34、L44–46、L103–106、L197；[fan_kuan.md](../../dossiers/_corpus/fan_kuan.md) L71；卡 L55、L85–88。

- **先选**：垂直亮线宽 ≤画宽 1%、高 ≥画高 8%、亮度 ≥纸色 95%、位于山体上 1/3–1/2 裂隙（§8.2-5 L206）；人物/驴 ≤1.5% 画高、总数 ≤8、全部下 1/4、面部特征 ≤3px（§8.2-6 L207）；P5 默认强=渺小（L98）。
- **牺牲**：大人物、叙事动作、面部特写、多瀑布、推拉镜头、帧间闪变（§8.2-8 L209）。
- **为什么**：NPM「近景渺小行旅與主山巍峨崇高的對比」（§7-1 L152）；米芾「溪出深虛，水若有聲」（corpus Q10 L78）；NPM 2021「從天而降的懸絲瀑布」（§2-7 L48）。点景越小，巨碑越大——尺度是压迫机制的另一半。
- **何时失效**：`--no human figures larger than a fingertip / close-up faces / narrative action`（卡 L40–41）；动画时云雾漂移 ≤0.5%/秒、瀑布水线水平位置固定、帧差 ≤1%（§8.2-8 L209）。
- **grade**：`[归纳]` / `[史料]+[研究]`。定位：[fan_kuan.md](../../dossiers/fan_kuan.md) L206–209、L36–37、L48、L98–101、L152；[fan_kuan.md](../../dossiers/_corpus/fan_kuan.md) L78；卡 L53–54、L80–83。
