## 2. 重点作品及来源（已有 §12 的练习入口）

- **《黄色基督》**：dossier §12 同名条目；以六色（含黑）、平涂、不使用渐变和统一轮廓为练习约束。练习 G-E1/G-E2 是项目教学改编，不是原作测量。
- **《布道后的幻象》**：dossier §12 同名条目与 corpus #5（本地标自述）；现实听众与想象搏斗的分区、非自然色与主题关系用于 G-E3。
- **《死者的幽灵》**：dossier §12 同名条目；保持人物较静，将不安的表达任务放在背景色／光中，可作为 G-E3 的迁移分支，未证实能引发特定观者反应。

证据等级分开：corpus #3/#5 的自述、#26 的 Sérusier 转述，均保留本地源分级；dossier 的作品解读按其原等级引用；下面练习与验收预测全部为本项目 `[归纳]`／proposed。外部引文真实性未在此重新核实。

## 4. 三个具体 proposed 练习（未执行；效果未评价）

<a id="db-source-line-59"></a>
### G-E1 基础：六色平涂草图
- **输入／来源**：dossier §12《黄色基督》；自建三形体静态布局，预先列六个色值（含黑），固定画幅与形状。
- **操作／提交**：用这六色平填，不使用渐变；交区域—色值表、草图和 R1/R3 的适用说明。此处不要求宗教物件，也不宣称满足全部风格条件。
- **反馈／常见错**：检查是否偷偷增加颜色／渐变；无实际像素数据时只记录构造约束，R1 方差及点阵统计为未测，不填 PASS。先修一个超出条件的区域再检查。
- **迁移**：保持色板和构造约束，把人物替换为静物，记录哪些形式关系可保留、哪些主题含义已不再主张。

<a id="db-source-line-65"></a>
### G-E2 进阶：轮廓覆盖率局部 A/B
- **输入／来源**：同一 G-E1 构图与 dossier §8.2 R2。固定色板、布局、全部形状边界、画幅、暗线色值和线宽；预先声明“主要形体边界”的总长度及计数方法。
- **操作／提交**：A 给预定边界的 80% 加暗轮廓，B 仅将覆盖改为 40%；线宽和暗度保持在所选 R2 条件内（源阈值仍未校准）。交 A/B 规格、标注的轮廓段及覆盖分子／分母。当前是待执行设计，80/40 为构造目标，非已测结果。
- **正／负预测**：在实际长度复核且 R2 其他条件相同后，A 预期满足 ≥60% 覆盖，B 预期不满足。这里只检验 R2 覆盖条件；B 不等于整图“不是 Gauguin”。若删线同时改变形状或色板，恢复固定条件再比。
- **迁移／边界**：换一组形状重新定义边界分母再做；源 §4 的 P1/P2/P3 至少两项中档口径保留。静态图不能证明 P6 多源合成工作流。

<a id="db-source-line-71"></a>
### G-E3 比较：可替换对象与被声明的色彩—主题关系
- **输入／来源**：dossier §12《布道后的幻象》、corpus #5；先写一个“现实观察者／想象事件”的短 brief，再做分区与非自然色的对应表。corpus #3 又允许题材作为线色和谐的借口，两种目标不能合并成普遍宗教要求。
- **操作／提交**：自建两区草图，标出至少两处自然色替换及其表达理由；交 brief—区域—颜色—关系表。若选择 R7，再明确色区面积与源所选主题锚点；其他非宗教表达可研究，但不得自动称为原 R7 全部通过。
- **反馈／常见错**：正例保留自己声明的关系；负例可保持像素规格而删除／错配关系表，预计只使“brief 对应可追溯”失败，并不证明观者必然失去某感受或整图风格失败。仅写正确器物名不构成关系证据。
- **迁移**：更换观察者／事件对象时保留所选角色关系；或者切换为《死者的幽灵》的背景情绪练习并重新写目标，不再沿用前一关系的成功声明。全部仍为 proposed。

## 6. 常见失败（F1–F5）

- **F1 把物件或形式单独当完整机制**：画对器物名称不证明风格成立；名称可替换，但若选择 R7，仍须保留所声明的颜色—主题关系。形式练习可以排除语义结论，不能声称已检验被排除的部分（corpus #3/#5；dossier §8.2 R7）。
- **F2 把 `[归纳]` 阈值当已实测**：练习自查 ≠ 原作像素测量（分母＝假想参考帧）。
- **F3 混写等级**：`[自述]` 与 `[归纳]`/`[reported speech]` 不得并成一句、不得反推心理。
- **F4 把反例当史实证伪**：8 条为规则边界清单／`[inference]` 纸面设计，非独立反例实测。
- **F5 把 open 写成已收口**：conflicts 命中、外部取证 partial、权利漂移一律携带。
