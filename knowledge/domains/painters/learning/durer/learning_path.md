### 台阶 1 — 观察日课：先看见「灰是线做的」而不是「灰是涂的」

- **观察对象**：《大草坪》1503 / 《野兔》1502（§12-3/4）。
- **创作决策**：画之前先决定「本幅不允许任何实心灰面」——这是丢勒机制的第一取舍（牺牲「快捷的涂灰」，换「可印刷、可复制的线密度」）。依据 §1-1/§1-10（dossier L29/L38）、§8.2-1（module L64）。
- **机制**：两色媒介的「假灰」——真实灰阶像素=0，灰值由排线频率等效。`[归纳]`（媒介事实见 §2-3 L46）。
- **参数**：P1 排线密度梯度（默认 70%，弱 20–30%「仅暗部加单向平行线」→ 强 80–95%「≥3 层多方向交叉、暗部线距≤1.5px」，module §4 L77）。
- **一次可做的练习**：取一丛真草逐叶画 ≥15 片、每片自带投影，不许概括成「一团绿」（§12-4 练习①）；蹲到草丛高度再写生一次（练习②）。
- **反例**：把暗部涂成灰块 / 用喷枪做柔和渐变 → 直接违反 §8.1 负向段 `--no greyscale gradients, --no grey flood fill`（module L36–L40）。
- **自检**：2×2 下采样后仍读得出草叶纹理（§12-4 练习③）；放大后应全是线、无像素级灰面（§8.1 中文说明 L201 核对①）。

<a id="db-source-line-73"></a>
### 台阶 2 — 排线体系 I：明度→线密度的单调映射

- **观察对象**：《亚当与夏娃》1504 躯干（§12-5）；《骑士》1513 马后腿（§12-6）。
- **创作决策**：先把画面分成 5 级「明度地图」，再决定每级用几层线、线距多少；**先定 s，再落线**，不是边画边补。`[归纳]`（§12-7 练习②原型）。
- **机制**（brief 重点 ①核心）：`s = lerp(8px, 1.2px, 1−L)`，线宽恒定 1.5–2px；层数规则 L>0.75→0–1 层 / 0.35<L≤0.75→2 层 / L≤0.35→≥3 层（module §8.2-1/3 L64/L66）。
- **参数**：P1（70%）、P4 细节密度（默认 80%，自然研究 90%/叙事 55%，module L80）。
- **一次可做的练习**：放大临摹躯干排线 1 处（≥3 层），标注每层方向角（§12-5 练习②）；约束练习「只用 3 种排线方向画一件金属物，不得涂黑」（§12-6 练习②）。
- **反例**：暗部出现单色实心填充 >5% 面积（§8.2-3）；缩略图出现「新的实心区」（§8.2-7 L70，说明原图用了填充而非排线）。
- **自检**：任取两个 16×16 区块，若块均值 L₁<L₂ 则 s₁≤s₂（单调性处处成立，§8.2-1 自查句）；2×2 下采样后实心黑 ≤8%、纯白 ≤35%（§8.2-7）。

### 台阶 3 — 排线体系 II：方向场 / 收锋 / 缩略图一致性

- **观察对象**：《野兔》毛流方向场（§12-3）；《骑士》质感区分（§12-6）。
- **创作决策**：排线方向要「包裹形体」而非「平铺网格」；每根线中段鼓、端点尖（burin 推刀签名）。允许等宽线**仅限**轮廓线与结构线。`[归纳]`
- **机制**：主方向 = 形体等高线切向 ±(30°–45°)，同形体 ≥2 段、段差 ≥25°，交叉层夹角 ∈[25°,50°]（§8.2-2 L65）；线端收锋两端宽 ≤ 中段 30%（§8.2-4 L67），§4 P2 强档单线宽变化 2–3 倍（module L78）。
- **参数**：P2 线端收锋（默认 65%）、P3 轮廓硬度（默认 85%，弱档「边缘柔化、允许 2–4px 过渡」可对接达芬奇柔和轴，module L79）。
- **一次可做的练习**：先画毛流方向图（≥6 区），再在图上做 3 层交叉排线（§12-3 练习①）；A5 水彩/水粉「褐色薄底→明暗→细笔毛发→白粉高光，眼部画反光」（练习②）。
- **反例**：`--no uniform line weight`（等宽线稿）；「数码灰渐变」；「软边油画」；「照片感」——§8.1 中文说明 L203 给 4 条退化处理追加快照。
- **自检**：缩到 25% 仍能看出「毛是顺的」（§12-3 练习③）；轮廓抗锯齿过渡 ≤1px、轮廓线宽 ≥1.5× 内部排线（§8.2-5 L68）；相邻帧线距变化 ≤10°（§8.2-8 L71，动画时）。

### 台阶 4 — 比例几何机制（brief 重点 ②）

- **观察对象**：《亚当与夏娃》1504（1:7.4）、《自画像》1500 中轴对称、《书斋中的圣哲罗姆》1514 透视盒、《忧郁 I》魔方阵/截角菱面体。

- **一次可做的练习**（照录 §12，不新增）：① 以 7.5 头身重建 Adam 站姿骨架与原图同尺寸叠比（§12-5 ①）；② 镜前正面自画像「先中轴＋眉/眼/鼻底/嘴四横线，再五官，最后头发，擦改 ≤3 次」（§12-2 ①）；③ 先只画透视线框（消失点、地砖/家具盒）再放物件（§12-7 ①）；④ 圆规＋直尺画截角菱面体一次、重建 4×4 魔方阵并验算 34（§12-8 ②③）。

### 台阶 5 — C-07 组合边界（brief 必携带，正本 L136–L147）

- **观察对象**：把丢勒模块与北斋模块并排（`conflicts.md` §2 L136–L147 正本；[durer.md](../../modules/durer.md) L90 C-07 注记；[durer.md](../../dossiers/durer.md) §6 L149/§8.1 L204「与北斋分工」）。
- **创作决策（硬边界，内化）**：
  1. **着色系统二选一、不可拆分**（L145）：二者都是「全画面」机制，无自然分区（N4 L314–L315 判别：作用于同一全帧统计量 → 不可拆）。以丢勒为主 → 北斋只贡献构图类参数（P2 非对称 / P3 尺度对比 / P6 负空间），其 §8.2-1/-6 表面规则**整条移除**（N3 L312：辅模块在冲突轴上的 §8.2 规则整条移除，不是调档）；以北斋为主 → 丢勒只贡献题材/符号堆叠（P5）与几何秩序（P6）。
  2. **明确禁止**「丢勒排线 + 北斋平涂」拼接（L146）：会得到「线稿上贴色块」第三种风格，两条规则都判不合格。
  3. **线宽轴**（L147）：两者都不持有时归 Lane B 08 卡「线宽不变」（near-miss #6，§4 L352）。
- **机制**：丢勒明暗只能由排线产生（禁实心填充），北斋明暗只能由平涂色块产生（禁排线）；线宽子冲突 2–3 倍变化 vs ≤30%（L142/L143）。AUDIT-durer §5.1 已判「C-07 成立（supported）」。
