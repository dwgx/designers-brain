## §1 机制 A：版画排线体系（brief 重点 ①）

<a id="db-source-line-26"></a>
### M1 — 明度→线密度单调映射（核心机制）
- **机制**：灰由线密度合成，真实灰阶像素=0；`s = lerp(8px, 1.2px, 1−L)`，线宽恒定 1.5–2px（1000px 宽参考帧）。`[归纳]`（媒介事实 `[研究]`：dossier §1-10 L38、§2-1 L44）。
- **参数**：§8.2-1（module **L64** / dossier **L208**）；P1 排线密度梯度（module §4 **L77**，默认 70%，弱「仅暗部单向平行线、线距≥6px」/ 强「≥3 层多方向交叉、暗部线距≤1.5px」）。
- **失败条件**：任取两个 16×16 区块若 L₁<L₂ 但 s₁>s₂（单调性被破坏）；画面出现像素级灰面（即用了填充）。
- **可复跑自查**：`取块均值 L → 算 s → 验证 s₁≤s₂`；§8.1 中文说明 L201 ①「放大后应全是线，无像素级灰面」。

<a id="db-source-line-32"></a>
### M2 — 排线方向场（包裹形体）
- **机制**：主方向 = 形体等高线切向 ±(30°–45°)；同形体 ≥2 段、段间差 ≥25°；交叉层与主层夹角 ∈[25°,50°]。`[研究]` 定义（dossier §2-2 L45）+ `[归纳]` 角值。
- **参数**：§8.2-2（module **L65** / dossier **L209**）。
- **失败条件**：全局单一方向平铺；同形体方向段 <2 或差 <25°；交叉角不在 [25°,50°]。
- **可复跑自查**：在曲面上标 ≥2 段方向并量角；§12-3 ①「先画毛流方向图 ≥6 区」。

<a id="db-source-line-38"></a>
### M3 — 层数规则 / 实心填充上限
- **机制**：L>0.75→0–1 层；0.35<L≤0.75→2 层；L≤0.35→≥3 层；任何区域单色实心填充 ≤5% 画面面积（画框/边线例外）。`[归纳]`
- **参数**：§8.2-3（module **L66** / dossier **L210**）。
- **失败条件**：暗部一涂了之（实心填充 >5%）；层数与 L 不匹配。
- **可复跑自查**：按 L 直方图分桶 → 数每桶层数；量实心连通域面积占比。

<a id="db-source-line-44"></a>
### M4 — 线端收锋（burin 签名）
- **机制**：每条排线两端宽 ≤ 中段 30%；等宽线仅限轮廓/结构线；§4 P2 强档单线宽变化 2–3 倍（默认 65%）。`[研究]` 工艺（dossier §2-3 L46）+ `[归纳][UNVERIFIED]` 量化（§1-3 L31 自承「量化值未实测」）。
- **参数**：§8.2-4（module **L67** / dossier **L211**）；§4 P2（module **L78** / dossier **L77**）。
- **失败条件**：`--no uniform line weight` 被违反（等宽线稿）；端点不收锋。
- **可复跑自查**：量单线中段宽 vs 端点宽；退化处理追加 `lines swell and taper, varied line weight`（§8.1 L203）。

<a id="db-source-line-50"></a>
### M5 — 轮廓连续性 / 硬轮廓
- **机制**：轮廓线为全图最连续（最长连续段 ≥ 形体周长 60%），线宽 ≥1.5× 内部排线，抗锯齿过渡 ≤1px；无 sfumato（§1-4 L32）。`[归纳]/[研究]`
- **参数**：§8.2-5（module **L68** / dossier **L212**）；P3 轮廓硬度（module **L79**，默认 85%，弱档「边缘柔化、2–4px 过渡」可对接达芬奇柔和轴）。
- **失败条件**：软边油画、羽化过渡 >1px、轮廓比内部线还细。
- **可复跑自查**：Canny 边缘量过渡宽度；退化处理追加 `hard engraved contour, no soft edges`（§8.1 L203）。

<a id="db-source-line-56"></a>
### M6 — 细节下限 / 全幅均匀
- **机制**：主体内部排线 ≥200 根（512×512），毛发/草叶 ≥300 根独立线段，背景纯空白 ≤10%；全幅无「低细节糊弄区」（§1-5 L33）。`[归纳]/[研究]`
- **参数**：§8.2-6（module **L69** / dossier **L213**）；P4 细节密度（module **L80**，默认 80%，自然研究 90%/叙事 55%）。
- **失败条件**：背景大片留白、主体概括成「一团」。
- **可复跑自查**：数独立线段；§12-4 ①「逐叶 ≥15 片、每片自带投影」。

<a id="db-source-line-62"></a>
### M7 — 缩略图一致性（防「填充冒充排线」）
- **机制**：2×2 下采样后实心黑 ≤8%、纯白 ≤35%；排线应在缩小时自然融合为灰，**不得出现新的实心区**（出现即说明原图用了填充而非排线）。`[归纳]`
- **参数**：§8.2-7（module **L70** / dossier **L214**）。
- **失败条件**：下采样后冒出实心黑块 = 原图有填充。
- **可复跑自查**：下采样 → 量实心黑/纯白占比；§12-4 ③「2×2 下采样后仍读得出草叶纹理」。

<a id="db-source-line-68"></a>
### M8 — 帧间稳定性（动画扩展）
- **机制**：相邻帧同区域线距变化 ≤10%、方向变化 ≤10°；无运动解释的明度跳变 >0.1 判「排线闪烁」不合格。`[归纳]`
- **参数**：§8.2-8（module **L71** / dossier **L215**）。
- **失败条件**：静态区明度跳变被误判为运动。
- **可复跑自查**：帧差图（Δ）+ 线距/方向时序量测。

> **M1–M8 全表证据级**：规则文本来自 [durer.md](../../modules/durer.md) §8.2 L64–L71 与 [durer.md](../../dossiers/durer.md) §8.2 L208–L215（逐字一致，AUDIT-durer §1 已核 sha `ad49cd77…` / `4f5be577…`）；档位来自 module §4 L77–L82。**全部为 `[归纳]`，dossier §10 L269 自陈未经真实渲染器跑过**。

## §2 机制 B：比例几何机制（brief 重点 ②）

<a id="db-source-line-80"></a>
### G1 — 数理秩序可见（作品层）
- **机制**：头身比建构（1504 Adam 1:7.4 → 1507 Eve 1:8.2）、透视消失点明确（*Melencolia* 消失点分彩虹直径为黄金比）。`[研究]`（dossier §1-8 L36，[R8][R2]）。
- **失败条件**：自由手比例、无消失点、比例不可叠比。
- **边界**：1:7.4→1:8.2 出自 [R8] 转引、未回 Prado 原始著录核对（§10 L271）；透视装置细节 `[UNVERIFIED]`（§10 L267）。

<a id="db-source-line-85"></a>
### G2 — 《测量四书》1525（理论工具）
- **机制**：四册 = 线性几何（螺线/蚌线/外摆线）、正多边形、建筑与字体、多面体（5 柏拉图体 + 7 阿基米德体）；**第一部面向成人的德语数学书**，后被伽利略/开普勒引用。`[研究]`（dossier §2-8 L51，[R1]）。
- **配套自述**：「没有几何，无人能成为绝对的艺术家」「方法要写成可教、可复制的书」（§3-3/4 L63–L64，`[自述]` [R14] 献词）。

<a id="db-source-line-89"></a>
### G3 — 《比例四书》1528（比例建构法）
- **机制**：维特鲁威为底 + 自述「实测二到三百名活人」；第一册 5 组、第二册 8 组体型（按总高分数表达），第三册修改比例原则（含凸/凹镜数学模拟）与面相学，第四册运动论；把「美」转成「可测量的建构问题」。`[自述]+[研究]`（dossier §2-9 L52、§3-6 L66）。
- **立场边界**：§3-2 L62「美没有终审，只有上帝知道」——拒绝 Alberti 客观美、主张基于多样性的相对美。**不得把比例机制写成「绝对客观美」**。`[自述]`（[R16] 转引 1994 二手文献）。

<a id="db-source-line-93"></a>
### G4 — 几何秩序参数 P6（操作化）
- **机制**：弱「自由手比例」→ 中「明确头身比/透视结构」→ 强「圆规直尺式建构痕迹 + 测量级比例 + 单点透视」，默认 60%。`[归纳]`（module §4 **L82** / dossier §4 **L81**）。
- **失败条件**：强档无建构痕迹；弱档硬套单点透视。
- **可复跑自查**：§12-5 ①「7.5 头身重建 Adam 站姿骨架与原图同尺寸叠比」；§12-7 ①「先只画透视线框（消失点、地砖/家具盒）再放物件」；§12-8 ③「圆规＋直尺画截角菱面体一次」+ ②「重建 4×4 魔方阵验算 34」。

<a id="db-source-line-98"></a>
### G5 — 建构式对称与符号几何
- **机制**：中轴 + 比例控制（1500 自画像）；≥8 件静止陈列符号（*Melencolia I*：罗盘、球、截角菱面体、梯、铃、沙漏、天平、魔方阵…）。`[研究]`（§1-7 L35、§12-2 L366、§12-8 L395）。
- **参数**：P5 象征堆叠度（module **L81**，默认 50%，寓意画 85%/肖像 5%）。
- **可复跑自查**：§12-2 ①「先中轴＋眉/眼/鼻底/嘴四横线，再五官，最后头发，擦改 ≤3 次」；§12-8 ①「符号清单 ≥10 行（物件/位置/含义/出处）」。

> **G1–G5 的证据分层（关键）**：G2/G3 的方法论句可标 `[自述]`；G1/G5 的作品观察为 `[研究]`；G4 的 P6 档位是 `[归纳]`。**没有任何一条排线数值规则能标 `[自述]`** —— 这是 how-to-think.md §3 的硬分离依据。

## §3 机制 C：C-07 冲突机制（brief 必携带，正本 L136–L147）

<a id="db-source-line-109"></a>
### C1 — 互斥轴：表面着色系统
- **丢勒侧**（实测 module **L64/L66/L70** / dossier **L208/L210/L214**）：排线是唯一明暗手段；`s=lerp(8px,1.2px,1−L)`；实心填充 ≤5%；缩略图不得出现新实心区。
- **北斋侧**（实测 [hokusai.md](../../modules/hokusai.md) **L45/L50** / dossier **L199/L204**）：线宽恒定、同一元素内变化 ≤30%，无排线、无羽化；天空/水面单色平涂或留白 ≥35%。
- **子冲突**：丢勒 §4 P2 线端收锋 2–3 倍（module **L78** / dossier **L77**）× 北斋 §8.2-1 ≤30%（L45/L199）。
- **后果**（正本 L143）：同帧不可能同时满足，二者对「明暗怎么来」给出互斥的唯一解；硬冲突（总表 L38）。AUDIT-durer §5.1 判「规则文本无误，C-07 成立（supported）」。

<a id="db-source-line-115"></a>
### C2 — 不可拆判别（N4 / N3）
- **N4**（`conflicts.md` L314–L315）：作用于同一全帧统计量 → 不可拆、二选一；作用于可分空间区域/对象类别 → 可拆但须写死分区表 + 掩膜。C-07 两条都是「全画面」机制（L145），无自然分区 → 不可拆。
- **N3**（L311–L312，C-07 在其适用清单内）：组合卡附「轴所有权表」`轴名 | 持有模块 | 对方处置`；每轴单持有者；辅模块在冲突轴上的 §8.2 规则**整条移除**（不是调档）。
- **N1**（L305–L306）：反约束段与画风段一致性检查；**N6**（L323–L324）：色数计数口径（本卡不涉及，但 L88 点名）。
- **N9**（L332–L333）：逐帧自查表 = 主模块规则全集 + 辅模块非冲突轴规则；「冲突轴出现双标准」列为失败形态。

<a id="db-source-line-121"></a>
### C3 — 解法与禁止（正本逐条 carried）
1. L145：**着色系统二选一**。以丢勒为主 → 北斋只贡献构图类 P2/P3/P6，其 §8.2-1/-6 表面规则全部移除；以北斋为主 → 丢勒只贡献 P5 符号堆叠 + P6 几何秩序。
2. L146：**明确禁止**「丢勒排线 + 北斋平涂」拼接（「线稿上贴色块」第三种风格，两条规则都判不合格）。
3. L147：**线宽轴**两者都不持有时归 Lane B 08 卡「线宽不变」类 → near-miss #6（§4 L352，AUDIT-durer §5.3 判自洽）。
4. 口径提醒：dossier §6 L149 / §8.1 L204 的「前景单线剪影 + 背景排线塑形」是**同屏分工**（谁管形状、谁管密度），不等于 C-07 可拆分；L145/L146 的「全画面二选一」优先。

<a id="db-source-line-127"></a>
### C4 — 失败条件 / 自检
- 组合卡若同时出现「排线密度 s(L)」与「单色平涂 ≥35%」两行 → N9 失败（双标准）。
- 若把「同屏分工」误读成「可分区组合」→ 违反 L145 不可拆。
- 自检：填轴所有权表 → 逐条反约束×画风规则标 `一致/冲突`（N1）→ 冲突轴只留持有者一行（N9）。
