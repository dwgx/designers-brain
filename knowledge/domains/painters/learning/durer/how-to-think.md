## §0 一条总纲：两条机制谁先谁后

**先定「可测量的骨架」，再定「灰怎么由线来」，最后才往里放细节与符号。**

理由：丢勒留下的作者自述只支撑「几何/测量/著书」这一层（[durer.md](../../dossiers/durer.md) §3 L61–L66）；排线的数值规则（§8.2 八条、§4 六参数）全部是本项目 `[归纳]`，没有一条是丢勒自述。所以「像丢勒地思考」= 用他**自述过的方法论**（几何建构、测量、可复制）去组织一套**本项目归纳的**线密度规则；两者不能混称。

> 硬约束：本文件任何「丢勒主张/说过」只能落在 `[自述]` 句上（§3 L61–L66、§2-9 L52），不得把 `s=lerp(8px,1.2px,1−L)` 写成他的原话。

## §1 决策序（7 个检查点）

<a id="db-source-line-21"></a>
### D1 — 先选「灰的唯一来源」：排线，不是涂灰
- **先选**：本幅所有明度由线密度合成，真实灰阶像素 = 0（dossier §1-10 L38 `[归纳]`；§1-1 L29 `[研究]`）。
- **牺牲**：涂灰、喷枪、柔和渐变、摄影感这些「快捷的灰」。
- **为什么**：单色黑墨版画媒介 → 灰只能由线频率等效；且「可刻、线线分离、可印刷复制」（§2-4 L47、§12-1 L361）。
- **落地**：§8.2-1 `s=lerp(8px,1.2px,1−L)`（实测 [durer.md](../../modules/durer.md) L64 / dossier L208）；§8.1 负向段 `--no greyscale gradients, --no grey flood fill`（module L36–L40）。
- **检查点**：放大后应全是线，无像素级灰面（dossier §8.1 中文说明 L201 核对①）。

<a id="db-source-line-28"></a>
### D2 — 再选「可测量的建构骨架」：几何/比例/透视先于表面
- **先选**：中轴、头身比、消失点、几何体（截角菱面体、魔方阵）先建好，再挂线（§1-8 L36；§3-3/4/6 L63–L66）。
- **牺牲**：凭灵感的自由比例、无消失点的散点构图。
- **为什么（这是唯一有 `[自述]` 支撑的决策）**：「没有几何，无人能成为绝对的艺术家」「方法要写成可教、可复制的书」「以测量超越灵感」（dossier §3 L63/L64/L66）；《测量四书》四册 + 《比例四书》「实测二到三百名活人」（§2-8/9 L51–L52）。把「美」从主观争议转成「可测量的建构问题」（§3-2 L62 相对美立场）。
- **落地**：P6 几何秩序（默认 60%，强档圆规直尺式建构 + 测量级比例 + 单点透视，module L82）；§12 练习「7.5 头身重建」「先画线框再放物件」（L382/L392）。
- **检查点**：能指出消失点、能叠比头身骨架（§12-5 ①）。

<a id="db-source-line-35"></a>
### D3 — 决定「线怎么走」：包裹形体，不套网格
- **先选**：主排线方向 = 形体等高线切向 ±(30°–45°)，同形体 ≥2 段、段差 ≥25°，交叉层夹角 ∈[25°,50°]（§8.2-2，实测 module L65 / dossier L209）。
- **牺牲**：全局统一方向的平铺排线（省事但丢体积感）。
- **为什么**：交叉排线用「方向差」制造对比而非颜料（§2-2 L45 `[研究]`）；线随曲面弯曲才有「丝般柔软」的皮肤（§2-1 L44）。
- **落地**：先画毛流/曲面的方向场图（§12-3 ①「≥6 区」），再叠 3 层交叉线。
- **检查点**：同一形体上能数出 ≥2 个方向段且差 ≥25°。

<a id="db-source-line-42"></a>
### D4 — 决定「明暗预算」：先分 5 级明度地图，再定层数与线距
- **先选**：L>0.75 → 0–1 层；0.35<L≤0.75 → 2 层；L≤0.35 → ≥3 层（§8.2-3，实测 module L66 / dossier L210）；任何区域单色实心填充 ≤5%。
- **牺牲**：暗部「一涂了之」；大面积留白（背景纯空白 ≤10% 面积，§8.2-6 module L69）。
- **为什么**：暗部靠多层叠加而非涂黑，才能把明度两端都拉开（§2-1 L44）。
- **落地**：P1 排线密度梯度（默认 70%，强档 ≥3 层、暗部线距 ≤1.5px，module L77）；§12-7 ②「5 级明度地图 → 5 档线距」。
- **检查点**：任取两个 16×16 区块，块均值 L₁<L₂ 则 s₁≤s₂（§8.2-1 自查句，单调性处处成立）。

<a id="db-source-line-49"></a>
### D5 — 决定「线的签名」：收锋 + 硬轮廓
- **先选**：每根线中段鼓、端点成尖，两端宽 ≤ 中段 30%（§8.2-4，实测 module L67 / dossier L211）；等宽线**仅限**轮廓线与结构线；轮廓过渡 ≤1px（§8.2-5）。
- **牺牲**：等宽线稿的整齐感、sfumato 柔边。
- **为什么**：burin 推刀的工艺签名（§2-3 L46 `[研究]`；量化值 §1-3 L31 标 `[归纳]`+`[UNVERIFIED]`）；硬轮廓让形与形以线分隔、不用渐变（§1-4 L32）。
- **落地**：P2 线端收锋（默认 65%，强档单线宽变化 2–3 倍，module L78）；P3 轮廓硬度（默认 85%，module L79）。
- **检查点**：缩到 25% 仍看得出线端方向（§12-3 ③）；轮廓抗锯齿过渡 ≤1px。

<a id="db-source-line-56"></a>
### D6 — 组合前先做「轴所有权表」：C-07 是硬边界（brief 必携带）
- **先选（正本 `conflicts.md` L136–L147）**：**着色系统二选一、不可拆分**（L143/L145）。二者都是「全画面」机制，N4（L314–L315）判别：作用于同一全帧统计量 → 不可拆，二选一。
- **牺牲**：以丢勒为主 → 牺牲北斋的平涂/留白表面规则（其 §8.2-1/-6 整条移除，N3 L312）；以北斋为主 → 牺牲丢勒的排线明暗，只留 P5 符号堆叠 + P6 几何秩序（L145）。
- **为什么**：丢勒明暗只能由排线（禁实心填充）、北斋明暗只能由平涂（禁排线），同帧数学上不可同时满足（L143）。AUDIT-durer §5.1 已判 C-07 成立（supported）。
- **明确禁止**（L146）：「丢勒排线 + 北斋平涂」拼接 → 「线稿上贴色块」第三种风格，两条规则都判不合格。
- **线宽轴**（L147）：都不持有时归 Lane B 08 卡「线宽不变」类（near-miss #6，§4 L352）。
- **落地**：写 `轴名 | 持有模块 | 对方处置` 表（N3 L311–L312）；N1（L305–L306）逐条反约束 × 逐条画风规则标 `一致/冲突`；N9（L332–L333）自查「冲突轴上是否出现双标准」。
- **注意口径**：dossier §6 L149 / §8.1 L204 允许「前景单线剪影 + 背景排线塑形」的**同屏分工**（谁管形状、谁管密度），但这是「分工」不是「C-07 可拆分」；L146 禁的是同一区域既排线又平涂。别混读。

<a id="db-source-line-65"></a>
### D7 — 收束：署名、符号、可复制性
- **先选**：AD 花押 + 年份、≥8 件静止陈列的符号物（§1-7/§1-9 L35/L37；P5 默认 50%，module L81）。
- **牺牲**：空背景、「气氛」叙事（背景用密排线场闭合，§8.1 正向段 L186）。
- **为什么**：版画是「声誉与生计的引擎」（§3-8 L68）；花押维权（§2-11 L54）；「方法写成可教可复制的书」（§3-4 L64）。
- **检查点**：能列出 ≥8 件可点名符号（§12-8 ①「≥10 行符号清单」）。
