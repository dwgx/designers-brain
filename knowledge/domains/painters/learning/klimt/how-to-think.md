## 2. 逐展开（每步：先选 / 牺牲 / 为什么[分栏] / 何时失效 / 等级）

<a id="db-source-line-43"></a>
### D1 · 先定「画出来的表面」
- **先选**：把目标定为「一张装饰过的贵重物件表面」，而非通往空间的窗（`modules/klimt.md:19-22` §8.1 正向段「reads as a flat decorated surface, like a precious object, not a window into space」，`[归纳]` 提示词）。
- **牺牲**：空间纵深、线性透视、投射阴影、写实环境色（§8.1 负向段 `:222-227`）。
- **为什么（分栏，不混写）**：
  - `[归纳]`：dossier `:15` 一句话能力定位（「画出来的表面」+ 图案独立图层系统）是**项目能力标签**，用来给系统补 `装饰图案系统` / `金属/金箔材质` / `平面拼贴构图` 三块缺口（归属 expansion §2.2 G4，经 dossier 转述）。
  - `[研究]`：§1-4 平面化有 Attersee 风景「flattened to a single plane」的史料支撑（`:35` [R14][R12]）；§3-1「把画当贵重物件来造」有 Belvedere/馆藏研究支撑（`:62` [R3][R12]）。
  - **不写**：「克里姆特想否定西方透视传统」——这是从画面推思想史动机，属 `[推测]`，禁用。
- **何时失效**：任务要求可辨识空间纵深/写实场景/图解式透视时；或把「表面」误当成「只铺一层金色」（丢掉金箔材质层与图案图层两块，K1）。
- **等级**：`[归纳]`（定位）+ `[研究]`（平面化史实）；失效 `[归纳]`。

<a id="db-source-line-53"></a>
### D2 · 先规划「金属底层」再定构图边界
- **先选**：大面积金属底预先铺好，构图边界线随之预定；按 §2-2 的逐层顺序作业（浅色底 → 石墨构图 → 罩染固定 → 满铺黄铜箔 → 局部金/铂箔 → 棕树脂罩染 → 撒屑 → 笔线贴金浮雕）。
- **牺牲**：「边画边改背景」的自由度、后加金属底的可能（§2-3 改绘时「脚与草地画到了已铺金属底的背景上」正是代价，`[研究]`）。
- **为什么（分栏）**：
  - `[研究]`：§2-3「构图在许多部分由金属底面的边界线预先决定」需提前精确规划（`:49` [R1][R2]）；§2-2 逐层工艺来自 Jahn 修复研究（`:48` [R2]）。
  - `[归纳]`：dossier `:69`（§3-8）把这套整理成「精确规划 × 手工材质实验」的工作结构——**整理动作归本项目**，dossier 该行标 `[研究]`，不混为作者自述。
- **何时失效**：介质要求分层合成/分区掩膜（C-15 与 Lane B 色数卡组合、或近-miss #9 三选同屏分区）时，预先满铺让位于**显式材质层声明表**（`dossiers/klimt.md:115,231-232`）。
- **等级**：`[研究]`（工艺与规划史实）+ `[归纳]`（工作结构、失效条件）。

<a id="db-source-line-62"></a>
### D3 · 先划「不铺金属」的保留区
- **先选**：动笔前先标出肉体、头发、彩花、草地为保留区，不铺金属。
- **牺牲**：满幅统一金属覆盖、把人物一起贴金。
- **为什么（分栏）**：
  - `[研究]`：§2-4「肉体、头发、彩花、草地不铺金属；底稿与底布透过画面可见、UV 下呈紫色」（`:50` [R2]）——这是修复研究的观察，不是作者宣言。
  - `[归纳]`：§8.2-1 金属面积 ≥30%（默认档）、P1 三档是**逐帧判分阈值**（`:237,:83-86`）；把「保留区」翻译成「金属面积 <100% 的判据」是项目操作，**不声称克里姆特说过「≥30%」**。
- **何时失效**：纯装饰/无人物题材（Stoclet 马赛克横饰带 `:24`）时「保留肉体区」不适用；P1 强档 ≥50% 满铺时须显式声明档位，不与「保留区」默认口径混用。
- **等级**：`[研究]`+`[归纳]`；失效 `[归纳]`。

<a id="db-source-line-71"></a>
### D4 · 把图案当独立图层系统（**纯 `[归纳]` 步**）
- **先选**：图案层与金属层、写实层并列组织；图案不是背景、不是点缀。
- **牺牲**：「主体 + 背景」的单一图层观；图案只作点缀的用法。
- **为什么**：**`[归纳]`** dossier `:15`「把图案当独立图层系统来组织」、§3-2「装饰即内容」（`:63` 行内明标 `[归纳]`，依据 [R1][R6][R13]）、§4 用法句「P2/P5 定图案与写实如何对撞、P6 定装饰画 vs 寓言画」（`:114`）。**此步没有任何作者自述支撑「图案=情感载体」**——§3-2 是项目研究者从作品归纳的操作规则（AUDIT CSV:27 KL-3-2 标 `[归纳]`），不是克里姆特关于「爱之喜悦=花田与金晕」的自述。
- **何时失效**：图案区与主体区处理无差别（同线宽、同色阶层数、明度动态 ≤5%）→ 判马蒂斯 P4 域、换模块（`:92`、`:238`）。**不得**把「装饰即内容」写成「克里姆特认为装饰承载情感」的心理/意图句。
- **等级**：`[归纳]`（单一步，不夹 `[自述]`）。

<a id="db-source-line-78"></a>
### D5 · 定「双分辨率」分区
- **先选**：面孔/手用连续体积塑形，衣饰/背景/光环转平涂图案；边缘用细而肯定的轮廓线。
- **牺牲**：全画面统一渲染级别、在图案区做体积渐变。
- **为什么（分栏）**：
  - `[研究]`：§1-2 双分辨率共存（`:33` [R17][R1]，《吻》男女由图案差异区分身体）、§1-5 细而肯定的轮廓线（`:36` [R1] + `[归纳]` 对照）；§2-5《吻》改绘「加强女性轮廓与背线」（`:51` [R1]）。
  - `[归纳]`：§8.2-4 面孔/图案局部方差比 ≥2.0、同向亮度梯度段 ≥3（`:240`）、P5 落差 ≥1 渲染级（`:104`）——**数值全是项目阈值，非史料**（`:245`）。

### D6 · 空间只由遮挡与图案区块位置提供
- **先选**：画面压成单一平面；取近方形（0.8–1.25）、人物推到边缘由图案包围、主体包围盒 ≥60%。
- **牺牲**：焦点透视、空气/光影深度、非方形画幅的叙事展开。

### D7 · 收笔不解释（**唯一以 `[自述]` 为决策来源的一步**）
- **先选**：对作品的寓意不追加说明、不辩论；观者自行判断；本人不以自画像/文字自述占据画面。

- **为什么（分栏，严格只取言语记录）**：
  - `[自述转述]`（= `[reported speech]`）：1913 面对《死与生》《处女》「…hm, man kann sich dabei denken, was man will…」（`_corpus/klimt.md:26-31` Q3，Else Grüttel《Neues Wiener Journal》1913-02-11 记录，经 Belvedere 藏品论文注 23 转引；dossier `:64` §3-3 标 `[自述转述]`）。它是**访客转述的一句应答**，不是美学论文；风险：来源本轮未重访、德文逐字照录但语境为工作室访问。
  - `[自述]`（= `[self-written]`，按转引处理）：「我没有自画像……谁想了解我这个人——就该仔细看我的画」（`_corpus/klimt.md:10-16` Q1 c.1900 英译全文；dossier `:65` §3-4、`:121-123` §5-1）。**风险不消除**：德文原题与原刊未定位（`:99`、dossier `:296` §10-2），经 Whitford 1990 p.18 转引、Obelisk 英译，按「转引」口径，不升格为德文逐字原话。

- **何时失效**：任务明确要求 artist statement / 策展文字 / 教育性图注时「不解释」让步；**任何情况下都不得把它读成「克里姆特内向/神秘/刻意制造距离」的心理断言**。
- **等级**：`[自述转述]`/`[自述]`（决策来源，带转引与未定位风险标记）；失效 `[归纳]`。
