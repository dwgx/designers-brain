### 阶梯一：metal-leaf layer studies（金箔装饰层 / 材质层）
- **目标机制**：M1（§8.2-1 / §4 P1 / §2-1–4 工艺链）。
- **动作**：取 §0-1《吻》/§0-2《阿黛尔 I》为参照（`dossiers/klimt.md:20,21,48`），做 3 张同构图小稿（建议近方形，比例 0.8–1.25）；按 §2-2 逐层工艺的**顺序**记录而非只画结果：① 浅色底 + 石墨构图 → ② 预留肉体/头发/彩花/草地**不铺金属**（§2-4 `:50`）→ ③ 满铺金属底（箔块接缝、碎屑、罩染）→ ④ 笔线贴金形成浅浮雕纹样。三张只变 **P1 档位**（弱 <20% / 中 20–50% / 强 ≥50%，`:83-86`）与金属种类（黄铜/金/铂），**不许用平滑金色渐变代替箔块**。

### 阶梯三：division-vs-exclusive-criterion discipline（分工边界 + 组合自律）
- **目标机制**：M3 + M5（§8.2-2 / §4 P2/P4 / C-15 / N6 / near-miss #9/#10 / 5–10% 灰区）。
