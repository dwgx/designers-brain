## §1 前置知识（先具备什么，再开练）

1. **中西融合的定位**（`dossiers/lin_fengmian.md:L20` `[研究]`）：林风眠是「调和中西艺术」的倡导者与「彩墨画」创造者，与颜文梁/徐悲鸿/刘海粟并称「四大校长」。一句话能力定位（`:L22`）：「**把西方现代主义的形色结构（印象派/野兽派/立体主义）转译为水墨与彩墨的抒情语言**」。 capability 标签：`方纸布阵` · `块面线弦` · `墨彩调合` · `涂白叠白` · `民间瓷绘色` · `孤寂抒情`。
2. **材料转向**（`:L21`、`:L60` `[史料]/[研究]`）：1938 抗战重庆物资困难无法作油画 → 转向宣纸＋毛笔＋水墨＋水粉，此后为唯一主项；正式作画前铅笔淡稿经营位置并文字注明「何处用何色彩」，墨彩齐下、纸背托色、「惜纸如金」覆盖重画。
3. **三档分工的「不得混看」**（`§3.1 :L81–L100` `[归纳]`）：vs 吴冠中（师生线：林＝构图/色块，吴＝形式抽象）、vs 马蒂斯（色块：西方平面 vs 水墨色块）、vs 徐悲鸿（四轴：写实融合 vs 现代主义融合）——三条写死条款 + 判据 + 边界注，是开练前的「防越界」前提。
4. **语料底本**（`_corpus/lin_fengmian.md:L5–L6`）：30 条编号原话，分 self-written / self-spoken / reported speech / reception 四类，1930s 印刷文献保留繁体照录、转引逐条注明链条。其中 **#5「短長相補」、#9「忘記了時間，忘記了自然」、#16「折叠」、#21 四句话** 是「调和中西」与「戏曲折叠」的自述锚点。

## §3 要观察的机制（带定位与等级）

> 两个主轴（brief 强调点）+ 一个底层立场。全部操作半为 `[归纳]`，可回源的自述/史料另标。

**主轴 A｜中西融合 · 方纸布阵（brief「方纸鸿蒙」）** —— 形式壳是西方的，抒情核是水墨的。
- 方构图满幅（`:L38` `[研究]`）：画幅 1:1±5%、四方等量扩展、画满、常连签名位也无——「构成一统天下与大气磅礴之感」。可观察量：四边触满率、负空间低且为主动安排。
- 块面与线弦的二重唱（`:L39` `[研究]`）、墨彩调合「墨中叠彩，彩中叠墨」（`:L40`）、涂白「叠白法/白分五彩」（`:L41`）、民间瓷绘色（`:L42`）。
- 调和中西的底层立场（`:L70` `[自述]` + corpus #1/#5/#21）：「绘画底本质是绘画，无所谓派别也无所谓『中西』」「短長相補」「介绍西洋艺术，整理中国艺术，调和中西艺术，创造时代艺术」。**这是创作原则，不是心理描写**。
- 来源支撑（`:L55–L58` `[史料]`）：巴黎柯罗蒙工作室、北京/杭州艺专「中西画不分系」、抗战转水墨——「取（引入西方形色结构）→ 炼（以记忆与默记提炼母题）」两阶段（`:L217` `[归纳]`）。

**主轴 B｜戏曲人物变形机制（折叠 + 几何化）** —— brief 第二强调点。
- 自述锚点 corpus **#16**（`_corpus/lin_fengmian.md:L104–L107` `[self-spoken]`）：「像毕加索有时解决物体都折叠在一个平面上一样……一场一场的故事人物，也一个一个把它**折叠**在画面上，我的目的不是求物、人的**体积感**而是求**综合的连续感**」。版本差异：文汇报「體積感」/ HKMA 场刊「體質感」（`§10-5/L276`），引用以文汇报为准。
- 档案定义（`:L44` `[自述]`）：「把一场一场的故事人物折叠在画面上」= 人物组群平面化叠加 + 时空交错 + 无固定视点 + 无叙事时间线；借皮影几何强化几何化（`:L64` `[史料]/[研究]`：受关良影响看戏、带小本子画速写、用英文标注色彩特征）。
- 可观察半（`:L45` `[研究]`）：静物/桌面/门窗/瓶罐「像是压缩在斜面上」（塞尚式平面化）、透视有意错位 ≥1 处、追求「艺术构成中的几何秩序」；但几何被包在墨彩与抒情之内、**不作独立主题**（`§3.1 :L85` 边界注）。
- **变形 ≠ 写实**：与 vs 徐悲鸿四轴（`:L95`）对照——徐＝写实解剖/素描结构，林＝线描＋色块抒情；戏曲人物的变形是「平面化叠加 + 时空折叠」，不是解剖变形。
- 参数挂接：P6「折叠几何度」默认 50%（`:L113` `[归纳]`）；§8.2 规则 7「几何秩序规则」（`:L207`）；§4 越界警报⑤「零对象、纯抽象形式 → 越界康定斯基/赵无极侧」（`:L116`）——折叠仍须 ≥1 母题（§8.2 规则 6）。

## §4 具体练习（三阶梯；全为 `[归纳]` 建议练习）

顺序 = 观察 → 决策 → 机制 → 参数 → 一次练习 → 反例 → 自检。每阶梯的「怎么练」直接复用 §12，不自编作品、不声称效果。

**阶梯 1｜识读：方纸布阵 + 色从墨里长出来（先立「是不是林风眠」）**
- 观察：§12 第 1/2/3 件（仕女） + §8.1 生成后自查三件事（`:L196`）：① 正方形满幅、无签名位/空角？② 色块从墨里生长（柔边渗化）而非硬边平涂？③ 白色是否主动涂上去、与留白并用？
- 决策：按 §4 用法（`:L115`）P1 方纸布阵 85% + P2 墨彩调合 70% 起步——两条中 ≥1 条 ≥ 中档才成立。
- 一次练习：画「单人坐姿＋屏风」，只用 3 色族（蓝/赭/白）＋墨，轮廓线不闭合、色块与墨相叠（§12/L399）。
- 反例/自检：若出现硬边平涂 → 越界马蒂斯侧（警报②）；若出现签名位/结构性白 → 吴冠中式构成侧。

**阶梯 2｜机制：戏曲折叠 + 几何变形（brief 主轴 B 专场）**
- 观察：§12 第 4/5/6 件（《宇宙锋》《火烧赤壁》《舞》）+ corpus #16 + §3.1 边界注。
- 决策：选一出戏的 3 个瞬间折叠进一张方幅；**不画舞台、不画透视**；人物 ≥2 个交叠（§12/L414）。
- 参数：P6 折叠几何度 50% 起（不强档，强档易滑向纯抽象 → 警报⑤）；色域受 §8.2 规则 4 约束（主色相 ≤5、高饱和 ≤12%）。
- 一次练习：折叠练习（§12/L414）完成后自问「能不能读出一条『综合的连续感』？」；再做 3 步转译「忠实临摹 → 去背景 → 色块简化」（§12/L424），要求「认得出源头、看不出摹本」。
- 反例：把戏曲内容讲成情节/叙事手势 = 失败（§8.2 规则 6「无叙事性事件与情节」）；把折叠做成点线面独立成网 = 越界吴冠中侧（警报①）。

**阶梯 3｜参数 + 反例 + 自检（收口阶梯）**
- 观察：§8.2 八条逐帧自查表（`:L201–L208`）+ §4 六参数（`:L108–L113`）+ 五条越界警报（`:L116`）。
- 决策：按 `mechanism_notes.md §1` 的「参数→规则→练习」映射表逐项对照；与吴冠中/马蒂斯/徐悲鸿做 A/B 对照（§12/L446）。
- 一次练习：任选一题材跑一帧，按 §8.2 八条 + 五条警报逐条打勾/打叉，记录失败条件。
- 反例（AUDIT 已记录的一次，照实携带）：`RESULT.md §Counterexample` 的「方形＋墨彩＋风景」三共享轴测试——§3.1/L85 已预先排除「只看方形/墨彩」的误判，规则稳健；但 §8.2 阈值为 `[归纳]`、未对原作像素测量（分母＝假想参考帧），**不构成像素级证伪**。

## §5 可观察结果（练习做成什么样算「这一轮走完」）

全部为「建议练习的自检项」，不是「已证实学习收益」（`01-AUDIT.md:L273`）：
1. 方幅 1:1±5%、四边触满、无签名位/空角（§8.2-1）。
2. 色块柔边渗化、色墨互叠，无「先勾后填」闭合描边（§8.2-2/5）。
3. 主动白区 3–15% 且与留白并存（§8.2-3）；主色相 ≤5、彩色以点面出现（§8.2-4）。
4. ≥1 母题、无叙事情节、情绪「哀而不伤」（§8.2-6）；近方形/圆/弧几何 ≥2 处且透视有意变形 ≥1 处（§8.2-7）。
5. 戏曲折叠帧能读出「综合的连续感」、人物交叠 ≥2、不出现舞台透视（§12/L414 + corpus #16）。
6. 五条越界警报逐条不成立（§4/L116）；三条分工判据能写出「判给了谁、看哪两轴」。
