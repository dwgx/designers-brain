## 1. 逐步展开（每步带 evidence grade + 定位 + 失效条件）

<a id="db-source-line-26"></a>
### D1 — 先判「多联画/三幕装置」，再谈画面 `[归纳]`
- 定位：[bosch.md](../../dossiers/bosch.md) §0 L18「全景道德叙事（天堂—人间—地狱的多幕结构 + 单帧多事件编目）」、§12-1 L389–L392、§3-1 L67、§4 P4 L102、§8.2-8 L240。
- 动作：先问「这一单有没有一个可读的三幕/序列结构（或 ≥2 组帧内善恶成对）」。有 → 走三联/多帧；没有 → 至少显式声明「单帧讽喻档」。
- 为什么：三联不是装裱形式，是把「罪—罚—救赎」铺开的装置（§3-1 L67 引 1605 西古恩萨「不是胡闹，是大智之书」）；缺了它，后面的生物群会退化为无语义的怪物陈列。
- 失效条件：任务要求「单事件/单肖像聚焦」时，三联装置不适用——按 §4 L107 这已是戈雅侧信号，不要硬套。

<a id="db-source-line-32"></a>
### D2 — 定「生物=多来源拼装」而非「单物种畸变」 `[归纳]`
- 定位：[bosch.md](../../dossiers/bosch.md) §1-3 L35、§2-7 L56、§4 P2 L100、§8.2-3 L235、§3.1 判据① L81；card L10/L48/L62。
- 动作：为每个新生物列「部件来源清单」（兽首/卵壳/器皿/箭矢/乐器/刀具/树干腿/鸟头…），要求 ≥2 类来源、≥3 个混合体/帧。
- 为什么：档案写死「不是一种动物的畸变，是多个来源的合成」（L35）；判据①把「生物发明计数」作为博斯/戈雅分野的第一条（L81）。
- 失效条件：一旦写成「把一种动物放大/拟人化」，§4 L107 分工注明确「P2 退化为单物种畸变且无拼装部件 → 越界」；§8.2-3 L235 也排除「单物种的等比放大」。

<a id="db-source-line-38"></a>
### D3 — 判「形象能否逐件道德解码」 `[归纳]`
- 定位：[bosch.md](../../dossiers/bosch.md) §3-1 L67（道德编码优先）、§3-3 L69（谚语/隐喻图像化，Dirk Bax 1949）、§3.1 L86–L89（vs 林飞龙：道德 vs 仪式）；corpus #19（西古恩萨 1605）。
- 动作：给每个混合体/母题标一个「讽喻零件」职能（罪/罚/欲/愚行/骄傲…）。干草车=世界、樱桃=骄傲（L69）是现成范式。
- 为什么：博斯档的混种＝「道德编码的讽喻机器」（L86），与林飞龙档「仪式性在场、不可道德解码」（L87）在**职能**上分档；L89 边界注「不得只看怪诞/混种程度，职能才是判据」。
- 失效条件：若形象只营造「交感/迷狂/敬畏」而不可读作道德命题，决策序应切到仪式档，不继续用博斯标签。对侧 `lam.md` 归 A-114，本 lane 未读其全文，只登记接口。

<a id="db-source-line-44"></a>
### D4 — 定「全景编目密度」并**显式写 P1 档位** `[归纳]`
- 定位：[bosch.md](../../dossiers/bosch.md) §1-1 L33 / §1-2 L34、§3-4 L70、§4 P1 L99、§8.2-1/-2 L233–L234；card L9/L46–L47/L61。
- 动作：写明 P1 = 弱(1–2 单元)/中(3–5)/强(≥8) 哪一档；配地平线 ≥上 1/3、景深 ≥2、单焦点 ≤20%、叙事单元 ≥5。
- 为什么：「系统感来自目录而非叙事」（L70）；P1 是 §4 L106 身份门三条之一，不显式写档就无法在 D8 联立。
- 失效条件：P1 留白/不写值 → D8 无法执行；P1=弱时即便 D2 生物计数达标，也不得单独据此判「博斯」（反例 A）。

<a id="db-source-line-50"></a>
### D5 — 定「画内单点主光 = 0」 `[归纳]`
- 定位：[bosch.md](../../dossiers/bosch.md) §1-6 L38、§2-3 L52（白底快笔）、§8.2-6 L238、§8.1 正向段 card L27–L28、card L11/L51；§3.1 判据④ L81（戈雅=画内证据光 ≥1）。
- 动作：日景用均匀天光（暗带 ≤30%），夜景用 ≥2 处分散火光；亮度前 10% 质心不集中于单一对象。
- 为什么：平光/环境光是博斯/戈雅/卡拉瓦乔三方分野（L44、L91）；card L78 把 C-01（硬阴影）列为组合预检重点。
- 失效条件：出现「1 个提灯/火把聚焦」= 戈雅侧证据光（§3.1 判据④）；出现单点硬光锥 = 卡拉瓦乔侧（C-01）。任一出现，D6 之前就该停。

<a id="db-source-line-56"></a>
### D6 — 定「色域=宝石谱亮色铺开」并显式写 P6 档 `[归纳]`
- 定位：[bosch.md](../../dossiers/bosch.md) §1-7 L39、§4 P6 L104、§8.2-7 L239、§3.1 判据② L80、§4 分工注 L107；card L12/L52/L66。
- 动作：写 P6 = 弱(土色)/中(混合)/强(宝石亮色) 档；显式取值蓝绿 15–35%、暖亮 ≥10%、土黑 ≤55%、V≥0.45（乐园档）/≤0.45（夜档），并声明色板清单（azurite/verdigris/lead-tin yellow/vermilion/红淀 + 铅白，§8.3 L249）。
- 为什么：P6「定档期（夜/地狱↔乐园滑轨）」（L106）；§3.1 判据②把亮度/色域作为博斯/戈雅第二分野（L80）。
- 失效条件：P6 收窄「土黑+白闪点」且 P1 降单事件 → §4 L107 明确越界进戈雅；C-15（色数）与 Lane B「同屏 ≤3 色」类约束冲突时按 card L78/§8.3 L249 显式声明色板，不偷偷减色。

<a id="db-source-line-62"></a>
### D7 — 放「直视目光/猫头鹰 + 尺度错乱」 `[归纳]`
- 定位：[bosch.md](../../dossiers/bosch.md) §1-4 L36 / §1-5 L37、§4 P3 L101 / P5 L103、§8.2-4 L236 / §8.2-5 L237；card L13/L49–L50/L63/L65。
- 动作：≥1 形象直视观众（板缘成对猫头鹰更佳）；≥1 组元素与人体 ≥2:1 巨物。
- 为什么：P3/P5「定奇想强度」（L106）；直视目光是「邪恶的目光」装置（L37），尺度错乱让「比例服务寓意而非物理」（L57）。
- 失效条件：只当装饰、不写进自查表 → 强度档落空；把巨物做成「单物种等比放大」会与 D2 冲突，应回到部件拼装。

### D8 — 跑「身份门」联立自查（守门步） `[归纳]` / 设计候选
- 定位：[bosch.md](../../dossiers/bosch.md) §4 用法行 L106（「P1/P2/P4 三条同时 ≥ 中档才成立」）、分工注 L107、§8.2 注 L242（「3/5 条与 §3.1 分工判据同轴」）；`AUDIT-bosch/RESULT.md` §4 反例 A；§10-9 L314。
- 动作：下结论前，联立检查 `P1≥中 ∧ P2≥中 ∧ P4≥中`。任一不达标 → 判 `not_bosch`（或按 L107 越界到戈雅），**即使** §8.2-3（生物 ≥3）与 §8.2-8（成对 ≥2）单独都达标。
- 为什么（反例 A，`[inference]`）：§3.1 的 5 条判据被写成「各自可数」，§8.2 自查表也没把「三条联立」列为第 9 条；若只跑 §8.2-3+§8.2-8，一个「P2 强、P1 弱、P6 土黑+白闪点、单点提灯」的帧会被误判为博斯，与 L106 矛盾。这不是推翻档案，是暴露**判据粒度不一致**。
- **身份门 proposal**：在 §8.2 自查表加一条「身份门：P1≥中 ∧ P2≥中 ∧ P4≥中，三者同时成立才允许打 bosch 标签；否则即使生物计数达标也判 not_bosch」。与 §10-9 L314「组合实验可按 §8.2 自查表回改」口径一致。
- **状态 = 未证伪（not-falsified），作为设计候选保留**：反例 A 没有证伪它，也没有验证它；本 lane 未做像素实测、未跑生成帧、不把它升级为 validated_rule，交 RULE/CONFLICT lane 定夺。
- 失效条件：若未来组合实验给出「P1 弱但其余强仍应判博斯」的具体反例，身份门须按同口径回改；在那种证据出现前，它是防守性自查，不是史实。

## 3. 何时整套决策序失效（总边界）

1. **任务落在戈雅档**：单事件/单肖像聚焦、土黑+白闪点、画内证据光 ≥1、单物种畸变（§3.1 L79/L81、§4 L107）——D1/D2/D5/D6 同时反向，整套失效。
2. **任务落在林飞龙档**：混种生物用于仪式在场、暗域月光、不可道德解码（§3.1 L87–L89）——D3 失效，须换「职能」判据，不硬套道德解码。
