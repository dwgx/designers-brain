## 2. 逐步展开

<a id="db-source-line-40"></a>
### S1 · 先选：骨架 + 块面分配　`[归纳]`
- **先选什么**：下笔前先定透视骨架（桌面/地平线角度）、主要形块、每物主色，再逐物深入（`D : L40` 四阶段：①稀薄蓝灰笔触定骨架 → ②粗略勾形块 → ③每物铺主色 → ④逐物深入）。
- **牺牲什么**：牺牲「局部提前画完」的痛快感；任何深入之前不得把某个苹果/局部收尾。
- **为什么**：`[归纳]` 自 `D : L40` 的 NG 逐层复原归纳（`D : L51`「先骨架后表皮」`[归纳]`）；`D : L329`「未完成感 = 工序外显」。`[研究]` 依据为 NG 对《有蓝水壶的静物》的逐层分析 `D : L326–329`。
- **何时失效**：纯色块平涂类题材、或把「未完成」误解为随手涂（B-4 已 OVERTURNED `D : L375`）；与要求「完整收尾」的模块组合时 P6 需降档。
- **自述锚点**：无。`D : L51` 自标 `[归纳]`；本步**不冒充**塞尚自述。

<a id="db-source-line-47"></a>
### S2 · 先选：色阶（modulation）而非明暗　`[归纳]`（`[自述]` 只作锚点引用）
- **先选什么**：用「明调 / 半调 / 四分之一调」的同色系色阶差塑形，禁黑阴影、禁单方向光源渐变（`D : L177` §8.2-2）。
- **牺牲什么**：牺牲古典明暗对照（chiaroscuro）与「加黑压暗」这条最省力的塑形路径。
- **为什么**：`[归纳]` 操作理由见 `D : L26`（红↔绿强度代替明暗 `[研究]`）、`D : L74`（P3 强档 = 仍像塞尚的关键）。
- **`[自述]` 锚点（只引用，不外推心理）**：
  - `D : L41`（§2-2）：「光对画家来说并不存在」——1904-12-23 致 Bernard 信，`[自述]`，出 [3] 译本「light does not exist for the painter」。
  - `C : Q3 L23–27`：« On ne devrait pas dire modeler, on devrait dire *moduler*. »（`[reported speech]`，Bernard《L'Occident》1904 p.24）。
  - `C : Q4 L29–33`：« Il n'y a pas de ligne, il n'y a pas de modelé, il n'y a que des contrastes… »（`[reported speech]`，同上）。
  - `D : L55`（§3-1）：「以圆柱、球体、圆锥来处理自然」`[自述]`（1904-04-15 信，F1 互证 `D : L213`）。
- **何时失效**：`D : L376`（B-5 WEAKENED）已修正「全画无黑」为「无黑阴影（L\*≤10 像素 ≤0.5%），保留黑色用于轮廓加固与最深点」。所以「禁黑」不是绝对禁令；与卡拉瓦乔深棕底组合时见 S5 / C-13。

### S3 · 先选：建设性笔触铺满全画面　`[归纳]`＋`[研究]`
- **先选什么**：短、可见、平行的小笔触（8–24 px / 4–8 角度族 / 覆盖率 ≥80%，`D : L176`），一次完成「塑形 + 统一表面」。
- **牺牲什么**：牺牲平滑渐变、 photorealistic detail、光泽罩染（`M : L33–39` 负向段）。
- **为什么**：`D : L25`（NG 音频稿 `[研究]`：「Around 1880 Cezanne developed his so-called 'constructive' stroke…create both three dimensional forms but also to unify the entire surface」）、`D : L42`（§2-3 `[研究]`）、`D : L169`（防退化关键：模型默认会用黑阴影+渐变塑形）。
- **何时失效**：`C-05`（`X : L36`、`X : L109–121`）与达·芬奇「只有渐变、看不到笔触」互斥；**本 brief 未指派 C-05**，仅记录不处理（`A/coverage_manifest.md` §2 L42）。此外 1860s 调色刀厚涂期不适用（`M : L37` 负向段「palette-knife impasto (that is the 1860s style)」）。
- **自述锚点**：无；本步为 `[研究]`/`[归纳]`。

### S4 · 先选：暖冷交错编织　`[归纳]`
- **先选什么**：暖（橙/黄/赭）与冷（绿/蓝）小块交替，暖冷像素各 30–70%，全帧 L\* 直方图无单一桶 >20%（`D : L182`）。
- **牺牲什么**：牺牲「大面积均匀天空块」和任何大片纯色平铺（`D : L34` `[研究]`）。
- **为什么**：`[归纳]` 自 `D : L34`「暖冷交错编织」、`D : L26` 红绿强度交替归纳；对应 `Q1` 自述里「在由红与黄代表的光的振动中引入足量的蓝调，以产生空气感」（`C : Q1 L11–15`、`D : L55–56` `[自述]`）——**仅引用该信句，不据此宣称塞尚的「意图是 X」**。
- **何时失效**：`C-04`（`X : L97–107`）：与卡拉瓦乔「暗带 ≥40% + 背景均匀」同帧时，按 `X : L105–107` 把作用域改「受光区 + 中间调区」、双掩膜分别统计；否则卡拉瓦乔背景压暗机制被拆掉（`X : L103` 强反例）。

### S5 · 先选：蓝只进阴影 + 轮廓　`[归纳]`
- **先选什么**：蓝网贯穿阴影/轮廓/天空/远山，阴影+轮廓区 H 200–250° 像素 ≥15%（`D : L179`），断口/双线轮廓（§8.2-3 `D : L178`）。
