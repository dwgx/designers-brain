## 4. 具体练习（阶梯；全部为「建议练习」）

顺序按 brief：**暖冷交错编织 pass → 蓝调轮廓纪律 → 多点透视空间压缩**；G0 作为三阶共用的前置基底（不算独立一阶）。每阶给「操作 / 用哪条判据 / 失败信号 / 对应作品」，参数与失败条件的可执行映射见 [mechanism_notes.md](mechanism_notes.md)。

<a id="db-source-line-77"></a>
### 基底 A0 · 建设性笔触铺底（每阶开头都做，约 20 分钟）
- **操作**：取一张自己的风景或静物照，限定 6 色（赭、橙、橄榄绿、翠绿、钴蓝、群青，`D : L349`），用 ≤1 cm 等值、平行短笔触铺满全画面，**禁用黑色与平滑渐变**（`D : L169`、`D : L319`）。先按 3 个明度层做 15×20 cm 底稿，再用 4–6 个方向族重画一遍（`D : L319`）。
- **判据**：G0 笔触覆盖率 ≥80%、方向族 4–8、同族偏差 ≤25°、近黑像素 ≤0.5%（`D : L176–177`）。
- **为什么先做**：`D : L51`（§2-12「先骨架后表皮」`[归纳]`）与 `D : L40`（§2-1 四阶段工序 `[研究]`）都要求先完成骨架/块面分配再深入；A0 是后面三阶的承载面。
- 对应作品 §12-1 `D : L316–319`、§12-7 `D : L346–349`。

<a id="db-source-line-83"></a>
### 阶梯 1 · 暖冷交错编织 pass（warm-cold weaving pass）
- **操作**：在 A0 的底稿上做一遍「暖冷编织」：把画面按 64×64 块扫一遍，任何出现大片同色/同明度的块，用相反温度的小笔触插入（暖区插冷、冷区插暖），直到暖像素与冷像素各自占比落在 30–70%。**不允许**用加黑或加白来拉开明度（`D : L26`、`D : L41` 的「明调/半调/四分之一调」）。
- **对照练习**（沿用现有记录，不新编）：同一取景点画两张 15×20 cm，A 版近景只许暖、远景只许冷，B 版冷暖互换，比较哪张「退得更远」——`D : L321–324`（§12-2）。
- **判据**：G1 全帧 L\* 直方图**无单一桶 >20%**、暖冷各 30–70%（`D : L182`）；配套 `D : L177`（无单方向光源渐变、64×64 块 L\* 梯度均值 ≤2）。
- **失败信号**：出现大面积均匀天空块 / 单一明度桶堆积 → 触发 C-04 的退化（见 §6、[mechanism_notes.md](mechanism_notes.md)）。
- 对应作品 §12-2 `D : L321–324`、§12-7 `D : L346–349`、§12-9 `D : L356–359`。

<a id="db-source-line-90"></a>
### 阶梯 2 · 蓝调轮廓纪律（blue-contour discipline）
- **操作**：只画轮廓线稿——每个物体轮廓画两遍、留 ≥30% 断口（`D : L339` ①）；再用蓝色重描全部轮廓并**局部**以黑加固（②）；最后按规则 3/4 自查（③）。蓝只进「阴影 + 轮廓」，不要把整块暗部涂成蓝（C-13 的边界，见 §6）。
- **判据**：G2 阴影与轮廓区域蓝像素（H 200–250°）**≥15%**、天空/地面平均饱和度差 ≤15%（`D : L179`）；配套 `D : L178`（轮廓 2–4 px、≥30% 断口/双线错位 ≥3 px）。
- **注意黑的用法**：`D : L376`（自审 B-5）已把「全画无黑」修正为「无黑阴影（L\*≤10 像素 ≤0.5%），保留黑色用于轮廓加固与最深点」——NG 浴者原句「reinforced by black」`D : L338`。不要为了「纯塞尚」把黑全删掉。
- **失败信号**：整片暗部变蓝、或蓝只在天空不在轮廓 → 蓝网贯穿失效；与卡拉瓦乔深棕底同帧时互拆（C-13）。
- 对应作品 §12-5 `D : L336–339`、§12-8 `D : L351–354`（虚线多重轮廓）。

<a id="db-source-line-97"></a>
### 阶梯 3 · 多点透视空间压缩（multi-point perspective compression）
- **操作（正常通过版 A，预期满足门槛）**：在静物或屋顶照片上，刻意让**同一桌面两侧不共线**、让杯口/屋顶从不同视点呈现（`D : L43`）；把远景同类物体的画幅高度抬到近景的 ≥0.5，**不靠变淡/加雾推远**，靠色阶与块面推（`D : L29–30`）。方向族保持 **4–8 个**（落在 G0 的 4–8 内，与 §4 A0 的 4–6 方向族一致），色阶与块面做空间压缩。该版对标 §12-3 桌沿错位（`D : L326–329`），按 G0/G3 自查应为**通过**。
- **边界对照版 B（预期边界反例，非通过样本）**：B 版只保留几何块面 + 色阶、把方向族**收紧到 3 个**（`D : L359` 的「立体主义前夜」实验、加尔达讷 §12-9 `D : L356–359`）。**3 个方向族 < 4，明确违反 G0「4–8 角度族」规则**（规则行 `D : L176`（§8.2-1）＝`M : L66`，本文件 §3 G0 行、§4 A0 判据行同指此规则）。因此 B 是**预期边界反例**：用来观察「越过塞尚模块门槛、靠近立体主义前夜」时长什么样，**预期在 G0 上失败**，不得当作 G0=4–8 的通过样本，也不为让它过门而下调 4–8 阈值。
- **两版对照与两种判断（分别列，不混为一谈）**：
  - **练习完成**：A、B 两版都画完、各自记录方向族数与空间压缩手法，即完成本对照练习（两版都是有效练习产物）。
