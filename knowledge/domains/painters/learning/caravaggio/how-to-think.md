# LEARN-caravaggio — How to Think（创作决策序）

> 任务 `LEARN-caravaggio` ｜ 仓库只读 @ `f008952365a77e140cbda3f3959d43ef000f9a22`。
> **本文件回答「做一张卡拉瓦乔式画面时，先选什么 / 牺牲什么 / 为什么 / 何时失效」，不回答「卡拉瓦乔本人当时怎么想」。**

<a id="db-source-line-6"></a>
## 0. 铁律：自述 vs 推断，严格分栏

档案 `:5` 定义分级：`[自述]` 本人写下/说出（带出处）· `[史料]` 当时记录 · `[研究]` 艺术史家/馆方分析 · `[归纳]` 本项目从作品归纳的操作规则 · `[推测]` 低置信。档案 `:7`、`:132` 写明：**卡拉瓦乔几乎没有文字留世，没有任何一条可作画论引用**——「本模块的 prompt 只能从作品可见机制反推」。

因此本文件采用：

- **`[自述]` = 空集**。唯一接近的是 1603 年诽谤案法庭证词（corpus #2 `:18-23`、#3 `:25-31`；档案 §5-1 `:91-95`），但其内容是**贬损对手**（"I don't know any painter who thinks Giovanni Baglione is a good painter"），且 Graham-Dixon 判其真诚度可疑（档案 `:95`、`:127`、corpus `:178`）。**它不是画论，本文件不拿它当创作依据。**
- **`[归纳]`** = 从作品可见机制 + §4/§8.2 规则反推的「决策序」，是本项目操作规则，**不冒充艺术家内心**（档案 `:69`、`:132`、`:503`）。
- **`[推测]`** = 更低置信的「若…则…」外推，明确标注、不当判据。
- **`[史料]` / `[研究]`** = 只用于给归纳步骤提供「作品/同代记述确实这样」的锚点，不升级为「他心里想」。

> **禁止事项**：不因为「画面看起来很戏剧」就发明「他想制造戏剧张力」之类心理；不把同代敌意传记（Baglione 1642 / Bellori 1672，档案 `:7`）包装成自述；不把 §4 量化阈值（未实测，`:222`/`:503`）说成他的设定。每一决策步都带**证据级**。

## 1. 决策序（先选 → 牺牲 → 为什么 → 何时失效）

> 顺序 = 档案 §3-2 归纳的操作序列「先定光位 → 再定亮部三对象 → 最后压暗背景」（`:61`），并由 §4 用法「P1/P2 定身份、P4/P6 定叙事、P3/P5 定时期」（`:85`）扩展为 6 步。**每步标证据级。**

<a id="db-source-line-25"></a>
### 步 1 — 先选：光的开关（P1 强档）
- **选什么**：全帧只用**一个画外高置硬光**（左上/右上，仰角 30°–60°），无反射、无补光、亮部边界硬；可见光源数 = 0（§4 P1 `:77`；§8.2-1 `:214`）。默认 **85% 强档**（`:77`；强调「single-hard-light discipline」）。
- **牺牲什么**：环境补光、反射光、柔边过渡、多光源、天光。
- **为什么**：`[史料]` 同代批评家/Mancini/Bellori 都把该派机制描述为「高置聚焦光、无反射、暗室黑墙」（corpus #11 `:88-93`、#14 `:110-115`、#20 `:154-159`；档案 §5-7 `:121-125`）—— 这是 P1/P2 的直接史料依据（`:125`）。`[归纳]` 把 P1/P2 定为「是不是卡拉瓦乔」的身份轴（`:85`）。
- **何时失效**：一旦 P1 降到中档、允许「光在面部连续衰减」，产出进入伦勃朗地盘（`:84`）；套用 Lane B 默认「别做成：硬阴影」会把核心机制抵消（C-01 `conflicts.md:55`；档案 §8.3 `:228`）；画中出现可见光源/蜡烛/吊灯即违约（§8.1 负向段 `:200-204`、模块卡 `:39`）。
- **证据级**：决策本身 `[归纳]`；锚点 `[史料]`。

<a id="db-source-line-32"></a>
### 步 2 — 再选：亮部只给三类对象（P6 / 光斑三处法则 `[2,5]`）
- **选什么**：光斑只落在**脸 / 手 / 关键道具**；高光连通域（≥0.9×max）数量 ∈ **[2,5]**，每域与三者之一相交，人物背部高光 = 0（§4 P6 `:82`；§8.2-4 `:217`）。
- **牺牲什么**：全身均匀受光、背景受光、人物背部/衣物大面积亮部、装饰性多点高光。
- **为什么**：`[归纳]` 手势是叙事主语、且手被光点亮（§1-5 `:34`）；§4 用法把 P6 定为「定叙事」轴（`:85`）。`[研究]` Met「pushed the figures up against the picture plane」（§1-4 `:33`）支持把光聚在前景主体而非空间。
- **何时失效**：混入维米尔 100+ 点状高光 → [2,5] 计数失效（C-11 `conflicts.md:188`）；为了「讲清故事」加第二束光去照第二个人的脸（破坏步 1）；肖像居中、光均匀铺满全身（P6 弱档 `:82`）。
- **证据级**：决策 `[归纳]`；锚点 `[研究]`。

<a id="db-source-line-39"></a>
### 步 3 — 压暗但留底：背景 ≤10% + 暗部非死黑（P2 + P3/§8.2-7）
- **选什么**：背景最大亮度 ≤ 0.10×全帧最大、背景标准差 ≤ 全帧 5%（§8.2-2 `:215`；§4 P2 `:78`）；中间调压缩成**双峰直方图**（中间带 [0.35,0.65] ≤25%、暗带 [0,0.25) ≥40%）（§8.2-3 `:216`；§4 P3 `:79` 默认 30%）；**同时**暗区标准差 ≥1.5/255、纯黑 ≤10%，深棕底透出作中间调（§8.2-7 `:220`；§1-3 `:32`、§1-10 `:39`）。
- **牺牲什么**：全调域渐变（学院式）、大面积均匀亮背景、光晕渐变、纯黑剪影。
- **为什么**：`[研究]` NG 论《莎乐美》「the dark ground left deliberately exposed … to provide the mid-tone in the shadows」（§1-3 `:32`）；`[史料]` 暗室黑墙记述（corpus #20）。`[归纳]` 把「双峰 + 非死黑」当成一体两面：压掉中间调，但把层次藏进暗部底色里。
- **何时失效**：混入达·芬奇「中间调 ≥55%」→ 与 ≤25% 空交集（C-03 `conflicts.md:84`）；混入塞尚「无单桶 >20%」全帧直方图 → 近黑背景被拆（C-04 `:97`）；把暗部涂成纯黑剪影（违反 §8.2-7）；为「可读性」擅自把 P3 提到中档却不说（§8.2-3 中档需显式）。
- **证据级**：决策 `[归纳]`；锚点 `[研究]`+`[史料]`。

<a id="db-source-line-46"></a>
### 步 4 — 贴平面 + 定格一瞬（P4 + §8.2-5/6）
- **选什么**：主人物包围盒 ≥ 画幅 80%、至少一主体被边缘裁切、地平线 ≤ 下缘以上 15%（§8.2-5 `:218`；§4 P4 `:80`）；每帧仅 1 个动作极值、运动模糊核 = 0、手势延长线 ±15° 指向叙事对象（§8.2-6 `:219`；§1-8 `:37`）。
- **牺牲什么**：景深纵深、风景/天空、过程帧、运动模糊、多动作同时发生、对称构图。
- **为什么**：`[研究]` Met「pushed the figures up against the picture plane」（§1-4 `:33`）、R1「the passing of a crucial moment」、NG「the moment of revelation」（§1-8 `:37`）。`[归纳]` 把 P4 定为叙事轴、把「定格」写成可判定规则。
- **何时失效**：画面出现风景/天空/纵深背景（§8.1 负向段 `:202-204`）；加运动模糊或「过程帧」（违反 §8.2-6；另见 C-08 `conflicts.md:149`，本卡不展开）；多个动作极值同时发生；手势箭头不汇聚（§12.2 `:391`、§12.4 `:401`）。
- **证据级**：决策 `[归纳]`；锚点 `[研究]`。

<a id="db-source-line-53"></a>
### 步 5 — 色域收窄 + 反理想化（P5）
- **选什么**：赭 / 红棕 / 铅白 / 黑土色系，饱和色仅出现在道具（§4 P5 `:81` 罗马期 60%／晚期 85%；§8.1 `:194-195`）；圣徒画成普通劳动者——皱纹、破衣、脏指甲、17 世纪当代服装（§1-6 `:35`、§1-7 `:36`、§8.1 `:192-193`）。
- **牺牲什么**：理想化人体、光环/象征符号、冷色大面积、霓虹/粉彩、风景与天空。
- **为什么**：`[史料]` R1「dirt under his fingernails」/「figures in contemporary dress」（§1-6/7）；`[研究]`「restricted range of colour」（§1-9 `:38`）、Met「a provocative insistence on the physical reality」（§3-3 `:62`）。`[归纳]` 物理真实压倒象征程式（§3-6 `:65`）。
- **何时失效**：混入北斋「蓝 ≥40%」或梵高互补对 1:1 → 深棕底被挤掉（C-12 `conflicts.md:203`）；混入塞尚「阴影蓝 ≥15%」→ 暗部色相丢失（C-13 `:217`）；加光环盘/可见蜡烛（§8.1 负向段 `:204`）。
- **证据级**：决策 `[归纳]`；锚点 `[史料]`+`[研究]`。

<a id="db-source-line-60"></a>
### 步 6 — 直接画法的工作流（§2 技法，流程层）
- **选什么**：不做纸上素描，深棕笔线在画布上定形（abbozzo）+ 笔杆尾端刻定位线（incisions）→ 铺色 → 亮部概括性厚涂（§2-1/2/3/8 `:45-47`、`:52`）；真人摆姿势、从真人写生（§2-5 `:49`）。
- **牺牲什么**：学院式多张预备素描、理想化范式、平滑喷枪式渐变。
- **为什么**：`[研究]` NG「not a single drawing that can be firmly attributed to Caravaggio survives」、Borghese 2012 画布底层草图（§2-1 `:45`、§2-2 `:46`）；Met「painting directly from posed models」（§2-5 `:49`）。注意 NG 同时说「carefully composed / high degree of preparation」—— 直接画 ≠ 无准备（AUDIT RESULT §4.2 已核）。
- **何时失效**：把「直接画」误读成「不打腹稿、随意」（AUDIT RF-2 已证 NG 强调高度预谋、少 pentimenti，§2-9 `:53`）；用平滑 airbrush 渐变代替硬边亮部（§8.1 负向段 `:202`）。
- **证据级**：决策 `[归纳]`；锚点 `[研究]`。

> 步 6 是**执行流程**而非画面判据，放在最后是因为它不改变画面机制，只改变「怎么把前 5 步落上去」。练习阶梯见 [learning_path.md](learning_path.md) §4。

## 3. 「不冒充心理」的自查

1. 本文件是否出现「他想 / 他认为 / 他为了表达…」？→ **应为空**。所有动机描述都写成「操作规则/可观察结果」。
2. `[自述]` 是否为空？→ **是**（无画论；唯一法庭证词是贬损语，不作依据）。
3. 每条决策是否带证据级、且锚点指向 corpus / 档案 §1-§5？→ 是（见各步「为什么」）。
4. 是否把画面外观直接当心理？→ 否；「戏剧性」只作为作品可见机制（§1、`[研究]`），不推断内心。
5. 是否把未实测阈值说成「他设定的」？→ 否；§4/§8.2 阈值全程标 `[归纳]` 未实测（`:222`、`:503`）。
