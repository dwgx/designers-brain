## 1. 前置知识（先知道什么，再开练）

1. **硬光/软光的物理分野**：单一硬光源 = 亮部边界硬、无反射补光；软光 = 多光源/天光/环境补光。这是 P1 的「开关」本质（档案 §4 `:77`，模块卡 `:76`）。不先分清二者，后面所有自查都会失准。
2. **两级明暗（tenebrism）与直方图**：亮部极亮、暗部极暗、中间调被压缩成双峰（档案 §1-2 `:31`、§8.2-3 `:216`）。**双峰 ≠ 死黑**：暗区仍留深棕底作可辨中间调（档案 §1-3 `:32`、§1-10 `:39`、§8.2-7 `:220`）。
3. **「光的开关」身份边界**：卡拉瓦乔 = 光的开关 + 物理（硬光戏剧）；伦勃朗 = 光的连续衰减 + 心理。P1 降到中档、允许「光在面部连续衰减」就越界（档案 §4 分工注 `:84`，模块卡 `:83`）。开练前先认定这条，免得把「柔边衰减」当成本模块目标。
4. **叙事语法三件套**：人物贴画面平面 + 手势当主语 + 定格一瞬（档案 §1-4/5/8 `:33`/`:34`/`:37`，§8.2-5/6 `:218`/`:219`）。
5. **史料定位**：同代批评家（Met 转引）/Mancini/Bellori 都把机制落在「高置单灯、无反射、暗室黑墙」（corpus #11 `:88-93`、#14 `:110-115`、#20 `:154-159`；档案 §5-7 `:121-125`）—— 这是 P1/P2 的直接史料依据（档案 `:125`）。练的是「作品可见机制」，不是「猜他怎么想」（档案 `:132`）。

## 3. 要观察的机制（练时盯什么）

1. **单硬光纪律（P1 85%→强档）**：全帧可见光源数 = 0（光从画外来）、主光方向固定左上/右上、环境光 ≤ 主光 5%、无反射/补光（§8.2-1 `:214`）。
2. **光斑三处法则 `[2,5]`**：高光连通域（亮度 ≥ 0.9×max）数量 ∈ [2,5]，每个都落在「脸 / 手 / 关键道具」之一，人物背部高光连通域 = 0（§8.2-4 `:217`；§4 P6 `:82`）。这是本模块最核心的签名。
3. **中间调压缩双峰直方图**：中间带 [0.35,0.65] 占比 ≤ 25%、暗带 [0,0.25) ≥ 40%（强档）；中档放宽到 ≥25%/≤40%（§8.2-3 `:216`；§4 P3 `:79` 默认 30%）。
4. **背景明度上限 + 均匀**：非人物/道具像素最大亮度 ≤ 0.10×全帧最大亮度，背景亮度标准差 ≤ 全帧 5%（禁光晕渐变）（§8.2-2 `:215`；§4 P2 `:78`）。
5. **暗部保细节（非死黑）**：暗区（<0.15）内部标准差 ≥ 1.5/255，纯黑像素 ≤ 10%（§8.2-7 `:220`）—— 与机制 3 的「暗带 ≥40%」是**一体两面**，不可拆。
6. **贴平面 + 定格**：主人物包围盒 ≥ 画幅 80%、至少一主体被裁切；每帧仅 1 个动作极值、运动模糊核 = 0、手势延长线 ±15° 指向叙事对象（§8.2-5 `:218`、§8.2-6 `:219`）。

> 观察顺序建议：先 1（光的开关）→ 2（光斑落点）→ 3+5（双峰但非死黑）→ 4（背景）→ 6（叙事）。前四步都是「光」的判定，后一步才是「人」。

## 4. 具体练习（可操作 · ≥3 阶梯 · 全为「建议练习」）

> **每一级都带「可观察结果」与「自查」**，自查引用 §8.2 原文规则作判据（不另造阈值）。执行介质为纸笔/数字笔临摹或重演（§12 `:380`）。**全部标 `建议练习`；练习效果未经真人验证，不声称已证实学习收益。**

<a id="db-source-line-55"></a>
### 阶梯 1 — 单光源静物（single-source still-life）

**目标**：先只建立「光的开关」，不带人物、不带叙事。
1. 摆一组真实水果 + **单一硬光（无补光、无反光板）**拍照或摆静物（§12.1 `:386` 步骤①）。
2. 起手只画水果与篮，**明暗两大区**，禁细化（§12.1 `:386` 步骤②）。
3. 加一只手入画（§12.1 `:386` 步骤③）。
4. 自查（§12.1 `:386` 步骤④）：§8.2-4 高光连通域 ≤5 且落脸/手/道具；§8.2-2 背景最亮 ≤ 全帧 10%。
- **可观察结果**：直方图出现双峰、中间调被压掉；画面里找不到第二盏灯；果皮/篮条的高光方向一致。
- **常见失败**：不自觉用环境补光把暗部提亮（P1 降到中档）；背景带渐变光晕；高光散成十几处。

<a id="db-source-line-65"></a>
### 阶梯 2 — 暗调肖像裁切（tenebrist portrait crop）

**目标**：把光斑收进「脸/手/关键道具」，并引入贴平面裁切。
1. 写一张「光选人」分镜：标出谁被照亮、谁留暗里、光源画外位置（§12.2 `:391` 步骤①）。
2. 画 5 人视线链与手势向量图，检查箭头是否汇聚（§12.2 `:391` 步骤②）；或对照《以马忤斯》复现「手—面包—酒杯」三角（§12.3 `:396` 步骤③）。
3. 临摹为明暗大块（只画 3 个亮块）再逐步加深（§12.2 `:391` 步骤③）；半身/大半身、被画幅边缘裁切（§8.1 `:25-26`、§8.2-5 `:218`）。
4. 不打草稿纸，直接在深棕色笔线定形 + 笔杆尾端刻位置线（§12.3 `:396` 步骤①②，对应 §2-2/3 `:46-47`）；限 30 分钟。
5. 自查：光斑只落脸/手/道具（§8.2-4）；中间调压缩 + 暗部保细节（§8.2-3/-7，§12.3 `:396` 步骤④）。
- **可观察结果**：高光连通域数落在 [2,5] 且每域都与脸/手/道具相交；主人物 ≥ 画幅 80%、至少一处被裁；暗部仍见深棕底层次。
- **常见失败**：光均匀铺满全身（P6 弱档）；肖像居中带纵深背景（P4 弱档）；把暗部涂成纯黑剪影（违反 §8.2-7）。

<a id="db-source-line-76"></a>
### 阶梯 3 — 定格动作构图（frozen-action composition）

**目标**：加入叙事一瞬 + 群体，把前两级的光纪律顶住不退化。
1. 用箭头图标注所有手势/视线向量，检查是否汇聚到画外一点（§12.4 `:401` 步骤①）；或把七个动作写成七行分镜再压进一格（§12.8 `:421`）。
2. 只画大块明暗（忽略细节）、做「谁被裁切」检查（§12.4 `:401` 步骤②）；约束「暗面 ≥60%」做同构草图（§12.7 `:416` 步骤①）。
3. 冻结单一动作极值：运动模糊核 = 0、手势延长线 ±15° 指向叙事对象（§8.2-6 `:219`）。
4. 自查：可见光源数 = 0、光斑落点 = 三个关键人物部位（§12.7 `:416` 步骤③）；每件善事至少一只可辨的手 + 光斑覆盖（§12.8 `:421` 步骤③）；高光连通域 [2,5]（§8.2-4）。
- **可观察结果**：整张只有 1 个动作极值、无运动模糊；光斑计数仍 ∈[2,5]；暗带 ≥40% 而纯黑 ≤10%；色域收窄到赭/红棕/铅白/黑（§4 P5 `:81`）。
- **常见失败**：为了讲清故事加第二束光/补光（破坏 P1）；加运动模糊或「过程帧」（破坏 §8.2-6）；多动作同时发生（>1 个极值）；亮部铺到人物背部（§8.2-4 背部高光 = 0）。

> **阶梯间递进逻辑**：L1 光 → L2 光+人+裁切 → L3 光+人+群+叙事。每升一级，**已建立的光纪律不得回退**（这正是 mechanism_notes 里 C-01/C-03/C-04/C-11/C-12/C-13 作为「失败条件」的用武之地）。
