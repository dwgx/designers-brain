## §1 前置知识（先具备什么，再开练）

1. **先接受两条写死的分工条款**（dossier §3.7 L85-93 / §3.8 L95-104；卡「冲突注记」L73-75）：
   - **vs 欧洲学院派写实线**（技术来源）——口径「**技术输入 → 本土化转译**」：油彩/明暗/透视自欧洲来，但被重写为**神话叙事与达显图像**。光=**柔光均匀化**（服务于识读与礼拜），不是卡拉瓦乔的「硬光开关」、不是伦勃朗的「连续衰减 + 心理光斑」、不是维米尔的「光学室内」；空间=**浅舞台**（柱/幕/墙、纵深 ≤2 层）；面孔=**理想类型**（跨画同款），不是心理个案；功能=**史诗与神祇（礼拜 + 印刷复制双功能）**。一句话（dossier L93）：**「同是写实，欧洲线把光变成戏剧与心理；拉维把光变成识读与礼拜——技术同源，功能相反。」**
   - **vs 谢尔吉尔**（未来卡）——「**民族图像的通俗/大众档 vs 现代主义/个体档**」：拉维=**复制**（石版/印刷、标准化神祇、礼拜凝视 darshan）；谢尔吉尔=**独幅**（个体观察、画内互视、后印象派色彩）。判据：版式是否成立、类型脸 vs 唯一脸、视线出画礼拜 vs 画内互视（dossier L103）。
   - **vs 北斋**（同属「大众印刷时代」两路，dossier §3.9 L108）：北斋=**木版分色**（等宽线 + 平涂 + 留白）；拉维=**石版彩印**（油画感明暗 + 套色饱和）。出现「单线骨架 + 平涂」→ 北斋域；「明暗渐层 + 套色」→ 拉维域。

### 阶梯 1：西法转译——浅舞台与柔光（先立「识读/礼拜」的光与空间）
- **观察对象**：《Sri Krishna as Envoy》（登场式亮相 + 群像舞台，§12-4）、《Nair Lady 梳妆》（单侧室内柔光，§12-2）、《Shakuntala 回眸》（双层动作 + 出画，§12-1）。
- **创作决策**（见 [how-to-think.md](how-to-think.md) D1–D3）：先定「这是给谁看的」——礼拜/识读 → 柔光均匀化 + 浅舞台；**牺牲**硬光戏剧、深透视、心理光斑。
- **机制**：M1（舞台）+ M3（柔光）+ M2（亮相/出画）。
- **参数**：P1 舞台调度度 中–强（默认 70%）、P3 光戏剧性 **弱–中（默认 45%，不进夜色单光源）**、P2 默认 75%。
- **一次可做的练习**（§12-4/1/2 改写）：① 画一幕「主角登场」（1 主角 + ≥4 配角，主角 3/4 正面、动作定格于高潮前一瞬），背景只给 1 个柱/幕框景、纵深 ≤2 层；② 同稿再画一版「硬光开关」对照，自查柔光版是否满足「阴影边界软边 ≥8px、无 >15%/px 硬边、面部最亮/最暗比 ≤2.5:1」；③ 生成式：固定 prompt（§8.1 正向段）只改 `soft even lighting` ↔ `hard chiaroscuro`，成组 4–6 张对照 §8.2-1/2。
- **反例**：出现「硬光开关 / 亮部只落脸手道具 / 画内无光源」→ **越界卡拉瓦乔域**（§3.7、§8.1 L226）；出现「单张脸连续衰减 + 心理光斑」→ 伦勃朗域。
- **自检**：§8.2-3（框景 ≥25%、纵深 ≤2、无 ≥3 条汇聚透视线）、§8.2-4（正面/3-4 正面 ≥80%）、§8.2-1/2。

### 阶梯 2：神话题材的达显化——法器清单 + 双层动作 + 织物珠宝
- **观察对象**：《Saraswati》（法器清单 + 书作递出手势，§12-10）、《Draupadi Vastrapaharanam》（三方姿态叙事，§12-5）、《Hamsa Damayanti》（人-动物对视，§12-6）、《Galaxy of Musicians》（身份清单群像，§12-7）。
- **创作决策**（D4–D6）：先定「类型 vs 个体」——神祇/英雄走**理想类型脸**（跨画同款）；先定「叙事靠姿态不靠表情」；把织物珠宝当**身份清单**而非装饰。
- **机制**：M4（达显/类型化）+ M5（清单密度 + 暖调）+ M6（手部语义）+ M2（双层动作）。
- **参数**：P2 强（80–95%，理想脸 + 类型身）、P4 强（锦缎 + 全套珠宝）、P5 中–强（叙事 3/4 面向 ↔ 礼拜像完全正面）。
- **一次可做的练习**（§12-10/5/6/7 改写）：① 按「图像志清单」画一尊正面神像（法器 ≥3、对称、正面），另画一版 3/4 侧身叙事像，比较「达显 vs 叙事」；② 画一幕冲突（施暴/受害/干预三方各 ≥1 人），**仅用姿态与色区**完成叙事、不靠表情；③ 画 ≥6 人群像，每人一种服饰 + 一件乐器，光源统一、视线分两组；④ 每人物点检珠宝 ≥3 件、高光带 ≥3 条、褶皱线 ≥5 条、每手一个可命名动作。
- **反例**：把神祇画成「唯一脸/个体凝视 + 后印象派色彩调制」→ **越界谢尔吉尔域**（§3.8）；法器难读、多臂从简过度 → 破「看过即识、识过即拜」。
- **自检**：§8.2-4/5/6/7；§3.8 三判据（复制版式 / 类型 vs 个体 / 视线出画 vs 画内互视）。
