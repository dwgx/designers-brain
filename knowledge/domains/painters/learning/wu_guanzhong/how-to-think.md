## 2. 逐展开（每步：先选 / 牺牲 / 为什么[分栏] / 何时失效 / 等级）

<a id="db-source-line-42"></a>
### S1 · 先定「抽象动力」= 自然母题提炼
- **先选**：把对象当「白墙黑瓦的几何结构 / 藤蔓荷梗的线 / 山石的转折」，从自然形式里提炼点线面；不从「内在必然性 / 色彩-声音通感」出发。`[归纳]` §3.1 ③（`:83`）、§0 一句话定位。
- **牺牲**：零对象纯抽象、高纯多色族声部化、互补对撞。
- **为什么（分栏）**：
  - `[自述]`：「形式美是美术创作中关键的一环，是我们为人民服务的独特手法」（1979，§3-1 `:64`；§5-11 `:144`）；「我想造一座桥，是东方和西方、人民和专家、具像和抽象之间的桥」（§5-8 `:139`）。
  - `[归纳]`：§3.1 把「欧洲理论路径（内在必然/音乐性）」判给康定斯基、「水墨线/形式美路径」判给吴（`:81-83`）；**这是项目分工，不是吴冠中说过「我反对康定斯基」**。
- **何时失效**：任务明确要求「零对象 + 高纯互补对撞 + 声部化」→ 换康定斯基模块（§8.1 越界警报 `:228`）。
- **等级**：`[自述]`（形式美主张）+ `[归纳]`（动力归轴）。

<a id="db-source-line-51"></a>
### S2 · 先定「银灰统调 + 几何简化」身份门
- **先选**：P1 银灰统调 80% + P2 几何简化 75%（定调三件套含 P5 60%）。`[归纳]` §4 `:109-110`、§8.1 `:226`。
- **牺牲**：彩色区域主导、门窗/瓦当细节、写实水乡层次。
- **为什么（分栏）**：
  - `[归纳]`：§4 用法「**P1+P2 定『是不是吴冠中』**（银灰统调 + 几何简化；两条同时 ≥中档才成立）」（`:116`）；§8.2-1/-3 给出可判定阈值（`:52,54`）。**数值全是项目操作化，非史料、非像素实测**（`:117`）。
  - `[研究]`：苏富比「dots, lines, and planes」是其标志技法（§7-6）、HKMA 藏品说明支持白墙黑瓦几何化（§1-2）。
- **何时失效**：近抽象档《朱颜未改》——P2 几何黑/白块面被色块溶解、P1 银灰被「浓抹重彩」削弱，按字面「两条同时≥中档」会被判「不是吴冠中」；但 §4 P5 弱档又把同一作品列为 in-domain。**两侧并列，见 S6**。
- **等级**：`[归纳]`（身份门）。

<a id="db-source-line-60"></a>
### S3 · 先定「风筝线」P5≠0（乡土母题机制）
- **先选**：保留 1–3 个可辨锚点（燕/桥/屋/石/树），母题不是装饰而是「线」本身。`[归纳]` §4 P5 `:113`、§8.2-7 `:58`。
- **牺牲**：完全断绝物象与人情联系的纯抽象自由。
- **为什么（分栏）**：
  - `[自述]`：「如作品中绝无抽象、不写意，那便成了放不上天空的风筝。但当作品完全断绝了物象与人情的联系，风筝便断了线。我探求不断线的风筝！」（Q12，1983，`_corpus/wu_guanzhong.md:81-82`）；变体 Q13「线的另一端联系的是启发作品灵感的母体」（`:87-88`，`[self-written·转引]`，原书页码未核）。
  - `[归纳]`：把命题参数化为 P5 母题锚点残留（默认 60%、弱档 20–30% 仅留 1 锚点）、§8.2-7 面积 0.5–15%、§4 分工注「P5=0 且 P1 弱 → 越界警报」（`:118`）。**「P5=60%」不是吴冠中的话**。
- **何时失效**：P5=0 且 P1 弱 → 康定斯基域；P5=0 + P1 strong 是 AUDIT `counterexample.md` Attempt 2 登记的**边界洞**（既非 clean 吴、亦非 clean 康），本卡不把它当合法档，留待 E 系列实验。
- **等级**：`[自述]`（命题）+ `[归纳]`（参数/失效）。

<a id="db-source-line-69"></a>
### S4 · 起手「形式先行」再组织母题
- **先选**：先起草抽象形线构图，再让景物/人物适应它（巴黎壁画案例）；「写生即创作」，现场即可大幅重组（搬家写生）。`[自述]` §2-3、§2-1、§2-2（`dossiers/wu_guanzhong.md:48-50`）。
- **牺牲**：「习作→创作」二分、按对象逐笔描摹、固定视点。
- **为什么（分栏）**：
  - `[自述]`：「先起草四种音乐特色的形线抽象构图……然后组织人物形象，人物组合必须紧密适应形式在先的抽象形线构图」（§2-3）；「逐步减去房屋的具像细节，转化成几何结构之美」（§2-4 减法）。
  - `[归纳]`：§2-2「搬家写生/移花接木」被结构化为「3 张速写各取 1 元素重组为宽幅」（§12-2 怎么练）；**结构归项目，动作起点归自述**。
- **何时失效**：与康定斯基同屏分区、或 C-17 负空间 / 分层掩膜要求显式分区表时，「一整张形式先行」让位于分区表（`conflicts.md §3 N1/N4`）。
- **等级**：`[自述]`（决策来源）+ `[归纳]`（重组结构/失效）。

<a id="db-source-line-78"></a>
### S5 · 组合前先选「冲突主轴」（kandinsky 互洽 3 判据 + ④色彩角色）
- **先选**：把「母题残留度」或「色彩角色」**二选一**作主轴（N3 单主），同屏显式分区（康元素区 vs 吴线网区）。`[归纳]` §3.1 `:84`、§8.1 `:231`。
- **牺牲**：同屏双开「纯色声部 ↔ 银灰+彩点」两档标志机制。
- **为什么（分栏）**：
  - `[归纳]`：四判据自查表——① 母题来源 零对象（康）／1–3 锚点（吴）；② 媒介 油/版（康）／水墨+油彩互译（吴）；③ 抽象化动力 内在必然/音乐性（康）／自然形式简化（吴）；④ **色彩角色** 高纯多色族+互补对撞+声部化（康）／银灰统调+彩点浓缩（吴）（§3.1 `:83`）。
  - `[研究]`（互洽核验）：康卡 §3.1「vs 吴冠中」反向列 ①②③（`dossiers/kandinsky.md:86-88`）、`modules/kandinsky.md:71` 收「零对象＋油/版 vs 风景母题＋水墨，动力相反」→ **前 3 判据双向互洽**；④是吴卡侧专属补轴（康卡 §8.1 `:19-29` 以「色彩声部化」为默认档，并不自称「色彩角色判据」），**非矛盾**。AUDIT `RESULT.md §Conflicts.md locator drift` 判 A-74「与 kandinsky.md 互洽」holds。
- **何时失效**：同屏既「零对象+纯色声部」又「银灰+彩点浓缩」→ 双标准（N9）；出现「互补色对远看振动」的组织意图 → 按康卡处理（§3.1 越界判定 `:84`）。
- **等级**：`[归纳]`（四判据/组合纪律）+ `[研究]`（互洽核验）。

<a id="db-source-line-87"></a>
### S6 · 近抽象档决策：反例张力 carried（核心红线）
- **先选**：做《朱颜未改》式变体时，**同时**登记两侧，不选边、不抹平。`[inference]` 沿用 AUDIT `counterexample.md` Attempt 1。
- **牺牲**：给一个顺滑结论的便利。
- **为什么（分栏）**：
  - `[自述]`：「即使断了有形的线，却没有放弃手中的遥控」（Q14，`_corpus/wu_guanzhong.md:93-94`；§5-4 `:132-134`），同说明并引「道是无题却有题」；「我浓抹重彩，一味显示朱颜未改」（§5-3 `:130`，《文心画眼》）。
  - `[归纳]` 侧 A：§4 P5 弱档「锚点全沉（近乎纯抽象；**朱颜未改档**）」（`:113`）、§8.1 近抽象档「P5 降到 20–30%，仅留 1 个锚点，《朱颜未改》式——极端档，慎用」（`:227`）→ 把该作列为 **in-domain 档位**。
  - `[归纳]` 侧 B：§4 用法「P1+P2 同时≥中档才成立」（`:116`）→ 该作 P1 银灰被浓抹重彩削弱、P2 几何块面被色块溶解，按字面身份门会**拒绝**这件「真实、作者命名、HKMA 馆藏」的作品。
  - `[inference]`（AUDIT 口径）：Attempt 1 判 **counterexample found — internal inconsistency**；根因是 §4 阈值 `[归纳]`、未实测（`:117`、§10-12 `:312`），属**规则校准缺口**，不是被证伪的历史 claim，也不是把张力改写掉的理由。
- **何时失效**：若笔记只写「P5 弱档合法」或只写「身份门判其不是吴冠中」→ 本步失效（F3）。正确停位=「两侧并列 + `[inference]` + 待 E 系列组合实验」；Attempt 2（P5=0 + P1 strong 边界洞）与 Attempt 3（§8.1 `--no` 比 §4 分工注更严、措辞漂移）一并 carried，不升级为已验证。
- **等级**：`[自述]`（Q14）+ `[归纳]`（参数/身份门）+ `[inference]`（AUDIT 反例登记）。
