## 4. 何时整体失效（决策序的边界汇总，含强调③/④）

1. **【主边界】离开绘画默认档** → D2/D3/D4/D6/D9 的 §8.2 判分不再全局适用：早期具象档（§4 分工注 D:L109「P1 弱 + P2 弱 → 表现主义具象域，允许」）、版画 lane（§2-9 D:L57 黑白木刻「线的纯化」）是分开的 lane。**黑白木刻反例（强调④）正是这条边界的 `[inference]` 探针**：44 幅 B&W *Klänge* 木刻有 2 色族 / 0 互补对 / 0 高饱和，喂 §4+P3 与 §8.2-3 会被误判，但**不推翻规则在声明域内的成立**；review-evidence §4 复核「近单色档豁免」也解不了互补对 ≥1 / 色相族 4–8。判别动作＝预注册 E4 把 44 帧喂检查器、测参考帧分布后再决定是否加显式「版画/黑白档」豁免（本 leaf 不预填结果）。⟨K40⟩⟨K41⟩
2. **把 Q09 英文句当已核实英译** → D3 的「声部字典」被污染：G4 德文可用，英文引号句 + `[R5]` 标 `conflict / known-open`，译名 Sadler/Sadleir 双写加注（强调③）。⟨K30⟩⟨K31⟩
