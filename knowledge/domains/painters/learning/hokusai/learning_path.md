## 1. 前置知识（先知道什么，再开练）

1. **等宽线 + 平涂是「表面系统」的开关**：轮廓线宽恒定、同一元素内变化 ≤30%、无排线、无羽化；色块贴线平涂（档案 §1-1 `:29`、§8.2-1 `:199`；模块卡 `:45`）。**先分清「平涂/无排线」与「排线塑形」是互斥的表面系统**（C-07 `conflicts.md:136`）——否则后面自查全失准。这不是历史断言「北斋从不用明暗」，而是本模块默认输出的硬约束（档案 §8.1 禁令范围 `:192`）。
2. **普鲁士蓝主导 + 留纸当高光**：蓝系（普鲁士蓝＋靛）面积常 ≥40%（1830 年代「蓝色革命」，§1-2 `:30`、§8.2-2 `:200`）；浪花白＝纸白、不加白颜料（§1-9 `:37`）。开练前先认定「白是留出来的，不是画上去的」。
3. **运动拆成曲线族（波浪线组）**：浪/云/雾/瀑布被处理成可重复的图形符号（§2-10 `:53`）；同心曲线尺度嵌套 ≥3 级、每级曲率符号与上一级一致（同向弯）（§8.2-4 `:202`；参数 P4 `:76`）。这是「把自然力画成图形」的核心，也是本卡第一强调「波浪线组」。
4. **远近挤压 = 尺度戏法**：远景主体高度 ≤ 前景元素 1/4、且落在画面上/下 1/3 带内、不得压中线（§8.2-5 `:203`；参数 P3 `:75`，默认 80%）；主体中心偏离几何中心 ≥10%、存在且仅存在一条 15°–45° 主斜线、无单点透视消失点（§8.2-3 `:201`）。这是本卡第一强调「远近挤压机制」。
5. **绘→雕→印分工条款（大分工）**：画稿贴版后原稿即毁，成品由雕师与摺师完成；北斋曾写信给雕师 Egawa Tomekichi 与 Sugita Kinsuke 纠正眼鼻刻法并附样式示例（§2-7 `:50`，`[史料]` [R1]）。**这是「分工」，不是「一人一笔」**：练的是把「设计意图」写成可交接、可复刻的规则（等宽线、色版数、bokashi 段数），而非浪漫化的即兴。见 §3.6 / how-to-think.md 步 6。
6. **人物＝剪影 + 极简线、留白 ≥35%**：人物/船 ≤3 组、每组 ≤ 画面高 1/8、细节线 ≤6 条、不得遮挡主曲线族的「峰」（§8.2-7 `:205`）；天空/水面单色平涂或留白 ≥35%（§8.2-6 `:204`；参数 P6 `:78` 默认 40%）。
7. **史料定位与阈值诚实**：19 条语料 typing 已核（AUDIT RESULT §2、coverage_manifest `per_quote`），但**全部为转录底本**（原刊/影印未直读，corpus `:5`/`:138-140`），read_scope 为 `citation_context`；§8.2 的「蓝 ≥40% / 留白 ≥35% / 人物 ≤6 线」是**按馆藏图目测归纳的未实测参数**（档案 `:453`）。练的是「作品可见机制 + 模块自查阈值」，不是对原作的实测结论。
8. **locator 漂移（known-open，必须记住）**：`conflicts.md` 里 `hokusai.md L188/L189/L193` 是**过期绝对行号**；真实规则在档案 `:199/:200/:204`（§8.2-1/-2/-6）、模块卡 `:45/:50`（详见 §8「来源边界」、AUDIT RESULT §3 表 `:61-70`）。本卡一律用**冻结 head 实测行号**，不复制 conflicts.md 的旧 L 号。

## 3. 要观察的机制（练时盯什么）

1. **波浪线组 / 曲线族同向嵌套（第一强调）**：流体（浪/云/雾）由同心曲线构成、尺度嵌套 ≥3 级；每一级曲率符号与上一级一致（同向弯）；动画时相位错帧 ≥2 帧（§8.2-4 `:202`；模块卡 `:48`；P4 `:76` 默认 3 级）。§1-5 `:33`「大浪生成小浪、小浪生成波纹」是它的图像描述。[归纳]/[研究]（[R2]）。
   > **「大返回/возвращ」词条口径**：brief 强调里的 `возвращ` token 在冻结仓库与包内**无可匹配来源**（全仓 grep 仅命中 aivazovsky 的俄文抓取，与本卡无关）。本卡不虚构来源：把它映射到两条**确证**机制——(a) 曲线族的「同向回归」＝每级重复上级曲率符号（§8.2-4 `:202`，即「大浪→小浪→波纹」的大回环）；(b) 下条「绘→雕→印分工条款」。该词条记为 **known-open 口径注记**，见 §8、RESULT.md、[claim_evidence_map.md](claim_evidence_map.md)。
2. **远近挤压 / 尺度戏法（第一强调）**：远景主体 ≤ 前景 1/4 高、落在上/下 1/3 带、不得压中线（§8.2-5 `:203`；P3 `:75` 默认 80%）；配合非对称＋单条 15°–45° 主斜线、无消失点（§8.2-3 `:201`；P2 `:74` 默认 75%）。§1-4 `:32`、§2-9 `:52`（消化西法透视后「比欧洲人更有戏剧性」）。[归纳]/[研究]。
3. **等宽线 + 平涂（表面系统）**：线宽变化 ≤30%、无排线/羽化、过渡带 ≤1px（§8.2-1 `:199`）；主色 ≤7、蓝系 ≥40%（§8.2-2 `:200`）；留纸当高光（§1-9 `:37`）。[归纳]/[史料]（木版工艺）。
4. **负空间 / 留白**：天空/水面单色平涂或留白 ≥35%，留白内部无均匀噪点/渐变（除天空 ≤1 段 bokashi）（§8.2-6 `:204`；P6 `:78` 默认 40%）。[归纳]。
5. **人物剪影 + 不遮峰**：人物/船 ≤3 组、每组 ≤1/8 画高、细节线 ≤6 条，不得遮挡主曲线族的「峰」（§8.2-7 `:205`；P5 `:77`）。[归纳]。
6. **绘→雕→印分工条款（「大分工」强调）**：原稿贴版即毁、成品由雕师/摺师完成，北斋以书信＋样式示例纠正刻法（§2-7 `:50`，`[史料]` [R1]）；一版一色、先蓝摺后锦绘（§2-3 `:46`）；bokashi 靠「极细雕刻」（§2-5 `:48`）。**可迁移的操作含义**：设计意图必须写成可交接的离散参数（线宽、色版数、bokashi 段数、套色错位容差），而不是靠「手感」。[史料] 锚点 + [归纳] 操作化。
7. **版次痕迹 / 套色微错位**：线版与色版微错位、后印本线断云褪（§1-10 `:38`）；§8.1 prompt 正向段含 `slightly misregistered colour plates` `:180`。作为「平涂但不死板」的可观察细节。[史料]。

> 观察顺序建议：先 1（曲线族）→ 2（远近挤压）→ 3（线＋色）→ 4（留白）→ 5（人）→ 6（分工/交接）→ 7（版次）。前五步是「画面判据」，第 6 步是「工作流判据」，第 7 步是「质感细节」。

## 4. 具体练习（可操作 · ≥3 阶梯 · 全为「建议练习」）

> **每一级都带「可观察结果」「自查」「常见失败」**；自查引用 §8.2 原文规则作判据（不另造阈值）。执行介质为纸笔/数字笔临摹或重演（§12 `:346`）。练习条目部分沿用 §12 已有「怎么练」步骤（已标 locator）。**全部标 `建议练习`；练习效果未经真人验证，不声称已证实学习收益。**

<a id="db-source-line-63"></a>
### 阶梯 1 — 三级曲线族单色稿（nested-curve monochrome）

**目标**：只建立「波浪线组」——用一条等宽线把运动拆成 3 级同向曲线，不带色彩、不带人物、不带叙事。
1. 把《神奈川沖浪裏》的浪拆成 3 级曲线（大浪 / 中浪 / 泡沫爪），各级只许等宽线、各画 5 遍（§12.1 `:351` 步骤①）。
2. 检查每一级弯曲方向：曲率符号必须与上一级一致（同向弯），不得出现反向 S 扭（§8.2-4 `:202`）。
3. 用 2 色（蓝＋纸白）重画「浪与远山」，禁用渐变与排线（§12.1 `:351` 步骤②）。
4. 自查：§8.2-4 嵌套 ≥3 级 + 同向；§8.2-1 线宽变化 ≤30%、无排线；§8.2-2 蓝系 ≥40%（§12.1 `:351` 步骤③）。
- **可观察结果**：画面里能数出 3 个尺度的曲线族，且三级同向；全图只有一根等宽黑线 + 一块蓝 + 纸白；找不到排线或羽化过渡。
- **常见失败**：把浪画成写实水花/喷枪渐变（违反 §8.1 负向段 `:184-189`）；三级里有反向弯；曲线只有 1–2 级；线宽忽粗忽细。

<a id="db-source-line-73"></a>
### 阶梯 2 — 远近挤压 + 极简留白（scale-compression / negative-space）

**目标**：加入「远近挤压」与「留白」——把远景压到 ≤前景 1/4、主体偏轴、天空大留白，同时保住 L1 的曲线族不退化。
1. 只用 3 个明度（纸白/淡蓝/赤）画「晨空＋山」，限 20 分钟；天空渐变只许「一段式」（§12.2 `:356` 步骤①②）。
2. 把远景主体（富士/塔/船）压到前景元素 ≤1/4 高，放进画面上/下 1/3 带，禁压中线（§8.2-5 `:203`）。
3. 主体中心偏离几何中心 ≥10%，只留 1 条 15°–45° 主斜线，删掉所有单点透视消失线（§8.2-3 `:201`）。
4. 画「一山两候」变体：上半晴、下半雨，雷只用 1 条折线、云只用 2 块平涂，禁用喷枪/羽化（§12.3 `:361`）。
5. 自查：§8.2-5 尺度比 + 带位、§8.2-6 留白 ≥35% 且天空 ≤1 段 bokashi（§12.2 `:356` 步骤③）、§8.2-2 主色 ≤7。
- **可观察结果**：远景明显「被前景挤小」、偏在 1/3 带；整张只有 1 条主斜线；留白（含平涂天空）≥35%；仍能数出 L1 的 3 级同向曲线。
- **常见失败**：远景与前景同大或居中（P3 弱档 `:75`）；为「讲清透视」加消失点；天空多段渐变或满构图（P6 弱档 `:78`）；加第二/第三条斜线。

<a id="db-source-line-84"></a>
### 阶梯 3 — 系列化 + 分工交接（series & hand-off）

**目标**：把前两级纪律顶住不退化，同时做「一个母题×条件变化」的系列，并把设计写成**可交接的分工条款**（绘→雕→印）。
1. 画「水之四态」（檐溜/溪流/暴雨/涌泉）各一图，限等宽线与 3 色；每图 ≥3 级曲线嵌套（§12.9 `:391`；自查 §8.2-4）。
2. 或挑 1 图《富嶽百景》做「三灰阶结构图」，再自拟「富士的第 101 景」（3 灰阶＋ぼかし）（§12.6 `:376`）。
3. 挑一格做「岩石上一个人＋一张网」3 稿，人物 ≤1/8 高、细节线 ≤6 条，第 3 稿把人物再缩小一半比较戏剧性变化（§12.4 `:366`）；检查人物不遮挡主曲线族的「峰」（§8.2-7 `:205`）。
4. **写一张分工交接单**（本阶梯核心，对应 §2-7 `:50`）：列出线宽恒定值、色版数（≤7 色，蓝 ≥40%）、bokashi 段数（天空 ≤1）、套色微错位容差、留白比例——把它交给另一个人（或另一轮自己）按单复刻一版，比较两版是否落在同一 §8.2 判据内。
5. 自查：§8.2-1/-2/-4/-5/-6/-7 全套逐帧打勾（§8.2 `:199-205`）；「分工交接单」复刻版与原版判据一致。
- **可观察结果**：四态/101 景共享同一曲线族语法但条件不同；人物始终是剪影、不遮峰；交接单复刻版无需口头补充即可通过同一自查表。
- **常见失败**：系列里每图换一套线/色语法（分工条款失效）；为「丰富」加人物细节 >6 线或让人物挡住浪峰；回到写实渲染/渐变；把「分工」误读成「随意让别人改」，复刻版偏出判据却无记录。

> **阶梯间递进逻辑**：L1 曲线族 → L2 曲线族＋远近挤压＋留白 → L3 曲线族＋挤压＋留白＋系列化＋分工交接。每升一级，**已建立的波浪线组与远近挤压不得回退**（这正是 [mechanism_notes.md](mechanism_notes.md) 把 C-07/C-12/C-16/C-17 当作「失败条件」的用武之地）。三级全为**建议练习**，未渲染、未像素测量、未经真人学习效果验证。
