# LEARN-bruegel — How to Think（创作决策序）

> 本文件回答「做一张勃鲁盖尔式画面时，先选什么 / 牺牲什么 / 为什么 / 何时失效」，**不回答「勃鲁盖尔本人当时怎么想」**（00-GOAL.md :9）。

<a id="db-source-line-6"></a>
## 0. 铁律：自述 vs 推断，严格分栏

- 档案 :9 / :109 / 自审 B6 :406 / AUDIT X-4（supported）：勃鲁盖尔**无任何存世自述文字**——无书信、无笔记、无画论、无访谈（corpus L5：self-written=0）。最接近「自述」的两条 van Mander 转记（临终烧素描 Q13；「据他说」真理破壁 Q14，nae zijn seggen）按 [reported speech] 降级，**不作画论**。
- [自述] = 空集。所有「先选/牺牲/为何」= [归纳] 操作规则（从作品与馆方文字归纳，不冒充内心，档案 :69）。
- [史料] / [研究] 只给归纳步骤提供「作品/记述确实这样」的锚点，不升级为「他心里想」。
- 禁止：不因「画面像全景」就发明「他想画整个世界」之类心理；不把 §4 未实测阈值说成「他设定的」；不把 127 摹本 / Kapellekerk / Large Landscapes 说成创作意图。

## 1. 决策序（6 步，每步标证据级）

<a id="db-source-line-15"></a>
### 步 1 — 先选：把视点抬起来（P1 全景俯视）★
- **选什么**：鸟瞰全景，地平线上 1/4–1/3、俯角 ≥15°、无单一消失点主导（§8.2-1 :191；Q17）。默认 P1 70%（§4 :96）。
- **牺牲什么**：平视剧场构图、单点焦点透视、单一消失点轴、前景英雄特写。
- **为什么**：[研究] KHM x-321「让人群显形的唯一办法」(Q17)；[归纳] §4 用法把 P1 定为身份轴 (:103)。
- **何时失效**：P1 降到弱档（平视近景《农民婚礼》）却仍强判身份；出现单点硬光＋戏剧投影 → 越界卡拉瓦乔 (:103)；出现大留白/曲线族 → 越界北斋 (§3.1 :77-82)。
- **证据级**：决策 [归纳] / 锚点 [研究]。

<a id="db-source-line-22"></a>
### 步 2 — 再选：「一整年」的骨架（季节结构 + 共时叙事 + 单一基调）★
- **选什么**：季节作组画骨架（六件十二月、存五件，Q19/Q26）、同帧 ≥3 类时间状态 (Q16)、先定单一季节调子再铺细节（tone-first :56 / Q21「永久寒冷」）。P3 默认 65%（:98）。
- **牺牲什么**：单一事件叙事、全调域渐变、把季节当背景装饰、细节喧宾夺主。
- **为什么**：[研究] Q16「同地同时…勃鲁盖尔的发明」、Q19 3/1 岁首、Q21「不是细节总和而是整体效果」；六 vs 十二争议史如实并存 (§10-3 :238，AUDIT S1-4 supported)。
- **何时失效**：转成天气事件/能量场/漩涡 → 越界透纳 (:103)；季节模糊到读不出 (§8.2-4 :194)；把「六件」当无争议定论（AUDIT 记争议史）。
- **证据级**：决策 [归纳] / 锚点 [研究]。

<a id="db-source-line-29"></a>
### 步 3 — 铺：分布式农俗人群（P2/P4/P6 微观情节）★
- **选什么**：数十~数百匿名小人、每人一个独立动作、网格/环带/对角分布式、无主角无中心聚类（最大 ≤15%）；主场景可「嵌进、几乎藏进」(Q22)；农事/游戏/节庆/谚语为可解码民俗编码（§1-9 :42、Q17 230+/83）。P2 60% / P4 70% / P6 40%。
- **牺牲什么**：中心英雄、向心/旋转集中、单人特写、大留白、统一叙事动线。
- **为什么**：[研究] KHM「painted encyclopaedia」(Q17)、「slow and selective study」(Q17 注)、Q22 embedded；[归纳] §3-2 :67 人群=人类全谱而非英雄。
- **何时失效**：英雄化裸体＋向心旋转 → 越界米开朗基罗 (§3.1 :83-88)；单景裁切框景 → 越界北斋；新物种发明 → 越界博斯 (:89)；把主事件画 >5%（§12-9 :377）。
- **证据级**：决策 [归纳] / 锚点 [研究]。

<a id="db-source-line-36"></a>
### 步 4 — 定边界：软光 / 反理想人体 / 满构图 / 土色红点锚
- **选什么**：漫射天光无单点光源 (§8.2-8 :198)、短壮弯曲日常体（身高/肩宽 <4，§8.2-7 :197）、满构图 C-17 ≤15%、蓝仅远景大气 C-12、土色低饱和＋小面积红点 (§1-10 :43)。
- **牺牲什么**：单点硬光/戏剧投影、英雄化裸体、对称站姿、艳色/金属光/HDR、大负空间、主色蓝 ≥40%。
- **为什么**：[研究] Q24「realism bordering on idealism」、KHM x-331；[归纳] §4 六越界警报 :103。
- **何时失效**：C-01（硬光侧与卡拉瓦乔互斥，须显式声明软侧同侧，§8.3-1 :206）、C-09（运动预算静侧）、C-12 / C-17。
- **证据级**：决策 [归纳] / 锚点 [研究]。

<a id="db-source-line-43"></a>
### 步 5（关键）— 身份判据前先过媒介轴：Large Landscapes「吸入前」反例 ★
- **选什么**：任何「是不是勃鲁盖尔」的判断，**不得只用** P1/P2/P4 视觉阈值（≥2 中档）；必须联合 §3.1 媒介/系列骨架轴（≥2 轴联合、限定绘画 :81），先问「油画成套板 vs 版画母题连作」。
- **牺牲什么**：把「像不像」当「是不是」的充分判据；把纯视觉规则的充分性当定论。
- **为什么**：[inference] 作者本人 Large Landscapes 版画设计（1555–56，Hieronymus Cock，40+ 件）同样鸟瞰 Weltlandschaft 全景 (:54/:129)＋可含分布式小人物＋系列化（母题连作）——AUDIT §H L140-146、档案 :17/:81/:129/:257/:280/:401、wiki 缓存命中「Large Landscapes…published by Hieronymus Cock」。纯视觉阈值会把它与「油画全景」同判，从而与 §3.1「限定绘画、北斋=版画单景」的媒介轴冲突。AUDIT 判定：**不推翻**数值阈值，只削弱「充分判据」读法；档内已用 :81 边界注＋自审 B1（:401 WEAKENED→补注）预先承接。实验层 [UNVERIFIED]（未做像素级组合实验）。
- **何时失效**：把反例讲成「推翻 §4」；把 127 件摹本（可复制性史实）误当风格参数或反推「原作是版画」；把 Kapellekerk（生平时间轴）误当画面元素；把 [inference] 说成像素实验已证。
- **证据级**：反例 [inference] / 实验层 [UNVERIFIED] / 锚点 [史料]+[归纳]。

<a id="db-source-line-50"></a>
### 步 6 — 工作流：tone-first + 消化自然，不冒充心理（流程层）
- **选什么**：先定季节调子 → 分布式活动 → 民俗符号 → 距离导引（§12 尾 :384「季节组画四步」）；素材「吸收/消化再吐回」（§3-8 :73 / Q9「吞下阿尔卑斯」/ JHNA Ribouillault 2016 消化论 R8）。
- **牺牲什么**：对景写生式复刻、无准备的「随意」、把轶事当心理证据。
- **为什么**：[研究] Q21 / Q9 + Ribouillault 2016；[归纳] 操作序列，置于最后因它不改变画面机制。
- **何时失效**：把「消化自然」误读成「不观察」；用结果图反推作者意图。
- **证据级**：决策 [归纳] / 锚点 [研究]。

> 步 5 是本片相对其他画家的**特有决策步**：把「反例」变成创作前的身份预检，而非事后辩解。步 6 是流程，不改变机制。

## 3. 「不冒充心理」自查

1. 本文件是否出现「他想 / 他认为 / 他为了表达…」？→ **应为空**；所有动机写成「操作规则/可观察结果」。
2. [自述] 是否为空？→ **是**（无画论；两条转记按 [reported speech] 降级，不作依据）。
3. 每条决策是否带证据级、锚点指向 corpus / 档案 §1–§5 / AUDIT §H？→ 是。
4. 是否把画面外观直接当心理？→ 否；「全景/百科」只作可见机制（[研究]）。
5. 是否把未实测阈值说成「他设定的」？→ 否；§4/§8.2 全程标 [归纳] 未实测 (:200/:239)。
6. 是否把 127 摹本 / Kapellekerk / Large Landscapes 史料锚误当参数或心理？→ 否（见步 5、learning_path.md §3.6）。
