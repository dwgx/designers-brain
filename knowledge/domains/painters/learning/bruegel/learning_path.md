## 3. 要观察的机制（6 条；强调项标 ★）

<a id="db-source-line-48"></a>
### ★3.1 全景俯视（bird's-eye panorama）— 身份轴 P1
- **机制**：视点抬到人群与风景之上，连续全景无断，地平线高置、无单一消失点主导。KHM 原文「让人群显形的唯一办法」（Q17）。
- **可观察量**：地平线在上 1/4–1/3；俯角 ≥15°；引导线消失点 ≥2 组或散点（§8.2-1 `:191`）。
- **参数**：P1 弱=平视近景（《农民婚礼》档）/ 中=低俯中景 / 强=高俯全景（《儿童游戏》《雪中猎人》档），默认 **70%**（§4 P1 `:96`；卡 `:61`）。
- **级**：`[研究]`（视角事实）+`[归纳]`（档位/阈值，未实测）。

<a id="db-source-line-54"></a>
### ★3.2 农俗场面机制（distributed micro-episodes / crowd-as-encyclopaedia）— 身份轴 P2/P4
- **机制**：数十至数百匿名小人，**每人一个独立动作**（劳作/休息/游戏/仪式/旁观），按网格/对角/环带分布式铺开，无主角、无中心聚类；主场景可「嵌进、几乎藏进」大场景。农事（刈草/收割/牧归）、游戏（83 种）、节庆（狂欢节/四旬斋）、谚语（约百条）都是**可解码的民俗编码**（P6）。
- **可观察量**：人物 ≥30（中）/≥100（强）；最大人物聚类 ≤15% 画布；人物高度中位 ≤画高 1/15；姿态重复率 ≤30%；同帧 ≥3 类时间状态（§1-2 `:35`、§1-3 `:36`、§8.2-2/3/5 `:192-195`）。
- **参数**：P2 默认 60%、P4 默认 70%、P6 默认 40%（§4 `:97/:99/:101`）；「纯观察（《收割者》《农民婚礼》）→ 1–3 民俗元素 → 全画百科（《尼德兰谚语》《儿童游戏》）」。
- **级**：`[研究]`（馆方「painted encyclopaedia」）+`[归纳]`（人数/分布/编码密度操作化）。

<a id="db-source-line-60"></a>
### ★3.3 季节基调先行（tonal unity / seasons as structure）
- **机制**：季节不是背景而是**组画骨架**；「不是细节总和，而是整体效果」——先定单一季节调子（雪→冬、黄绿→夏、棕金→秋），细节服从整体；用「永久寒冷」证明色调写温度。
- **可观察量**：全帧色相族 ≤4；季节可判（雪白 ≥15%→冬）；前景暗框→中景亮带→远景蓝灰三段明度（§1-5 `:38`、§8.2-4/6 `:194/:196`；corpus Q20/Q21）。
- **参数**：P3 默认 65%（§4 `:98`）；土色低饱和＋红点锚（§1-10 `:43`）。

<a id="db-source-line-65"></a>
### ★3.4 软光 / 反理想人体 / 满构图（边界机制）
- **漫射天光、无单点光源**（§8.2-8 `:198`；§8.1 负向段 `:175`）；**短壮弯曲的日常身体**（身高/肩宽 <4、对称站姿 ≤20%）；**满构图**（C-17 负空间 ≤15%，蓝仅作远景大气 C-12）。
- **级**：`[研究]`+`[归纳]`；与卡拉瓦乔/米开朗基罗/北斋的「越界警报」见 §4 用法 `:103`。

### ★3.5 Large Landscapes 反例 —「吸入前」（pre-absorption）必须讲清的一课
> 这是 brief 点名的 counterexample，AUDIT [claim_evidence_map.md](claim_evidence_map.md) §H（L140–146）已作为 `[inference]` 反例接受、review-evidence §5 复核其逻辑成立且 wiki 锚点存在。

- **目标规则**：§4 用法 `P1/P2/P4 ≥2 条 ≥中档 ⇒ 「是不是勃鲁盖尔」`（档案 `:103`；§8.2-1 `:191`），以及 §3.1 的「vs 北斋＝油画全景 vs 版画单景」写死条款（`:77-82`）。
- **反例构造 `[inference]`**：勃鲁盖尔**本人**为 Hieronymus Cock 设计的 **Large Landscapes 版画系列（1555–56，40+ 件）**同样具备 ① 高视点 Weltlandschaft 世界风景全景（§2-6 `:54`）、② 可含分布式小人物、③ 系列化（母题连作）。按 P1/P2/P4 的**纯视觉阈值**，这些**版画**会与「勃鲁盖尔绘画全景」同判为「是勃鲁盖尔」——于是和 §3.1「限定绘画、北斋＝版画单景」的**媒介轴**冲突：同一作者、同一鸟瞰语汇、不同媒介，视觉规则给不出区分。
- **判定（AUDIT 已接受）**：**不推翻** §4 数值阈值本身（它是 `[归纳]` 操作阈值，非身份定义），但证明「视觉阈值 ≥2 中档」若被读作**充分身份判据**则过强；必须**联合 §3.1 媒介/系列骨架轴**（≥2 轴联合，尤其「媒介/系列骨架」）。
- **「吸入前」含义（教学用）**：dossier 其实已用 §3.1 边界注（`:81`「判定须以 ≥2 轴联合」「限定绘画」）与自审 B1（`:401` WEAKENED→补注）**预先承接**了这个反例。学习路径要把「**先讲原始强规则 → 再亲自用作者自己的版画把它撞穿 → 再看档内预吸收的边界注**」作为固定顺序；否则学生会误把「像不像」当成「是不是」的判据。
- **证据层**：文本层反例；AUDIT RESULT §6 标 `[UNVERIFIED]`（实验层未做像素级组合实验），本路径不升级、不补做实验。锚点：档案 `:17/:81/:129/:257/:280/:401`；wiki 缓存「Large Landscapes」×2；AUDIT §H [claim_evidence_map.md](claim_evidence_map.md)；自审 B1/B3。

## 4. 具体练习（3 阶梯，均为「建议练习」）

> 骨架复用档案 §12（10 件「看什么/学什么/怎么练」）与 §12 尾 `:384` 的组合建议；本路径重排成**先判视角 → 再铺农俗 → 最后用反例自检**的阶梯。每阶给「可观察结果 + 自查 + 常见失败」。**本轮未渲染、未像素测量；效果未经人评。**

<a id="db-source-line-89"></a>
### L1 — 单季全景的「先把视点抬起来」
- **做**：画「一个季节」：限 3 个色相族 + 1 条导引斜线 + ≥15 个小人；地平线置于上 1/3、无单一消失点（§12-1 `:337`）。
- **可观察结果**：转灰度后「前景暗框 / 中景亮带 / 远景灰」三段明度仍成立；季节能被读出来（§12-2 `:342` 同构图换色温对照）。
- **自查**：地平线位置？俯角是否 ≥15° 感？是否存在单一消失点轴？
- **常见失败**：平视剧场构图（P1 弱档却想强判身份）；单点硬光/戏剧投影（越界卡拉瓦乔，`:103`）；细节抢整体（违反 tone-first `:56`）。

<a id="db-source-line-95"></a>
### L2 — 农俗场面的「人群调度三档」
- **做**：画「一场劳作的中午」：≥20 人、≥3 类活动（工作/休息/进食）、1 棵前景大树、**禁止中心人物**（§12-3 `:347`）→ 进阶「一场群体活动」≥40 人、每人独立动作、用方格网查分布均匀度（最大空区 ≤10%，§12-7 `:367`）→ 进阶「一场宴席」≥15 人、仅用一条服务动线组织（§12-5 `:357`）。
- **可观察结果**：无一人被读成主角；视线被导引到纵深而非汇聚到某事件；转灰度后人群仍「铺满全画」。
- **自查**：人物计数？姿态重复率？最大聚类 ≤15%？同帧时间状态 ≥3 类？民俗元素每个 ≤3% 画布且能被他人盲猜（§12-4 `:352`）？
- **常见失败**：向心/旋转集中（越界米开朗基罗，`:103`）；单点大留白/曲线族（越界北斋）；把「主事件」画成 5% 以上（§12-9 隐藏术 `:377`）。

<a id="db-source-line-101"></a>
### L3 — 反例自检：「像不像」≠「是不是」
- **做**：用 L1/L2 的同一套视觉阈值，刻意产出**两件**同构图的作品：(a) 标为「油画季节全景」、(b) 标为「为出版商做的版画/母题连作」；然后**只按 P1/P2/P4** 让同伴判断「是不是勃鲁盖尔」，记录两件是否被同判。再补交 §3.1 四判据（媒介与复制性 / 画面结构 / 系列骨架 / 人物与自然关系，`:80`）重新判定。
- **可观察结果**：学生能说出「纯视觉阈值把 (b) 也判成是 → 阈值不是充分判据 → 必须联合媒介/系列骨架轴」；并能指出档内哪一句已预先承接（`:81` 边界注、`:401` 自审 B1）。
- **自查**：是否把 127 件摹本误当成风格参数？是否把 Kapellekerk 误当成画面元素？是否把 `[inference]` 反例说成「已由像素实验证明」？
- **常见失败**：把反例讲成「推翻了 §4」（AUDIT 判定为**不推翻**数值规则、只削弱充分性读法）；把转记「据他说」当自述画论；把未实测阈值说成「画家设定」。
- **证据级**：练习设计 `[归纳]`；反例 `[inference]` / 实验层 `[UNVERIFIED]`（AUDIT §H）。

> 组合练习（档案 `:384`）：第 1/2/3/4 件练「季节组画四步」（基调→活动→符号→距离）；第 5/6/7 件练「人群调度三档」；第 8/9/10 件练「主场景隐藏与尺度」。A/B 对照轴＝§3.1 分工判据（vs 北斋媒介骨架 / vs 米开朗基罗人体理想度 / vs 博斯怪诞来源）。
