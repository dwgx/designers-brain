## 4. 具体练习（阶梯；全部为「建议练习」`[归纳]`，未经人评）

> 三条阶梯按作业顺序设计：先建白上加白/高调去黑（M1）→ 再叠海滩逆光 + 透光白/反光白（M2）→ 最后做正午顶光长笔触 + 反光网 + 摄影裁切（M3+M4），并全程带分工边界自律（M5）。每条含「可操作动作 / 自查 / 完成定义」，**不声称学习收益**。

<a id="db-source-line-65"></a>
### 阶梯一 · 白上加白 / 高调去黑（M1）
- **动作**（改写自 §12-6 `怎么练`，`dossiers/sorolla.md:364`）：单一题材（白衣/白布/白裙）画 5 张 30–90 分钟小稿，只准用「白 + 3 色」；每张要求白区 ≥3 档色温。再补一张「白帆 + 浪花 + 湿沙」同屏练习（§12-1 `怎么练`：白+钴蓝+紫+一点橙四色，`:344`）。
- **自查**：直方图平均明度 ≥72%、纯黑 ≤0.3%、暗部色相 H 230–290°；白区色相聚类 ≥3 簇、明度范围 ≤8%（§8.2-1/-2）。
- **完成定义**：5 张里至少 3 张自查通过；能口头指出每张白区的 3 档色温分别落在哪。
- **失败对照**：出现褐黑阴影、白区 1 档/灰白渐变 → 记入 §6。

<a id="db-source-line-71"></a>
### 阶梯二 · 海滩逆光 + 透光白/反光白（M2，**本路径强调项**）
- **动作**（改写自 §12-7 `怎么练`，`dossiers/sorolla.md:368`）：逆光窗帘/晾晒白裙/海边白衣写生 3 张，重点画「透光的白」；再取 §12-6 的「反光里白被打碎成玫瑰与蓝」做一张对照（`:362-364`）。同一白裙对象画「顺光 / 侧逆光 / 正逆光」三张，只变光向，不许变构图。
- **自查**：逆光张里透光白（半透布料/被光穿透的白）与反光白（湿皮肤/湿沙高光旁的橙-玫瑰-丁香反光白）是否分成**不同明度/色温层**；橙/桃反光是否贴着高光；整张仍满足 M1 高调去黑（逆光≠剪影近黑）。
- **完成定义**：三张里能明确区分「透光白」与「反光白」各一层，且无一张把逆光画成近黑剪影。
- **失败对照**：逆光=黑剪影、白裙=单色白、反光用灰 → §6。

### 阶梯三 · 正午顶光长笔触 + 反光网 + 摄影裁切（M3+M4）

## 6. 常见失败（与 §3 失败形态、§4 失败对照对应）

1. **黑褐阴影 / 纯黑 >0.3%**：把逆光或暗部画成黑褐、巧克力棕 → 违 §8.2-1、§8.1 负向 `dark brown or black shadows`，也丢掉 corpus #16「紫罗兰是印象派唯一发现」（`_corpus/sorolla.md:125-130`）。→ 改紫/蓝紫短影。
2. **白区单档 / 灰白渐变（明度范围 >8%）**：把「白上加白」误做成「一片白 + 明暗渐变」→ 违 §8.2-2。白上加白 = 高明度**窄域** + **色相**变化，不是明度变化。
3. **逆光 = 黑剪影**：把「海滩逆光」做成低-key 剪影 → 同时违 M1 高调 + M2 透光白分层。透光白仍是亮部、仍带色温。
4. **碎短笔触分解色点**：把长笔一笔定型画成莫奈式短逗号并置 → 越界 **莫奈**（`dossiers/sorolla.md:82` 笔触轴、`:85` 莫奈 P3 只许弱档）。或把笔触抹平 → C-05 对侧。
5. **统一雾色 / 晨昏 / 雨雾天气事件**：→ 越界 **莫奈/透纳**（`modules/sorolla.md:66` 警报①⑤）；索罗拉天气 = 恒定晴天档。
6. **色板收窄为四色封闭 / 北窗受控光**：→ 越界 **佐恩**（`modules/sorolla.md:66` 警报②、`zorn.md:95` 四轴 mirror、N3 色板宽度单主）。
7. **暗背景塌陷黑 / 画外单光源**：→ 越界 **卡拉瓦乔**（`modules/sorolla.md:66` 警报③），索的暗部是**彩色透明**。
8. **中心对称完整构图 / 完整地平线 + 天空**：→ 违 §8.2-6 摄影裁切（`dossiers/sorolla.md:190`）。
9. **把 §4 阈值套到全部作品**：把《¡Triste herencia!》或 2 张暗调室内件判为「违规则」→ 量词/范围错误；见 §8、AUDIT counterexample。
10. **把阈值写成史料 / 作者自述**：「索罗拉规定明度 ≥72%」是错的，那是本项目 `[归纳]` 操作阈值。
11. **转记当心理证据**：「我恨黑暗」「画室只是个车库」是 1909 `[reported speech]` 转记，不写「索罗拉内心厌恶…」（00-GOAL.md:9、corpus header L6）。
