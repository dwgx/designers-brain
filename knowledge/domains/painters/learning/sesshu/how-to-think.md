## 2. 逐展开（每步：先选 / 牺牲 / 为什么[分栏] / 何时失效 / 等级）

<a id="db-source-line-44"></a>
### S1 · 先定「构造装置，不是滤镜」
- **先选**：先立骨架——斧劈直线段组（≥60%、单段 ≤8% 画高）+ 岩组 ≥3 层、接缝明确；再谈墨面/空气/留白。
- **牺牲**：先铺氛围再补形的顺序；把「水墨」当风格贴纸。
- **为什么（分栏，不混写）**：
  - `[归纳]`：dossier `:9,:21` 能力定位「日本水墨 / 破墨山水」+ `:149` §6.2 一句话「先立骨架 → 破墨/泼墨做空气 → 实景再構成 → 移动视点」——**这是项目对能力的结构化，不是雪舟说过「我是构造装置」**。
  - `[研究]`：[R5]「構築的で堅固な画面構成」(`:156`)、[R17]「assertive rock contours… angular brushstrokes」(`:164`) 为馆方/西方研究对「构造性」的二手支撑。
- **何时失效**：题材 = 单主体悬置 / 极简空场 / 花卉大写意 → 按 §3.1 换八大/徐渭模块（`:80-86`）。
- **等级**：`[归纳]`（定位）+ `[研究]`（史实支撑）；失效 `[归纳]`。

<a id="db-source-line-53"></a>
### S2 · 破墨工序（本卡强调①前半）
- **先选**：淡墨先画要所（崖/树/远山），**未干时点入浓墨**使墨色互破成面；墨面可溢出轮廓，但「確かな骨組み」骨架线始终可读。
- **牺牲**：一次画完再罩染的可控性；把墨面补描回硬轮廓。
- **为什么（分栏）**：
  - `[自述]`：破墨山水図自序「相随ひて設色の旨と兼ねて**破墨の法**を伝ふ」(`dossiers/sesshu.md:120` §5-2；`_corpus/sesshu.md:20` Q2，「書き下し文」，汉文冒頭以東文研 #3148 互证)——「破墨」称呼的自述来源之一。
  - `[史料]`：§2-1 破墨法（`:53`，引 [R2] 衛藤駿「淡墨で絵の要所を描いたのち、それが乾かないうちに濃墨を点ずる技法」）；§2-2 泼墨「輪郭線を用いず…粗放な画法」但「確かな骨組み」仍在（`:54`）；[R3] e国宝（`:155`）。
  - `[归纳]`：§8.2-3 把上述工序翻译成逐帧可判定阈值（边缘梯度 ≤2/255、区内 ≥1 条浓墨结构线、洒点方差 ≤30°，`:204`）——**翻译动作归研究者**。
- **何时失效**：墨面吞掉骨架线 / 一次成型灰平涂块（§8.2-4 `:205`）；或单看「有无泼墨」把雪舟判成徐渭（`:85` 边界注①：破墨洒点与徐渭泼墨同族，须以题材与空间轴为主、联合 ≥2 轴）。
- **等级**：`[自述]`（称呼来源）/ `[史料]`（工序）/ `[归纳]`（判据与失效）。

<a id="db-source-line-63"></a>
### S3 · 留白作云水（本卡强调①后半）
- **先选**：留白（纸色 ±5%）30–60% 服务于云/水/气，≥1 条横向云带贯通 ≥50% 画宽；水面留白与云带可区分（波纹线 ≤3%）。
- **牺牲**：满构图 / 填满细节；「单主体悬置 + 大空场」的极简表达。
- **为什么（分栏）**：
  - `[归纳]`：§1-5（`:40`）、§8.2-5（`:206`）、§4 P4 默认中 35%（`:107`）——**留白率是项目阈值，非史料、非雪舟自述、非像素实测**。
  - `[研究]`：[R4][R17] 对「移动视点 / progressive vision / 云雾」的分析（`:41,:164`）为云气/留白作为空间手段的二手支撑；**不把「留白」解释成雪舟的禅意心理**。
- **何时失效**：留白 = 「单主体悬置 + ≥60% + 一笔造型」→ §4 越界警报②（`:111`）；留白 >60% 又不显式取值 → 40–60% 交集争议（`:85`，见 S5）。
- **等级**：`[归纳]`+`[研究]`；失效 `[归纳]`。

<a id="db-source-line-72"></a>
### S4 · 墨阶 + 淡彩克制
- **先选**：墨色明度分层 4–5 带；淡墨（降幅 ≤40%）≥35%、浓墨（降幅 ≥70%）≤25%；淡彩仅薄罩（S ≤30%、色相 ≤2 族）。
- **牺牲**：重彩 / 高饱和 / 平涂色块。
- **为什么（分栏）**：`[研究]` §1-3（`:38`）、§1-9（`:44` [R9]「寒々しい色の淡彩」）、§2-5（`:57` 田中一松评）；`[归纳]` §8.2-4（`:205`）、§4 P6（`:109`）。**二者不混为一句自述**。
- **何时失效**：等宽线 + 平涂 + 蓝 ≥40% → 越界北斋（`:111` 警报④，C-12）；画内单光源 + 暗部塌陷 → 越界卡拉瓦乔/伦勃朗（警报⑥）。
- **等级**：`[研究]`+`[归纳]`；失效 `[归纳]`。

<a id="db-source-line-79"></a>
### S5 · 40–60% 交集分工（**纯 `[归纳]` 步**，本卡强调②）
- **先选**：组合帧的 P4 一旦落在 **40–60% 交集区**（雪舟留白 30–60% ∩ 八大留白 ≥60%），**显式写出 P4 数值**（如 55%），并**联合 ≥2 轴**判定（①题材与空间为主 ②轮廓 ③笔数预算 ④情绪温度），按 §3.1 组合纪律选主导轴（建议 70/30 起）。
