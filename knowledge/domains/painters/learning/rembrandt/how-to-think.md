## 0. 写作纪律（本文件如何读）

- **严格分区**：`[自述]`（伦勃朗本人书信/手迹/题字，带出处）与 `[归纳]`/`[研究]`/`[史料]` **分开列、不混写**。伦勃朗**有**真实自述（不同于维米尔），但**没有一条自述规定过数值阈值、决策顺序或「连续衰减」这个机制词**——机制词全是本项目归纳。

## 4. 何时整体失效（决策序的边界汇总）

1. **出现硬切光斑 / 亮暗两级无过渡 / 无反射单光源** → D0/D2 失效，判卡拉瓦乔模块，换模块或降档（§8.1 L253；N3）。
2. **与达·芬奇组合且借 sfumato** → D2 失效：本模块渐变必须「有方向」（沿光轴单调），禁全画无向柔边（卡 L100）。
3. **默认柔光语境（Lane B / 3D 卡）** → D2/D5 被同化：须显式写回 `directional + deep readable darks`（C-01 / dossier §8.3 L268-272）。
4. **题材本身无叙事动作（正式合影/静物/图标）** → D4 失效；「≥2 进行时动作」不写入判分。
5. **静态图被套动画专属项**（§8.2-7 全帧光强漂移 / 光斑漂移 ≤2px/帧）→ 收口误用（01-AUDIT.md）。
6. **known-open 不进决策**：§C 的 near-miss 11/8 计数漂移、§D《夜巡》反例未决、RF 单源边界都不改变上述任何一步的依据等级；它们只在 `RESULT.md` / `receipt.unresolved` / [claim_evidence_map.md](claim_evidence_map.md) 登记。
