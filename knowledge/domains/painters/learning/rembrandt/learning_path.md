## §1 前置知识（先具备什么，再开练）

1. **先接受分工条款（写死）**：伦勃朗 = 光的**连续衰减 + 心理**；卡拉瓦乔 = 光的**开关 + 物理**（dossier L6/L70/L108；卡 L93；AUDIT RE-DIV-01 `validated_rule`）。判分口径：出现「硬切光斑 / 亮暗两级无过渡 / 无反射单光源」→ 越界到卡拉瓦乔，换模块或降档（§8.1 中文说明 L253）。**这是两人组合时的冲突轴 = 光的衰减方式**（N3 轴所有权）。
2. **三个要先分清的「层」**（02-EXECUTION-PLAN.md L64 学习顺序）：

   - **创作原则层**（`[自述]` 仅 §3-1/§3-2 两条画论/展示条件，及 §5 十处原话）：`die meeste ende die naetuereelste beweechgelickheijt`（情绪/动作最大值）、「挂在强光里、站得远远地看」。**伦勃朗有真实自述**（与维米尔不同），但**自述不规定任何数值阈值**。

3. **最小工具/概念**：单侧平行光、亮度梯度/单调性、连通域分析（高光）、分区亮度均值、暗部局部亮度标准差（std）、色相聚类、高频纹理能量、线密度-亮度回归。这些是 §8.2「自查方法」列要求的量（dossier L255-L265），**不是史实**。

## §4 三段练习阶梯（建议练习，顺序 = 观察→决策→机制→参数→一次练习→反例→自检）

> 全部练习为建议练习、效果未经人评（01-AUDIT.md §8.1 L273）；§8.2 七阈值均为 `[归纳]` 未实测、只作为**自查口径**而非史实。

<a id="db-source-line-63"></a>
### 阶梯 1：光暗分区（单人 / 自画像式变奏）
- **观察对象**：自画像序列（1628 小自画像：光从脑后一侧进入、脸大部沉入暗部；1669《63岁自画像》：亮部厚涂）。dossier §12-1 L426-428。
- **创作决策**（how-to-think D1）：先定光斑地图，再压暗其余；牺牲「照亮整张脸」与「表情可读」。
- **机制**：M1 + M2 + M3（连续衰减而非开关）。
- **参数**：P1 强–中、P2 强–中、P3 中（§8.1 中文说明 L250）。
- **一次可做的练习**（§12-1 L428）：① 同一头像画三张：侧光/逆光/烛光（各限 40 分钟）；② 眼窝区平均亮度 ≤ 面部平均 60%；③ 生成式：固定 prompt 只改 `light direction / falloff steepness / number of highlights`，4–6 张成组自查。
- **反例**：出现硬切光斑 / 亮暗两级 → 越界卡拉瓦乔（§8.1 L253）；暗部死黑或纯黑>5% → 破 M3。
- **自检**：§8.2-1（连通域 [3,7]）、§8.2-2（单调 ≥80%、过渡带 ≥8px、阶跃 ≤1%）、§8.2-3（暗部 std ≥2/255、纯黑 ≤5%）。

<a id="db-source-line-72"></a>
### 阶梯 2：群像叙事（「正在做事」）
- **观察对象**：《夜巡》（队长下令、卫兵列队、光聚焦手势/女孩）、《蒂尔普解剖课》（七人视线不同）、《呢商行会理事》（全体抬头）。dossier §12-4/2/8。
- **创作决策**（how-to-think D2）：先写「这一刻正在发生什么」，把光当作叙事聚光灯；牺牲「排排站静态肖像」与「平均照亮每个人」。
- **机制**：M5 + M1（光斑＝叙事关键物）+ M6（视线/手势为叙事主语）。
- **参数**：P2 强档（亮斑 4–7 处成「地图」但全部与关键物相交）；P3 强档（暗部 ≤8–10% 但保微层次）。
- **一次可做的练习**（§12-4 L439 / §12-2 L430）：① 写一张 5 人「出发前一刻」分镜，至少 2 个进行时动作；② 光只允许落在 3 个关键物上；③ 画七人圆桌、每人视线方向不同，画视线向量图检查不聚成一点；④ 临摹只做「三个亮块」（脸/手/纸）再压暗其余。
- **反例**：排排站静态肖像 → 无 M5；视线聚成一点 → 退回旧式行会肖像；硬切光 → 越界。
- **自检**：§8.2-2（衰减连续）、§8.2-1（连通域 [3,7] 与关键物相交）、M5「≥2 进行时动作」。
- **单源诚实**：「第一个画正在做事的群体肖像」保持 CC-4 单源口径，练习里只用「进行时动作」这个可观察量，不把「第一个」写成定论。

<a id="db-source-line-82"></a>
### 阶梯 3：材质与版画（光的另一载体）+ 收口
- **观察对象**：《三棵树》《百盾版画》（线密度＝明度）、《犹太新娘》（笔杆划痕）、《伯沙撒的盛宴》（亮部厚涂/暗部薄画）。dossier §12-3/5/6/9。
- **创作决策**（how-to-think D3）：选「厚涂」或「排线」作为光的载体；版画模式启用 P6、改用 §8.2 规则 5 判分；牺牲「平滑过渡」与「1px 描边」。
- **机制**：M4；P6 强档「线密度=f(明度) 连续」。
- **一次可做的练习**（§12-5 L444 / §12-6 L448）：① 放大《三棵树》右半天空临摹排线密度梯度（3–4 档）；② 拟合线密度-亮度 R² ≥0.8；③ 用「加线压暗」法改一版（模拟第二态）；④ 亮部厚涂、暗部薄画、最后用笔杆划 3–5 道湿痕。
- **反例**：用 crossfade 冒充形变 / 无交叉排线 / 最亮区留白 >20% → 破 §8.2-5。
- **收口自查**：跑 §8.2 七条逐帧自查；按 §4 分工口径判「这个需求还是不是伦勃朗」（出现硬切即越界）；按 §8.1 中文说明 L253 换模块或降档，而不是去改阈值。
