## 2. 逐展开（每步：先选 / 牺牲 / 为什么[分栏] / 何时失效 / 等级）

<a id="db-source-line-41"></a>
### S1 · 先定「表达 > 再现」
- **先选**：不复制眼前所见，用色为表达服务（§3-1 `:63`、§5 R3 `:115-116`）。
- **牺牲**：固有色、写实光、形似可核对性。
- **为什么（分栏）**：`[自述]` 信 663 `I use colour more arbitrarily in order to express myself forcefully` / `I'm now going to be an arbitrary colourist`（dossier §5 R3 `:115-116`，法文原句见 AUDIT `claim_evidence_map.md:84`）；`[归纳]` 对应 §4 P2 色彩主观度（默认 60%，`:80-83`）——**「对应」是研究者映射，不是梵高说「设 P2=60%」**。
- **何时失效**：任务=写实记录/科学图解/证件肖像；或把此选法写成「梵高主张忽略对象」的心理学断言（禁止）。
- **等级**：`[自述]` + `[归纳]`，分列。

<a id="db-source-line-48"></a>
### S2 · 先建「方向场草图」（**厚涂笔触方向场**，本卡点名机制一）
- **先选**：先把画面按**区域场**分区并画出方向草图（天空湍流 ±30°、麦田 ±15° 顺风、柏树 75–90° 上升），再用 6–24 px 短线段铺满（§8.2-1 `:204`；§12-7 `:431`「笔触方向场先于颜色」）。
- **牺牲**：「先铺色块再补笔触」的顺序；全场同一方向的省事画法；平滑底色。
- **为什么（分栏）**：
  - `[归纳]`：§8.2-1 把方向场定为逐帧可查判据（天空区 ≥60% 落噪声场 ±20° 内）、§8.2-3 把覆盖率定 ≥95%；AUDIT `claim_evidence_map.md:98` 用**实测 L207/L208** 定位运动规则，方向场用 **L204**。
  - `[自述]`：信 596「Ne suis aucun système de touche…des empâtements, des endroits de toile pas couvertes」(corpus 条目 1 `:11-16`)——他本人说笔触不规则、厚涂、留白画布，但**没说过 ±30° / 6–24 px**；这些是项目判据。
- **何时失效**：与达·芬奇「Laplacian ≤2 / 只有渐变」组合 → C-05；按 N3 让「笔触轴」单主，以梵高为主时达·芬奇 §8.2-7 整条移除（`conflicts.md:119`）。
- **等级**：`[归纳]`（顺序/数值/失效）+ `[自述]`（笔触态度），**不混写**。

<a id="db-source-line-57"></a>
### S3 · 表面：全覆盖厚涂（**纯 `[归纳]` 步**）
- **先选**：≥95% 画面被笔触覆盖、每笔上亮下暗 1–2 px 边、全画无 >12 px 无笔触平滑区（§8.2-3 `:206`）；P1/P6 强档调到「画布纹理压痕/可投影厚涂」（`:78,100-103`）。
- **牺牲**：平滑渐变、柔和无笔触过渡、摄影景深/HDR（§8.1 负向 `:189-195`、§8.2-7 `:210`）。
- **为什么**：**`[归纳]`** C-05 把「笔触可见度」定为一条轴、达·芬奇在另一端，同一高频能量统计量数学互斥（`conflicts.md:114-119`）；AUDIT 确认该侧阈值标 `[归纳]`、未冒充史料（`claim_evidence_map.md:97`）。
- **何时失效**：以达·芬奇为主时整条移除；把「平滑渐变填充」全局化时误伤（C-14 类比，反约束是卡级资产）。
- **等级**：`[归纳]`（单一步，**不夹 `[自述]`**）。

<a id="db-source-line-64"></a>
### S4 · 颜色：互补对并置（**互补色机制**，本卡点名机制二）
- **先选**：色相簇 ≤8、**≥2 对互补簇同帧出现**（黄/蓝、橙/蓝、黄/紫），靠相邻笔触**并置**产生振动；P3 强档双互补对近 1:1（§8.2-2 `:205`、§4 P3 `:85-88`、§8.1 `:179-180`）。
- **牺牲**：低对比和谐、把补色调成中间色、平滑过渡（`no smooth blending`）。
- **为什么（分栏）**：
  - `[自述]`：信 673「To express the love of two lovers through a marriage of two complementary colours…through the vibrancy of our colorations」（§5 R6 `:118-119`）；§2-2「互补色承担情感语法」（`:49`）。
  - `[归纳]`：§8.2-2 的「簇 ≤8 / ≥2 对」与 §4 P3 的「近 1:1」是**逐帧聚类判据**，AUDIT `claim_evidence_map.md:99` 用**实测 L205** 定位；**「婚配/颤动」是作者比喻，「1:1 面积」是项目阈值**，不互相翻译。
- **何时失效**：与北斋蓝≥40% / 卡拉瓦乔土色系同帧 → C-12（同一色相面积预算三主张互斥，`conflicts.md:209-215`）；按硬规则「单卡只允许一个模块主张主色≥40%」，梵高降档为「≥1:3」并写进卡。
- **等级**：`[自述]`（情感语法）+ `[归纳]`（阈值/失效），分列。

<a id="db-source-line-73"></a>
### S5 · 运动：全画面旋度场（**纯 `[归纳]` 步**，静态图不启）
- **先选**：天空笔触随旋度场漂移 2–6°/s、漩涡中心 2–3 个半径≥画宽 25%（§8.2-4 **实测 L207**）；星核≥40 px + ≥2 圈同心环、环递减≥30%、闪烁 0.8–1.5 s 幅度≤±10%（§8.2-5 **实测 L208**）。
- **牺牲**：静止画面、单点低调运动。
- **为什么**：**`[归纳]`** C-09 把「一帧里允许几个运动区域」定为全画面场 vs 单点事件的互斥答案（`conflicts.md:170`），N8 追加「运动区域数」字段（`:329-330`）。**「L207/L208」是实测行号；conflicts.md:168 把它写成 L205/L206（+2 漂移），见 §3 登记**。
- **何时失效**：与维米尔「事件区域外 Δ≤1%」组合 → C-09；按 N8 显式登记，不静默折中。静态练习只到 S3/S4。
- **等级**：`[归纳]`（单一步）。

<a id="db-source-line-80"></a>
### S6 · 收笔：一次完成 + 母题放大
- **先选**：单幅「一次完成、画对就别再动」（§5 R2 `:112-113`）；柏树/尖塔竖直母题≥85% 画高穿地平线、天体带同心环（§8.2-6 `:209`、P5 `:95-98`）。
- **牺牲**：反复抠细节、多层透明罩染（§8.1 负向 `thin transparent glazes` `:193`）。
- **为什么（分栏）**：`[自述]` 信 535；`[归纳]` §8.2-6/P5 数值；`[研究]` §12-8 现场初稿→工作室两版→缩小版谱系（`:434-437`）——**「一次完成」指单幅起稿，不等于不复制**；三版谱系是史料，不写成「他反复怀疑自己」的心理推断。
- **何时失效**：进入系列/再版工作流时，收笔是**单幅**判据；组合时按 S7 先判轴。
- **等级**：`[自述]` + `[归纳]` + `[研究]`，分列。

<a id="db-source-line-87"></a>
### S7 · 组合：先判轴、不先调强度
- **先选**：按 N3 列「轴名｜持有模块｜对方规则处置」（笔触轴 C-05、运动轴 C-09、色相面积轴 C-12）；每轴单主，§8.2 是判分规则不是强度旋钮（`conflicts.md:311-312`）。
- **牺牲**：「两边各取一半」的折中直觉。
- **为什么**：**`[归纳]`** N1 反约束逐条重算（`:305-306`）、N9 把「冲突轴双标准」列为失败形态（`:332-333`）；C-04 的「记录两套数字」规范层问题说明「两套并存 ≠ 裁决」。
- **何时失效**：任何冲突轴出现双标准即失败；降档/移除必须显式写进卡（C-12 `:214`、C-05 `:119`）。
- **等级**：`[归纳]`。

## 3. 组合时的决策序（C-05 / C-09 / C-12 插入点）+ 行号漂移登记

> 全部 `[归纳]`；规则层判定，**非实验验证**（AUDIT `RESULT.md §4`「precise migration 属 CONFLICT lanes，本 lane 记录不 author fixes」）。

1. **先判轴**：C-05 笔触轴（以梵高为主 → 达·芬奇 §8.2-7 整条移除，`conflicts.md:119`）；C-09 运动轴（全画面场 vs 单点事件，N8 登记运动区域数，`:170,329-330`）；C-12 色相面积轴（预算表 + 单主色≥40% 独占 + 梵高降档 ≥1:3 写进卡，`:211-215`）。
