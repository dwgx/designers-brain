## 4. 何时整体失效（决策序的边界汇总 / known-open 隔离）

1. **出现交叉排线 / 版画式线网明暗** → D2/D0 失效，判丢勒模块（§3.1 第一轴，§4 警报①）。
2. **出现硬切光斑 / 戏剧投影 / 烛光 / 心理化光斑** → D4/D0 失效，判卡拉瓦乔或伦勃朗（§3.1 第二轴，§4 警报②，C-01）。
3. **出现可见厚涂/肌理表达** → D2 失效（§4 警报③，C-05 近无笔触侧）。
4. **题材是极端格式（6:1 横幅 / 单人净面特写）** → §4「≥2 条≥中档」粗筛**必要非充分**，须把「画幅比 + 题材类别」前置为分母（counterexample §反例1 `[inference]`）；D7 收口不能只跑 P1/P2/P3。
5. **文字落在毛皮/金线等材质分化区而非功能表面** → D3 的 §8.2-5「功能表面」前提失效（counterexample §反例2 `[inference]`）。
6. **静态图被套动画专属项 / 生成式流水线无写生条件** → D1 或收口误用。
7. **known-open 不进决策**：X-AGES 双说、X-ANGLE 观看角度两说、X-ITALY 两说、11 处 C-row 行号漂移、Q1 遗嘱 locator drift（Windsor drawings 页文本）、权利 metadata 边界、3 个 `[inference]` 反例、Q5/Q6 拉丁原文 unverified —— 都**不改变**上述任何一步的依据等级；它们只在 `RESULT.md` / `receipt.unresolved` / [claim_evidence_map.md](claim_evidence_map.md) / [mechanism_notes.md](mechanism_notes.md) 登记。
