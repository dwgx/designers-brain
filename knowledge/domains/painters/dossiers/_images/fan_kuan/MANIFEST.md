## 逐张明细与处理说明

1. **xishan_xinglv.jpg** — 自 11105×24176 全轴扫描（Commons《谿山行旅图轴…》68.57MB）的 3840px 版本裁出**画心**（x 186–3647、y 1246–8144；纵横比 1.993 与原作 206.3×103.3cm 吻合），再缩至 1800 高。**未含**上方诗塘（董其昌「北宋范中立谿山行旅圖」题记）——诗塘内容见档案 §7-1。高清版（3461×6898 画心裁片 + 3840×8360 全轴）存私有层。
2. **xishan_signature.jpg** — 谿山行旅图右下局部：驴队行旅与树荫；**红框为 Commons 上传者所加标注**，框出「范寬」二字款位置（1958-08-05 李霖灿与技工牛性群共同发现）。
3. **xuejing_hanlin.jpg** — 绢本设色，193.5×160.3cm，三拼绢；画面前景树干中有「臣范宽制」署款（1981 年徐邦达辨出）。天津博物馆镇馆之宝。
4. **linliu_duzuo.jpg** — 双拼大轴，156.4×106cm；NPM 判为「传称作品」（皴笔已呈侧锋小斧劈，年代近李唐）；图像为 NPM 开放数据版（含原装裱边），与 NPM IIIF（detail/45）逐段核对一致。
5. **qiulin_feipu.jpg** — 181×99.5cm；NPM 判为传称作品（山石皴纹用斧劈，近李唐画风；画中红枫飘于水上，诗意取唐崔信明「枫落吴江冷」）。图像为 NPM 开放数据版（含金褐色装裱边）。
6. **fang_fankuan_met.jpg** — 绢本设色立轴，画心 166.1×104.5cm；MET 定名「Landscape in the Style of Fan Kuan」（佚名，12世纪初）。取 MET 开放获取原图 DP165245。
7. **wanghui_fa_fankuan.jpg** — 王翬 41 岁时作；画上自题「紅林秋霁。用范華原筆法」（此开又名《紅林秋霁》）。**处理**：裁去底部 NPM 色标尺与扫描边（y 25–2145、x 55–3000），保留册页装裱面。图源为 NPM IIIF 服务（3058×2289）；Commons 另有上传版（1416×1060，标 CC0，本次因 Wikimedia 限流未取——两版均为 NPM 开放资料衍生物）。
8. **zhaoyuan_handscroll.jpg** — 纸本水墨手卷，画心 24.9×77.5cm；此图取全卷多段影像之一段（DP303149）。MET 英文题名「Landscape」，中文题名「倣燕文貴范寬山水圖」（Commons/MET 记录）。用于「影响链」——元末对范宽＋燕文贵两家风格的合成。
