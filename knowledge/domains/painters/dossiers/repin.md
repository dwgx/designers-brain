- **主要流派**：批判现实主义；巡回展览画派（Товарищество передвижных художественных выставок）核心成员（1878 年入会，其后多次进出，1900s 仍参展）。艺术史定位：19 世纪下半叶俄罗斯现实主义绘画的领军者与集大成者。`[研究]`（[R1][R4][R5]）
- **主要媒介**：油画（历史画 / 风俗画 / 肖像）、素描（铅笔、炭笔）、水彩、版画（晚年石版画与蚀刻试验）、插画；另著有大量书信、回忆录与艺术评论（文学写作本身是研究他的第一手宝库）。`[史料]`（[R4][R6][R7]）

## 2. 技法规则（10 条）

1. **习作→合成法（先分解再合成）**：大型作品先做单人习作、构图试验与小稿，最后合成到全尺寸；肖像亦先经 6–7 张素描（每张肖像「先有六七个草图」口径）。`[史料]` [R4]（preceded each portrait with six or seven sketches）；[R2]（《库尔斯克》70+ 人物草稿）。
2. **从自然（натура）直接写生**：模特就地写生，写生即研究——「Натура — учитель（自然是老师）」是其伏尔加章的工作口号；对景、对人、对光都先「到场」。`[自述]` [R6]（гл. VIII 第 IX 节标题「Натура — учитель」）；`[史料]` [R2]。
3. **跨年修改与版本迭代**：画作完成后持续修改——在特列季亚科夫画廊展厅现场改《意外归来》中「进入者」的脸；《雷帝》多次重画（1909 年做变体）；《十字游行》从 1877 年画到 1924 年。`[史料]` [R2][R16]。
4. **湿画法与可见笔触**：肖像多直画（alla prima）、笔触果断；大画分层推进（底色→塑造→调整），局部厚涂。`[研究]` [R4]；`[自述]` [R10]（「我不在乎颜料、笔触和运笔的炫技」——反炫技但笔触可见）。
5. **户外光研究（plein-air）**：诺曼底（1874）两个月的户外写生、巴黎时期对光色的学习；《库尔斯克》的「阳光-尘埃」是俄式 plein-air 名例。`[史料]` [R1][R2]；`[研究]` [R4]。
6. **群像调度工程**：先建「人物谱」（为《库尔斯克》写下 70+ 人物），再排布阶级/行列/视线；巨幅《国务会议》80+ 人物、48 个肖像写生「在厅内原位进行」。`[史料]` [R2]。
7. **素描体系**：铅笔/炭笔起稿，线与交叉排线并用，常以手指或橡皮擦出精确的调子；为大型画做极详细的局部研究（衣服、手、道具）。`[研究]` [R4]（lines and cross-hatching… rub the drawing with his finger）。
8. **肖像会话法**：与模特交谈、抓住「不耐烦」的瞬间——他自己总结：无懈可击的耐心坐姿出乏味肖像，不耐烦的坐姿出意外之喜（《П. М. 特列季亚科夫像》因过度认真而「不好」，《皮谢姆斯基像》因每五分钟跳起来而成功）。`[自述]` [R10]（гл. IX）。
9. **材料与身体管理**：与门捷列夫、彼得鲁舍夫斯基等研究颜料性能（测色敏感度）；晚年右手失灵后练左手作画，托不住调色板就用吊带挂在脖子上。`[史料]` [R15]（azbooka 引门捷列夫圈实验）；[R16]（左手/吊带）。
10. **工程化分工**：超大幅作品由学生协助——1903 年《国务会议》右翼由库斯托季耶夫、左翼由库利科夫绘制，列宾负责中央；使用照片辅助（首批用「柯达」相机记录现场）。`[史料]` [R2]。

## 3. 创作原则（8 条 + 分工条款）

1. **艺术＝表现人民利益**：「如今农民才是法官，所以必须表现他的利益」（1872）——把「为谁画」放在「怎么画」之前；他本人以「退役列兵之子」身份自认「庄稼汉」。`[自述]`（corpus #1）。
2. **多样性的权利**：拒绝被钉在单一方向上——「我爱多样性（я люблю разнообразие）」；被批评「今天画福音、明天民俗、后天历史」时，他的回答是「от себя не уйдешь（躲不开你自己）」；「дикие организмы（野蛮机体）」事件：他拒绝只画「民族题材」，坚持「我什么都要画，一切让我产生印象的」。`[自述]`（致克拉姆斯科伊 1875，[R16] 转引；致费奥多罗夫 1886，[R16]）。
3. **艺术自由对抗道德训诫**：1893–94 年公开主张「只坚守艺术本身」；与托尔斯泰的长期张力——他敬爱托尔斯泰，但拒绝把绘画降为道德工具（「任何良好意愿都不能让我在糟糕的画布前停下」）。`[自述]`（corpus #6；[R15][R16] 语境）。
4. **「物质本身」**：「我在绘画上的首要原则是：物质本身……我始终追求实质——身体就要像身体」（回忆录）——反炫技、反「漂亮的笔触」，材质与形体优先。`[自述]`（corpus #8）。
5. **信念与人格先于天赋**：「人没有信念——是只空鹰……无原则会贬低艺术家的人格」（回忆录·论谢罗夫）。`[自述]`（corpus #7）。
6. **同情而非俯视（见证伦理）**：画纤夫不是画「牲口」而是画人——卡宁「像受着试炼的圣徒」；不美化、不丑化、不居高临下，「每个几乎沦为奴隶的人都各有一段自己的命运」。`[自述]`（corpus #10/#11）＋ `[研究]`（[R2]：「在这些几乎沦为奴隶的人身上，列宾看到了人」）。
7. **历史画＝情感表达**：历史题材对他的吸引力在「所给情境的情感表达力」——历史是当下情绪的出口（《雷帝》缘起：里姆斯基-科萨科夫《安塔尔》的音乐与「当代的恐怖」；「有上帝在，有历史的报应」）。`[研究]`（[R5]）+ `[自述]`（corpus #17）。
8. **工作到最后**：晚年右手失灵用左手，「没放下艺术——最后的一切念头都是关于它」（1927）；85 岁「要虔敬地活着」（1929）。`[自述]`（corpus #22；[R16]）。

### 3.1 分工条款（写死；来源：`roster.md` §2.9 + wave17 brief；`[归纳]`，可被组合实验推翻）

- **vs 戈雅（纪实叙事）**——「有立场的画面」一族内部二分：
  - 戈雅 = **灾难与暴力的新闻构图**：战争/处决/怪诞；关键元素出画外、即时动作推前景、施害者匿名化（0 面孔）、画内证据光（提灯）。
  - 列宾 = **日常与仪式的社会横截面**：游行/河岸/家庭/会议厅；全阶层并置、面孔全部可读、环境光（日光/尘埃）。
  - **判据（可判读，写进自查表）**：① 事件类型：戈雅 = 暴力/灾难/噩梦 vs 列宾 = 日常仪式/社会场景/历史心理剧；② 面孔预算：戈雅 = 施害者 0 面孔 vs 列宾 = 可读面孔 ≥8（群像档）；③ 光源：戈雅 = 画内可指认证据光（提灯型）vs 列宾 = 环境光（无单一光锥）；④ 情感谱：戈雅 = 恐怖/惨剧极值 vs 列宾 = 笑/惊/怒/疲等日常情感谱。
- **vs 米开朗基罗（群像）**——「多人画面」的两条路：
  - 米开朗基罗 = **英雄化人体 + 理想力量**：超常肌群、扭转体、涡旋绕中心、敬畏（terribilità）。
  - 列宾 = **真实劳损身体 + 疲态尊严**：弯腰、破衣、绷带、下坠的重量；群像水平展开（队列/圆圈/分层），不是绕中心涡旋。
  - **判据**：① 人体：米 = 超常肌群、裸体主导 vs 列 = 劳损身体、衣装主导（破布/制服/衬衫）；② 情感：米 = 崇高/敬畏 vs 列 = 同情/理解/共鸣；③ 群像组织：米 = 涡旋/密集环绕 vs 列 = 队列/横带/视线网。
- **vs 伦勃朗（肖像心理）**——「心理」的两种载体：
  - 伦勃朗 = **单张脸的光斑地图**：光连续衰减、眼窝留暗、表情「读不准」；心理在光影里。
  - 列宾 = **多张脸的目光网络 + 全身姿态**：家庭/群体的相互注视链、手的动作、道具旁证；心理在关系里。
  - **判据**：① 面孔数：伦 = 单脸占满资源 vs 列 = ≥3 张脸相互注视（家庭档）；② 光：伦 = 单光源连续衰减 vs 列 = 环境光多向；③ 心理载体：伦 = 光影 vs 列 = 目光 + 姿态 + 道具。
- **与系统其余模块**：不得复制邻近模块独有机制——不借卡拉瓦乔的「光开关 + 画内无光源」（列宾的光是环境光）；不借梵高的「笔触情绪场」（列宾的笔触服从材质）；不借马蒂斯的「平涂色块」（列宾有完整明暗与材质）；组合时冲突轴按 `knowledge/cross/conflicts.md` 预检（重点：C-01 硬阴影、C-05 笔触可见度、C-12 色相面积预算）。

## 4. 控制参数（6 个，各三档）

| # | 参数 | 弱（20–30%） | 中（50–60%） | 强（80–95%） | 默认建议 |

## 6. 临摹与影响链

### 6.1 他学过谁（来源方向）

- **И. М. 布纳科夫（丘古耶夫，1857 起）**：圣像画与肖像作坊；作坊式训练（修补古圣像、为地方显贵画肖像）是全部手艺的地基。列宾回忆布纳科夫：「他以激情作画……安静的作坊里常能听到他轻轻的叹气」（[R15] 转引）。此前另受地方画家 Л. И. 佩尔萨诺夫影响。`[史料]` [R1][R15]。
- **И. Н. 克拉姆斯科伊（1863–64 起，关键）**：导师、批评家、终身参照；列宾：「学院教授们没看出的错误，克拉姆斯科伊一眼指出……我逐渐对教授们失去信任，只对克拉姆斯科伊的评语感兴趣，只听他的」（[R17] 转引）。经他进入「彼得堡画家协会（Артель）」圈。`[史料]` [R1][R17]。
- **学院（1864–1871）**：历史画构图、素描与临摹训练；1871 年大金奖（《睚鲁女儿复活》）。同时代学院训练给他「工程能力」，但他把「公民立场」归功于克拉姆斯科伊圈。`[史料]` [R1]。
- **委拉斯开兹（1883，普拉多）**：旅欧期间在马德里普拉多博物馆临摹委拉斯开兹与提香；其肖像笔法公认受委拉斯开兹（及马奈）影响。`[史料]` [R1][R4]。
- **伦勃朗**：经版画与冬宫油画研究（回忆录写他带诗人维尔哈伦直扑冬宫看伦勃朗；另与罗温斯基的伦勃朗版画收藏圈有交往）。`[史料]` [R10]（гл. IX）。
- **马奈与印象派（巴黎 1873–76）**：研究其光色与「自由」，但明确拒绝其「无社会目的」路线——「他们能吸引你，但会使你瘫软」（corpus #3）；同时在诺曼底做 plein-air 写生（1874，与波列诺夫等）。`[自述]`＋`[史料]` [R1][R7]。

### 6.2 谁学过他（输出方向）

- **瓦伦丁·谢罗夫（Валентин Серов）**：1878–1882 在列宾工作室学习（列宾回忆录专章记之）；后成俄罗斯肖像画大师——「谢罗夫式」肖像的源头之一在列宾的「会话式肖像法」。`[史料]` [R6]（гл. XII）[R4]。
- **鲍里斯·库斯托季耶夫、伊万·库利科夫**：1903 年《国务会议》的助手/学生（库斯托季耶夫画右翼、库利科夫画左翼）；二人后皆成名。`[史料]` [R2]。
- **伊萨克·布罗德斯基**：学生；1926 年率苏联代表团访佩纳特劝其回国。`[史料]` [R1]。
- **俄罗斯—苏联现实主义谱系**：列宾被苏联官方确立为「社会主义现实主义」的先驱（生前他本人反对布尔什维克——见 §11；身后被「国有化」为苏联艺术的正典）。`[研究]` [R4]。
- **当代**：俄罗斯/乌克兰叙事绘画与插画的共同源头；「群像 + 目光 + 心理瞬间」装置在现代分镜与插画中被反复挪用（`[推测]`，系统内观察）。

### 6.3 一句话总结（提示词模块的「来历」注脚）

这条链说明列宾模块不是「风格滤镜」，而是一套**社会叙事装置**：**先用「全阶层横截面」把社会铺进画面（纤夫/游行/会议）→ 再用「目光网」把观者绑进现场关系（《意外归来》）→ 最后用「情感极值瞬间」钉住历史（《雷帝》）**；上游是布纳科夫的作坊手、克拉姆斯科伊的公民立场、委拉斯开兹—伦勃朗的眼与笔、法国 plein-air 的光；下游是谢罗夫 → 俄罗斯肖像谱系 → 苏联现实主义 → 当代叙事绘画。

### 8.1 图像生成模块（英文 prompt + 中文说明）

**正向段（可直接粘贴）**
```
Repin-style social realist painting — a wide horizontal group scene treated as a cross-section of society:
several figures of different classes (peasants, officials, clergy, soldiers, children, beggars)
arranged in receding bands; readable individualized faces — every face a character, not a type;
eyes linked in a network of gazes (several mutual looks, a newcomer noticed by many);
one emotional extreme as the anchor (uproarious laughter / sudden grief / the shock of a return),
everyone else in modulated in-between states;
environmental daylight — noon haze, dust, window light — natural colored shadows,
no single theatrical spotlight; earth-tone palette with honest skin tones,
white shirts and uniforms as accents, one saturated note (red or blue) used sparingly;
confident visible brushwork, wet-in-wet — cloth feels like cloth, skin like skin, metal like metal;
narrative props that tell the story (icons, portraits on the wall, ropes, spears, ledgers);
a moment just after the event — the instant the situation becomes readable;
composed like a chapter of a novel, not like a stage set

```

```
--no single spotlight or stage lighting, no faceless anonymous ranks, no heroic nude musculature,

no cross-hatching print surface, no glossy academic varnish, no symmetrical ceremonial arrangement,
```

**中文使用说明**
- 三档先跑：P1 群像密度 + P2 社会横截面从中档起步（3–10 人、2–3 阶层）是「是不是列宾」的起步；历史/家庭题材把 P3 升强；户外题材把 P5 升强（《库尔斯克》档）；「《意外归来》式」家庭场景把 P4 拉满。
- 生成后自查三件事：① 可读面孔数 ≥ 人数 × 0.6 且表情非中性？② 光源是否**环境型**（无单一光锥）？③ 白色块 ≥3 处、高饱和点缀 ≤5%？
- 组合注意（预检写死）：与戈雅模块组合时，冲突轴 = **面孔预算**（不许出现「施害者 0 面孔队列」）与**事件类型**（灾难 vs 日常）；与米开朗基罗组合时，冲突轴 = **人体理想化**（不许超常肌群）；与伦勃朗组合时，冲突轴 = **心理载体**（不许单脸光斑地图）。与 Lane B 组合时：列宾作品为 PD，可直接作为素材源（对照其「只用公有领域素材」纪律）。

### 8.2 代码艺术模块（8 条可判定规则，逐帧可查）

1. **群像规则**：人数 ≥8 时，身份类别（服饰/职业可辨）≥3；画面分前/中/远 3 个层带，每层 ≥2 人。（依据：《库尔斯克》70+ 人物、分层排布 `[史料]`[R2]）
2. **目光网规则**：注视向量 ≥3 条；相互注视对 ≥2；「新入场者」被 ≥2 人注视。自查：面部朝向/瞳孔方向检测。
3. **情感极值规则**：全帧表情强度峰值人物 = 1（可归类：笑/惊/怒/悲）；其余人物强度 ≤ 峰值的 70%。（依据：《哥萨克》「笑」为全画主角 `[研究]`[R2]）
4. **环境光规则**：全帧可见光源 ≥1 且为环境型（日光/窗）；无单一光锥；阴影饱和度 > 0（有色阴影）；明暗层次 ≥3 带。（依据：外光实验 `[研究]`[R2][R4]）
5. **色彩预算规则**：土色系+肤色面积 ≥60%；白色连通域 ≥3 处；高饱和（S≥0.6）面积 ≤5%。（自查：HSV 掩膜 + 连通域）
6. **笔触规则**：可见笔触覆盖 ≥70%；笔触方向随形体/衣褶；最大平滑渐变区 ≤2% 面积。（对照「материя как таковая」原则 `[自述]`[R10]）
7. **道具规则**：叙事道具 ≥3 类（墙上图像/器物/服装细节）；每件道具与人物关系可述（人工核）。（依据：《意外归来》墙面四件套 `[史料]`[R2]）
8. **现场感规则**：存在 ≥1 处低完成度区域（粗率笔触但非空白）或可辨版本痕迹；无 3D/照片质感。（依据：跨年修改史 `[史料]`[R2][R3]）

> 以上阈值为本项目 `[归纳]`，**未对原作做像素测量**（分母＝假想参考帧）；1–2 条与 §3.1 分工判据同轴，组合实验时以本节自查表为准。
