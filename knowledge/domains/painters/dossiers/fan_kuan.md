## 2. 技法规则（10 条）

1. **雨点皴操作**：中锋短笔（郭若虚称「搶（枪）筆俱均」），千笔万笔、逐层叠搭；线条方向并不一致，但整体不紊乱，以密集点线堆出山体崢嶸堅實的质感（刘芳如文放大检视）。`[史料]`+`[研究]`
2. **积墨与渍染**：山石「水墨層加漬染，用墨甚濃，有堅實厚重之感」（NPM《临流独坐图》著录语）；轮廓重墨勾勒、内部层层加染，故有「深暗如暮夜晦暝」之评。`[史料]`
3. **轮廓方折**：全幅以方折墨线钩勒轮廓（NPM：「全幅以方折線條鉤勒輪廓，再藉短筆皴畫土石質感」）。`[史料]`
4. **山顶密林**：山顶作密林/灌木丛——「山頂好作密林」（米芾）；以点簇表现，远观呈深色冠带（NPM 2015：「礬頭密林」）。`[史料]`
5. **水际大石**：「水際作突兀大石」（米芾）；前景大石表面作凹洞质感——照金山砾岩地表特征与此相似（刘芳如实地比对）。`[史料]`+`[研究]`
6. **云雾留白**：山腰/林麓间留白作烟云，「與山石成虛實之呼應，凝重中有靈秀之韻」（NPM）；是「空气」与空间远隔感的来源。`[史料]`
7. **瀑布与湍泉**：悬瀑以细长亮线（「從天而降的懸絲瀑布」——NPM 2021）；湍泉以近乎随兴的快速笔触勾画水流跳踯与细碎波浪（刘芳如）。`[史料]`+`[研究]`
8. **树法**：针叶树（雪松/侧柏对应）＋阔叶树；树叶以墨线圈轮廓内加淡彩，叶形如菊花层叠或伞状放射；树干轮廓及木瘤用黝黑墨线、树身以淡墨短线堆砌（与画土石同法）；树根外露如爪。`[研究]`（刘芳如）
9. **界画屋宇**：寺观「結構十分完整，可以逐一辨識每處屋脊、飛簷、斗栱、柱椽」（刘芳如）；屋宇以墨笼染，谓之「铁屋」（郭若虚）。`[史料]`+`[研究]`
10. **雪景法**：雪山「借地为雪」（以留白为雪），墨色染出阴霾天空衬托雪岭高寒（NPM《雪山萧寺图》：「墨色染出陰霾的天空，益能襯托出雪嶺高寒的氣氛」）；米芾谓「其作雪山，全師世所謂王摩詰」。`[史料]`

## 3. 创作原则（7 条 + 分工条款）

1. **三阶师法（师人 → 师物 → 师心）**：「吾與其師於人者，未若師諸物也；吾與其師於物者，未若師諸心。」（《宣和畫譜》转述）；《畫鑒》本作「與其師人不若師諸造化」。——先学李成/荆浩（师人），再卜居终南太华对景观察（师物），终以心运化（师心）。`[自述]`（转述）
2. **对景造意，不取华饰，写山真骨**：《宋朝名画评》：「對景造意，不取華飾，寫山真骨，自為一家。」——面对真景提炼立意，拒绝装饰性细节，直取山体结构。`[史料]`
3. **危坐终日，纵目四顾（长期静观）**：「居山水間，嘗危坐終日，縱目四顧，以求其趣，雖雪月之際，必徘徊凝覽，以發思慮。」（《宋朝名画评》）`[史料]`
4. **隐居好道**：终南、太华「岩隈林麓之间」卜居；「性嗜酒、好道」（《圖畫見聞誌》）。其「好道」是隐逸与静观的精神基础（韩长生：「澄懷味象，拒絕功名利祿……專意於山水」）。`[史料]`+`[研究]`
5. **刚古之势，不犯前辈**：「故其剛古之勢不犯前輩，由是與成並行。」——在师承之外立自己的刚硬古拙面貌，不冒犯（重复）前人。`[史料]`
6. **雪景专长**：「中正好畫冒雪出雲之勢，尤有骨氣」（《宋朝名画评》）；「尤長雪山，見之使人凜凜」（《畫鑒》）；周密记「范寬雪景五幅，闊景甚偉」。`[史料]`
7. **布衣身份与「以俚语行」**：蔡卞：「中立不以名著，以俚語行，故世傳范寬山水」；终身未入仕，往来京洛之间。`[史料]`

### 3.1 分工条款（写死；来源：`roster.md` §2.1 + wave19 brief；`[归纳]`，可被组合实验推翻）

- **vs 黄公望（北宗/南宗式对照：全景巨碑/湿笔密点 vs 干笔披麻/长卷）**——同属「中国山水」大族，必须分档，不得互相吞并：
  - **皴法单元轴**：范宽 = **密点**（雨点皴：短点/钉头，千笔万笔叠搭）；黄公望 = **长线**（披麻皴：成组、近平行、随坡向的松秀长线）。
  - **构图轴**：范宽 = **纵向巨碑**（高远，主山中轴、占高约 2/3）；黄公望 = **横向长卷**（平远/阔远，段落横向展开）。
  - **墨法轴**：范宽 = **浓墨湿笔**（层层渍染、深暗浑厚）；黄公望 = **淡墨积叠**（干笔淡墨渐积、浓墨仅作醒点）。
  - **形制轴**：范宽 = **立轴**（单帧垂直观看）；黄公望 = **手卷**（数米横向、时间性展开）。
  - **判据（可判读）**：① 皴法单元：短点（范）／长线（黄）；② 画面纵横比与观看方向：竖式 ≥1.5:1 高宽比（范）／横式 ≥5:1 长卷（黄）；③ 墨色：平均明度低、浓墨占比高（范）／淡墨为主、纸色占比 40–60%（黄）；④ 空间：高远纵深（范）／平远开阔（黄）。
  - **两卡不得混同**：范宽卡禁「披麻皴／长卷多段连续空间／浅绛淡彩」；黄公望卡禁「雨点皴／纵向巨碑主山／浓墨渍染」。
- **vs 北斋（皴法质感 vs 等宽线）**：北斋 = 版画媒介（雕刻线条**宽度均等**、平涂色块、平面叙事、单页/系列）；范宽 = 毛笔媒介（**提按变化的短点皴**塑造山石质感与体积）。**判据**：① 线条：毛笔提按、短点千叠（范）／刻线等宽、轮廓利落（北）；② 质感生成：密集皴点堆出体量与肌理（范）／线描＋平涂色面（北）；③ 媒介：绢本水墨（范）／木版套色（北）；④ 空间：高远纵深（范）／平面剪影式构图（北）。
- **vs 塞尚（山体量感的两条路径）**：塞尚 = 以色块调制（modulation）与几何体（圆柱/球/锥）**推导**结构，山体量感来自色价关系与多点透视；范宽 = 以**密点积墨**（笔墨的密度与层次）堆叠出山体量感，量感来自笔触密度与墨色深度。**判据**：① 量感来源：密点皴＋渍染（范）／色块调制＋几何推导（塞）；② 空间：高远理想山水（范）／多点透视的结构空间（塞）；③ 笔触单元：短点（范）／斜向排笔色块（塞）；④ 媒介：水墨绢素（范）／油彩画布（塞）。
- **与系统其余模块**：不借黄公望的披麻长线与淡墨积叠；不借北斋的等宽线与平涂；不借塞尚的几何网格与色块调制。组合时冲突轴按 `knowledge/cross/conflicts.md` 预检（重点：笔触/线条、墨色浓度、负空间）。

## 4. 控制参数（6 个，各三档）

**P1 雨点皴密度（Raindrop-stroke Density）**（默认 强）`[归纳]`
- 弱: 皴点稀疏，山体以轮廓＋淡染为主（雪景简笔式）
- 中: 皴点成片但不塞满，留出山体结构线
- 强: 千笔万笔密布、层层叠搭（《谿山行旅图》式满皴）

**P2 主山压迫度（Monumental Dominance）**（默认 强）`[归纳]`
- 弱: 主山占画面高 ≤40%，群峰并置（平远式）
- 中: 主山占 40–60%，有陪峰
- 强: 主山占 ≥60%、中轴耸立、顶天立地（巨碑式）

**P3 墨色浓度（Ink Darkness）**（默认 中–强）`[归纳]`
- 弱: 淡墨为主、层次清爽（雪景留白多的画面）
- 中: 浓淡相济、山体层次 3 级可辨
- 强: 湿笔浓墨、深暗浑厚（「深暗如暮夜晦暝」；注意上限——「土石不分」为退化）

**P4 云雾留白带（Mist Band）**（默认 中）`[归纳]`
- 弱: 云雾仅局部点缀（≤5% 面积）
- 中: 山腰一条横向留白带（8–15% 面积、横贯 ≥60% 宽）
- 强: 大面积云雾缭绕、山体如浮（≥15% 面积，多带）

**P5 点景渺小比（Point-scenery Scale）**（默认 强=渺小）`[归纳]`
- 弱: 点景清晰可辨、高度 ≤ 画面高 3%
- 中: 点景高度 ≤ 2%、位于下 1/3
- 强: 点景高度 ≤ 1.5%、隐于下 1/4（《谿山行旅图》驴队式）

**P6 轮廓方折度（Angular Contour）**（默认 强）`[归纳]`
- 弱: 轮廓多圆弧长线
- 中: 方折与圆弧相间
- 强: 方折墨线主导、折角分明（山石如斧凿）

## 5. 自述与原话（8 条，逐条带出处；「自述」均为宋元人转述）

1. **三阶师法**：「前人之法未嘗不近取諸物，吾與其師於人者，未若師諸物也。吾與其師於物者，未若師諸心。」
   **白话**：前人的画法未尝不就近取于物象——但我与其师法于人，不如师法于物；与其师法于物，不如师法于心。
   **出处**：《宣和畫譜》卷十一（维基文库直读 2026-10-16）。`[自述]`（转述）
2. **「与其师人不若师诸造化」**：「既乃嘆曰：與其師人不若師諸造化。乃脫舊習，遊秦中，徧觀奇勝……」
   **白话**：既而叹道：与其师法于人，不如师法于造化（自然）。于是脱去旧习，游于秦中，遍观奇胜。
   **出处**：《畫鑒（四庫全書本）》（维基文库直读）。`[自述]`（转述）
3. **《宋朝名画评》小传（核心句）**：「居山水間，嘗危坐終日，縱目四顧，以求其趣，雖雪月之際，必徘徊凝覽，以發思慮。學李成筆雖得精妙，尚出其下，遂對景造意，不取華飾，寫山真骨，自為一家，故其剛古之勢不犯前輩。」
   **白话**：居山水间常危坐终日、纵目四顾以求其趣；即使雪月之时也必徘徊凝览以发思虑。学李成之笔虽得精妙尚在其下，遂对景造意、不取华饰、写山真骨，自成一家——其刚古之势不犯前辈。
   **出处**：《宋朝名畫評（四庫全書本）》卷二（维基文库直读）。`[史料]`
4. **时人议语**：「李成筆迹近視如千里之逺，范寛之筆逺望不離坐外，皆所謂造乎神者也。然中正好畫冒雪出雲之勢，尤有骨氣也。」
   **白话**：李成之笔近视如千里之远；范宽之笔远望不离坐外——皆所谓造乎神者。然中正好画冒雪出云之势，尤有骨气。
   **出处**：同上。`[史料]`
5. **《圖畫見聞誌》三家判语**：「峯巒渾厚，勢狀雄強，搶（上聲）筆俱均，人屋皆質者，范氏之作也。」
   **白话**：峰峦浑厚、势状雄强、枪笔俱匀、人屋皆质者，是范宽之作。
   **出处**：《圖畫見聞誌》卷一（维基文库直读）。`[史料]`

   **白话**：范宽山水高耸如恒岱；远山多正面、折落有势。晚年用墨太多、土石不分。本朝无人出其右。溪出深虚，水若有声。

## 6. 临摹与影响链

### 6.1 他学过谁（来源方向）
- **李成**（916–967）与**荆浩**（10世纪）：「始學李成，既悟……」（《宣和畫譜》）；「范寬師荊浩……信荊之弟子也」（《畫史》）；《畫鑒》「初師李成」。`[史料]`
- **王维（王摩诘）——仅限雪山**：米芾「其作雪山，全師世所謂王摩詰」。`[史料]`
- **造化（终南、太华）**：脱去旧习、卜居观察——师法链的第三阶（师物/师造化）。`[史料]`
- **一句话**：李成＋荆浩（师人）→ 终南太华（师物）→ 写山真骨、自成一家（师心）。

### 6.2 谁学过他（输出方向）
- **弟子（同代）**：黄怀玉（「學范中正畫山水，頗得其格」，有误藏为范笔者）、纪真、商训；《畫鑒》评「黄失之工、纪失之似、商失之拙，各得其一體」。`[史料]`
- **北宋中后期**：关陕之士大规模效仿（郭熙：「關陜之士惟摹范寬」）；李成谢世、范宽死后，许道宁等承续（张士逊诗）。`[史料]`
- **南宋院体**：李唐学范宽，马远、夏圭学李唐——「整个南宋时期的山水画几乎系出范寬一脈」（zh.wiki 综述；NPM 2015 展影响名单：萧照、夏珪、江参等）。日本东京国立博物馆藏梁楷《雪景山水图》亦被论为范宽画风在域外的运用（竹浪遠）。`[研究]`
- **元—明—清谱系**（NPM 2015/2021 展影响名单）：元·盛懋；明·沈周、文徵明、蓝瑛、赵左、赵澄、董其昌；清·王时敏、王鑑、王翬、王原祁、周鲲、唐岱、张雨森、弘旿；民国·钱崖、关山月；近现代·黄宾虹等。另有同名摹作与託名作（董其昌题《倣范寬谿山行旅圖》縮本、清人《行旅圖》、唐岱《倣范寬山水》等）。`[史料]`+`[研究]`
- **一句话总结**：这条链给系统的是「**量感语法**」——以密点皴（雨点）建立山体的质量与体感 → 以巨碑式中轴建立压迫性崇高 → 以云雾留白与悬瀑注入空气与纵深；上游＝荆浩/李成（北方山水）＋王维（雪景），下游＝李唐→南宋院体→元明清正统派与职业画家两支，「北宋三大家」由此成为后世山水的百代师法（《畫鑒》「照耀古今，為百代師法」）。

### 8.2 代码艺术模块（8 条可判定规则，逐帧可查）

1. **雨点皴覆盖**：主山区域（最大连通山体）内，短笔触（长度 ≤ 主山高 2%）纹理覆盖率 ≥ 60%；笔触方向角标准差 ≥ 20°（防规整排线）；不得出现单一方向平行排线占比 ≥ 30%。
2. **巨碑主山**：最大山体连通域高度 ≥ 画面高 60%；其水平重心与画面中线偏差 ≤ 10% 宽；顶部距画面上缘 ≤ 5% 高（或直抵上缘）。
3. **墨色层次**：山体区域明度直方图呈 ≥ 3 个可辨带；深色（≤40% 亮度）像素占山体面积 25–60%；不得出现内部标准差 < 5% 的平涂块（防死黑/防平涂）。
4. **云雾留白带**：≥ 1 条水平亮带（亮度 ≥ 纸色 90%）横贯 ≥ 60% 宽、位于画面高 35–60% 区间、面积占比 8–25%；带内连续墨线覆盖 ≤ 3%。
5. **悬瀑**：≥ 1 条垂直亮线（宽 ≤ 画面宽 1%、高 ≥ 画面高 8%、亮度 ≥ 纸色 95%），位于山体上 1/3–1/2 裂隙处。
6. **点景比例**：人物/驴马高度 ≤ 画面高 1.5%；总数 ≤ 8；全部位于画面下 1/4；面部无可辨细节（特征尺度 ≤ 3px）。
7. **轮廓方折**：主山轮廓拐点中折角（60–120°）占比 ≥ 50%；恒定曲率长弧 ≤ 30% 周长。
8. **点景与动画（动画时）**：云雾漂移 ≤ 0.5%/秒；瀑布允许纵向流动（≤ 2px/帧）但水线水平位置固定；点景位移 ≤ 1% 画幅/秒；不得出现推拉镜头、人物动作与墨迹闪变（帧间差 ≤ 1%）。

## 11. 生平与年代轴（详细）

### 11.1 生平叙述

范宽（约 950–1030/1032），名中正，字中立（一說字仲立），京兆华原（今陕西铜川市耀州区）人。生卒年均无确切记载：据《图画见闻志》「天圣中犹在」一语，可知 1023–1032 年间尚在世；学界一般推定其生于五代末年（约 950 年前后）、卒于北宋前期（约 1030 年前后；台北故宫有两组口径「约 950-1031 间」与「约 950-1032 后」，英文学界则作 c.960–c.1030——异说见 §10）。其名之由来有两说并存：《宣和画谱》引蔡卞题画语称「关中人谓性缓为宽，中立不以名著，以俚语行，故世传范宽山水」——即「宽」是关中方言语词（性缓），人们以此相称，他不以本名行世；《画鉴》则称「以其豁达大度人故以宽名之」。两说都指向同一事实：这是一个以性格特征行世的「绰号」式名字——其人为终身布衣，风仪峭古、进止疏野、嗜酒好道，往来于京洛之间，从未入朝任职。

范宽的时代，正值唐末五代战乱之后、北宋立国未久的关中。据竹浪远的研究，唐末动乱使京兆府及整个陕西地区衰颓，北宋建国后当地仍持续遭受党项与流寇侵扰——这一政治地理处境，被认为是范宽隐居于故乡山中、创发独特画风的原因之一。他壮年时期适逢真宗朝（997–1022），陕西作为边防重地，频繁有出身华北的宰相、枢密使等官员派驻；这些官员很可能成为理解并赏识其作品的鉴赏者。与此同时，都城开封因「天书降临」事件大举兴建道观、动员大批画家，而实际掌权者多为江南出身的财政官僚与宦官——以质朴手法描绘陕西山岳的范宽作品未能获得都城画坛青睐。直到仁宗朝（1022–1063）以后，随着李成「平远山水」声誉日隆，与其风格截然不同的范宽「高远山水」才开始受到广泛关注，范宽也由此逐步获得与关仝、李成并列的地位。

据《宣和画谱》，范宽「喜画山水，始学李成，既悟」——他先从李成、荆浩入手（米芾《画史》记「范宽师荆浩……信荆之弟子也」，并鉴定过其「少年所作」），继而觉悟到「前人之法未尝不近取诸物」——「吾与其师于人者，未若师诸物也；吾与其师于物者，未若师诸心」（《宣和画谱》转述；《画鉴》本作「与其师人不若师诸造化」）。于是他舍去旧习，卜居于终南、太华「岩隈林麓之间」，遍观「云烟惨淡、风月阴霁难状之景」，默与神遇。《宋朝名画评》记其观察方式：「居山水间，尝危坐终日，纵目四顾，以求其趣，虽雪月之际，必徘徊凝览，以发思虑」——这种长期静观（加上「好道」的精神底色，韩长生释为老庄之道、「澄怀味象」）是其「对景造意，不取华饰，写山真骨，自为一家」的直接基础。米芾《画史》记其鉴定要点：「山顶好作密林，自此趋枯老；水际作突兀大石，自此趋劲硬」；并总评「范宽山水，嶪嶪如恒岱，远山多正面，折落有势。晚年用墨太多，土石不分。本朝自无人出其右。溪出深虚，水若有声。其作雪山，全师世所谓王摩诘」。「用墨太多、土石不分」常被读作其晚年风格走向深暗浑厚的记录（亦为后世争议点）。

范宽在世时已负盛名：《宋朝名画评》列其山水林木门「神品二人」之一（另一人为李成），时人议曰「李成之笔，近视如千里之远；范宽之笔，远望不离坐外——皆所谓造乎神者也」；郭若虚《图画见闻志》以「峰峦浑厚，势状雄强，抢笔俱均，人屋皆质」定其面目，并与李成、关仝合称「三家鼎峙，百代标程」；郭熙《林泉高致》记「关陕之士惟摹范宽」——其追随者在他生前或身后不久已遍及关陕。他尤以雪景著称：「中正好画冒雪出云之势，尤有骨气」（《宋朝名画评》）；汤垕《画鉴》称「宽尤长雪山，见之使人凛凛」，并给出元代的经典定位——「董源得山之神气，李成得体貌，范宽得骨法，故三家照耀古今，为百代师法」。其弟子黄怀玉、纪真、商训「各得其一体」，然「黄失之工、纪失之似、商失之拙」（《画鉴》）；黄怀玉学之「颇得其格」，甚至有藏家误收其作。周密《云烟过眼录》记藏家处「范宽雪景五幅，阔景甚伟」。宣和御府藏其作品五十八件（《宣和画谱》著录全目，中有《雪景寒林图一》《夏山图十》《寒林图十二》等），米芾自称见过三十本——足见其北宋流传之盛。卒年无确载；「李成谢世范宽死，唯有长安许道宁」（张士逊诗）为旁证之一。

身后，范宽经李唐（「其源出于范、荆之间」）而下启南宋院体——马远、夏圭皆学李唐，南宋山水几乎系出范宽一脉；元代汤垕、赵孟頫（「大图阔幅，山势逼人，真古今绝笔也」）续加揄扬；明清两代，沈周、文徵明、董其昌、蓝瑛、赵左，以至清初四王、唐岱等皆有仿作传世（2015 特展影响名单列 20 位）；近代徐悲鸿、黄宾虹亦受其泽。今存系于其名下的作品主要有：《谿山行旅图》（台北故宫，公认度最高的真迹）、天津博物馆《雪景寒林图》、《临流独坐图》《雪山萧寺图》《秋林飞瀑》《群峰雪霁》（台北故宫，皆传称作品），以及波士顿美术馆《雪山楼阁图》等。其中《谿山行旅图》的「成名史」本身即为一段传奇：入清宫时《石渠宝笈》初编仅列为「次等」且以「无款」著录；1932 年《故宫周刊》首刊图版；1958 年 8 月 5 日，李霖灿与技工牛性群在画面右下角树荫中发现「范宽」二字款；此后经 1959 年《故宫名画三百种》、1961–62 年赴美展览、方闻等学者的研究，逐步确立为镇院之宝——2012 年 3 月由文化部核定公告为国宝，2015 年「典范与流传——范宽及其传派」特展、2021 年「镇院国宝」特展先后以之为核心；其故里铜川照金一带的山川，也成为学界（刘芳如、韩长生等）持续实地比对的「写山原型」。范宽与同为华原人的唐代书法家柳公权被后世合称「柳范」。

关于鉴藏与流传，两件最重要作品各有清晰而曲折的流传史：《谿山行旅图》北宋时已见钱勰（1034–1097）「忠孝之家」藏印，历元明内府与王时敏、周祚新、梁清标等递藏，乾隆年间入清内府（重华宫）；《雪景寒林图》则经清初梁清标、安岐鉴藏，乾隆时收入内府、存于圆明园，1860 年英法联军之劫流散民间，为工部右侍郎张翼购得——张翼、张叔诚父子两代珍护，1981 年由张叔诚捐入天津艺术博物馆，成为天津博物馆镇馆之宝。两作一在台北、一在天津，共同构成范宽存世作品的双极。此外，后世同名摹作与託名作（董其昌题《倣范寬谿山行旅圖》縮本、清人《行旅圖》——原题范宽，或为王翬所仿、唐岱《倣范寬山水》等）的大量存世，本身即是范宽影响史的一部分，构成从「临摹」到「再演绎」的完整接受链；而其故里照金山川（薛家寨、大香山一带）经刘芳如、韩长生等实地比对，被认为是「写山原型」的候选——亦有学者（竹浪远）据画中僧侣与驮队分析，论证《谿山行旅图》所绘为夏末黄昏之景。范宽作品的散佚亦极严重：宣和御府所藏五十八件今无一存世可确证，《宣和画谱》著录与米芾所见三十本均只存文字，今日研究只能依赖传称作品与后世摹作重建其面貌——这也是「范宽研究」始终伴随真伪讨论的原因。

## 12. 临摹/学习清单（8 件，各写「看什么 / 学什么 / 怎么练」）

1. **《谿山行旅图》轴（台北故宫博物院；国宝）**
   - 看什么：主山占高约 2/3 的中轴巨碑构图；满山「雨点皴」的千笔万笔（放大看方向离散而不乱）；山腰云雾留白带与一线悬瀑；近景大石、树根外露与右下驴队的渺小比例；诗塘董其昌题（原迹未含于图库裁片，见 §7-1）。
   - 学什么：密点皴法（笔触密度、方向、层次）；方折轮廓；点景比例控制（P5）。
   - 怎么练：对临主山中段一块（用图库 `xishan_xinglv.jpg`），临后统计：单位面积皴点数、方向分布、墨色层数；与 §4 P1/P2/P5 对照打勾。
2. **《雪景寒林图》轴（天津博物馆）**
   - 看什么：三拼绢大幅；雪峰的「借地为雪」与阴霾天空的墨染；深谷寒林间萧寺、流水无波；前景树干中「臣范宽制」款（需细看）。
   - 学什么：雪景的留白与墨色平衡（白与黑的面积比）；寒林枯枝的「锐枝」质感。
   - 怎么练：对临前景寒林一组（用图库 `xuejing_hanlin.jpg`）；记录留白面积比与墨色层次（≥3 带）；写 100 字「雪景中的骨法」。
3. **《临流独坐图》轴（台北故宫博物院；传称）**
   - 看什么：双拼大轴的主峰传承（与《谿山行旅》同构）；皴笔已转向侧锋砍斫（小斧劈雏形）；临流独坐的减笔点景人物。
   - 学什么：范宽图式的「下一站」（李唐方向的过渡形态）；点景人物的减笔写法。
   - 怎么练：先默画其构图骨架，再与《谿山行旅》骨架并排，列 5 条异同（用图库 `linliu_duzuo.jpg`）。
4. **《雪山萧寺图》轴（台北故宫博物院；传称）**
   - 看什么：数峰高耸、山顶密林、古寺关隘寒泉行旅；墨染阴霾天空衬雪岭高寒；皴法树法的「概念化倾向」。
   - 学什么：雪景山水的「寒」气氛营造；概念化倾向的鉴别意义（学范宽 vs 学「范宽样式」）。
   - 怎么练：读 NPM 著录（§7-2）+ 复制品观察；画构图骨架一张；写 3 条「为何此幅可能晚于范宽」。
5. **《秋林飞瀑》轴（台北故宫博物院；传称）**
   - 看什么：斧劈皴与雨点皴的直接对比（NPM 语：「面目顯見不同」）；红枫飘于水上的诗意点题。
   - 学什么：传称作品的鉴别视角（皴法断代）；「近李唐画风」的判断依据。
   - 怎么练：与《谿山行旅》皴法并排对比（用图库 `qiulin_feipu.jpg`），写 3 条差异；标注其可能年代。
6. **《群峰雪霁图》册（台北故宫博物院；传称）**
   - 看什么：册页小尺幅中的雪景与矾头密林；范宽语法被缩写的形态。
   - 学什么：小幅中的「巨碑」简化；雪景册页的构图密度。
   - 怎么练：以著录描述 + 展览记录为准做「文字临摹」（先读著录、后默画）；记录与大幅雪景的取舍差异。（公开高清图未获取，见 §10。）
7. **倣范寬山水圖（大都会艺术博物馆；佚名，12 世纪初）**
   - 看什么：直接仿作与原作的距离——雨点皴是否变「概念化」、主山气势是否衰减。

   - 学什么：影响链两个样本——「法某家」的两种做法（局部用笔／整幅面貌）。
   - 怎么练：各临一小段（用图库 `wanghui_fa_fankuan.jpg`、`zhaoyuan_handscroll.jpg`）；写 100 字「为什么后世仿作多失巨碑气势」。
