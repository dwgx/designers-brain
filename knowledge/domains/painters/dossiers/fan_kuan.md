## 2. 技法规则（10 条）

1. **雨点皴操作**：中锋短笔（郭若虚称「搶（枪）筆俱均」），千笔万笔、逐层叠搭；线条方向并不一致，但整体不紊乱，以密集点线堆出山体崢嶸堅實的质感（刘芳如文放大检视）。`[史料]`+`[研究]`
2. **积墨与渍染**：山石「水墨層加漬染，用墨甚濃，有堅實厚重之感」（NPM《临流独坐图》著录语）；轮廓重墨勾勒、内部层层加染，故有「深暗如暮夜晦暝」之评。`[史料]`
3. **轮廓方折**：全幅以方折墨线钩勒轮廓（NPM：「全幅以方折線條鉤勒輪廓，再藉短筆皴畫土石質感」）。`[史料]`
4. **山顶密林**：山顶作密林/灌木丛——「山頂好作密林」（米芾）；以点簇表现，远观呈深色冠带（NPM 2015：「礬頭密林」）。`[史料]`
5. **水际大石**：「水際作突兀大石」（米芾）；前景大石表面作凹洞质感——照金山砾岩地表特征与此相似（刘芳如实地比对）。`[史料]`+`[研究]`
6. **云雾留白**：山腰/林麓间留白作烟云，「與山石成虛實之呼應，凝重中有靈秀之韻」（NPM）；是「空气」与空间远隔感的来源。`[史料]`
7. **瀑布与湍泉**：悬瀑以细长亮线（「從天而降的懸絲瀑布」——NPM 2021）；湍泉以近乎随兴的快速笔触勾画水流跳踯与细碎波浪（刘芳如）。`[史料]`+`[研究]`
8. **树法**：针叶树（雪松/侧柏对应）＋阔叶树；树叶以墨线圈轮廓内加淡彩，叶形如菊花层叠或伞状放射；树干轮廓及木瘤用黝黑墨线、树身以淡墨短线堆砌（与画土石同法）；树根外露如爪。`[研究]`（刘芳如）
9. **界画屋宇**：寺观「結構十分完整，可以逐一辨識每處屋脊、飛簷、斗栱、柱椽」（刘芳如）；屋宇以墨笼染，谓之「铁屋」（郭若虚）。`[史料]`+`[研究]`
10. **雪景法**：雪山「借地为雪」（以留白为雪），墨色染出阴霾天空衬托雪岭高寒（NPM《雪山萧寺图》：「墨色染出陰霾的天空，益能襯托出雪嶺高寒的氣氛」）；米芾谓「其作雪山，全師世所謂王摩詰」。`[史料]`

## 3. 创作原则（7 条 + 分工条款）

1. **三阶师法（师人 → 师物 → 师心）**：「吾與其師於人者，未若師諸物也；吾與其師於物者，未若師諸心。」（《宣和畫譜》转述）；《畫鑒》本作「與其師人不若師諸造化」。——先学李成/荆浩（师人），再卜居终南太华对景观察（师物），终以心运化（师心）。`[自述]`（转述）
2. **对景造意，不取华饰，写山真骨**：《宋朝名画评》：「對景造意，不取華飾，寫山真骨，自為一家。」——面对真景提炼立意，拒绝装饰性细节，直取山体结构。`[史料]`
3. **危坐终日，纵目四顾（长期静观）**：「居山水間，嘗危坐終日，縱目四顧，以求其趣，雖雪月之際，必徘徊凝覽，以發思慮。」（《宋朝名画评》）`[史料]`
4. **隐居好道**：终南、太华「岩隈林麓之间」卜居；「性嗜酒、好道」（《圖畫見聞誌》）。其「好道」是隐逸与静观的精神基础（韩长生：「澄懷味象，拒絕功名利祿……專意於山水」）。`[史料]`+`[研究]`
5. **刚古之势，不犯前辈**：「故其剛古之勢不犯前輩，由是與成並行。」——在师承之外立自己的刚硬古拙面貌，不冒犯（重复）前人。`[史料]`
6. **雪景专长**：「中正好畫冒雪出雲之勢，尤有骨氣」（《宋朝名画评》）；「尤長雪山，見之使人凜凜」（《畫鑒》）；周密记「范寬雪景五幅，闊景甚偉」。`[史料]`
7. **布衣身份与「以俚语行」**：蔡卞：「中立不以名著，以俚語行，故世傳范寬山水」；终身未入仕，往来京洛之间。`[史料]`

### 3.1 分工条款（写死；来源：`roster.md` §2.1 + wave19 brief；`[归纳]`，可被组合实验推翻）

- **vs 黄公望（北宗/南宗式对照：全景巨碑/湿笔密点 vs 干笔披麻/长卷）**——同属「中国山水」大族，必须分档，不得互相吞并：
  - **皴法单元轴**：范宽 = **密点**（雨点皴：短点/钉头，千笔万笔叠搭）；黄公望 = **长线**（披麻皴：成组、近平行、随坡向的松秀长线）。
  - **构图轴**：范宽 = **纵向巨碑**（高远，主山中轴、占高约 2/3）；黄公望 = **横向长卷**（平远/阔远，段落横向展开）。
  - **墨法轴**：范宽 = **浓墨湿笔**（层层渍染、深暗浑厚）；黄公望 = **淡墨积叠**（干笔淡墨渐积、浓墨仅作醒点）。
  - **形制轴**：范宽 = **立轴**（单帧垂直观看）；黄公望 = **手卷**（数米横向、时间性展开）。
  - **判据（可判读）**：① 皴法单元：短点（范）／长线（黄）；② 画面纵横比与观看方向：竖式 ≥1.5:1 高宽比（范）／横式 ≥5:1 长卷（黄）；③ 墨色：平均明度低、浓墨占比高（范）／淡墨为主、纸色占比 40–60%（黄）；④ 空间：高远纵深（范）／平远开阔（黄）。
  - **两卡不得混同**：范宽卡禁「披麻皴／长卷多段连续空间／浅绛淡彩」；黄公望卡禁「雨点皴／纵向巨碑主山／浓墨渍染」。
- **vs 北斋（皴法质感 vs 等宽线）**：北斋 = 版画媒介（雕刻线条**宽度均等**、平涂色块、平面叙事、单页/系列）；范宽 = 毛笔媒介（**提按变化的短点皴**塑造山石质感与体积）。**判据**：① 线条：毛笔提按、短点千叠（范）／刻线等宽、轮廓利落（北）；② 质感生成：密集皴点堆出体量与肌理（范）／线描＋平涂色面（北）；③ 媒介：绢本水墨（范）／木版套色（北）；④ 空间：高远纵深（范）／平面剪影式构图（北）。
- **vs 塞尚（山体量感的两条路径）**：塞尚 = 以色块调制（modulation）与几何体（圆柱/球/锥）**推导**结构，山体量感来自色价关系与多点透视；范宽 = 以**密点积墨**（笔墨的密度与层次）堆叠出山体量感，量感来自笔触密度与墨色深度。**判据**：① 量感来源：密点皴＋渍染（范）／色块调制＋几何推导（塞）；② 空间：高远理想山水（范）／多点透视的结构空间（塞）；③ 笔触单元：短点（范）／斜向排笔色块（塞）；④ 媒介：水墨绢素（范）／油彩画布（塞）。
- **与系统其余模块**：不借黄公望的披麻长线与淡墨积叠；不借北斋的等宽线与平涂；不借塞尚的几何网格与色块调制。组合时冲突轴按 `knowledge/cross/conflicts.md` 预检（重点：笔触/线条、墨色浓度、负空间）。

## 4. 控制参数（6 个，各三档）

**P1 雨点皴密度（Raindrop-stroke Density）**（默认 强）`[归纳]`
- 弱: 皴点稀疏，山体以轮廓＋淡染为主（雪景简笔式）
- 中: 皴点成片但不塞满，留出山体结构线
- 强: 千笔万笔密布、层层叠搭（《谿山行旅图》式满皴）

**P2 主山压迫度（Monumental Dominance）**（默认 强）`[归纳]`
- 弱: 主山占画面高 ≤40%，群峰并置（平远式）
- 中: 主山占 40–60%，有陪峰
- 强: 主山占 ≥60%、中轴耸立、顶天立地（巨碑式）

**P3 墨色浓度（Ink Darkness）**（默认 中–强）`[归纳]`
- 弱: 淡墨为主、层次清爽（雪景留白多的画面）
- 中: 浓淡相济、山体层次 3 级可辨
- 强: 湿笔浓墨、深暗浑厚（「深暗如暮夜晦暝」；注意上限——「土石不分」为退化）

**P4 云雾留白带（Mist Band）**（默认 中）`[归纳]`
- 弱: 云雾仅局部点缀（≤5% 面积）
- 中: 山腰一条横向留白带（8–15% 面积、横贯 ≥60% 宽）
- 强: 大面积云雾缭绕、山体如浮（≥15% 面积，多带）

**P5 点景渺小比（Point-scenery Scale）**（默认 强=渺小）`[归纳]`
- 弱: 点景清晰可辨、高度 ≤ 画面高 3%
- 中: 点景高度 ≤ 2%、位于下 1/3
- 强: 点景高度 ≤ 1.5%、隐于下 1/4（《谿山行旅图》驴队式）

**P6 轮廓方折度（Angular Contour）**（默认 强）`[归纳]`
- 弱: 轮廓多圆弧长线
- 中: 方折与圆弧相间
- 强: 方折墨线主导、折角分明（山石如斧凿）

## 5. 自述与原话（8 条，逐条带出处；「自述」均为宋元人转述）

1. **三阶师法**：「前人之法未嘗不近取諸物，吾與其師於人者，未若師諸物也。吾與其師於物者，未若師諸心。」
   **白话**：前人的画法未尝不就近取于物象——但我与其师法于人，不如师法于物；与其师法于物，不如师法于心。
   **出处**：《宣和畫譜》卷十一（维基文库直读 2026-10-16）。`[自述]`（转述）
2. **「与其师人不若师诸造化」**：「既乃嘆曰：與其師人不若師諸造化。乃脫舊習，遊秦中，徧觀奇勝……」
   **白话**：既而叹道：与其师法于人，不如师法于造化（自然）。于是脱去旧习，游于秦中，遍观奇胜。
   **出处**：《畫鑒（四庫全書本）》（维基文库直读）。`[自述]`（转述）
3. **《宋朝名画评》小传（核心句）**：「居山水間，嘗危坐終日，縱目四顧，以求其趣，雖雪月之際，必徘徊凝覽，以發思慮。學李成筆雖得精妙，尚出其下，遂對景造意，不取華飾，寫山真骨，自為一家，故其剛古之勢不犯前輩。」
   **白话**：居山水间常危坐终日、纵目四顾以求其趣；即使雪月之时也必徘徊凝览以发思虑。学李成之笔虽得精妙尚在其下，遂对景造意、不取华饰、写山真骨，自成一家——其刚古之势不犯前辈。
   **出处**：《宋朝名畫評（四庫全書本）》卷二（维基文库直读）。`[史料]`
4. **时人议语**：「李成筆迹近視如千里之逺，范寛之筆逺望不離坐外，皆所謂造乎神者也。然中正好畫冒雪出雲之勢，尤有骨氣也。」
   **白话**：李成之笔近视如千里之远；范宽之笔远望不离坐外——皆所谓造乎神者。然中正好画冒雪出云之势，尤有骨气。
   **出处**：同上。`[史料]`
5. **《圖畫見聞誌》三家判语**：「峯巒渾厚，勢狀雄強，搶（上聲）筆俱均，人屋皆質者，范氏之作也。」
   **白话**：峰峦浑厚、势状雄强、枪笔俱匀、人屋皆质者，是范宽之作。
   **出处**：《圖畫見聞誌》卷一（维基文库直读）。`[史料]`
6. **《畫史》总评**：「范寬山水，嶪嶪如恆岱，遠山多正面，折落有勢。晚年用墨太多，土石不分。本朝自無人出其右。溪出深虛，水若有聲。」
   **白话**：范宽山水高耸如恒岱；远山多正面、折落有势。晚年用墨太多、土石不分。本朝无人出其右。溪出深虚，水若有声。
   **出处**：《畫史》（米芾；维基文库直读）。`[史料]`
7. **赵孟頫题语**：「所画山，皆写秦陇峻拔之势，大图阔幅，山势逼人，真古今绝笔也。」
   **白话**：所画之山皆写秦陇峻拔之势；大图阔幅、山势逼人——真古今绝笔。
   **出处**：经《大觀錄》宋君臣名画卷之十二（识典古籍直读）。`[史料]`（元初）
8. **董其昌诗塘题（《谿山行旅图》定名）**：「北宋范中立谿山行旅圖。董其昌觀。」
   **白话**：北宋范中立《溪山行旅图》。董其昌观。
   **出处**：台北故宫博物院著录·题跋资料（浏览器直读）。`[史料]`（明）

## 6. 临摹与影响链

### 6.1 他学过谁（来源方向）
- **李成**（916–967）与**荆浩**（10世纪）：「始學李成，既悟……」（《宣和畫譜》）；「范寬師荊浩……信荊之弟子也」（《畫史》）；《畫鑒》「初師李成」。`[史料]`
- **王维（王摩诘）——仅限雪山**：米芾「其作雪山，全師世所謂王摩詰」。`[史料]`
- **造化（终南、太华）**：脱去旧习、卜居观察——师法链的第三阶（师物/师造化）。`[史料]`
- **一句话**：李成＋荆浩（师人）→ 终南太华（师物）→ 写山真骨、自成一家（师心）。

### 6.2 谁学过他（输出方向）
- **弟子（同代）**：黄怀玉（「學范中正畫山水，頗得其格」，有误藏为范笔者）、纪真、商训；《畫鑒》评「黄失之工、纪失之似、商失之拙，各得其一體」。`[史料]`
- **北宋中后期**：关陕之士大规模效仿（郭熙：「關陜之士惟摹范寬」）；李成谢世、范宽死后，许道宁等承续（张士逊诗）。`[史料]`
- **南宋院体**：李唐学范宽，马远、夏圭学李唐——「整个南宋时期的山水画几乎系出范寬一脈」（zh.wiki 综述；NPM 2015 展影响名单：萧照、夏珪、江参等）。日本东京国立博物馆藏梁楷《雪景山水图》亦被论为范宽画风在域外的运用（竹浪遠）。`[研究]`
- **元—明—清谱系**（NPM 2015/2021 展影响名单）：元·盛懋；明·沈周、文徵明、蓝瑛、赵左、赵澄、董其昌；清·王时敏、王鑑、王翬、王原祁、周鲲、唐岱、张雨森、弘旿；民国·钱崖、关山月；近现代·黄宾虹等。另有同名摹作与託名作（董其昌题《倣范寬谿山行旅圖》縮本、清人《行旅圖》、唐岱《倣范寬山水》等）。`[史料]`+`[研究]`
- **一句话总结**：这条链给系统的是「**量感语法**」——以密点皴（雨点）建立山体的质量与体感 → 以巨碑式中轴建立压迫性崇高 → 以云雾留白与悬瀑注入空气与纵深；上游＝荆浩/李成（北方山水）＋王维（雪景），下游＝李唐→南宋院体→元明清正统派与职业画家两支，「北宋三大家」由此成为后世山水的百代师法（《畫鑒》「照耀古今，為百代師法」）。
