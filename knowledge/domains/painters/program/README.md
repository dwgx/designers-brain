# 画家蒸馏计划（Program）

> **目标（Owner 2026-10-15 令）**：**各国大师、全量蒸馏**——「人家的出生到现在所能找到的记录相关都可以」；质量优先、范围尽量广、深度绝对。服务于两个目标：设计顾问（skill）+ 「临摹彻底」（学习）。
> 本目录 = 计划层（roster / 规格 / 波次 / 验收）；档案产物在 `../dossiers/`。

## 1. 档案规格 v2（wave13 起适用）

每份档案 = v1 基础 + 深度增项：

- v1 基础：§0 元信息 · §1 视觉指纹 · §2 技法规则 · §3 创作原则（含**分工条款**） · §4 控制参数（三档） · §5 自述与原话 · §6 临摹与影响链 · §7 深度分析 · §8 提示词模块（8.1/8.2 与 v1 同构——`_extract.py` 抽取契约） · §9 参考资料 · §10 缺口与待验证 · 自审四段
- **§B 生平与年代轴**（新增）：生平叙述 300–500 字 + 关键年份表（出生 / 学徒 / 转折 / 代表作 / 晚年）+ 生平细节来源
- **§C 临摹/学习清单**（新增）：5–10 件代表作，各写「看什么 / 学什么 / 怎么练（可执行练习）」
- 语料 `_corpus/<id>.md`：**≥15 条**带出处原话（v1 约 12–20）
- 图库 `_images/<id>/`：**≥6 张** PD/开放许可（v1 为 3）
- 深度纪律：「出生到现在」= 生平 + 书信/日记/同时代记述 + 技法研究 + 作品记录，尽力找全；查不到写「未找到（已查: …）」

## 2. 波次

- **wave12（跑）**：Turner / Rembrandt / Klimt（v1 规格）
- **wave13（跑）**：Goya / Seurat / Hopper / 八大山人 / 齐白石 / 伊藤若冲（v2 规格）
- **wave14+**：见 `roster.md`（RosterBuilder 产出；40+ 候选、全文化覆盖）
- **加固 pass（wave15+）**：对 v1 档案补 §B/§C 深度增项

## 3. 验收管线（每份档案）

1. **机械**：结构同构（§8.1/§8.2/§4 可抽取）+ 引文抽查 ≥10 条（逐字对照来源）+ 图像许可核查
2. **独立评审**（换人、干净上下文）
3. **主脑验收** → GOALS 收口
4. 波次收口后：模块卡提取（`_extract.py` 扩 ARTISTS）+ 图库合并 + skill `domains.yaml` 计数更新

## 4. 命名与写路径

- id：小写（`turner`、`bada_shanren`、`qi_baishi`、`ito_jakuchu` …）
- 一图一路径：dossier / corpus / images 三处归该画家工人独占；跨画家共享文件（manifest、INDEX）由主脑合并

## 5. 来源政策

- **公开仓**：PD/开放许可图 + 引文（正常出处）
- **`_private/`**（仓内、永不提交）：版权材料副本（书 / 论文 / 图）；来源记 `_private/INVENTORY.md`
- 未找到（已查: …）纪律照旧；证据等级标注照旧
