# 可证伪失效规格 — `aivazovsky` §8.1b（S02 题材独立性修复）[inference]

> **状态标签（全文件适用）**：`draft` · `E4-unexecuted` · `written spec only` · `[inference]`。
> 本文件是**预注册的书面反例规格（written counterexample specifications）**，**不是已执行的图像测试**：未渲染任何像素、未跑生成通道、未产出图像、未做 E4、未做像素测量。按 `research-application.md` §3.3「Falsifiable STYLE」：预先定义「保留表层调色板/纹理、破坏机制」的失效案例，并**明确区分书面规格与已执行图像测试**。这些规格在任何执行之前写好；若将来做预注册 E4，须**先固定** §2.1 的 `θ_L / θ_H / X / [归纳]` 阈值再执行，不得看到结果后调阈值（S02 §3.4 / Bauhaus 同源纪律）。
> 与 [style_only_draft.md](style_only_draft.md) 的关系：本文件对齐其**硬化后的 R1–R8**（`B` 高亮高频带 / `S` 平滑透射主体层 / `D` 长水平亮度不连续 / `T_u` 分类性纹理均匀度检验 / `E_hi` 区域高频能量，见 draft §2.1），并逐格指向 §7 的**玻璃 / 冰 / 抽象**适用性表。题材对象名（海/浪/月/冰/玻璃）**不参与任何判据**。

## 1. 固定不变量：被「保留」的表层调色板与纹理

每条 CE 都**固定以下表层量不变**（这是「preserve superficial palette/texture」的可复算定义），只改动一个**机制变量**：

| 不变量 | 可复算定义（与题材无关） | 为什么算「表层」 |
|---|---|---|
| `PAL` 双色温调色板 | 暖族 H 20–60° / 冷族 H 160–230° 各占 ≥15% 画幅；银白高亮 L≥0.9、S≤0.25 存在 | 色相/明度直方图，一眼可认的「像不像」线索 |
| `HF` 表层高频纹理 | 全帧高通能量 `H` 的总量 `∑H` 固定（即「有细碎高光/碎屑感」）；`B={L≥θ_L ∧ H≥θ_H}` 的**总面积也固定 ≤30%** | 高频亮纹理「看起来有泡沫/霜花/噪点」 |
| `LUM` 明度大势 | 上半大面积亮、下半较暗的整体明度布局固定 | 大面积构图观感 |

**被破坏的是机制，不是上表**：即 draft 中「`B` 必须邻接不连续（R2/R7/C1）」「`D` 必须是连续长水平不连续（R8①）」「`S` 与 `B` 的纹理能量比（R7）」「关系是否满足与对象标签无关」。因此这些 CE 直接反驳「认出调色板 / 有碎高光 / 叫它海或冰 ⇒ 风格成立」。

> **可证伪性口径**：每条给出「单变量操作 → 被破关系 ID + §2.1 算子 → 预注册的判别量与**方向性预测** → 期望裁决 → **什么结果会推翻本规格**」。因阈值 `[归纳]` 未实测，预测用**方向性不等式/比较**（一旦阈值固定即可复算），不编造已测得的像素数值。

## 2. 失效规格（≥2；本节 4 条，全部为书面规格）

<a id="db-source-line-23"></a>
### CE-F1 — 保留调色板与高频碎屑，破坏「高频高亮带邻接不连续」机制（R2 / R7 / C1）

- **场景归属**：§7 **玻璃**列（也可平移到抽象列；不依赖「海」）。
- **固定**：`PAL`、`HF`（`B` 总面积 ≤30% 不变）、`LUM` 全部不变——画面仍「暖冷双族 + 银白高光 + 一层细碎亮纹理 + 上亮下暗」。
- **单变量操作**：把 `B` 从「邻接 `D`/凸弧不连续」**整体平移为在 `S` 内均匀散布**（同样的 `B` 像素集合，逐像素搬到平滑层内部，远离任何 `‖∇L‖` 峰）。表层「有泡沫状碎高光」完全保留，但 `B` 与不连续的邻接关系被切断。
- **被破坏的机制**：R2「`B` 只附着于不连续/凸弧邻接处」、R7「`E_hi(S) ≤ E_hi(B)/3`」、C1「平滑层 × 高亮高频带」。等价地说：dossier §8.2-7 的「非泡沫区高频 ≤ 泡沫区 1/3」被反转——因为高频亮纹理被撒进了 `S`。
- **预注册判别量**：① 邻接分数 `A = area(B ∩ dilate(D)) / area(B)`；② 能量比 `ρ = E_hi(S) / E_hi(B)`。
- **方向性预测（期望裁决 = FAIL）**：`A` 降到接近 0（`B` 已离开不连续邻域）；`ρ` 升到 `> 1/3`（`S` 吞入了高频能量）。故 R2、R7、C1 判 **fail**；`PAL`/`HF` 直方图与通过样本几乎一致，单看表层会误判为「像」。
- **推翻本规格的条件（falsifier）**：若在固定阈值下 `A` 仍 ≥ 预注册阈值且 `ρ ≤ 1/3` 成立，则「搬走 `B` 即破机制」被证伪——说明邻接/能量比并非该风格的机制，本 CE 作废并须改写 draft §2.1。
- **对应越界**：dossier §4 越界警报③「点彩/短笔并置 → 越界修拉/莫奈」的**机制化版本**（旧稿 CE-A1 只说「换笔触」，本条把它锁到 `B`/`S` 算子上，题材词为零）。

<a id="db-source-line-34"></a>
### CE-F2 — 保留调色板与「有明暗分界」观感，破坏「长水平亮度不连续」机制（R8①）

- **场景归属**：§7 **抽象**列（色块边界即 `D`；也可平移到冰列）。
- **固定**：`PAL`、`HF`、`LUM` 不变；并且**刻意保留**「下半有一条明暗分界」的观感——把同一批梯度像素重排成若干**短、斜、互不相连**的亮度台阶，总梯度幅值 `∑‖∇L‖` 与通过样本相同。
- **单变量操作**：把单一连续 `D`（跨度 ≥X% 画宽、倾角 ±1.5° 内的最长连续段）**碎片化**为 N 段斜向短边，使近水平投影积分不存在任何 ≥X% 画宽的连续段。「看起来有道分界线」还在，几何连续性没了。
- **被破坏的机制**：R8①「长水平亮度不连续 `D`」——dossier §8.2-8 「落水线/水线」已按 C-05 改写为几何量；本条证明破的是**连续跨度**，不是「有没有水」。R4 的面积比仍可成立，故这是 R8① 的**单规则失败**，不是整幅崩。
- **预注册判别量**：近水平方向 `G` 投影积分的最长连续段跨度 `S_D`（%画宽）。
- **方向性预测（期望裁决 = R8① FAIL / not-applicable；R8②③④ 与 R4 仍可 PASS）**：`S_D < X`（碎片化后无长连续段）。表层 `PAL`/`LUM` 与通过样本一致 → 若只靠「有低分界」会误判为通过。
- **推翻本规格的条件（falsifier）**：若 `S_D ≥ X` 仍成立（碎片在投影上意外连成一条），或 R8① 被改写成不需要连续跨度，则本 CE 不能证伪机制；须回到 draft §2.1 重定义 `D`。这正是「书面规格先写死、执行后才能判」的用意。
- **与 C-05 的关系**：旧稿把「无完整落水线」当题材语义；本条把它变成「连续跨度不足」的几何失败，且明确「无 `D` 时 R8① 走 not-applicable 分支、其余子条仍判」，不是按题材排除。

<a id="db-source-line-45"></a>
### CE-F3 — 保留调色板与「冰/霜」表层，破坏「 categorical 排除 vs 纹理均匀度检验」（R2 / R7 / C1 / `T_u`）

- **场景归属**：§7 **冰**列的两个子态（亮裂冰面 / 均匀霜面）。这是 C-05 点名的「按对象类别排除冰封/冻海」的直接对照。
- **固定**：`PAL`、`LUM` 不变；表层「冷白、像冰/霜」的观感保留。两个子态只差 `HF` 的**空间分布**（总量可相同）。
- **单变量操作**：构造两幅统计量可分辨的冰面：
  - (a) **亮裂冰面**：`B` 非空（亮裂高频带）、`S` 平滑 → 与玻璃列同格；
  - (b) **均匀霜面**：`area(B)/area(S) ≤[归纳]`（`B` 几乎为空）、`E_hi(S)` 在主区空间变异系数 ≤[归纳] → 触发 `T_u`。
- **被破坏的机制**：**不是**「因为是冰所以不算」。检验的是 `T_u`：当 `B` 近空、`E_hi(B)` 分母近零时，`ρ = E_hi(S)/E_hi(B)` **无定义**，故 R2/R7/C1 判 **not-applicable**（缺少可测关系对象）；(a) 子态则 **applicable 且可满足**。旧稿 §5⑤ 会把 (a)(b) 一起整类排除， repaired 稿按统计量分流。
- **预注册判别量**：`area(B)/area(S)`、`CV(E_hi(S) 的空间分块)`、`ρ` 是否有定义。
- **方向性预测（期望裁决）**：(a) 与玻璃列逐格一致（R7 applicable）；(b) R2/R7/C1 = not-applicable，其余 R1/R3/R4/R5/R8 仍逐条判。**两子态的裁决不同，但差异完全由统计量解释，与「它叫冰/叫冻海」无关**。
- **推翻本规格的条件（falsifier）**：若在 (b) 中 `B` 实际非空且 `ρ` 可定义、却仍被判 not-applicable（或反过来 (a) 被整类拒绝），则 repaired 稿仍残留题材依赖，C-05 未修好，须回到 §5⑤ / §7 冰列。
- **对应越界**：dossier §4 越界警报⑤「冰封/冻海 → 越界弗里德里希」被改写为**关系冲突**：均匀纹理场因缺少 `B`/`S` 对照而不可测，而非因题材名。

<a id="db-source-line-58"></a>
### CE-F4 — 标签互换 A/A 对照：像素统计量相同，只换题材名（题材独立性的直接证伪测试）

- **场景归属**：§7 **玻璃**列 ↔ **冰**列的同一组统计量（A/A control）。
- **固定**：`PAL`、`HF`、`LUM`、以及 `B`/`S`/`D`/`E_hi` 的**全部像素统计量逐字节相同**；只把语义标签从「玻璃静物」换成「冰封海面 / frozen sea」（或反向）。这是**零像素改动**的标签互换。
- **单变量操作**：`label ∈ {glass, frozen-sea}`，其余一切不变。
- **被破坏的机制**：无机制被破坏——本条是**对照**，用来证伪「判过关/拒绝仍偷偷依赖对象名」。旧稿 §5⑤ 会对 `frozen-sea` 标签直接排除； repaired 稿应给**逐格完全相同的裁决**。
- **预注册判别量**：§7 表中 R1–R8 每格的 `{applicable/conditional/not-applicable}` 裁决向量 `V(label)`。
- **方向性预测（期望裁决 = 相同）**：`V(glass) == V(frozen-sea)`。若成立，题材独立性在**这格对照上**成立（仍只是纸面规格，非实测）。
- **推翻本规格的条件（falsifier）**：若 `V(glass) ≠ V(frozen-sea)`（任何一格因标签变化而改变裁决），则 §2.1/§7 仍藏有 `is_sea()/is_foam()/is_ice()` 之类的隐式谓词，本轮 S02 修复失败，须逐格追查判据来源。
- **边界**：这是**标签互换的书面规格**，不是统计主张、不是审美效度证明、不声称「模型从没见过该画作」（package holdout 不等于未见过）。仅检验规则写法是否题材无关。

## 3. 与 §7 适用性表的对齐（每条 CE 探哪一格）

| CE | 探的格 | 破的关系 | 保留的表层量 | 期望裁决 |

| CE-F1 | 玻璃（R2/R7/C1）；平移到抽象 | `B` 邻接不连续、`E_hi(S)/E_hi(B)` | `PAL` + `HF` + `LUM` | FAIL |
