### 2.1 掩膜与算子的独立定义（C-05 核心修法）

所有掩膜由**像素统计量**得到，不引用任何对象类别；`is_sea()` / `is_foam()` / `is_waterline()` 之类谓词在本段**不存在**。

| 符号 | 名称 | 独立定义（算子） | 介质无关性 |
|---|---|---|---|
| `H(x,y)` | 高频能量图 | 对灰度 `L` 做高通（如 Laplacian / 高斯差）取绝对值，窗口内求和 | 任何材质都有高频分量 |
| `G(x,y)` | 亮度梯度幅值 | `‖∇L‖` | 任何图像可算 |
| `B` | **高亮高频带** | `{ L ≥ θ_L ∧ H ≥ θ_H }` 经形态学闭运算后的连通带；θ_L/θ_H 为 `[归纳]` 阈值（未实测）。即「高频 + 高亮」的交集 | 玻璃高光、冰裂亮边、霜花、抽象噪点带都可落进来；海浪泡沫只是其中一个实现 |
| `S` | **平滑透射主体层** | `S = ¬B`（可再排除 `B` 的膨胀邻域以去溢出） | 磨砂玻璃体、抛光冰面、渐变抽象场都可实现 |
| `D` | **长水平亮度不连续** | 对 `G` 沿近水平方向做投影积分，取跨度 ≥X% 画宽且平均梯度 ≥[归纳] 的最长连续段；倾角 ±1.5° | 台面/背景分界、冰层/空气界面、抽象色块边界均可；「水线」只是它的一个题材实例 |
| `E_hi(M)` | 区域高频能量 | `∑_{(x,y)∈M} H(x,y)` / 面积归一化 | 纯统计量 |

- **C1 改写**：原「非泡沫掩膜/泡沫掩膜」→ 「`S` 平滑层 / `B` 高亮高频带」。R1 阶梯在 `S` 上测、R2 把 `B` 限定在不连续邻接处、R7 要求 `E_hi(S) ≤ E_hi(B)/3`。三者都用上表算子，玻璃/冰/抽象逐格可判（§7），不再需要认出浪脊。
- **frozen-sea 排除改写**：删除 §5⑤「冰封/冻海类静态现场」按对象类别的排除，改为**分类性纹理均匀度检验** `T_u`：若某候选场景的 `S` 区纹理能量在整个主区近似均匀（`E_hi(S)` 的空间变异系数 ≤[归纳] 且 `B` 带几乎为空，`area(B)/area(S) ≤[归纳]`），则 **R7/C1 判为 not-applicable（既非 pass 也非 fail），R2 判为 not-applicable**——这是「缺少关系量可测对象」的**可计算条件**，不是「因为它是冰所以排除」。冰面若带亮裂高频带（`B` 非空）且 `S` 平滑，反而可满足 R7；冻海若满足同一统计量也一视同仁。见 §7 冰例。

**必要耦合（拆开会破的关系，全部 `[归纳]`）**：

- **C1 ⟨R1 ∧ R2 ∧ R7⟩「平滑层 × 高亮高频带」**：R1 的阶梯必须在 `S` 上测，R2 把 `B` 限定在不连续/凸弧邻接，R7 要求 `E_hi(S) ≤ E_hi(B)/3`。只留 R1 撤掉 R2/R7 → 「整体渐变 + 满幅高频」，`area(B)/area(S) ≤0.30` 与能量比同时失效 → 不是本风格（见 [counterexamples.md](counterexamples.md) CE-F1）。
- **C2 ⟨R3 ∧ R5⟩「单柱 × 双色温」**：R3 全帧高亮银白像素只构成一条连通路径；R5 暖族集中于该路径/光源带。允许第二发光体 → 暖族分区失去唯一锚点 → 双色温退化为随机斑块。
- **C3 ⟨R4 ∧ R6⟩「低分界 × 高亮底剪影」**：R6 明度差 ≥0.5 依赖 R4 把高亮底放在下半部对置。P4 是 R4 的档位开关，不可与 R6 独立乱调。
- **C4 ⟨R8 ∧ R1⟩「悬停帧 × 阶梯可读」**：R8 ≤2%/帧 让 R1 的 2–4 级阶梯保持可读；帧位移放大到事件级（越界透纳），阶梯被运动模糊抹平。
- **C5 ⟨R5 银灰档例外⟩**：P6 弱档（全帧饱和 ≤0.25）时 R5 改判单色档，不得同时要求双族与低饱和。

## 5. 适用 / 不适用条件（按关系量，不按对象类别）

**适用**：① 存在「半透明/可透光体积（可实现 `S`） + 单一强光源（可实现 R3） + 大面积上下分区（可实现 R4/`D`）」的构图类；② 输出需逐帧像素自查（渲染/静态海报/无字 key visual）；③ 需要「平滑层 + 局部高频高亮带」的质感对比（`B` 非空且 `E_hi(S)` 低）；④ 悬停/微动预算受控的 motion 场景。

**不适用（全部改写为关系冲突，不再是题材黑名单）**：
① 需要**可见笔触/厚涂能量场**（`E_hi(S)` 高，与 R7 硬冲突）；② 需要**多光源/画内点光落脸/暗部塌陷**（与 R3/C2 冲突）；③ 需要**边缘溶解、天气当主角**（与 R1/R8/C4 冲突）；④ 线族/平涂剪影版画语汇（与 R1/R2 冲突）；
⑤ **（C-05 修复）** 「冰封/冻海类静态现场」的按类排除**删除**，替换为**分类性纹理均匀度检验 `T_u`**：当 `S` 纹理能量在主区近似均匀、`B` 带几乎为空（`area(B)/area(S) ≤[归纳]`）时，R2/R7/C1 判 **not-applicable**（缺少可测关系对象），其余规则仍逐条判；若冰面带亮裂高频带（`B` 非空）且 `S` 平滑，则与玻璃一样可满足 R7——**判据是统计量，不是「它是不是冰/海」**。见 §7 冰列。
⑥ 本段**不含文字/排版规则**——S-06 无文字 key visual 边界下不补文字、不借 blake 式图文同版。

**组合预检（沿用 dossier）**：C-05 笔触可见度、C-09 运动预算、C-12 色相面积、C-13 阴影色相。越界轴按 70/30 选主导轴（均以关系冲突表述）。

## 7. R1–R8 逐格适用性表（glass / ice / abstract · 同一张三表 · 纸面约束检查）

> 口径：三列是**同一组 R1–R8 关系**在非海景候选上的逐格判定，不是三套规则。每格给 `applicable` / `conditional` / `not-applicable` / `fail` / `unknown` **并附理由**（理由只引用 §2.1 算子与统计量，不引用对象名）。全部为 `[inference]` 纸面规格、**draft / E4-unexecuted**：格内「满足」指「关系可写且参数化纸面约束有非空可满足解」，**不是已渲染实测通过**。`[归纳]` 阈值未实测，故所有 `applicable` 都带未实测限定。**裁决词分三类，不可混用**：① `not-applicable` 仅用于**关系本身缺席或缺少可测对象**（R6 是 optional 缺席；`T_u` 下 `B` 空使 `E_hi(B)` 分母无定义）；② `fail / not-satisfied` 用于**已知违反某条 mandatory 关系**（如 R3 已知多光源/多柱 → 连通域数 ≠1）；③ `unknown` 仅用于**证据不足、无法判定满足或违反**。已知违反 mandatory 规则**不得**降格为 not-applicable。

| 规则 | 玻璃（半透明磨砂体 + 抛光台面 + 单一顶光） | 冰（带亮裂的冰面 / 均匀霜面两种子态） | 抽象场（体积光 + 色块边界 + 噪点带） |
|---|---|---|---|
| **R1** 半透明体积连续明度阶梯 | **applicable** — 玻璃体 `S` 区沿竖向可做 ≥2 级 ΔL≥8/255 阶梯，与介质无关 | **conditional** — 冰体若存在内部透光梯度则 `S` 上阶梯可写；若为不透明均匀霜面（触发 `T_u`）则 R1 仍可写但缺对照体积，降级为依赖具体剖面 | **applicable** — 体积光在暗场的 2–4 级梯度即 `S` 阶梯，纯统计量 |
| **R2** 高亮高频带 `B` 覆盖 ≤0.30 + 邻接不连续 | **applicable** — 上缘花边高光满足 `L≥θ_L ∧ H≥θ_H`，`B` 非空且面积可 ≤30% | **conditional** — 亮裂高频带可形成 `B`（适用）；均匀霜面 `area(B)/area(S)≈0` → **not-applicable（子态）**，理由：`B` 为空缺少可测对象，非「因为它是冰」 | **applicable** — 噪点/碎屑带由高通能量阈值定义，与「是不是泡沫」无关 |
| **R3** 单一发光路径柱（连通域=1，≥40% 画高，**mandatory**：无第二发光体/无第二柱） | **applicable** — 顶光在台面投下单一银白连通反射柱 | **conditional（分两支）** — ① 单一低角度光源经冰面镜反射可成单柱 → 满足/可写；② **已知漫射天光为多光源、或出现第二高亮柱时，连通域数 ≠1、直接违反 R3 的 mandatory「唯一连通路径 + 无第二发光体/第二柱」→ `fail / not-satisfied`（按「连通域数」判，不按「冰」判）**，与 §4 强反例 2「双光源破 R3」同轴，破 C2；③ 若光源/柱数**未给定、证据不足** → `unknown`，不得预设为违反或满足。**注意**：②是「已知违反」的 FAIL，与 `T_u` 的「缺少可测对象 not-applicable」、R6 的「optional 缺席 not-applicable」是三类不同裁决，不混用 | **applicable** — 单条发光路径柱即唯一连通域，抽象场可直接给 |
| **R4** 近水平分界 ±1.5° / 下 1/3 带 / 面积比 ≥1.2 | **applicable** — 台面/背景分界压在下 1/3 带 | **applicable** — 冰层/空气界面即一条近水平边界，几何量可测 | **applicable** — 色块边界置于 0.55–0.75 画高，几何量可测 |
| **R5** 双色温分区（或银灰档例外） | **applicable** — 暖顶光 / 冷玻璃体分区；或全帧 S≤0.25 走银灰例外 | **conditional** — 冷族占主时若暖族 <15% 且未触发银灰例外，则不满足（这是面积统计，不是题材）；可参数化给暖光源补 ≥15% | **applicable** — 暖族集中路径带、冷族集中暗场，HSV 面积可算 |
| **R6** 可选深剪影 / 高亮底明度对置 | **applicable（optional）** — 深剪刀 L≈0.2 与台面差 0.6；R6 本就是可选关系，缺席不扣分 | **not-applicable（通常）** — 若构图不含深剪影组，R6 作为 optional 关系判 not-applicable；理由：可选关系缺席，非介质排除 | **applicable（optional）** — 可放/可不放深形；不放时 optional 不扣分 |
| **R7** `E_hi(S) ≤ E_hi(B)/3`（平滑层 vs 高亮高频带） | **applicable** — 磨砂玻璃非高光区高频能量可设为高光区 1/4，能量比可写 | **conditional** — 亮裂冰面：`S` 平滑、`B` 非空 → 可满足（与玻璃同格）；均匀霜面触发 `T_u`（`B` 空、`E_hi(S)` 空间均匀）→ **not-applicable（子态）**：分母 `E_hi(B)` 近零使比值无定义，是「缺少可测关系对象」，不是「冰被排除」 | **applicable** — 平滑渐变底 + 局部噪点带，能量比可写 |
| **R8** 长水平亮度不连续 `D` + 闭合度 + 悬停预算 | **applicable** — 台面/背景 `D` 跨度 ≥X% 画宽；定格帧位移 1% ≤2%，`B` 带位移 ≤10%/s | **conditional** — 冰层/空气界面给出 `D`（① 分支适用）；若无长水平不连续则 ① 判 not-applicable、②③④ 悬停预算仍判——按几何量分支，不按「冻海」强制排除 | **applicable** — 色块边界即 `D`；主形上凸弧不闭合 + 悬停微动，几何/时序量可算 |
| **C1 ⟨R1∧R2∧R7⟩** | **applicable** — `S`/`B` 三分量齐备 | **conditional** — 亮裂冰面 applicable；均匀霜面因 `B` 空判 not-applicable（`T_u`） | **applicable** — 三分量齐备 |
| **耦合/状态** | 8 条关系层均可写（R6 optional）→ **候选**，非「纯风格成立」 | 至少 3 个子态：亮裂冰面（单柱）多数格 applicable、均匀霜面 R2/R7/C1 not-applicable（`T_u` 缺少可测对象）、**已知多光源/多柱冰面 R3 = fail/not-satisfied（已知违反 mandatory，非 NA）**、光源数未给定则 R3 = unknown → **按统计量与已知条件分支，不是整类排除** | 8 条关系层均可写 → **候选**，非实测通过 |

**表的用途与边界**：① 证明「判过关/拒绝」**不靠对象名称**（冰不再整类排除、玻璃无需认出海）；② 给出「未知/条件」格而非全打勾，回应 C-05「没有证明全部 8 条均可迁」；③ 这是**参数化纸面约束检查**，缺渲染/E4，全部标 draft / `[inference]` / E4-unexecuted。具体可证伪的失效规格见 [counterexamples.md](counterexamples.md)。
