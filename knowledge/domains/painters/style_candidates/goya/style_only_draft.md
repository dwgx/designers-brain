## 1. 默认题材泄漏的剥离

dossier §8.1 正向段把「戈雅」强绑定在一组**历史事件—怪诞形象**内容对象上：背身的行刑队、被裁切在画外的决定性上下文、白衬衫张臂的受害者、地上方形提灯、远处城镇剪影，以及奇想集里的食子/飞女/女巫/巨人。这些是**题材档位**（§4 P3 怪诞强度默认 40%「讽喻按需升档」、P6 序列帧数是工作流参数），不是像素关系。本段把它们逐项降级为关系量：

| §8.1 内容词 | 为什么不是风格前提 | 本段处理 |
| --- | --- | --- |
| `firing squad seen from behind / victims in a white shirt / a single victim arms thrown up` | 具名阵营与身份是叙事内容；可判读的只有「施害者面孔可见数 = 0、受害者 ≤2、其余以体态/剪影」这一**计数关系** | 删除阵营/身份，保留 §8.2-3「施害者面孔 0、受害者可见面孔 ≤2」+ §8.2-4「已死/濒死/将死三态 ≥2 态」 |
| `one in-scene light source (a square lantern set on the ground)` | 「提灯/火把」是器物内容；关系量是「画内可见光源数 ∈[1,2]、位于下 1/3×中央 1/3、亮区重心落受害者包围盒」 | 保留为**光源计数 + 位置 + 亮度质心**关系（§8.2-1），器物专名不迁 |
| `monumental night scene / readable townscape silhouette` | 夜色与城镇是题材/地点；可算的是「黑+土色系 ≥60% 面积、饱和色 ≤3%、白色高光连通域 ≤5」 | 保留为 **HSV 掩膜 + 连通域**关系（§8.2-5），不要求认出城镇 |
| `nightmare creatures / witches / giants / cannibals`（怪诞档） | 怪兽清单是讽喻内容；关系量是「非人/半人形象 ≥1 且与讽喻对象同框、恐惧面容 ≥1」 | 只保留「同框 + 计数」关系（§8.2-8），语义讽喻对象不迁；P3 档位开关决定是否启用 |
| `one blood-red accent only / earth ochres, umber, black, lead white` | 色名是内容；风格要件是「饱和色 ≤3% 面积、红色仅允许在伤口/血迹区域、白色高光须与四类对象相交」 | 保留为**面积比 + 连通域相交**关系（§8.2-5），色名只作示例 |

**迁移判据**：撤掉阵营身份、处决事件、提灯器物、城镇夜景、怪兽清单后，§8.2 的 8 条自查（亮度质心/光源定位、画框裁切 + 前景带、人脸检测计数、姿态分类 + 空间排序、HSV 掩膜 + 连通域、高光检测 + 高频能量图、方向场 + 区域方差、对象检测 + 面容关键点）仍可逐帧计算 → 纯风格。按此判据 1/2/3/5/6/7 全可迁；4（队列三态）与 8（怪诞同框）只保留其**计数/同框/分类**关系，事件与讽喻语义不迁。

> **goya 特有的规则内张力（登记，不消歧）**：§4 P6「序列帧数」为工作流参数（默认 1 单幅），而 §8.2-7 版画帧附加把「交叉排线交叉点密度 ≈0、飞尘区 ≥10%、刮亮点、题刻 ≤1 行」写成可判定规则——版画工艺档与油画档是**档位开关**，不是无条件叠加；AUDIT-goya 的 counterexample 已登记其近邻（戈雅禁交叉排线 vs 荷加斯交叉排线）为组合冲突，本 lane 只登记不修。

**必要耦合（拆开会破，`[归纳]`）**：

- **C1 ⟨R1 ∧ R2⟩「证据光 × 即时构图」**：这是戈雅身份的双护栏（§4 用法「P1/P2 两条同时 ≥中档才成立」）。若保留画内光源却把构图改成闭合完整场面 → 退回挂毯期/白天记录档（P1 弱）；若保留出画外裁切却把光源移到画外、亮部只落脸/手/道具 → 越界**卡拉瓦乔**（分工注 L105）。二者必须同时成立。
- **C2 ⟨R1 ∧ R5⟩「画内光 × 暗调色彩预算」**：光源在画内且是唯一亮区重心，意味着饱和色只能 ≤3%、黑土色 ≥60%；若改成伦勃朗式「单光源连续衰减照单张脸」（P2 弱/中 + 单脸心理），R5 的「白色高光连通域 ≤5 且须与四类对象相交」会被单脸高光破坏（分工注 L105）。
- **C3 ⟨R3 ∧ R4⟩「面孔预算 × 队列三态」**：施害者 0 面孔、受害者 ≤2 面孔，配合「≥3 人读出三态中 ≥2 态」，构成「以体态/剪影叙事」的计数系统；若给每人清晰五官（§8.1 负向 `facial detail on every figure`），R3 破，R4 的三态也失去体态分类的落点。
- **C4 ⟨R5 ∧ R6⟩「暗调预算 × 哑光表面」**：黑土色 ≥60% 面积且无镜面高光、高频粗糙度均匀，二者共同排除洛可可亮色与光油；若加上 `glossy varnish` / 镜面斑 >0.5%，R6 破，R5 的「白色高光连通域」也会被镜面斑污染。
- **C5 ⟨R7 ∧ R2⟩「版画工艺档 × 禁交叉排线」**：版画帧附加把「交叉排线交叉点密度 ≈0」写成硬规则，与荷加斯 §8.2-8「排线族 ≥2 方向、交叉排线允许」同轴互斥（AUDIT-goya 已登记为组合冲突）；R7 是**版位开关**（版画档启用、油画档关闭），不是无条件叠加层。

## 3. 正例（跨场景，逐帧可自查）

**正例 1 — 抽象新闻版式 / 事故信息图（无处决、无士兵、无提灯器物）**：一张下 1/3 前景带放最大姿态偏移的抽象形体、≥1 组被画框裁切（R2）；画内 1 个可见光源置于下 1/3×中央 1/3，亮度前 10% 质心落在「受众组」包围盒，另一侧组平均亮度 ≤全帧 40%（R1）；一侧组面孔可见数 = 0、另一侧 ≤2（R3）；≥3 个单元读出「已停/将停/运行中」≥2 态（R4）；饱和色 ≤3%、黑土色 ≥60%、白高光连通域 ≤5（R5）；无镜面斑、高频粗糙度均匀（R6）；版画档取飞尘区 ≥10%、无交叉排线（R7）；怪诞档关闭（R8 档位）。**八条自查全是亮度质心/裁切检测/人脸计数/HSV 掩膜/连通域/方向场统计量，无需认出 1808 年的行刑队** → 纯风格成立。

**正例 2 — 监控截帧 / UI 告警态（内容全换）**：背身剪影组 + 画内单一光源 + 裁切出画外 + 0 面孔/≤2 面孔 + 暗土色调 + 哑光无高光 + 姿态冻结。R1–R8 仍逐条可算。仅声明视觉关系可迁，不声称任何生成通道已产出、不声称 E4 通过。

## 4. 强反例（题材全对但风格不成立）

**强反例 1 — 题材全对但改柔和多光源**：画出背身队列、白衬衫张臂者、地上提灯、远景城镇（题材齐备），但把光改成柔和工作室光 + 多光源 + 补光 + 反射。破 R1（画内可见光源数 ∈[1,2] 与亮区重心失效）、R6（哑光/无镜面斑失效）、连带破 C1/C2；§8.1 负向 `soft studio lighting, multiple light sources, fill light, reflections` 即此。**结论：题材齐全≠风格成立**。

**强反例 2 — 保留构图却把光源移出画外**：题材不变，把方形提灯撤掉、改成画外单光源只照亮一张脸/手/道具、背景近黑。破 R1（画内光源数归零）、R5（亮区重心不再落受害者组、黑土色 ≥60% 被近黑取代）；分工注 L105 明写「P2 为强但光源移到画外 → 越界卡拉瓦乔」。

**强反例 3 — 给每个形体清晰面孔**：题材不变，把背身剪影组改成逐个可辨五官的群像肖像。破 R3（施害者面孔 0 失效）、R4（三态失去体态分类落点）、连带破 C3；§8.1 负向 `facial detail on every figure, symmetry` 即此。

<a id="db-source-line-56"></a>
## 5. 适用 / 不适用条件

**适用**：① 单帧事件/告警/信息图类输出（光源计数、裁切、前景带、人脸计数可逐帧查）；② 需要「画内证据光 + 匿名施害侧 + 暗调哑光」的编辑插图/版画；③ 需要「≤3% 饱和色、≥60% 黑土色」的低成本高对比版式；④ 无镜面高光、无柔光补光约束明确的渲染通道。

**不适用**：① 需要**画外单光源 + 近黑背景照亮单张脸**的场景（破 R1/R5，越界卡拉瓦乔）；② 需要**单光源连续衰减照单脸心理**的场景（破 R1/R5，越界伦勃朗）；③ 需要**柔和多光源/工作室补光/光油反射**的场景（破 R1/R6，§8.1 负向）；④ 需要**逐个清晰面孔/对称群像**的场景（破 R3/R4）；⑤ 需要**亮色洛可可/甜粉彩/英雄化光环**的场景（破 R5/R6，§8.1 负向）；⑥ 需要**交叉排线明暗**的场景（破 R7，越界荷加斯版画档）；⑦ 需要运动模糊/连续动作推拉的场景（破 §8.2-6 哑光高频 + §8.1 负向 `motion blur`）。

**组合预检（沿用 dossier）**：§3.1 与卡拉瓦乔（光源数 ≥1 vs 0、亮部对象群体 vs 脸/手/道具，C-01/C-11/C-12）、伦勃朗（面孔预算类型化群脸 vs 单脸心理）、荷加斯（禁交叉排线 + 飞尘 vs 交叉排线）分工轴；Lane B「硬阴影」禁令按 C-01 改写句式（夜戏档需显式声明硬边光锥）。
