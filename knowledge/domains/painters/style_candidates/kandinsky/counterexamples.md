> 全部为**纸面推演 [inference]**，未渲染像素、未跑生成通道、未做 E4。每条给具体撤去/反转/保留操作，点名被破坏的 §8.1b 关系 ID 与 dossier §8.2 规则行。题材对象（点线圆三角/自由形清单、主圆星群锚、穿越色块的五线谱式细线、互补色对、黑色重音块、早期骑手/山/教堂碎片、包豪斯/巴黎时期名）全部保留，证明「题材齐备≠风格成立」。[STYLE-kandinsky]

## CE-N1 — 撤去零对象：让闭合线包围区出现可命名对象

**操作**：题材全保留；只把「对象检测器最高置信度 <0.35、线不闭合为轮廓」改成 ≥1 条闭合线勾出清晰人脸/骑士/山/教堂。

**被破坏的规则**：
- R1（§8.2-1 L245「COCO 最高置信度 <0.35、无可命名对象区域、像脸/物强暗示 = 0」）→ 直接 fail；
- R4（§8.2-4 L248「线不得闭合为物体轮廓、闭合线包围区内不得出现可命名对象」）→ 直接 fail；
- 连带破 C1（零对象 × 元素计数）、C3（独立线 × 零对象）。
- 对应 §8.1 负向 recognizable objects / faces / figures / landscapes / still life、§4 分工注 L109「回到表现主义具象域」。

**为何是风格级反例**：只换「线是否闭合勾形」这一关系；证明康定斯基身份轴是零对象（C1），不是「画的是不是圆和三角」。

## CE-N2 — 反转重力：把「无重力漂浮」改成地平线 + 接地投影

**操作**：保留零对象、元素 ≥8、声部色彩、独立穿越线、块面黑；但加地平线、消失点、底部接地投影与阴影连接。

**被破坏的规则**：
- R5（§8.2-5 L249「地平线 = 0、消失点检测失败、接地投影 = 0」）→ 直接 fail；
- R6（§8.2-6 L250「无全压底部/贴边、上下左右质量差 ≤35%、无阴影连接」）→ 被地心引力重写；
- C4（无重力 × 动态平衡）被拆。
- 对应 §8.1 负向 horizon line / vanishing point / cast shadows / grounding / perspective。

**为何是风格级反例**：只反转重力的有无，未改任何题材；证明「无重力 × 动态平衡」（C4）是纯几何分布关系。

## CE-N3 — 保留声部撤掉独立线：互补色与黑块还在，但改蒙德里安黑网格

**操作**：保留色相族 4–8、互补对 ≥1、高饱和 ≥15%、黑色块面（R3/R7 不动）；把细长独立穿越线改成规则黑色网格 + 对称装饰图案。

**被破坏的规则**：
- R4（§8.2-4 L248「线 ≥5、≥2 条穿越 ≥2 色块、不闭合为轮廓」）→ 网格线 fail；
- R7（§8.2-7 L251「黑色不得仅作细线、需有块面级黑」）→ 规则网格将黑降到线级、连带；
- 连带破 C2（色彩声部 × 黑色重音）、C3。
- 对应 §4 分工注 L109「P1 强 + P3 弱 + P2 强 → 蒙德里安域禁止」、§8.1 负向 Mondrian-style black grid / symmetrical ornament。

**为何是风格级反例**：声部色板与黑重音完全保留、题材全在，风格仍不成立——反驳「认出红绿互补对就是康定斯基」。也说明「独立线」是线-色块相交/非闭合关系。

## CE-N4 — （内容泄漏反证）把「必须有主圆/构成 VII/视觉音乐理论」升为必要条件

**被破坏的规则**：
