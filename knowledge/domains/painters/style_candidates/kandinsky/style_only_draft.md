## 1. 默认题材泄漏的剥离

dossier 特殊在它是**理论型画家**档案：§8.1 正向段把「康定斯基」绑在「painting as visual music」「cosmos of points/lines/circles/triangles」「a dominant circle or central constellation」「rider/hill/church 碎片（早期档）」「包豪斯 primary colors with black」等**理论话语与作品名**上，§0 口径明写「把内在必然性/声音-色彩/点线面理论话语翻译成可判定规则，凡从理论文本推导的规则一律标 [归纳]，不写成他作画时想着什么」。本段把这些话语逐项降级为像素关系：

| §8.1 内容词 | 为什么不是风格前提 | 本段处理 |
| --- | --- | --- |
| `painting as visual music / colors treated as sounding voices / inner necessity` | 「视觉音乐/内在必然性」是理论话语（§0 口径禁止写成心理状态）；关系量是「色相族 4–8、互补对 ≥1 组、高饱和 S≥0.5 像素面积 ≥15%」 | 删除音乐/精神词，保留 §8.2-3「色彩预算规则」的色相族/互补对/高饱和面积统计 |
| `points, lines, circles, triangles and free-form shapes / cosmos` | 元素清单与「宇宙」隐喻是话语；关系量是「可数元素 ≥8、元素类别 ≥3、存在 ≥1 个主形（面积前 3 连通域）」 | 保留为**元素计数 + 类别 + 连通域面积**关系（§8.2-2），形状专名只作类别示例 |
| `a dominant circle or a central constellation as the anchor` | 「主圆/星群锚」是构图话语；关系量是「元素质心分布无全压底部/全贴边、上/下左/右质量差 ≤35%」 | 保留为**动态平衡分布**关系（§8.2-6），不要求认出圆或星群 |
| `thin, independent lines that travel across color areas like a musical staff` | 「五线谱」是隐喻；关系量是「细长连通域(线)≥5、其中 ≥2 条与 ≥2 个色块相交(穿越)、线不得闭合为物体轮廓」 | 保留为**线-色块相交 + 非闭合**关系（§8.2-4），隐喻不迁 |
| `rider / hill / church dissolving into color patches`（早期档）/ `Bauhaus` / `Paris` 时期名 | 具体作品/时期名是内容档位；关系量是 §8.2-8 的**可切换档判据**（早期/包豪斯/巴黎），由 §4 P2 几何化滑轨决定 | 保留为**时期档位开关 + 判据**（§8.2-8；§4 P2 L102），时期名只作标签 |

**迁移判据**：撤掉「视觉音乐/内在必然性」理论话语、形状清单隐喻、主圆/星群锚、五线谱比喻、作品/时期名后，§8.2 的 8 条自查（对象检测器最高置信度 <0.35、元素计数/类别/主形连通域、色相族+互补对+高饱和面积、线连通域+相交计数+闭合检测、地平线/消失点/接地投影检测、质心分布+质量差、黑色像素占比+块面级黑、时期判据切换）仍可逐帧计算 → 纯风格。§0 口径明写「不写成他作画时想着什么」，故**全部 8 条可迁**，理论话语只作档位标签。

> **kandinsky 特有的规则内张力（登记，不消歧）**：§4 P1 强档「零对象 ≈0」与 §8.2-8 早期档「对象碎片 ≤2、轮廓软」是**时期档位开关**（早期允许具象残留，组合时按具象系处理，分工注 L109）；另 §8.2-3「色相族 4–8」与 Lane B 色数上限 ≤3 冲突，注记明写「康定斯基模块的色数不在 ≤3 色上限域内」（C-15/N6）。本段把 R8 写成档位开关、把色数域冲突登记为组合预检，不升级为无条件阈值。

## 2. 可迁移视觉关系（参数 · 单位 · 范围 · 必要耦合）— 零对象 × 色彩声部 × 独立线 × 漂浮动态平衡四族；全部 `[归纳] 未实测` [STYLE-kandinsky]

| ID (kandinsky) | 可迁移关系 | 单位 / 范围 `[归纳] 未实测` （kandinsky 专属口径：量纲取自 §8.2 L245-252 的「零对象」与 §4 L99-109 档位表，跨场景迁移不改此量纲。） | 源行 |
| --- | --- | --- | --- |
| R1 | **零对象** | 对象检测器(COCO 类)最高置信度 < 0.35，且不存在可命名对象区域；「看起来像脸/物」强暗示 = 0 | §8.2-1 L245；§4 P1 L101 |
| R2 | **元素计数** | 可数元素 ≥8；元素类别 ≥3(点/线/圆/自由形/多边形)；存在 ≥1 个主形(面积前 3 的连通域) | §8.2-2 L246；§4 P6 L106 |
| R3 | **色彩预算/声部** | 色相族 4–8(包豪斯档 3–5)；互补对 ≥1 组；高饱和(S≥0.5)像素面积 ≥15%；近单色档仅在「刻意克制」时允许且须显式声明 | §8.2-3 L247；§4 P3 L103 |
| R4 | **线-色块独立** | 细长连通域(线)≥5；其中 ≥2 条与 ≥2 个色块相交(穿越)；线不得闭合为物体轮廓(闭合线包围区内不得出现可命名对象) | §8.2-4 L248；§4 P4 L104 |
| R5 | **空间无重力** | 地平线检测 = 0；消失点检测失败；画面无接地投影(底部接触阴影 = 0) | §8.2-5 L249；§4 P5 L105 |
| R6 | **漂浮/动态平衡** | 元素质心分布无「全压底部」或「全贴边」；元素与背景对比 ≥阈值且无阴影连接；上/下、左/右元素质量差 ≤35% | §8.2-6 L250；§8.1 正向 L226 dynamic equilibrium |
| R7 | **黑色重音** | 黑色像素占比 5–25%(早期档 ≤30%)；黑色连通域 ≥1 个主形(面积 ≥全画 1%)；黑色不得仅作细线(需有块面级黑) | §8.2-7 L251；§8.1 正向 L225 black as accent mass |
| R8 | **时期判据(档位)** | 早期档 = 轮廓软 + 对象碎片 ≤2 + 不协和(色相对撞 ≥3 组)；包豪斯档 = 硬边 + 几何元素 ≥60% + 色形对应对 ≥1；巴黎档 = 生物形态 ≥3 + 砂质纹理(高频粗糙) + 深色底 ≥40% | §8.2-8 L252；§4 P2 L102 |

**必要耦合（拆开会破，`[归纳]`）**：

- **C1 ⟨R1 ∧ R2⟩「零对象 × 元素计数」**：这是康定斯基身份的双护栏（§4 用法「P1+P3 定是不是康定斯基，两条同时 ≥中档才成立」，§8.2-1 加零对象硬判据）。若元素 ≥8 却让某个闭合线包围区出现可命名对象 → 破 R1（分工注 L109「回到表现主义具象域」）；若零对象却元素 ≤5/类别 <3 → 退回装饰极简（§4 P6 弱档）。
- **C2 ⟨R3 ∧ R7⟩「色彩声部 × 黑色重音」**：色相族 4–8、互补对 ≥1、高饱和 ≥15% 与「黑色 5–25%、≥1 块面级黑、不得仅作细线」是同一声部化的彩色/重音两面；若 P3 强 + P4 弱（线=轮廓）→ 滑向装饰平面马蒂斯域（分工注 L109），若 P1 强 + P3 弱 + P2 强 → 蒙德里安域（**禁止**）。
- **C3 ⟨R4 ∧ R1⟩「独立线 × 零对象」**：线 ≥5 条、≥2 条穿越 ≥2 个色块、不闭合为轮廓，是「零可命名对象」的几何保证；若线闭合勾出物形（§8.1 负向 recognizable objects / faces / figures），R1 的对象检测与 R4 的非闭合同时失效。
- **C4 ⟨R5 ∧ R6⟩「无重力 × 动态平衡」**：地平线 = 0、消失点失败、接地阴影 = 0，给「质心不全压底/不贴边、上下左右质量差 ≤35%」一个无重力场；若加接地投影/地平线（§8.1 负向 horizon line / cast shadows / grounding），R5 破，R6 的动态平衡被地心引力重写。
- **C5 ⟨R8 ∧ R2/R3⟩「时期档位 × 元素/色彩」**：早期档（对象碎片 ≤2、色相对撞 ≥3 组）、包豪斯档（几何 ≥60%、色形对应 ≥1）、巴黎档（生物形态 ≥3、深色底 ≥40%）是 **P2 滑轨切换**（§4 P2 默认 50% 按时期切换），不是叠加层；R2 元素类别与 R3 色相族数随档位改取值（包豪斯档 3–5 色相族）。

## 3. 正例（跨场景，逐帧可自查）

**正例 1 — 抽象数据场 / 生成式图标云（无青骑士、无构成 VII、无圆/三角专名）**：一张无重力场：对象检测器最高置信度 <0.35、无「像脸/物」强暗示（R1）；10 个可数元素、类别 = 点/线/自由形/多边形 4 类、≥1 个面积前 3 主形（R2）；色相族 6、互补对 1 组、高饱和面积 ≥15%（R3）；6 条细长线其中 3 条各穿越 2 个色块、无闭合轮廓（R4）；地平线 0、消失点失败、接地阴影 0（R5）；质心上下/左右质量差 ≤35%、无阴影连接（R6）；黑像素 12%、1 个 ≥全画 1% 块面黑（R7）；包豪斯档取硬边 + 几何 ≥60% + 色形对应 ≥1（R8）。**八条自查全是对象置信度/连通域/色相族/线相交/地平线/质心分布/黑占比统计量，无需引用任何理论著作或作品名** → 纯风格成立。

**正例 2 — UI 加载态 / 乐谱式信息图（内容全换）**：零对象 + 元素 ≥8 + 声部色彩 + 独立穿越线 + 无重力 + 动态平衡 + 块面黑 + 时期档位。R1–R8 仍逐条可算。仅声明视觉关系可迁，不声称任何生成通道已产出、不声称 E4 通过。

## 4. 强反例（题材全对但风格不成立）

**强反例 1 — 题材全对但闭合线勾出可命名对象**：画出点线圆三角、主圆星群、穿越线、互补色、黑重音（题材齐备），但让 ≥1 条闭合线包围区出现清晰可命中的人脸/骑士/山/教堂。破 R1（对象检测器置信度 ≥0.35、可命名对象区域）、R4（线不得闭合为轮廓）、连带破 C1/C3；§8.1 负向 recognizable objects / faces / figures / still life 即此。**结论：题材齐全≠风格成立**。

**强反例 2 — 保留声部却改接地透视**：题材不变，加地平线、消失点、底部接地投影与阴影连接。破 R5（地平线 = 0、消失点失败、接地阴影 = 0）、R6（动态平衡质量差 ≤35% 被重写）、连带破 C4；§8.1 负向 horizon line / cast shadows / grounding / perspective。

**强反例 3 — 改蒙德里安黑网格/对称装饰**：题材不变，把独立穿越线改成规则黑色网格、对称装饰图案。破 R4（线=独立轨迹、穿越色块）、R7（黑色仅作细线、无块面级黑）、连带破 C2/C3；§4 分工注 L109「P1 强 + P3 弱 + P2 强 → 蒙德里安域禁止」、§8.1 负向 Mondrian-style black grid / symmetrical ornament。

## 5. 适用 / 不适用条件

**适用**：① 抽象/生成式/信息图类输出（对象置信度、连通域、色相族、线相交、质心分布可逐帧查）；② 需要「零对象 × 色彩声部 × 独立线 × 无重力平衡」的加载态/数据场；③ 包豪斯/早期/巴黎三档可切换的几何系统；④ 对象检测、地平线/消失点、黑占比约束明确的渲染通道。

**不适用**：① 需要**可命名对象/人脸/风景/静物**的场景（破 R1/R4，越界具象系，分工注 L109）；② 需要**地平线/消失点/接地投影/透视**的场景（破 R5/R6，§8.1 负向）；③ 需要**蒙德里安黑网格/对称装饰/墙纸图案**的场景（破 R4/R7，分工注 L109 禁止/§8.1 负向）；④ 需要**近单色极简/单色 minimalism**的场景（破 R3，除非显式声明「刻意克制」档）；⑤ 需要**喷枪渐变/霓虹发光/光油**的场景（破 R3 声部，§8.1 负向 airbrushed gradients / neon glow / glossy varnish）；⑥ 需要**喷溅/滴流/3D 渲染/摄影写实**的场景（§8.1 负向）；⑦ 与 **Lane B ≤3 色上限**同轴时：康定斯基色数不在该域内（C-15/N6），须按冲突预检改口径而非降色数。

**组合预检（沿用 dossier）**：§3.1 与毕加索（对象残留度/色彩角色，康 70% 时毕只贡献面片化边缘、禁止引入近单色与锚点）、萨拉希（roster §4-1）、吴冠中（§2.1）、恩格瓦雷（§2.15）分工轴 + 蒙德里安/波洛克禁区；Lane B 06 包豪斯卡反约束「别做成渐变、几样东西一起进场」须按 N1 改写（允许多元素并置与色场叠层，但禁弹性过冲等设计性动效，§8.1 说明 L241）。
