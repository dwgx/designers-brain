## 1. 默认题材泄漏的剥离

| §8.1 内容词 | 为什么不是风格前提 | 本段处理 |
|---|---|---|
| `mill pond, river ford, water meadow, village lane / Dedham, Salisbury, Flatford` | 地标专名是内容；可判读的是「≥1 个中景—天际线带锚点 + 单消失点收敛成功」 | 改写为 §8.2-5 的锚点/消失点关系，不锁任何地名 |
| `stacked cumulus … one darker shower cloud` | 具体云型是内容档；关系量是「天空带 ≥35% + ≥1 种云型结构 + 地平线可见」 | 保留为 §8.2-1 的区域/梯度关系 |
| `haymakers, a cart crossing a ford, a barge` | 人物/劳作语义是内容；§8.2-7 只要「≤5 实例 + 姿态为劳作 + 无背向凝视者 + 人脸 ≤1 组」 | 降为可选实例层（§4 用法：云研究档「无人物、无地标也成立」） |
| `individual trees painted as portraits / pollarded willows` | 树种是内容 | 删除；保留「植被高频区亮斑 ≥15 个」的统计量 |
| `specific, recognisable place faithfully recorded` | 「可辨地点」是**观察制度**（P2/P4），不是像素关系；§3.1 明写云研究档可关 | 降为 P2 工作流开关，不进必要关系 |

**迁移判据**：换掉全部地标/人物/树种后，§8.2 的 8 条自查（区域分割+边缘梯度、亮度阈值+斑点检测、HSV 掩膜、光流场+轮廓梯度、对象检测+消失点估计 RANSAC、分区色相/饱和比对、姿态估计+人脸检测、梯度带宽+多尺度能量比）仍可逐帧算 → 纯风格。

> **constable 特有的登记项**：AUDIT-constable 记录了**1 个 §4 机制强反例**——「云研究档被 §4 越界警报误判」（云研究档 P2 强、P6 弱、无人物无地标，却因 §4 越界警报③「外加象征装置…地点不可辨 → 越界弗里德里希」被误伤）。本段据此把 P4（地点锚定）明确写成**档位开关**而非无条件前提：云研究档取 P4 弱档合法，不得判越界。`dossier §4` 与 `friedrich.md §3.1` 四判据互查一致（AUDIT 结论 CONFIRMED）。

## 2. 可迁移视觉关系（参数 · 单位 · 范围 · 必要耦合）— 天空/色点/光流/干笔四族；全部 `[归纳] 未实测` [STYLE-constable]

| ID | 可迁移关系 | 单位 / 范围 `[归纳]` | 源行 |
|---|---|---|---|
| R1 | **天空带可读 / 地平线可见**：天空带面积 ≥35%（上 1/3 内云覆盖 ≥50%）；检出 ≥1 种云型结构；地平线处梯度带宽 ≤ 全帧中位梯度 2 倍（无雾幕吞没） | 面积(≥0.35)、云覆盖(≥0.50)、梯度带宽比(≤2) | §8.2-1；§4 P1 |
| R2 | **白点闪烁（「雪」）**：植被高频区亮斑（V≥0.9，直径 0.05–0.6% 短边）≥15 个；集中分布于高频区（不与天空混淆） | 亮斑数(≥15)、直径(%短边 0.05–0.6) | §8.2-2；§4 P3 |
| R3 | **绿-蓝-红点状预算**：绿族（H 70–150°）≥30%；天空蓝（H 190–230°）≥10%；红族（H 0–20°）0.3–3% 且点状集中（≥2 处、每处 ≤1%）；饱和 ≥0.85 且 ≥3% 面积区块数 = 0（防互补振动） | 面积%(30/10/0.3–3)、高饱和块(=0) | §8.2-3；§4 P5；C-12 |
| R4 | **无事件 / 边缘可辨**：无风暴灾难叙事；事件外全局光流 ≤1.5%/帧；水面局部光流 ≤2% 短边/秒；主体轮廓梯度带宽 ≤1% 短边 | 全局光流(≤1.5%/帧)、局部(≤2%/秒)、轮廓带宽(≤1% 短边) | §8.2-4；§3.1 vs 透纳 |
| R5 | **锚点 + 单消失点（档位可选）**：≥1 个建筑锚点位于中景—天际线带；单消失点估计成功（RANSAC 直线收敛 ≥5 条）；固定视角非随机全景 | 锚点(≥1)、收敛直线(≥5) | §8.2-5；§4 P4 |
| R6 | **水镜（可选分区）**：下部条带色相 ≈ 天空蓝降饱和镜像（色相差 ≤25°，饱和 = 天空 0.4–0.8 倍）；水平条带结构可检出 | 色相差(≤25°)、饱和比(0.4–0.8) | §8.2-6 |
| R7 | **劳作小实例（可选层）**：人物/马匹 ≤5 实例；姿态为劳作，无背向凝视者、无戏剧手势；人脸关键点 ≤1 组 | 实例(≤5)、人脸(≤1) | §8.2-7；§3.1 vs 弗里德里希 |
| R8 | **哑光软光 / 干笔表面**：无硬阴影（阴影边界梯度带宽 ≥1% 短边）；镜面高光块（V≥0.95 且 >1% 面积）= 0；笔触可见（高频能量集中 2–6px 尺度带，干笔斑驳可检出） | 带宽(≥1% 短边)、高光块(=0)、尺度带(2–6px) | §8.2-8；C-01 |

**必要耦合（拆开会破，`[归纳]`）**：

- **C1 ⟨R1 ∧ R4⟩「可见地平线 × 无事件」**：R1 的「地平线处梯度带宽 ≤ 全帧中位 2 倍」是「记录而非事件」的像素证据；一旦引入透纳式雾幕/风暴（R4 破），地平线被吞，R1 的可见性检查同时失效。§3.1 与透纳的冲突轴 = 天气地位（记录 vs 事件）**与**边缘（清晰 vs 溶解），两轴必须一起守。
- **C2 ⟨R3 ∧ R2⟩「绿底 × 白点 × 红点对位」**：白点（V≥0.9 亮斑）要落在**植被高频区**（R2），而植被由 R3 的绿族 ≥30% 定义；红点 0.3–3% 且每处 ≤1% 是在绿底上作**小面积对位**。若把红点放大成大面积块或把白点移到天空区，三者的对位/分区关系全破（§8.1 自查③）。
- **C3 ⟨R3 高饱和块=0 ∧ R8 高光块=0⟩**：两个「归零」约束共同保证「无 HDR / 无互补振动 / 无镜面 gloss」；任一放开，画面滑向梵高式互补振动或 glossy varnish（§8.1 负向 `no complementary-colour vibration / no glossy varnish reflections`）。
- **C4 ⟨R5 ∧ R6⟩「单消失点 × 水镜分区」**：R5 的单消失点给「可辨固定视角」的几何，R6 的下部条带镜像给「天空—地面」的色相耦合；二者都依赖 R1 的「天空是画面的材料部分」。云研究档（天空即主题）可把 R5/R6 关掉，但 R1 必须升强——§8.1 中文说明「云研究档把 P2 升强、P6 降弱（无人物、无地标也成立——天空即主题）」。
- **C5 ⟨P4 档位开关⟩（AUDIT 反例对应）**：P4 弱档 =「一般化乡村（无地标）」是**合法档位**，不是越界弗里德里希；越界判定须按 §3.1 四判据**联合**（外加象征装置 / 背向凝视者 / 地点不可辨 / 天空为气象记录）而非单看「地点不可辨」。本段把 R5 标为「档位可选」，正是为了避免把内容对象误升为风格前提。

## 3. 正例（跨场景，逐帧可自查）

**正例 1 — 抽象地形/气象面板（无英国乡村、无磨坊）**：上 40% 为可读带状区（R1 天空带）、地平线处梯度带宽 = 中位 1.5 倍；中景 1 个几何锚点 + RANSAC 收敛 6 条线（R5）；绿族 38% / 蓝 14% / 红点 3 处各 0.6%（R3）；植被高频区 22 个 V≥0.9 亮斑、直径 0.2% 短边（R2）；下部条带为上部蓝的降饱和镜像（色相差 18°、饱和比 0.6，R6）；全局光流 0.8%/帧、轮廓带宽 0.7% 短边（R4）；软阴影带宽 1.5% 短边、高光块 0、干笔 2–6px（R8）；劳作实例层关闭（R7 可选）。**八条自查全是区域/HSV/光流/RANSAC/斑点统计，无需认出「干草车/Dedham」** → 纯风格成立。

**正例 2 — 无字 key visual（S-06 边界）**：可读带状天空 + 绿底白点 + 红点对位 + 软光干笔表面。R1–R8（R5/R6/R7 按档关）仍逐条可算。仅声明关系可迁，不声称生成通道已产出、不声称 E4 通过。

## 4. 强反例（题材全对但风格不成立）

**强反例 1 —「干草车」题材、事件化 + 雾幕**：画出磨坊、干草车、村舍、树、河流（题材齐备），但改成透纳式风暴/边缘溶解/雾幕吞地平线。破 R1（地平线可见性）、R4（无事件 / 光流）、C1；§4 越界警报①「风暴/沉船/火灾等事件叙事、边缘溶解 → 越界透纳」、§8.1 负向 `no storm event … fog banks swallowing the horizon` 即此。**题材齐全≠风格成立**。

**强反例 2 — 保留色板、反转空间/撤掉形状**：绿-蓝-红预算与白点全保留，但把构图改成外加十字架/废墟 + 背向凝视者居中 + 深线性透视轴 + 地点不可辨。破 R5（单消失点/固定视角被换）、R7（背向凝视者禁令）、R4 的「无戏剧手势」；§4 越界警报③「→ 越界**弗里德里希**」、§8.1 负向 `no symbolic apparatus … no contemplative back-turned figure`。

**强反例 3（内容泄漏反证）— 把「必须有可辨英国地标/农人」当风格前提**：§8.1 中文说明明写「云研究档…无人物、无地标也成立——天空即主题」；§4 P2 是「观察档案」开关（完成作档关闭）；AUDIT-constable 已把「云研究档被 §4 越界警报误判」登记为机制强反例。若集成时把「Dedham 塔 / 干草车 / 劳作人物」写进 §8.1b 必要条件，云研究档会被误判「不像康斯泰勃尔」。**人物/风景内容对象不是风格前提**——§8.2 全部分母是面积、色相、光流、斑点计数。

## 5. 适用 / 不适用条件

**适用**：① 需要「可读带状天空 + 可见地平线 + 软光」的静帧/景观类；② 需要「绿底白点 + 红点小面积对位」的色相预算自查；③ 单消失点/固定视角的记录性构图；④ 记录的时间性在 motion 里的等价物（§8.3-2 缓慢横移/固定机位 + 云层缓慢漂移，与 C-09 低动势侧一致）。

**不适用**：① **风暴/沉船/火灾等事件叙事 + 边缘溶解**（破 C1，越界透纳）；② **系列化时刻编号 / 色点分解 / 有色阴影**（破 R3/R8，越界莫奈，越界警报②）；③ **外加象征装置 / 背向凝视者 / 深线性透视**（破 R5/R7，越界弗里德里希）；④ **硬单点光 + 戏剧投影**（破 R8，越界卡拉瓦乔）；⑤ **室内光/人造光几何**（破 R1，越界维米尔/霍珀）；⑥ **理想化合成风景 / 意大利式如画废墟**（§8.1 负向）；⑦ S-06 无文字 key visual 下不补题记文字——P2 的「气象题记」是**工作流/档案层**，不是画面文字。

**组合预检（沿用 dossier）**：C-12（绿-蓝-红预算）、C-01（软光侧）、C-09（低动势/记录侧）、§3.1 与透纳（70/30 主导轴，否则互相抵消）/莫奈（只借色彩亮度、保留记录结构）/弗里德里希（四判据选侧）分工轴。
