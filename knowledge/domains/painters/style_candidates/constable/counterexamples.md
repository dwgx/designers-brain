# 风格级强反例 — `constable` [inference]

> 全部为**纸面推演 [inference]**，未渲染像素、未跑生成通道、未做 E4。每条给具体撤去/反转/保留操作，点名被破坏的 §8.1b 关系 ID 与 dossier §8.2 规则行。题材对象（磨坊、干草车、教堂尖顶、农人、树、河流、云）全部保留，证明「题材齐备≠风格成立」。

<a id="db-source-line-5"></a>
## CE-O1 — 撤去纹理：把「白点闪烁 + 干笔斑驳」改成平滑渐变

**操作**：全套乡村题材保留；把树冠/树篱区的白点簇（V≥0.9、直径 0.05–0.6% 短边、≥15 个）与 2–6px 干笔斑驳抹成平滑渐变面。

**被破坏的规则**：
- R2（§8.2-2 L204「亮斑 ≥15 个、集中植被高频区」）→ 归零；
- R8（§8.2-8 L210「干笔斑驳可检出、高频能量集中 2–6px、表面哑光」）→ 平滑面失去尺度带；
- 连带破 C2（绿底 × 白点 × 红点对位）。
- 对应 §8.1 正向 `"Constable's snow": tiny dabs and flecks of white`、负向 `no blur, no motion smear`。

**为何是风格级反例**：只换表面斑点关系；证明「白点闪烁」是纯高频统计量，不是「画了树」的附属。

<a id="db-source-line-17"></a>
## CE-O2 — 反转空间：把「可见地平线 + 单消失点」改成雾幕吞没 + 漩涡事件

**操作**：保留云、绿底、红点、树、磨坊；但用透纳式雾幕吞掉地平线、把全局光流放大到事件级、轮廓溶进大气。

**被破坏的规则**：
- R1（§8.2-1 L203「地平线处梯度带宽 ≤ 全帧中位 2 倍（无雾幕吞没）、天空带 ≥35%、≥1 云型」）→ 可见性 fail；
- R4（§8.2-4 L206「事件外全局光流 ≤1.5%/帧、轮廓带宽 ≤1% 短边、无风暴灾难」）→ 事件级 fail；
- 连带破 C1（可见地平线 × 无事件）。
- 对应 §4 越界警报①「风暴/沉船/火灾等事件叙事、边缘溶解 → 越界透纳」、§8.1 负向 `fog banks swallowing the horizon`。

**为何是风格级反例**：只反转「边缘可读性 + 运动预算」两个关系；证明与透纳的分界在两轴联合（§3.1），不在「画的是不是风景」。

<a id="db-source-line-29"></a>
## CE-O3 — 保留色板撤掉形状：绿-蓝-红预算还在，但撤掉软光与红点对位

**操作**：保留绿族 ≥30% / 蓝 ≥10% / 红 0.3–3%（R3 数值不动）；把红点从小面积分散（≥2 处、每处 ≤1%）改成一整块大面积红，并引入镜面高光块（V≥0.95 且 >1% 面积）与硬阴影。

**被破坏的规则**：
- R3（§8.2-3 L205「红点状集中、每处 ≤1%、高饱和 ≥0.85 且 ≥3% 面积区块 = 0」）→ 大红块直接 fail（破 C2/C3）；
- R8（§8.2-8 L210「镜面高光块 = 0、阴影带宽 ≥1% 短边」）→ 高光块与硬阴影 fail；
- 对应 §8.1 负向 `no glossy varnish reflections, no hard cast shadows`、自查③「绿底上是否有红点对位、阴影是否柔而无声」。

**为何是风格级反例**：色板数值完全保留，风格仍不成立——反驳「认出绿+蓝+红预算就是康斯泰勃尔」。

<a id="db-source-line-40"></a>
## CE-O4（内容泄漏反证）— 把「必须有可辨英国地标/劳作农人」升为必要条件

**操作**：不改像素，只在集成时把 `Dedham 塔 / 萨利斯伯里尖顶 / Flatford 磨坊 / haymakers` 写成 §8.1b 前提。

**后果**：**云研究档**被误判——§8.1 中文说明明写「云研究档把 P2 升强、P6 降弱（**无人物、无地标也成立——天空即主题**）」；AUDIT-constable 已把「云研究档被 §4 越界警报③（地点不可辨 → 越界弗里德里希）误判」登记为**§4 机制强反例**。§4 用法把 P2 定为「观察档案开关」（完成作档关闭）。

**结论**：地标/农人是内容档位，不是风格前提；「地点不可辨」必须按 §3.1 四判据**联合**判定，不得单轴升格。本反例破的是规则写法，不是像素。
