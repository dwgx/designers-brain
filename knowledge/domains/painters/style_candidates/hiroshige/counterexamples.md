# 风格级强反例 — `hiroshige` [inference]

> 本页 3 例全部停在纸面：不渲染像素、不接图像通道、不做 E4 实测。每例写明撤去或反转的具体机制、被破的 R-ID 与 歌川广重 dossier §8.2 原文行；默认题材对象一律保留，用来证伪「题材齐备即风格成立」。

<a id="db-source-line-5"></a>
## CE-HIR1 撤去核心机制：把「斜线群方向方差≤10°、无交叉、无排线塑形」

**操作**：把「斜线群方向方差≤10°、无交叉、无排线塑形」换成北斋式曲线族嵌套≥3级+浪的动势事件，并让旅人被尺度戏法吞没。 **被破坏的规则**：R2(§8.2-2 L206 方向方差≤10°、无交叉、雪帧留纸白)fail；R7(§8.2-7 L211 近中远三层、地平线在上/下1/3带)被动势曲线取消；R8(§8.2-8 L212 帧间光流≤2%/帧、无运动模糊)被事件破；拆 C2。 **为何是风格级反例**：只换一组可迁移关系而不改题材，证明 歌川广重 身份轴是统计量耦合、不是「画的是不是默认题材」；对应 §4 越界警报与 §3.1 分工条款。 [STYLE-hiroshige[inference]]
<a id="db-source-line-8"></a>
## CE-HIR2 反转关系档：保留系列题名、渐印带、蓝系预算；只把裁剪框景改成

**操作**：保留系列题名、渐印带、蓝系预算；只把裁剪框景改成多层建筑剖面，并加入微书图案密度与图内书法诗行同页。 **被破坏的规则**：R3(§8.2-3 L207 连续梯度带、带内相邻差≤2/255)被平涂剖面取代；R4(§8.2-4 L208 前景与画框相交、远景中轴±25%)被建筑切分取消；拆 C3/C4。对应 §3.1 L85–89 vs 贝赫扎德。 **为何是风格级反例**：题材与色/光统计全在、关系仍不成立——反驳「认出默认题材就是 歌川广重」；对应 §4 越界警报与 §3.1 分工条款。 [STYLE-hiroshige[inference]]
<a id="db-source-line-11"></a>
## CE-HIR3 内容泄漏反证：把默认题材升为 §8.1b 必要条件

**操作**：不改任何像素，只在集成时把 §8.1 正向段的「浮世绘风景版画 / 东海道五十三次 / 名所江户百景 / weather as lyric subject」与相关器物/体裁专名写成 §8.1b 无条件前提。 **被破坏的规则**：后果：跨场景正例（抽象/图标族）会被误判「不像歌川广重」，而 §8.2 的 8 条统计量本不依赖任何题材专名。 **为何是风格级反例**：结论：默认题材是 R 表计数/档位的内容基底，不是风格前提；本反例破的是规则写法，不是像素。 [STYLE-hiroshige[inference]]
