# §8.1b 纯风格段（候选草案）— `hopper` 霍珀

## 1. 默认题材泄漏的剥离

dossier §8.1 正向段把「霍珀」强绑定在一组**20 世纪美国都市**内容对象上：storefront rows、diner、gas station、hotel room、movie theater、office、餐车灯窗、从街道或过路列车看的视点，以及「frozen stillness just before or after an event」的叙事情绪。这些是**题材档位**（§4 P4 夜光配比「日/夜双档可用」、P3 孤寂度按用途分档），不是像素关系。本段把它们逐项降级为关系量：

| §8.1 内容词 | 为什么不是风格前提 | 本段处理 |
| --- | --- | --- |
| `diner, gas station, hotel room, movie theater, office, storefront rows` | 建筑用途与年代是题材；可判读的只有「建筑长边 ≥70% 与水平/垂直轴夹角 ≤2°、画面矩形块 ≥6 个」这一**正交几何关系** | 删除场所专名，保留 §8.2-3「边缘角度直方图 / 霍夫直线统计」 |
| `20th-century American urban or coastal setting` | 时代/地域是内容背景；关系量是「亮部 ≥75% 与暗部 ≤35% 像素合计 ≥60%、中间调压缩」 | 保留为**逐帧直方图 + 色相聚类**关系（§8.2-5），不要求认出美国/20 世纪 |
| `at most one or two solitary figures, turned away or absorbed, not interacting` | 人物身份与情绪是叙事；关系量是「人物数 ≤2（默认 0–1）、占画面积 ≤8%、视线不相交、无肢体接触」 | 保留为**人物检测 + 面积/视线向量**关系（§8.2-4），删「孤寂」情绪词 |
| `a window, door or counter acting as a frame-within-the-frame` | 器物是内容；关系量是「≥1 个画中框被画边裁切 ≥1 处、主体距画面中心 ≥1/8 宽」 | 保留为**边界框位置与边缘相交统计**（§8.2-8），器物专名不迁 |
| `ochre, brick red, olive green and bone white / a few saturated accents` | 色名与地点气氛是内容；风格要件是「色相簇 ≤7、夜档暖光池面积 ≤25% 且集中照射面」 | 保留为**色相簇数 + 光池面积比**关系（§8.2-5），色名只作示例 |

**迁移判据**：撤掉餐馆/加油站/旅馆/办公室、美国时代地域、孤寂情绪、窗门器物清单、赭砖橄榄色名后，§8.2 的 8 条自查（明暗交界梯度宽度中位数、投影主轴角度直方图、边缘角度直方图/霍夫直线、人物检测+视线向量、逐帧直方图+色相聚类、高光/光源连通域计数、帧差图、边界框与边缘相交统计）仍可逐帧计算 → 纯风格。按此判据 1/2/3/4/5/6/7/8 **全部可迁**——霍珀八条本就是纯几何/光度统计量，默认题材几乎不进入规则层。

> **hopper 特有的规则内张力（登记，不消歧）**：§4 P1 弱档「漫射柔光、边界模糊」被明写为**越界：进入维米尔档**，且分工注 L98 写死「柔窗光 + 点状高光（pointillés）组合整体属于维米尔模块，禁止在本模块同档出现」。这是本卡唯一的档位硬边界；本段把「柔光」留作不适用条件，不把它当可选弱档。另一处 §8.1 负向 hard shadow 类 Lane B 反约束须按 C-01 同口径显式改写（给出半影宽度值），本 lane 只登记不改写。

## 2. 可迁移视觉关系（参数 · 单位 · 范围 · 必要耦合）— 硬边光影 × 正交几何 × 人烟预算 × 画中框取景四族；全部 `[归纳] 未实测` [STYLE-hopper]

| ID (hopper) | 可迁移关系 | 单位 / 范围 `[归纳] 未实测` （hopper 专属口径：量纲取自 §8.2 L240-247 的「硬边光影」与 §4 L87-98 档位表，跨场景迁移不改此量纲。） | 源行 |
| --- | --- | --- | --- |
| R1 | **硬边光影** | 亮暗边界过渡带 ≤2 px（1024 px 宽画布）；禁止 ≥8 px 羽化渐晕 | §8.2-1 L240；§4 P1 L89 |
| R2 | **投影几何一致** | 所有投影方向同一光源方位(偏差 ≤5°)；投影为简单多边形(边数 ≤6) | §8.2-2 L241；§4 P1 L89 |
| R3 | **正交几何主导** | 建筑长边 ≥70% 与水平/垂直轴夹角 ≤2°；画面矩形块 ≥6 个 | §8.2-3 L242；§4 P2 L90 |
| R4 | **人烟预算** | 人物数 ≤2（默认 0–1）；若有人物：占画面积 ≤8%、无互动(视线不相交、无肢体接触) | §8.2-4 L243；§4 P3 L91 |
| R5 | **两级明度/色域** | 色相簇 ≤7；亮部(≥75%)与暗部(≤35%)像素合计 ≥60%、中间调压缩；夜档暖光池面积 ≤25% 且集中光源/照射面 | §8.2-5 L244；§4 P6 L94 |
| R6 | **光源数受控** | 昼档 1 个太阳方向；夜档 ≤3 个可见光源各带明确照射面；禁止无源漫射光 | §8.2-6 L245；§4 P4 L92 |
| R7 | **全片静止** | 相机固定；帧间差 ≤1%（除光源闪烁 ≤2 Hz 外不允许运动元素） | §8.2-7 L246；§8.1 正向 L213 frozen |
| R8 | **画中框取景** | ≥1 个画中框(窗/门/镜/柜台)且被画边裁切 ≥1 处；主体距画面中心 ≥1/8 宽 | §8.2-8 L247；§4 P5 L93 |

**必要耦合（拆开会破，`[归纳]`）**：

- **C1 ⟨R1 ∧ R2⟩「硬边光 × 投影几何一致」**：这是霍珀身份的双护栏（§4 用法「P1/P2 定是不是霍珀」）。若保留硬边却让投影方向散乱（偏差 >5°）或多边形边数 >6 → 光失去单一方位逻辑；若保留投影几何却把边界柔化成 ≥8px 羽化渐晕 → 越界**维米尔**（P1 弱档明写越界）。二者必须同时成立。
- **C2 ⟨R1 ∧ R5⟩「硬边光 × 两级明度」**：亮暗过渡带 ≤2px 与「亮部+暗部 ≥60%、中间调压缩」是同一刀切边界的正反表述；若改成 sfumato 宽灰渐变（§8.1 负向 sfumato / hazy atmosphere / mist），中间调回升，R5 的两级压缩失效。
- **C3 ⟨R3 ∧ R8⟩「正交几何 × 画中框」**：建筑长边 ≥70% 贴轴、矩形块 ≥6 个，给「画中框 + 边缘裁切 + 主体偏心 ≥1/8 宽」一个几何骨架；若改成曲线/有机形或正面居中全景（§4 P5 弱档），R8 的裁切与偏心关系失去可测坐标。
- **C4 ⟨R4 ∧ R7⟩「人烟预算 × 全片静止」**：人物数 ≤2、占画 ≤8%、无互动，与帧间差 ≤1%/相机固定共同构成「空间本身成为主体」；若加入人群互动或运动元素（§8.1 负向 crowded busy street / motion blur / action），R4 破且 R7 的静止预算被突破。
- **C5 ⟨R6 ∧ R5⟩「光源数受控 × 夜档光池」**：昼档 1 个太阳 / 夜档 ≤3 个可见光源且各有照射面，与「夜档暖光池 ≤25% 且集中」耦合；若改成「单一烛光 + 近黑背景」的戏剧光源（§8.1 越界警报 vs 卡拉瓦乔），R6 的 ≤3 实用光源与 R5 的冷暗域细节（not black）同时失效。

## 3. 正例（跨场景，逐帧可自查）

**正例 1 — 抽象几何展厅 / UI 仪表盘（无餐馆、无加油站、无美国街景）**：一张 1024px 版式：亮暗交界梯度宽度中位数 ≤2px、无 ≥8px 羽化（R1）；所有投影主轴偏差 ≤5°、投影多边形边数 ≤6（R2）；长边 ≥70% 贴水平/垂直轴 ≤2°、矩形块 ≥6 个（R3）；人物 0 个（R4）；色相簇 ≤7、亮部+暗部 ≥60% 像素、夜档暖光池 ≤25%（R5）；夜档 2 个可见光源各带照射面（R6）；帧间差 ≤1%、相机固定（R7）；1 个画中框被画边裁切 ≥1 处、主体距中心 ≥1/8 宽（R8）。**八条自查全是梯度/角度/霍夫/直方图/连通域/帧差/边界框统计量，无需认出 Nighthawks 的餐车** → 纯风格成立。

**正例 2 — 建筑立面图 / 空舱界面（内容全换）**：硬边光 + 正交矩形 + 人烟 ≤2 + 两级明度 + 受控光源 + 静止 + 画中框偏心裁切。R1–R8 仍逐条可算。仅声明视觉关系可迁，不声称任何生成通道已产出、不声称 E4 通过。

## 4. 强反例（题材全对但风格不成立）

**强反例 1 — 题材全对但改柔窗光 + 点状高光**：画出餐馆灯窗、夜街、背对单人、画中框（题材齐备），但把硬边光改成漫射柔窗光 + 维米尔式 pointillés 点状高光 + 高调浅墙 + 生活器物。破 R1（过渡带 ≤2px）、R2（投影几何一致）、连带破 C1/C2；§4 分工注 L98 明写「柔窗光 + 点状高光组合整体属于维米尔模块，禁止同档出现」。**结论：题材齐全≠风格成立**。

**强反例 2 — 保留几何却改 sfumato/薄雾**：题材不变，把亮暗边界改成宽灰渐变带、加雾气/空气透视。破 R1（≥8px 羽化）、R5（中间调回升、两级压缩失效）、连带破 C2；§8.1 负向 sfumato / hazy atmosphere / mist / soft diffused window light。

**强反例 3 — 改单一烛光近黑背景**：题材不变，把夜档 ≤3 个实用光源改成「单一烛光 + 近黑背景 + 戏剧聚光」。破 R6（≤3 个可见光源各带照射面 → 单烛光结构不同）、R5（冷暗域须有细节 not black）；§8.1 越界警报（vs 卡拉瓦乔）。

## 5. 适用 / 不适用条件

**适用**：① 建筑/版式/界面类输出（梯度宽度、霍夫直线、直方图可逐帧查）；② 需要「硬边光 × 正交矩形 × 画中框偏心裁切」的立面图/仪表盘/空场景；③ 需要「人烟 ≤2 + 全片静止」的氛围帧；④ 无柔光、无 sfumato、无运动模糊约束明确的渲染通道。

**不适用**：① 需要**柔窗光 + 点状高光（pointillés）+ 生活器物**的场景（破 R1/R2，越界维米尔，分工注 L98 禁止同档）；② 需要**sfumato/薄雾/空气透视/柔光渐晕**的场景（破 R1/R5）；③ 需要**印象派碎笔触/厚涂**的场景（破 R3，§8.1 负向）；④ 需要**拥挤街道/人物互动/运动模糊/动作**的场景（破 R4/R7）；⑤ 需要**单一烛光 + 近黑背景戏剧光源**的场景（破 R5/R6，越界卡拉瓦乔）；⑥ 需要**彩虹霓虹满场/暖怀旧光晕**的场景（破 R5 两级明度，§8.1 负向）；⑦ 需要**17 世纪荷兰室内/田园牧歌**的场景（§8.1 负向）。

**组合预检（沿用 dossier）**：§3/§4 分工注 L98（与维米尔二选一，组合须显式分区如「前景霍珀街区 / 室内维米尔」且互不覆盖）；§8.1 越界警报 vs 卡拉瓦乔（城市电光 vs 单烛光）；Lane B C-01 同口径显式改写（给出半影宽度值，否则默认反约束「别做成硬阴影」会封堵本模块核心机制）。
