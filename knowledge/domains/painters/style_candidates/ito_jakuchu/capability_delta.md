## 1. 无 §8.1b 时，卡能做什么 / 不能做什么

**能做**：在「動植綵絵/群鶏/升目屏風」**默认题材域**内，用 §8.2 的 8 条（边缘+ΔE、色相簇/饱和统计、覆盖率+空区、格边/跨格渐变、色温+镜面斑、帧间位移、模板计数、墨线宽度）自查 §8.1/§8.2/§4 逐字一致（AUDIT-ito_jakuchu 记录 §8.1b 被排除在逐字比对之外）。

**不能做**：**跨场景路由**。把「无描边浓彩 × 满填充 × 裏彩暖白 × 模板节奏」迁到抽象色块满铺、数据马赛克、UI 图标墙、织物纹样时，§8.1 正向段会强制带回鸡/鹦鹉/群雀/鱼/花虫与「動植綵絵」作品语义，把内容对象当风格前提。

**本卡特有的未消歧张力（AUDIT-ito_jakuchu accepted 登记）**：§4 P3 升目默认 0%（实验档 100%），§8.2-4 的格边 1/40–1/120、跨格渐变 = 0、每格主色 = 1 是**档位开关**而非无条件阈值；§8.2 八条全为 [归纳] 未经真实渲染器实测（§10-8 L299 的 R8/R22/R23 [UNVERIFIED] 清单）。无 §8.1b 时卡没有「升目档启用时才生效」的写法，跨场景容易把格尺寸误当无条件规则。

## 2. §8.1b 草案新增的跨场景路由能力

| 增量 | 无 §8.1b 的卡 | 本 §8.1b 草案 |
| --- | --- | --- |
| 介质/语义无关的关系量 | §8.1 绑定鸡/鹦鹉/群雀/鱼/花虫、胡粉辰砂颜料名、動植綵絵作品名 | 拆成 R1–R8：无描边(线宽/长度/ΔE)、彩度(色相簇/饱和占比/低饱和面积)、填充(覆盖率/空区面积/带色)、升目(格边比/跨格渐变/格色数/对齐误差)、裏彩(色温/镜面斑面积)、冻结(位移 px/帧)、模板(模板数/间距变异)、墨线(细线宽/纯黑区块面积)——全是边缘/色相/覆盖/色温/帧差统计量 |
| 默认题材泄漏剥离表 | 无 | §1 表把物种/姿态/颜料名/作品名/极细描写逐项降级；给「迁移判据」：撤掉专名后 §8.2 自查仍可算 = 纯风格；R4 只保留「格级量化」，题材语义不迁 |
| 档位开关显式化 | 卡内 P3 升目未拆层 | §1 注把 P3=100% 写成**升目档开关**（默认 0%），C4 登记只在启用时与 R7 强耦合；§8.2-4 格边 1/40–1/120 标 [归纳] 未实测 |
| 正例 + 强反例 | 卡只有同域自查四问 | 抽象满铺色块 + UI 图标墙/织物纹样正例；counterexamples.md 4 条 [inference]：撤无描边改黑主線 / 反转裏彩改金箔 / 保留色板改挥翅风动 / 内容泄漏反证 |
| 适用/不适用 + 组合预检 | 散落在边界提醒 | 列 7 类不适用（等宽主線、白纸留白、金箔反光、渐变网格、风动斜构图、浓墨暗部、3D 写实）+ §3.7 北斋/§3.8 克里姆特分工预检 |
