## 1. 默认题材泄漏的剥离

dossier §8.1 正向段把「若冲」强绑定在一组**花鸟走兽**内容对象上：rooster 摆歌舞伎姿态、preening bird、群鸡群雀群鱼、牡丹小禽、向日葵雄鸡、羽毛/鳞片/花瓣/虫足的极细描写，以及「動植綵絵」「鳥獣花木図屏風」等具体作品。这些是**题材档位**（§4 P6 群像密度「单主体/2–5/群体 ≥10」、P5 墨彩比定题材面貌），不是像素关系。本段把它们逐项降级为关系量：

| §8.1 内容词 | 为什么不是风格前提 | 本段处理 |
| --- | --- | --- |
| `birds, fish, flowers, insects / a rooster striking a kabuki-like pose` | 物种与姿态名是叙事内容；可判读的只有「同类单元 ≥5 个时姿态模板 ≤3 种、模板间距变异系数 ≤0.3」这一**重复节奏关系** | 删除物种/姿态专名，保留 §8.2-7「模板 ≤3 种、图案节奏分布、不随机散布」 |
| `every feather, scale, petal and insect leg` | 「极细描写」是内容承诺；关系量是「不存在宽 ≥2px 且连续 >20px 的均匀深色轮廓线、相邻色区边界 ΔE ≥15」 | 保留为**无描边 + 边界色差**关系（§8.2-1），不要求认出羽毛或鳞片 |
| `colours built in layers on both sides of the silk (urazaishiki) / shell-white gofun` | 材料工艺是内容；关系量是「白/浅色区色温偏暖 +200~600K、镜面高光 ≤0.3%、金色感只能来自暖白+明度层次」 | 保留为**色温代理 + 高光面积**关系（§8.2-5），矿物颜料名不迁 |
| `near edge-to-edge composition / almost no empty background` | 「满构图」是题材印象；关系量是「主体覆盖 ≥85%、最大连续背景空区 ≤8%、空区须带色非白纸」 | 保留为**覆盖率 + 空区面积/带色**关系（§8.2-3） |
| `frozen theatrical postures / everything perfectly still` | 剧场姿态是内容；关系量是「主体像素位移 ≤1px/帧、介质水波 ≤2px/帧、禁翅膀/尾羽/花瓣连续摆动」 | 保留为**帧间位移 + 摆动禁止**关系（§8.2-6），与北斋「曲线族动势」互斥 |

**迁移判据**：撤掉鸡/鹦鹉/群雀/鱼/花虫、矿物颜料名、具体作品名、羽毛鳞片描写后，§8.2 的 8 条自查（边缘检测+ΔE、色相簇/饱和度统计、覆盖率+空区检测、格边/跨格渐变/格对齐、色温+镜面斑检测、帧间位移、模板计数+间距变异、墨线宽度/纯黑区块）仍可逐帧计算 → 纯风格。按此判据 1/2/3/5/6/7/8 全可迁；4（升目网格）是 P3=100% 的**档位开关**（默认 0%），只在其档位启用；语义题材全部不迁。

> **ito_jakuchu 特有的规则内张力（登记，不消歧）**：§4 P3「升目/图案量化」默认 **0%**（实验档 100%），而 §8.2-4 把「格边长 = 短边 1/40–1/120、跨格渐变 = 0、每格主色数 = 1」写成可判定规则——升目模式是**档位开关**而非无条件阈值（§8.1 中文说明明写 P3 默认 0%、实验档 100% 才追加升目句）。本段把 R4 写成 P3 档位开关；AUDIT-ito_jakuchu 的 counterexample 已登记 §8.2 阈值为 [归纳] 未实测，本 lane 只登记不修。

## 2. 可迁移视觉关系（参数 · 单位 · 范围 · 必要耦合）— 无描边浓彩 × 满填充 × 裏彩暖白 × 升目网格/模板节奏四族；全部 `[归纳] 未实测` [STYLE-ito_jakuchu]

| ID (ito_jakuchu) | 可迁移关系 | 单位 / 范围 `[归纳] 未实测` （ito_jakuchu 专属口径：量纲取自 §8.2 L235-242 的「无描边」与 §4 L102-132 档位表，跨场景迁移不改此量纲。） | 源行 |
| --- | --- | --- | --- |
| R1 | **无描边** | 不存在宽 ≥2px 且连续 >20px 的均匀深色轮廓线；相邻色区边界 ΔE ≥15（边界可读但不靠线） | §8.2-1 L235；§4 P5 L122 弱档 |
| R2 | **彩度/色数** | 色相簇 8–14 个；饱和像素(S ≥40%)占比 ≥55%；平均饱和度 ≥50%；低饱和区(S <15%)≤15% 面积 | §8.2-2 L236；§4 P1 L102 |
| R3 | **满填充** | 主体覆盖 ≥85% 画面；最大连续背景空区 ≤8% 面积；空区只能作水面/天空且须带色(不得为白纸) | §8.2-3 L237；§4 P2 L107 |
| R4 | **升目模式(档位 P3=100%)** | 格边长 = 短边 1/40–1/120；跨格渐变 = 0(相邻格独立取色)；每格主色数 = 1(允许格角 1 处加深)；格线对齐误差 ≤0.3 格 | §8.2-4 L238；§4 P3 L112 |
| R5 | **裏彩代理** | 白/浅色区色温偏暖 +200~600K；镜面高光(亮度 >95% 且低饱和孤立斑)面积 ≤0.3%；金色感只来自暖白+明度层次、不得出现金属反射带 | §8.2-5 L239；§4 P4 L117 |
| R6 | **姿态冻结** | 主体像素位移 ≤1px/帧；允许极慢介质(水波 ≤2px/帧、无风感)；禁翅膀/尾羽/花瓣连续摆动 | §8.2-6 L240；§8.1 负向 L221 windswept motion |
| R7 | **重复模板** | 同类单元 ≥5 个时姿态模板 ≤3 种；模板分布呈图案节奏(间距变异系数 ≤0.3)、不得随机散布 | §8.2-7 L241；§4 P6 L127 |
| R8 | **墨线预算** | 墨只作两种用途——极细结构线(宽 ≤1.5px)与点/苔；不得用墨做大面积暗部(纯黑 <5% 明度区块 >2% 面积禁止) | §8.2-8 L242；§4 P5 L122 |

**必要耦合（拆开会破，`[归纳]`）**：

- **C1 ⟨R1 ∧ R2⟩「无描边 × 高彩度」**：这是若冲身份的双护栏（§4 用法「P1/P2 决定是不是若冲的浓密」）。若保留高彩满覆盖却加回等宽黑色主線（宽 ≥2px 连续 >20px）→ 越界**北斋**等宽单线骨架（§3.7 分工）或歌麿线系统；若保留无描边却降成淡彩/一色（P1 弱档）→ 退回晚年水墨档，R2 的「饱和 ≥55%、色相簇 8–14」失效。
- **C2 ⟨R2 ∧ R3⟩「高彩度 × 满填充」**：色相簇 8–14 与覆盖 ≥85%、空区 ≤8% 且带色是同一个「浓密」的色与空间两面；若留出大面积白纸空区（§8.1 负向 empty white background / minimalism），R3 破，R2 的低饱和区 ≤15% 也被白纸抬高。
- **C3 ⟨R1 ∧ R5⟩「无描边 × 裏彩暖白」**：边界靠 ΔE ≥15 的色差而非线，恰依赖「白/浅色区偏暖 +200~600K、镜面高光 ≤0.3%」的裏彩层次；若改成金属反光/金箔（§8.1 负向 metallic gold leaf / shiny metal），R5 破并越界**克里姆特**（§3.8 分工），无描边边界也被反射带污染。
- **C4 ⟨R4 ∧ R7⟩「升目网格 × 模板节奏」**：P3=100% 时「每格主色数 = 1、跨格渐变 = 0、格线对齐 ≤0.3 格」与「同类单元 ≥5 时模板 ≤3 种、间距变异 ≤0.3」是同一图案量化的格级/单元级表述；若改成随机散布或跨格渐变（§8.1 负向 gradient mesh），两规则同时失稳。R4 是档位开关，启用时才与 R7 强耦合。
- **C5 ⟨R6 ∧ R8⟩「姿态冻结 × 墨线预算」**：位移 ≤1px/帧、禁连续摆动，配合「墨只作细线/点、无大面积纯黑」，排除北斋式曲线族动势与浓墨暗部；若加入风动/挥翅（§8.1 负向 windswept motion / ukiyo-e wave curves），R6 破，R8 的墨线预算也被大笔触暗部突破。

## 3. 正例（跨场景，逐帧可自查）

**正例 1 — 抽象色块满铺 / 数据马赛克（无鸡、无花、无群雀）**：一张满铺版式：相邻色区边界 ΔE ≥15、无宽 ≥2px 连续 >20px 的深色轮廓（R1）；色相簇 10 个、饱和像素 ≥55%、平均饱和 ≥50%、低饱和区 ≤15%（R2）；主体覆盖 ≥85%、最大空区 ≤8% 且带色（R3）；非升目档（P3=0%，R4 关闭）；白/浅色区偏暖 +400K、镜面斑 ≤0.3%、无金属反射带（R5）；帧间位移 ≤1px（R6）；同类几何单元 ≥5 个时模板 ≤3 种、间距变异 ≤0.3（R7）；墨只作 ≤1.5px 细线与点、无 >2% 面积纯黑（R8）。**八条自查全是边缘/ΔE/色相簇/覆盖率/色温/帧差/模板计数/墨线宽度统计量，无需认出動植綵絵的任何一只鸡** → 纯风格成立。

**正例 2 — UI 密集图标墙 / 织物纹样（内容全换）**：无描边高彩满填充 + 裏彩暖白 + 模板节奏 + 冻结 + 细墨线；升目档可切 P3=100% 出均匀方格。R1–R8 仍逐条可算。仅声明视觉关系可迁，不声称任何生成通道已产出、不声称 E4 通过。

## 4. 强反例（题材全对但风格不成立）

**强反例 1 — 题材全对但加黑轮廓**：画出群鸡、牡丹、群雀、羽毛鳞片极细描写、暖白胡粉（题材齐备），但给每个形体加等宽连续黑主線（宽 ≥2px、>20px）。破 R1（无描边、ΔE 边界失效）、连带破 C1；§8.1 负向 outlines / black contour lines / single uniform keyline 即此，§3.7 明写「等宽单线骨架 → 越界北斋」。**结论：题材齐全≠风格成立**。

**强反例 2 — 保留浓彩却改金箔金属反光**：题材不变，把「暖白+明度层次」的裏彩改成金箔/金属反射带/发光高光。破 R5（镜面高光 ≤0.3%、禁金属反射带）、连带破 C3；§8.1 负向 metallic gold leaf / gold foil / shiny metal / glowing highlights，§3.8 越界克里姆特。

**强反例 3 — 改动态斜构图/挥翅风动**：题材不变，把冻结姿态改成挥翅/尾羽连续摆动 + 大斜角动势线。破 R6（≤1px/帧、禁连续摆动）、破 R8（大笔触暗部），§8.1 负向 windswept motion / dynamic diagonal composition / ukiyo-e wave curves，越界北斋曲线族动势。

## 5. 适用 / 不适用条件

**适用**：① 满铺装饰/纹样/马赛克类输出（ΔE、色相簇、覆盖率、色温可逐帧查）；② 需要「无描边高彩 + 裏彩暖白 + 模板节奏」的织物/图标墙/屏风格；③ 升目档（P3=100%）的均匀网格量化；④ 冻结、无金属反射、无等宽主線约束明确的渲染通道。

**不适用**：① 需要**等宽黑色轮廓线/主線系统**的场景（破 R1，越界北斋/歌麿）；② 需要**大面积白纸留白/极简/淡彩水墨**的场景（破 R2/R3，破 P1/P2 浓密档）；③ 需要**金箔/金属反光/发光高光**的场景（破 R5，越界克里姆特）；④ 需要**跨格渐变/梯度网格/羽化**的场景（破 R4，§8.1 负向 gradient mesh / soft blur / airbrush）；⑤ 需要**挥翅/风动/曲线族动势/大斜角**的场景（破 R6/R8，越界北斋）；⑥ 需要**大面积浓墨暗部/纯黑区块 >2%**的场景（破 R8）；⑦ 需要**摄影写实/3D 渲染**的场景（§8.1 负向）。

**组合预检（沿用 dossier）**：§3.7 与北斋（等宽单线骨架/曲线族动势 vs 无描边+冻结，70/30 时若冲只借色彩密度与裏彩质感、负向约束按 N1 重算）、§3.8 与克里姆特（金属反光/金箔 vs 暖白模拟）分工轴；§10 [UNVERIFIED] 清单 R8/R22/R23。
