**迁移判据**：换掉全部自然物/象征物/人物后，§8.2 的 8 条自查（人脸关键点+实例分割+中轴度量、光流场+模糊核、边缘方向直方图+水平带分割、Hough+消失点估计、亮度质心+剪影分割、HSV 掩膜、对象检测+位置度量、梯度带宽+多尺度能量比）仍可逐帧算 → 纯风格。

## 2. 可迁移视觉关系（参数 · 单位 · 范围 · 必要耦合）— 层带/无透视轴/逆光/冻结/雾面五族；全部 `[归纳] 未实测` [STYLE-friedrich]

| ID | 可迁移关系 | 单位 / 范围 `[归纳]` | 源行 |
|---|---|---|---|
| R1 | **背向/中轴/小尺度（条件关系）**：若存在焦点人形则背向（人脸关键点 ≤1 组、五官不可辨）、位于中轴 ±10% 画宽；多人时 ≤3 人且同朝向；**P1 弱档允许 0 人** | 人脸(≤1)、中轴(±0.10 画宽)、人数(0/≤3) | §8.2-1；§4 P1/P2；自审 B2 |
| R2 | **冻结**：视频帧间全局光流 Δ ≤0.5%/帧（事件外）；无运动模糊核；仅雾带/水面极慢渐变（局部光流 ≤2% 短边/秒） | 全局光流(≤0.5%/帧)、局部(≤2%/秒)、模糊核(=0) | §8.2-2；§4 P3；C-09 |

| R6 | **冷调低饱和**：全帧中位饱和 ≤0.35；蓝灰（H 180–240°）/褐（20–45°）/赭金（35–55°）三族合计 ≥80%；饱和 ≥0.85 且 ≥3% 面积区块 = 0 | 中位饱和(≤0.35)、三族(≥0.80)、高饱和块(=0) | §8.2-6；C-12 |

| R8 | **软光 / 雾面 / 无纯黑**：阴影边界梯度带宽 ≥2% 短边；暗部 V ≥0.05；镜面高光块（V≥0.95 且 >1%）= 0；雾/雪区高频能量集中 2–8px 尺度带、整体低频占优 | 带宽(≥2% 短边)、暗部 V(≥0.05)、高光块(=0)、尺度带(2–8px) | §8.2-8；C-01 |

**必要耦合（拆开会破，`[归纳]`）**：

- **C1 ⟨R3 ∧ R4 ∧ R5⟩「凝视结构三件套」**：水平层带（R3）+ 无透视轴向中轴收束（R4）+ 逆光剪影光源在天空带（R5）合起来才是 dossier 自审 B2 说的「凝视结构」——**它不依赖人物存在**。若引入深线性透视轴（R4 破）或画内单点光（R5 破），即便保留背影人也失去凝视结构；反之撤掉人物而三条全守，仍是合法 friedrich 档（《冰海》《瓦茨曼》）。
- **C2 ⟨R2 ∧ R8⟩「冻结 × 雾面软光」**：R2 的 ≤0.5%/帧 只允许雾带/水面极慢渐变，R8 的「雾/雪区 2–8px 尺度带 + 低频占优」正是这种渐变的表面证据；若改成全画面能量场/天气事件（越界透纳，越界警报②、§3.1 vs 透纳），R2 与 R8 同时失效。C-09 运动预算站「冻结」侧。
- **C3 ⟨R5 ∧ R6⟩「逆光 × 冷调低饱和」**：R5 的光源质心在上 1/3 天空带、剪影比全帧暗 0.15，依赖 R6 的「高饱和块 = 0 / 中位饱和 ≤0.35」来保持「冷金天光下的暗剪影」；若加亮饱和色或互补振动（越界梵高/蒙克，越界警报④），逆光剪影读法被破坏。
- **C4 ⟨R1 ∧ R7⟩「可选人物 × 可选象征」**：R1（人物）与 R7（象征）都是**档位可选**（P1 弱档 0 人、P6 弱档 0–1 象征），dossier §4 用法明写「P6 是象征层参数（**可关**）」；两者同时关闭时，identity 由 C1 的凝视结构 + R2/R6/R8 承担。把任一升为「必须有」都会误判无人物纯风景档。
- **C5 ⟨R8 无纯黑 × 卡拉瓦乔⟩**：R8 的「暗部 V ≥0.05、无高光块、带宽 ≥2% 短边」与「画外单光 + 近黑背景 + 高光只落脸手」硬互斥（C-01，§3.1 vs 卡拉瓦乔）；§8.1 负向 `no hard cast shadows, single spot light, chiaroscuro` 即此。

## 3. 正例（跨场景，逐帧可自查）

**正例 1 — 抽象层带构成 / 无人物纯风景（无雾海、无十字架）**：4 条水平带（倾角 ≤2°）、上带占 48%、带内边缘密度 = 全帧 0.7×（R3）；无单消失点、左右向心斜线对 1 组（R4）；前景暗块明度 = 全帧中位 −0.20、光源质心在上 1/3、高亮成带状连通域 2 处（R5）；中位饱和 0.28、蓝灰/褐/赭金三族 85%、高饱和块 0（R6）；全局光流 0.2%/帧、无模糊核（R2）；阴影带宽 2.5% 短边、暗部 V=0.08、高光块 0、雾区 2–8px（R8）；**0 个人物实例**（R1 取 P1 弱档）、**0 个象征物**（R7 取 P6 弱档）。**八条自查全是带状分割/Hough/HSV/光流/质心统计，无需认出「背影人/十字架」** → 纯风格成立，且与 dossier 自审 B2「5/12 无人物」一致。

**正例 2 — 无字 key visual（S-06 边界）**：冷调水平层带 + 逆光剪影 + 向中轴收束 + 冻结 + 雾面软光，零文字零象征标签。R1–R8（R1/R7 按档关）仍逐条可算。仅声明关系可迁，不声称生成通道已产出、不声称 E4 通过。

## 4. 强反例（题材全对但风格不成立）

**强反例 1 —「雾海漫游者」题材、事件化 + 硬光**：画出居中背影人、雾、山、层带（题材齐备），但改成透纳式全画能量场/天气事件（破 R2/C2）、加画外单光 + 近黑背景 + 硬投影（破 R5/R8/C5）。§4 越界警报①②「→ 越界**卡拉瓦乔** / **透纳**」、§8.1 负向 `no dramatic action, storm or weather event / no hard cast shadows, single spot light, chiaroscuro` 即此。**题材齐全≠风格成立**。

**强反例 2 — 保留色板、反转空间**：冷调低饱和、无人物、逆光全保留，但把「无透视轴 + 水平层带 + 向中轴收束」改成深线性透视 + 单一消失点 + 对角线纵深，并给人物加可读面孔/无脸扭曲。破 R3/R4（层带/无透视轴）、R1（人脸 ≤1 组）；§4 越界警报④「无脸扭曲 + 非现实色区 → 越界**蒙克**」、§8.1 负向 `no readable faces, no deep linear perspective`。

**强反例 3（内容泄漏反证）— 把「必须有背影人/十字架/哥特废墟」当风格前提**：dossier 自审 B2 已把「Rückenfigur 是核心指纹」判为 **WEAKENED**（5/12 无人物，核心是凝视结构）；§4 P1 弱档 = 「无人物纯风景（《冰海》《瓦茨曼》档）」，P6 用法「可关」；§8.1 中文说明「《海边僧侣》档…**无人物也成立**」。若集成时把「single figure seen from behind / a cross on a rock」写进 §8.1b 必要条件，纯风景档与正例 1 会被误判「不像弗里德里希」。**人物/风景内容对象不是风格前提**——§8.2 全部分母是带数、倾角、面积比、色相、光流、质心。

## 5. 适用 / 不适用条件

**适用**：① 水平层带、逆光剪影、向中轴收束的静帧/景观类；② 冷调低饱和 + 无纯黑 + 软光雾面的渲染通道；③ 冻结/极慢渐变的 motion（C-09 冻结侧，§8.3-2 极慢推/微移 = 凝视的机械等价物）；④ **无人物、无象征物**的纯关系构成（本段 explicit 允许）。

**不适用**：① **单点硬光 + 戏剧投影**（破 C5，越界卡拉瓦乔）；② **全画能量场/漩涡/天气事件**（破 C2，越界透纳）；③ **人造光/都市几何/夜街**（破 R5/R6，越界霍珀）；④ **无脸扭曲 + 非现实色区**（破 R1/R6，越界蒙克）；⑤ **地点可辨 + 象征归零 + 天空为气象记录**（破 R4/R7，越界康斯泰勃尔，越界警报⑤）；⑥ **可读面孔 / 深线性透视 / 人群叙事**（§8.1 负向）；⑦ S-06 无文字 key visual 下不补任何题记/象征标签文字。

**组合预检（沿用 dossier）**：C-01（无硬阴影的漫射天光，与卡拉瓦乔/米开朗基罗硬阴影侧显式互斥）、C-09（冻结侧）、C-12（冷调低饱和、天空带主导）；§3.1 与透纳（运动预算 + 大气手段，70/30 主导轴）/康斯泰勃尔/蒙克/普桑分工轴。
