# 风格级强反例 — `friedrich` [inference]

> 全部为**纸面推演 [inference]**，未渲染像素、未跑生成通道、未做 E4。每条给具体撤去/反转/保留操作，点名被破坏的 §8.1b 关系 ID 与 dossier §8.2 规则行。题材对象（背影人、雾海、冰海、十字架、哥特废墟、枯橡树、层带风景）全部保留，证明「题材齐备≠风格成立」。

## CE-F1 — 撤去纹理：把「雾面 2–8px 点彩 + 软光」改成硬边平涂 / glossy 高光

**操作**：全套题材保留；把雾/雪区的高频能量 2–8px 尺度带、低频占优、阴影带宽 ≥2% 短边、暗部 V ≥0.05 改成硬边平涂 + 镜面高光块（V≥0.95 且 >1%）+ 纯黑大暗部。

**被破坏的规则**：
- R8（§8.2-8 L196「带宽 ≥2% 短边、暗部 V≥0.05、高光块 = 0、雾区 2–8px 尺度带」）→ 逐项 fail；
- R5（§8.2-5 L193「剪影明度 < 全帧 −0.15、光源质心上 1/3、高亮成带 ≥2」）→ 高光块集中破坏「无画内单点光」；
- 连带破 C2（冻结 × 雾面软光）、C5（无纯黑 × 卡拉瓦乔互斥）。
- 对应 §8.1 负向 `no hard cast shadows, single spot light, chiaroscuro, glossy varnish reflections`、C-01。

**为何是风格级反例**：只换表面/光质关系；证明「软光与雾面」是纯梯度/尺度统计量，不是「画了雾」的附属。

<a id="db-source-line-17"></a>
## CE-F2 — 反转空间：把「水平层带 + 无透视轴」改成深线性透视 + 事件动势

**操作**：保留背影人、冷调、逆光、象征物；把 §8.2-3 的 ≥3 条水平带（倾角 ≤3°）、§8.2-4 的单消失点 = 0 改成单一消失点深透视 + 对角纵深，并让云/水出现事件级动势（透纳式）。

**被破坏的规则**：
- R3（§8.2-3 L191「≥3 水平带、天空 ≥40%、带内密度 ≤0.8×」）→ 带结构被对角线取代；
- R4（§8.2-4 L192「单消失点引导线 = 0、向心斜线对 ≥1」）→ 消失点 = 1；
- R2（§8.2-2 L190「全局光流 ≤0.5%/帧、无模糊核」）→ 事件级 fail；
- 连带破 C1（凝视结构三件套）、C2。
- 对应 §4 越界警报②「全画能量场/漩涡/天气事件 → 越界透纳」、§8.1 负向 `no deep linear perspective, no dramatic action, storm or weather event`。

**为何是风格级反例**：只反转空间/运动关系；证明 dossier 自审 B2 说的「凝视结构」由 R3/R4/R5 三条几何关系承担，**不依赖人物存在**。

## CE-F3 — 保留色板撤掉形状：冷调低饱和三族还在，但撤掉逆光剪影与向中轴收束

**操作**：保留蓝灰 H180–240° / 褐 20–45° / 赭金 35–55° 合计 ≥80%、中位饱和 ≤0.35、高饱和块 = 0（R6 不动）；撤掉前景剪影明度差 < −0.15、光源质心移到画内中部、山棱改平行不向中轴收束。

**被破坏的规则**：
- R5（§8.2-5 L193「剪影比全帧暗 0.15、光源质心上 1/3、高亮 ≥2 或成带」）→ 逆光关系 fail（破 C3）；
- R4（§8.2-4「左右向心斜线对 ≥1」）→ 平行线 fail；
- 连带破 C1/C3。
- 对应 §8.1 正向 `no conventional perspective axis — mountains and slopes fall toward the central vertical`、自查②「≥3 条水平带、天空占比大、无纵深透视轴」。

**为何是风格级反例**：色板（最像「弗里德里希」的冷灰线索）完全保留，风格仍不成立——反驳「认出冷调低饱和就是本风格」。

## CE-F4（内容泄漏反证）— 把「必须有背影人/十字架」升为必要条件

**操作**：不改像素，只在集成时把 `a single figure seen from behind / a cross on a rock, a Gothic ruin` 写成 §8.1b 前提。

**后果**：dossier 自审 B2 已把「Rückenfigur 是核心指纹」判为 **WEAKENED**（清点图库 12 件、**5/12 无人物**：《冰海》《瓦茨曼山》《山十字》《孤独的树》等；结论「核心是**凝视结构**，不要求必须有人物」）；§4 P1 弱档 = 「无人物纯风景」，P6 用法「**可关**」；§8.1 中文说明「《海边僧侣》档…**无人物也成立**——纯风景 + 层带 + 逆光即可」。AUDIT-friedrich 的 counterexample 也把「Rückenfigur-only identity 张力」标为 `[inference]`。若升为必要条件，纯风景档与本草案正例 1（零人物零象征）会被误判「不像弗里德里希」。

**结论**：背影人/十字架是可选内容档位，不是风格前提；§8.2 全部分母是带数、倾角、面积比、色相、光流、质心。本反例破的是规则写法，不是像素——这是本批 8 张里**最明确由档案自审亲自削弱过**的默认题材泄漏案例。

> 与 AUDIT-friedrich 的关系：其 accepted counterexample.md 的 2 条是 **§4/§8.2 机制层** [inference]（单轴运动预算不足；Rückenfigur-only identity 张力）；本文件 4 条是**纯风格关系层**反例，其中 CE-F4 把该 identity 张力明确落到题材泄漏，两者不同层、不互相替代。
