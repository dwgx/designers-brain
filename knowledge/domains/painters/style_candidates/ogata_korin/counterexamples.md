# 风格级强反例 — `ogata_korin` [inference]

> 3 例停在规格层面 [inference]：未出帧、未接渲染器、未做 E4。每例标出被改的材质/空间关系、R-ID 与光琳 §8.2 十条中的对应行；燕子花与屏风题材词不撤。

<a id="db-source-line-5"></a>
## CE-OK1 — 撤去材质：把金/水材质纹样换平涂纯色大块

**操作**：题材全保留(金地/燕子花群/双幅/水流)，只把「箔目 σ + たらし込み斑 + 纹样区内部动态≥8%」换成 machine-perfect 平涂纯色、内部动态≤5%、无斑纹。**被破坏的规则**：R1(§8.2-1 L242 单一 RGB 平涂 ΔV≤1.5% 判 fail)直接 fail；R5(§8.2-5 L246 斑纹区 5–25%)→斑缺失；R6(§8.2-6 L247 ≤5% → 马蒂斯域退档)；连带破 C1/C3。**为何是风格级反例**：只换「承载面是材质还是平涂」这一关系，证明 ogata_korin 身份轴是金/水材质×型紙反復(C1/C3)，不是「画的是不是燕子花」。对应 §3.1 L88 三选口径。

<a id="db-source-line-9"></a>
## CE-OK2 — 反转空间：保留金地但引入西方透视与镜面高光

**操作**：保留金地占比、色相簇、母题反復、双幅对照、斑纹；只把「无消失点/无投影/软 uneven sheen」换成 Western perspective 消失点、cast shadows、glittering specular highlights / plastic gold。**被破坏的规则**：R7(§8.2-7 L248 收敛检测 fail + 方向性>25% 投影 fail)直接 fail；R10(§8.2-10 L251 高光斑>0.5%→fail、深水区须邻接金/银)；R1(§8.2-1 L242 箔目 σ2–8%)→镜面高光取代柔和变异；拆 C4。**为何是风格级反例**：金地与节奏全在、题材全在，风格仍不成立——反驳「认出金屏风就是光琳」；证明「金属≠镜面」是亮度分布关系。对应 §8.1 负向 L225–228。

<a id="db-source-line-13"></a>
## CE-OK3 — 内容泄漏反证：把燕子花図/伊勢物語/琳派升为必要条件

**操作**：不改任何像素，只在集成时把 §8.1 的 `byobu / Rinpa school / irises, plum trees / Ise monogatari` 与作品专名写成 §8.1b 无条件前提。**后果**：抽象金地节奏海报与双屏 UI 对照会被误判「不像光琳」，而 §8.2 的 10 条统计量本不依赖任何作品名或文学底本。**结论**：作品/底本/画派是 R3/R8 的计数与对照关系、P6 的画面装置档位，不是风格前提；本反例破的是规则写法，不是像素。
