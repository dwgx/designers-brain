## 1. 默认题材泄漏的剥离

dossier §8.1 正向段把「尾形光琳」强绑定在一组**内容对象**上，本段逐项降级为关系量：

| §8.1 内容词 | 为什么不是风格前提 | 本段处理 |

| `byobu / Rinpa school / irises, plum trees, waves, cranes, autumn grasses` | 屏风体制、画派名与母题清单是题材/器物；可判读的是「同类母题实例≥8 时姿态模板≤3、间距变异系数≤0.35」 | 删除专名，保留 §8.2-3 的**实例计数/模板数/间距变异**关系(R3)；P6 屏风降为**画面装置档位** |
| `the Irises / Red and White Plum / Wind and Thunder Gods / Ise monogatari` | 作品名与文学底本(伊勢物語九段)是叙事内容，不是像素关系 | 删除；「双幅对照」改写为 R8 的**左右幅色相/密度差≥20% + 节奏相关系数≥0.4、镜像翻转相关>0.9 判 fail**统计量 |
| `gold leaf covering the whole background, faint foil seams / gold-leaf squares` | 金箔/金泥/箔足是材质考据(2011 X 线分析)；关系量是「金色带 H38–55°/S25–70%/V55–95% 占比≥65% + 箔目 σ2–8% 明度」 | 改写为 R1 的**HSV 掩膜 + 亮度变异**，不要求认出「燕子花図」或金箔考古结论 |

| `a decorative Japanese folding-screen painting` | 体裁与国别标签不是像素关系；风格前提取「无消失点 + 无投影 + 静止 + 金属/颜料区分」几何关系 | 删除；P6 画面装置写成档位(掛幅/二曲一双/六曲一双)，不作题材前提 |

**迁移判据**：迁移判据：换掉全部作品名、伊勢物語底本与琳派谱系后，§8.2 的 10 条自查（HSV 金色带+σ、色相簇、实例计数+间距 CV、轮廓线覆盖、斑纹区低频缺失、色块内部动态、Hough 收敛+投影检测、左右幅相关、帧差/位移、高光斑+邻接）仍可逐帧计算 → 纯风格。按此判据 10 条全可迁；P6 屏风体制只保留**画幅/双幅档位层**，文学语义不迁。

> **ogata_korin 特有的规则内张力（登记，不消歧）**：§8.2-6 L247「任一纹样色块内部明度动态≥8%；若全帧最大色块内部动态≤5% → 属马蒂斯域(退档)」× §8.2-1 L242「单一 RGB 平涂(ΔV≤1.5%)判 fail」为同一「金/水材质 vs 平涂纯色」的两处护栏；§3.1 L88 又把「内部明度动态≤5%→马蒂斯 / ≥8%→光琳 / 金属+人物对撞→克里姆特」写成三选。本段把 ≥8% 写成**本卡身份下限**、≤5% 写成**越界退档线**、1.5% 写成金区平涂 fail，三值并存不合并；AUDIT 登记「金地论争若日后裁定为金泥说，箔足网格线检测需改写」(§10 L316)，本 lane 只登记不预判。

## 2. 可迁移视觉关系（参数 · 单位 · 范围 · 必要耦合）— 尾形光琳 关系族；全部 `[归纳] 未实测` [STYLE-ogata_korin]

**必要耦合（拆开会破，`[归纳]`）**：

- **C1 ⟨R1∧R10⟩「総金地箔目 × 非金属高光」**：金地要有箔目 σ2–8% 的柔和亮度变异(R1)，但不得出现镜面高光斑>0.5%(R10)——「软 uneven sheen 不是 flat yellow，也不是 plastic gold」；二者拆开则要么平涂黄、要么塑料金 → §8.1 正向 L207 / 负向 L228。
- **C2 ⟨R3∧R8⟩「型紙反復 × 双幅非镜像对照」**：≥8 实例/模板≤3/间距 CV≤0.35(R3)给双幅对照(R8 节奏相关≥0.4)一个可计算的节奏基底；若改成 machine-perfect symmetry(镜像相关>0.9)则 R8 fail，若改成随机散布则 R3 的 CV 失守 → §8.1 负向 `machine-perfect symmetry, mirror-symmetric pair`。
- **C3 ⟨R2∧R6⟩「色相簇≤6 × 内部动态≥8%」**：大和絵窄色域(R2 ≤6 簇)与纹样区内部材质动态(R6 ≥8%)共同把「平涂纯色」挡在马蒂斯域外；若出现内部动态≤5% 的平涂大块，R6 退档、R2 的群青/緑青占比也失去材质承载 → §3.1 L88 三选口径。
- **C4 ⟨R5∧R7⟩「たらし込み斑 × 无投影」**：湿接湿斑纹(R5 低频边界模糊)是「水性材质」而非「光影」；R7 禁方向性投影保证斑不被误读成阴影；若加 chiaroscuro/3D shading，两者同破 → §8.1 负向 L225–227。
- **C5 ⟨R9∧全体⟩「静止封在纹样里」**：全画面静止(R9)是 §1-11 L47「动只封在纹样里」的操作化：波/风为纹样而非事件；若引入母题位移>0 或风暴动势，则 R3 的间距节奏与 R8 的对照同时失效。

## 3. 正例（跨场景，逐帧可自查）

**正例 1 — 抽象金地节奏海报（无燕子花、无屏风专名）**：金地占 72%、箔目 σ5%、无 ΔV≤1.5% 平涂(R1)；色相簇 5、蓝 18%/绿 12%(R2)；12 个同类模块用 3 姿态模板、间距 CV0.28(R3)；深轮廓线覆盖 22%、花弁区 7%(R4)；斑纹区 14%、斑内动态 12%(R5)；纹样色块内部动态 9%(R6)；无收敛线、无方向性投影(R7)；双幅色相密度差 24%、节奏相关 0.55、无镜像(R8)；水面微动 1px/帧、母题位移 0(R9)；无镜面高光斑、深水区邻接金(R10)。十条全是 HSV/实例计数/相关/帧差统计量，无需认出伊勢物語或燕子花。

**正例 2 — 包装纹样 / 双屏 UI 对照（内容全换）**：総金地箔目 + 型紙反復 + 窄色域 + 内部材质动态 + たらし込み斑 + 无透视 + 非镜像双幅对照 + 静止。R1–R10 仍逐条可算；仅声明视觉关系可迁，不声称任何生成通道已产出、不声称 E4 通过。

## 4. 强反例（题材全对但风格不成立）

**强反例 1 — 题材全对但换成平涂纯色大块**：画出金地、燕子花群、双幅(题材齐备)，但把纹样区内部明度动态压到≤5%、去掉箔目 σ 与たらし込み斑、换成 machine-perfect 平涂 → 破 R1(平涂 ΔV≤1.5%)、R5(斑缺失)、R6(≤5% 退档马蒂斯域)、拆 C1/C3；§3.1 L88 三选口径即此。**题材齐全≠风格成立**。

**强反例 2 — 保留金地但改西方透视+镜面高光**：题材不变，引入 Western perspective/消失点、cast shadows、glittering specular highlights、plastic gold → 破 R7(收敛/投影)、R10(高光斑>0.5%)、R1(箔目失)、拆 C4；§8.1 负向 L225–228。

**强反例 3 — 内容泄漏反证**：把「必须是燕子花図/紅白梅図/風神雷神図/伊勢物語九段/琳派」写进 §8.1b 必要条件 → 抽象金地节奏海报与双屏 UI 对照会被误判「不像光琳」；作品名与文学底本是 R3/R8 的计数/对照关系与题材档位，不是风格前提。

## 5. 适用 / 不适用条件

**适用**：① 装饰/纹样/包装类输出(HSV 金地+实例 CV+相关系数可逐帧查)；② 需「型紙反復 + 双幅非镜像对照」的版式；③ 需金/水材质(非平涂纯色)的平涂系组合(与马蒂斯按 §3.1-d 分区)；④ 需静止纹样的渲染通道。

**不适用**：① 需平涂纯色/内部动态≤5%(破 R6，越界马蒂斯)；② 需金属+写实面孔人体对撞(破 C3，越界克里姆特)；③ 需西方透视/投影/sfumato(破 R7，§8.1 负向)；④ 需镜面高光/塑料金(破 R1/R10)；⑤ 需 machine-perfect 镜像对称(破 R8)；⑥ 需 Art Nouveau whiplash / Vienna Secession 装饰(破 R3 节奏，§8.1 负向)。

**组合预检（沿用 dossier）**：C-15/N6(金层单列与平涂点金声明)、C-16(没有高光的平涂——本模块为金属+水性材质侧、须显式声明)、N1(与马蒂斯组合反约束重算)、N3/N4(轴所有权/分区表)；§3.1 L88 三选(金属+人物→克里姆特 / 金水材质图案→光琳 / 平涂纯色→马蒂斯)为分工正本。
