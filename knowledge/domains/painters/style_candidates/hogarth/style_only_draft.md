## 1. 默认题材泄漏的剥离

dossier §8.1 正向段把「荷加斯」强绑定在一组**英国洛可可道德叙事**内容对象上：浪子与荡妇、纨绔/守财奴/牧师/鸨母、可读信件/账本/镜子/时钟/画中画、琴酒巷与残忍四阶段的恶果、以及成对印品的题刻诗句。这些是**题材档位**（§4 P1 系列化强度是工作流参数、P4 讽刺/道德强度「温和→严酷」是档位），不是像素关系。本段把它们逐项降级为关系量：

| §8.1 内容词 | 为什么不是风格前提 | 本段处理 |
| --- | --- | --- |
| `a fop, a miser, a parson, a bawd / the same protagonist across frames` | 具名社会类型与主角身份是叙事内容；可判读的只有「面孔可归类社会类型 ≥3 种、关键点比例偏差 ≤15%」这一**类型化计数关系** | 删除人物专名，保留 §8.2-4「类型化 ≥3 种、夸张度低 ≤15%（无漫画式扭曲/兽化）」 |
| `a readable letter, a ledger, a mirror, a clock, paintings-within-the-painting` | 器物清单是内容；关系量是「每帧可辨认叙事线索 ≥5 条、其中可读文字 ≥1 处」 | 保留为**线索计数 + OCR 计数**关系（§8.2-1），器物专名不迁 |
| `a moral counterpoint: folly answered by its consequence / in terrorem` | 道德判词是语义；可算的是「对位两张共享构图骨架相似度 ≥70%、语义相反标志物 ≥3 对」 | 保留为**结构相似度 + 标志物清单**关系（§8.2-5），判词语义降为可选层 |
| `one frozen moment from a larger story / numbered progress / caption or verse` | 「系列进度/题刻」是工作流与语义；关系量是「系列帧数 ≥6、主角可追踪元素每帧出现率 100%、跨帧 ≥2 次状态变化」+「题刻 ≤2 行」 | 保留为**逐帧登记表 + 文本行检测**关系（§8.2-2/7），P1/P6 档位开关决定是否启用 |
| `English rococo palette: brick reds, blue coats, buff and white, black accents` | 色名是内容；风格要件是「全帧画内单一硬光源 =0、暗部(L<0.2)≤35%、近黑(L<0.08)≤10%」 | 保留为**光源检测 + 直方图**关系（§8.2-3），色名只作示例 |

**迁移判据**：撤掉浪子/荡妇/纨绔/牧师、信件账本器物清单、道德判词、系列题刻语义后，§8.2 的 8 条自查（对象检测+OCR、逐帧登记表+元素比对、光源检测+直方图、人脸关键点+比例比对、结构相似度+标志物清单、模糊核+动作计数、文本行检测+关键词比对、方向场+覆盖率统计）仍可逐帧计算 → 纯风格。按此判据 1/3/4/5/6/8 全可迁；2（系列进度）与 7（题刻语义）只保留其**计数/出现率/行数/骨架相似度**关系，道德/叙事语义不迁。

> **hogarth 特有的规则内张力（登记，不消歧）**：§4 P5 光线戏剧度默认 30%（平光/舞台聚光「仍是看清逻辑」）与 §8.2-3「全帧画内单一硬光源 = 0」是同一「可读性」关系的正反表述；但 §8.2-8 版画帧要求「排线族 ≥2 方向、交叉排线允许、线覆盖率 ≥15%」，而戈雅 §8.2-7 明写「交叉排线交叉点密度 ≈0」——两卡版画工艺同轴互斥（AUDIT-hogarth 已登记为与戈雅的系列连续性/版画工艺冲突）。本段把 R8 写成**版画档开关**，不无条件叠加。

## 2. 可迁移视觉关系（参数 · 单位 · 范围 · 必要耦合）— 剧场化台口 × 线索编目 × 类型化面孔 × 均匀可读光四族；全部 `[归纳] 未实测` [STYLE-hogarth]

**必要耦合（拆开会破，`[归纳]`）**：

- **C1 ⟨R1 ∧ R4⟩「线索编目 × 类型化面孔」**：这是荷加斯身份的双护栏（§4 用法「P2/P3 两条同时 ≥中档才成立」）。若线索 ≥5 条却把面孔改成漫画式扭曲/兽化 → 越界戈雅怪诞档或卡通（§8.1 负向 caricature distortion）；若面孔类型化却撤掉可读文字/画中画 → 退回一般风俗画。二者必须同时成立。
- **C2 ⟨R3 ∧ R6⟩「均匀可读光 × 定格」**：暗部 ≤35%、近黑 ≤10% 是为了「看清」线索；定格（运动模糊 = 0、1 个动作极值）保证线索可逐件点读。若改成单点聚光 + 深黑背景（§8.1 负向 chiaroscuro drama, deep black backgrounds），R3 破，R1 的 OCR 计数也失去可读照度。
- **C3 ⟨R2 ∧ R7⟩「系列进度 × 题刻」**：P1 系列化与 P6 角色复用是**工作流参数**（不进画面重叠计算），其画面落点是「主角可追踪元素 100% 出现率 + ≥2 次状态变化」与「题刻 ≤2 行」。与洛克威尔组合时「叙事单位轴单主」（洛承担单帧自足、荷承担系列骨架）——帧间进度依赖整体属于本模块，不得与「帧内自足」同档并存（§4 分工注 L115）。
- **C4 ⟨R5 ∧ R4⟩「对位骨架 × 类型化」**：对位两张骨架相似度 ≥70%、语义相反标志物 ≥3 对，要求人物位置/尺度稳定；若面孔换成夸张类型（关键点偏差 >15%），骨架比对与标志物清单会同时失稳。
- **C5 ⟨R8 ∧ R3⟩「版画工艺 × 均匀可读光」**：排线族 ≥2 方向、线覆盖率 ≥15% 是「明暗由线密度」而非光源塑造；R3 的「画内单一硬光源 = 0」正是其反面：光不成为主角，线密度承担明暗。§8.2-8 与戈雅 §8.2-7「交叉排线 ≈0」同轴互斥，R8 是**版画档开关**。

## 3. 正例（跨场景，逐帧可自查）

**正例 1 — UI 状态对照页 / 数据看板对位图（无浪子、无琴酒巷、无道德判词）**：两张骨架相似度 ≥70% 的并列面板：每面板 ≥5 条可辨认线索（可读文字 ≥1 处）(R1)；主角可追踪元素（同一图标/配色）每帧出现率 100%、跨帧 ≥2 次状态变化（R2）；无画内单一硬光源、暗部 ≤35%、近黑 ≤10%（R3）；≥3 种类型化图标但关键点比例偏差 ≤15%、无夸张扭曲（R4）；两面板语义相反标志物 ≥3 对（满/空、完好/告警、绿/红）（R5）；运动模糊 = 0、1 个动作极值（R6）；下缘 ≤2 行标题与标签匹配（R7）；版画档取线覆盖率 ≥15%、平涂 ≤10%（R8）。**八条自查全是 OCR/直方图/关键点/结构相似度/动作计数/方向场统计量，无需认出 18 世纪伦敦浪子** → 纯风格成立。

**正例 2 — 流程步骤图 / 成对 A-B 测试卡（内容全换）**：线索编目 + 均匀可读光 + 类型化不夸张 + 对位骨架 + 定格 + 题刻行数 + 排线表面（可选档）。R1–R8 仍逐条可算。仅声明视觉关系可迁，不声称任何生成通道已产出、不声称 E4 通过。

## 4. 强反例（题材全对但风格不成立）

**强反例 1 — 题材全对但改单点聚光深黑**：画出浪子、纨绔、可读信件/账本/画中画、成对题刻（题材齐备），但把光改成画外单光源 + 近黑背景 + 聚光戏剧。破 R3（画内单一硬光源 = 0、暗部 ≤35%、近黑 ≤10% 全失效）、连带破 C2；§8.1 负向 chiaroscuro drama / single spotlight / deep black backgrounds 即此。**结论：题材齐全≠风格成立**。

**强反例 2 — 保留线索却改漫画扭曲**：题材不变，把类型化面孔改成戈雅式兽化/夸张漫画脸、关键点比例偏差 >15%。破 R4（无漫画式扭曲/兽化）、连带破 C1/C4；§8.1 负向 caricature distortion / exaggerated cartoon faces 即此。

**强反例 3 — 改运动模糊与连续推拉**：题材不变，加入运动模糊与多动作连续叙事、镜头推拉。破 R6（模糊 = 0、1 个动作极值）、R5（骨架相似度 ≥70% 被镜头运动打散）；§8.1 负向 soft-focus blur / impressionist brushwork 与 Lane B 同侧（定格侧）。

## 5. 适用 / 不适用条件

**适用**：① 单帧信息密集/流程说明类输出（线索计数、OCR、直方图可逐帧查）；② 需要「均匀可读光 + 类型化不夸张 + 对位骨架」的成对比较图/看板；③ 需要「系列进度 + 题刻行数」的帧组工程；④ 交叉排线明暗、运动模糊 = 0 约束明确的版画/线描通道。

**不适用**：① 需要**画外单光源 + 近黑背景聚光**的场景（破 R3，越界卡拉瓦乔，§4 分工注 L115）；② 需要**单光源连续衰减照单脸**的场景（破 R3，越界伦勃朗）；③ 需要**漫画式扭曲/兽化怪诞**的场景（破 R4，越界戈雅怪诞档）；④ 需要**空极简/装饰抽象**的场景（破 R1，§8.1 负向 empty minimal scenes / decorative abstraction）；⑤ 需要**运动模糊/镜头推拉/连续动作**的场景（破 R6）；⑥ 需要**帧内自足、无跨帧进度依赖**的场景（破 C3，越界洛克威尔单帧档）；⑦ 需要**禁交叉排线飞尘**的版画档（破 C5，越界戈雅版画档）。

**组合预检（沿用 dossier）**：§3.1 与戈雅（系列连续性 vs 帧间独立、交叉排线 vs 禁交叉排线＋飞尘，N4 分区）、洛克威尔（叙事单位轴单主，70/30 起）、Lane B（硬阴影禁令同侧、运动模糊 = 0、题刻用作结尾文案槽）分工轴。
