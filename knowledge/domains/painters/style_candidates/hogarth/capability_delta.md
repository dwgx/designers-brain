## 1. 无 §8.1b 时，卡能做什么 / 不能做什么

**能做**：在「浪子进度/婚约对位/琴酒巷警示」**默认题材域**内，用 §8.2 的 8 条（对象检测+OCR、逐帧登记表、光源+直方图、人脸关键点、结构相似度、模糊核+动作计数、文本行+关键词、方向场+覆盖率）自查 §8.1/§8.2/§4 逐字一致（AUDIT-hogarth 记录 §8.1b 被排除在逐字比对之外）。

**不能做**：**跨场景路由**。把「剧场化 × 线索编目 × 均匀可读光 × 对位骨架」迁到 UI 状态对照页、数据看板、A-B 测试卡时，§8.1 正向段会强制带回浪子/荡妇/纨绔、可读信件账本、道德判词与成对诗句，把内容对象当风格前提。

**本卡特有的未消歧张力（AUDIT-hogarth accepted 登记）**：§4 P1 系列化与 P6 角色复用是工作流参数（不进画面重叠计算），R2/R7 是其画面落点；无 §8.1b 时卡没有「帧间进度依赖整体属于本模块、不得与帧内自足同档并存」的拆法，跨场景容易把系列帧数/题刻误当无条件阈值，并与戈雅「帧间独立 + 禁交叉排线」同轴冲突（AUDIT-hogarth counterexample 登记）。

## 2. §8.1b 草案新增的跨场景路由能力

| 增量 | 无 §8.1b 的卡 | 本 §8.1b 草案 |
| --- | --- | --- |
| 介质/语义无关的关系量 | §8.1 绑定浪子/荡妇/纨绔、信件账本镜子时钟、道德判词、成对题刻 | 拆成 R1–R8：线索(计数/OCR)、进度(帧数/出现率/状态变化)、光(硬光源数/暗部占比/近黑占比)、面孔(类型数/关键点偏差)、对位(骨架相似度/相反标志物对数)、定格(模糊/动作极值)、题刻(行数/关键词)、版画(方向族/覆盖率/平涂占比)——全是计数/直方图/相似度统计量 |
| 默认题材泄漏剥离表 | 无 | §1 表把人物专名/器物清单/道德判词/系列题刻/色名逐项降级；给「迁移判据」：撤掉专名后 §8.2 自查仍可算 = 纯风格；R2/R7 只保留「计数/出现率/行数/骨架相似度」，叙事语义不迁 |
| 工作流参数显式化 | 卡内 P1/P6 未拆层 | §1 注把 P1 系列帧数、P6 角色复用、R8 版画档写成**工作流/档位开关**；C3 登记与洛克威尔叙事单位轴单主、C5 登记与戈雅交叉排线同轴互斥 |
