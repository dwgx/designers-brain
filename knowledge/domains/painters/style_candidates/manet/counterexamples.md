# 风格级强反例 — `manet` [inference]

> 本页 3 例全部停在纸面：不渲染像素、不接图像通道、不做 E4 实测。每例写明撤去或反转的具体机制、被破的 R-ID 与 manet dossier §8.2 原文行；巴黎题材对象一律保留，用来证伪「题材齐备即风格成立」。

<a id="db-source-line-5"></a>
## CE-M1 — 撤去双峰：把亮暗直接并置换成完整中间调渐变

**操作**：题材全保留(阳台/黑裙/直视/裁切)，只把明暗机制从「亮暗双峰并置 + 一次性宽笔」换成萨金特式平滑罩染、完整半调过渡、空间恢复体积与浅纵深。**被破坏的规则**：R1(§8.2-1 L243 中带≤25%、双峰间距≥0.25)直接 fail；R5(§8.2-5 L247 色层≤3、笔触覆盖≥60%)→罩染使色层>3、可见笔触消失；R2(§8.2-2 L244 消失点≤1)→纵深回归；连带破 C1、C2。**为何是风格级反例**：只换「明暗由什么承载」这一关系，证明 manet 身份轴是中间调压缩×一次性笔触(C1)，不是「画的是不是巴黎」。对应 §4 越界警报①、§3.1 vs 萨金特笔触功能轴。

<a id="db-source-line-9"></a>
## CE-M2 — 反转光位：保留黑面积色但引入画外单光源

**操作**：保留收窄色域、黑区平整、宽笔、裁切、直视；只把正面平光换成卡拉瓦乔式画外单光源 + 近黑背景 + 光斑只落脸/手。**被破坏的规则**：R3(§8.2-3 L245 黑区σ≤0.06 的平整面积色)→黑变成暗部光源背景；R6(§8.2-6 L248 面部阴影≤15%、无单侧硬阴影)→出现方向性硬影；拆 C2/C3。**为何是风格级反例**：色板与笔触全在、题材全在，风格仍不成立——反驳「认出黑+平涂就是马奈」；证明黑是「面积色」而非「暗」。对应 §4 越界警报③。

<a id="db-source-line-13"></a>
## CE-M3 — 内容泄漏反证：把 1860s 巴黎与直视名妓升为必要条件

**操作**：不改任何像素，只在集成时把 §8.1 的 `café-concert/balcony/boating party` 与「当代生活 + 直视观众」写成 §8.1b 无条件前提。**后果**：抽象双峰海报正例与 UI 图标族会被误判「不像马奈」，而 §8.2 的 8 条统计量本不依赖任何器物专名。**结论**：现代生活题材与具体器物是 R8 的视线计数/题材档位，不是风格前提；本反例破的是规则写法，不是像素。
