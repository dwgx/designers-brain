# 风格级强反例 — `holbein` [inference]

> 本页 3 例全部停在纸面：不渲染像素、不接图像通道、不做 E4 实测。每例写明撤去或反转的具体机制、被破的 R-ID 与 荷尔拜因 dossier §8.2 原文行；默认题材对象一律保留，用来证伪「题材齐备即风格成立」。

## CE-HOL1 撤去核心机制：把「hatching检出=0、可见笔触≤5%」换

**操作**：把「hatching检出=0、可见笔触≤5%」换成丢勒式两组交叉排线网造灰、硬轮廓；材质与铭文全保留。 **被破坏的规则**：R1(§8.2-1 L207 排线=0、笔触≤5%、纹理<2px)fail；R2(§8.2-2 L208 边界梯度≤2px、内过渡≥2%短边)被排线灰阶取消；拆 C1/C5。 **为何是风格级反例**：只换一组可迁移关系而不改题材，证明 荷尔拜因 身份轴是统计量耦合、不是「画的是不是默认题材」；对应 §4 越界警报与 §3.1 分工条款。 [STYLE-holbein[inference]]
<a id="db-source-line-8"></a>
## CE-HOL2 反转关系档：保留净面、材质、铭文；只把均匀软光换成伦勃朗式重

**操作**：保留净面、材质、铭文；只把均匀软光换成伦勃朗式重点区域照亮+连续衰减+选择性粗化肌理表达情绪。 **被破坏的规则**：R6(§8.2-6 L212 无画内光源、暗部V≥0.05、阶跃≤10%/px)fail；R1(§8.2-1 L207 可见笔触≤5%)被粗化肌理破；拆 C5/C3。对应 §3.1 L83–88 vs 伦勃朗。 **为何是风格级反例**：题材与色/光统计全在、关系仍不成立——反驳「认出默认题材就是 荷尔拜因」；对应 §4 越界警报与 §3.1 分工条款。 [STYLE-holbein[inference]]
<a id="db-source-line-11"></a>
## CE-HOL3 内容泄漏反证：把默认题材升为 §8.1b 必要条件

**操作**：不改任何像素，只在集成时把 §8.1 正向段的「北方文艺复兴肖像 / 《大使们》/ 材质物证与画内铭文」与相关器物/体裁专名写成 §8.1b 无条件前提。 **被破坏的规则**：后果：跨场景正例（抽象/图标族）会被误判「不像荷尔拜因」，而 §8.2 的 8 条统计量本不依赖任何题材专名。 **为何是风格级反例**：结论：默认题材是 R 表计数/档位的内容基底，不是风格前提；本反例破的是规则写法，不是像素。 [STYLE-holbein[inference]]
