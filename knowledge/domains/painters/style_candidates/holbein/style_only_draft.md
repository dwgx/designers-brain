## 1. 默认题材泄漏的剥离

dossier §8.1 正向段把「荷尔拜因」强绑定在一组**内容对象**上，本段逐项降级为关系量：

| §8.1 内容词 | 为什么不是风格前提 | 本段处理 |
|---|---|---|
| `one or two sitters / half-length / gaze level / likeness` | 人物与肖像体裁是内容；关系量是净面（排线=0、可见笔触≤5%）+对称/三角结构线 | 保留 §8.2-1/§8.2-7 |
| `satin / fur / gold thread / glass / parchment / instruments / letters` | 材质与道具清单是内容；关系量是≥3类材质高光签名可分类、每类≥5%、道具可读≥3件 | 保留 §8.2-3/§8.2-4 |
| `signature / date / age / motto / anamorphic skull` | 铭文与变形骷髅是内容；关系量是文字字符高≥全画高1%、位于功能表面、≥1处自指 | 保留 §8.2-5/§8.2-8 |

**迁移判据（已收窄）**：换掉专名后，§8.2 的 8 条里**只**有「可原样转移到无语义输入的形式子集」（§2.2：R1、R2、R6、R7）能逐条在无人物 / 文字 / 器物 / 事件的纯几何图上计算；带语义前提的规则（§2.3）在无对应内容时必须标**不适用 / 未知**，不得记通过。「语义专名不迁」≠「语义前提不迁」。

> **荷尔拜因 特有的规则内张力（登记，不消歧）**：§8.2-8 L214「变形元素面积≤8%、仿射校正后IoU≥0.5」为「可选、启用时」条款；本段标「启用时才生效」，不擅自把变形装置写成无条件前提。

### 2.2 可原样转移的形式子集（对无语义输入的几何输入仍可定义）

仅以下量**不依赖「认出人物 / 面孔 / 文字 / 事件 / 器物 / 材质」这一语义前提**，可在纯色块 / 线 / 面积 / 直方图 / 连通域 / 方向场上逐帧计算：
- **R1**（净面规则：hatching 检出 = 0 / 可见笔触 ≤5% / 表面纹理 <2px）；
- **R2**（「外硬内柔」边缘规则：边界梯度带宽 ≤2px / 面部内过渡 ≥2% 短边 / 外 3px 无 >30% 羽化）；

- **R7**（几何构图规则：中轴 ±5% 锚点 / 对称或三角/圆结构线 ≥1 组）；

其余规则的阈值文字含语义承载（见 §2.3），**不得**因「删掉题材专名」就宣称在无语义输入上仍逐条可算。

## 3. 组合条件（旧「五条耦合断言」已校准）

## 6. 适用 / 不适用条件

**适用**：
1. 平面/材质样本板/UI铭牌（方向滤波+梯度剖面+高光分类+OCR可逐帧查）
2. 需材质物证化+画内铭文自指的版式
3. 无排线罩染渐变、软光无硬影的渲染通道
4. 几何对称/三角结构、可选变形装置的输出

**不适用**：
1. 需排线/交叉排线（破 R1，越界丢勒）
2. 需硬切光斑/戏剧投影（破 R6，越界卡拉瓦乔）
3. 需可见厚涂笔触/肌理表达（破 R1，越界伦勃朗/梵高）
4. 需装饰金平面+图案化（破 R3，越界克里姆特）
5. 需高彩度补色并置（破 §4 越界⑥，越界梵高）

**组合预检（沿用 dossier）**：vs 丢勒（§3.1 L77–82：油画材质物证/无排线 vs 版画排线密度/可复制线网）、vs 伦勃朗（L83–88：信息照明/外表物证 vs 情感照明/内心光）；按 [conflicts.md](../../../../cross/conflicts.md) 预检，冲突轴单主（N3），不得双开标志机制。
