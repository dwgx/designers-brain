## 1. 默认题材泄漏的剥离

| §8.1 内容词 | 为什么不是风格前提 | 本段处理 |
|---|---|---|
| `village, fields, river, distant mountains` | 地物清单是题材；可判读的是**高视点 + 无单一消失点 + 引导线散点** | 改写为透视/地平线关系（§8.2-1） |
| `dozens of small anonymous figures … reaping, resting, playing, skating` | 人物身份与动作语义是内容；风格要件是**实例计数 + 无中心聚类 + 姿态去重** | 改写为分布式多实例的统计量（§8.2-2/-3/-5） |
| `one unified seasonal key / snow / ochre, brick red, forest green` | 具体季相与色名是内容档；关系量是「色相族 ≤4 + 单一基调 + 小面积红锚点」 | 保留为色相预算关系（§8.2-4），不锁「冬/秋/雪」 |
| `Netherlandish Proverbs / Children's Games` 的谚语/游戏 | 可解码语义是内容层；P6 只是「编码密度」档位开关 | 降为可选层，见 §4 用法「P5/P6 定人物与语义层（可关）」 |
| `a painted encyclopedia of everyday life` | 体裁标签 | 删除；保留「微缩细节能量集中于 2–16px 尺度带」 |

**迁移判据**：换掉全部地物/人物语义后，§8.2 的 8 条自查（地平线检测+透视估计、实例分割+聚类+姿态去重、场景分类+视线估计、HSV 掩膜、多尺度能量比、亮度统计+Hough、姿态比例、梯度带宽+高光计数）仍可逐帧算 → 纯风格。八条全可迁。

> **bruegel 特有注意**：§8.2-2 的 `≥30 人`、§8.2-3 的 `≥3 类不同时间活动并存`、§8.2-5 的 `人物高度中位 ≤ 画高 1/15` 都以「实例」为分母；换成非人物元素（图标、零件、数据点）时，计数/尺度关系仍成立，但须显式声明「实例类别已替换」，不可把「人」写死为前提。AUDIT-bruegel 记录 0 处野外样本卡、72 claim 行全部 locator 可解析。

## 2. 可迁移视觉关系（参数 · 单位 · 范围 · 必要耦合）— 视点/分布/色相/软光四族；全部 `[归纳] 未实测` [STYLE-bruegel]

| ID | 可迁移关系 | 单位 / 范围 `[归纳]` | 源行 |
|---|---|---|---|
| R1 | **高视点 / 无单一消失点**：地平线位于上 1/4–1/3；俯角 ≥15°；引导线消失点 ≥2 组或散点，无单一消失点主导 | 地平线(%画高 上 25–33)、俯角(≥15°)、消失点组(≥2) | §8.2-1；§4 P1 |
| R2 | **分布式多实例 / 无中心**：实例 ≥30（中强档），最大聚类 ≤15% 画布面积，单实例独立动作（姿态重复率 ≤30%） | 实例数(≥30)、最大聚类(≤0.15)、重复率(≤0.30) | §8.2-2；§4 P2 |
| R3 | **共时性 / 无统一动线**：同帧 ≥3 类不同活动态并存；无指向单一事件的视线/手势汇聚 | 活动类(≥3)、汇聚(无) | §8.2-3 |
| R4 | **单一基调色相预算**：全帧色相族 ≤4；季节/基调可判（如雪白 ≥15% → 冬）；蓝仅作远景大气，不主张 ≥40% | 色相族(≤4)、单族面积(≥0.15 判据) | §8.2-4；§4 P3；C-12 |
| R5 | **微缩细节 / 尺度带**：实例高度中位 ≤ 画高 1/15；细节能量集中于 2–16px 尺度带；逐实例动作可分类 | 高度比(≤1/15)、尺度带(2–16px) | §8.2-5；§4 P4 |
| R6 | **前景暗框 + 导引线**：前景（下 1/4）明度中位 < 全帧中位 −0.1；≥1 条导引线指向纵深；暗框元素 ≥1 | 明度差(< −0.1)、导引线(≥1)、暗框(≥1) | §8.2-6 |
| R7 | **反理想比例**：无英雄化裸体；实例身高/肩宽比 <4（短壮）；姿态多弯曲（对称站姿 ≤20%） | 高肩比(<4)、对称站姿(≤0.20) | §8.2-7；§4 P5 |
| R8 | **漫射软光 / 暗部不塌**：阴影边界梯度带宽 ≥2% 短边；无单点光源（高亮连通域 ≥2 或成带状）；暗部 V ≥0.05 | 带宽(≥2% 短边)、高亮连通域(≥2)、暗部 V(≥0.05) | §8.2-8；C-01 |

**必要耦合（拆开会破，`[归纳]`）**：

- **C1 ⟨R1 ∧ R2 ∧ R6⟩「全景骨架」**：高视点（R1）让分布式实例（R2）铺满全幅而不聚成中心，前景暗框 + 导引线（R6）给「无中心」的散点一个**进入纵深**的读法。若把视点压成平视且保留 100+ 实例，实例会互相遮挡成团，R2 的「最大聚类 ≤15%」失效；§3.1 越界警报③「向心旋转集中 → 越界米开朗基罗」即失 R1/R2 后的塌缩。
- **C2 ⟨R2 ∧ R3 ∧ R5⟩「百科全书式细节」**：R2 给数量、R3 给「≥3 类并存且无统一动线」、R5 给「尺度小到需逐一看」。三者合起来才是 §2/§8.1 的 `slow and selective study`；若只保留 R2 的 100+ 实例而撤掉 R5 的微缩尺度（把实例放大到画高 1/3），画面变成少数大主体，R2 的无中心聚类仍成立但「百科」读法消失。
- **C3 ⟨R4 ∧ R8⟩「统一基调 × 漫射光」**：R4 的色相族 ≤4 依赖 R8 的漫射软光（无单点光、暗部不塌）来维持「同一季节基调铺满全幅」；若引入卡拉瓦乔式单点硬光，亮暗把画面切成两半，R4 的单基调与 R8 的 ≥2 高亮连通域同时失效（§4 越界警报①）。
- **C4 ⟨R4 红锚点 × R2 分布⟩**：§8.1 `small red accents as anchors` 是**小面积红在分布式实例中作对位**；红点必须「小且分散」，否则变成单一焦点，破 R2/R3 的无中心。
- **C5 ⟨P6 编码密度可关⟩**：§4 用法明写「P5/P6 定人物与语义层（**可关**）」；《农民婚礼》《收割者》档 P6 弱（纯观察）。可解码语义不是风格前提——本段不把「谚语/游戏编码」列入必要关系。

## 3. 正例（跨场景，逐帧可自查）

**正例 1 — 数据可视化 / 城市俯瞰信息图（无农民、无雪）**：高俯角 ≥18°、地平线在上 1/3、引导线 3 组散点消失（R1）；≥60 个微缩图标实例铺满全幅、最大聚类 12%、姿态重复率 22%（R2）；同屏并存「流动/静止/交互」≥3 类状态、无单一事件汇聚（R3）；全帧 3 个色相族 + 单一暖灰基调、小面积红锚点分散（R4）；实例高度 ≈ 画高 1/18、细节能量集中 2–16px（R5）；下 1/4 暗框 + 一条导引线（R6）；无单点光、阴影带宽 ≥2% 短边（R8）。**八条自查全是透视/计数/HSV/多尺度能量统计，无需认出「村庄/农民」** → 纯风格成立。

**正例 2 — 无字 key visual（S-06 边界）**：纯几何微缩元素的高视点分布式满幅构图，单基调 + 前景暗框 + 漫射光。R1–R8 仍逐条可算。仅声明关系可迁，不声称生成通道已产出、不声称 E4 通过。

## 4. 强反例（题材全对但风格不成立）

**强反例 1 —「雪中猎人」题材、单点硬光 + 向心集中**：画出雪景、猎人、村庄、树（题材齐备），但改成画外单光 + 戏剧投影（破 R8）、把人群聚成一个向心旋转焦点（破 R2/R3）、加英雄化裸体（破 R7）。§4 越界警报①（卡拉瓦乔）与③（米开朗基罗）、§8.1 负向 `no single spotlight, hard cast shadows / no concentric or rotational composition around one figure / no idealized heroic nudes` 即此。**题材齐全≠风格成立**。

**强反例 2 — 保留人群但改平面装饰 + 大留白**：题材不变，把全景改成北斋式平涂曲线族 + 大留白 + 单一蓝轴。破 R1（无高视点/多消失点）、R2（实例不足且留白破坏铺满）、R4（色相族虽少但蓝 ≥40% 违反「蓝仅作远景」）。§4 越界警报④、§3.1 vs 北斋分工轴。

**强反例 3（内容泄漏反证）— 把「必须有农民/谚语/冬季」当风格前提**：§4 P6 弱档明写「纯观察（《农民婚礼》《收割者》档）」、P3 弱档「季节模糊/中性」；§3 原则 6 把「可解码编码密度」列为**可控参数**。若集成时把「尼德兰谚语/儿童游戏/雪」写进 §8.1b 必要条件，纯观察档与中性季相档会被误判「不像勃鲁盖尔」。**人物/花卉/风景内容对象不是风格前提**——§8.2 全部分母都是像素/实例/几何量。

## 5. 适用 / 不适用条件

**适用**：① 高视点、满幅、多实例、无单一焦点的构图类（信息图、俯瞰、密集型版式）；② 需要「共时多状态 + 逐实例可读」的静态图；③ 单基调低饱和 + 漫射光的渲染通道；④ 共时叙事在视频里的等价物（§8.3-2 分屏/画中画/焦点轮巡，选主导轴）。

**不适用**：① 需要**单点硬光/戏剧投影**的场景（破 R8/C3，越界卡拉瓦乔）；② 需要**天气事件/能量场/漩涡**的场景（破 R3/R8，越界透纳，越界警报②）；③ 需要**英雄化裸体 + 向心旋转集中**的场景（破 R1/R2/R7，越界米开朗基罗）；④ 需要**平面装饰 + 大留白 + 曲线族**的场景（破 R1/R2/R4，越界北斋）；⑤ 以**新物种发明**为主装置（破 R3 的日常性，越界博斯）；⑥ **现代都市/人造光/夜街**（越界霍珀，越界警报⑥）；⑦ S-06 无文字 key visual 下不补任何可读文字/谚语标签。

**组合预检（沿用 dossier）**：C-12（蓝仅作远景大气，不主张 ≥40%；与北斋蓝轴预检）、C-01（与卡拉瓦乔/米开朗基罗硬光侧显式互斥）、§3.1 与北斋（70/30 主导轴）/米开朗基罗（分区或二选一）/博斯（怪诞来源不互抄）分工轴。
