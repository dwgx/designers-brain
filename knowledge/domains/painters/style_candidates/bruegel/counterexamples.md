# 风格级强反例 — `bruegel` [inference]

> 全部为**纸面推演 [inference]**，未渲染像素、未跑生成通道、未做 E4。每条给具体撤去/反转/保留操作，点名被破坏的 §8.1b 关系 ID 与 dossier §8.2 规则行。题材对象（村庄、雪、农民、节庆、谚语、树）全部保留，证明「题材齐备≠风格成立」。

<a id="db-source-line-5"></a>
## CE-R1 — 撤去纹理：把「微缩细节 2–16px」改成概括大笔触

**操作**：题材全保留（100+ 小人、雪景、村庄、树）；但把逐人逐物的微缩细节改成大笔概括、个体不可辨。

**被破坏的规则**：
- R5（§8.2-5 L195「实例高度中位 ≤ 画高 1/15、细节能量集中于 2–16px 尺度带、逐实例动作可分类」）→ 尺度带上移、动作不可分类；
- R2（§8.2-2 L192「≥30 实例、姿态重复率 ≤30%」）→ 逐实例分类失效使重复率无法计算；
- 连带破 C2（R2 ∧ R3 ∧ R5「百科全书式细节」三件套）。

**为何是风格级反例**：只换细节尺度关系，未改题材；证明「微缩 + 分布式 + 共时」的耦合（C2）才是身份轴，不是「画了很多农民」。

<a id="db-source-line-16"></a>
## CE-R2 — 反转空间：把「高视点散点消失」改成平视单一消失点 + 向心集中

**操作**：保留人群、季节、土色、软光；但把 §8.2-1 的鸟瞰（地平线上 1/4–1/3、俯角 ≥15°、消失点 ≥2 组/散点）改成平视单点透视，并把人群聚成一个向心旋转焦点（米开朗基罗式）。

**被破坏的规则**：
- R1（§8.2-1 L191）→ 俯角/消失点组失效；
- R2（§8.2-2 L192「最大聚类 ≤15% 画布、无单一中心聚类」）→ 向心集中使最大聚类远超 15%；
- R3（§8.2-3 L193「无统一叙事动线、≥3 类活动并存」）→ 视线/手势汇聚单一事件；
- 连带破 C1（全景骨架）。
- 对应 §4 越界警报③「英雄化裸体＋向心旋转集中 → 越界米开朗基罗」、§8.1 负向 `no concentric or rotational composition around one figure, no single-point perspective axis`。

**为何是风格级反例**：只反转视点与聚类关系；证明「高视点 × 无中心 × 前景暗框」（C1）是纯几何关系。

<a id="db-source-line-29"></a>
## CE-R3 — 保留色板撤掉形状：土色低饱和 + 小面积红锚点还在，但撤掉软光与暗框

**操作**：保留全帧色相族 ≤4、暖土/砖红/雪白/石板蓝、小面积红锚点（R4 不动）；撤掉 R8 的漫射软光（改卡拉瓦乔式单点硬光 + 戏剧投影 + 近黑暗部），撤掉 R6 的前景暗框与导引线。

**被破坏的规则**：
- R8（§8.2-8 L198「阴影带宽 ≥2% 短边、无单点光源（高亮连通域 ≥2 或成带）、暗部 V ≥0.05」）→ 单点光 + 暗部塌陷直接 fail（破 C3）；
- R6（§8.2-6 L196「前景下 1/4 明度中位 < 全帧 −0.1、≥1 导引线、暗框 ≥1」）→ 撤除后 fail；
- R4 的「单一季节基调铺满全幅」因亮暗切两半而失去统一性。
- 对应 §4 越界警报①「单点硬光＋戏剧投影 → 越界卡拉瓦乔」、§8.1 负向 `no single spotlight, hard cast shadows, chiaroscuro, theatre lighting`。

**为何是风格级反例**：色板（最像「勃鲁盖尔」的线索）完全保留，风格仍不成立——反驳「认出土色全景配色就是本风格」。

## CE-R4（内容泄漏反证）— 把「必须有农民/谚语/冬季」升为必要条件

**操作**：不改像素，只在集成时把 `Netherlandish Proverbs / Children's Games / 雪中猎人` 写成 §8.1b 前提。

**后果**：§4 P6 弱档「纯观察（《农民婚礼》《收割者》档）」、P3 弱档「季节模糊/中性」会被误判「不像勃鲁盖尔」；§3-6 明写「编码密度是**可控参数**（§4 P6）」、§4 用法「P5/P6 定人物与语义层（**可关**）」。

**结论**：谚语/游戏/冬季是内容档位，不是风格前提；§8.2 全部分母是实例计数、聚类面积、色相族、多尺度能量、梯度带宽。
