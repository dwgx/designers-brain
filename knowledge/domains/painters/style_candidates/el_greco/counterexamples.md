# 风格级强反例 — `el_greco` [inference]

> 全部为**纸面推演 [inference]**，未渲染像素、未跑生成通道、未做 E4。每条给具体撤去/反转/保留操作，点名被破坏的 §8.1b 关系 ID 与 dossier §8.2 规则行。题材对象（圣徒、圣母、拉长人形、酸色、云幕、拜占庭正面）全部保留，证明「题材齐备≠风格成立」。

## CE-G1 — 撤去纹理：把「火舌碎边 + 薄罩染」改成厚涂能量场

**操作**：全套宗教题材保留；把轮廓外 2% 环带的火舌碎笔（边缘密度 ≥1.5×、连通段 ≤1.5% 短边、无厚涂）改成梵高式厚涂堆料 + 全幅互补对振动。

**被破坏的规则**：
- R2（§8.2-2 L229「环带边缘密度 ≥1.5×、段长 ≤1.5% 短边、法线/浮雕强度低」）→ 厚涂使法线强度升高；
- R8（薄罩染 / 无厚涂）→ fail；
- R7（§8.2-8 L235「无互补对全幅 1:1 振动、主色族 ≤3」）→ 全幅振动 fail；
- 连带破 C1（连续拉长 × 火舌碎边 × 薄罩染）与 C3。
- 对应 §4 越界警报④「厚涂能量场 + 互补对振动 → 越界**梵高**」、§8.1 负向 `no impasto relief with palette-knife texture, no complementary-colour vibration across the whole canvas`。

**为何是风格级反例**：只换表面笔触/厚度关系，未改任何人物；证明「碎化只在轮廓环带、形体内部连续」（C1）是纯边缘统计量。

<a id="db-source-line-18"></a>
## CE-G2 — 反转空间：把「云幕未定义空间」改成深线性透视 + 单一外光

**操作**：保留拉长人形、酸色、红事件、火舌边；把 §8.2-5 的低熵云幕（背景熵 ≤0.7×、地平线 ≤1 弱线、透视收敛 ≤2 组）改成写实深线性透视 + 明确地平线 + 画外单光源 + 近黑背景 + 硬投影。

**被破坏的规则**：
- R5（§8.2-5 L232）→ 熵/地平线/收敛线索 fail；
- R4（§8.2-4 L231「阴影方向一致性 ≤0.3、亮度离散 ≤0.15、高光连通域 ≥4 且分散」）→ 单一外光使方向一致性升高、高光集中；
- 连带破 C2（自有光 × 云幕）。
- 对应 §4 越界警报③「画外单光源 + 近黑背景 + 高光只落脸手道具 → 越界**卡拉瓦乔**」、§8.1 负向 `no naturalistic daylight, no deep linear perspective with vanishing point, no heavy chiaroscuro with near-black background`。

**为何是风格级反例**：只反转空间深度与光源关系；证明「人人自带光」必须配「未定义空间」才能逐帧自查。

## CE-G3 — 保留色板撤掉形状：酸黄绿/冷蓝 + 红事件还在，但撤掉纵向拉伸与形体连续性

**操作**：保留 ≥2 个酸色区块、红 ≤12% 且最高饱和、主色族 ≤3（R3/R7 不动）；但把实例框高/宽 ≥3.5、头身 ≤0.11 改回自然比例，并允许面片拼接/直线折角段（毕加索式多视点）。

**被破坏的规则**：
- R1（§8.2-1 L228「高宽比 ≥3.5、头身 ≤0.11」+ §8.2-6 L233「轮廓连续无断裂、折角段 = 0」）→ 双 fail；
- 连带破 C1（概念性拉伸而非解构）。
- 对应 §4 越界警报②「面片拆解 + 多视点、色彩转近单色 → 越界**毕加索**」、§8.1 自查①「头身比 ≥9 且形体连续无断裂/拼接」。

**为何是风格级反例**：色板（最像「格列柯」的线索）完全保留，风格仍不成立——反驳「认出酸色 + 红袍就是本风格」。也说明「拉长」是包围盒比例，不是「画了圣徒」的内容事实。

## CE-G4（内容泄漏反证）— 把「必须有圣徒/圣母/希腊文题记」升为必要条件

**操作**：不改像素，只在集成时把 `saints, martyrs, the Virgin / Greek-letter inscription / Byzantine gold fields` 写成 §8.1b 前提。

**后果**：§8.1 `[portrait variant]`（半身肖像、幽灵平背景、修辞手势）与 [style_only_draft.md](style_only_draft.md) 正例 1（抽象柱体光柱）会被误判「不像格列柯」；§4 P6 是组稿参数、P3/P5 是时期档、§8.1 中文说明「早期/意大利档把 P1 降到 20–30%（只剩威尼斯色）」——连纵向拉伸都是**合法弱档**，不是无条件前提。S-06 无文字 key visual 边界下 `Greek-letter inscription` 更不得写入。

**结论**：宗教人物/题记是内容档位，不是风格前提；§8.2 全部分母是框高宽比 / 环带边缘密度 / HSV 面积 / 阴影方向 / 背景熵 / 光流 / 色相族。本反例破的是规则写法，不是像素。
