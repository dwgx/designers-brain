## 1. 默认题材泄漏的剥离

| §8.1 内容词 | 为什么不是风格前提 | 本段处理 |
|---|---|---|
| `saints, martyrs, the Virgin, heavenly visions / devotional, ecstatic` | 人物身份与宗教情绪是内容；可判读的是「纵向拉伸 + 蛇形扭转 + 自有光」 | 删除专名，保留 §8.2-1/-4/-6 的几何/光度关系 |
| `long thin hands and fingers / small heads on long swaying bodies` | 肢体描述是内容的**一个实例**；关系量是「实例框高/宽 ≥3.5、脸框高/人框高 ≤0.11」 | 改写为 §8.2-1 的包围盒比例，不锁「手/头」 |

**迁移判据**：换掉全部圣像/人物/色名后，§8.2 的 8 条自查（人体关键点+实例分割框比例、边缘检测+连通域+表面法线、HSV 掩膜+面积、阴影方向场+分区亮度、熵图+直线检测、轮廓跟踪+折角、光流场直方图、色相直方图+面积预算）仍可逐帧算 → 纯风格。

## 2. 可迁移视觉关系（参数 · 单位 · 范围 · 必要耦合）— 拉伸/碎边/酸色/自有光/云幕五族；全部 `[归纳] 未实测` [STYLE-el_greco]

| ID | 可迁移关系 | 单位 / 范围 `[归纳]` | 源行 |
|---|---|---|---|
| R1 | **纵向拉伸比例**：焦点实例分割框高/宽 ≥3.5；局部框高 ÷ 整体框高 ≤0.11（≥9 头身当量）；形体连续无断裂（断裂点 ≤1 且非结构性）、直线折角段计数 = 0 | 高宽比(≥3.5)、头身比(≤0.11)、断裂(≤1)、折角段(=0) | §8.2-1/-6；§4 P1 |
| R2 | **火舌碎化边缘**：形体轮廓外 2% 环带内高频边缘密度 ≥ 全帧均值 1.5×；边缘连通段中位长度 ≤ 短边 1.5%；无厚涂（法线/浮雕强度低） | 边缘密度倍率(≥1.5)、段长(≤1.5% 短边) | §8.2-2；§4 P2 |

| R5 | **云幕 / 未定义空间**：背景区纹理熵 ≤ 全帧均值 0.7×；地平线检测命中 ≤1 条弱线；透视收敛线索 ≤2 组 | 熵比(≤0.7)、地平线(≤1 弱)、收敛线索(≤2) | §8.2-5；§4 P5 |

| R8 | **薄罩染 / 无厚涂**：薄 glazes over 灰底、粗糙未混合笔道、红底透出；与 R2 的「法线/浮雕强度低」同侧 | 定性（由 R2 的法线估计自查） | §8.2-2；§8.1 正向 L209 |

**必要耦合（拆开会破，`[归纳]`）**：

- **C1 ⟨R1 ∧ R2 ∧ R8⟩「连续拉长 × 火舌碎边 × 薄罩染」**：R1 要求**形体连续无断裂**（折角段 = 0），R2 只让**轮廓外 2% 环带**碎化，R8 禁止厚涂堆料。三者合起来才是「概念性拉伸而非解构」；若把碎化扩散到形体内部（面片拼接/多视点），直接破 R1 与 §3.1 vs 毕加索判据（越界毕加索，越界警报②）。若改成厚涂能量场 + 互补对全幅振动，破 R8/R7（越界梵高，越界警报④）。
- **C2 ⟨R4 ∧ R5⟩「自有光 × 云幕」**：R4 的「无方向性投影 + 高光分散 ≥4」需要一个**无地平线、无透视收敛、低熵背景**（R5）来成立；若引入深线性透视或单一画外光源，阴影方向一致性 ≤0.3 与背景熵 ≤0.7× 同时失效（越界卡拉瓦乔，越界警报③；§8.1 负向 `no deep linear perspective / no hard cast shadows from a single light source`）。
- **C3 ⟨R3 ∧ R7⟩「酸色 + 红事件」**：R3 给酸色区块数与红面积上限，R7 给主色族 ≤3 + 红为最高饱和 + 禁互补 1:1 振动。两者是同一色相预算的两个口径：撤掉 R7 的「主色族 ≤3」，酸色会铺成多族花布，破 §8.2-8；撤掉 R3 的「红 ≤12%」，红事件变成主色，破「红事件」定义。
- **C4 ⟨R6 ∧ R4⟩「弱上升场 × 自有光」**：R6 的 |v_y| ≤1.5% 短边/帧 是「介于冻结与全画面场之间」的弱场；它依赖 R4 的「光来自形体自身」——若改成单一外光，上升会让投影方向逐帧变化，破阴影一致性。C-09 运动预算在此取中间档。
- **C5 ⟨P1/P3/P4 三档滑轨⟩**：§4 用法把 P1/P2/P4 定为「是不是格列柯」（三条 ≥2 条 ≥ 中档），P3/P5 定时期档（意大利化 → 成熟 → 晚期白炽）；§8.1 中文说明「早期/意大利档把 P1 降到 20–30%（只剩威尼斯色）」——即 **P1 弱档是合法档位**，纵向拉伸不是无条件前提，这与「不能把内容/强度档写成风格必要条件」同一道理。

## 3. 正例（跨场景，逐帧可自查）

**正例 1 — 抽象柱体/光柱构成（无圣徒、无宗教）**：一组竖向柱形，实例框高/宽 3.8、顶部单元/整体 = 0.10、轮廓连续无折角（R1）；柱缘外 2% 环带高频边缘密度 = 全帧 1.7×、连通段中位 1.2% 短边、法线强度低（R2/R8）；两块 ≥6% 面积的酸黄绿/冷蓝区块 + 一处 8% 红为全帧最高饱和、中位饱和 0.5（R3）；阴影方向一致性 0.2、亮度离散 0.12、高光连通域 5 个分散（R4）；背景纹理熵 = 全帧 0.6×、地平线 0 条强线、收敛线索 1 组（R5）；主色族 3、无互补 1:1 振动（R7）；视频帧 v_y < 0、|v_y| 中位 1.0% 短边/帧（R6）。**八条自查全是包围盒比例/边缘密度/HSV/方向场/熵/光流统计，无需认出「圣徒/圣母」** → 纯风格成立。

**正例 2 — 无字 key visual（S-06 边界）**：纵向拉伸 + 酸色红事件 + 自有光 + 云幕低熵背景 + 弱上升。R1–R8 仍逐条可算。仅声明关系可迁，不声称生成通道已产出、不声称 E4 通过。

## 4. 强反例（题材全对但风格不成立）

**强反例 1 —「托莱多/圣像」题材、改面片解构 + 单光源**：画出拉长人形、圣像式正面、酸色（题材齐备），但把形体拆成多视点面片拼接（破 R1 折角段 = 0 / 连续性）、加画外单光 + 近黑背景 + 硬投影（破 R4/C2）。§4 越界警报②③「→ 越界**毕加索** / **卡拉瓦乔**」、§8.1 负向 `no heavy chiaroscuro with near-black background / no hard cast shadows from a single light source` 即此。**题材齐全≠风格成立**。

**强反例 2 — 保留色板、反转空间/撤掉自有光**：酸黄绿/冷蓝/红事件色板全保留，但改成写实自然日光 + 深线性透视 + 明确地平线 + 单一投影方向。破 R4（方向一致性 ≤0.3 / 高光 ≥4 分散）、R5（熵 ≤0.7× / 收敛 ≤2）、C2；§8.1 负向 `no naturalistic daylight, no deep linear perspective with vanishing point`。

**强反例 3（内容泄漏反证）— 把「必须有圣徒/圣母/希腊文题记/拜占庭金底」当风格前提**：§8.2 全部分母是「框高宽比 / 环带边缘密度 / HSV 面积 / 阴影方向 / 背景熵 / 光流 / 色相族」，没有一条要求认出宗教人物；§8.1 `[portrait variant]` 明写「bust-length portrait … spectral plain background」也成立；§4 P6 是组稿参数、P3/P5 是时期档。若集成时把「saints, martyrs, the Virgin」写进 §8.1b 必要条件，肖像档与抽象构成（正例 1）会被误判「不像格列柯」。**人物/花卉/风景内容对象不是风格前提**；`Greek-letter inscription` 在 S-06 无文字边界下更不得写入。

## 5. 适用 / 不适用条件

**适用**：① 纵向拉伸、连续形体、低熵未定义空间的构成类；② 需要「酸色 + 单一红事件 + 无互补全幅振动」的色相预算自查；③ 需要「无方向性投影 / 高光分散」的自发光渲染；④ 弱上升场 motion（C-09 中间档，介于冻结与全画面场之间）；⑤ 薄罩染/无厚涂的表面通道。

**不适用**：① **压缩/波动扭曲 + 世俗心理题材**（破 R1，越界蒙克，越界警报①）；② **面片拆解 + 多视点 + 近单色**（破 C1/R1/R3，越界毕加索）；③ **画外单光源 + 近黑背景 + 高光只落脸手道具**（破 C2，越界卡拉瓦乔）；④ **厚涂能量场 + 互补对全幅振动**（破 R8/R7，越界梵高）；⑤ **写实自然光 / 深线性透视 / 风景细节**（破 R4/R5）；⑥ S-06 无文字 key visual 下不补希腊文题记/任何可读文字。

**组合预检（沿用 dossier）**：C-01（站「无硬阴影」侧）、C-05（「可见碎笔触但**无厚涂堆料**」句式处理）、C-09（弱上升场）、C-12（蓝为罩染层积、非平涂大色域）；§3.1 与蒙克（70/30 主导轴）/毕加索/卡拉瓦乔分工轴。
