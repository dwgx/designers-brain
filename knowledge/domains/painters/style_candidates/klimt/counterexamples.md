# 风格级强反例 — `klimt` [inference]

> 本页 3 例全部停在纸面：不渲染像素、不接图像通道、不做 E4 实测。每例写明撤去或反转的具体机制、被破的 R-ID 与 克里姆特 dossier §8.2 原文行；默认题材对象一律保留，用来证伪「题材齐备即风格成立」。

<a id="db-source-line-5"></a>
## CE-KLI1 撤去核心机制：把纹样区「内部明度动态≥10%且与主体区有材质/

**操作**：把纹样区「内部明度动态≥10%且与主体区有材质/纹理差」改成平涂纯色（≤5%、同线宽同色阶），并去掉金属箔块；金色调保留为背景色块。 **被破坏的规则**：R2(§8.2-2 L238 纹样内明度动态≥10%、≤5%判越界马蒂斯域)fail；R1(§8.2-1 L237 金属区≥30%、箔块边界≥3处、平滑渐变金属≤5%)被平涂色块取代；R3(§8.2-3 L239 材质类别≥2、镜面高光聚类分离度≥1.5)被单材质取消；拆 C1/C2/C5。 **为何是风格级反例**：只换一组可迁移关系而不改题材，证明 克里姆特 身份轴是统计量耦合、不是「画的是不是默认题材」；对应 §4 越界警报与 §3.1 分工条款。 [STYLE-klimt[inference]]
<a id="db-source-line-8"></a>
## CE-KLI2 反转关系档：保留金属覆盖率与图案密度，只把「面孔+手局部方差

**操作**：保留金属覆盖率与图案密度，只把「面孔+手局部方差:图案≥2.0、面孔连续体积过渡≥3段」改成面孔与图案同一渲染等级（落差<1级）。 **被破坏的规则**：R4(§8.2-4 L240 方差比≥2.0、连续体积梯度≥3段)fail；R3(§8.2-3 L239 ≥2类材质清晰可分)失去写实皮肤簇；拆 C2/C4。对应 §4 P5 弱档 L105「落差<1级越界」。 **为何是风格级反例**：题材与色/光统计全在、关系仍不成立——反驳「认出默认题材就是 克里姆特」；对应 §4 越界警报与 §3.1 分工条款。 [STYLE-klimt[inference]]
<a id="db-source-line-11"></a>
## CE-KLI3 内容泄漏反证：把默认题材升为 §8.1b 必要条件

**操作**：不改任何像素，只在集成时把 §8.1 正向段的「维也纳分离派 / 黄金时期 / 金箔材质与写实面孔对撞」与相关器物/体裁专名写成 §8.1b 无条件前提。 **被破坏的规则**：后果：跨场景正例（抽象/图标族）会被误判「不像克里姆特」，而 §8.2 的 7 条统计量本不依赖任何题材专名。 **为何是风格级反例**：结论：默认题材是 R 表计数/档位的内容基底，不是风格前提；本反例破的是规则写法，不是像素。 [STYLE-klimt[inference]]

> 与 AUDIT-klimt 的关系：其 accepted 记录是 §4/§8.1/§8.2 逐字抽取一致性(A06 存在性检查)；本文件 3 条是**纯风格关系层**反例(机制撤去/反转/题材泄漏)，两者不同层、不互相替代。全部 `[inference]` 纸面推演，未渲染像素、未跑生成通道、未做 E4。CE-3 为内容泄漏反证：破的是规则写法，不是像素。
