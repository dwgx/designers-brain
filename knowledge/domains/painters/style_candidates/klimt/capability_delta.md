## 1. 无 §8.1b 时，卡能做什么 / 不能做什么

现有卡：视觉指纹要点、§8.1 图像 prompt（**正向段把 克里姆特 默认题材专名写死为题材**）、§8.2 逐帧规则、§4 六参数、冲突注记。

- **能做**：在「维也纳分离派 / 黄金时期 / 金箔材质与写实面孔对撞」**默认题材域**内，用 §8.2 的 7 条逐帧自查 `_extract.py --check` 所校验的 §8.1/§8.2/§4 逐字一致(AUDIT-klimt 记录 §8.1b 被排除在逐字比对之外)。
- **不能做**：**跨场景路由**。把「金属材质≥30% × 图案密度（带材质硬约束） × 材质对比≥2类 × 写实-装饰落差≥2.0 × 平面化 × 图案词汇尺度 × 近方形静止」迁到抽象海报、图标族、产品图时，§8.1 正向段会强制带回题材专名与体裁标签，把内容对象当风格前提 → 01-AUDIT.md A06 所指「有模块/能抽取/已做纯风格迁移」混淆。
- **本卡特有的未消歧张力**：§8.2-2 L238「纹样区明度动态≥10%（默认）/≥15%（强档）；≤5%越界、5–10%灰区」与 §4 P2 边界注 L92 同尺；本段把「灰区记警告、不得单独用于区分两人」写成显式取值，不擅自把 5–10% 并入 ≥10%。 无 §8.1b 时卡没有显式取值写法，跨场景路由易把两口径误当无条件阈值。

## 2. §8.1b 草案新增的跨场景路由能力

| 增量 | 无 §8.1b 的卡 | 本 §8.1b 草案 |
|---|---|---|
| 介质/语义无关的关系量（已收窄） | §8.1 绑定维也纳分离派 / 黄金时期 / 金箔材质与写实面孔对撞 | 保留 7 条源规则原文作来源映射；单列**可原样转移形式子集** R1/R2/R3（聚类量）/R5/R6 与**带语义前提规则** R4（面孔+手）、R7 主体包围盒分项；后者在无对应内容时标**不适用/未知**，不记通过——不再称「全是像素/几何/统计量」 |
| 默认题材泄漏剥离表 | 无 | §1 表把题材专名、器物清单、体裁标签逐项降级；迁移判据收窄：撤专名后**仅形式子集**可原样转移，语义前提规则标不适用 |
| 张力显式化 | 卡内两口径未处理 | §1 注把口径写成显式取值、标「须显式取值」；旧「C1–C5 必要耦合」删除，改为联合身份判据（§4 L114 用法）+ 5 条 `[inference]` 逐对假说（各带反证） |
| 正例 + 强反例 | 卡只有同域自查 | 跨场景正例 + 图标族正例；[counterexamples.md](counterexamples.md) 3 条 [inference]：机制撤去 / 关系反转 / 内容泄漏反证 |

## 3. 回退与状态（关键，不得夸大）

- **回退契约**：staging-only 草案；[klimt.md](../../modules/klimt.md) 在集成写者写入 §8.1b 之前**保持无 §8.1b**(`card_has_81b=false`)。若草案未采纳或集成未发生，卡退回只有 §8.1/§8.2/§4：仍可在默认题材域内自查，但**不获得**跨场景路由能力，也不解决两口径张力。不得把「草案已写」记成「卡已具备 §8.1b」。
- **草案非实测结论**：正例与反例都只是 `[inference]` 纸面推演；关系是否被真实渲染器复现、有无预注册 E4，本 lane 一概未做（02-EXECUTION-PLAN Lane C）。克里姆特 §4/§8.2 的阈值仍是 `[归纳]`、分母＝假想参考帧，不升格为 validated。

- **独立审阅**：`receipt.json` status=`submitted`、`review: null`、`human_review.status: not_applicable`；作者不自接受。 [STYLE-klimt]
