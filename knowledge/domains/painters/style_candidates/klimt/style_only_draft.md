## 1. 默认题材泄漏的剥离

dossier §8.1 正向段把「克里姆特」强绑定在一组**内容对象**上，本段逐项降级为关系量：

| §8.1 内容词 | 为什么不是风格前提 | 本段处理 |
|---|---|---|
| `gold/silver/platinum leaf / 《吻》/《阿黛尔 I》` | 金属箔与作品名是内容；关系量是金属区≥30%、亮度动态范围≥40%、箔块边界≥3处、平滑渐变金属≤5% | 保留 §8.2-1，删箔材与作品名 |
| `spirals / eye motifs / checkerboards / embrace / femme fatale` | 纹样母题与象征题材是内容；关系量是单元集{螺旋/圆/眼/方块/三角/十字/花点}、尺度2–15%短边、重复周期≥3 | 保留 §8.2-6 |
| `realistically modelled faces and hands / tree of life` | 面孔与寓言母题是内容；关系量是面孔:图案局部方差比≥2.0、面孔连续体积梯度≥3段 | 保留 §8.2-4 |

**迁移判据（已收窄）**：换掉全部题材专名与体裁词后，§8.2 的 7 条里**只**有「可原样转移到无语义输入的形式子集」（见 §2 末）能在无人物/文字的纯几何图上逐帧计算；带语义前提的规则在无对应内容时必须标**不适用/未知**，不得记通过。「语义专名不迁」≠「语义前提不迁」。

> **克里姆特 特有的规则内张力（登记，不消歧）**：§8.2-2 L238「纹样区明度动态≥10%（默认）/≥15%（强档）；≤5%越界、5–10%灰区」与 §4 P2 边界注 L92 同尺；本段把「灰区记警告、不得单独用于区分两人」写成显式取值，不擅自把 5–10% 并入 ≥10%。

**可原样转移的形式子集（对无人物/文字的几何输入仍可定义）**：R1（镜面掩膜、亮度动态范围、箔块边界——量金属材质本身即可算）；R2（A_p、纹样区明度动态范围）；R3 的可判定核心（镜面高光聚类、两簇分离度——类别名「写实皮肤」需语义认出，仅聚类量可算）；R5（透视线/消失点检测、投影阴影面积）；R6（图案单元分类、尺度、自相关周期）。

**仍带语义前提、不能记「内容全换仍可算」的规则**：R4——「面孔+手区」局部方差比需要认出面孔/手，无人物时**不适用**（不能记通过）；R7 的「主体（人物/树/死亡）包围盒 ≥60%」分项需要识别主体，无内容时该分项**不适用/未知**（宽高比与静止段分项仍可算）。

**替代规则（项目提案，不等价，新 ID）**：若要给纯几何/无人物输入覆盖 R4 的「渲染落差」，必须另立新 ID 并声明**不等价**：**R4′（提案，不等价于 R4）**：图案区 vs 非图案区局部方差比 ≥2.0、图案区同向梯度段 ≥3——去掉「面孔+手」前提；**不等价**于 R4，不能沿用 R4 宣称通过。R4′ 为项目工程假说 `[inference]`，未实测、未渲染，本版不拟完整判据；R4 在无人物输入上维持**不适用**。


**组合条件（旧「五条必要耦合」已校准）**：

旧版 C1–C5 对五对耦合统一写同一句「拆开会破——vs 马蒂斯…」（uniqJust=1），**不是逐对论证，也无 §4 支持**，已删除；可复核反证：R5（透视线）与 R1（金属掩膜）可分别判定——去掉金属要求后消失点检测仍可算，去掉平面化要求后金属统计仍可算，故「计算上不可分」不成立。

**有来源的联合身份判据（准确引用 §4 L114 用法）**：P1/P3/P4 定「是不是克里姆特（vs 马蒂斯）」——判分按三参数联合；P2/P5 定「图案与写实如何对撞」；P6 定「装饰画 vs 寓言画」。这是「联合出现有助身份区分」，不是「五对数学上无法拆分」。

**逐对假说（标 `[inference]`，各带可推翻反证）**：
- **H-C1 ⟨R1∧R3⟩**：两规则共享镜面掩膜（R3 的金属高光聚类以 R1 的金属区簇为输入），联合判定可能提高 vs 马蒂斯的区分度。**反证**：无金属区、仅颜料/平涂两簇分离度 ≥1.5 的图，R3 仍可独立判定 → 非不可分，`[inference]`。
- **H-C2 ⟨R2∧R4⟩**：两规则共享「图案区」掩膜（R2 定纹样区、R4 取图案区局部方差），联合判定可能更稳。**反证**：面孔+手 vs 非图案区的方差比 ≥2.0 在 A_p 弱档（≤5%）画面上仍可判 → `[inference]`。
- **H-C3 ⟨R3∧R5⟩**：材质对比 × 平面化同现可能对应「装饰表面」族征。**反证**：金属/颜料分离度 1.8（R3 pass）但存在 ≥3 条透视线收敛（R5 fail）的图，两规则分别可判 → `[inference]`。
- **H-C4 ⟨R4∧R6⟩**：写实-装饰落差 × 图案词汇尺度同现可能提高识别度。**反证**：单元尺度 8%、自相关峰值 3（R6 pass）但面孔与图案同一处理等级（R4 fail）的图，R6 仍可判定 → `[inference]`。
- **H-C5 ⟨R1∧R2⟩**：金属覆盖 × 带材质图案密度同现可能提高 vs 马蒂斯 P4 域的区分度。**反证**：金属区 ≥50%（强档）但纹样区明度动态 ≤5%（R2 越界）的图，R1 仍可判定 → `[inference]`。

> 以上 H-C* 均为项目工程假说 `[inference]`，各带能推翻它的纸面情形；不得写成「拆开无法判定」的必要性结论，也不并入 receipt 的 supported observation（见 §6）。

## 3. 正例（跨场景，逐帧可自查）

**正例 1 — 抽象材质板（无题材专名，纸面规格）** `[inference]`

输入（完整、可逐项判定）：无人物、无面孔/手、无文字；金属区 35%、P95−P5=50、箔块边界 4 处、平滑金 4%；纹样 A_p=25%、纹样内明度动态 12%；镜面高光聚类 3 簇、金属 ≥15%/颜料 ≤5%、分离度 1.8；消失点 0、投影 0.5%；螺旋/圆/方块单元尺度 8% 短边、自相关峰值 3；宽高比 1.0、静止段 ≥3 个/10 秒。

| 规则 | 适用性 | 结果 | 依据 |
|---|---|---|---|
| R1 | 适用 | pass | 35%≥30%、50≥40、4≥3、4%≤5%（§8.2-1） |
| R2 | 适用 | pass | A_p 25% 中档、明度动态 12%≥10%（§8.2-2） |
| R3 | 适用（聚类量） | pass | 3 簇 ≥2、金属/颜料阈值达标、分离度 1.8≥1.5；类别名「写实皮肤」无承载，仅按聚类量计 |
| R4 | **不适用** | 未知/不计通过 | 无面孔/手，方差比与连续梯度无承载 |
| R5 | 适用 | pass | 消失点 0、投影 0.5%≤1% |
| R6 | 适用 | pass | 单元在允许集内、8%∈[2%,15%]、周期 3≥3 |
| R7 | 部分适用 | pass（形式分项） | 宽高比 1.0∈[0.8,1.25]✓、静止段✓；主体包围盒分项**不适用/未知**（无主体可识别） |

结论：该正例**只**在形式子集 R1/R2/R3/R5/R6（R7 形式分项）上逐项可判定并 pass；R4 标**不适用**。不再写「内容全换仍七条全通过」。阈值沿用 `[归纳]` 未实测、本例仅 `[inference]` 纸面输入，不渲染。

**正例 2 — 含人物/面孔的同域稿** `[inference]`：若输入含写实面孔+手（局部方差比 ≥2.0、连续梯度 ≥3 可界定）与可识别主体（包围盒 ≥60%），则 R4 与 R7 主体分项**适用**；R1/R2/R3/R5/R6 同正例 1。此例说明**带语义内容的场景**才能覆盖七条，与正例 1 是「适用集合不同」，不是「内容换掉仍全通过」。

## 5. 适用 / 不适用条件

**适用**：
1. 平面/纹样板/UI装饰系统（镜面掩膜+局部方差+材质聚类+自相关可逐帧查）
2. 需带材质图案（纹样内明度≥10%）+金属层的版式
3. 写实区×装饰区高落差的图标族
4. 近方形、静止段≥3个/10秒的输出

**不适用**：
1. 需平涂纯色/剪纸硬边（破 R2/R3，越界马蒂斯）
2. 需纹样内明度≤5%（破 R2，越界马蒂斯 P4 域）
3. 需面孔与图案同一渲染等级（破 R4，§4 P5 弱档）
4. 需线性透视/投射阴影>1%（破 R5）
5. 需CG金属shader/平滑渐变金（破 R1，§8.1 负向）

**组合预检（沿用 dossier）**：vs 马蒂斯（§3.1 边界注见 §4 P2 L92、§8.2 规则2：带材质图案 ≥10%明度动态 vs 平涂纯色 ≤5%；分工条款见档案头部 L6 与 §4 P4 边界注）；按 [conflicts.md](../../../../cross/conflicts.md) 预检，冲突轴单主（N3），不得双开标志机制。
