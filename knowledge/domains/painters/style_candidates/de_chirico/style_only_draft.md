### 2.2 可原样转移的形式子集（对无语义输入的几何输入仍可定义）

仅以下量**不依赖「认出人物 / 面孔 / 文字 / 事件 / 器物 / 材质」这一语义前提**，可在纯色块 / 线 / 面积 / 直方图 / 连通域 / 方向场上逐帧计算：
- **R1**（超长投影：投影长度 ÷ 源高 ≥2.5 / 过渡带 ≤2px / 方向主峰 ±5° 内 ≥80%）；
- **R5**（色域与平涂：色相簇 ≤8 / 四族 ≥60% / 平均 S ≤0.45 / 块内明度 σ ≤6%）；
- **R6**（硬边：边界过渡带中位数 ≤2px / 无 ≥8px 羽化 / 影块边数 ≤6）；
- **R7**（静默（动画附加）：帧间差 ≤1% / 相机固定 / 运动 ≤0.5%/s）；
- **R8**（舞台构成：前区空 ≥25% / 画中框 ≥1 / 中轴偏移 ≤1/6 画宽）；

其余规则的阈值文字含语义承载（见 §2.3），**不得**因「删掉题材专名」就宣称在无语义输入上仍逐条可算。

## 6. 适用 / 不适用条件

**适用**：
