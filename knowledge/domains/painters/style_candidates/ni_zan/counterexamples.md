# 风格级强反例 — `ni_zan` [inference]

> 以下 3 例是七规则卡的纸面反证：不画一笔、不调生成通道、不跑 E4。逐条写明撤去/反转操作、失效关系与 §8.2 行号；一河两岸的题材词全部留着，只换承载它的结构关系。

<a id="db-source-line-5"></a>
## CE-NZ1 — 撤去纸色水面：把淡墨留白换浓墨湿墨满构图

**操作**：题材全保留(近岸坡石/数树/空亭/远山一线/长题)，只把「纸色承担水面与天空」换成浓墨湿墨块、彩设色、水面波纹倒影、天空渲染。**被破坏的规则**：R1(§8.2-1 L227 水面带内纸色≥85%)直接 fail；R2(§8.2-2 L228 全幅纸色≥40%、天空σ≤2%)→渲染；R3(§8.2-3 L229 彩像素≤1%、中位灰度≥60%)→设色浓墨；连带破 C1/C2。**为何是风格级反例**：只换「空间由什么承担」这一关系，证明 ni_zan 身份轴是三段式纸色×淡墨(C1/C2)，不是「画的是不是山水亭树」。对应 §8.1 负向 L211–216。

<a id="db-source-line-9"></a>
## CE-NZ2 — 反转笔法：保留留白但换圆笔披麻并加人物

**操作**：保留三段分带、纸色留白、淡墨近单色；把 ≥60° 折角线段换成圆笔披麻/雨点簇，并加人物、风线、水波位移。**被破坏的规则**：R4(§8.2-4 L230 折角比≥50%、组线≥3)→圆笔；R6(§8.2-6 L232 人形=0)→人物>0；R7(§8.2-7 L233 光流≤0.5%/帧)→风线水波；拆 C2/C3。**为何是风格级反例**：留白与淡墨全在、题材全在，风格仍不成立——反驳「认出留白+淡墨就是倪瓒」；证明「方折带状」是线段角度关系。对应 §3.1 vs 塞尚/董巨。

<a id="db-source-line-13"></a>
## CE-NZ3 — 内容泄漏反证：把逸气/荒寒/元四家品题升为必要条件

**操作**：不改任何像素，只在集成时把 §8.1 的 `Chinese literati ink landscape / 荒寒空寂 / 逸笔草草 / 容膝斋长题` 写成 §8.1b 无条件前提。**后果**：抽象三段式留白版式与极简 UI 分带会被误判「不像倪瓒」，而 §8.2 的 7 条统计量本不依赖任何品题或朝代。**结论**：审美品题、朝代、长题内容是题材档位(§5 自述按操作陈述使用，不冒充内心)，不是风格前提；本反例破的是规则写法，不是像素。
