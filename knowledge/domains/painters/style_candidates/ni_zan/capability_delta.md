## 1. 无 §8.1b 时，卡能做什么 / 不能做什么

现有卡：视觉指纹要点、§8.1 图像 prompt（**正向段把 倪瓒 默认题材专名写死为题材**）、§8.2 逐帧规则、§4 六参数、冲突注记。

- **能做**：在「一河两岸极简山水」**默认题材域**内，用 §8.2 的 7 条(覆盖率曲线、纸色面积+σ、彩像素/灰度/灰阶、折角线段+组夹角、树实例/倾角、人形计数、帧间光流)自查 `_extract.py --check` 所校验的 §8.1/§8.2/§4 逐字一致(AUDIT-ni_zan 记录 §8.1b 被排除在逐字比对之外)。注意本卡 §8.2 为 **7 条**(非 8 条)，§4 为六参数。
- **不能做**：**跨场景路由**。把「三段式纸色留白 + 淡墨近单色 + 折带方折 + 疏林/空亭计数 + 静态」迁到抽象分带版式、极简 UI、留白海报时，§8.1 正向段会强制带回倪瓒专名、元四家品题、荒寒空寂阐释与「逸笔草草」自述，把内容对象当风格前提 → 01-AUDIT.md A06 所指「有模块/能抽取/已做纯风格迁移」混淆。
- ****本卡特有的未消歧张力(AUDIT-ni_zan 登记)**：§8.2-2「全幅纸色≥40%」× §3.1「与八大山人留白≥55%(默认60–70%)同侧、55–60% 重叠区组合取交集」——两卡留白同侧但分母不同；§4 P1 强档「水面≥45%」× §8.2-1「水面带 25–45%」为档位/规则两写。无 §8.1b 时卡没有「≥40% 是本卡独立下限、P1 是档位开关」的写法，跨场景路由易把两卡留白口径误当同一阈值。**

## 2. §8.1b 草案新增的跨场景路由能力

| 增量 | 无 §8.1b 的卡 | 本 §8.1b 草案 |
|---|---|---|
| 介质/语义无关的关系量 | §8.1 绑定倪瓒专名/元四家/逸气/荒寒空寂 | 拆成 R1–R7：分带覆盖率/水面占比/纸色、纸色面积/σ、彩像素/灰度/灰阶、折角比/组夹角、树数/倾角/叶点、人形计数/空舟、光流/墨差——全是覆盖率/灰度/角度/计数统计量 |
| 默认题材泄漏剥离表 | 无 | §1 表把画家名/朝代/文人画体裁、亭树远山器物、审美品题、书法印章内容、皴法材料专名逐项降级；给迁移判据：撤专名后 §8.2 自查仍可算 = 纯风格；P6 款题只留**面积/档位层** |
| 张力显式化 | 卡内两卡留白口径/P1 两写未处理 | §1 注把 ≥40% 写成**本卡独立下限**、55–60% 重叠区标「组合取交集、须显式取值」、P1 强档标档位开关；C1–C5 列出 ⟨三段式×纸色留白⟩、⟨淡墨×折带⟩、⟨疏林×人物零⟩、⟨纸色水面×静态⟩、⟨款题层×彩像素⟩ |
| 正例 + 强反例 | 卡只有同域自查六问 | 抽象三段式留白版式正例(七条全可算，无需认出山水)+ 极简 UI 分带正例；[counterexamples.md](counterexamples.md) 3 条 [inference]：撤纸色改浓墨满构图 / 保留留白改圆笔加人物 / 内容泄漏反证 |
| 适用/不适用 + 组合预检 | 散落在负向段 | 列 6 类不适用(彩色、浓墨湿墨、人物叙事、形体几何化、纯色块、深透视)+ §3.1 四条分工/C-09 预检 |
