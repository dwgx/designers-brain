# 风格级强反例 — `mucha` [inference]

> 本页 3 例全部停在纸面：不渲染像素、不接图像通道、不做 E4 实测。每例写明撤去或反转的具体机制、被破的 R-ID 与 慕夏 dossier §8.2 原文行；默认题材对象一律保留，用来证伪「题材齐备即风格成立」。

<a id="db-source-line-5"></a>
## CE-MUC1 撤去核心机制：把「印刷平涂面+字画一体」改成金箔镜面/箔块/纹

**操作**：把「印刷平涂面+字画一体」改成金箔镜面/箔块/纹理明度≥10%的图案区+写实面孔×装饰高落差对撞；曲线族保留。 **被破坏的规则**：R8(§8.2-8 L236 帧内出现金属镜面/箔块→越界克里姆特域)fail；R4(§8.2-4 L232 饱和色≤15%、主色相≤5、渐变≤5%)被金属光泽打散；R2(§8.2-2 L230 环线与面部不重叠)被写实面孔对撞取代；拆 C2/C5。对应 §3.1 L77–81。 **为何是风格级反例**：只换一组可迁移关系而不改题材，证明 慕夏 身份轴是统计量耦合、不是「画的是不是默认题材」；对应 §4 越界警报与 §3.1 分工条款。 [STYLE-mucha[inference]]
<a id="db-source-line-8"></a>
## CE-MUC2 反转关系档：保留曲线族与光环，只把「排版文字≥1区、曲线骨架

**操作**：保留曲线族与光环，只把「排版文字≥1区、曲线骨架」去掉，改成无文字、无曲线骨架的平涂纯色图案块。 **被破坏的规则**：R1(§8.2-1 L229 曲率连续、线宽族≤3档、直线≤5%)被纯色块取消；R5(§8.2-5 L233 花叶母题≥3处、主轴与附着切线夹角≤30°)失去曲线附着；R6(§8.2-6 L234 排版文字≥1区、字体曲率同族)fail；拆 C1/C4。对应 §4 越界 L100、§3.1 L82 vs 马蒂斯。 **为何是风格级反例**：题材与色/光统计全在、关系仍不成立——反驳「认出默认题材就是 慕夏」；对应 §4 越界警报与 §3.1 分工条款。 [STYLE-mucha[inference]]

## CE-MUC3 内容泄漏反证：把默认题材升为 §8.1b 必要条件

**操作**：不改任何像素，只在集成时把 §8.1 正向段的「新艺术运动石版海报 / 曲线族与字画一体 / 装饰板」与相关器物/体裁专名写成 §8.1b 无条件前提。 **被破坏的规则**：后果：跨场景正例（抽象/图标族）会被误判「不像慕夏」，而 §8.2 的 8 条统计量本不依赖任何题材专名。 **为何是风格级反例**：结论：默认题材是 R 表计数/档位的内容基底，不是风格前提；本反例破的是规则写法，不是像素。 [STYLE-mucha[inference]]
