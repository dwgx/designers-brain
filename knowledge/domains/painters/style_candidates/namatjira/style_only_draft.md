## 1. 默认题材泄漏的剥离

dossier §8.1 正向段把「纳马吉拉」强绑定在一组**内容对象**上，本段逐项降级为关系量：

| §8.1 内容词 | 为什么不是风格前提 | 本段处理 |
|---|---|---|
| `Central Australian / Hermannsburg School / named country, held in stillness` | 地名、画派名与「乡国」神圣语义是文化内容，不是像素关系；且涉 ICIP 伦理 | 删除专名与「named country」措辞，保留 §8.2-1「远景带 vs 前景带 ΔH≥25°(向蓝紫)」的**分带色相位移**关系(R1)；文化伦理转为 R8 合规清单 |
| `ghost gums / Glen Helen / Standley Chasm / Mount Sonder / MacDonnell Ranges` | 具体树/峡谷/山系是题材器物；关系量是「≥1 株近垂直白干(值≥85%、干宽≤4%画幅、分叉≥2)」或「山体剪影轮廓可辨」 | 改写为 R4 的**连通域明度筛选 + 形状检查**，不要求认出 ghost gum 或任何地点 |
| `red-brown ridges / ochre reds, earth yellows, violet greys, deep blues, paper white` | 颜料/土色清单是内容；关系量是「同屏色相簇≤7 + 饱和均值≤55%/峰值≤75% + 互补对撞≤10%」 | 保留 §8.2-3 的**色相聚类 + 直方图统计**(R3)，删土色清单 |
| `the land itself is the portrait / sacred or ceremonial motifs` | 「土地即肖像」是阐释、神圣仪式图式是禁忌内容，不是可判定关系 | 删除；R8 明写「神圣/仪式专属元素 0 个、人物 0–2 且非仪式、无签名/品牌」为**清单对照 + OCR**合规项 |
| `transparent watercolour over faint graphite underdrawing / matte paper` | 材料史是完成度标签；可判定的是「岩面/山体每块≥3 明度台阶(步长≤12%/级)、无单色平涂大块」 | 改写为 R6 的**明度分层计数 + 边缘图**，不要求「水彩纸/石墨底稿」叙事 |

**迁移判据**：迁移判据：换掉全部中部澳大利亚地名、画派名与「乡国/圣地」语义后，§8.2 的 8 条自查（分带色相直方图+ΔH、水平边缘检测+带划分、色相聚类、连通域明度筛选+形状、分块明度/纹理、明度分层计数、帧差+调制曲线、清单对照+OCR）仍可逐帧计算 → 纯风格。按此判据 R1/R2/R3/R4/R5/R6/R7/R8 全可迁；R8 是**伦理验收层**(本模块特有)，不迁「文化归属」语义、只迁清单零命中。

> **namatjira 特有的伦理/规则双重张力（登记，不消歧）**：§8.2-8 L248 是「文化合规检查」(神圣/仪式元素 0 个、无冒充署名)——它不是视觉关系而是**验收护栏**；§4 P4 L105 弱档「阴影平涂(无受光逻辑)」× §8.2-6 L246「每块≥3 明度台阶、无单色平涂大块」为同一「平涂 vs 分层」的档位/统计量两写。本段把 R8 单列为**伦理层(不进风格判定、但不可删)**，把 P4 弱档标为「单侧受光未启用的峡谷档、须显式取值」，不擅自消歧；版权期至 2029-08-08 与 ICIP 风险随模块分发(§8.1 L233)，本 lane 不越权改伦理条款。

## 2. 可迁移视觉关系（参数 · 单位 · 范围 · 必要耦合）— 纳马吉拉 关系族；全部 `[归纳] 未实测` [STYLE-namatjira]

| ID | 可迁移关系 | 单位 / 范围 `[归纳]` | 源行 |
|---|---|---|---|
| R1 | **远山色相位移**：远景带(上1/3山体区)平均色相 vs 前景带位移≥25°(向蓝紫)；明度对比逐带递减 | 分带 ΔH(≥25°)、对比(逐带递减) | §8.2-1 L241；§4 P1 L102 |
| R2 | **高地平线层带**：地平线位于画高35–60%(自上而下)；层带≥3(前景/中景/远景)；天空带≤40% | 地平线(0.35–0.60)、层带(≥3)、天空(≤0.40) | §8.2-2 L242；§4 P5 L106 |
| R3 | **土色系色数预算**：同屏色相簇≤7；饱和均值≤55%、峰值≤75%；互补色对撞面积≤10% | 色相簇(≤7)、饱和均值(≤0.55)、峰值(≤0.75)、对撞(≤0.10) | §8.2-3 L243 |
| R4 | **白干桉/山体剪影(择一)**：树档≥1 株近垂直白干(值≥85%、干宽≤4%画幅、分叉≥2)；非树档允许0株但须山体剪影轮廓可辨 | 白干值(≥0.85)、干宽(≤0.04)、分叉(≥2) | §8.2-4 L244；§4 P2 L103 |
| R5 | **天空空场**：天空区域≥20%画幅；云覆盖≤15%；无事件性云型(积雨云/风暴云纹理) | 天空(≥0.20)、云(≤0.15)、事件云(=0) | §8.2-5 L245；§4 P3 L104 |
| R6 | **分层罩染可见度**：岩面/山体每块≥3 明度台阶(步长≤12%/级)；无单色平涂大块；可选底稿线残留 | 台阶(≥3)、步长(≤0.12/级) | §8.2-6 L246；§4 P6 L107 |
| R7 | **静场运动预算**：视频档无天气运动；仅≤1%/s 光色慢调制；帧间差≤1.5%；无溶解/位移 | 调制(≤0.01/s)、帧间差(≤0.015) | §8.2-7 L247 |
| R8 | **文化合规(伦理层,不进风格判定)**：神圣/仪式专属元素0个；人物0–2且非仪式；无文字/签名/品牌；无冒充署名 | 神圣元素(=0)、人物(0–2) | §8.2-8 L248；§8.1 伦理护栏 L233 |

**必要耦合（拆开会破，`[归纳]`）**：

- **C1 ⟨R1∧R2⟩「远山位移 × 高地平线」**：这两条是 §4 L109 明写的「是不是纳马吉拉」双判据：色相位移(R1)必须挂在层带(R2 ≥3 带)上才有「逐带递减」的载体；若改低地平线海报式日落(天空≥1/2)，层带压缩消失、ΔH 失去分带 → §4 P5 弱档、§8.1 越界警报。
- **C2 ⟨R3∧R6⟩「土色预算 × 分层罩染」**：色相簇≤7(R3)给分层罩染(R6 ≥3 明度台阶/块)一个窄色域；若引入饱和互补对撞/霓虹，分层台阶被高纯色块压平 → §8.1 负向 `saturated complementary-contrast pairs, neon colours`。
- **C3 ⟨R5∧R7⟩「天空空场 × 静场运动」**：云≤15%的空场(R5)与帧间差≤1.5%的静场(R7)共同排除「事件光色」；若出现风暴/浪/蒸汽/边缘溶解，两者同破 → §4 L111 分工注、§8.1 越界警报(vs 透纳)。
- **C4 ⟨R4∧R2⟩「剪影择一 × 层带」**：白干桉近垂直白干或山体剪影(R4)是前景层带(R2)的锚点；树肖像档(P2→90%)把单株裁切到前景，全景档(P2低)靠山体剪影——两者都须仍在 ≥3 层带内，不是「有没有树」的内容事实。
- **C5 ⟨R8∧全体⟩「伦理层不可删」**：R8 不是视觉关系但随模块分发：撤掉「神圣/仪式元素0、无冒充署名、版权期至2029」的合规项，即使 R1–R7 全成立也不得记为合格产出(§8.1 L233 文化伦理护栏)。这是本模块特有的验收耦合，不迁文化归属语义。

## 3. 正例（跨场景，逐帧可自查）

**正例 1 — 抽象分带色阶图（无澳洲地名、无树肖像专名）**：三层带自上而下：远景带色相向蓝紫位移 28°、明度对比逐带递减(R1)；地平线 45% 画高、3 层带、天空 35%(R2)；色相簇 6、饱和均值 48%/峰值 70%、互补对撞 6%(R3)；前景一近垂直白干值 88%、干宽 3%、分叉 2(R4)；天空云 10%、无积雨云纹理(R5)；山体每块 4 个明度台阶、步长 10%(R6)；定格帧、帧间差 0.8%、光色调制 0.5%/s(R7)；合规清单零命中、OCR 无签名(R8)。八条全是分带色相/带划分/聚类/连通域/帧差/OCR 统计量，无需认出 ghost gum 或任何乡国。

**正例 2 — UI 分层渐变背景 / 数据带（内容全换）**：高地平线层带 + 远山蓝紫位移 + 土色窄预算 + 空场天空 + 分层台阶 + 静场。R1–R8 仍逐条可算；仅声明视觉关系可迁，不声称任何生成通道已产出、不声称 E4 通过；伦理层 R8 仍须零命中。

## 4. 强反例（题材全对但风格不成立）

**强反例 1 — 题材全对但换成事件光色**：画出红土山系、白干桉、高地平线、空场天空(题材齐备)，但把「地点常态光」换成透纳式风暴/蒸汽/边缘溶解/大气混沌 → 破 R5(事件云型)、R7(帧间差>1.5%)、拆 C3；§8.1 越界警报(vs 透纳)即此。**题材齐全≠风格成立**。

**强反例 2 — 保留色板但改湿润农事云型**：题材不变，把空场天空换成康斯泰勃尔式云型系统研究(云占≥40%)、加树篱/田畴/风车/农事人物 → 破 R5(云>15%)、R2(层带被农事元素打散)、R8(人物仪式/语义风险)；§8.1 越界警报(vs 康斯泰勃尔)。

**强反例 3 — 内容泄漏反证**：把「必须是中部澳大利亚/赫尔曼斯堡/乡国圣地/白干桉树肖像」写进 §8.1b 必要条件 → 抽象分带色阶图与 UI 数据带会被误判「不像纳马吉拉」；且把文化归属写成风格前提会触 §8.1 L233 ICIP 伦理护栏。地名/圣地是题材档位，不是风格前提。

## 5. 适用 / 不适用条件

**适用**：① 分带/渐变/层带类输出(ΔH+带划分+色相聚类可逐帧查)；② 需「远山蓝紫位移 + 高地平线」的信息图/背景；③ 需静场光色慢调制的渲染通道；④ 与康斯泰勃尔/透纳显式分区后的组合(§8.1 L234)。

**不适用**：① 需湿润农事景观/云型系统研究(破 R5/R2，越界康斯泰勃尔)；② 需风暴/浪/蒸汽/边缘溶解(破 R5/R7，越界透纳)；③ 需饱和互补对撞/霓虹(破 R3，越界平面档)；④ 需单色平涂大块/厚涂(破 R6，§8.1 负向 opaque gouache)；⑤ 需神圣/仪式专属图式或冒充署名(破 R8，伦理禁止)；⑥ 与恩格瓦雷默认不组合(§8.1 L234)。

**组合预检（沿用 dossier）**：§4 L111 分工注(vs 康斯泰勃尔/透纳禁止同档)；§8.1 越界警报 L231–232；文化伦理护栏 L233(版权期 2029-08-08、ICIP 风险、Namatjira Legacy Trust)；C-09(运动预算静场侧)、C-06(饱和低侧)。
