# 风格级强反例 — `namatjira` [inference]

> 这里 3 例只做纸面判定：零渲染、零通道、零 E4，且 R8 伦理层在每例中仍须零命中。每例记录改动、破掉的 R-ID 与纳马吉拉 §8.2 行；红土山系/白干桉等题材词原样保留。

<a id="db-source-line-5"></a>
## CE-N1 — 撤去静场：把地点常态光换成透纳式事件光色

**操作**：题材全保留(红土山系/白干桉/高地平线/空场)，只把「地点的常态光」换成风暴/浪/蒸汽/速度/边缘溶解/大气混沌。**被破坏的规则**：R5(§8.2-5 L245 云≤15%、无事件性云型)直接 fail；R7(§8.2-7 L247 帧间差≤1.5%、无溶解/位移)→事件运动；连带破 C3。**为何是风格级反例**：只换「光是不是事件」这一关系，证明 namatjira 身份轴是空场×静场(C3)，不是「画的是不是澳洲红土」。对应 §4 L111 分工注、§8.1 越界警报(vs 透纳)。

<a id="db-source-line-9"></a>
## CE-N2 — 反转天空：保留色板但换康斯泰勃尔云型系统

**操作**：保留远山蓝紫位移、高地平线层带、土色窄预算、分层罩染；把空场天空换成云占≥40% 的成体系云型研究，并加树篱/田畴/风车/农事人物。**被破坏的规则**：R5(§8.2-5 L245)→云>15%；R2(§8.2-2 L242 层带≥3、天空≤40%)→农事元素打散层带；R8(§8.2-8 L248 人物0–2且非仪式)→语义风险；拆 C1/C3。**为何是风格级反例**：色板与层带全在、题材全在，风格仍不成立——反驳「认出土色+远山紫就是纳马吉拉」；证明「空场」是面积关系。对应 §8.1 越界警报(vs 康斯泰勃尔)。

<a id="db-source-line-13"></a>
## CE-N3 — 内容/伦理泄漏反证：把乡国圣地与树肖像升为必要条件

**操作**：不改任何像素，只在集成时把 §8.1 的 `named country / sacred sites / ghost gum portrait / Hermannsburg` 写成 §8.1b 无条件前提。**后果**：抽象分带色阶图与 UI 数据带会被误判「不像纳马吉拉」；更严重的是把文化归属写成风格前提会触 §8.1 L233 的 ICIP 伦理护栏(不得宣称为原住民文化表达、版权期至 2029)。**结论**：地名/圣地/树专名是题材档位，R8 合规层才是随模块分发的硬项；本反例破的是规则写法与伦理，不是像素。
