# 风格级强反例 — `behzad` [inference]

> 本页 3 例全部停在纸面：不渲染像素、不接图像通道、不做 E4 实测。每例写明撤去或反转的具体机制、被破的 R-ID 与 贝赫扎德 dossier §8.2 原文行；默认题材对象一律保留，用来证伪「题材齐备即风格成立」。

<a id="db-source-line-5"></a>
## CE-BEH1 撤去核心机制：把「无消失点」改成单点透视汇聚线（≥3 条线共点

**操作**：把「无消失点」改成单点透视汇聚线（≥3 条线共点）；题材、微书、金点、文本全保留。 **被破坏的规则**：R1(§8.2-1 L202 消失点检验=0组汇聚线)直接 fail；R3(§8.2-3 L204 人物高度方差≤15%)→纵深缩放回流；连带破 C1/C3。 **为何是风格级反例**：只换一组可迁移关系而不改题材，证明 贝赫扎德 身份轴是统计量耦合、不是「画的是不是默认题材」；对应 §4 越界警报与 §3.1 分工条款。 [STYLE-behzad[inference]]
<a id="db-source-line-8"></a>
## CE-BEH2 反转关系档：版面全保留，只把「金只做点状、面积≤5%」升成满

**操作**：版面全保留，只把「金只做点状、面积≤5%」升成满幅金饰，并把微书空场改成满幅纹样、人物姿态动势化。 **被破坏的规则**：R5(§8.2-5 L206 金面积≤5%、连通域≤7)fail；R4(§8.2-4 L205 保留≥1块≥10%未图案化空场)fail；R6(§8.2-6 L207 色相簇≤8、高饱和≤25%)被金饰挤破；拆 C2/C4。 **为何是风格级反例**：题材与色/光统计全在、关系仍不成立——反驳「认出默认题材就是 贝赫扎德」；对应 §4 越界警报与 §3.1 分工条款。 [STYLE-behzad[inference]]
<a id="db-source-line-11"></a>
## CE-BEH3 内容泄漏反证：把默认题材升为 §8.1b 必要条件

**操作**：不改任何像素，只在集成时把 §8.1 正向段的「帖木儿宫廷手抄本 / 赫拉特画派 / 波斯细密画叙事页」与相关器物/体裁专名写成 §8.1b 无条件前提。 **被破坏的规则**：后果：跨场景正例（抽象/图标族）会被误判「不像贝赫扎德」，而 §8.2 的 8 条统计量本不依赖任何题材专名。 **为何是风格级反例**：结论：默认题材是 R 表计数/档位的内容基底，不是风格前提；本反例破的是规则写法，不是像素。 [STYLE-behzad[inference]]
