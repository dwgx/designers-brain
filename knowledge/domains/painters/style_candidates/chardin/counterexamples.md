# 风格级强反例 — `chardin` [inference]

> 全部为**纸面推演 [inference]**，未渲染像素、未跑生成通道、未做 E4。每条给具体撤去/反转/保留操作，点名被破坏的 §8.1b 关系 ID 与 dossier §8.2 规则行。题材对象（铜锅、陶罐、面包、野味、水果、木桌、室内）全部保留，证明「题材齐备≠风格成立」。

<a id="db-source-line-5"></a>
## CE-C1 — 撤去纹理：把「30–80% 可辨触感」压成平滑不可见面

**操作**：全套静物题材保留；只把表面从「密集点触 + 层叠罩染、近看颜料」换成 levigated 平滑面、笔触不可见。

**被破坏的规则**：
- R1（§8.2-1 L203「可辨笔触纹理面积 30–80%、粒径 2–8px、方向峰值 ≤35%」）→ 覆盖≈0；
- R6（§8.2-6 L208「≥2 类材质各有专属表面处理」）→ 平滑面抹平材质差异，触发「一律同处理」禁令；
- R8（§8.2-8 L210「64×64 块内 L* 梯度 0.5–3、无大单色平滑区」）→ 大平滑区直接 fail；
- 连带破 C1（触感表面三件套）。
- 对应 §4 越界警报①「表面压平 → 越界**维米尔**」、§8.1 负向 `levigated flat paint`。

**为何是风格级反例**：只换表面纹理关系，未改任何器物；这正是 chardin 与维米尔最核心的分界，且**两者都画静物**——证明差别在关系而非题材。

<a id="db-source-line-18"></a>
## CE-C2 — 反转空间：把「浅空间中性场」改成深单点透视 + 地砖网格

**操作**：保留触感、反光、暖暗部、色板；把 §8.2-4 的「主体贴前缘 ≥50% 画幅、背景低细节、无网格」改成维米尔式几何网格 + 单点透视 + 背景可读细节。

**被破坏的规则**：
- R4（§8.2-4 L206「背景边缘密度 ≤ 前景 30%、主体 ≥50% 画幅、无地砖网格/单点透视网格」）→ 直接 fail（破 C3）；
- R2 的跨物反光因背景细节增多而失去「物体互为邻色」的封闭网络；
- 对应 §8.1 负向 `no aerial perspective haze`、`geometric faceting` 侧、§3.1 与维米尔判据①–⑤。

**为何是风格级反例**：只反转空间深度关系；证明「浅空间 × 密实表面」（C3）是纯构图/表面关系。

<a id="db-source-line-29"></a>
## CE-C3 — 保留色板撤掉形状：暖土低饱和 + 宽软高光还在，但撤掉跨物反光与暖暗部

**操作**：保留中位饱和 ≤0.45、赭/棕/灰绿主色、宽软高光形态（R5/R2 形态不动）；撤掉「≥2 处跨物色相偏移」，把暗部改成冷蓝平坦（H 200–250°）、纯黑比例放宽。

**被破坏的规则**：
- R2（§8.2-2 L204「跨物反光 ≥2 处（色相相关矩阵）」）→ 归零；
- R3（§8.2-3 L205「阴影色相暖 H20–60°/灰绿 60–120°、禁 200–250° 冷蓝主导、暗部 σ≥2/255」）→ 冷蓝平坦 fail；
- 连带破 C2（反光网络 × 暖暗部）。
- 对应 §4 越界警报①「冷调蓝阴影」、§8.1 自查③「暗部是否有暖色与层次」。

**为何是风格级反例**：色板与高光形态（最直观线索）全保留，风格仍不成立——反驳「认出暖褐静物色调就是夏尔丹」。

<a id="db-source-line-41"></a>
## CE-C4（内容泄漏反证）— 把「必须有 humble domestic objects / 铜锅面包」升为必要条件

**操作**：不改像素，只在集成时把 `copper cauldron / earthenware jug / loaf / game and fruit / 18th-century French still life` 写成 §8.1b 前提。

**后果**：[style_only_draft.md](style_only_draft.md) 正例 1（工业材质样张：拉丝金属/磨砂玻璃/颗粒陶）会被误判「不像夏尔丹」；§8.2 全部分母是「可辨纹理面积 / 高光连通域形态 / 色相簇 / 材质类数 / 帧间差」，没有一条要求认出器物；§3.1 边界注把人物档/门洞第二空间列为**可选**，§4 P5/P6 是构图与时期开关。

**结论**：静物器物是内容基底，不是风格前提；人物/花卉/风景内容对象同样不是。本反例破的是规则写法，不是像素。
