## 1. 默认题材泄漏的剥离

| §8.1 内容词 | 为什么不是风格前提 | 本段处理 |
|---|---|---|
| `copper cauldron / earthenware jug / glass bottle / loaf / game and fruit` | 器物清单是题材；可判读的是「≥2 类材质各有专属表面处理」的**材质对比关系** | 删除器物名，保留 §8.2-6 的材质类别数与表面统计 |
| `still life of humble domestic objects / 18th-century French` | 体裁与年代标签 | 删除；保留「浅空间 + 中性场 + 静止」的构图/时间关系 |
| `a red gleam of meat in the copper, the fruit echoed in the glass` | 具体互映对象是内容；关系量是「≥2 处跨物色相偏移」 | 改写为 §8.2-2 的「跨物反光 ≥2 处 + 色相相关矩阵」，不锁「肉红/果色」 |
| `absorbed figure … eyes lowered`（人物档） | 人物是可选档；§3.1 边界注把「门洞第二空间」列为可选 | 降为可选层，不进必要关系 |
| `the humble elevated / quiet suspended time` | 美学评价 | 删除；保留 §8.2-7「0 帧运动模糊 + 帧间差 ≤1%」的纯时间量 |

**迁移判据**：换掉全部器物名后，§8.2 的 8 条自查（高频能量图+梯度方向直方图、高光连通域形态+色相相关矩阵、直方图+阴影区统计、边缘密度分区+透视线检测、饱和度直方图+色相聚类、材质分区+局部表面统计、帧差图+光流、底色检测+边缘宽度）仍可逐帧算 → 纯风格。八条全可迁。

> **chardin 特有的表面档位**：§8.2-1 明写「可辨笔触纹理面积 30–80%（介于『不可见』与『全覆盖』之间）」——chardin 既不是「平滑不可见」（维米尔 levigated）也不是「全覆盖」（能量场），是**中间档**；方向直方图峰值 ≤35% 专门用来与塞尚的 4–8 角度族切开。AUDIT-chardin 为 A-92 闭环（Cochin/Diderot），0 处野外样本卡。

## 2. 可迁移视觉关系（参数 · 单位 · 范围 · 必要耦合）— 触感/反光/暖暗部/浅空间四族；全部 `[归纳] 未实测` [STYLE-chardin]

| ID | 可迁移关系 | 单位 / 范围 `[归纳]` | 源行 |
|---|---|---|---|
| R1 | **中间档可辨纹理**：全帧「可辨笔触纹理」面积 30–80%；粒径 2–8px（1080p 基准）；**禁统一方向角度族**（方向直方图峰值 ≤35%） | 面积(0.30–0.80)、粒径(2–8px)、方向峰值(≤0.35) | §8.2-1；§4 P1；C-05 |
| R2 | **宽软高光 + 跨物反光**：镜面高光连通域为宽软形（圆度 ≤0.7 或长宽比 ≥2；边缘过渡 σ ≥2px）；**禁 1–3px 点状系统**；跨物反光 ≥2 处 | 圆度(≤0.7)/长宽比(≥2)、σ(≥2px)、跨物处数(≥2) | §8.2-2；§4 P2；C-11 |
| R3 | **暖暗部 / 无纯黑**：纯黑（L*≤5）≤0.5%；阴影色相暖（H 20–60° 或灰绿 60–120°，**禁 200–250° 冷蓝主导**）；暗部内部亮度标准差 ≥2/255 | 纯黑(≤0.005)、阴影 H(20–120°)、暗部 σ(≥2/255) | §8.2-3；§4 P4；C-13 |
| R4 | **浅空间 / 中性场**：单一视点；背景为低细节区（边缘密度 ≤ 前景 30%）；主体贴前缘（包围盒 ≥50% 画幅）；**无地砖网格/单点透视网格** | 背景/前景边缘密度(≤0.30)、主体(≥0.50 画幅) | §8.2-4；§4 P5 |
| R5 | **暖土色预算**：全帧中位饱和 ≤0.45；高饱和（S≥0.6）≤8% 且集中于食物/织物/反光；色相簇 ≤8；主色暖土 | 中位饱和(≤0.45)、高饱和(≤0.08)、色相簇(≤8) | §8.2-5；C-12 |
| R6 | **材质专属表面**：同屏可辨材质 ≥2 类、各有专属处理（金属=宽软反光带；玻璃=透射+反光；颗粒=点触；瓷=温润渐变）；**禁两种材质共用同一处理**（防「一律点彩」） | 材质类(≥2)、共用处理(=0) | §8.2-6；§4 P3 |
| R7 | **静止**：全片 0 帧运动模糊；除反光/蒸汽微动（≤0.5% 像素）外帧间差 Δ ≤1% | 运动模糊帧(=0)、帧间差(≤0.01) | §8.2-7；C-08 |
| R8 | **完成度 / 密实表面**：裸露底子 ≤1%；无骨架线；边缘无硬线（过渡带 ≥2px）；单一 64×64 块内 L* 梯度幅值均值 ∈[0.5, 3]（无大单色平滑区） | 裸底(≤0.01)、边缘过渡(≥2px)、块内梯度(0.5–3) | §8.2-8；§4 P6 |

**必要耦合（拆开会破，`[归纳]`）**：

- **C1 ⟨R1 ∧ R6 ∧ R8⟩「触感表面三件套」**（§4 用法：P1 触感 + P2 反光网络，两条 ≥ 中档才成立）：R1 给纹理的**面积/粒径/方向**，R6 要求不同材质**用不同纹理**，R8 要求表面**密实无裸底无硬线**。若只保留 R1 的 30–80% 覆盖而撤掉 R6，会变成「全画一律点彩/一律同向排线」——§8.2-6 明令禁止，且 §4 越界警报②（塞尚 tache 方向族）会被误命中。
- **C2 ⟨R2 ∧ R3 ∧ R5⟩「反光网络 × 暖暗部」**：R2 的跨物反光要求「每物借邻物色」，这依赖 R3 的暖阴影（无纯黑、暗部有层次）与 R5 的暖土低饱和来传递色相；若把暗部改成冷蓝平坦（越界维米尔），跨物色相偏移无处附着，R2 的「色相相关矩阵」失效。§8.1 自查①③ 即此耦合的中文表述。
- **C3 ⟨R4 ∧ R8⟩「浅空间 × 密实表面」**：R4 的背景低细节（≤前景 30%）若被误做成「大块单色平滑区」，会直接撞 R8 的「64×64 块内 L* 梯度 ≥0.5」；两者合起来要求背景是**低细节但仍有微梯度**的中性半调场，不是平涂。
- **C4 ⟨P4 光质柔和 × R3⟩**：§4 P4 弱档 = 方向性硬光与锐投影（**越界警报：卡拉瓦乔档**）。硬光一引入，R3 的「暗部暖且 σ≥2/255」与 R8 的「边缘过渡 ≥2px」同时失效——所以 P4 ≥ 中档是本段所有明暗/表面关系成立的前提开关。
- **C5 ⟨P6 时期滑轨⟩**：§4 用法把 P6 定为「早期并置 ↔ 晚期揉合（**工作流参数**）」；早期档 R1↑/R8 局部、晚期档反光/透明/fondu 主导。P6 不改变 R1–R8 的存在，只改 `R1 与 R8 的权重`，不是内容前提。

## 3. 正例（跨场景，逐帧可自查）

**正例 1 — 工业产品微距 / 材质样张（无静物题材）**：三块不同材质样片（拉丝金属 / 磨砂玻璃 / 颗粒陶），可辨纹理占 55%、粒径 2–8px、方向峰值 28%（R1）；拉丝金属上一道宽软反光带（长宽比 2.5、σ=3px），玻璃里映出一点邻片暖色——跨物反光 2 处、无 1–3px 圆点（R2）；阴影暖褐、纯黑 0.2%、暗部 σ=3/255（R3）；主体贴前缘占 60% 画幅、背景中性半调低细节（边缘密度 = 前景 25%）、无网格（R4）；中位饱和 0.38、色相簇 6（R5）；金属/玻璃/陶三种专属处理、无共用（R6）；静帧、Δ=0.4%（R7）；裸底 0.5%、边缘过渡 3px、块内梯度 1.2（R8）。**八条自查全是频域/色相/连通域/帧差统计，无需认出「铜锅/面包」** → 纯风格成立。

**正例 2 — 无字 key visual（S-06 边界）**：一块暖土色密实表面 + 宽软互映高光 + 浅中性场 + 静止。R1–R8 仍逐条可算。仅声明关系可迁，不声称生成通道已产出、不声称 E4 通过。

## 4. 强反例（题材全对但风格不成立）

**强反例 1 — 保留全套静物题材、撤掉纹理**：铜锅/陶罐/面包/水果全在，但把表面压成 levigated 平滑面（R1 的 30–80% → ≈0）、高光改成 1–3px 点状 pointillés（R2 破）、冷调蓝阴影（R3 破）、加地砖网格（R4 破）。这正是 §4 越界警报①「表面压平、高光点状、冷调蓝阴影、地砖网格 → 越界**维米尔**」、§8.1 负向 `levigated flat paint / isolated pin-point highlights (pointillés)`。**题材齐全≠风格成立**——chardin 与维米尔的差别全在表面/高光关系，不在「画的是不是静物」。

**强反例 2 — 保留色板、撤掉形状/反光网络**：暖土低饱和色板不变，但撤掉跨物反光（各物孤立高光）、把方向笔触改成 4–8 角度族 tache + 多轮廓 + 裸露画布。破 R2（跨物 ≥2 失效）、R1（方向峰值 ≤35% 失效）、R8（裸底 ≤1% 失效）；§4 越界警报②「→ 越界**塞尚**」。

**强反例 3（内容泄漏反证）— 把「必须有 humble domestic objects / 铜锅面包」当风格前提**：§8.2 全部分母是「可辨纹理面积 / 高光连通域形态 / 色相簇 / 材质类数 / 帧间差」，没有一条要求认出器物。§3.1 把人物档列为可选（`absorbed figure` + 门洞第二空间可选），§4 P5/P6 是构图与时期开关。若集成时把「18 世纪法国静物」写进 §8.1b 必要条件，则材质样张/抽象表面（正例 1）会被误判「不像夏尔丹」。**人物/花卉/风景内容对象不是风格前提**。

## 5. 适用 / 不适用条件

**适用**：① 多材质、浅空间、近前缘的静帧类（产品微距、材质样张、包装特写）；② 需要「宽软互映高光 + 暖暗部」的渲染通道；③ 需要「中间档可见纹理但非全覆盖」的表面自查（C-05 显式取值）；④ 静止/悬停时间感的 motion（R7 帧间差 ≤1%）。

**不适用**：① **平滑不可见笔触 / 点状高光 / 冷蓝阴影 / 地砖网格**（破 R1/R2/R3/R4，越界维米尔）；② **方向族 tache / 多轮廓 / 裸露画布 / 几何分面**（破 R1/R8，越界塞尚）；③ **画外单光 + 近黑背景 + 亮部只落脸手**（破 C4，越界卡拉瓦乔）；④ **平涂无笔触无高光**（破 R1/R2，越界马蒂斯，越界警报④）；⑤ **纯黑塌陷 / 高饱和霓虹**（破 R3/R5）；⑥ S-06 无文字 key visual 下不补任何标签/寓意道具（§8.1 负向 `no allegorical props, no text`）。

**组合预检（沿用 dossier）**：C-01（软光侧，顺风）、C-05（「可见但非全覆盖」档须显式取值）、C-11（按 N7 声明「反光带」类）、C-12（暖土色系显式取值）、C-13（暖褐/灰绿阴影）；§3.1 与维米尔（70/30 主导轴，默认二选一）/塞尚（N4 分轴，形体处理不可拆）分工轴。
