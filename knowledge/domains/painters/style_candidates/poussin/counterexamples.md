# 风格级强反例 — `poussin` [inference]

> 本页 3 例全部停在纸面：不渲染像素、不接图像通道、不做 E4 实测。每例写明撤去或反转的具体机制、被破的 R-ID 与 普桑 dossier §8.2 原文行；默认题材对象一律保留，用来证伪「题材齐备即风格成立」。

<a id="db-source-line-5"></a>
## CE-POU1 撤去核心机制：把「均匀白昼光、无单一戏剧源、L<0.2≤15%

**操作**：把「均匀白昼光、无单一戏剧源、L<0.2≤15%」换成画外单光源+近黑背景+戏剧亮斑；舞台人物几何全保留。 **被破坏的规则**：R3(§8.2-3 L190 L<0.2≤15%、最大暗区≤5%、高亮连通域=0)fail；R7(§8.2-7 L194 轮廓阶跃≥0.2/≤3px、断裂率≤20%)被暗绘法吞掉；拆 C2。对应 §3.1 L87 C-01「普桑站均匀光侧」。 **为何是风格级反例**：只换一组可迁移关系而不改题材，证明 普桑 身份轴是统计量耦合、不是「画的是不是默认题材」；对应 §4 越界警报与 §3.1 分工条款。 [STYLE-poussin[inference]]
<a id="db-source-line-8"></a>
## CE-POU2 反转关系档：保留舞台排列与受控色阶，只把「≥3深度层、中带可

**操作**：保留舞台排列与受控色阶，只把「≥3深度层、中带可辨元素≥3、中景非空缺」换成弗里德里希式层带阻隔+中景空缺+人物凝视背影。 **被破坏的规则**：R6(§8.2-6 L193 ≥3深度层、遮挡链≥2级、中带≥3元素)fail；R7(§8.2-7 L194 轮廓清晰)被层带雾化取消；拆 C4。对应 §3.1 L86 vs 弗里德里希镜像条款。 **为何是风格级反例**：题材与色/光统计全在、关系仍不成立——反驳「认出默认题材就是 普桑」；对应 §4 越界警报与 §3.1 分工条款。 [STYLE-poussin[inference]]
<a id="db-source-line-11"></a>
## CE-POU3 内容泄漏反证：把默认题材升为 §8.1b 必要条件

**操作**：不改任何像素，只在集成时把 §8.1 正向段的「古典主义历史画 / 舞台式编排 / 清晰几何秩序」与相关器物/体裁专名写成 §8.1b 无条件前提。 **被破坏的规则**：后果：跨场景正例（抽象/图标族）会被误判「不像普桑」，而 §8.2 的 8 条统计量本不依赖任何题材专名。 **为何是风格级反例**：结论：默认题材是 R 表计数/档位的内容基底，不是风格前提；本反例破的是规则写法，不是像素。 [STYLE-poussin[inference]]
