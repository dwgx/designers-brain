## 1. 默认题材泄漏的剥离

dossier §8.1 正向段把「普桑」强绑定在一组**内容对象**上，本段逐项降级为关系量：

| §8.1 内容词 | 为什么不是风格前提 | 本段处理 |
|---|---|---|
| `history / mythology / Sabine women / antique drapery` | 历史题材与衣饰是内容；关系量是≥60%触地点落在≤15%画高带、≥2组「排」夹角≤10° | 保留 §8.2-1 |
| `even lucid daylight / noble restrained ochre/blue/olive palette` | 光与色名是内容；关系量是L<0.2≤15%、无戏剧亮斑、色相簇≤8、中位饱和≤0.55 | 保留 §8.2-3/§8.2-4 |
| `figures disposed like actors on a stage / architecture as backdrop` | 舞台与建筑是内容；关系量是≥3深度层、遮挡链≥2级、中带可辨元素≥3 | 保留 §8.2-6 |

**迁移判据（已收窄）**：换掉全部题材专名与体裁词后，§8.2 的 8 条里**只**有「可原样转移到无语义输入的形式子集」（见 §2 末）能在无人物/无对象的纯色块/线面图上逐帧计算；带语义前提的规则在无对应内容时必须标**不适用/未知**，不得记通过。「语义专名不迁」≠「语义前提不迁」。

> **普桑 特有的规则内张力（登记，不消歧）**：§8.2-7 L194「主体轮廓阶跃≥0.2（≤3px内）、断裂率≤20%」与 §3.1 L79 判据①「阶跃≥0.2（≤3px）」同尺；本段把「可读区间（介于达·芬奇≥1.5%柔边与米开朗基罗≤0.6%硬边之间）」写成显式取值，不擅自取两端任一口径。

**可原样转移的形式子集（对无人物/无对象的几何输入仍可定义）**：R2（Hough 直线、配重/镜像对称检测）；R3（亮度直方图、暗区/亮斑连通域）；R4（HSV 色相簇/饱和统计）；R7（边缘阶跃剖面、边缘链断裂率）；R8（Laplacian 能量、镜面高光计数）——全部量「线/光/色/边」本身。

**仍带语义前提、不能记「内容全换仍可算」的规则**：R1——「人物触地点/姿态检测」需人物语义，无人物**不适用**；R5——「人物重心投影/失稳姿态」需姿态语义，无人物**不适用**（「无运动模糊核」「对称/配重对位」两个形式分项可判）；R6——「同类物体尺度梯度」需同类识别，形式分项「遮挡链 ≥2 级」「中带可辨元素 ≥3」可判、该分项**未知**。

**替代规则（项目提案，不等价，新 ID）**：若要给无人物输入覆盖 R1 的「舞台排列」，必须另立新 ID 并声明**不等价**：**R1′（提案，不等价于 R1）**：≥60% 可检锚点（角点/基座类几何特征）落在 ≤15% 画高的水平带内、锚点群 ≥2 组「排」——去掉「人物姿态/触地点」语义前提；**不等价**于 R1，不能沿用 R1 宣称满足。R1′ 为项目工程假说 `[inference]`，未实测、未渲染。




**组合条件（旧「五条必要耦合」已校准）**：

旧版 C1–C5 对五对耦合统一写同一句「拆开会破——vs 达·芬奇/米开朗基罗/弗里德里希…」（uniqJust=1），**不是逐对论证，也无 §4 支持**，已删除；可复核反证：R3（清晰光）与 R7（轮廓清晰）可分别判定——去掉边缘剖面后亮度直方图仍可算，去掉光照统计后边缘链跟踪仍可执行，故「计算上不可分」不成立。

**有来源的联合身份判据（准确引用 §4 L100 用法 + 越界警报）**：**P1/P2/P4 定「是不是普桑」**——三条中 ≥2 条 ≥ 中档才成立（舞台调度＋几何骨架＋清晰光）；P3/P5 定时代档（早年威尼斯 → 中期舞台 → 晚期冷调）；P6 是题材参数（可关）。越界警报：①画外单光源＋近黑背景→卡拉瓦乔；②sfumato 全域柔边＋空气消融远景→达·芬奇；③个体化扭转挣扎＋硬边凿刻→米开朗基罗；④层带阻隔＋中景空缺＋凝视背影→弗里德里希；⑤室内点状高光＋光学盒空间→维米尔。这是「联合出现有助身份区分」，不是「五对数学上无法拆分」。

**逐对假说（标 `[inference]`，各带可推翻反证）**：
- **H-C1 ⟨R1∧R2⟩**：舞台排列 × 几何骨架同现可能构成「编排舞台」身份（对应 P1+P2）。**反证**：≥2 条长对角线交叉、配重差 10%（R2 pass）但人物散布无「排」（R1 fail）的画面，R2 仍可独立判定 → 非不可分，`[inference]`。
- **H-C2 ⟨R3∧R7⟩**：清晰光 × 轮廓清晰同现可能对应「可读形式」美学（P4）。**反证**：亮度均值 0.6、无亮斑（R3 pass）但边缘柔化断裂率 35%（R7 fail）的画面，R3 仍可判定 → `[inference]`。
- **H-C3 ⟨R4∧R5⟩**：收窄色阶 × 冻结编排同现可能对应古典档（P5+P3）。**反证**：色相簇 6、中位 S 0.4（R4 pass）但出现运动模糊（R5 形式分项 fail）的序列，R4 仍可判定 → `[inference]`。
- **H-C4 ⟨R6∧R7⟩**：空间分层 × 轮廓清晰同现可能互证「舞台可读纵深」。**反证**：遮挡链 2 级、中带元素 4（R6 形式分项 pass）但轮廓阶跃不足（R7 fail）的画面，R6 仍可判定 → `[inference]`。
- **H-C5 ⟨R5∧R8⟩**：冻结编排 × 净面完成同现可能对应「enamel 表面」档。**反证**：Laplacian 方差 3（R8 pass）但人物重心失衡（R5 语义分项 fail）的画面，R8 仍可判定 → `[inference]`。

> 以上 H-C* 均为项目工程假说 `[inference]`，各带能推翻它的纸面情形；不得写成「拆开无法判定」的必要性结论，也不并入 receipt 的 supported observation（见 §6）。

## 3. 正例（跨场景，逐帧可自查）

**正例 1 — 抽象编排图（无题材专名，纸面规格）** `[inference]`

输入（完整、可逐项判定）：无人物/姿态、无同类可识别物体；2 条 45% 对角线交叉、左右质量差 10%；L<0.2 占 10%、高亮连通域 0、亮度均值 0.6；色相簇 6、中位 S 0.4、无 S>0.8 大区块；无运动模糊核、1 组配重对；遮挡链 2 级、中带可辨元素 4；轮廓阶跃 0.25/2px、断裂率 15%；Laplacian 方差 3、镜面高光 1。

| 规则 | 适用性 | 结果 | 依据 |
|---|---|---|---|
| R1 | **不适用** | 未知/不计通过 | 无人物触地点/姿态承载（不再声称「7 个锚点触地点、2 组排」；几何锚点替代需 R1′ 另判，不等价） |
| R2 | 适用 | pass | 对角线 2≥2 且交叉、质量差 10%≤15%（§8.2-2） |
| R3 | 适用 | pass | L<0.2 占 10%≤15%、亮斑 0、均值 0.6∈[0.45,0.75]（§8.2-3） |
| R4 | 适用 | pass | 色相簇 6≤8、中位 S 0.4≤0.55、无 S>0.8 大区块（§8.2-4） |
| R5 | 部分适用 | pass（形式分项） | 无模糊核✓、配重对 1≥1✓；重心投影/失稳姿态分项**不适用**（无人物；不再声称「重心投影在支撑面内」） |
| R6 | 部分适用 | pass（形式分项） | 深度层 3≥3、遮挡链 2≥2、中带元素 4≥3✓；「同类物体尺度梯度」分项**未知**（无同类物体） |
| R7 | 适用 | pass | 阶跃 0.25≥0.2（2px≤3px）、断裂率 15%≤20%（§8.2-7） |

**正例 2 — 含人物编排的同域稿** `[inference]`：若输入含可检人物（触地点成 2 排、重心投影在支撑面内、无失稳姿态）与同类可辨物体（近/中景尺度梯度可回归），则 R1/R5/R6 尺度分项**适用**；其余同正例 1。此例说明**带语义内容的场景**才能覆盖八条，与正例 1 是「适用集合不同」，不是「内容换掉仍全通过」。

## 5. 适用 / 不适用条件

**适用**：
1. 平面/编排图/舞台式版式（触地点聚类+Hough+直方图+边缘剖面可逐帧查）
2. 需几何骨架+群体编排配平的构图
3. 均匀白昼光、无戏剧亮斑的渲染通道
4. 中景非空缺（≥3元素）的分层空间

**不适用**：
1. 需画外单光源+近黑背景（破 R3/R7，越界卡拉瓦乔）
2. 需sfumato柔边+空气消融远景（破 R7，越界达·芬奇）
3. 需个体化扭转挣扎+硬边凿刻（破 R5，越界米开朗基罗）
4. 需层带阻隔+中景空缺+凝视背影（破 R6/R7，越界弗里德里希）
5. 需室内点状高光+光学盒空间（破 R3，越界维米尔）

**组合预检（沿用 dossier）**：vs 达·芬奇（§3.1 L76–80：几何清晰/分层布景 vs sfumato柔边/空气透视）、vs 米开朗基罗（L81–84：群体编排配平 vs 个体化扭转挣扎）、vs 弗里德里希（L86：完整舞台/历史行动者 vs 层带阻隔/凝视者）；按 [conflicts.md](../../../../cross/conflicts.md) 预检，冲突轴单主（N3），不得双开标志机制。
