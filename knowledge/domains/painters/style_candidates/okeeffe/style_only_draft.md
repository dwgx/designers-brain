## 1. 默认题材泄漏的剥离

dossier §8.1 正向段把「欧姬芙」强绑定在一组**内容对象**上，本段逐项降级为关系量：

| §8.1 内容词 | 为什么不是风格前提 | 本段处理 |
|---|---|---|
| `a flower, a bone, a shell, a hill, a door` | 单主体清单是题材器物；可判读的是「最大连通主体占画幅≥70% + ≥1 处被框裁切 + 第二主体≤10%」 | 删除专名，保留 §8.2-1 的**连通域面积比/裁切/第二主体计数**(R1)；「花如建筑」改写为 R6 的感知尺度标记 |
| `nobody sees a flower / I'll paint it big / that blue / desert` | 自述语句、作者意图与地名是内容(§5 按方法陈述使用，不冒充内心)；不是像素关系 | 删除引语与地名，保留 §8.2-2「曲率拐点≤12、纹理能量<参考帧30%」的**曲率/频域**关系(R2) |
| `blush pink, ivory, pale blue, grey-green / one small saturated accent` | 颜料名与「那蓝」是色域内容；关系量是「中位饱和≤0.45 + 高饱和S>0.6占比≤8%、≤3连通域且与主体核心相交」 | 保留 §8.2-5 的**HSV 统计**(R5)，删色名清单 |
| `petals like flesh, bone surfaces like dunes / a series sensibility` | 比喻与「系列」体裁是阐释；可判定的是「相邻16px窗口均值差≤2/255、平涂色块数=0」与「跨帧简化度/放大度单调不减」 | 改写为 R3 的**梯度连续性**与 R7 的**跨帧单调序列**，删比喻 |
| `20th-century American modernism, oil on canvas, museum reproduction` | 年代/国别/材质/完成度是标签，不是可判定关系 | 删除；「无笔触/无硬边」由 R3 的平涂色块=0 与 §8.2 注 C-05 同侧声明承担 |

**迁移判据**：迁移判据：换掉全部花/骨/沙漠专名、作者引语与「美国现代主义」体裁词后，§8.2 的 7 条自查（分割+面积比、边缘曲率+频域、梯度窗口+带纹检测、投影连通域+光源计数、HSV 统计、构图模板+地平线检测、跨帧指标序列）仍可逐帧计算 → 纯风格。按此判据 7 条全可迁；R7 只保留**跨帧单调计数**，题材语义(同母题是什么)不迁。

> **okeeffe 特有的规则内张力（登记，不消歧）**：§8.2-3 L198「全帧平涂色块数=0」× §8.2-2 L197「无平涂块、无硬边色界」两处同写「禁平涂」；但 §4 P4 L97 弱档却写「硬色块/高对比(近平面档——越界警报)」——弱档是**越界档**而非可迁移档位。另 §8.2-3「渐变必须存在且无缝」× conflicts.md C-14「别做成：渐变」须改写为「别做成：渐变中断/带纹」(§8.3-1 L210)。本段把 P4 弱档标为「越界退档线、不作档位前提」，把 C-14 改写口径登记为组合预检项，不擅自消歧。

## 2. 可迁移视觉关系（参数 · 单位 · 范围 · 必要耦合）— 欧姬芙 关系族；全部 `[归纳] 未实测` [STYLE-okeeffe]

| ID | 可迁移关系 | 单位 / 范围 `[归纳]` | 源行 |
|---|---|---|---|

**必要耦合（拆开会破，`[归纳]`）**：

- **C1 ⟨R1∧R6⟩「单主体 × 尺度错位」**：单主体占≥70%且出框(R1)是「把小物画大」的操作化，尺度错位(R6 长边≥80%或极端画幅比)给放大一个可测标记；若引入环境参照/地平线/第二主体同权，则「无环境、无 context」失守 → §8.1 正向 L165–166、越界警报①(多元素平铺)。
- **C2 ⟨R2∧R3⟩「简化 × 无缝渐变」**：删细节留形状(R2 拐点≤12、纹理<30%)后，体积只能靠连续渐变建模(R3 窗口差≤2/255、平涂块=0)；若出现可见笔触/硬边色块/带纹，则「crisp contours over continuous tonal transition」破 → §8.1 负向 L182–186、C-05/C-14。
- **C3 ⟨R4∧R5⟩「平光 × 柔和色域」**：光＝清晰度(R4 投影≤2%、光源=0、对比≤120/255)保证亮暗来自固有色明度而非明暗塑造，柔和高调(R5 中位饱和≤0.45)才不被硬影切碎；若引入 dramatic lighting/硬色块高对比，则两者同破 → 越界警报③/①。
- **C4 ⟨R3∧C-14改写⟩「渐变必须存在 × Lane B 禁令改写」**：欧姬芙的渐变是**正向要求**(R3 必须连续无缝)，而 Lane B 06/07/13 卡反约束写「别做成：渐变」；组合时须改写为「别做成：渐变中断/带纹；渐变必须无缝」并显式声明无投影(§8.3-1 L210)。这是组合预检耦合，不改本段正向关系。
- **C5 ⟨R7∧R1/R2⟩「系列单向 × 放大/简化单调」**：系列档(R7 跨帧≥3)把 R1 放大度与 R2 简化度写成单调不减序列(写实→几乎纯形)；若跨帧出现回退或换母题，系列语义破 → §3.1 判据④、§8.1 正向 L176。不启用系列档时 R1/R2 仍独立成立。

## 3. 正例（跨场景，逐帧可自查）

**正例 1 — 抽象单形放大海报（无花、无骨、无沙漠）**：一个连通主体占 78% 画幅、被右边缘裁切 1 处、无第二主体(R1)；轮廓曲率拐点 9、碎块 2、高频能量为参考帧 22%(R2)；内部相邻16px窗口差 1.4/255、平涂块 0、无带纹(R3)；投影 1%、画内光源 0、P95−P5 对比 95/255(R4)；中位饱和 0.38、高饱和 6% 集中 2 个与核心相交连通域、色相家族 5(R5)；主体长边占画幅 84%(R6)；不启用系列档。七条全是连通域/曲率/梯度/HSV/对比统计量，无需认出花或骨盆。

**正例 2 — UI 单锚形 / 微距数据图（内容全换）**：单一锚形持续放大 + 简化 + 无缝渐变 + 平光 + 柔和色域 + 尺度错位。R1–R7 仍逐条可算；仅声明视觉关系可迁，不声称任何生成通道已产出、不声称 E4 通过。

## 4. 强反例（题材全对但风格不成立）

**强反例 1 — 题材全对但换成多元素平铺纯色**：画出巨大单形、裁切、柔和色(题材齐备)，但把「无缝渐变 + 无笔触」换成马蒂斯式平涂硬边色块、图案同权、多主体平铺 → 破 R1(第二主体同权)、R3(平涂块>0)、R5(高饱和占比>8%)、拆 C1/C2；§4 越界警报① 即此。**题材齐全≠风格成立**。

**强反例 2 — 保留渐变但引入硬光戏剧**：题材不变，引入 chiaroscuro/画外单光源/近黑背景/可见笔触与投影 → 破 R4(投影>2%、光源>0)、R2(纹理能量>30%)、R3(带纹/笔触)、拆 C2/C3；§8.1 负向 L182、越界警报③。

**强反例 3 — 内容泄漏反证**：把「必须是放大花/骨盆/新墨西哥沙漠/Pedernal/七八个版本」写进 §8.1b 必要条件 → 抽象单形放大海报与 UI 微距数据图会被误判「不像欧姬芙」；花骨清单与作者引语是 R1/R2 的面积/曲率关系与题材档位，不是风格前提(§5 自述按方法陈述使用)。

## 5. 适用 / 不适用条件

**适用**：① 微距/单主体/海报类输出(连通域面积+曲率+梯度可逐帧查)；② 需「无缝渐变 + 平光」的柔色 UI/数据图；③ 需尺度错位的图标族；④ 系列模式(单向演进链)的时间轴设计。

**不适用**：① 需多元素平铺/平涂纯色/图案同权(破 R1/R3，越界马蒂斯)；② 需破碎笔触/有色阴影/环境光场(破 R2/R4，越界莫奈)；③ 需硬光戏剧/近黑背景(破 R4，越界卡拉瓦乔/伦勃朗)；④ 需人造光几何/投影计算(破 R4，越界霍珀)；⑤ 需点彩/光学混合(破 R3，越界修拉)；⑥ 需深透视广角地平线(破 R6)。

**组合预检（沿用 dossier）**：C-01(硬阴影——欧站「无投影」侧、同侧声明)、C-05(笔触可见度——欧站「无笔触」侧，与梵高/莫奈硬冲突)、C-06(饱和度——欧站低饱和侧)、C-14(渐变——须改写 Lane B 反约束为「渐变中断/带纹」)；§3.1 vs 马蒂斯/莫奈分工为正本。
