# 风格级强反例 — `okeeffe` [inference]

> 这 3 例是七规则卡的案头推演：没有像素输出、没有生成通道、没有 E4。逐例给出改动、被破 R-ID 与欧姬芙 §8.2 行号；放大单形的题材词保留，只替换建模机制。

<a id="db-source-line-5"></a>
## CE-OKee1 — 撤去渐变：把无缝连续体积换平涂硬边图案

**操作**：题材全保留(巨大单形/裁切/柔和高调/平光)，只把「无缝渐变建模 + 无笔触」换成马蒂斯式平涂纯色硬边大块、图案与主体同权、多元素平铺。**被破坏的规则**：R3(§8.2-3 L198 平涂色块数=0、窗口差≤2/255)直接 fail；R1(§8.2-1 L196 第二主体≤10%)→多主体同权；R5(§8.2-5 L200 高饱和≤8%)→硬色块；连带破 C1/C2。**为何是风格级反例**：只换「体积由什么建模」这一关系，证明 okeeffe 身份轴是单主体×无缝渐变(C1/C2)，不是「画的是不是花」。对应 §4 越界警报①、§3.1 vs 马蒂斯。

<a id="db-source-line-9"></a>
## CE-OKee2 — 反转光位：保留渐变但引入硬光戏剧与笔触

**操作**：保留单主体放大、无缝渐变、柔和高调色域；只把「平光无投影无光源」换成 chiaroscuro/画外单光源/近黑背景/可见笔触与 cast shadows。**被破坏的规则**：R4(§8.2-4 L199 投影≤2%、光源=0、对比≤120/255)直接 fail；R2(§8.2-2 L197 纹理能量<30%、碎块≤3)→笔触；R3(§8.2-3 L198 无带纹)→硬影切碎渐变；拆 C2/C3。**为何是风格级反例**：放大与渐变全在、题材全在，风格仍不成立——反驳「认出巨大柔色单形就是欧姬芙」；证明「光＝清晰度」是投影面积关系。对应 §4 越界警报③、§8.1 负向 L182。

<a id="db-source-line-13"></a>
## CE-OKee3 — 内容泄漏反证：把放大花/骨盆/沙漠升为必要条件

**操作**：不改任何像素，只在集成时把 §8.1 的 `a flower, a bone, a shell / desert / that blue / a series sensibility` 写成 §8.1b 无条件前提。**后果**：抽象单形放大海报与 UI 微距数据图会被误判「不像欧姬芙」，而 §8.2 的 7 条统计量本不依赖任何花骨清单或作者引语。**结论**：花骨器物、沙漠地名与「画大」自述是 R1/R2 的面积/曲率关系与题材档位(§5 按方法陈述使用，不冒充内心)，不是风格前提；本反例破的是规则写法，不是像素。

> 与 AUDIT-okeeffe 的关系：其 accepted 记录是「Black Iris 双作品混淆风险、OKM 自述语料链、放大花摄影先例」的证据分级与 §4/§8.1/§8.2 逐字抽取一致性；本文件 3 条是**纯风格关系层**反例(渐变/光位/题材泄漏)，两者不同层、不互相替代。全部 `[inference]` 纸面推演，未渲染像素、未跑生成通道、未做 E4。
