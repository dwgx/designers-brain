## 1. 无 §8.1b 时，卡能做什么 / 不能做什么

现有卡：视觉指纹要点、§8.1 图像 prompt（**正向段把 欧姬芙 默认题材专名写死为题材**）、§8.2 逐帧规则、§4 六参数、冲突注记。

- **能做**：在「放大花/骨/沙漠单主体」**默认题材域**内，用 §8.2 的 7 条(分割面积比、边缘曲率+频域、梯度窗口+带纹、投影连通域+光源计数、HSV 统计、构图模板+地平线、跨帧单调序列)自查 `_extract.py --check` 所校验的 §8.1/§8.2/§4 逐字一致(AUDIT-okeeffe 记录 §8.1b 被排除在逐字比对之外)。注意本卡 §8.2 为 **7 条**(非 8 条)。
- **不能做**：**跨场景路由**。把「单主体放大出框 + 简化 + 无缝渐变 + 平光 + 柔和色域 + 尺度错位」迁到抽象单形海报、UI 锚形、微距数据图时，§8.1 正向段会强制带回花/骨/贝壳清单、新墨西哥沙漠、作者「画大」引语与「美国现代主义」体裁，把内容对象当风格前提 → 01-AUDIT.md A06 所指「有模块/能抽取/已做纯风格迁移」混淆。
- ****本卡特有的未消歧张力(AUDIT-okeeffe 登记)**：§4 P4 弱档「硬色块/高对比」被明写为越界警报(近平面档)，却与 §8.2-2/3 的「禁平涂」同列于参数表——弱档是**退档线**不是可迁移档位；另 C-14「别做成：渐变」与 R3「渐变必须存在且无缝」须靠改写口径(§8.3-1 L210)共存。无 §8.1b 时卡没有「P4 弱档=退档线、C-14 改写为组合项」的写法，跨场景路由易把弱档误当可选档。**

## 2. §8.1b 草案新增的跨场景路由能力

| 增量 | 无 §8.1b 的卡 | 本 §8.1b 草案 |
|---|---|---|
| 介质/语义无关的关系量 | §8.1 绑定花/骨/贝壳/沙漠/Pedernal/作者引语 | 拆成 R1–R7：连通域占比/裁切/第二主体、曲率拐点/碎块/纹理、窗口差/平涂块、投影/光源/对比、中位饱和/高饱和连通域、长边比/画幅比、跨帧单调——全是分割/曲率/梯度/HSV/序列统计量 |
| 默认题材泄漏剥离表 | 无 | §1 表把单主体器物清单、作者引语与地名、颜料色名、比喻与系列体裁、年代/材质标签逐项降级；给迁移判据：撤专名后 §8.2 自查仍可算 = 纯风格；R7 只留**跨帧单调计数** |
| 张力显式化 | 卡内 P4 弱档/C-14 两写未处理 | §1 注把 P4 弱档标为「越界退档线、不作档位前提」、把 C-14 改写登记为组合预检项；C1–C5 列出 ⟨单主体×尺度错位⟩、⟨简化×无缝渐变⟩、⟨平光×柔和色域⟩、⟨渐变必须存在×C-14改写⟩、⟨系列单向×放大/简化单调⟩ |
| 正例 + 强反例 | 卡只有同域自查三问 | 抽象单形放大海报正例(七条全可算，无需认出花)+ UI 微距数据图正例；[counterexamples.md](counterexamples.md) 3 条 [inference]：撤渐变改平涂 / 保留渐变改硬光 / 内容泄漏反证 |
| 适用/不适用 + 组合预检 | 散落在越界警报 | 列 6 类不适用(平涂图案、碎笔环境光、硬光戏剧、人造光几何、点彩、深透视)+ C-01/C-05/C-06/C-14 预检 |

**路由收益（一句话）**：从「认出放大花 → 套 §8.1 prompt」升级为「读出 R1–R7 关系 → 判断任意单主体/微距场景是否满足单主体×无缝渐变、平光×柔和色域等耦合，并按 P3 档位决定是否带系列链」；跨场景判定**不再依赖花骨清单或沙漠地名**。
