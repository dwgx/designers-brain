## 3. 组合条件（旧「五条必要耦合」已校准）

旧版 C1–C5 统一句「两条规则共享同一关系量；拆开后另一条阈值统计不再可判定」**不是通用真理，也无 §4 支持，已删除**。可复核反证：任选两条规则（如两条形式子集规则）的阈值各自有独立分母，去掉其一另一仍可定义 → 「计算上不可分」不成立。配对形状 C1⟨R1∧R2⟩…C5 是按索引套用的模板，非艺术家内容推导。

**有来源的联合身份判据（准确引用）**：§4 L111 **用法**：「P1 + P2 定『是不是佐恩』（≥2 条 ≥中档才成立）；P1 + P2 + P4 是『四色控制』三件套」——这是**有来源的联合身份判据**，不是「五对规则数学上无法拆分」。L112 越界警报另记五种越界组合。

这是「联合出现有助身份区分/档位判定」，不是「五对数学上无法拆分」。

**新增组合假说（标 `[inference]`，各带可推翻反证）**：
- **H-C1 ⟨R1∧R2⟩**：同现可能提高身份区分度。**反证**：构造一个 R1 单独达标而 R2 不达标（或反之）的纸面输入，两规则仍分别可判定 → 二者非不可分，`[inference]`。
- **H-C2 ⟨R3∧R4⟩**：同现可能对应同一档位的视觉机制。**反证**：构造一个 R3 单独达标而 R4 不达标（或反之）的纸面输入，两规则仍分别可判定 → 二者非不可分，`[inference]`。
- **H-C3 ⟨R1∧R5⟩**：同现可能提高与邻近模块的区分度。**反证**：构造一个 R1 单独达标而 R5 不达标（或反之）的纸面输入，两规则仍分别可判定 → 二者非不可分，`[inference]`。
- **H-C4 ⟨R2∧R6⟩**：同现可能提高识别度。**反证**：构造一个 R2 单独达标而 R6 不达标（或反之）的纸面输入，两规则仍分别可判定 → 二者非不可分，`[inference]`。
- **H-C5 ⟨R4∧R7⟩**：同现可能对应族征组合。**反证**：构造一个 R4 单独达标而 R7 不达标（或反之）的纸面输入，两规则仍分别可判定 → 二者非不可分，`[inference]`。
