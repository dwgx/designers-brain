# 风格级强反例 — `bosch` [inference]

> 本页 3 例全部停在纸面：不渲染像素、不接图像通道、不做 E4 实测。每例写明撤去或反转的具体机制、被破的 R-ID 与 博斯 dossier §8.2 原文行；默认题材对象一律保留，用来证伪「题材齐备即风格成立」。

<a id="db-source-line-5"></a>
## CE-BOS1 撤去核心机制：改成戈雅式土黑+白闪点+画内证据光≥1+单事件聚

**操作**：改成戈雅式土黑+白闪点+画内证据光≥1+单事件聚焦；怪物巨果全保留。 **被破坏的规则**：R1(§8.2-1 L233 地平线≤40%高、≥2平面)被压平；R6(§8.2-6 L238 无单点戏剧主光源、日景暗带≤30%)fail；R7(§8.2-7 L239 蓝绿15–35%、土黑≤55%)被挤破；拆 C1/C3。 **为何是风格级反例**：只换一组可迁移关系而不改题材，证明 博斯 身份轴是统计量耦合、不是「画的是不是默认题材」；对应 §4 越界警报与 §3.1 分工条款。 [STYLE-bosch[inference]]
<a id="db-source-line-8"></a>
## CE-BOS2 反转关系档：保留全景均匀光，只把混合体≥3且≥2类部件改成单

**操作**：保留全景均匀光，只把混合体≥3且≥2类部件改成单一物种整体放大。 **被破坏的规则**：R3(§8.2-3 L235 混合体≥3、≥2类部件)fail；R4(§8.2-4 L236 等效比例≥2:1)被等比放大取消；R8(§8.2-8 L240 ≥2组善恶对位)失去讽喻机器；拆 C2/C4。 **为何是风格级反例**：题材与色/光统计全在、关系仍不成立——反驳「认出默认题材就是 博斯」；对应 §4 越界警报与 §3.1 分工条款。 [STYLE-bosch[inference]]
<a id="db-source-line-11"></a>
## CE-BOS3 内容泄漏反证：把默认题材升为 §8.1b 必要条件

**操作**：不改任何像素，只在集成时把 §8.1 正向段的「三联画全景 / 道德编目 / 天堂-人间-地狱」与相关器物/体裁专名写成 §8.1b 无条件前提。 **被破坏的规则**：后果：跨场景正例（抽象/图标族）会被误判「不像博斯」，而 §8.2 的 8 条统计量本不依赖任何题材专名。 **为何是风格级反例**：结论：默认题材是 R 表计数/档位的内容基底，不是风格前提；本反例破的是规则写法，不是像素。 [STYLE-bosch[inference]]
