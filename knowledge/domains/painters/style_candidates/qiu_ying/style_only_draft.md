**可原样转移的形式子集（对无人物/无器物语义的青绿输入仍可定义）**：R1（骨架连续率、线宽级差）；R2（HSV 色相聚类、面积比）；R3（边缘检测 + 色区采样）；R4 的形式分项（给定区域内的直线段占比、闭合度）；R6（单色块明度动态、色带过渡宽度）；R8（帧差图、平移速度拟合、转场检测）。

**仍带语义前提、不能记「内容全换仍可算」的规则**：R5——「可辨人物」识别与点算需人物语义，无人物输入**不适用**；R7——「琴棋书画/器皿/文玩」器物识别需对象语义，无器物**不适用**；R4 的「建筑区」定位需语义（栏杆/檐口/门框识别），形式分项在给定区域后可算。

**替代规则（项目提案，不等价，新 ID）**：若要给无人物输入覆盖 R5 的「细密密度」，必须另立新 ID 并声明**不等价**：**R5′（提案，不等价于 R5）**：可辨封闭小单元密度 ≥15 个/米（长卷档）或 3–10 个/页（册页档）——去掉「人物」识别前提；**不等价**于 R5，不能沿用 R5 宣称满足。R5′ 为项目工程假说 `[inference]`，未实测、未渲染。




**组合条件（旧「五条必要耦合」已校准）**：

旧版 C1–C5 对五对耦合统一写同一句「拆开会破——vs 克里姆特/北斋/若冲…」（uniqJust=1），**不是逐对论证，也无 §4 支持**，已删除；可复核反证：R2（青绿主色）与 R6（渲染过渡带）可分别判定——去掉明度剖面后 HSV 聚类仍可算，去掉色相聚类后过渡带宽度仍可测，故「计算上不可分」不成立。

**有来源的联合身份判据（准确引用 §4 L109 用法 + L110 分工注）**：**P1+P2 定「是不是仇英重彩档」**——青绿矿物色 + 匀称勾线，两条同时 ≥ 中档才成立；P3/P4 定「精密密度」；P5/P6 切「册页/挂轴档 ↔ 长卷档」。L110 分工注：金属箔贴面+装饰图案块+写实面孔对撞→克里姆特；刻线等宽+套色平涂+无渲染→北斋；无轮廓线色面+升目网格→若冲。这是「联合出现有助身份区分」，不是「五对数学上无法拆分」。

**逐对假说（标 `[inference]`，各带可推翻反证）**：
- **H-C1 ⟨R1∧R3⟩**：勾线连续 × 色下线可辨同现可能互证「先线后色」工序。**反证**：轮廓连续率 97%（R1 pass）但色层盖线、可辨率 50%（R3 fail）的画面，R1 仍可独立判定 → 非不可分，`[inference]`。
- **H-C2 ⟨R2∧R3⟩**：青绿主色 × 色不掩线同现可能对应「大青绿勾廓晕染」档（对应 P1）。**反证**：石青石绿 30%、比 2.5:1（R2 pass）但平涂盖线（R3 fail）的画面，R2 仍可判定 → `[inference]`。
- **H-C3 ⟨R4∧R6⟩**：界画直线度 × 渲染过渡带同现可能对应「界画工整 + 绢本晕染」。**反证**：直线段 68%、结构闭合（R4 形式分项 pass）但单色块明度动态 40%（R6 fail）的画面，R4 仍可判定 → `[inference]`。
- **H-C4 ⟨R5∧R7⟩**：人物密度 × 器用密度同现可能对应「汉宫春晓」式满密度场景（对应 P6+P4）。**反证**：器物 5 件/1000cm²（R7 pass）但无人物（R5 不适用）的文玩静物图，R7 仍可判定 → `[inference]`。
- **H-C5 ⟨R1∧R2⟩**：匀称勾线 × 青绿主色同现可能构成重彩身份核心（对应 P2+P1，两条同时 ≥ 中档）。**反证**：青绿 30%（R2 pass）但线宽级差 4.0（R1 fail，率笔）的画面，R2 仍可判定 → `[inference]`。

> 以上 H-C* 均为项目工程假说 `[inference]`，各带能推翻它的纸面情形；不得写成「拆开无法判定」的必要性结论，也不并入 receipt 的 supported observation（见 §6）。

## 3. 正例（跨场景，逐帧可自查）

**正例 1 — 抽象青绿界画板（无题材专名，纸面规格）** `[inference]`

输入（完整、可逐项判定）：无人物、无器物、无建筑区标注（但含给定直线主导区）；轮廓连续率 97%、线宽 p90/p10=2.0、收笔不虚断；石青石绿占比 30%、青绿:赭朱 2.5:1；色层下墨线可辨 85%；给定区内直线段占比 68%、结构线闭合；单色块明度动态 15%、色带过渡 5px；长卷平移 1.5% 画幅宽/秒、帧间差 0.3%。

| 规则 | 适用性 | 结果 | 依据 |
|---|---|---|---|
| R1 | 适用 | pass | 连续率 97%≥95、级差 2.0≤2.5、不虚断（§8.2-1） |
| R2 | 适用 | pass | 青绿 30%≥25%（大青绿档）、比 2.5:1≥2:1（§8.2-2） |
| R3 | 适用 | pass | 色下墨线可辨 85%≥80%（§8.2-3，边缘检测可算） |
| R4 | 部分适用 | pass（形式分项） | 给定区内直线段 68%≥60%、闭合✓；「建筑区」自身定位需语义（栏杆/檐口/门框识别），标注缺失时**未知** |
| R5 | **不适用** | 未知/不计通过 | 无人物承载（不再声称「18 人/米等效、6 个/页」；封闭小单元替代需 R5′，不等价） |
| R6 | 适用 | pass | 明度动态 15%∈[5,25]、过渡 5px∈[3,8]（§8.2-6） |
| R7 | **不适用** | 未知/不计通过 | 无器物承载（不再声称「每 1000cm² 器物 5 件」） |
| R8 | 部分适用 | pass（形式分项） | 平移 1.5%≤2%/s✓、帧间差 0.3%≤0.5%✓（全帧统计）；「人物微动」分项**不适用**（无人物） |

结论：该正例**只**在形式子集 R1/R2/R3/R6（R4/R8 形式分项）上逐项可判定并 pass；R5/R7 标**不适用**、R4 区域分项标**未知**。不再写「内容全换仍八条全通过」。阈值沿用 `[归纳]` 未实测、本例仅 `[inference]` 纸面输入，不渲染。

**正例 2 — 含人物/器物/界画的同域稿** `[inference]`：若输入含可辨人物（≥15 人/米长卷档或 3–10 人/页册页档）、可识别器物 ≥4 件/1000cm² 与可定位建筑区，则 R5/R7/R4 区域分项**适用**；其余同正例 1。此例说明**带语义内容的场景**才能覆盖八条，与正例 1 是「适用集合不同」，不是「内容换掉仍全通过」。

## 5. 适用 / 不适用条件

**适用**：
1. 平面/青绿线稿/界画版式（骨架连续率+HSV+霍夫线+明度剖面可逐帧查）
2. 需勾线-渲染-罩色、色不掩线的工笔系统
3. 青绿:赭朱≥2:1的矿物色预算
4. 界画直线度≥60%、结构线闭合的构图

**不适用**：
1. 需金属箔/反光/装饰图案块（破 R2/R3，越界克里姆特）
2. 需刻线等宽/套色平涂（破 R1/R3/R6，越界北斋）
3. 需无轮廓线色面+网格量化（破 R1，越界若冲）
4. 需水墨写意减笔/一笔造型（破 R1/R5，越界八大/齐白石）
5. 需披麻皴+积墨长卷（破 R6，越界黄公望）

**组合预检（沿用 dossier）**：vs 克里姆特（§3.1 L80–84：矿物颜料层/描绘 vs 金属箔材质层/装饰对撞）、vs 北斋（L85–89：毛笔匀称线+渲染罩色 vs 刻线等宽+套版平涂）、vs 伊藤若冲（L90：有轮廓线 vs 无轮廓线网格）；按 [conflicts.md](../../../../cross/conflicts.md) 预检，冲突轴单主（N3），不得双开标志机制。
