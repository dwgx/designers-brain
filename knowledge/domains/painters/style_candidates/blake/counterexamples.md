# 风格级强反例 — `blake` [inference]

> 全部为**纸面推演 [inference]**，未渲染像素、未跑生成通道、未做 E4。每条给具体撤去/反转/保留操作，点名被破坏的 §8.1b 关系 ID 与 dossier §8.2 规则行。题材对象（幻视书页、命名神谱、腾空人体、辐射光、手写诗行、粗边框）全部保留，证明「题材齐备≠风格成立」。

<a id="db-source-line-5"></a>
## CE-B1 — 撤去纹理：把「铁丝轮廓 + 平涂」改成交叉排线明暗

**操作**：题材全保留；只把明暗机制从「平涂色区/留白」换成丢勒式平行+交叉排线、线距梯度、线端收锋。

**被破坏的规则**：
- R2（§8.2-2 L213「交叉排线 **0 命中**、单区明度标准差 ≤12/255」）→ 直接 fail；
- R1（§8.2-1 L212「≥80% 边界连续硬轮廓、过渡带 ≤1px、线宽变异 2–3:1」）→ 排线把边界让位给线密度；
- 连带破 C1（「铁丝轮廓 × 无排线」双护栏）。
- 对应 §4 越界警报①「明暗由交叉排线/线密度承担 → 越界**丢勒**」、C-07、§8.1 负向 `no crosshatching, no hatched shading, no tonal line-density gradients, no stipple`。

**为何是风格级反例**：只换「明暗由什么承载」这一关系；证明 blake 的身份轴是线功能（C1），不是「画的是不是神话人物」。

<a id="db-source-line-17"></a>
## CE-B2 — 反转空间：把「单中心轴对称/涡旋」改成散点分布式构图

**操作**：保留硬轮廓、平涂、手写质感带、辐射装置、腾空动态；但把 §8.2-8 的中心轴对称 ≥60% / 涡旋，换成勃鲁盖尔式散点分布、无中心、多消失点。

**被破坏的规则**：
- R8（§8.2-8 L219「轴对称 ≥60% 或旋转对称分量 ≥1 + 粗边框/页面建筑」）→ 失效；
- R5（§8.2-5 L216「≥1 处单中心辐射装置、射线 ≥6、面积 ≥8%」）→ 单中心光源失去几何锚（破 C3）；
- R4（平涂色区 ≤10 主色）仍在，但 C2「平涂 × 单中心光」被拆。
- 对应 §8.1 正向 `composition on a central axis or vortex … symmetrical wings of cloud`。

**为何是风格级反例**：只反转构图的对称关系，未改任何题材；证明「中心/涡旋 × 单中心光」耦合（C3）是纯几何关系。

<a id="db-source-line-29"></a>
## CE-B3 — 保留色板撤掉形状：淡彩平涂色区还在，但撤掉硬轮廓与同版关系

**操作**：保留 pale blues / olive greens / ochre / rose madder / grey-violet 平涂色板与金点缀 ≤5%（R4 不动）；把轮廓改成 sfumato 宽灰渐变（达·芬奇侧），并把手写质感带做成独立排印字体层/贴上去的标题。

**被破坏的规则**：
- R1（过渡带 ≤1px、线宽变异 2–3:1）→ 渐变带失效；
- R2（明暗改由渐变承担，非平涂色区/留白）→ 连带；
- R3（§8.2-3 L214「手写蚀刻质感、与图同墨同层、5–35%」）→ 独立字体层触发 §8.1 负向 `no typographic or printed-font text, no clean vector lettering on a separate layer`（破 C4）；
- 对应 §4 越界警报④「涂抹式渐变、sfumato 或厚涂笔触 → 越界达·芬奇/油画传统」。

**为何是风格级反例**：色板完全保留、题材全在，风格仍不成立——反驳「认出淡彩水彩配色就是布莱克」。也说明「同墨同层」是层关系，不是「有文字」这个内容事实。

<a id="db-source-line-41"></a>
## CE-B4（内容泄漏反证）— 把「必须有命名神谱/可读经文」升为必要条件

**操作**：不改任何像素，只在集成时把 §8.1 的 `Urizen / Los / Orc / …` 与「文字板 5–35%」写成 §8.1b 无条件前提。

**后果**：§4 P4 弱档明写 `0%（纯图像；大彩色版画档）`、§8.1 `[single-colour variant]` 允许纯线状态——两者会被误判「不像布莱克」。这正是 AUDIT-blake 已登记的**规则内张力**（counterexample 1：§4 P4 0% × §8.2-3 ≥5%，自查脚本可能双判 pass/fail）。

**结论**：命名神谱/可读经文是**内容档位**，不是风格前提；「文字带」应像本草案那样写成 P4 档位开关的可选层关系（0% / 5–35%）。本反例破的是规则写法，不是像素。

> 与 AUDIT-blake 的关系：其 accepted counterexample.md 的 2 条是**§4/§8.2 阈值互斥的规则系统张力 [inference]**（0% vs 5–35%；≥20% vs ≥8%）；本文件 4 条是**纯风格关系层**反例，其中 CE-B4 复用并明确落点于「题材泄漏」，两者不同层、不互相替代。
