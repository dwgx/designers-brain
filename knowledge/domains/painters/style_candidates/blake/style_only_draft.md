## 1. 默认题材泄漏的剥离

dossier §8.1 正向段把「布莱克」强绑定在一组**内容对象**上，本段逐项降级为关系量：

| §8.1 内容词 | 为什么不是风格前提 | 本段处理 |
|---|---|---|
| `Urizen / Los / Orc / Albion / Enitharmon`（命名神谱） | 具名人物与谱系是叙事内容；可判读的只是「可点名象征物 + 主题对照」这一**锚点关系** | 删除专名，保留 §8.2-7「≥1 个可点名象征锚点 + 结构对应」的**位置/计数**关系 |
| `heroic muscular bodies, nude/semi-nude` | 人体身份是题材；风格要件是**非重力动态**（躯干轴偏离竖直 ≥15°、包围盒无支撑） | 改写为几何姿态关系（§8.2-6），不要求「裸体/英雄」 |
| `hand-lettered text (etched script), verse` | 具体文字/诗句是语义内容；`文字板比例`是**面积比 + 同墨同层**的版面/层关系 | 保留为「一层 5–35% 面积的手写质感线带，与图同墨同层」（§8.2-3），**不要求可读文字/具体经文** |
| `visionary / illuminated page / religious` | 体裁与情绪标签，不是像素关系 | 删除；§8.2-5 的「单中心辐射装置」保留为纯几何/光度关系 |
| `radiating beams, orbs, compasses, scales, open book` | 器物清单是象征内容；关系量是「单中心、射线 ≥6、面积 ≥8%」 | 保留径向梯度/光源定位关系，删除器物专名 |

**迁移判据**：换掉全部专名与宗教词后，§8.2 的 8 条自查（Sobel 边缘+线宽剖面、线方向直方图+交叉检测、文字区检测+手写/排印分类、色彩量化、径向梯度、姿态粗检、物件清单对照、镜像差分对称）仍可逐帧计算 → 纯风格。按此判据 1/2/4/5/6/8 全可迁；3（图文同版）与 7（神谱锚点）只保留其**计数/面积/层关系**，语义部分不迁。

> **blake 特有的规则内张力（登记，不消歧）**：§4 P4 弱档 L95 = `0%（纯图像；大彩色版画档）` × §8.2-3 L214 = `文字区 5–35% 页面`。AUDIT-blake 的 counterexample 1 已把它标为 `[inference]` 规则系统张力（自查脚本可能双判 pass/fail）。本段把「文字带」写成**可选层关系**：大彩色版画档可取 0%，书页叙事档取 5–35%；`P4` 是档位开关，不是无条件阈值。另一处 §4 P6 强档 ≥20% × §8.2-5 ≥8% 为同一量的两个下限，8–20% 区间须显式取值（AUDIT counterexample 2，near-miss 缺口，本 lane 只登记不修）。

## 2. 可迁移视觉关系（参数 · 单位 · 范围 · 必要耦合）— 铁丝线/平涂/单中心光/对称四族；全部 `[归纳] 未实测` [STYLE-blake]

| ID | 可迁移关系 | 单位 / 范围 `[归纳]` | 源行 |
|---|---|---|---|
| R1 | **硬「铁丝」轮廓**：≥3 个主要形体，各 ≥80% 边界连续硬轮廓（边缘过渡带 ≤1px）；轮廓线宽变异比 2–3:1 | 边界覆盖(≥0.80)、过渡带(≤1px)、线宽比(2–3:1) | §8.2-1；§4 P1 |
| R2 | **明暗不来自线密度**：交叉排线 **0 命中**；单色区明度标准差 ≤12/255；明暗由平涂色区/留白承担 | 交叉命中(=0)、区明度σ(≤12/255) | §8.2-2；§4 P1 用法 |
| R3 | **同墨同层的手写质感带（可选）**：≥1 处面积 5–35% 页面的手写蚀刻质感文字区，与图像同一墨色、同一质感层；禁排印字体；大彩色版画档可取 0% | 面积比(0 / 0.05–0.35) | §8.2-3；§4 P4 |
| R4 | **平涂色区**：单区明度变化 ≤12%；主色 ≤10；金点缀 ≤5% 面积；允许纸白留白；单色墨档 = 全帧单色 | 区明度Δ(≤0.12)、主色数(≤10)、金(≤0.05) | §8.2-4；§4 P2 |
| R5 | **单中心辐射装置**：≥1 处射线 ≥6 条（或环形光晕/光球），面积 ≥8%；光源在画内 | 射线数(≥6)、面积(≥0.08)、光源位置(画内) | §8.2-5；§4 P6 |
| R6 | **非重力动态**：≥1 形体腾空/俯冲/螺旋扭转（包围盒底部无支撑，或躯干轴偏离竖直 ≥15°）；禁写实日常步态 | 轴偏角(≥15°)、支撑(无) | §8.2-6；§4 P5 |
| R7 | **可点名锚点**：≥1 个能与主题对应的象征锚点（只取「存在 + 位置/计数」，不取专名） | 锚点数(≥1) | §8.2-7；§4 P3 |
| R8 | **页面建筑/中心对称**：≥1 条粗边框或拱门/光球/洞穴式「页面建筑」；构图轴对称 ≥60% 或明确涡旋（旋转对称分量 ≥1） | 轴对称(≥0.60) / 旋转对称分量(≥1) | §8.2-8；§4 P3 |

**必要耦合（拆开会破，`[归纳]`）**：

- **C1 ⟨R1 ∧ R2⟩「铁丝轮廓 × 无排线」**：这是 blake 身份的双护栏（§4 用法「P1 是负向护栏的正向表述」）。若保留硬轮廓却让明暗由交叉排线承担 → 越界**丢勒**（§4 越界警报①、C-07）；若保留无排线却把轮廓软化为 sfumato/渐变 → 越界**达·芬奇/油画传统**（越界警报④）。二者必须同时成立。
- **C2 ⟨R4 ∧ R5⟩「平涂 × 单中心光」**：平涂色区（单区明度变化 ≤12%）意味着光不能靠渐变塑造，只能靠**一处单中心辐射装置**提供明度层级；若撤掉单中心而改用多点/全画面渐变照明，R4 的「单区平涂」与 R5 的「单中心」互相拆台（与 C-01/C-14 同侧）。
- **C3 ⟨R8 ∧ R5⟩「中心/涡旋构图 × 单中心光源」**：R8 的轴对称 ≥60% 或涡旋，给 R5 的辐射中心一个**几何锚**；把构图改成散点分布式（越界勃鲁盖尔）则「单中心辐射」失去构图支撑。
- **C4 ⟨R3 ∧ R1 ∧ R4⟩「同版关系」**：手写质感带要与图「同墨同层」——其线质必须落在 R1 的硬轮廓线体系内、色质落在 R4 的平涂/主色 ≤10 内；若把文字做成独立排印字体层（§8.1 负向 `no typographic text / no clean vector lettering on a separate layer`），R3 失效。
- **C5 ⟨R4 弱档 P2 × R1⟩**：单色墨档（P2 弱）下 R4 的「主色 ≤10 / 金 ≤5%」退化为全帧单色，能量全压在 R1 的轮廓；§8.1 `[single-colour variant]` 明写「all energy in the contour and the etched script」——即单色档是 R1↑ / R4↓ 的显式重配，不是缺规则。

## 3. 正例（跨场景，逐帧可自查）

**正例 1 — 抽象徽章/海报（无宗教、无命名人物）**：一个中心轴对称 ≥60% 的版式，3 组主要几何形体各 ≥80% 边界为 ≤1px 硬轮廓、线宽 2–3:1 起伏（R1）；通体平涂 ≤10 色、单区明度变化 ≤10%、留白纸底（R4/R2 无排线）；中心一处 8 条射线、占 9% 面积的光球（R5）；≥1 形体躯干轴偏离竖直 18°、无支撑（R6）；一圈粗边框 + 涡旋对称（R8）；一条 12% 面积的手写蚀刻质感饰带与图同墨同层（R3）；≥1 个可点名锚点（几何化的「圆规/天平」抽象形，只取其存在与位置，R7）。**八条自查全是边缘/直方图/径向/对称统计量，无需认出任何神话人物** → 纯风格成立。

**正例 2 — 产品爆炸图 / UI 图标族（内容全换）**：硬轮廓线描 + 平涂分区 + 单中心高亮 + 轴对称编排 + 无交叉排线 + 可选手写质感标注带。R1–R8 仍逐条可算。仅声明视觉关系可迁，不声称任何生成通道已产出、不声称 E4 通过。

## 4. 强反例（题材全对但风格不成立）

**强反例 1 —「幻视书页」题材、交叉排线明暗**：画出腾空人物、命名神谱、辐射光、手写诗行、粗边框（题材齐备），但把明暗改成丢勒式平行/交叉排线、线距梯度。破 R2（交叉排线 0 命中失效）、连带破 C1；§4 越界警报①、§8.1 负向 `no crosshatching, no hatched shading, no tonal line-density gradients` 即此。**结论：题材齐全≠风格成立**。

**强反例 2 — 保留线描但改 sfumato 渐变**：题材不变，把硬轮廓改成达·芬奇式宽灰渐变带、上油画罩染。破 R1（过渡带 ≤1px）、R4（平涂 ≤12%）、R2（虽仍无排线但明暗来自渐变而非平涂色区/留白）；越界警报④、§8.1 负向 `no sfumato, no soft airbrush transitions, no oil-painting modelling`。

**强反例 3（内容泄漏反证）— 把「必须有命名神谱/可读经文」当风格前提**：dossier §4 用法把 P3/P5/P6 定为「题材与强度档」，P4 弱档明写 `0%（纯图像；大彩色版画档）`；§8.1 `[single-colour variant]` 允许纯线状态。若集成时把「≥2 个具名神话人物」写进 §8.1b 必要条件，大彩色版画档与单色墨档会被误判「不像布莱克」。**神谱/经文是内容档位，不是风格前提**——这正是 AUDIT-blake 已受理的 0% vs 5–35% 张力所暴露的默认题材泄漏。

## 5. 适用 / 不适用条件

**适用**：① 线描/矢量/版面类输出（轮廓硬、平涂、单中心光可逐帧查）；② 需要「线体系 + 平涂色区 + 中心/涡旋对称」的装饰/图标/海报；③ 需要「同墨同层」版面关系的信息图；④ 无排线、无 sfumato 约束明确的渲染通道。

**不适用**：① 需要**排线/线密度明暗**的场景（破 R2，越界丢勒）；② 需要**宽灰渐变/sfumato/厚涂油画**的场景（破 R1/R4，越界达·芬奇）；③ 需要**均匀点阵/光学混合**的场景（破 R1/R4，越界修拉）；④ 需要**分布式无中心人群/散点构图**的场景（破 R5/R8，越界勃鲁盖尔）；⑤ 需要**纯情绪变形、无锚点无光装置**的场景（破 R5/R7，越界蒙克，§3.1 判据）；⑥ 金/材质成为主装置 >5%（破 R4，越界克里姆特，越界警报⑤）；⑦ S-06 的「无文字 key visual」边界下，R3 的可选手写质感带**须关闭为 0%**——本段不强制文字，也不借别的卡补排版。

**组合预检（沿用 dossier）**：C-07（× 丢勒，线功能/文字地位同轴不可叠加）、C-14/C-16（× Lane B 渐变禁令：blake 本不需渐变，平涂水彩，改写口径不误伤）、§3.1 与蒙克/北斋/达·芬奇/克里姆特分工轴。
