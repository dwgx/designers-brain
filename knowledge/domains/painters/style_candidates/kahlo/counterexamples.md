# 风格级强反例 — `kahlo` [inference]

> 全部为**纸面推演 [inference]**，未渲染像素、未跑生成通道、未做 E4。每条给具体撤去/反转/保留操作，点名被破坏的 §8.1b 关系 ID 与 dossier §8.2 规则行。题材对象（直视女子、Tehuana/huipil、蜘蛛猴鹦鹉、外露心脏/断柱/荆棘项链、热带植被、日期手书题字、还愿小画幅）全部保留，证明「题材齐备≠风格成立」。[STYLE-kahlo]

## CE-K1 — 撤去可解码性：把「具体自传符号」改成蒙克式通用原型 + 全场景变形

**操作**：题材全保留；只把符号层从「≥2 个可命名生平指涉物、可解码」换成无脸原型 + 全场景焦虑变形 + 无需生平即可读。

**被破坏的规则**：
- R2（§8.2-2 L250「≥2 个来自生平符码表的可识别物、符号必须可解码」）→ 直接 fail；
- R1（§8.2-1 L249「面轴 ≤10°、瞳孔 ±15°」）→ 无脸原型吞没正视几何；
- 连带破 C2（符号计数 × 焦平面清晰）。
- 对应 §4 分工注 L101「通用情绪原型符号 + 全场景变形组合整体属于蒙克模块，禁止同档出现」。

**为何是风格级反例**：只换「符号是否需要生平词典解码」这一关系；证明卡罗身份轴是可解码符号（C2），不是「画的是不是自画像」。

## CE-K2 — 反转尺幅：把「单人小画幅压缩舞台」改成巨幅群像深空间

**操作**：保留正视、民间色平涂、可解码符号；但把 §8.2-6 的「人物数 =1、占画高 40–70%」改成公共巨幅 + 群像 + 历史叙事 + 深消失点透视。

**被破坏的规则**：
- R6（§8.2-6 L254「人物数 =1（≥90% 帧）、主体占画高 40–70%、边缘裁切 ≤1 处」）→ 失效；
- R5（§8.2-5 L253「纵深 ≤2 平面、无收敛透视」）→ 深透视破；
- C1（正视 × 单人）、C4（压缩舞台 × 单人小画幅）被拆。
- 对应 §4 分工注 L101「公共巨幅＋群像＋历史叙事 → 越界里维拉」、P6 弱档「越界：壁画档」。

**为何是风格级反例**：只反转尺幅与空间关系，未改任何题材；证明「单人小画幅 × 压缩舞台」（C4）是纯计数/透视关系。

## CE-K3 — 保留色板撤掉硬边：洋红钴蓝还在，但改 sfumato 渐变 + 景深虚化

**操作**：保留洋红/钴蓝/翠绿/黄/血红民间色板与色相簇 6–9（R3 色数不动）；把色区过渡带改成宽灰渐变、加 sfumato 薄雾与背景景深虚化。

**被破坏的规则**：
- R3（§8.2-3 L251「色区内色彩方差 ≤5%」）→ 渐变 fail；
- R4（§8.2-4 L252「过渡带 ≤2px、禁止 ≥8px 羽化」）→ 直接 fail；
- R7（§8.2-7 L255「符号处于焦平面、边缘清晰度 ≥主体 80%」）→ 虚化 fail；
- 对应 §8.1 负向 sfumato haze / soft gradients / heavy impasto。

**为何是风格级反例**：民间色名完全保留、题材全在，风格仍不成立——反驳「认出洋红+钴蓝就是卡罗」。也说明「硬边」是梯度带关系，不是「用了哪些民间色」。

## CE-K4 — （内容泄漏反证）把「必须有 Tehuana 裙/猴/断柱/迭戈生平对应」升为必要条件

**操作**：不改任何像素，只在集成时把 §8.1 的 Tehuana dress / spider monkey / broken column / precise dates 与「符号必须对应生平事件」写成 §8.1b 无条件前提。

**被破坏的规则**：
- 后果：§4 P1 是「自传具体度」档位（弱档=通用肖像/静物无生平指涉）、§8.2-2 的符码表只是**可识别物清单**；抽象正视图标族与 UI 头像态正例（生平对应层关闭）会被误判「不像卡罗」。

**为何是风格级反例**：本反例破的是规则写法，不是像素；生平符号专名与词典对应是**内容基底/可选层**，不是风格前提。
