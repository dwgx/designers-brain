## 1. 无 §8.1b 时，卡能做什么 / 不能做什么

**能做**：在「自画像/生平符号/还愿小画幅」**默认题材域**内，用 §8.2 的 8 条（面轴+视线、符号清单核对、色相聚类+区域方差、梯度宽度、透视+背景分割、人物检测+边界框、清晰度图、帧差图）自查 §8.1/§8.2/§4 逐字一致（AUDIT-kahlo 记录 §8.1b 被排除在逐字比对之外）。

**不能做**：**跨场景路由**。把「正视 × 可解码符号 × 民间色硬边 × 压缩单人」迁到抽象正视图标族、单人信息卡、UI 头像态时，§8.1 正向段会强制带回 Tehuana 裙、蜘蛛猴鹦鹉、断柱/心脏/荆棘、迭戈与事故手术的生平词典，把内容对象当风格前提。

**本卡特有的未消歧张力（AUDIT-kahlo accepted 登记）**：§8.2-2 依赖 §5/§12 生平符码表（事故-飞床/手术-断柱/迭戈-肖像坠饰/民族-服饰/宠物-猴与鹦鹉），而 §4 分工注写死与蒙克「互为对侧」、与里维拉「巨幅群像禁止同档」；无 §8.1b 时卡没有「符码表是可选对应层、符号计数/清晰度是必选关系」的拆法，跨场景容易把「可命名生平事件」误当无条件阈值。

## 2. §8.1b 草案新增的跨场景路由能力

| 增量 | 无 §8.1b 的卡 | 本 §8.1b 草案 |
| --- | --- | --- |
| 介质/语义无关的关系量 | §8.1 绑定自画像女子、Tehuana 服饰、猴/鹦鹉/心脏/断柱、热带植被、日期题字 | 拆成 R1–R8：正视(面轴夹角/瞳孔偏角)、符号(可识别物计数/可解码性)、民间色(色相簇/饱和区域数/区域方差)、硬边(过渡带 px/羽化)、背景(纵深平面数/消失点/覆盖率)、单人(人数/占画高/裁切数)、焦平面(符号类别数/清晰度比)、静止(帧间差%/微动%)——全是角度/计数/聚类/梯度/边界框统计量 |
| 默认题材泄漏剥离表 | 无 | §1 表把人物身份/服饰/符号专名/场景/题字体裁逐项降级；给「迁移判据」：撤掉专名后 §8.2 自查仍可算 = 纯风格；R2 只保留「≥2 个可识别物 + 焦平面清晰」，生平词典对应语义不迁 |
| 分工对侧显式化 | 卡内越界警报散落 | §1 注把蒙克「通用原型+全场景变形禁止同档」、里维拉「巨幅群像禁止同档」写成硬边界；C2 登记符号可解码性、C4 登记压缩舞台×单人尺幅 |
| 正例 + 强反例 | 卡只有同域自查三问 | 抽象正视图标族 + 正视肖像徽章/UI 头像态正例；counterexamples.md 4 条 [inference]：撤可解码性改蒙克原型 / 反转尺幅改里维拉群像 / 保留色板改 sfumato 虚化 / 内容泄漏反证 |
| 适用/不适用 + 组合预检 | 散落在越界警报 | 列 7 类不适用（蒙克原型、里维拉群像、sfumato 虚化、深透视壁画、侧身时装、运动镜头、梦境超现实）+ 蒙克/里维拉二选一、Lane B 手写题字例外改写 |

**路由收益（一句话）**：从「认出自画像/生平符号题材 → 套 §8.1 prompt」升级为「读出 R1–R8 关系 → 判断任意正视单人/图标场景是否满足正视×单人、符号计数×焦平面清晰等耦合，并把生平符码表当作可选对应层」；跨场景判定**不再依赖 Tehuana 裙或断柱**。
