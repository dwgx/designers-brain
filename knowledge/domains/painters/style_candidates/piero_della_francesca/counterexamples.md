# 风格级强反例 — `piero_della_francesca` [inference]

> 下列 3 例纯属纸面判读：不渲染、不接通道、不做 E4。每例写明撤去/反转项、失效关系与皮耶罗 §8.2 行号；圣像与柱廊题材词全部原样保留以证伪内容即风格。

<a id="db-source-line-5"></a>
## CE-P1 — 撤去清晰边缘：把几何轮廓换 sfumato 宽灰过渡

**操作**：题材全保留(柱廊/静立人物/浅色调/主轴/浅影)，只把「清晰连续轮廓 + 可读几何影」换成达·芬奇式 sfumato 宽灰渐变带(≥1.5%短边)、无轮廓线、空气透视溶解远景。**被破坏的规则**：R7(§8.2-7 L194 折线≤6段、直线占比≥30%)直接 fail；R8(§8.2-8 L195 影为可读几何形、自洽≤15%)→影被雾溶解不可拟合；R5(§8.2-5 L192 明度中位≥0.55)→中间调回流；连带破 C2/C3。**为何是风格级反例**：只换「边缘/影由什么承载」这一关系，证明 piero 身份轴是透视测量×清晰几何(C1/C2)，不是「画的是不是圣像」。对应 §4 越界警报①、C-02。

<a id="db-source-line-9"></a>
## CE-P2 — 反转空间：保留轴线但改色阶调制与扭转人体

**操作**：保留贯穿主轴、浅色调、静止尝试、几何影；把「透视测量生成空间」换成塞尚式色阶调制/轮廓破碎/黑影蓝阴影，并把静立人体改成肩髋反向扭转、硬边凿刻影。**被破坏的规则**：R1(§8.2-1 L188 质心偏差≤2%)→轴线被打散；R2(§8.2-2 L189 收敛≤2点)→多点透视/远近同尺度；R5(§8.2-5 L192 高饱和≤3%、平均饱和≤0.35)→黑影；R6(§8.2-6 L193 镜像≥70%)→扭转；拆 C1/C4。**为何是风格级反例**：主轴与浅色调全在、题材全在，风格仍不成立——反驳「认出轴线+浅色就是皮耶罗」；证明「可测空间」是收敛拟合关系。对应 §4 越界警报②/④、§3.1 vs 塞尚/米开朗基罗。

## CE-P3 — 内容泄漏反证：把受洗/鞭笞/阿雷佐/透视论升为必要条件

**操作**：不改任何像素，只在集成时把 §8.1 的 `Baptism / Flagellation / sacred narrative / Tuscan valley` 与「De prospectiva pingendi 数学著作」写成 §8.1b 无条件前提。**后果**：抽象轴线网格海报与等距 UI 信息图会被误判「不像皮耶罗」，而 §8.2 的 8 条统计量本不依赖任何圣像题材或理论著作名。**结论**：作品名/圣像/地名与作者著作是 R1/R2 的轴线/收敛关系与题材档位(§5 自述为著作文字级证据、按操作陈述使用)，不是风格前提；本反例破的是规则写法，不是像素。
