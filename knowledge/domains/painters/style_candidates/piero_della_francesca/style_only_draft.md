## 1. 默认题材泄漏的剥离

dossier §8.1 正向段把「皮耶罗·德拉·弗朗切斯卡」强绑定在一组**内容对象**上，本段逐项降级为关系量：

| §8.1 内容词 | 为什么不是风格前提 | 本段处理 |

| `Baptism / Resurrection / Flagellation / Brera / Arezzo True Cross / Tuscan valley` | 作品名、圣像题材与托斯卡纳地名是叙事内容；可判读的是「垂直主轴贯穿≥80%帧高 + 质心偏差≤2%帧宽」 | 删除专名，保留 §8.2-1 的**列梯度投影 + 质心检测**(R1)；叙事歧义(鞭笞 500 年解释史)不迁 |

| `sacred narrative / angel descending with a cross / faces impassive and timeless` | 宗教体裁与「永恒」品题是阐释；可判定的是「夜景档最亮连通域与发光体距离≤5%帧宽 + 径向衰减 R²≥0.8」与「静止规则」 | 改写为 R4 的**亮度场径向衰减拟合**与 R6 的**光流/镜像匹配**，删神圣语义 |

**迁移判据**：迁移判据：换掉全部圣像/作品/地名专名与「数学/神圣/永恒」阐释后，§8.2 的 8 条自查（列梯度投影+质心+地砖行计数、Hough 拟合+消失点求交、阴影方向直方图+影长比、亮度场径向衰减拟合、HSV 统计、光流+镜像匹配+视线、多边形近似误差+直线占比、影形拟合+光向一致性）仍可逐帧计算 → 纯风格。按此判据 8 条全可迁；夜景档(P3 显式切换)只保留**径向衰减统计量**，光源的「天使」语义不迁。

**必要耦合（拆开会破，`[归纳]`）**：

- **C1 ⟨R1∧R2⟩「主轴网格 × 透视收敛」**：这是 §4 L102 明写的「是不是皮耶罗」双判据：贯穿主轴(R1)给消失点(R2 ≤2 个、误差≤1.5°)一个对称锚；若改自由构图/多点透视/远近同尺度，则轴线与收敛同破 → 越界塞尚(§4 越界警报②、§3.1 vs 塞尚)。
- **C2 ⟨R3∧R8⟩「光一致 × 影形几何可读」**：影向夹角≤10°/影长≤25%(R3)与「影是可读几何形、与光向自洽≤15%」(R8)共同把影当**构件**而非气氛；若改 sfumato 宽灰过渡带/无轮廓线，则影失去可拟合形状 → 越界达·芬奇(§4 越界警报①、C-02)。
- **C3 ⟨R5∧R7⟩「珍珠浅调 × 低多边形轮廓」**：低饱和高明度(R5)给 ≤6 段折线近似(R7)一个均匀哑光承载面；若出现高饱和/黑影蓝阴影/碎片化高频轮廓，则「均匀表面」破 → 越界塞尚/巴洛克(§4 越界警报②、§8.1 负向 L176)。
- **C4 ⟨R6∧R1⟩「静止 × 轴线」**：镜像对称≥70%、直视≤1(R6)与主轴质心对齐(R1)共同构成「仪式化静立」；若人体扭转肩髋反向(米开朗基罗)或巴洛克 turbulence，两者同失 → §4 越界警报④、§3.1 vs 米开朗基罗。
- **C5 ⟨P3昼/夜开关∧R3/R4⟩「档位互斥」**：昼档启用 R3(影一致+无第二主光源)、夜档启用 R4(画内发光体径向衰减)——P3 是**单主档位开关**，不可同时套两套光源自查；AUDIT 登记《圣诞》「影被刻意省略」(§7-2 L138)属神迹档特例，本 lane 只登记不改写。

## 3. 正例（跨场景，逐帧可自查）

**正例 1 — 抽象轴线网格海报（无圣像、无教堂）**：一条贯穿 85% 帧高的垂直主轴、质心偏差 1.2% 帧宽、地砖 7 行近大远小(R1)；直线向 1 个消失点收敛、拟合误差 1.1°(R2)；昼档投影方向夹角 7°、影长 18% 物高、无次峰(R3)；平均饱和 0.28、明度中位 0.62、高饱和 2%、主色相 4(R5)；无运动模糊、镜像对称 78%、直视 0(R6)；山体轮廓 5 段折线、建筑直线占比 38%(R7)；1 处椭圆影与光向自洽 10%(R8)。八条全是列梯度/Hough/HSV/折线拟合统计量，无需认出受洗或鞭笞。

**正例 2 — 建筑透视 UI / 透视信息图（内容全换）**：贯穿主轴 + 单点透视收敛 + 一致浅影 + 珍珠浅调 + 静止 + 低多边形轮廓 + 几何影。R1–R8 仍逐条可算；仅声明视觉关系可迁，不声称任何生成通道已产出、不声称 E4 通过。

## 4. 强反例（题材全对但风格不成立）

**强反例 1 — 题材全对但换成 sfumato 宽灰过渡**：画出柱廊、静立人物、浅色调、轴线(题材齐备)，但把清晰几何轮廓换成达·芬奇式 sfumato 宽灰渐变带(≥1.5%短边)、无轮廓线、空气透视溶解远景 → 破 R7(折线≤6/直线≥30%失)、R8(影形不可拟合)、R5(中间调回流)、拆 C2/C3；§4 越界警报① 即此。**题材齐全≠风格成立**。

**强反例 2 — 保留轴线但改色阶空间+扭转人体**：题材不变，把透视测量空间换成塞尚式色阶调制/轮廓破碎/黑影蓝阴影，人体改肩髋反向扭转 → 破 R1/R2(收敛失)、R5(黑影)、R6(镜像<70%)、拆 C1/C4；§4 越界警报②/④。

**强反例 3 — 内容泄漏反证**：把「必须是受洗/复活/鞭笞/阿雷佐真十字架/圣墓镇/皮耶罗数学著作」写进 §8.1b 必要条件 → 抽象轴线网格海报与透视 UI 信息图会被误判「不像皮耶罗」；圣像题材与理论著作名是 R1/R2 的轴线/收敛关系与题材档位，不是风格前提(§5 自述为著作文字级证据)。

## 5. 适用 / 不适用条件

**适用**：① 建筑/单点或双点透视类输出(列梯度+Hough+HSV+折线拟合可逐帧查)；② 需「主轴+可测空间」的信息图/版式；③ 需一致浅影/几何影的渲染通道；④ 需静止仪式化的对称构图。

**不适用**：① 需 sfumato 宽灰过渡/空气透视(破 R7/R8，越界达·芬奇)；② 需色阶调制/轮廓破碎/黑影蓝阴影(破 R1/R2/R5，越界塞尚)；③ 需画外单光+近黑背景(破 R3，越界卡拉瓦乔)；④ 需扭转人体/硬边凿刻影(破 R6，越界米开朗基罗)；⑤ 需点状高光群+左窗高调暗部压平(破 R5，越界维米尔)；⑥ 需巴洛克 turbulence/夸张表情(破 R6)。

**组合预检（沿用 dossier）**：C-02(明暗过渡带宽度——vs 达·芬奇单主轴处置)、C-05(笔触——两模块同侧可协同)、C-10(深度衰减——vs 塞尚两向相反)、C-01(硬阴影——皮耶罗要浅而一致的影、不封堵)、C-14(渐变——皮耶罗的光是均匀而非渐变雾、按 N1 改写句式)；§3.1 vs 达·芬奇/塞尚/米开朗基罗分工为正本。
