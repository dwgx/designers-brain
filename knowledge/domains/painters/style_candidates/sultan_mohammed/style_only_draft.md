### 2.2 可原样转移的形式子集（对无人物/文字的几何输入仍可定义）

仅以下量**不依赖「认出人物/面孔/文字/事件」这一语义前提**，可在纯色块/线/面积上计算：
- **R2**（色相簇数、饱和面积、空场占比）；

## 3. 组合条件（旧「五条必要耦合」已校准）

旧版 C1–C5 统一句「两条规则共享同一关系量；拆开后另一条阈值统计不再可判定」**不是通用真理，也无 §4 支持**，已删除。可复核反证：R1（姿态/事件）与 R2（色相/饱和/空场）**可分别判定**——去掉人物姿态要求后色相/饱和统计仍可定义；去掉满幅色彩要求后姿态角度仍可判读。故「计算上不可分」不成立。

**有来源的联合身份判据（准确引用 §4 L107）**：P1/P2/P3 定「是不是苏丹·穆罕默德（vs 贝赫扎德）」——**三条中 ≥2 条 ≥ 中档**才成立；§4 L108 分工注另记 P1 弱且 P2/P3 同步收窄、空场增大即越界贝赫扎德；P4 金层出现光泽/材质即越界克里姆特；出现单点透视/光学景深 → 塞尚/欧洲体系。这是**「联合出现有助身份区分」**，不是「五对数学上无法拆分」。

**新增组合假说（标 `[inference]`，未检验）**：
- **H-C1 ⟨R1∧R2⟩**：动势 + 满幅色彩同现可能提高与贝赫扎德的区分度。**对旧不可分说法的反例**：一幅全静场（R1 fail）但色相簇 ≥6、饱和 ≥35%（R2 pass）的图，R2 仍可独立判定 → 二者非不可分，`[inference]`。
- **H-C2 ⟨R3∧R4⟩**：平涂金层 + 拟人化景观同现可能提高识别度。**对旧不可分说法的反例**：金区平涂合规（R3 pass）但无可辨面孔（R4 不适用）的图，R3 仍可判定 → `[inference]`。
- **H-C3 ⟨R1∧R5⟩**：动势 + 无消失点同现可能对应「层叠平面」族征。**对旧不可分说法的反例**：≥1 偏轴 45° 姿态（R1 pass）同时 ≥3 条平行后退线收敛共点（R5 fail）的图，两规则分别可判 → `[inference]`。
- **H-C4 ⟨R2∧R6⟩**：满幅色彩 + 人物比例恒定同现可能提高身份区分。**对旧不可分说法的反例**：含两名等高人物（R6 pass）但色相簇 =4（R2 fail）的图，R6 仍可判定 → `[inference]`。
- **H-C5 ⟨R4∧R7⟩**：拟人化景观 + 预兆装置同现可能提高识别度。**对旧不可分说法的反例**：岩中 3 处可辨脸（R4 pass）但无指向/预兆装置（R7 不适用）的图，R4 仍可判定 → `[inference]`。

> 以上 H-C* 均为未检验的项目工程假说 `[inference]`。上述纸面案例只反驳旧「计算不可分」主张，不能验证或推翻新的识别收益猜想；尚未建立该收益的判别标准。**不得**写成「拆开无法判定」的必要性结论，也不并入 receipt 的 supported observation（见 §7）。

## 6. 适用 / 不适用条件（已校准，逐条连到确切 R-ID）

**适用**：① 含人物/事件/可辨面孔/文本等语义承载、且能逐帧计算面积/直方图/连通域/方向场的稿子 → 八条 R 可逐条判；② 纯平面/矢量/海报类但**只**用形式子集 R2/R3/R5 的路由判定；③ 需要 `R1′/R4′` 替代规则且已声明**不等价**的几何场。

**不适用（逐条给出违规组合，平涂本身不列为拒绝）**：
- 需单点透视/光学景深/≥3 线收敛共点 → 破 **R5**（§4 L108 分工注越界塞尚/欧洲体系）。
- 需金区出现光泽/材质起伏（金区明度动态范围 >5%）或升成材质性金饰 → 破 **R3 / 越界克里姆特**（§4 L108）；**平涂金面本身合规，不是拒绝条件**。
- 需大块未图案化空场（>20%）、色相簇 <6 或高饱和面积 <35% → 破 **R2**。
- 需人物高度随纵深缩放（同帧方差 >15%）→ 破 **R6**（仅当有人物时适用）。
- 需把默认题材专名写成 §8.1b 必要条件 → 内容泄漏，破的是规则写法（§5 CE-SU-4）。
