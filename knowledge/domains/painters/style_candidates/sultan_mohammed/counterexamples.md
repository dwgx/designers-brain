## CE-SU-1（像素反例，针对 R1）

- **基线（含语义承载）**：稿中 ≥1 人物姿态偏轴 45°（相对垂直轴）、含事件性动势（奔/斗），满足 R1；其余 R2/R3/R4/R5/R6/R7/R8 输入与 [style_only_draft.md](style_only_draft.md) §4 正例 2 一致。
- **保持项**：题材对象、全部色板（7 簇 / 高饱和 40% / 空场 15%）、金区平涂参数（12%、明度动态范围 ≤5%）、直线族平行、等高双人物、指向装置及空间分离、文本栏——**全部不变**；**R1 的人物姿态／事件性动势不属于保持项，按下项修改**。
- **单项改变**：把所有人物姿态改为偏轴 <30° 且移除全部事件性动势（抹去奔/斗/坠/旋，改为全静场端坐）。
- **具体 R-ID**：**R1**（§8.2-1 L201）。
- **跨越门槛结果**：R1 要求「≥1 人物姿态偏轴 ≥30° **或** 事件性动势」；改后两个条件都为 0 → 「全静场判失败」触发 → **R1 fail**。改变项直接跨过 R1 的 30°/事件门槛，本例只判定 R1 的两个析取支均为 false；其他规则是否仍适用或满足，应按修改后输入分别记录，不由本例预先保证。 [inference]
- **为什么不反转明暗**：反转明暗/层次（渐变↔并置 / 硬切↔衰减 / 平滑↔笔触）改的是**明暗处理**，与 R1 的姿态角度/事件计数无关；保留 45° 姿态即可使 R1 仍为 true（见作废说明）。

## CE-SU-2（像素反例，针对 R3）

- **基线**：稿中金区 H 35–55° / S≥0.5 / V≥0.7、面积 12%（金天档）、**平涂**、区域内部明度动态范围 ≤5% → R3 pass。
- **保持项**：题材对象、题材内容、色域（7 簇 / 高饱和 40%）、金区色相/饱和/面积（12%）、空场 15%、人物姿态、指向装置、文本栏、直线族平行——**全部不变**。
- **单项改变**：只令**已定义金区**内部出现高光/光泽起伏，使其**明度动态范围 >5%**（例如设为 8%）；其余一切不动。
- **具体 R-ID**：**R3**（§8.2-3 L203）。
- **跨越门槛结果**：R3 要求「平涂色面、区域内部明度动态范围 ≤5%（无高光/光泽起伏）」；改后 >5% → **R3 fail**，并按 §4 L108 分工注越界克里姆特。**平涂本身不是拒绝条件**；被拒绝的是金区出现光泽/材质起伏这一组合（§8.3 L216 / C-16）。改变项只跨 R3 的 5% 门槛；R2（色相/饱和/空场）与 R5（汇聚线）保持项未动，故不能写成 R2/R3「方向性统计量失守」。 [inference]

<a id="db-source-line-24"></a>
## CE-SU-3（像素反例，针对 R5；空间机制的正确落点）

- **基线**：全帧直线族平行后退、0 组 ≥3 条线收敛共点 → R5 pass。
- **保持项**：题材对象、全部颜色属性（色相簇 7 / 高饱和 40% / 空场 15%）、**金层全部属性（含平涂、12%、明度动态范围 ≤5%）**、人物姿态、指向装置、文本栏——**全部不变**。
- **单项改变**：把直线族改为 **≥3 条平行后退线收敛于同一共点**（引入单点透视消失点）。
- **具体 R-ID**：**R5**（§8.2-5 L205）。
- **跨越门槛结果**：R5 要求「0 组汇聚线（≥3 条线共点即失败）」；改后出现 1 组共点 → **R5 fail**，并按 §4 L108 越界塞尚/欧洲体系。**该项只动空间机制**：R2（颜色）与 R3（金层）保持项完全未变，因此不推出 R2 或 R3 失败——这正是旧版 CE-SU-2 把「变化透视」错配成 R2/R3 的纠正。 [inference]

## CE-SU-4 — 内容泄漏反证（单独列出，**不是像素反例**）

- **操作**：不改任何像素，只在集成时把 §8.1 的 苏丹·穆罕默德 默认题材专名写成 §8.1b 无条件前提。
- **后果**：无题材专名但满足形式子集 R2/R3/R5 的抽象关系海报（§4 正例 1）会被误判「不像 苏丹·穆罕默德」；§8.2 形式子集的统计量本不依赖器物专名。
- **结论**：破的是**规则写法**（把内容对象当风格前提），不是像素。按 S12 §A 要求单列，不充当前三条像素反例之一，不计入「3 条视觉规格」数量。 [inference]

## 作废说明（旧版两条的逻辑反证，非新反例）

- **旧 CE-SU-1 作废**：操作是反转明暗/层次，却判 R1 fail。可复现反证：保持人物姿态偏轴 45° 及事件动作不动，只修改明暗处理 → R1 的「≥30° 或事件性动势」仍为 true。该操作可能破坏别的规则（如影响明度统计），但**不能由此推出 R1 必败**。已由新 CE-SU-1 以「全静、所有姿态 <30°、无事件动势」替换，才真正跨 R1 门槛。
- **旧 CE-SU-2 作废**：只说反转光位/空间/纵深，却判 R2、R3「方向性统计量失守」。R2 是色相簇/饱和面积/空场，R3 是金区色域/明度动态范围/面积，都不是方向性统计；**仅改变线条为汇聚透视、保留颜色/金层属性，并不必然使 R2/R3 失败**，它更可能针对 R5（见新 CE-SU-3）。已按「固定题材/色域/面积、只令金区明度动态范围 >5%」重建为针对 R3 的新 CE-SU-2。
