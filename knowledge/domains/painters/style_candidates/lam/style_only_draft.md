## 1. 默认题材泄漏的剥离

> **威尔弗雷多·林 特有的规则内张力（登记，不消歧）**：§8.2-4 L197「表面高频能量显式中档（介于平涂与厚涂之间——须声明）」与 §3.1 C-05「薄涂渗化、可见但非厚涂」为同一量的定性/组合两写；本段把「显式声明」写入，不擅自给出数值阈值。

**仍带语义前提、不能记「内容全换仍可算」的规则**：R1——「可拆出 ≥2 类部件来源（人/马/鸟/植物/果实）」需认出部件来源，无主体时**不适用**（「拼贴接缝＝0」分项可判）；R5——面具脸/人脸检测与类型化判定，无面孔时**不适用**；R6——仪式符号（月/供盘/烟叶/剪刀）识别与「承担叙事」判定，无符号时**不适用**；R7——夸张部件与雌雄特征判定需身体语义，无人物时**不适用**。

**替代规则（项目提案，不等价，新 ID）**：若要给纯几何输入覆盖 R1 的「生长式合体」，必须另立新 ID 并声明**不等价**：**R1′（提案，不等价于 R1）**：≥1 个连通主体轮廓、边界呈融合/嵌套过渡（无直线剪切边）——去掉「部件来源（人/马/鸟/植物）识别」前提；**不等价**于 R1，不能沿用 R1 宣称通过。R1′ 为项目工程假说 `[inference]`，未实测、未渲染。




**组合条件（旧「五条必要耦合」已校准）**：

旧版 C1–C5 对五对耦合统一写同一句「拆开会破——vs 毕加索/博斯…」（uniqJust=1），**不是逐对论证，也无 §4 支持**，已删除；可复核反证：R3（色域）与 R6（仪式符号）可分别判定——去掉符号要求后 HSV 统计仍可算，去掉色相聚类后符号检测仍可执行，故「计算上不可分」不成立。

**有来源的联合身份判据（准确引用 §4 L105 用法 + L106 越界警报）**：**P1/P2 定「是不是林飞龙」的起步**——两条中 ≥1 条 ≥ 中档才成立（混种合体或满幅丛林）；P3 定氛围（暗域档）；P4 定仪式档；P5/P6 定身体-面部档。L106 越界警报：①碎裂/多视点/拼贴物→毕加索；②明亮全景＋多事件编目＋可解码道德讽喻→博斯；③装饰性热带色→高更/塔西拉侧；④植物学细描＋透视消失点→卢梭式；⑤壁画工程尺度＋历史全景→里维拉。这是「联合出现有助身份区分」，不是「五对数学上无法拆分」。

**逐对假说（标 `[inference]`，各带可推翻反证）**：
- **H-C1 ⟨R1∧R2⟩**：混种合体 × 满幅密度同现可能构成「沉浸丛林」身份（对应 P1+P2 定身份）。**反证**：负空间 12%、触边率 92%（R2 pass）但主体为单物种装饰变形（R1 弱档/fail）的画面，R2 仍可独立判定 → 非不可分，`[inference]`。
- **H-C2 ⟨R2∧R3⟩**：满幅无地平线 × 暗域色同现可能对应「夜色丛林」档。**反证**：红橙 5%、平均明度 0.4（R3 pass）但天空可见 20%（R2 fail）的画面，两规则分别可判 → `[inference]`。
- **H-C3 ⟨R3∧R6⟩**：暗域 × 仪式符号同现可能提高仪式档识别。**反证**：1 个可辨符号（R6 pass）但亮色铺开（R3 fail，越界高更侧）的画面，R6 仍可判定 → `[inference]`。
- **H-C4 ⟨R4∧R5⟩**：露纸薄涂 × 面具脸同现可能对应「纸本仪式」质感。**反证**：面具脸 1（R5 pass）但出现厚涂高光（R4 fail）的画面，R5 仍可判定 → `[inference]`。
- **H-C5 ⟨R1∧R7⟩**：混种合体 × 性征并置同现可能提高身份区分（对应 P1+P5）。**反证**：1 处 1.6× 夸张部件（R7 pass）但无可拆 ≥2 类部件来源的主体（R1 fail）的画面，R7 仍可判定 → `[inference]`。

> 以上 H-C* 均为项目工程假说 `[inference]`，各带能推翻它的纸面情形；不得写成「拆开无法判定」的必要性结论，也不并入 receipt 的 supported observation（见 §6）。

## 3. 正例（跨场景，逐帧可自查）

**正例 1 — 抽象暗域纹理板（无题材专名，纸面规格）** `[inference]`

输入（完整、可逐项判定）：无人物/面具/仪式符号/身体部件；负空间 12%、地平线检测无、四边触边率 92%；主色相 4（绿/黑/赭/红橙）、红橙 5%、高饱和 10%、平均明度 0.4；露纸 12%、滴点 4、厚涂高光 0；竖线族 4 组、弧线与竖线交替、重心偏下。

| R2 | 适用 | pass | 负空间 12%≤15%、地平线无、触边 92%≥90%（§8.2-2） |
| R3 | 适用 | pass | 主色相 4≤4、红橙 5%∈[2,8]、高饱和 10%≤12%、明度 0.4≤0.45（§8.2-3） |
| R4 | 适用 | pass | 露纸 12%∈[5,20]、滴点 4≥3、厚涂高光 0（§8.2-4） |
| R5 | **不适用** | 未知/不计通过 | 无面具/人脸承载 |
| R6 | **不适用** | 未知/不计通过 | 无仪式符号承载（不再声称「1 个节律符号承担构图」） |
| R7 | **不适用** | 未知/不计通过 | 无身体部件承载（不再声称「1.6× 夸张部件、雌雄同体」） |

## 5. 适用 / 不适用条件

**适用**：
1. 平面/暗域纹理/生长式图标族（部件模板+分区直方图+HSV+方向直方图可逐帧查）
2. 需人-兽-植物连续过渡、无拼贴接缝的构图
3. 暗绿-赭-黑+红橙闪点（2–8%）的版式
4. 露纸薄涂、哑光无清漆的渲染通道

**不适用**：
1. 需面片碎裂/多视点/拼贴物（破 R1/R4，越界毕加索）
2. 需明亮全景+多事件编目（破 R2/R3，越界博斯）
3. 需装饰性热带色/图案化植物（破 R3，越界高更/塔西拉）
4. 需植物学细描+透视消失点（破 R2，越界卢梭）
5. 需壁画工程尺度+历史全景（破 R2，越界里维拉）

**组合预检（沿用 dossier）**：vs 毕加索（§3.1 L77–82：生长式合体/加勒比仪式 vs 面片碎裂/拼贴物/欧洲神话）、vs 博斯（L83–88：仪式在场/沉浸丛林 vs 道德编码/百科全景）；按 [conflicts.md](../../../../cross/conflicts.md) 预检，冲突轴单主（N3），不得双开标志机制。
