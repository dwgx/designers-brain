## 1. 默认题材泄漏的剥离

| §8.1 内容词 | 为什么不是风格前提 | 本段处理 |
|---|---|---|
| `dancers / rehearsal room / theatre interior / ballet` | 人物身份与场所是题材；可判读的是「偏心裁切 + 高视点 + 对角地板线 + 人工方向光」 | 删除专名，保留 §8.2-1/-2/-3 的几何/光度关系 |
| `adjusting a ribbon, tying a shoe, rubbing a tired muscle, stretching, waiting` | 动作语义是内容；关系量是「过程态/失衡」（重心投影偏离支撑面 ≥10% 身高、左右臂展差 ≥20%） | 改写为 §8.2-6 的姿态统计量 |
| `white tulle, skin, the sheen of the floor / tutus` | 具体受光物是内容；关系量是「亮部集中 ≤35% + 可见光路/方向性光源」 | 保留 §8.2-3 的亮度直方图关系 |
| `several figures seen from behind … no eye contact` | 人物朝向是内容；关系量是「焦点人形中背对/侧背 ≥1/3、直视面孔 ≤1/3」 | 保留 §8.2-4 的实例计数关系 |
| `pastel over monotype or charcoal` | 具体媒介是内容档（P4 时期/媒介参数）；关系量是「可见笔触 ≥70% + 方向族 2–5 + 色层 ≥2」 | 降为 P4 档位，保留 §8.2-5 的表面统计 |

**迁移判据**：换掉全部人物/场所/媒介名后，§8.2 的 8 条自查（质心计算+边缘切割计数+Hough、消失点估计+区域分割、亮度直方图+光源检测、人脸关键点+姿态估计、边缘方向场+渐变带检测+色彩层分析、姿态估计+支撑点计算、SSIM 构图相似度聚类、底材色检测+完成度热力图）仍可逐帧算 → 纯风格。

> **degas 特有的工作流参数**：§4 P6「系列/变体幅度」被明确归为**工作流参数**（不进画面重叠计算，`expansion.md §4.3 规则 5`），§8.2-7 也标「工作流参数」。本段把它列为**可选族谱关系**（同一构图家族 ≥2 变体，SSIM ≥0.6 归族），不写成画面内必要像素条件。AUDIT-degas 的 A-55 原书级核验（Moore 1891 / Vollard 1927 八条引文定位）确认「repetition is exactly what the dancers do」是**操作陈述**，不是内心状态证据。

## 2. 可迁移视觉关系（参数 · 单位 · 范围 · 必要耦合）— 取景/人工光/方向笔触/过程态四族；全部 `[归纳] 未实测` [STYLE-degas]

| ID | 可迁移关系 | 单位 / 范围 `[归纳]` | 源行 |
|---|---|---|---|
| R1 | **偏心裁切 / 对角切入**：主体簇质心偏离画面中心 ≥15% 画宽；≥1 个主要实例被画框边缘切割；对角元素（地板线/台边/谱架）横跨 ≥60% 画宽 | 质心偏(≥0.15 画宽)、切割(≥1)、对角横跨(≥0.60 画宽) | §8.2-1；§4 P1 |
| R2 | **高视点 / 地板收敛**：视平线 ≥55% 画高（俯角 10–25°）；工作平面占 ≥20% 面积；地板线族 ≥3 条向消失点收敛 | 视平线(≥0.55 画高)、俯角(10–25°)、平面(≥0.20)、线族(≥3) | §8.2-2；§4 P1 |
| R3 | **人工方向光 / 亮部集中**：方向性光源（亮暗分界夹角 ≤45°）或可见光路；亮部（V≥0.9）集中面积 ≤35%；暗部 ≥30% 时脸/手仍可读 ≥1 处 | 夹角(≤45°)、亮部(≤0.35)、暗部(≥0.30) | §8.2-3；§4 P3 |
| R4 | **背面/转身比例**：焦点实例（面积前 3 位）中背对/侧背 ≥1/3；直视观众的面孔 ≤1/3 | 背对(≥1/3)、直视(≤1/3) | §8.2-4；§4 P5 |
| R5 | **方向性笔触 / 多层表面**：可见笔触覆盖 ≥70%；方向族 2–5 个；平滑渐变带宽度 ≤2% 短边（禁 sfumato）；可见色层 ≥2 | 覆盖(≥0.70)、方向族(2–5)、渐变带(≤2% 短边)、色层(≥2) | §8.2-5；§4 P4；C-05 |
| R6 | **失衡「过程态」**：≥1 实例重心投影偏离支撑面 ≥10% 身高（或单点支撑/悬吊）；肢体非对称伸展（左右臂展差 ≥20%） | 重心偏(≥0.10 身高)、臂展差(≥0.20) | §8.2-6；§4 P2 |
| R7 | **族谱/变体（工作流，可选）**：同一构图家族（姿态/机位/房间）≥2 变体可对读；单帧发布标「家族编号+变体序号」；SSIM ≥0.6 归族 | 变体(≥2)、SSIM(≥0.6) | §8.2-7；§4 P6 |
| R8 | **未完成/过程感**：可见未覆盖底子 ≥5% 面积；允许拼贴/覆盖/重描痕迹；禁「全画均匀收尾」（四角与中心完成度差异 ≥1 档） | 裸底(≥0.05)、完成度差(≥1 档) | §8.2-8 |

**必要耦合（拆开会破，`[归纳]`）**：

- **C1 ⟨R1 ∧ R2⟩「取景框 × 高视点」**：偏心裁切（R1）与高视点地板收敛（R2）共同定义「frame used like a viewfinder, not a stage」。若把视点放平、主体居中且完整（撤掉 R1/R2），画面变成舞台正面全景——§8.1 负向 `no symmetrical centred composition, full uncropped figures, stage-front ballet glamour`。§4 用法把 P1/P2/P5 定为「是不是德加」三条中 ≥2 条 ≥ 中档。
- **C2 ⟨R3 ∧ R5⟩「人工光 × 方向性笔触」**：R3 的亮部集中（≤35%）必须靠 R5 的「可见笔触 + 禁平滑渐变」来表达，而不是靠达·芬奇式 sfumato 渐变；若把光改成「无源自然光 + 大气包络」（越界莫奈，越界警报①），R5 的「渐变带 ≤2% 短边」与 R3 的「夹角 ≤45° 方向光」同时失效。§3.1 光源轴（人工/室内 vs 自然/户外）+ 轮廓（保持 vs 溶解）两轴一起守。
- **C3 ⟨R5 方向族 2–5 ∧ 修拉点阵⟩**：R5 要「方向性排线（2–5 族）」，与修拉「均匀点阵 + 补色光学混合」同轴互斥（C-05）；§8.1 负向 `no uniform pointillist dots, no optical colour mixture, no geometric freeze`。二者不得叠加于同一表面系统。
- **C4 ⟨R6 ∧ R4⟩「过程态 × 背面」**：失衡姿态（R6）与「看而不被看见」（R4 背对 ≥1/3）共同保证「非表演状态」；若把人物全部改成正面直视 + 静止平衡，瞬间抓拍感消失（§8.1 负向 `no smiling faces turned to viewer, no hieratic frontal pose`）。
- **C5 ⟨R8 ∧ R7⟩「未完成 × 变体」**：R8 的「四角与中心完成度差异 ≥1 档」与 R7 的「同族 ≥2 变体」同为**过程/组稿**证据；单幅发布时 R7 可关，但 R8 保留——§4 用法明写 P6 是组稿参数、不进画面重叠计算。

## 3. 正例（跨场景，逐帧可自查）

**正例 1 — 机械车间 / 工作台俯拍（无舞者、无芭蕾）**：偏心的机床簇质心偏 18% 画宽、一侧被画框切掉、对角台边横跨 65% 画宽（R1）；视平线 60% 画高、俯角 18°、工作平面占 28%、地板线族 4 条收敛（R2）；一盏可见顶灯（亮暗分界 30°）、亮部集中 28%、暗部 34% 处仍可读 1 个操作点（R3）；面积前 3 的部件里 2 个「背面/侧背」朝向镜头、0 个正面可读面（R4）；表面可见笔触 78%、方向族 3、渐变带 1.5% 短边、色层 3（R5）；一个悬吊件重心偏 14% 身高、左右展差 24%（R6）；底子裸露 7%、四角比中心低 1 档（R8）；R7 族谱层关闭。**八条自查全是质心/Hough/直方图/方向场/姿态统计，无需认出「舞者/排练室」** → 纯风格成立。

**正例 2 — 无字 key visual（S-06 边界）**：偏心裁切 + 高视点对角 + 人工方向光 + 方向性笔触 + 未完成底子。R1–R8（R7 按档关）仍逐条可算。仅声明关系可迁，不声称生成通道已产出、不声称 E4 通过。

## 4. 强反例（题材全对但风格不成立）

**强反例 1 —「舞蹈课」题材、改自然光大气包络**：画出舞者、排练室、纱裙、把杆（题材齐备），但把脚灯换成户外无源自然光 + 边缘溶解 + 柔和 sfumato 渐变。破 R3（方向光/亮部集中）、R5（渐变带 ≤2% 短边 / 方向族）、C2；§4 越界警报①「→ 越界**莫奈**档」、§8.1 负向 `no plein-air natural light, atmospheric envelope, fog, soft dissolving contours, sfumato` 即此。**题材齐全≠风格成立**。

**强反例 2 — 保留人工光与色板、撤掉形状/裁切**：脚灯、赭/棕/白蓝色板全保留，但把主体居中完整、视点放平、地板线不收敛、全画均匀收尾。破 R1（质心偏 ≥15% / 边缘切割）、R2（视平线 ≥55% / 线族 ≥3）、R8（完成度差 ≥1 档）；§8.1 负向 `no symmetrical centred composition, full uncropped figures`。

**强反例 3（内容泄漏反证）— 把「必须有芭蕾舞者/排练室」当风格前提**：§8.2 全部分母是「质心偏移 / Hough 直线 / 亮度直方图 / 人脸关键点 / 方向场 / 支撑点 / SSIM / 完成度热力图」，没有一条要求认出舞者；§4 P3/P4 被定为「时期与媒介档」，P6 是工作流参数；§8.1 `[sculpture variant]` 甚至允许蜡像/铜像档。若集成时把「dancers in rehearsal」写进 §8.1b 必要条件，车间俯拍（正例 1）与雕塑变体档会被误判「不像德加」。**人物/花卉/风景内容对象不是风格前提**。

## 5. 适用 / 不适用条件

**适用**：① 偏心取景、高视点、有可见人工光源的室内/俯拍类；② 需要「方向性笔触 + 可见色层 + 未完成底子」的表面自查；③ 「过程态/失衡瞬间」的单帧定格（运动以姿态而非模糊表达，§8.1 中文说明）；④ 需要同族变体对读的组稿工作流（R7 可选）。

**不适用**：① **无源自然光 + 大气包络 + 边缘溶解**（破 C2，越界莫奈）；② **均匀点阵 + 补色光学混合 + 几何定格**（破 C3，越界修拉）；③ **画外单光源 + 近黑背景 + 高光只落脸/手/道具**（破 R3，越界卡拉瓦乔）；④ **理想化力量裸体 + 雕塑式完成态**（破 R6/R8，越界米开朗基罗，越界警报④）；⑤ **厚涂能量场 + 全幅互补振动**（破 R5/R8）；⑥ S-06 无文字 key visual 下不补任何标题/排版文字（§8.1 负向 `no text`）。

**组合预检（沿用 dossier）**：C-05（与达·芬奇「只有渐变」硬冲突；与梵高/莫奈/塞尚同侧但机制不同——德加笔触是「描线成面」）、C-01/C-08（硬阴影/运动模糊禁令按句式改写；德加定格 = 单帧冻结）、§3.1 与莫奈（70/30 主导轴 + 大气包络降弱档）/修拉（表面系统不得叠加）分工轴。
