## 1. 默认题材泄漏的剥离

dossier §8.1 正向段把「高更」强绑定在一组**异域—宗教—原始**内容对象上：布列塔尼戴白帽的农妇、路旁 calvary 十字架、塔希提 vahine、芒果林、被放大成神像的雕刻偶像。这些是**题材档位**（§4 P4/P5/P6 明写「定时期与题材档」「方法/组稿参数」），不是像素关系。本段把它们逐项降级为关系量：

| §8.1 内容词 | 为什么不是风格前提 | 本段处理 |
| --- | --- | --- |
| `Breton women in white coiffes / wayside calvary / vahine in a tropical grove / mango trees` | 具名人物、地点、宗教器物是叙事内容；可判读的只有「浅空间水平色带层数」「消失点命中数」这一**几何关系** | 删除专名与地名，保留 §8.2-5「消失点检测 0 命中、水平色带 ≥2 层、天空纯色或图案非渐变」 |
| `carved idols enlarged to the scale of gods / pareu cloth / patterned tree canopies` | 器物清单是象征内容；关系量是「图案区与人物区渲染级别差 ≤1 级、强档图案密度 ≥10% 面积」 | 保留为「装饰同权」的**渲染级别 + 面积比**关系（§8.2-6），不要求认出偶像/pareu |
| `symbolist stillness and mystery / no anecdote` | 情绪与体裁标签不是像素量；可算的是帧间光流 Δ ≤1%/帧、无运动模糊、无镜头运动 | 改写为「合成/静止规则」的**光流 + 模糊核**统计量（§8.2-8），不要求「神秘」语义 |
| `vermilion / cadmium yellow / chrome green / violet` 具体色名 | 色名是内容；风格要件是「主色 ≤10、光学混合点阵 0 命中、主要色块内部明度 σ ≤5%」 | 保留为**色数量化 + 点阵检测**关系（§8.2-3），色名只作示例 |
| `red field where grass would be / lemon-yellow sky / pink sand` | 「草地/天空/沙」是题材所指物；关系量是「≥1 处非自然色区 ≥8% 面积 + 色相异常可检出」 | 保留为**色相异常区面积比**（§8.2-7）与主题锚定的可选对应层，语义对应不迁 |

**迁移判据**：撤掉全部专名、地名、宗教器物与情绪词后，§8.2 的 8 条自查（区域分割+分区统计、边缘/暗像素掩膜、色彩量化+点阵检测、边界梯度剖面、直线透视检测、分区渲染级别比对、色相异常检测、光流场+模糊核）仍可逐帧计算 → 纯风格。按此判据 1/2/3/4/5/6/8 全可迁；7（象征色锚点）只保留其「非自然色区面积 + 可检出异常」关系，主题对应语义不迁。

> 本卡 §4 档位与 §8.2 阈值一一对应，未登记互斥下限；跨场景仍需按档位开关显式取值。 [STYLE-gauguin]

## 2. 可迁移视觉关系（参数 · 单位 · 范围 · 必要耦合）— 平涂色块 × 景泰蓝暗轮廓 × 象征非自然色 × 层叠浅空间四族；全部 `[归纳] 未实测` [STYLE-gauguin]

| ID (gauguin) | 可迁移关系 | 单位 / 范围 `[归纳] 未实测` （gauguin 专属口径：量纲取自 §8.2 L219-226 的「平涂色块」与 §4 L92-102 档位表，跨场景迁移不改此量纲。） | 源行 |
| --- | --- | --- | --- |
| R1 | **平涂色块** | 主要色块(各 ≥5% 画布)内部明度标准差 ≤5%(0–255 尺度 ≤12)、色相变化 ≤8°；全帧渐变带(连续过渡 >2% 短边)面积 ≤10% | §8.2-1 L219；§4 P1 L94 |
| R2 | **景泰蓝暗轮廓** | 暗轮廓(明度 ≤30%)线宽 ≥0.3% 短边；覆盖主要形体边界 ≥60%；线宽变异 ≤2:1(不得时粗时细) | §8.2-2 L220；§4 P2 L95 |
| R3 | **色数与无光学混合** | 主色 ≤10(含黑轮廓)；光学混合点阵 0 命中(点径 ≤2px 孤立像素簇不得 ≥5% 面积) | §8.2-3 L221；§4 P1 用法 L101 |
| R4 | **硬边界** | 色块边界梯度带 ≤1% 短边(无羽化/抗锯齿宽边)；相邻色块明度跳变 ≥15% | §8.2-4 L222；§4 P1 用法 |
| R5 | **层叠浅空间** | 线性透视消失点检测 0 命中；水平色带 ≥2 层(绿/黄/红类)；天空区为纯色或图案、非渐变 | §8.2-5 L223；§4 P4 L97 |
| R6 | **装饰同权** | 图案区与人物区渲染级别差 ≤1 级(同为平涂)；强档图案密度 ≥10% 面积 | §8.2-6 L224；§4 P5 L98 |
| R7 | **象征色锚点** | ≥1 处非自然色区(红草地/黄天/粉沙/紫影)≥8% 面积，色相异常可检出 | §8.2-7 L225；§4 P3 L96 |
| R8 | **合成/静止** | 场景不可对景复原(多源拼合)；静止悬置——事件外光流 Δ ≤1%/帧、无运动模糊、无镜头运动 | §8.2-8 L226；§4 P6 L99(方法) |

**必要耦合（拆开会破，`[归纳]`）**：

- **C1 ⟨R1 ∧ R2⟩「平涂 × 景泰蓝轮廓」**：这是高更身份的双护栏（§4 用法「P1/P2/P3 三条中 ≥2 条 ≥中档才成立」）。若保留平涂却撤掉暗轮廓 → 越界**马蒂斯/塞尚**（越界警报①）；若保留轮廓却让色块内出现 >5% 渐变/笔触 → 越界塞尚且破 R1。二者必须同时成立。
- **C2 ⟨R1 ∧ R3⟩「平涂 × 点阵 0 命中」**：平涂色区（内部明度 σ ≤5%）与光学混合互斥：表面一旦出现点阵/光学混合 ≥40% → 越界**修拉**（越界警报②，§3.1 表面轴同轴不可叠加）。平涂与零光学混合是同一个表面关系的正反表述。
- **C3 ⟨R4 ∧ R2⟩「硬边界 × 暗轮廓」**：色块边界梯度带 ≤1% 短边（无羽化）给暗轮廓线一个可判读的落点；若边界改成 sfumato 宽渐变，R2 的「覆盖 ≥60% 形体边界」失去可测边界，越界警报④（蒙克侧变形）/①（塞尚侧）同时触发。
- **C4 ⟨R5 ∧ R6⟩「层叠浅空间 × 装饰同权」**：水平色带 ≥2 层、无消失点，意味着图案与人物只能**同处一个浅层**；§8.2-6 的「渲染级别差 ≤1 级」正是这个浅空间的直接后果。若恢复单点透视深空间，装饰图案会被压成背景细节，破 C4。
- **C5 ⟨R7 ∧ R3⟩「象征色 × 主色 ≤10」**：非自然色区 ≥8% 面积是**色相异常**，但必须落在「主色 ≤10」的量化预算内；否则变成全画面互补色振动 → 越界**梵高**（越界警报③，厚涂方向性笔触 ≥60%）。象征色是受色数约束的色相关系，不是「颜色越怪越好」。

## 3. 正例（跨场景，逐帧可自查）

**正例 1 — 抽象色带海报（无农妇、无十字架、无热带果林）**：一张由 3 条水平色带（绿/黄/红）叠成的版式，各色块内部明度 σ ≤5%、色相变化 ≤8°、无渐变（R1）；主要形体边界 ≥60% 被明度 ≤30%、线宽 ≥0.3% 短边的暗轮廓勾住、线宽变异 ≤2:1（R2）；主色 ≤10、点阵 0 命中（R3）；边界梯度带 ≤1% 短边、相邻明度跳变 ≥15%（R4）；消失点 0 命中、天空区为纯色（R5）；一处几何纹样与主体同为平涂、渲染差 ≤1 级、占 12% 面积（R6）；一处 10% 面积的柠檬黄非自然色区（R7）；帧间光流 Δ ≤1%/帧、无模糊（R8）。**八条自查全是分区统计/边缘掩膜/色相直方图/透视检测，无需认出布列塔尼或塔希提** → 纯风格成立。

**正例 2 — UI 图标族 / 数据色阶（内容全换）**：平涂分区 + 景泰蓝描边 + 主色 ≤10 + 硬边界 + 无透视色带层叠 + 装饰纹样同权 + 一处非自然色强调 + 静止无动效。R1–R8 仍逐条可算。仅声明视觉关系可迁，不声称任何生成通道已产出、不声称 E4 通过。

## 4. 强反例（题材全对但风格不成立）

**强反例 1 — 题材全对但改点阵混合**：画出白帽农妇、十字架、热带果林、红草地、偶像（题材齐备），但把平涂色区改成修拉式点径 2–5px、覆盖率 ≥85% 的点阵并置、光学混合 ≥40%。破 R1（色块内明度 σ 失控）、R3（点阵 0 命中失效、主色量化失效）、连带破 C2；§4 越界警报②即此。**结论：题材齐全≠风格成立**。

**强反例 2 — 保留色名却改厚涂方向性笔触**：题材不变，把平涂改成梵高式覆盖 ≥60% 的厚涂方向性笔触 + 全画面补色振动。破 R1（内部明度变化 >5%）、R4（边界梯度带被笔触打散）；虽然主色名仍可叫朱红/铬黄，但 R7 的「非自然色区」与 R3 的「主色 ≤10」一起失效（越界警报③）。

**强反例 3 — 改单点透视深空间**：题材不变，把层叠浅空间改成有消失点的深景、天空加空气透视渐变。破 R5（消失点 0 命中失效）、R1（天空渐变带 >10% 面积）、连带破 C4（装饰不再同权）。越界进入写实/学院档（§8.1 负向 `single-point perspective, deep space, atmospheric effects, sfumato`）。

## 5. 适用 / 不适用条件

**适用**：① 平涂/矢量/版式类输出（色块分区、暗轮廓、硬边界可逐帧查）；② 需要「平涂 × 描边 × 非自然色强调」的装饰/图标/海报；③ 需要浅空间色带层叠的信息图；④ 无渐变、无点阵、无线密度明暗约束明确的渲染通道。

**不适用**：① 需要**点阵/光学混合**的场景（破 R1/R3，越界修拉）；② 需要**色块内渐变/可见笔触/sfumato**的场景（破 R1，越界塞尚/马蒂斯①）；③ 需要**厚涂方向性笔触 + 全画补色振动**的场景（破 R1/R7，越界梵高）；④ 需要**单点透视深空间/空气透视**的场景（破 R5，越界写实档）；⑤ 需要**物理不可能变形/无脸化**的场景（破 R2/R6，越界蒙克，越界警报④）；⑥ 色彩沦为纯装饰配比、无象征色异常区（破 R7，越界马蒂斯装饰端，越界警报⑤）；⑦ 需要运动镜头/动效叙事的场景（破 R8 光流 ≤1%/帧）。

**组合预检（沿用 dossier）**：§3.1 与马蒂斯（轮廓有/无、色彩功能象征/配比）、修拉（表面同轴不可叠加）、梵高（笔触可见度 ≤15% vs ≥60%）、蒙克（物理变形）四条分工轴；C-07/C-14 类线功能与渐变禁令预检。
