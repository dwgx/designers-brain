# 风格级强反例 — `gauguin` [inference]

> 全部为**纸面推演 [inference]**，未渲染像素、未跑生成通道、未做 E4。每条给具体撤去/反转/保留操作，点名被破坏的 §8.1b 关系 ID 与 dossier §8.2 规则行。题材对象（白帽农妇、calvary、vahine、芒果林、偶像、红草地、朱红/铬黄色名）全部保留，证明「题材齐备≠风格成立」。[STYLE-gauguin]

## CE-G1 — 撤去表面：把「平涂 + 点阵 0 命中」改成修拉式点阵光学混合

**操作**：题材全保留；只把色区机制从「平涂、无渐变、点阵 0 命中」换成点径 2–5px、覆盖率 ≥85% 的并置点阵、光学混合 ≥40%。

**被破坏的规则**：
- R1（§8.2-1 L219「主要色块内部明度标准差 ≤5%、色相变化 ≤8°」）→ 直接 fail；
- R3（§8.2-3 L221「光学混合点阵 0 命中、主色 ≤10」）→ 直接 fail；
- 连带破 C2（平涂 × 点阵 0 命中）、C1（平涂身份护栏）。
- 对应 §4 越界警报②「表面出现点阵/光学混合 ≥40% → 越界修拉」、§3.1 判据①表面/②混合机制。

**为何是风格级反例**：只换「色彩由什么表面承载」这一关系；证明高更身份轴是平涂零混合（C2），不是「画的是不是塔希提女人」。

## CE-G2 — 反转空间：把「层叠浅空间」改成单点透视深景

**操作**：保留平涂、暗轮廓、朱红/铬黄、装饰纹样、象征色区；但把 §8.2-5 的水平色带 ≥2 层、消失点 0 命中，换成有消失点的深景与空气透视渐变天空。

**被破坏的规则**：
- R5（§8.2-5 L223「线性透视消失点 0 命中、天空非渐变」）→ 失效；
- R1（渐变带面积 ≤10%）→ 天空空气透视破；
- C4（层叠浅空间 × 装饰同权）被拆：深空间把图案压成背景细节，渲染级别差 >1 级（破 R6）。
- 对应 §8.1 负向 `single-point perspective, deep space, atmospheric effects, aerial perspective`。

**为何是风格级反例**：只反转空间关系，未改任何题材；证明「无消失点色带层叠 × 装饰同权」（C4）是纯几何关系。

## CE-G3 — 保留色名撤掉边界：淡彩色板还在，但改宽渐变 + 厚涂笔触

**操作**：保留朱红/铬黄/铬绿/钴蓝/紫色名与非自然色区（R7 不动）；把硬边界改成宽灰渐变带（塞尚/马蒂斯侧），色块内加覆盖 ≥60% 的厚涂方向性笔触。

**被破坏的规则**：
- R1（内部明度 σ ≤5%、色相变化 ≤8°）→ 厚涂笔触直接 fail；
- R4（§8.2-4 L222「边界梯度带 ≤1% 短边、相邻明度跳变 ≥15%」）→ 宽渐变失效；
- R2（暗轮廓覆盖 ≥60% 边界）→ 边界被渐变吃掉，失去可测落点（破 C3）；
- 对应 §4 越界警报①（渐变/笔触 >5% 且无轮廓 → 马蒂斯/塞尚）、③（厚涂 + 补色全振 → 梵高）。

**为何是风格级反例**：色板名完全保留、题材全在，风格仍不成立——反驳「认出朱红+铬黄就是高更」。也说明「硬边界」是梯度带关系，不是「用了哪些颜料」。

## CE-G4 — （内容泄漏反证）把「必须有布列塔尼农妇/十字架/vahine」升为必要条件

**操作**：不改任何像素，只在集成时把 §8.1 的 `Breton women in white coiffes / wayside calvary / vahine in a tropical grove` 写成 §8.1b 无条件前提。

**被破坏的规则**：
- 后果：§4 P4/P5/P6 明写「定时期与题材档」、P6 是「方法/组稿参数不进画面重叠计算」；抽象色带海报与 UI 图标族正例会被误判「不像高更」。
- 这正是「有模块/能抽取/已做纯风格迁移」混淆（01-AUDIT A06）：内容档位被当成风格前提。

**为何是风格级反例**：本反例破的是规则写法，不是像素；命名农妇/宗教器物是**题材档位**，不是风格前提。
