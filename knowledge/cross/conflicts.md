**判定方法**：把每条 §8.2 规则归到一个「轴」（明暗过渡带宽度 / 直方图分布 / 笔触可见度 / 饱和度 / 色相面积 / 高光计数 / 运动预算 / 深度衰减 / 反约束覆盖面…），同轴规则做数值或布尔求交：**交集为空 → 硬冲突；交集非空但需显式取值 → 记入 §4 near-miss 表**。

**计数**（分母 = 18 条，与 §1 总表逐行一致）：硬冲突 **12** 条 · 覆盖冲突 **5** 条 · 退化冲突 **1** 条。

## 2. 逐条冲突

### C-01　硬阴影：Lane B 默认反约束 × 卡拉瓦乔硬光戏剧 / 米开朗基罗硬边阴影（种子案例）

- **涉及模块**：Lane B 模板（全部卡）｜卡拉瓦乔 §4 P1 + §8.2-1｜米开朗基罗 §8.2-3
- **冲突点（双方原文）**
  - Lane B 模板级（`knowledge/domains/motion-graphics/origin/提示词全文.md` L40）：「4. **别做成（固定位置）**：3–4 条反向约束，每条都在封堵一个默认退化行为——交叉淡化冒充形变、默认塑料材质、**硬阴影**、运动模糊、淡入淡出转场、发光字、细字体、半像素位置、互补色、多个强调色。」`[史料]`
  - Lane B 01 卡（同文件 L60）：「别做成：默认的塑料材质、**硬阴影**、全画面都清楚。」`[史料]`
  - 卡拉瓦乔（`caravaggio.md` L76，§4 P1 强档）：「单一硬光（画外、高置 30°–60° 仰角），无反射、无补光，**亮部边界硬**」，默认 **85%**（"本模块强档即其身份"）；§8.2-1（L213）：「全帧可见光源数 = 0（光从画外来）」。`[归纳]`
  - 米开朗基罗（`michelangelo.md` L175，§8.2-3）：「**硬边阴影**：形体转折处的明暗过渡带 ≤ 画面短边的 0.6%…即"凿出来"的边缘。」`[归纳]`
  - Lane B 侧旁证（`blender/workflow.md` L442）：「0.1 → 3 px 是刀切；2.0 → 235 px 是柔光。差 78 倍。出厂 `size=0.25`，就是「硬阴影」的默认值——这正是 01 卡「别做成：硬阴影」要封堵的东西。」`[实测]`
- **后果**：Lane B 的禁令**原意**是封堵 Blender 出厂灯光 `size=0.25` 造成的「未调节刀切阴影」；但它以「硬阴影」字样进入模板后，字面上同时封堵了卡拉瓦乔（整条 P1 强档）与米开朗基罗（§8.2-3）的**有意控制**硬阴影。照抄即互相抵消：产出退回「柔和自然光」，正是 `expansion.md` §2.2 记录的现状（G1：四份核心档案的默认/强档输出在提示词层排除硬光）。
- **组合时怎么解**
  1. **判别口径**：把「硬阴影」拆成两个量——**半影宽度**（可控参数）与**是否显式声明**（意图）。Lane B 禁的是「未声明光源尺寸的默认硬阴影」；卡拉瓦乔/米开朗基罗要的是「显式声明的半影宽度上限」。
  2. **显式覆盖**：卡内含硬光模块时，把反约束句 **「别做成：…硬阴影…」整条改写**为：「别做成：多光源、环境补光、背景发亮、软边扩散；主光半影宽度必须显式给出（Blender 侧 `light.size` 值 / 2D 侧半影 ≤ 画面短边 0.6%）」。（改写建议原句见 `caravaggio.md` §8.3。）
  3. **条件**：仅当卡内**画风段**出现「硬光 / 硬边阴影 / 半影上限」的显式声明时才覆盖；否则保留默认禁令。
  4. **验收**：自查表加一项「半影宽度（像素）」实测值；Lane B 已有现成测法（`blender/workflow.md` 半影宽度表）。

### C-02　明暗过渡带宽度：达·芬奇 ≥1.5% 短边 × 米开朗基罗 ≤0.6% 短边

- **涉及模块**：达·芬奇 §8.2-1/-2｜米开朗基罗 §8.2-3
- **冲突点（双方原文）**
  - 达·芬奇（`da_vinci.md` L162，§8.2-2）：「**明暗带宽度**：任一"受光面→阴影面"的过渡带宽度 **≥ 画面短边的 1.5%**（即不存在一条线上明暗突变）。」；§8.2-1（L161）：「**无硬边**：…人物区域内的连续边缘链长度 ≤ 40 px；超过即判"轮廓线泄漏"。」`[归纳]`
  - 米开朗基罗（`michelangelo.md` L175）：「形体转折处的明暗过渡带 **≤ 画面短边的 0.6%**（对比达·芬奇模块的 ≥1.5%）。」`[归纳]`
  - 米开朗基罗 §4 使用建议（L71）：「（与达·芬奇模块**天然互斥**，注意主辅 70/30 分配）。」`[归纳]`
- **后果**：同一量（过渡带宽度占短边比例）一侧要求 ≥1.5%、另一侧 ≤0.6%，**交集为空**（1920 宽下 = ≥28.8 px vs ≤11.5 px）。同帧双标准不可能满足；agent 会静默二选一或折中成中间值（约 20 px），两边判分都不过——产出「既不达芬奇也不米开朗基罗」。档案已自我标注「天然互斥」，但没有给出组合时的**处置规则**（只有 70/30 这个比例词）。
- **组合时怎么解**
  1. **轴所有权**：过渡带宽度是**单主轴**。70/30 组合时，该轴归主模块，**辅模块的这条规则整条移除**（不是调档）——因为 §8.2 是判分规则而非强度旋钮。
  2. **若必须共存 → 分区**（唯一可行拆分）：写死区域分配表，例如「人脸与手（达芬奇柔边 ≥1.5%）/ 肌肉转折与衣物（米开朗基罗硬边 ≤0.6%）」，并要求自查按区域分别测量（用人物区域掩膜分区跑边缘宽度统计）。**未写分区表则不许组合**。
  3. **验收**：自查表在冲突轴上只保留主模块一行。

### C-03　直方图：达·芬奇中间调 ≥55% × 卡拉瓦乔中间调 ≤25% + 暗带 ≥40%

- **涉及模块**：达·芬奇 §8.2-3｜卡拉瓦乔 §4 P3 + §8.2-3
- **冲突点（双方原文）**
  - 达·芬奇（`da_vinci.md` L163，§8.2-3）：「**中间调占比**：帧直方图中 L∈[40,70] 的像素 **≥ 55%**；纯黑（L<8）与纯白（L>92）合计 ≤ 3%。」`[归纳]`
  - 卡拉瓦乔（`caravaggio.md` L215，§8.2-3）：「**中间调压缩（直方图双峰）**：亮度直方图中，中间带 [0.35, 0.65] 像素占比 **≤ 25%**；暗带 [0, 0.25) 占比 **≥ 40%**。」；§4 P3 默认 30%（"比强档松一档，保可读性"）`[归纳]`
- **后果**：两条规则覆盖同一区间（[0.40,0.65]），一个要求 ≥55%、一个要求 ≤25%——**空交集**。且卡拉瓦乔的「暗带 ≥40%」与达·芬奇的「纯黑+纯白 ≤3%」虽不直接矛盾，但同时执行会得到一张「亮调灰画」：两个模块的身份特征全部消失（这是退化冲突的典型形态）。
- **组合时怎么解**
  1. **不可拆分**：直方图是**全帧统计量**，无法按区域分配（分区统计会改变判分口径）。→ 只能**二选一**。
  2. **显式覆盖**：以主模块的直方图规则为唯一验收标准；把辅模块的该条**整条删除**（不是降档）。
  3. **已有一半的解法**：`caravaggio.md` §8.1 已写「与达·芬奇模块组合时：只借用其**人物结构的体感**，禁止其 sfumato 的柔边与全调域（两条规则的冲突点就是"光的硬度轴"两端）」——本清单把它升级为模板级规则：**在「光的硬度轴」上只能有一位持有者**（见 §3 N3）。
  4. **实验口径**：A-12 的 E2（达芬奇+米开朗基罗 / 毕加索+马蒂斯）应补一组 **E2b 达·芬奇+卡拉瓦乔**，用来验证本条的处置是否可判分。

### C-04　直方图单桶上限：塞尚「无单一桶 >20%」× 卡拉瓦乔「暗带 ≥40% + 背景均匀」

- **涉及模块**：塞尚 §8.2-7｜卡拉瓦乔 §8.2-2/-3
- **冲突点（双方原文）**
  - 塞尚（`cezanne.md` L181，§8.2-7）：「**明度直方图**：全帧 L* 直方图**无单一桶占比 >20%**（防止大面积均匀天空块）；暖冷像素占比均在 30–70% 之间。」`[归纳]`
  - 卡拉瓦乔（`caravaggio.md` L214，§8.2-2）：「**背景明度上限**：背景区域…最大亮度 ≤ 0.10 × 全帧最大亮度；**背景亮度标准差 ≤ 全帧 5%（禁光晕渐变）**」；§8.2-3（L215）：「暗带 [0, 0.25) 占比 ≥ 40%」`[归纳]`
- **后果**：卡拉瓦乔要求的「暗带 ≥40%」+「背景大面积、近黑、无渐变（标准差 ≤5%）」在直方图上必然表现为**若干暗桶合计 ≥40%**——按 10% 分桶，至少一个桶 >20%。塞尚的规则正是为了排除这种「大面积均匀块」（他的目标是暖冷交错编织）。两条同时执行则卡拉瓦乔的背景压暗机制被拆掉。
- **组合时怎么解**
  1. **改写塞尚规则的作用域**：把「全帧」改为**「受光区 + 中间调区」**（即排除暗部/背景区后的直方图），保留其防「大面积均匀天空」的本意，同时不误伤近黑背景。这是**可拆的**——因为塞尚规则的真实目标是「亮部不许有大片均匀块」。
  2. **条件**：仅当卡内出现「背景明度上限 ≤10%」类规则时启用该改写；否则保留全帧口径。
  3. **验收**：自查脚本需分两个掩膜（背景掩膜 / 非背景掩膜）分别跑直方图，并记录两套数字。

### C-05　表面系统：达·芬奇「笔触不可见、只有渐变」× 梵高/莫奈/塞尚「笔触全覆盖、禁平滑区」

- **涉及模块**：达·芬奇 §8.2-7｜梵高 §8.2-3 + §8.2-7｜莫奈 §8.2-1｜塞尚 §8.2-1
- **冲突点（双方原文）**
  - 达·芬奇（`da_vinci.md` L167，§8.2-7）：「**笔触不可见**：平坦区域的高频能量（Laplacian 方差）≤ 2——即画面上看不到笔触纹理，**只有渐变**。」`[归纳]`
  - 梵高（`van_gogh.md` L204，§8.2-3）：「**厚涂模拟**：**≥95% 画面被笔触覆盖**；每笔带上亮下暗 1–2 px 边；全画无 >12 px 的无笔触平滑区。」；§8.2-7（L208）反约束：「出现…**平滑渐变填充**…任一出现即判不合规。」`[归纳]`
  - 莫奈（`monet.md` L200，§8.2-1）：「短逗号形笔触，长 4–12 px、间距 2–6 px，覆盖率 90–100%；**不得出现 >12 px 的无笔触平滑区**。」`[归纳]`
  - 塞尚（`cezanne.md` L175，§8.2-1）：「**笔触覆盖率 ≥80%**（边缘检测密度判定）。」`[归纳]`
- **后果**：达·芬奇的「Laplacian ≤2 + 只有渐变」与梵高「每笔上亮下暗 1–2 px 边」是**同一像素统计量的两端**（高频能量），数学互斥；梵高把「平滑渐变填充」列为失败项，而达·芬奇把它列为**唯一合法表面**。这是「笔触轴」上的镜像禁令：一边把对方的核心机制写成违规项。
- **组合时怎么解**
  1. **轴所有权 + 反约束重算**：笔触轴单主。以达·芬奇为主时，梵高的 §8.2-3 与 §8.2-7 中的「平滑渐变填充」条必须**删除**（其余反约束保留）；以梵高/莫奈为主时，达·芬奇 §8.2-7 删除，且 §8.2-2 的「过渡带 ≥1.5%」需改写为「笔触过渡带」口径。
  2. **可拆分方案（限于分层题材）**：把画面分为「主体表面」（笔触方）与「远景/空气层」（渐变方，即达·芬奇式 sfumato 只用于远景）。要求显式写「哪一层归谁」+ 分层掩膜。
  3. **模板注记**：反约束段必须与画风段做一致性检查（§3 N1）。

### C-06　饱和度：马蒂斯「每块 ≥70%」× 毕加索「全帧均值 ≤35%」（+达·芬奇/莫奈/米开朗基罗同侧）

- **涉及模块**：马蒂斯 §4 P1 + §8.2-1｜毕加索 §8.2-1｜达·芬奇 §8.2-4｜莫奈 §8.2-3｜米开朗基罗 §8.2-6
- **冲突点（双方原文）**
  - 马蒂斯（`matisse.md` L180，§8.2-1）：「**色数**：同屏纯色块 ≤ 8（含黑白）；**每块饱和度 ≥70%**，明度分层 ≤3 级；除纸张底色外，任何渐变面积 ≤5% 画面。」；§4 P1 默认 85%（"全画面高纯度纯色对撞，无灰阶缓冲"）`[归纳]`
  - 毕加索（`picasso.md` L167，§8.2-1）：「**色数**：全帧唯一色相 ≤5（分析档 ≤3），明度级（L* 分桶）≥6；**平均饱和度（HSL S）≤35%**。」`[归纳]`
  - 同侧旁证：达·芬奇 §8.2-4（`da_vinci.md` L164）「全帧平均 HSV 饱和度 ≤ 0.35；S>0.6 的像素 ≤ 5%」；莫奈 §8.2-3「饱和度中低（S ≤65%），避免高饱和撞色」；米开朗基罗 §8.2-6「全帧平均饱和度 ≤ 0.5；强调色（S>0.6）同屏 ≤ 2 种」。`[归纳]`
- **后果**：若马蒂斯的「每块 ≥70%」作用于大面积色块（其 §8.2-4 要求最大色块占 25%–45%），则全帧均值必然显著 >35%——**空交集**。四个模块（达·芬奇/毕加索/莫奈/米开朗基罗）在同一轴上站在同一侧，马蒂斯独自在另一侧 → 马蒂斯与**任何**「低饱和」模块组合都会触发本条。
- **组合时怎么解**
  1. **轴所有权**：饱和度轴单主；70/30 时辅模块的饱和度**均值型**规则删除。
  2. **可拆方案（推荐）**：把马蒂斯的规则从「每块」改写为「**主体色块**（面积 ≥ 画面 5% 者）每块 ≥70%」，并规定**背景/次级块**走另一模块的饱和度规则。这样得到「主体高饱和 + 背景灰调」的组合，两个模块的特征都可辨认。
  3. **条件**：辅模块的规则必须是「区域型」（如「背景 S ≤35%」）才可拆；若辅模块给的是**全帧均值**型，不可拆（见 §3 N4 判别标准）。

### C-07　表面着色系统：丢勒「排线是唯一明暗手段」× 北斋「无排线、色块平涂」

- **涉及模块**：丢勒 §4 P1/P2 + §8.2-1/-3/-7｜北斋 §8.2-1/-2/-6
- **冲突点（双方原文）**
  - 丢勒（`durer.md` L206，§8.2-1）：「**明度→线密度单调映射**：…像素亮度 L∈[0,1] 决定排线间距 **s = lerp(8px, 1.2px, 1−L)**；线宽恒定 1.5–2px。」；§8.2-3（L208）：「**任何区域单色实心填充 ≤5% 画面面积**（画框/边线例外）」；§8.2-7（L212）：「排线应在缩小时自然融合为灰，**不得**出现新的实心区（出现即说明原图用了填充而非排线）」`[归纳]`
  - 北斋（`hokusai.md` L188，§8.2-1）：「**线宽**：轮廓线宽恒定，同一元素内变化 ≤30%；**无排线、无羽化**（线与色块之间无抗锯齿过渡带 >1px）。」；§8.2-6（L193）：「天空/水面**单色平涂**或留白 ≥35% 面积」`[归纳]`
  - 附同轴子冲突：丢勒 §4 P2（`durer.md` L76）「**线端收锋**…强：每根线中段鼓、端点成尖；**单线宽变化 2–3 倍**（默认 65%）」× 北斋 §8.2-1「线宽恒定，同一元素内变化 ≤30%」。`[归纳]`
- **后果**：丢勒的明暗**只能**由排线产生（禁实心填充）；北斋的明暗**只能**由平涂色块产生（禁排线）。二者对「明暗怎么来」给出互斥的唯一解——同帧不可能同时满足。线宽子冲突同理（2–3 倍变化 vs ≤30%）。
- **组合时怎么解**
  1. **着色系统二选一**（不可拆分：二者都是「全画面」机制，没有自然分区）。以丢勒为主时，北斋只贡献**构图类**参数（P2 非对称、P3 尺度对比、P6 负空间），其 §8.2-1/-6 的表面规则全部移除；以北斋为主时，丢勒只贡献题材/符号堆叠（P5）与几何秩序（P6）。
  2. **明确禁止**「丢勒排线 + 北斋平涂」的拼接式组合——会得到「线稿上贴色块」的第三种风格（既非铜版也非浮世绘），且两条规则都判不合格。
  3. **线宽轴**：若两者都不持有（即不组合作画），该轴由 Lane B 侧「线宽不变」类卡（08 一笔画 L144「别做成：…线宽变化…」）持有——三方一致，见 §4 near-miss 表。

### C-08　运动模糊：Lane B 默认禁令 × 01/12 卡自身要求；× 卡拉瓦乔/维米尔定格要求

- **涉及模块**：Lane B 模板 L40 + 11 卡 L180｜Lane B 01 卡 L56 + 12 卡 L188｜卡拉瓦乔 §8.2-6｜维米尔 §8.2-8
- **冲突点（双方原文）**
  - Lane B 模板（L40）：「…**运动模糊**、淡入淡出转场…」列为默认退化行为；11 卡（L180）：「别做成：**运动模糊**、半像素位置、顺滑缓动的角色。」`[史料]`
  - Lane B 01 卡（L56，画风段）：「大面积柔光、软阴影…**快动作带运动模糊**」；12 卡（L188）：「**快动作插 1 帧拉长的残影**；烟、火花、速度线都手画」`[史料]`
  - 卡拉瓦乔（`caravaggio.md` L218，§8.2-6）：「**定格瞬间**：每帧只允许 1 个"动作极值"…**运动模糊核 = 0**」`[归纳]`
  - 维米尔（`vermeer.md` L241，§8.2-8）：「**全画面静止，单一事件在动**：除事件区域（牛奶流/烛焰/烟）外，帧间差 **Δ ≤1%**」`[归纳]`
- **后果**：三处冲突叠在一起——① Lane B **内部**：「别做成：运动模糊」与 01 卡画风段「快动作带运动模糊」字面矛盾（同一张卡的正反段互斥）；② 跨车道：卡拉瓦乔「运动模糊核 = 0」、维米尔「静止」与 01 卡「快动作带运动模糊」不可共存；③ 12 卡的「1 帧残影」是**有意的**运动模糊变体，也被 L40 的字面禁令覆盖。
- **组合时怎么解**
  1. **Lane B 侧已有半条解法**（`blender/workflow.md` L504）：「01 卡「别做成」里有「运动模糊」一条，指的是**滥用**（全片都糊）。所以它应该**只在「快动作」帧开启**，或者用逐帧开关 `scene.render.use_motion_blur` 精确控制。」`[归纳]` → 把它升级为模板条款：**运动模糊是帧级开关，不是全片属性**。
  2. **改写句式**：「别做成：运动模糊」→「别做成：**无差别**的运动模糊（全片糊）；只允许出现在显式声明的快动作帧」。
  3. **跨车道条件**：卡内含定格类模块（卡拉瓦乔/维米尔）时，快动作帧开关**全程关闭**，并在自查表加「全片运动模糊帧数 = 0」。
  4. **验收**：Lane B 已有现成测法（`blender/workflow.md` §3.7：开/关像素差，实测 max 0.647）。

### C-09　运动预算：梵高「全画面漩涡 2–6°/s」× 维米尔「事件区域外 Δ ≤1%」

- **涉及模块**：梵高 §8.2-4/-5｜维米尔 §8.2-8
- **冲突点（双方原文）**
  - 梵高（`van_gogh.md` L205，§8.2-4）：「**漩涡运动**：天空笔触随旋度场漂移，**角速度 2–6°/s**；漩涡中心 2–3 个，半径 ≥ 画宽 25%。」；§8.2-5（L206）：「**星体规则**：星 = 亮核 + ≥2 圈同心环…**闪烁周期 0.8–1.5 s**、幅度 ≤±10%」`[归纳]`
  - 维米尔（`vermeer.md` L241，§8.2-8）：「除事件区域（牛奶流/烛焰/烟）外，**帧间差 Δ ≤1%**」`[归纳]`
- **后果**：梵高的运动是**全画面场**（天空、麦田、星体同时动），维米尔允许的运动是**单点事件**。同帧双标准下：梵高的天空漂移直接违反维米尔 Δ≤1%；维米尔的静止让梵高的漩涡/闪烁参数无处安放。二者对「一帧里允许几个运动区域」给出不同答案（全画面 vs 1 个）。
- **组合时怎么解**
  1. **新增可判定量「运动区域数」**：维米尔 = 1；梵高 = 全画面场（可记为 ∞ 或「场驱动」）。组合时按主模块取其一。
  2. **可拆方案（题材分层）**：把画幅分为「事件区」（维米尔规则：唯一运动点）与「氛围层」（梵高规则：低频场运动，角速度降到 ≤1°/s）。需显式写分层掩膜与两层各自的角速度上限——**否则不可拆**。
  3. **验收**：帧差图按掩膜分区统计，分别与 Δ≤1% / 角速度上限比对。

### C-10　深度衰减：莫奈「大气包络」× 塞尚「反大气透视 + 空间压缩」

- **涉及模块**：莫奈 §4 P3 + §8.2-4｜塞尚 §4 P4 + §8.2-5
- **冲突点（双方原文）**
  - 莫奈（`monet.md` L203，§8.2-4）：「**包络规则**：**远景对比度 ≤ 近景的 60%**；从远到近存在**单调对比度梯度**（线性拟合 R² ≥0.8）。」；§4 P3「大气包络强度…强：≤60%，全画色相向单一大气色收拢（**雨/雾/晨昏；边界外=透纳领域**）」`[归纳]`
  - 塞尚（`cezanne.md`，§4 P4）：「**空间压缩度**…强：多点透视 + 远近同尺度 + **反大气透视**」；§8.2-5（L179）：「**空间**：无单点透视…**远景物体高度 ÷ 近景同类物体高度 ≥0.5**（空间压缩）」`[归纳]`
- **后果**：同一深度轴，莫奈要求「越远越糊越淡」（单调对比度衰减），塞尚要求「远处不衰减」（反大气透视，用色阶而非雾来暗示空间）。同帧双标准下 R²≥0.8 的单调梯度与「反大气透视」互斥；若强行折中，会得到「远景既没雾也没压平」的平庸空间。
- **组合时怎么解**
  1. **可拆（分层）**：按地平线分层——**远景层/天空层**用莫奈包络（对比度梯度、色相收拢）；**中近景体块**用塞尚压缩（高度比 ≥0.5、多点透视）。要求：① 显式写分层边界；② 包络的单调梯度**只在远景层内**拟合（否则 R² 判据失效）；③ 近景层不许出现雾色。
  2. **不可拆的替代**：若题材无明确分层（如纯静物），则深度轴单主，另一模块的深度规则整条移除。
  3. **实验口径**：A-12 的 E2 建议加一组 **莫奈+塞尚**（现表只有莫奈+梵高、达芬奇+米开朗基罗、毕加索+马蒂斯）。

### C-11　高光计数：卡拉瓦乔「高光连通域 ∈[2,5]」× 维米尔「点状高光 100+」

- **涉及模块**：卡拉瓦乔 §8.2-4｜维米尔 §4 P3 + §8.2-3
- **冲突点（双方原文）**
  - 卡拉瓦乔（`caravaggio.md` L216，§8.2-4）：「**光斑三处法则**：高光连通域（**亮度 ≥ 0.9 × max**）数量 ∈ [2, 5]，且每个连通域必须与"脸 / 手 / 关键道具"之一相交；人物背部的高光连通域数 = 0。」`[归纳]`
  - 维米尔（`vermeer.md` L88，§4 P3）：「**点状高光密度**（Pointillé Density）…强：**满画面数百点**（Rijksmuseum 对 *The Milkmaid* 的描述："hundreds of colourful dots"）」，默认 50%（人物特写）/ 80%（静物）；§8.2-3（L236）：「圆点直径 **1–3 px**（1024 px 宽画布）；软边 σ = 0.5–1 px；数量按 P3 分档（0–2 / 5–20 / 100+）」`[归纳]`
- **后果**：若「高光连通域」按卡拉瓦乔的定义（亮度 ≥0.9×max）全帧统计，维米尔的 100+ 个 pointillés 中只要有 6 个达到该亮度阈值就违规——**数值互斥**。这是两个模块最核心的签名特征之间的直接对撞（卡拉瓦乔「光只落在三处」vs 维米尔「光撒成几百点」）。
- **组合时怎么解**
  1. **拆成两个可判定类别（推荐，唯一实用解）**：
     - **主光斑**：面积 ≥ 画面 0.05% 的连通域 → 受卡拉瓦乔 [2,5] 约束；
     - **点状高光**：直径 1–3 px（1024 宽基准）的连通域 → 计入维米尔 P3 分档，**不计入** [2,5]。
  2. **必须写死的量**：面积阈值（建议 0.05% 画面 = 1024×576 下约 295 px²）、亮度阈值是否统一（建议点状高光阈值降到 ≥0.85×max，主光斑保持 ≥0.9×max）。
  3. **条件**：仅当两模块同帧组合时启用分类口径；单模块卡保持原定义（避免改写档案）。
  4. **验收**：自查脚本输出两个计数（主光斑数 / 点状高光数），各自对照自己的模块标准。

### C-12　色相面积预算：北斋「蓝 ≥40%」× 卡拉瓦乔「土色系收窄」× 梵高「互补对近 1:1」

- **涉及模块**：北斋 §4 P1 + §8.2-2｜卡拉瓦乔 §4 P5 + §8.1｜梵高 §4 P3 + §8.2-2
- **冲突点（双方原文）**
  - 北斋（`hokusai.md` L189，§8.2-2）：「**色数**：主色 ≤7（普鲁士蓝、靛蓝、白/纸、赭、灰、黑、一点淡红或淡黄）；**蓝色系面积占比 ≥40%**。」`[归纳]`
  - 卡拉瓦乔（`caravaggio.md` L80，§4 P5 强档）：「色相多、含冷色与高纯色（晚期以后被弃）→ **近乎单色阶：赭/红棕/铅白/黑，饱和色仅出现在道具**」，默认 60%（罗马期）；§8.1 正向段：「restrained earth palette — ochre, madder red, lead white, bitumen black」`[归纳]`
  - 梵高（`van_gogh.md` L203，§8.2-2）：「**色数限制**：色相簇 ≤8…且 **≥2 对互补簇同帧出现**」；§4 P3 强档：「双互补对同时在场（黄-紫 + 橙-蓝），**并置面积接近 1:1**」，默认 70%`[归纳]`
- **后果**：三者对**同一面积预算**（画面的色相配比）提出不可同时满足的主张：北斋把 ≥40% 锁给蓝；卡拉瓦乔的暗部是赭/棕/黑（无蓝，蓝最多作为道具上的饱和点缀）；梵高要求互补对（蓝↔橙）接近等面积。北斋×卡拉瓦乔组合时，「蓝 ≥40%」与「色域收窄至土色」直接对冲。
- **组合时怎么解**
  1. **新增字段「色相面积预算表」**：每个模块在卡内显式声明「主色相 + 目标面积占比」；组合时按主模块归一化。
  2. **硬规则**：**同一张卡内只允许一个模块主张「主色面积 ≥40%」**；其余模块的色相主张降到点缀级（≤10% 面积）。若两个模块都主张 ≥40%（如北斋蓝 + 马蒂斯某主色块 25–45%），则判为不可组合，必须二选一。
  3. **梵高的互补对**在 70/30 下按辅模块处理：保留「≥2 对互补簇**出现**」，把「面积接近 1:1」降为「≥1:3 即可」——**降档要写进卡里**，不许静默。
  4. **验收**：逐帧输出色相面积直方图，对照预算表逐项打勾。

### C-13　阴影色相：塞尚「阴影+轮廓蓝 ≥15%」× 卡拉瓦乔「深棕黑暗部」

- **涉及模块**：塞尚 §8.2-4｜卡拉瓦乔 §4 P5 + §8.2-2/-7
- **冲突点（双方原文）**
  - 塞尚（`cezanne.md` L178，§8.2-4）：「**蓝调**：**阴影与轮廓区域中蓝色像素（H 200–250°）占比 ≥15%**；天空与地面区域的平均饱和度差 ≤15%。」`[归纳]`
  - 卡拉瓦乔（`caravaggio.md` L214，§8.2-2）：「背景区域…最大亮度 ≤ 0.10 × 全帧最大亮度」；§8.2-7（L219）：「**暗部保细节**：暗区（亮度 < 0.15）内部亮度标准差 ≥ 1.5/255（非死黑）」；§4 P5 强档「赭/红棕/铅白/黑」；§8.1 正向段：「deep dark brown ground left visible inside the shadows as their mid-tone」`[归纳]`
- **后果**：卡拉瓦乔的暗部是**深棕底（bitumen/dark ground）**，色相落在橙红—棕区；塞尚要求暗部 ≥15% 像素落在蓝区（H 200–250°）。同帧双标准下：卡拉瓦乔的暗部若满足塞尚就变成「蓝调暗部」（丢掉深棕底这一 §1-3/§2-4 的核心机制），反之塞尚的自查判不合格。
- **组合时怎么解**
  1. **可拆（区域改写）**：把塞尚规则的作用域从「阴影与轮廓区域」收窄为**「轮廓区」**（物体轮廓线及其 ±2 px 带），保留其「蓝网贯穿」的本意；暗部色相归卡拉瓦乔（深棕）。
  2. **条件**：仅当卡内存在「暗部色相被另一模块锁定」的声明时启用；否则保留原口径。
  3. **验收**：自查脚本分掩膜统计（轮廓带 / 暗部区），分别对照 ≥15% 与「深棕主导」。

### C-14　渐变：Lane B 06/07/13 卡反约束 × 达·芬奇/莫奈（+09 卡自身）

- **涉及模块**：Lane B 06 卡 L120、07 卡 L132、13 卡 L204（行号指 `knowledge/domains/motion-graphics/origin/提示词全文.md`）｜达·芬奇 §8.2-2/-7｜莫奈 §8.2-4｜（内部）09 卡 L152
- **冲突点（双方原文）**
  - Lane B 06（L120）：「别做成：弹性过冲、**渐变**、圆角、半透明叠色、几样东西一起进场。」；07（L132）：「别做成：大面积实色、**渐变按钮**…」；13（L204）：「别做成：**渐变**、线宽不一、同一帧全弹出来、淡入淡出转场。」`[史料]`

- **组合时怎么解**
  1. **反约束必须标注适用域**：06/13 卡的「别做成：渐变」适用域 = **UI 元件 / 平涂形状内部**（原意是禁止按钮式渐变与材质渐变），不是全画面。
  2. **改写句式**：「别做成：渐变」→「别做成：**形状内部的装饰性渐变**（按钮/图标式）；允许且仅允许**用于明暗过渡的连续渐变**（过渡带 ≥ 画面短边 1.5%）」。
  3. **条件**：卡内出现「sfumato / 大气包络 / 明暗过渡带」类正向规则时启用该改写。
  4. **模板级一致性检查**：见 §3 N1。

### C-15　色数上限 × 金属金彩（克里姆特类模块）

- **涉及模块**：Lane B 15 卡 L224、14 卡 L212/L216、06 卡 L116、07 卡 L128（行号均指 `knowledge/domains/motion-graphics/origin/提示词全文.md`；模板级同族表述在 L40「多个强调色」）｜马蒂斯 §4 P4 边界注 + §8.2-8｜`expansion.md` §2.2 G4
- **冲突点（双方原文）**
  - Lane B 15 卡（L224，画风段）：「高饱和，**同屏不超过三种颜色**」；14 卡（L212）：「浅灰蓝底、深灰字，**只用一个强调色**」，别做成（L216）：「…**第二个强调色**」；06 卡（L116）：「只用红、黄、蓝、黑加纸色」；07 卡（L128）：「…**只用这两种色**」`[史料]`
  - 马蒂斯（`matisse.md` L82，§4 P4 边界注）：「P4 只调**图案密度**，其承载面恒为"平涂纯色、无材质"…它**不含**材质区分、**金属/金箔表面**、纹理明度范围与"写实面孔 × 装饰"的渲染方式对撞——需要这些时不属于本模块，**应交给克里姆特类模块**（另立参数：材质对比度 / 纹理明度范围 / 写实-装饰渲染落差）。」；§8.2-8（L187）：「三档共同硬约束：**纹样区内部明度动态范围 ≤5%**（与"带材质图案"的分界）」`[归纳]`
  - `expansion.md`（L346，G4）：「**装饰图案系统 + 金属材质**…克里姆特（仅剩**带材质/金属/纹理密度**的图案与写实面孔对撞）」`[归纳]`
- **后果**：金箔/金属的本质是**高动态范围的高光材质**（局部接近纯白 + 强反射）。它与「同屏 ≤3 色」「只用一个强调色」的**色数上限**直接冲突（金 = 第 4 色）；同时马蒂斯的「纹样区明度动态范围 ≤5%」会把金箔高光整条排掉。→ 只要沿用现有色数口径，G4 缺口（金属材质）在 Lane B 侧**永远补不上**：不是能力缺失，是计数口径把它锁死了。
- **组合时怎么解**
  1. **色数计数口径分层**：模板显式规定色数上限**只约束「平涂色块层」**；**金属/金箔/高光材质层单列**，不计入色数，但必须限制面积（建议 ≤5% 画面，与马蒂斯「渐变 ≤5%」同量级）与明度上限（允许到 100%，即豁免马蒂斯的 ≤5% 动态范围约束，但仅限该层）。
  2. **改写句式**：「别做成：第二个强调色」→「别做成：第二个强调**色相**（金属/高光材质层除外，其面积 ≤5% 画面）」。
  3. **条件**：仅当卡内声明了「金属/金箔/装饰金彩」材质层时启用豁免。
  4. **后续**：本条在克里姆特档案落地（wave4+）后需回填实测阈值。

### C-16　反约束适用域：「没有高光的平涂」× 平涂系模块（马蒂斯/毕加索/北斋）

- **涉及模块**：Lane B 02 卡 L72｜马蒂斯 §8.2-1/-2｜毕加索 §8.2-6｜北斋 §8.2-1/-6
- **冲突点（双方原文）**

  - 马蒂斯（`matisse.md` L180，§8.2-1）：同屏纯色块 ≤8、每块饱和度 ≥70%、渐变面积 ≤5%；§8.2-2（L181）：「所有形状边缘为"剪裁边"——**无描边、无羽化、无投影**」`[归纳]`

- **组合时怎么解**

### C-17　负空间：米开朗基罗「连续空白背景 ≤15%」× 北斋「留白 ≥35%」/ 马蒂斯「背景可见 ≥20%」

- **涉及模块**：米开朗基罗 §8.2-4｜北斋 §4 P6 + §8.2-6｜马蒂斯 §8.2-5
- **冲突点（双方原文）**
  - 米开朗基罗（`michelangelo.md` L176，§8.2-4）：「**构图密度**：主体人群占画面面积 ≥ 55%；**连续空白背景区域 ≤ 画面 15%**。」`[归纳]`
  - 北斋（`hokusai.md` L193，§8.2-6）：「**负空间**：天空/水面单色平涂或留白 **≥35% 面积**」；§4 P6 默认 40%`[归纳]`
  - 马蒂斯（`matisse.md` L184，§8.2-5）：「**负空间**：相邻形状间隙 ≥ 最短边长的 2% 且 ≤12%；**背景/纸色可见面积 ≥20%**。」`[归纳]`
- **后果**：空白预算互斥：≤15%（米开朗基罗）与 ≥35%（北斋）/ ≥20%（马蒂斯）**空交集**。这条同时暴露了一个口径问题：米开朗基罗的「空白背景」与北斋的「负空间」是不是同一个量？——若把北斋的留白算作「平涂的天空/水面」（有颜色、有笔触边界）而非「空白」，则两者可部分共存。**必须先统一口径再判分**，否则自查表自相矛盾。
- **组合时怎么解**
  1. **定义对齐（必须写进卡）**：**空白 = 无内容区域**（纯背景/纸色/未画区域）；**留白 = 低信息密度区域**（平涂色块、单色天空也算）。两者分开统计。
  2. **判分规则**：米开朗基罗规则只约束「空白 ≤15%」；北斋/马蒂斯规则只约束「留白 ≥35% / ≥20%」。二者可同时成立（如：满构图人物 + 大块平涂天空）。
  3. **若不做定义对齐**，则本条按硬冲突处理（二选一）。

### C-18　形体塑造：米开朗基罗「浮雕式强明暗 + 投影」× 毕加索/马蒂斯「全平涂零渐变、无投影」

- **涉及模块**：米开朗基罗 §4 浮雕强度 + §8.2-3｜毕加索 §4 P3 + §8.2-6｜马蒂斯 §4 P3 + §8.2-2
- **冲突点（双方原文）**
  - 米开朗基罗（`michelangelo.md` §4，L67）：「**浮雕强度**（塑形 vs 平涂）…强：形体像从墙面"凿出"，**硬边投影**」，默认 65%；§8.2-3（L175）硬边阴影 ≤0.6% 短边`[归纳]`
  - 毕加索（`picasso.md` §4 P3，L73）：「**平面化程度**（明暗渐变的残留）…强：全平涂面片拼合，**零渐变**」，默认「**强档**（分析期）」；§8.2-6（L172）平涂判据 ΔE≤6 占比 ≥85%`[归纳]`
  - 马蒂斯（`matisse.md` §4 P3，L76）：「**平面化程度**…强：全平涂 + 无消失点，深度仅靠面积/遮挡」，默认 **80%**；§8.2-2（L181）：「无描边、无羽化、**无投影**」`[归纳]`
- **后果**：形体塑造方式互斥：一边用明暗建模（浮雕感、投影），一边明令禁止渐变与投影。同帧双标准下主体要么被凿出来（违反平涂判据 ΔE≤6 ≥85%），要么被压平（违反浮雕强度与硬边阴影规则）。列为**退化冲突**（而非硬冲突）的原因：两者的作用对象可分离（人物 vs 背景/装饰），存在可行的分区解。
- **组合时怎么解**
  1. **分对象拆分（推荐）**：主体人物 = 米开朗基罗式建模（允许明暗与投影）；背景/装饰面 = 平涂（ΔE≤6 ≥85%、无投影）。要求显式写「主体掩膜」并分区判分。
  2. **马蒂斯「无投影」的改写**：「无投影」→「**主体外无投影**（主体自身允许 ≤1 个投影，且必须与主体轮廓相连）」。
  3. **比例**：按 70/30 时，主模块的塑造方式覆盖 ≥70% 画面面积（可判定：掩膜面积比）。
